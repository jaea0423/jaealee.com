누나, 이거 지금 시작해야 해
핵심 한 줄. 혼자 쇼핑몰 운영하는 사람한테 AI는 "직원 한 명"이에요. 그런데 월급이 2만 원이에요. 그리고 한국어 잘하고, 새벽 3시에도 일해요. 안 쓸 이유가 없어요.

① 1인 사업자에게 가장 잘 맞아요

상품 설명 쓰기, 고객 답변, 인스타 캡션, 매출 분석. 평소에 누나 혼자 다 하던 일을 "초안 80%"는 클로드한테 시키고, 누나는 "검토·다듬기"만 하면 돼요.

② 하루 1-2시간이 비어요

상품 상세 페이지 하나 쓰는 데 1시간 걸렸다면, 클로드 쓰면 10분이에요. 단순 반복 업무를 줄이면 진짜 중요한 일(상품 소싱, 마케팅 기획)에 시간 쓸 수 있어요.

③ 경쟁자들은 이미 쓰고 있어요

지금 잘되는 1인 셀러들은 거의 다 AI를 써요. 안 쓰는 사람은 점점 뒤처져요. 지금이 격차 벌어지기 전 마지막 타이밍이에요.

④ 진입 비용 거의 0원

무료로도 충분히 써볼 수 있고, 본격적으로 쓰려면 월 2만 원이에요. 일주일이면 손에 익어요. 미루면 미룰수록 손해예요.

AI는 누나 일을 뺏는 게 아니라, 누나가 안 해도 되는 일을 가져가는 거예요. 그래서 누나는 더 큰 일을 할 수 있어요.

01클로드가 뭔가요?

한 줄 요약. 클로드(Claude)는 대화형 AI예요. 채팅창에 한국어로 말 걸면, 사람처럼 답해주고 일도 해줘요.

"AI 챗봇"이 뭐예요?

네이버 검색창 같은 거예요. 근데 검색 결과 링크를 주는 게 아니라, 직접 답을 해주고 문서를 써줘요. 예를 들어:

  • "상품 상세 설명 좀 써줘" → 바로 써줍니다
  • "이 엑셀 파일 분석해줘" → 파일 올리면 분석해줍니다
  • "고객한테 사과 메시지 어떻게 보내지?" → 시안 3개 만들어줍니다

누가 만들었어요?

Anthropic(앤트로픽)이라는 미국 AI 회사가 만들었어요. 2021년에 설립됐고, 구글·아마존이 거액을 투자한 회사예요. 회사 모토가 "안전한 AI 만들기"라서, 다른 AI들보다 답변이 솔직하고 신중한 편이에요.

참고

"Claude(클로드)"는 사람 이름처럼 부르는 거예요. 정보 이론을 만든 수학자 Claude Shannon(클로드 섀넌)에서 따왔다고 해요.

왜 클로드를 추천하나?

제가 누나한테 클로드부터 추천하는 이유는 세 가지예요:

  1. 글이 자연스러워요. 상품 설명·고객 응대 메시지를 쓰면 "AI가 쓴 티"가 가장 안 나요. 한국어 어순·존댓말이 안정적이에요.
  2. 긴 자료를 잘 봐요. 엑셀 파일, PDF 매뉴얼, 거래처 계약서 같은 긴 문서를 통째로 올려도 처리해요.
  3. 거짓말을 덜 해요. 모르면 "모른다"고 말하는 성향이 강해요. 1인 사업할 땐 잘못된 정보가 위험하니까 이게 중요해요.
현실적인 조언

꼭 하나만 써야 한다는 법은 없어요. 둘 다 무료 버전이 있으니 같이 써보고, 결국엔 한두 개에 정착하면 돼요. (이건 25번에서 자세히 다룰게요.)

03사람들이 어디에 써요?

요약. "공부할 때만 쓰는 거 아냐?"라고 생각하시는데, 실제로는 회사·자영업·일상 거의 모든 영역에 써요.

📝 글쓰기·콘텐츠

상품 설명, 블로그 글, 인스타 캡션, 메일·공문, 보고서 초안. AI가 가장 잘하는 영역이에요.

📊 자료 분석

엑셀 매출 데이터, PDF 계약서, 긴 회의록을 올리면 핵심을 뽑아주고 정리해줘요.

💡 아이디어 회의

혼자 운영하면 의논할 사람이 없잖아요. 클로드를 "마케팅 팀원"이라고 생각하고 브레인스토밍할 수 있어요.

💬 고객 응대

까다로운 반품·환불 요청에 어떻게 답할지, 답장 시안을 여러 개 받아서 골라 쓰면 돼요.

📚 학습·번역

모르는 개념 쉽게 설명받기, 영어 자료 번역, 외국 셀러 메시지 응대 같은 것도 됩니다.

🗂️ 단순 작업

긴 텍스트 요약, 데이터 정리, 표 만들기, 양식 통일 같은 잡일을 빠르게 처리해요.

04가입하고 첫 화면 둘러보기

요약. 3분이면 끝나요. claude.ai로 들어가서 구글 계정으로 가입하면 됩니다.

가입 절차

  1. 크롬·사파리·엣지 등 웹브라우저에서 claude.ai 접속
  2. "Sign up" 또는 "회원가입" 클릭
  3. 구글 계정으로 가입(추천) 또는 이메일로 가입
  4. 이름 입력 → 휴대폰 인증 (한국 번호 가능)
  5. 완료! 바로 채팅창이 나와요.

구글 계정으로 가입하면 비밀번호 따로 관리 안 해도 되고, 나중에 구글 드라이브 연동도 쉬워요.

첫 화면 구성

들어가면 보이는 화면을 친구처럼 풀어드릴게요:

기본 화면 구조
  • 왼쪽 사이드바 — 새 대화 시작 버튼, 이전 대화 목록, Projects, 설정

  • 오른쪽 위 프로필 — 설정·요금제·로그아웃
처음에는 이거만 기억하세요

07질문 잘하는 법 — 프롬프트 4원칙

요약. AI한테 질문 잘하는 법을 프롬프트(Prompt)라고 해요. 잘 쓰면 답변 품질이 2~3배 좋아져요. 외울 건 4가지뿐이에요.

4가지 원칙

① 맥락(Context) 주기

"누가, 어떤 상황에서, 누구한테 보여줄 건지" 알려줘요. 같은 질문도 맥락을 알면 답이 달라져요.

② 역할(Role) 부여

"너는 10년 차 카피라이터야" 같이 캐릭터를 주면 답변 톤이 그쪽으로 맞춰져요.

③ 예시(Example) 보여주기

"이런 느낌으로 써줘 [예시 첨부]"하면 원하는 결과에 훨씬 빨리 도달해요.

④ 형식(Format) 지정

"표로 정리해줘", "3줄 이내로", "마크다운으로" 같이 결과 형식을 미리 말해줘요.

실전 비교 — 좋은 예 vs 나쁜 예

케이스 1. 상품 설명 부탁할 때

✗ 나쁜 예
"이 헤어밴드 설명 좀 써줘"
✓ 좋은 예
"(역할) 너는 10년 차 여성 패션 카피라이터야. (맥락) 내 쇼핑몰은 20대 여성 타겟이고, 자사몰에 올릴 상품 상세야. (작업) '벨벳 헤어밴드 5종 세트' 상품 설명을 써줘. (형식) ① 후킹 한 줄 ② 본문 5줄 ③ 해시태그 5개 순서로. (톤) 친구한테 추천하듯 다정하게."

케이스 2. 고객 답변 요청할 때

✗ 나쁜 예
"고객한테 답장 어떻게 쓰지?"
✓ 좋은 예
"환불 요청 받았어. 상황은: 배송 7일 지난 상품이고 사용 흔적이 있어서 정책상 환불 어려운 상황. 고객은 강하게 항의 중. 답장 시안 3개 만들어줘. ① 단호하지만 정중한 톤 ② 공감 우선 톤 ③ 부분 해결 제안 톤으로."

한 줄로 기억하기

"누가" "누구한테" "뭘" "어떻게" — 이 4개만 챙기면 답변 품질이 달라져요.
완벽주의는 금지

처음부터 완벽한 프롬프트를 쓰려고 하지 마세요. 대충 물어보고 → 답 보고 → 마음에 안 들면 추가 주문하기가 가장 빠른 방법이에요. 대화하듯 다듬어가면 돼요.

08내 스타일대로 설정 — 개인 프롬프트

요약. 매번 "친근하게 답해줘", "쇼핑몰 운영자야" 하고 설명하기 귀찮잖아요? 한 번만 등록해두면 모든 대화에 자동 적용되는 기능이 있어요.

두 가지 설정 방법

① User Preferences (사용자 선호) — 누구나 무료

설정에 들어가서 "나는 어떤 사람이고, 어떻게 답해줬으면 좋겠다"를 적어두면, 클로드가 모든 대화에서 그걸 기억해요.

10대화 관리 — 저장·검색·이어가기

요약. 대화는 자동으로 저장돼요. 왼쪽 사이드바에서 이전 대화 다시 찾고, 이어서 대화도 할 수 있어요.

핵심 4가지 동작

➕ 새 대화 시작

왼쪽 위 "+ New chat" 또는 단축키. 주제 바뀔 때마다 새로 시작하는 게 좋아요(클로드가 헷갈리지 않게).

🔍 이전 대화 검색

사이드바 검색창에 키워드 입력하면 옛날 대화 찾아줘요. "헤어밴드 캡션" 검색하면 그 주제 대화들 다 나옴.

↩️ 대화 이어가기

옛날 대화 클릭하면 그 자리에서 이어서 메시지 보낼 수 있어요. "지난번 그 캡션 좀 더 짧게 다듬어줘" 가능.

🗑️ 삭제·이름 변경

대화 위에 마우스 올리면 ··· 메뉴 나옴. 이름 바꾸거나 삭제 가능. 정리 잘 해두면 나중에 찾기 쉬워요.

대화 정리 팁 (1인 셀러용)

대화가 쌓이면 찾기 힘드니까, 제목을 일관성 있게 다는 습관을 들이는 게 좋아요. 예시:

11Artifacts — 결과물 따로 만들기

요약. Artifacts(아티팩트)는 클로드가 만든 결과물을 오른쪽에 따로 띄워서 보여주는 기능이에요. 글·표·웹페이지 같은 걸 깔끔하게 확인하고 다운로드할 수 있어요.

언제 자동으로 나오나?

특정 요청을 하면 클로드가 알아서 Artifacts 창을 열어요:

  • "상세 페이지 HTML로 만들어줘"
  • "상품 리스트를 표로 정리해줘"
  • "긴 글(2000자 이상) 써줘"
  • "간단한 웹페이지 만들어줘"

1인 셀러 활용 예시

📝 긴 상품 설명

스크롤 길어지는 상세 페이지 본문. 오른쪽 창에서 편하게 보면서 다듬어요.

📋 상품 비교표

"내 상품 10개 비교표 만들어줘" 하면 깔끔한 표로 만들어줘요. 복사해서 블로그·상세 페이지에 붙이면 끝.

🎨 간단한 랜딩 페이지

"신상품 소개 미니 홍보 페이지 HTML로 만들어줘" → 진짜 웹페이지 형태로 결과를 받음.

📅 일정·체크리스트

"이번 주 마케팅 체크리스트 만들어줘" → 항목별 정리된 문서로 받음.

활용 팁

Artifacts에 나온 결과물은 오른쪽 위에서 복사·다운로드할 수 있어요. 마음에 안 들면 그 안에서 바로 "여기 부분만 다시 써줘" 하면 그 부분만 수정돼요.

12Projects — 자료 모아 작업하기

요약. Projects(프로젝트)는 "같은 주제로 계속 작업할 때 쓰는 폴더"예요. 자료를 넣어두면 클로드가 그 자료 기억해서 답해줘요.

일반 대화 vs Projects 비교

일반 대화의 한계
매번 새 대화에서 "내 쇼핑몰은 이런 컨셉이고, 톤은 이렇고..." 처음부터 설명해야 함. 귀찮음.
Projects의 장점
프로젝트에 브랜드 가이드, 톤 설명, 자주 쓰는 자료를 한 번만 올려두면 그 프로젝트 안의 모든 대화가 자동으로 그 자료를 참고함.

이수연 님 추천 프로젝트 구조

예시 1. "내 쇼핑몰 마케팅" 프로젝트

등록할 자료:

  • 브랜드 컨셉 문서 (타겟, 톤, 컬러, 가치)
  • 기존에 잘 됐던 인스타 캡션 모음
  • 상품 카탈로그 (이름·가격·특징)
  • 고객 페르소나 정리

활용: 새 상품 캡션·상세 페이지 작성 시 이 프로젝트에서 대화 시작 → 클로드가 톤·컨셉 알아서 맞춰줌

예시 2. "고객 응대 매뉴얼" 프로젝트

등록할 자료:

  • 환불·교환 정책
  • 자주 묻는 질문 정리
  • 이전에 잘 된 답변 모음 (베스트 케이스)

활용: 새 고객 문의 답변할 때 이 프로젝트에서 시작 → 정책에 맞춘 답변 자동 생성

만드는 법

  1. 왼쪽 사이드바 → "Projects" 클릭
  2. "+ New project" → 프로젝트 이름 입력
  3. 프로젝트 설명("Custom instructions") 칸에 기본 설정 입력 (예: "내 쇼핑몰 톤은 다정하고 친근함")
  4. 오른쪽 "Project knowledge"에 자료 파일 업로드
  5. 이제 그 프로젝트 안에서 새 대화 시작하면 끝!
유료 기능

Projects는 Claude Pro 이상에서 풀로 쓸 수 있어요. 무료에선 제한적이라, 본격적으로 쓸 거면 Pro 가입을 고려하세요. (23번 요금제에서 자세히)

13Memory & 과거 대화 검색

요약. 클로드가 "누나에 대한 정보"를 기억해두는 기능이에요. 매번 자기소개 안 해도 돼요.

두 가지 기억 방식

① Memory (메모리) — 자동 기억

대화하면서 클로드가 "이건 기억해둘 만하다"고 판단되는 정보를 자동으로 저장해요.

  • "제 쇼핑몰 이름은 ○○이에요" → 기억됨
  • "저는 2001년생이에요" → 기억됨
  • "주로 패션 카테고리 다뤄요" → 기억됨

이후 새 대화에서도 클로드가 이 정보를 알고 있어요.

② Past chats 검색 (과거 대화 검색)

지난 대화 내용을 클로드가 찾아서 활용할 수 있어요. "지난번에 그 헤어밴드 캡션 어떻게 썼더라?"라고 물어보면 찾아줘요.

설정 확인

Settings → Profile → "Memory" 토글이 켜져 있어야 작동해요. 기억된 정보는 같은 메뉴에서 확인·삭제 가능. 잘못 기억된 게 있으면 "이건 잊어줘"라고 말해도 돼요.

14그 외 — 웹 검색, 스타일 설정

요약. 클로드는 기본적으로 학습된 정보로 답해요. 최신 정보가 필요하면 웹 검색 기능을 켜면 돼요.

웹 검색 (Web Search)

대화 중에 "최근 ○○ 트렌드 알려줘" 같은 질문을 하면 클로드가 자동으로 인터넷을 검색해서 답해줘요. 구체적으로 켜라고 안 해도 알아서 동작해요.

  • "최근 인스타에서 뜨는 패션 트렌드 뭐야?"
  • "오늘 환율 어때?"
  • "이번 주 네이버 인기 검색어 정리해줘"

구글 드라이브 연동 (Connectors)

Claude Pro 이상에선 구글 드라이브를 연동할 수 있어요. 그러면 "내 드라이브의 ○○ 파일 분석해줘" 가능해요.

스타일 (Styles) — 빠른 톤 전환

8번에서 한 번 다뤘죠. 짧게 다시 정리하면:

  • Default — 기본 톤
  • Concise — 짧고 핵심만
  • Explanatory — 자세히 설명
  • Custom — 직접 만든 스타일 (고객 응대용·SNS용 등)

핵심. 클로드한테 "상품 정보 + 타겟 + 톤"만 던지면 상세 페이지 본문 80%가 나와요. 누나는 다듬기·사실 확인만 하면 끝.

3단계. 다듬기

  • "두 번째 매력 부분이 너무 평범해. 좀 더 구체적이고 와닿게 다시 써줘."

20Claude Cowork — 데스크톱 업무 자동화

핵심. Cowork(코워크)는 "디지털 직원"이에요. 클로드한테 "이 폴더 정리해줘", "이 자료들 모아서 보고서 만들어줘" 시키면 진짜로 컴퓨터에서 작업해서 결과물을 만들어줘요.

일반 채팅 vs Cowork 차이

일반 채팅
"어떻게 하면 되는지 설명해줘요." → 누나가 직접 따라해야 함
Cowork
"누나 컴퓨터에서 직접 작업해서 결과물을 만들어줘요." → 결과물만 받으면 됨

핵심 특징

  • 데스크톱 앱 전용 — 웹 버전엔 없어요. 데스크톱 앱(5번)을 깔아야 써요.
  • 로컬 파일 직접 접근 — 누나가 지정한 폴더 안에서 파일을 읽고, 수정하고, 새로 만들어요.
  • 여러 단계 자동 수행 — "1번 하고, 2번 하고, 3번 결과 보고 4번 결정" 같은 다단계 작업 가능.
  • 모바일에서 작업 시작 — 폰으로 "이거 해줘" 보내면, 데스크톱이 알아서 돌아요 (단, PC 켜져 있어야 함).

1인 셀러용 활용 시나리오 5가지

📁 ① 파일 정리

"내려받은 상품 사진 100장이 폴더에 뒤죽박죽인데, 상품별로 폴더 만들어서 분류해줘." → 알아서 정리해서 폴더에 넣어줍니다.

📑 ② 자료 모아 리포트

"이번 달 매출 엑셀, 광고 데이터, 인스타 인사이트 자료를 모아서 월간 리포트 만들어줘." → 통합 분석 문서를 생성.

🔁 ③ 반복 작업 자동화

"신상품 폴더의 모든 사진을 1080×1080으로 리사이즈하고, 워터마크 넣어줘." → 일괄 처리.

🌐 ④ 웹 리서치

"경쟁사 5개 인스타 분석해서 최근 마케팅 트렌드 정리해줘." → 브라우저 자동 사용해서 자료 수집.

📊 ⑤ 데이터 정리

"고객 문의 엑셀에서 환불 관련만 추출해서 카테고리별로 정리하고 빈도수 분석해줘." → 정리된 엑셀 반환.

⏰ ⑥ 예약 작업 (Scheduled Tasks)

"매주 월요일 아침 9시에 지난주 매출 요약 리포트 만들어 둬." → 자동 반복.

실행 흐름

  1. 데스크톱 앱을 열고, 상단 탭에서 "Cowork" 선택 (Chat / Cowork / Code 세 개 있음)
  2. 작업할 폴더를 선택 (예: /내문서/쇼핑몰/2026년5월)
  3. 한국어로 작업 지시 (예: "이 폴더의 상품 사진들 카테고리별로 정리해줘")
  4. 클로드가 계획을 먼저 보여주고, 누나가 "OK" 하면 실행
  5. 진행 상황 실시간 확인 가능. 중간에 멈추거나 방향 바꿀 수 있음
  6. 완료되면 결과물 폴더에서 확인
중요 · 안전 사항

Cowork는 누나 컴퓨터에서 실제로 파일을 만들고 수정해요. 중요 파일은 백업해두고 시작하세요. 그리고 파일 삭제는 항상 확인 받음 (클로드가 마음대로 못 지움). 처음에는 덜 중요한 폴더로 연습해보세요.

21Claude Code — 참고용으로만 알고 가세요

요약. Claude Code는 개발자(프로그래머)용 도구예요. 누나한테는 직접적으로 필요 없지만, "이런 게 있다"는 것만 알면 돼요.

뭐 하는 거예요?

프로그래머가 코드 작성·수정·디버깅(버그 잡기)할 때 쓰는 명령줄(터미널) 도구예요. 검은 창에 명령어 쳐서 쓰는 거라 비개발자한테는 진입 장벽이 높아요.

누나가 알아도 되는 이유

  • 나중에 자사몰 사이트를 직접 개선하고 싶을 때 개발자한테 의뢰하면 "Claude Code로 작업했다"는 말 들을 수 있어요.
  • Cowork가 이 Claude Code를 비개발자용으로 쉽게 만든 거예요. 그래서 "Cowork의 형님 격"이라고 생각하면 돼요.
  • 혹시 나중에 코딩 배우고 싶어지면, 클로드와 Claude Code로 시작하면 진입이 쉬워요.
결론

당장은 "개발자용 도구가 따로 있다"만 기억하시면 돼요. 누나 업무엔 Cowork가 훨씬 잘 맞아요.

자동차 비유로 이해하기

Haiku
빠름·가벼움
경차 같은 모델. 가볍고 빠르고 싸요. 짧은 질문·간단한 답변에 최적. "이 문장 맞춤법 확인해줘", "한 줄로 요약해줘" 같은 단순 작업.
Sonnet
균형
중형 세단 같은 모델. 가장 많이 쓰는 표준 모델. 글쓰기·분석·일반 대화 90%는 이걸로 충분해요. 기본값으로 이거 쓰면 됨.
Opus
최상위
대형 럭셔리 세단. 가장 똑똑하지만 느리고 비싸요. 복잡한 분석, 긴 보고서, 까다로운 글쓰기에 써요. 아껴서 쓰세요.

24한계와 주의점

핵심. 클로드는 만능이 아니에요. 세 가지 한계를 알고 쓰면 사고 안 나요.

① 할루시네이션(Hallucination) — 환각

가장 중요한 한계예요. 클로드가 가끔 그럴듯한 거짓말을 해요. 모르는 걸 자신 있게 말하는 거예요.

실제 예시

"○○ 도매상 연락처 알려줘" → 클로드가 그럴듯한 가짜 전화번호 알려줄 수 있어요. 그대로 믿고 전화하면 낭패.

대처법

  • 구체적 사실(전화번호·주소·법조항·통계)은 반드시 직접 검증하세요.
  • "모르면 모른다고 말해줘"라고 프롬프트에 명시하면 환각이 줄어요.
  • 최신 정보(가격·트렌드)는 웹 검색 켜고 물어보세요.
  • 중요한 결정에 쓸 정보는 두 번째 출처로 교차 확인 필수.

② 최신 정보의 한계

클로드는 학습된 시점 이후 정보를 모를 수 있어요. "어제 뉴스 어떻게 됐어?" 같은 건 웹 검색이 켜져야 답해요.

대처법

  • "최신 정보로 검색해서 답해줘"라고 명시하기
  • 날짜·연도가 중요한 정보는 다시 한 번 확인
  • 가격·환율·트렌드는 항상 실시간 출처에서 확인

③ 개인정보·기밀 관리

절대 올리지 말 것

① 고객 실명·전화번호·주소·주민번호

꼭 분석이 필요하면 해당 정보만 지우거나 가명으로 바꿔서 올리세요. 클로드는 패턴 분석에 진짜 이름이 필요 없어요.

④ AI 의존 경계

너무 의존하면 누나만의 감각·판단이 무뎌져요. 클로드는 "보조 도구"이지 "대체자"가 아니에요. 최종 결정은 항상 누나가.
