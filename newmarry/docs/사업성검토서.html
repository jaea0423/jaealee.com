1. 결론 요약

"적자만 아니면 해 볼 만하다"는 기준에서는 사업성이 있습니다. 변동비가 거의 없고 고정비가 월 약 3.75만 원 수준이라, 예식이 월 5건만 결제돼도 손익분기를 넘습니다. 다만 큰 수익을 기대할 사업은 아닙니다. 기준 시나리오(연 240건)에서도 연 순이익은 약 150만 원이며, 규모를 키우려면 청첩장 등 상위 브랜드 확장이 필요합니다.
  • 강점: 요청→준비→진행→현황→결과를 한 흐름으로 묶은 서비스를 검색 범위에서는 찾지 못했습니다. 신랑신부가 실시간 현황을 보고, 정산 차액·식권 출납까지 다룹니다.
  • 약점: 결혼은 1회성이라 재구매가 없고, 신규 유입은 입소문과 검색에 의존합니다. 현금·개인정보를 다루는 만큼 신뢰와 보안이 사업의 전제입니다.
  • 가장 큰 리스크: 수익 부족이 아니라 현장 사고(오입력·접속 장애)와 개인정보 문제입니다. 이는 설계와 운영 방침으로 대응 가능합니다(6장).
  • 권고: 진행(3)·정산·결과(5) 화면을 먼저 만들고, 지인 결혼식 1~2건으로 실사용 검증 후 결제를 연결합니다. 투자 금액이 작아 실패 비용이 낮습니다.

2. 서비스 정의와 구조

정의: 축의대를 대신 서주는 대행이 아니라, 축의대를 서는 사람과 맡긴 사람을 위한 운영 도구(소프트웨어)입니다. 현금 보관·접수 책임은 이용자에게 있음을 약관과 소개 문구에 명시합니다.

2.1 5단계 흐름

단계내용과금
1. 요청축의대 요청(일시, 요청 사항)을 간략히 전달하는 페이지무료
2. 준비담당자, 식장, 진행 방식, 식권 배부 방식, 돌발상황 처리 방식을 합의해 정리한 문서무료
3. 진행현장 실시간 입력(성명, 금액, 식권, 메모), 식권 출납부, 정산·최종 제출9,900원(결제 시점)
4. 현황신랑신부(및 열람 허용된 혼주)가 하객 수, 식권, 축의금 내역을 실시간 확인포함
5. 결과정산 결과 리포트(HTML), 엑셀 내보내기, 인계서 출력, 계좌이체·별도 수령분 후입력포함

2.2 확정된 핵심 설계

  • 입력 구조: 신랑측/신부측 섹션을 분리하고 섹션당 입력자 1명입니다. 순번은 섹션별로 매기며 봉투 번호를 겸합니다.
  • 입력 항목: 성명(필수, 무기명 체크 가능), 금액(만원 단위 + 직접 입력, 숫자와 한글 병기), 식권(기본 0장, +/-), 메모. 선물 항목은 두지 않고 메모로 받습니다.
  • 입력 모드: 현장 금액 입력 / 후정산(현장에서는 식권만 기록) 중 신랑신부가 초기 설정에서 선택합니다.
  • 안전장치: 100만 원 이상 입력 시 재확인(기준 변경 가능), 동명이인 경고, 삭제 대신 변경 이력, 로컬 우선 저장 후 동기화, 수시 백업 버튼.
  • 식권 출납부: 축의대 외 배부(무축의 요청, 혼주·가족, 진행팀, 반환)를 사유별로 기록하고 정산 때 시작·잔여 장수와 대조합니다.
  • 정산: 권종별 현금 장수 입력 후 시스템 합계와의 차액 표시, 차액 사유 메모, 인계서 출력(서명 없음), 최종 제출 시 입력 잠금.
  • 유효기간: 예식일로부터 3개월 후 열람 불가 및 실제 삭제. 만료 전 알림과 결과 파일 다운로드 안내.

3. 시장 분석

3.1 시장 규모 (공식 통계 기준)

  • 2024년 혼인 건수(혼인신고 기준)는 약 22.2만 건으로 전년 대비 14.8% 증가했습니다.
  • 2025년 1~9월 누적 혼인은 17만 6,178건으로 전년 동기보다 8.9% 증가했고, 혼인 증가세는 18개월 연속입니다(국가데이터처 발표 보도 기준).
  • 월별 혼인은 12월(10.1%), 5월(9.4%), 1월(9.0%) 순으로 많았고(2024년), 예식 성수기인 9~10월에는 대여 업체 예약이 꽉 찬다는 보도가 있습니다.
  • 2026년의 최신 연간 통계는 확인하지 못했습니다.
해석 주의: 혼인 건수는 혼인신고 기준이라 실제 결혼식 개최 건수와 같지 않습니다. 결혼식을 하지 않는 부부도 포함되므로, 시장 규모를 연 22만 건으로 곧바로 쓰면 과대 추정입니다. 아래 시나리오는 점유율이 매우 낮은 구간(0.03~0.3%)만 다룹니다.

3.2 경쟁 현황 (검색 범위 내, 전수 조사 아님)

3.3 모바일 청첩장 가격대 (확장 검토용)

  • 확인된 사례: 크몽 판매자의 맞춤 제작 기본형이 49,000원부터입니다(판매자 홍보 문구이므로 시장 평균으로 보기 어려움).
  • 셀프 제작 도구로 무료 제작하는 사례도 보도됩니다. 대형 플랫폼(바른손, 보자기카드 등)의 가격표는 확인하지 못했습니다.
  • 시사점: "무료 기본 + 유료 옵션" 시장일 가능성이 큽니다. 20% 번들 할인은 약한 유인이며, RSVP 응답을 식권 매수 예측으로 잇는 데이터 연동이 더 강한 결합 이유입니다.

4. 수익 모델과 손익 분석

4.1 가격 정책

  • 예식 1건당 9,900원 단일 가격(신랑측·신부측·식당 구분 없음, 양쪽 모두 이용해도 동일).
  • 1·2번 무료 개방, 3번(진행) 활성화 시점부터 결제.
  • 추천인은 폐쇄형: 결제를 마친 예식 건에만 코드를 발급하고 1회 사용 시 7,900원. 추천인 보상은 없음.
  • 감사문자 발송, 고급 디자인 유료화는 하지 않음(연락처 미수집, 발신번호 연동 부담).

5. 성장 경로와 확장

  • 유입: 결혼은 입소문과 지인 추천의 영향이 크다고 판단합니다(검증 필요). 결과 페이지(5번) 하단의 서비스 소개, 폐쇄형 추천 코드, 안내문·체크리스트 같은 무료 콘텐츠로 검색 유입을 만듭니다.
  • 확장: 결혼 전반을 아우르는 상위 브랜드(이름 미정)를 따로 두고, 축의지기는 그 안의 서비스로 둡니다. 모바일 청첩장의 RSVP 응답이 식권 매수 예측으로 이어지는 데이터 연동이 결합의 핵심입니다.
  • 보류: 예식장·웨딩 커뮤니티 제휴는 초기 필수 요소로 보지 않고 추후 검토합니다.
