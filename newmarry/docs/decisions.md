# 축의지기 결정 사항 정리 (2026-10 기준)

대화로 합의한 내용을 모았습니다. 화면 규칙은 `CLAUDE.md`에, 사업성 분석 전문은 `사업성검토서.pdf`에 있습니다.

## 서비스 정의

- 축의대 **대행이 아니라 운영 도구**. 신랑신부가 등록하고, 축의대 담당자(가족·친구)가 노트북으로 접수·정산한다.
- 단계: 등록 → 설정 → 요청 → 준비 → 진행 → 현황 → 결과 (7단계).
  - 초기에는 요청·준비·진행·현황·결과 5단계로 불렀으나, "요청"은 신랑신부 → 담당자에게 보내는 부탁, "준비"는 담당자용 가이드로 재정의하면서 신랑신부용 등록·설정을 앞에 분리했다.
- 서비스명 **축의지기** (축의장은 기각). 상위 웨딩 브랜드명은 미정(모바일 청첩장 등 확장용, 나중에 결정).
- 운영 주체: 와이비테크랩(가족 단일 사업자). 시작 도메인은 jaealee.com 하위 경로(`/newmarry/`), 새 도메인은 추후.

## 요금

- 예식 1건 **9,900원** (VAT 포함), 추천 코드 7,900원. 추천 코드는 폐쇄형, 1회 한정, 추천인 보상 없음.
- 결제 시점: 진행(축의대 열기). 그 전 단계는 무료. 1건 단일 가격, 옵션(감사 문자·고급 디자인) 없음.
- 보관: 예식일 + 3개월 뒤 영구 삭제. 결과 HTML·Excel 다운로드.

## 손익 가정 (사업성검토서 기준, 검증 필요)

- 9,900원 → PG 3% 및 부가세 차감 후 순수입 약 8,703원 (7,900원 → 약 6,945원).
- 고정비 월 약 37,500원 (Supabase Pro $25 × 1,400원 + 도메인 3만 원/년).
- 손익분기 월 5건 / 연 약 56건 (추천 코드 30% 혼합 시 건당 8,176원 기준).
- 시나리오 연 60 / 240 / 720건 → 연 +4만 / +151만 / +544만 원 (소득세·인건비 제외).
- 시장: 2024년 혼인 22.2만 건(+14.8%), 2025년 1–9월 17만 6,178건(+8.9%). 혼인신고 기준이라 예식 수보다 많게 잡힘.
- 경쟁: 크몽 '축의대' 오프라인 파일(이름 충돌 주의), 메리웰, 키오스크 대여(약 20만 원), 개인 부조금 앱. 모바일 청첩장 시장은 "무료 기본 + 유료 옵션" 구조(크몽 기준 49,000원 선).

## 기술 방향 (실제 구현 시)

- 웹앱 + PWA: Service Worker + IndexedDB로 오프라인 우선, 재접속 시 동기화, CSV/Excel 백업 버튼. exe 설치형은 기각.
- 백엔드 Supabase (Auth + RLS). 유료 출시 시 Pro 플랜(월 $25) 예정 — 공식 요금 재확인 필요.
- 로그인·PIN·결제는 개발 마지막에 붙인다.

## 역할·권한

| 역할 | 할 수 있는 일 |
|---|---|
| 신랑신부 (공용 계정 1개) | 설정 전체, 축의대·혼주 PIN 발급, 혼주 열람 켜기, 계좌이체 후입력, 제출 잠금 해제, 열람, 내려받기 |
| 축의대 담당자 (구분별 PIN) | 자기 구분의 접수·수정·취소·식권 출납·정산·최종 제출. 구분당 기기 1대, 입력자 교체는 기록 |
| 혼주 (PIN) | 현황 열람만 |

## 설정 규칙

- 담당자 구분별 최대 4명, 이름·관계 분리.
- 미정 허용 항목: 식권 장수(신랑측/신부측), 도착 시간, 축의대 자리, 인계받을 분, 담당자. 미정이 남으면 축의대를 열 수 없음(진행 전 필수).
- 요청서를 보낸 뒤 바뀐 값에는 "변동" 표시 — 설정, 요청서, 진행 화면 모두.
- 혼주 열람을 켜면 혼주 이름을 적고 PIN이 발급된다.
- 배경 그림 6종 제공, 한복(4번)이 기본. 신랑신부가 직접 올리는 기능은 없음.
- 입력 방식: 현장에서 금액까지 / 금액은 나중에(후정산). 후정산용 금액 입력 화면은 아직 없음.

## 진행 화면 규칙

`CLAUDE.md`의 "진행(축의대) 입력 규칙" 참고. 핵심: 만 원 단위 금액, 식권 단축키, Tab은 입력칸만, 오류는 팝업, 저장 후 순번 배지, 삭제 대신 취소선, 수정 이력, 정산 비교, 제출 잠금, 변동 칩.

## 디자인 결정 이력

1. 분홍·연두 봄 테마 → 2. 사용자 결과 페이지(크림·로즈·골드) 참고 → 3. 밤 정원(남보라 유리) → 4. **낮 꽃밭(흰 유리 카드, 분홍 강조)** 확정.
- 곡률은 애플식 연속 곡률(squircle). 배경은 그림을 화면 전체에 깔고 왼쪽 칸에 신랑신부가 오도록 구도를 고정(`배경구도.jpg`).
- 그림 6장은 사용자가 생성해 제공(봄 들판, 호수 테라스, 요트, 한복, 겨울 설경, 밤 테라스).

## 미결·보류

- 상위 브랜드명, 새 도메인.
- 동명이인 팝업의 Enter 기본값(저장 vs 다시 확인).
- 식권 기본값 0장 유지 여부(현장에서 1장이 더 흔하면 변경 검토).
- 혼주가 현황에서 금액까지 볼지.
- 계좌이체 수정·삭제 UI.
- 첫 실전 검증(지인 결혼식) 시점.
- 법·세무: 개인정보 보호법(명부 저장), 약관, PG 심사, 업태·종목, 과세 유형.
