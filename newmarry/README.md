# 축의지기 화면 시안

결혼식 축의대(봉투 접수·식권·정산)를 노트북 한 대로 운영하는 웹서비스 **축의지기**의 정적 HTML 시안입니다.

- 보기: `index.html`을 브라우저로 열거나 `npm run serve` 후 http://localhost:5173
- 고치기: `src/` 를 수정한 뒤 `python src/build.py` (루트 파일은 생성물)
- 점검: `npm install && npx playwright install chromium` 한 번, 이후 `npm run check`
- 작업 규칙과 합의 사항: `CLAUDE.md`, `docs/decisions.md`
