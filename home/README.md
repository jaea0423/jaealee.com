# 개인 홈 대시보드

공개 주소는 `/home/`입니다. 기존 자료실·일정·뉴스·프로젝트의 주소를 유지합니다.

## 수정 위치

- `index.html`: 화면 구조와 서비스 링크 36개.
- `home.css`: 색상, 크기, 반응형 레이아웃. `.light`에서 밝은 테마를 정의합니다.
- `home.js`: 검색 엔진 전환, 테마, 시계, 바로가기 접기, 날씨와 시세.

빌드나 패키지 설치는 필요하지 않습니다. 저장소 루트를 정적 HTTP 서버로 열고 `/home/`에서 확인합니다. 하위 경로는 사이트 루트 기준이므로 `file://`로 열면 사이트 내부 이동은 동작하지 않습니다.

## 보존할 동작

- Google·Naver·YouTube 검색: 엔진 탭 선택 후 Enter 또는 검색 버튼. 방향키로 탭을 이동합니다.
- 메일 3개, 서비스 36개, `/drive/`, `/schedule/`, `/news/`, `/projects/` 바로가기.
- 테마는 기존 다른 페이지와 같은 `localStorage.dark` 키를 사용하며 미설정 시 어두운 테마입니다.
- 시계·날씨 시간은 서울 기준. Open-Meteo 날씨는 10분, 시세는 기존 주기에 따라 갱신합니다. 숨겨진 탭은 주기적 네트워크 갱신을 생략합니다.
- 기존 Finnhub·Upbit·환율 제공처와 종목 목록을 유지합니다. 이 화면의 데이터는 제공처 상황에 따라 지연되거나 로드에 실패할 수 있습니다.

## 확인 방법

1. JavaScript 문법 검사를 실행합니다: `node --check home/home.js`.
2. 데스크톱과 모바일에서 페이지 전체의 가로 넘침, 검색, 테마 전환, 바로가기 접기를 확인합니다.
3. 외부 API 성공·실패 상태에서 페이지의 다른 기능이 유지되는지 확인합니다.
4. 다른 폴더의 사용자 변경은 이 페이지 커밋에 포함하지 않습니다.

브라우저에서 호출되는 기존 시세 API 키는 비밀 저장소가 아닙니다. 키 관리 방식을 바꿀 때는 서버 프록시 등 별도 설계가 필요하며, 디자인 변경만으로 비공개가 되지 않습니다.
