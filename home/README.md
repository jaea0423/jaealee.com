# 개인 시작 페이지

공개 경로는 `/home/`입니다. 별도 빌드 없이 정적 서버에서 동작합니다.

- `index.html`: 엔진 선택형 검색창 1개, 내 페이지 메뉴, 메일, 서비스 링크 38개.
- `home.css`: 흰색 배경, 기기 기본 글꼴, 반응형 레이아웃. 다크모드는 없습니다.
- `home.js`: 검색, 서울 시간, 춘천 날씨와 기존 관심 시세.

다른 페이지의 테마 저장값은 읽거나 수정하지 않습니다. 학교 목록은 이루리, 강원대학교, 데이터보안활용혁신융합대학 순서로 시작합니다. AI 목록은 ChatGPT가 먼저입니다.

저장소 루트를 HTTP 서버로 열어 `/home/`에서 모바일 가로 넘침, 검색 이동, 링크 순서, 날씨와 시세 로드를 확인합니다. 문법 검사는 `node --check home/home.js`입니다.

외부 데이터는 제공처에 따라 지연되거나 실패할 수 있습니다. 기존 브라우저용 시세 키는 공개 코드에서 보이며 디자인 변경은 키 보관 방식을 바꾸지 않습니다.
