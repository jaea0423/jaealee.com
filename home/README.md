# 통합 개인 홈

`/home/`에서 홈·자료실·뉴스·프로젝트를 같은 테마의 탭으로 전환합니다. 일정 기능은 제거했습니다.

- `index.html`: 4개 패널, 기존 서비스 링크 38개, 과목 6개와 일반 폴더 1개, 프로젝트 3개.
- `home.css`: 라이트모드 테마와 반응형 탭·자료·뉴스 화면.
- `home.js`: 엔진 선택형 검색, 초 단위 서울 시계, 춘천 날씨, 관심 시세.
- `tabs.js`: 키보드 탭 이동, 해시 주소, 프로젝트 분류, 날짜별 뉴스 표시.

직접 주소는 `/home/#drive`, `/home/#projects`, `/home/#news/2026-09-10` 형태입니다. 기존 `/drive/`, `/news/`, `/projects/`와 뉴스 view 주소는 해당 탭으로 연결합니다. 과목 자료와 프로젝트 상세 폴더, 뉴스 데이터는 기존 위치를 유지합니다.

뉴스는 `/news/data/YYYY-MM-DD.json`을 읽습니다. 404인 경우에만 구형 HTML 보관본을 확인해 제한된 iframe으로 표시합니다. 구형 보관본의 내부 디자인은 원본 그대로입니다. 뉴스 데이터가 없을 때와 네트워크 오류는 구분합니다.

검증: 저장소 루트를 HTTP 서버로 열어 탭 전환, 뒤로 가기, 날짜별 뉴스, 자료 링크, 프로젝트 분류, 모바일 가로 넘침을 확인합니다. `node --check home/home.js`와 `node --check home/tabs.js`로 문법을 검사합니다. CSS와 JS를 수정하면 index의 버전 해시도 갱신합니다.

검색 엔진은 이 브라우저에 저장합니다. 입력 중이 아닐 때 `/` 키로 홈 탭의 검색창에 초점을 옮깁니다. 시스템 글꼴과 즉각적인 눌림 반응, 동작·투명도 감소 설정은 apple-design 원칙을 참고합니다.

외부 시세는 제공처에 따라 지연·실패할 수 있습니다. 기존 브라우저용 키는 공개 코드에 보이며 이 작업은 키 보관 방식을 바꾸지 않습니다.
