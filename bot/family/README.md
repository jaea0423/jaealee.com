# 흰둥이·검둥이 — 개인방 시험판

Python 3.10 이상. 표준 라이브러리만 사용합니다. 공개 저장소에는 가족 이름, 봇 토큰, API 키, 대화나 일정을 넣지 않습니다.

## 범위

- 흰둥이: 허용된 한 명의 개인채팅에만 응답. 자연어 일정 초안·조회·변경·취소. ‘맞아’, ‘응’, `/confirm 번호`로 확인. 날짜·시간 미정이면 알림 없음. 사라진 정보는 추측하지 않음.
- 확정 일정: 전날 20시, 당일 09시 알림. 09시 이전 일정은 1시간 전. 예정된 알림 시각에서 2시간 이내만 복구 발송. 일정 시작 후에는 보내지 않음.
- 개인시험에서는 먼저 말을 걸거나 답장을 독촉하지 않음. 일정을 알려달라는 질문 뒤 답이 없으면 미확정 기록을 유지. 사진·음성은 아직 미지원.
- 검둥이: 09시 뉴스, 12시 지식. 홈페이지 당일 JSON을 그대로 글로 변환. 시장 표·출처 URL 제외, 문장 저자/책 표기는 유지. 대화에는 응답하지 않음. 각 발송시간부터 3시간까지 복구 시도, 지난 날짜를 오늘 것으로 보내지 않음.
- 가족방 전송은 설정으로 켤 수 없으며 코드에서 차단됨. 개인시험 후 별도 변경·검증이 필요함.

## 아이맥 설정

1. 최신 저장소를 가져오고 이 폴더에서 `python3 -m unittest -v`를 실행합니다.
2. `config.example.json`을 **저장소 밖** `~/.config/jaealee-family-bots/config.json`에 복사합니다. 폴더 권한 700, 파일 권한 600으로 설정합니다.
3. `white_token`, `black_token`은 해당 봇의 BotFather 토큰입니다. 토큰을 채팅이나 명령 인자에 넣지 마세요.
4. `owner_id`는 시험할 본인의 텔레그램 숫자 사용자 ID입니다. 이름/사용자명/전화번호가 아닙니다. 본인이 두 봇 각각의 개인방에서 시작을 누릅니다.
5. 기본 `ai_provider`는 `gemini`. `gemini_api_key`, `gemini_model`을 입력합니다. 모델은 키에서 사용 가능한 텍스트·구조화 출력 지원 모델을 확인하여 선택합니다. 유료 모델/요금제 활성화는 사용자 승인 후 진행합니다. OpenAI로 바꾸면 `ai_provider: openai`, `openai_api_key`, `openai_model`을 설정합니다.
6. `family`에 실제 이름과 엄마/아빠/누나/형 호칭을 비공개로 기록합니다. 모델에는 최근 대화 10회와 최근 일정 최대 50건을 보냅니다.

본인 ID를 모르면 `pair.py --config 경로`를 먼저 실행한 뒤, 화면에 표시된 일회용 문구를 **흰둥이 개인방**으로 보냅니다. 2분 안에 정확히 일치하는 개인 메시지를 확인해 ID를 저장합니다. 기존 봇 서버가 같은 토큰으로 실행 중이면 먼저 해당 운영 상태를 확인하세요. 이 도구는 기존 webhook을 삭제하지 않습니다.

```sh
# 이 폴더에서 실행. 설정 경로만 인자로 넘기고 키는 넘기지 않습니다.
python3 pair.py --config "$HOME/.config/jaealee-family-bots/config.json"
python3 bots.py white --config "$HOME/.config/jaealee-family-bots/config.json" --probe
python3 bots.py white --config "$HOME/.config/jaealee-family-bots/config.json"
```

흰둥이 개인방에서 ‘안녕’, ‘내일 가족 식사 적어줘’, ‘저녁 6시’, ‘맞아’, ‘일정 보여줘’, ‘그 식사 취소해줘’, ‘응’을 시험합니다. AI 실제 해석·말투는 이 단계에서 검증합니다. 가짜 응답을 쓰는 단위 테스트로 AI 품질을 보장하지 않습니다.

검둥이는 별도 터미널에서 같은 형식으로 `white`를 `black`으로 바꿔 실행합니다. 연결 확인은 `--probe`, 실제 개인방 인사 한 건은 `--send-test`. 지금 원고 미리보기는 Python에서 `digest()`로 만들 수 있습니다. 가족방에는 보내지 마세요.

## 계속 실행

개인시험이 통과하면 아이맥에서 launchd 사용자 서비스를 등록합니다. `install_macos.py --config 경로 --role white`는 서비스 파일만 만듭니다. 출력된 명령을 실행해야 시작합니다. 검둥이도 동일하게 따로 등록할 수 있습니다. 기존 서비스가 있으면 덮어쓰지 않습니다.

사용자 로그인 세션에서 실행되며, 전원 꺼짐·잠자기·인터넷 끊김 동안 작동하지 않습니다. 서비스 폴더와 로그는 저장소 밖입니다. 이 프로그램은 커밋·푸시를 하지 않아 홈페이지 자동 발행과 Git 충돌이 나지 않습니다.

## 복구와 제한

- 당일 원고가 없거나 비어 있거나 읽을 수 없으면 검둥이는 아무 메시지도 보내지 않습니다. 뉴스·지식은 독립적으로 확인합니다. 기존 3시간 복구 범위 안에서 5분마다 다시 확인하며, 어제 원고로 대체하지 않습니다.
- 흰둥이의 AI 연결·해석 실패는 미리 준비한 짧은 존댓말 안내로 처리합니다. 원래 오류 본문을 대화에 노출하지 않고 저장 완료를 주장하지 않습니다. 1분간 AI 호출을 쉬며, 이후 새 사용자 메시지가 있을 때만 다시 시도합니다. `/events` 등 AI 없는 명령은 계속 작동합니다. 자동 공급자 전환은 하지 않습니다.
- AI 응답 형식·날짜·일정 대상 검증은 저장 전에 수행합니다. 다만 정상 형식 안의 사실 오류·의도 오해까지 모두 검출하지는 못하므로 개인방 실제 대화 시험이 필요합니다. 공급자별 안정성은 동일한 대화로 오류율·응답시간·정확성을 비교한 뒤 결정합니다.

- 흰둥이는 하루 AI 호출 최대 100회. 대기·검둥이 발송·일정 알림에는 AI 호출 없음. 토큰 기반 금액 상한은 아니므로 공급자 사용량도 확인합니다.
- 서비스 오류 메시지에는 토큰·가족 메시지를 기록하지 않음. 데이터베이스는 아이맥에 평문 저장되며 파일 권한으로 보호합니다.
- 같은 역할은 동시에 한 프로세스만 실행. 성공한 발송은 재시작해도 반복하지 않습니다.
- 발송 도중 연결이 끊기면 실제 수신 여부를 확정할 수 없어 자동 재발송을 중단합니다. `delivery:*` 값이 `sending`이면 개인방에서 수신 여부를 확인한 뒤 해당 항목만 `sent`로 표시하거나, 미수신이 확실할 때만 지우고 재시도합니다. 데이터베이스 전체를 지우면 중복 발송될 수 있습니다.
- 입력 처리 전에 수신 위치를 저장하므로 그 직후 강제 종료되면 답장/처리가 누락될 수 있습니다. 재시작 후 `/events`로 확인합니다. 10분 이상 지난 입력은 실행하지 않습니다.
- 미확정 일정은 자동 삭제하지 않습니다. 답이 없을 때 자동 확정·시간 보충·추가 질문을 보내지 않습니다.
- 테스트는 외부 호출을 대체합니다. 실제 봇 연결, Gemini 모델 사용 가능 여부, 장시간 실행은 아이맥에서 별도 확인해야 합니다.

공식 API: [Telegram](https://core.telegram.org/bots/api), [Gemini 호환 API](https://ai.google.dev/gemini-api/docs/openai), [OpenAI 구조화 출력](https://developers.openai.com/api/docs/guides/structured-outputs).
