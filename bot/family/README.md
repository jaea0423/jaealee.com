# 흰둥이·검둥이 — 개인방과 승인된 가족방

Python 3.10 이상. 표준 라이브러리만 사용합니다. 공개 저장소에는 가족 이름, 봇 토큰, API 키, 대화나 일정을 넣지 않습니다.

## 가족방 승인 이후 설정 (최신)

- 사용자가 가족방 사용을 승인했습니다. `family_chat_id`가 0이면 기존 개인시험만 동작하고, 연결된 음수 ID가 있으면 `family_runtime.py`가 지정된 그룹/슈퍼그룹 한 곳만 처리합니다. 채널·다른 그룹·익명 관리자·봇 메시지는 처리하지 않습니다.
- 실행 중인 흰둥이를 안전하게 중지하고 DB를 백업한 뒤 `python3 pair_group.py --config 경로`를 실행합니다. 본인 `owner_id`가 가족방에서 5분 내 보낸 일회용 명령과 두 봇의 그룹 가입을 확인해 비공개 설정에 저장합니다. webhook은 삭제하지 않습니다. 기존 그룹은 자동 교체하지 않습니다.
- 흰둥이의 60초 응답 제한은 없습니다. 직접 호출은 바로 처리하고, 이름 없는 말은 최근 대화 흐름으로 참여 여부를 먼저 판단합니다. 같은 발신자의 최근 대화와 그룹 최근 10개 메시지(15분 이내)를 비공개로 참고합니다. 날씨 답변에 대한 감상은 이어받고, 인간끼리 대화와 혼잣말에는 조용히 있습니다. 불확실하거나 판단 API가 실패하면 발송하지 않습니다. 참여 판단 호출도 하루 100회 한도에 포함합니다.
- 답장 대상은 본문에 우연히 등장한 다른 봇 이름보다 우선합니다. 다른 봇이나 가족 메시지에 대한 답장에는 끼어들지 않습니다. 명시적 @멘션으로 대상을 바꾸는 것은 가능하며 이때 기존 답장 대상 봇은 응답하지 않습니다. 이름만 부를 때는 먼저 부른 봇이 응답합니다.
- 검둥이는 멘션·답장뿐 아니라 검둥아·검둥이·검둥으로 직접 부르면 응답합니다. 흰둥이·흰둥아·흰둥 호출도 인식합니다.
- 강아지 캐릭터 설정은 `personas.json`에 기록하고 두 AI 경로에서 공통 사용합니다. 흰둥이는 세 살, 검둥이는 네 살이며 잠·간식·성격·재롱 설정을 고정합니다. 일상 대화에는 봇 기능 소개를 붙이지 않지만 실제 AI 정체를 직접 물으면 솔직하게 설명합니다. 허구의 캐릭터 행동과 실제 일정·검색 성공은 구별합니다.
- 검색 가능 여부에 대한 질문과 강아지 나이·잠·재롱 대화는 최신 자료를 요구하는 질문으로 분류하지 않습니다. 날씨 질문 뒤 다른 주제로 넘어가도 검색 실패 안내로 덮어쓰지 않습니다.
- 멘션 없는 내용을 받으려면 BotFather의 `/setprivacy`에서 흰둥이를 Disable로 설정한 뒤 그룹에 다시 초대합니다. 그룹 관리 권한은 필요하지 않습니다.
- **가족방 모드에서는 검둥이의 뉴스·지식 정기 발송을 하지 않습니다.** 검둥이는 자기 멘션, 자기 메시지에 대한 답장, 자기 이름이 붙은 명령에 Gemini로 짧게 답합니다. 두 봇 모두 Privacy Mode를 끄고 그룹에 다시 초대해야 일반 멘션과 대화 수신이 안정적입니다. 응답 대상은 코드로 제한합니다. 흰둥이는 다른 봇에 대한 멘션·답장에 끼어들지 않습니다. 뉴스·지식 생성 자동화와 기존 원고는 변경하지 않습니다.
- 검둥이는 질문, 답장으로 가리킨 텍스트, 같은 발신자의 최근 10회 문맥을 사용합니다. 호출 조건은 코드에서만 관리하며 AI가 멘션 안내나 자기소개를 반복하지 않도록 합니다. 일정 등록·알림 발송 기능은 흰둥이가 담당합니다.
- Gemini의 Google Search grounding을 연결했습니다. 검둥이는 대화 중 필요하면 검색하고, 흰둥이는 날씨·현재 정보 등의 일반 질문에 검색을 추가합니다. 지역이 없으면 날씨 지역을 물어보며, 검색 출처가 없으면 최신 사실로 확정하지 않습니다. 확인 시각·출처 꼬리말은 자동으로 붙이지 않고 검색 근거는 내부에서 검증합니다. 기존 Gemini 키를 사용하고 결제를 활성화하지 않습니다. 검색 사용량에는 공급자 요금/할당량이 적용됩니다. 흰둥이의 추가 검색 호출도 하루 AI 호출 한도에 포함합니다.
- 가족방 일정·알림은 같은 `state_dir`의 `white-group-<ID>.sqlite3`에 보관합니다. 개인방 `white.sqlite3`의 대화·일정·기억을 그룹에 옮기지 않습니다. 검둥이도 그룹 전용 DB를 사용합니다. DB 초기화 없이 재시작합니다.
- 가족방 일정은 공유하지만 제안 확정은 요청한 발신자만 가능합니다. 다른 구성원이 먼저 일정을 수정한 경우 오래된 제안은 적용하지 않습니다. 최근 대화 10회·장기 기억 최대 50개는 가족방 안에서 발신자별로 분리합니다. `/memory`와 `/forget`은 본인 기억만 처리하며 결과는 요청한 가족방에 표시됩니다.
- 가족 이름으로 숫자 ID를 추측하지 않습니다. 본인이 가족 메시지에 답장해 `/family 엄마`, `/family 아빠`, `/family 누나`, `/family 형`을 보내면 비공개 `addresses`에 해당 발신자 ID를 기록하고 두 봇이 함께 사용합니다. 미등록 구성원은 호칭을 생략합니다. 연결 명령은 본인만 사용할 수 있습니다.
- AI 호출은 흰둥이 개인방, 흰둥이 가족방, 검둥이 가족방 각각 하루 최대 100회입니다. 알림에는 AI 호출이 없습니다. Gemini 전송에는 해당 대화 문맥과 비공개 가족 이름·호칭이 포함됩니다.
- 가족방 `--probe`는 그룹 ID·봇 가입 확인만 하며 AI나 발송 검증이 아닙니다. `--send-test`는 지정된 가족방에 연결 인사 한 건을 보냅니다. 서비스 등록은 `install_macos.py`로 별도 수행합니다.
- 로컬 테스트 59개: 기존 개인시험, 그룹 경계·발신자별 확정·기억·재시작 중복 방지, 답장 우선순위·이름 호출, 맥락별 참여, 고정 캐릭터, 감상과 검색 질문 구분을 포함합니다. 명확한 재롱·애교 요청은 참여 분류기와 무관하게 처리합니다. 실제 키로 참여 판단과 대화·검색 연결도 별도 검증합니다.

아래 개인시험·검둥이 정기 발송 설명은 `family_chat_id`가 없는 기존 모드에 해당합니다. 가족방 모드에서는 위 최신 설정이 우선합니다.

## 범위

- 흰둥이: 허용된 한 명의 개인채팅에만 응답. 자연어 일정 초안·조회·변경·취소. ‘맞아’, ‘응’, `/confirm 번호`로 확인. 날짜 미정이면 기본 알림 없음. 시간 미정이어도 날짜 기준 알림 가능. 사라진 정보는 추측하지 않음.
- 확정 일정: 1주 전 10시 30분·전날 20시·요청한 추가 시각 알림. 시간이 있는 일정은 당일 09시(09시 이전이면 1시간 전)도 유지. 놓친 알림은 일정 시작 전까지 복구. 시간 미정 일정은 당일 자정까지 유지. 등록 전에 이미 지난 기본 알림은 별도 상태로 남기고 보내지 않음.
- 개인시험에서는 먼저 말을 걸거나 답장을 독촉하지 않음. 일정을 알려달라는 질문 뒤 답이 없으면 미확정 기록을 유지. 사진·음성은 아직 미지원.
- 검둥이: 09시 뉴스, 12시 지식. 홈페이지 당일 JSON을 그대로 글로 변환. 시장 표·출처 URL 제외, 문장 저자/책 표기는 유지. 대화에는 응답하지 않음. 뉴스는 09:00~11:00 직전, 지식은 12:00~15:00 직전까지 복구 시도, 지난 날짜를 오늘 것으로 보내지 않음.
- 개인시험 모드에서는 가족방 전송이 차단됩니다. 가족방 사용은 위 연결 절차가 필요합니다.

## 아이맥 설정

1. 최신 저장소를 가져오고 이 폴더에서 `python3 -m unittest -v`를 실행합니다.
2. `config.example.json`을 **저장소 밖** `~/.config/jaealee-family-bots/config.json`에 복사합니다. 폴더 권한 700, 파일 권한 600으로 설정합니다.
3. `white_token`, `black_token`은 해당 봇의 BotFather 토큰입니다. 토큰을 채팅이나 명령 인자에 넣지 마세요.
4. `owner_id`는 시험할 본인의 텔레그램 숫자 사용자 ID입니다. 이름/사용자명/전화번호가 아닙니다. 본인이 두 봇 각각의 개인방에서 시작을 누릅니다.
5. 기본 `ai_provider`는 `gemini`. `gemini_api_key`, `gemini_model`을 입력합니다. 모델은 키에서 사용 가능한 텍스트·구조화 출력 지원 모델을 확인하여 선택합니다. 유료 모델/요금제 활성화는 사용자 승인 후 진행합니다. OpenAI로 바꾸면 `ai_provider: openai`, `openai_api_key`, `openai_model`을 설정합니다.
6. `family`에 실제 이름과 엄마/아빠/누나/형 호칭을 비공개로 기록합니다. 모델에는 최근 대화 10회와 최근 일정 최대 50건을 보냅니다.

본인 ID를 모르면 `pair.py --config 경로`를 먼저 실행한 뒤, 화면에 표시된 일회용 문구를 **흰둥이 개인방**으로 보냅니다. 2분 안에 정확히 일치하는 개인 메시지를 확인해 ID를 저장합니다. 기존 봇 서버가 같은 토큰으로 실행 중이면 먼저 해당 운영 상태를 확인하세요. 이 도구는 기존 webhook을 삭제하지 않습니다.

```sh
# 이 폴더에서 실행. 설정 경로만 인자로 넘기고 키는 넘기지 않습니다.
python3 pair.py --config "$HOME/.config/jaealee-family-bots/config.json"
python3 bots.py white --config "$HOME/.config/jaealee-family-bots/config.json" --probe
python3 bots.py white --config "$HOME/.config/jaealee-family-bots/config.json"
```

흰둥이 개인방에서 ‘안녕’, ‘내일 가족 식사 적어줘’, ‘저녁 6시’, ‘맞아’, ‘일정 보여줘’, ‘그 식사 취소해줘’, ‘응’을 시험합니다. AI 실제 해석·말투는 이 단계에서 검증합니다. 가짜 응답을 쓰는 단위 테스트로 AI 품질을 보장하지 않습니다.

검둥이는 별도 터미널에서 같은 형식으로 `white`를 `black`으로 바꿔 실행합니다. 연결 확인은 `--probe`, 실제 개인방 인사 한 건은 `--send-test`. 지금 원고 미리보기는 Python에서 `digest()`로 만들 수 있습니다. 가족방에는 보내지 마세요.

## 계속 실행

개인시험이 통과하면 아이맥에서 launchd 사용자 서비스를 등록합니다. `install_macos.py --config 경로 --role white`는 서비스 파일만 만듭니다. 출력된 명령을 실행해야 시작합니다. 검둥이도 동일하게 따로 등록할 수 있습니다. 기존 서비스가 있으면 덮어쓰지 않습니다.

사용자 로그인 세션에서 실행되며, 전원 꺼짐·잠자기·인터넷 끊김 동안 작동하지 않습니다. 서비스 폴더와 로그는 저장소 밖입니다. 이 프로그램은 커밋·푸시를 하지 않아 홈페이지 자동 발행과 Git 충돌이 나지 않습니다.

## 복구와 제한

- 당일 원고가 없거나 비어 있거나 읽을 수 없으면 검둥이는 아무 메시지도 보내지 않습니다. 뉴스·지식은 독립적으로 확인합니다. 뉴스 11:00·지식 15:00 직전까지 5분마다 다시 확인하며, 어제 원고로 대체하지 않습니다.
- 흰둥이의 AI 연결·해석 실패는 미리 준비한 짧은 존댓말 안내로 처리합니다. 원래 오류 본문을 대화에 노출하지 않고 저장 완료를 주장하지 않습니다. 1분간 AI 호출을 쉬며, 이후 새 사용자 메시지가 있을 때만 다시 시도합니다. `/events` 등 AI 없는 명령은 계속 작동합니다. 자동 공급자 전환은 하지 않습니다.
- AI 응답 형식·날짜·일정 대상 검증은 저장 전에 수행합니다. 다만 정상 형식 안의 사실 오류·의도 오해까지 모두 검출하지는 못하므로 개인방 실제 대화 시험이 필요합니다. 공급자별 안정성은 동일한 대화로 오류율·응답시간·정확성을 비교한 뒤 결정합니다.

- 흰둥이는 하루 AI 호출 최대 100회. 대기·검둥이 발송·일정 알림에는 AI 호출 없음. 토큰 기반 금액 상한은 아니므로 공급자 사용량도 확인합니다.
- 서비스 오류 메시지에는 토큰·가족 메시지를 기록하지 않음. 데이터베이스는 아이맥에 평문 저장되며 파일 권한으로 보호합니다.
- 같은 역할은 동시에 한 프로세스만 실행. 성공한 발송은 재시작해도 반복하지 않습니다.
- 발송 도중 연결이 끊기면 실제 수신 여부를 확정할 수 없어 자동 재발송을 중단합니다. `delivery:*` 값이 `sending`이면 개인방에서 수신 여부를 확인한 뒤 해당 항목만 `sent`로 표시하거나, 미수신이 확실할 때만 지우고 재시도합니다. 데이터베이스 전체를 지우면 중복 발송될 수 있습니다.
- 입력 처리 전에 수신 위치를 저장하므로 그 직후 강제 종료되면 답장/처리가 누락될 수 있습니다. 재시작 후 `/events`로 확인합니다. 10분 이상 지난 입력은 실행하지 않습니다.
- 미확정 일정은 자동 삭제하지 않습니다. 답이 없을 때 자동 확정·시간 보충·추가 질문을 보내지 않습니다.
- 테스트는 외부 호출을 대체합니다. 실제 봇 연결, Gemini 모델 사용 가능 여부, 장시간 실행은 아이맥에서 별도 확인해야 합니다.

공식 API: [Telegram](https://core.telegram.org/bots/api), [Gemini 호환 API](https://ai.google.dev/gemini-api/docs/openai), [OpenAI 구조화 출력](https://developers.openai.com/api/docs/guides/structured-outputs).

## 호칭과 지연 발송

- 비공개 설정의 owner_address는 개인시험 상대의 기본 호칭입니다. 빈 문자열이면 생략합니다. addresses는 숫자 사용자 ID 문자열을 키로, 형·누나·엄마·아빠·오빠 등 원하는 호칭을 값으로 지정합니다. 이 설정은 가족방 접근 권한을 주지 않습니다.
- 오류 안내 여섯 문구를 순환하고 세 번 중 한 번만 호칭을 붙입니다. 원인을 확인하지 못했을 때 인터넷 장애라고 단정하지 않습니다. 일정 관련 요청에는 미처리 안내도 붙입니다.
- 검둥이는 가져온 원고를 비공개 데이터베이스에 보관합니다. 전송 중 홈페이지 API가 고장 나도 확보한 원고로 이어 보냅니다. 명확한 요청 거절(예: 429)은 5분 간격으로 재시도합니다. 전송 결과 불명 상태는 중복 방지 때문에 자동 재발송하지 않습니다.
- 뉴스 11:00·지식 15:00부터는 당일 발송 재시도를 멈춥니다. 다음 날로 이월하지 않습니다. 정상 연결을 보장할 수 없으므로 절대 무누락을 보장하는 방식은 아닙니다.

## 고정 성격과 장기 기억

- 성격은 코드의 PERSONA로 고정합니다. 짧고 친근한 존댓말, 상황에 대한 가벼운 농담, 재촉하지 않기, 가짜 경험을 만들지 않기입니다. 대화로 자동 수정하지 않습니다.
- 실제 데이터는 설정의 state_dir 아래 white.sqlite3에 저장됩니다. 기본 위치는 ~/.local/state/jaealee-family-bots/white.sqlite3입니다. 최근 대화 10회, 일정, 사용자가 직접 밝힌 생활정보 원문을 분리합니다.
- AI가 지속적인 취향·습관·본인 생활정보를 선별하면 현재 메시지에 실제 존재하는 원문인지 검사하고 발언자 ID·시각과 함께 최대 50개를 보관합니다. 저장 시 알리고 /memory로 조회, /forget 번호 또는 기억 삭제 번호로 삭제합니다. 삭제하면 단기 대화 문맥도 비워 재참조를 줄입니다. 일정은 별도 유지됩니다.
- 과거 발언은 검증된 사실로 취급하지 않으며 상충하는 발언을 덮어쓰지 않습니다. 충돌 시 확인하도록 AI에 지시합니다. 기억을 지침으로 실행하거나 가족 호칭·권한·성격을 바꾸지 않습니다.
- 장기 기억은 AI 요청에도 전달됩니다. 민감정보·비밀·가정·농담은 저장하지 않도록 지시하지만 AI 선별과 충돌 인식이 항상 정확하다는 보장은 없습니다. 실제 개인방에서 검증해야 합니다. 최대 50개가 차면 조용히 잊지 않고 정리를 요청합니다.

## 일정과 알림 관리

- /events는 예정·미확정·시각 지남·취소를 나눠 보여줍니다. 시각 지남은 실제 참석/완료를 뜻하지 않습니다. /reminders 또는 알림 상태로 각 알림의 발송 예정·전송 성공·수신 확인 필요·미발송 만료·취소/변경·등록 전에 지난 상태를 확인합니다.
- 자연어로 추가 알림 시각을 요청하면 remind_at에 해석하고 제안에 표시합니다. /confirm 번호 또는 맞아로 확인한 뒤 적용됩니다. 시간 해석은 실제 AI 시험이 필요합니다.
- 기본 시각과 요청 시각이 겹치면 한 번만 보냅니다. 한 알림 실패가 다른 일정 알림을 막지 않습니다. 미발송은 5분 간격으로 복구하고, 수신 여부 불명은 자동 반복하지 않고 확인 필요로 남깁니다. 일정 시각이 지난 미발송 기록도 삭제하지 않습니다.
- 알림 본문은 실제 발송일 기준으로 내일·오늘·다음 주 요일을 계산하고, 친족 관계 등 제목에 없는 사실을 추가하지 않습니다. 5분 이상 늦으면 원래 알림 시각을 표시합니다. 알림 생성·발송에 AI를 호출하지 않습니다.
- 기존 버전의 성공한 전날·당일 알림 기록도 확인해 중복을 피합니다. 뉴스 발송은 한국시간 09:00부터 11:00 직전, 지식은 12:00부터 15:00 직전입니다.
