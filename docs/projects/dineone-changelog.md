# DineONE(다인원) 개발자 업데이트 노트

다인원과 가게 시안(짚불태백 광교점 등)에서 무엇이 어떻게 바뀌었는지 한 파일에 계속 쌓습니다.
구조와 원칙은 [구조 정리](dineone-structure.md)에 있고, 이 파일은 **바뀐 기록**만 담습니다.

## 쓰는 법

- **최신이 맨 위**입니다. 날짜(한국시간) 아래에 작업 한 건씩 추가합니다.
- 작업 하나에 아래 항목 중 해당하는 것만 씁니다.
  - **추가**: 새 화면, 새 기능
  - **변경**: 동작이나 모양이 바뀐 것
  - **수정**: 고친 오류
  - **제거**: 없앤 것
  - **주의**: 자료가 초기화됨, 주소가 바뀜, 다른 화면에 영향 감 등 꼭 알아야 할 것
- 맨 끝에 `범위`(바뀐 폴더·화면)와 `커밋`(해시)을 적습니다.
- 실서비스가 시작되면 날짜 옆에 버전을 붙입니다. 예: `2026-12-01 · v0.1.0`
  - 큰 구조 변경은 가운데 숫자를 올리고, 작은 수정은 끝 숫자를 올립니다.
- 실서비스 저장소(`dineone`)가 생기면 이 파일을 `CHANGELOG.md`로 옮겨 이어 씁니다.

```
### 제목 한 줄
- 추가: …
- 변경: …
- 수정: …
- 주의: …
- 범위: dineone/… · 커밋 abc1234
```
