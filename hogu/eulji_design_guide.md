## INDEX (메인 페이지)

- 모바일 420px 고정 컨테이너 (hogu 사이트와 동일 폭)
- 헤더: 노포 간판 스타일
  - 빨간 바탕 + 형광 노랑 글씨 (또는 검정 바탕에 네온)
  - 약속 제목 (예: "을지로 1박 2일", "정연우 주량 검증의 밤" 등)
  - 한글 + 한자 병기 가능
  - 살짝 기울어진 각도, 그림자
- 카드 5개 (2x3 그리드 — 마지막 칸 비우거나 D-Day)
- 각 카드는 미니 간판
  - 빨간 바탕 + 흰/노란 글씨
  - 한글 메인 + 한자 서브 (예: 映畵 / 肉 / 酒 / 旅館 / 解酒)
  - 카드별로 살짝 다른 각도

## 페이지별 가이드

### 1. movie.html — 영화관람 (스파이더맨 브랜드뉴데이)
- **컨셉**: 영화 티켓 스타일
- 영화 정보: 제목 / 상영시간 / 관 / 좌석
- 티켓 절취선 디자인 (점선 dash border)
- 색조: 검정 + 빨강 + 노랑
- 영화관 로고 자리 (CGV/메가박스/롯데시네마 등)

### 2. meat.html — 고기타임
- **컨셉**: 정육식당 메뉴판
- 가게 정보 / 메뉴 / 가격
- 빨간 간판 + 노란 바탕
- "○○집" 한자 표기 (예: 老舗 = 노포)
- 메뉴는 한글+가격 두 열로

### 3. drink.html — 술 + 정연우 각서 ⭐ (핵심)

세 섹션 구성:

**[상단] 호프집 정보**
- 가게명, 메뉴, 위치

**[중단] 정연우 주량체크 각서** ← 이 페이지의 메인
- 누런 종이 배경 (`#F4ECD8`)
- 종이 가장자리 거친 효과 (border + 그림자)
- 손글씨 폰트 (Single Day 또는 East Sea Dokdo)
- 옛 차용증/각서 양식 문체. 예시:

  > **誓 約 書 (서약서)**
  >
  > 본인 鄭演佑(정연우)는 西紀(서기) 2026년 ○월 ○일
  > 을지로에서 본인의 酒量(주량)을 검증함에 있어,
  > 측정한 잔수와 상태를 後日(후일) 부정하지 아니하며
  > 다음 사항을 서약함.
  >
  > 一. 잔수 카운팅에 異意(이의) 없음
  > 一. 필름 끊김 시 영상 촬영을 허락함
  > 一. 다음날 해장값은 본인이 부담함
  >
  > 西紀 2026年 ○月 ○日
  >
  > 서약자: 鄭演佑 (印)
  > 증 인: ________________

- 도장 자리: 붉은 동그라미 (`border-radius: 50%` + 빨강)
- 서명란: 점선 위 손글씨 "정연우"
- 증인란: 나머지 멤버 이름

**[하단] 주량 카운터** (인터랙티브)
- 소주잔 아이콘 격자 (10개 또는 20개)
- 클릭하면 빈 잔 → 마신 잔으로 토글
- localStorage 저장 (hogu/checklist.html 패턴 재활용 가능)
- 현재 상태 표시:
  - 0~3잔: 멀쩡 (😎)
  - 4~7잔: 취기 오름 (🥴)
  - 8~10잔: 필름 끊김 직전 (😵)
  - 10잔+: 위험 (🚨)

### 4. motel.html — 모텔 (잠)
- **컨셉**: 모텔 네온 간판
- 어두운 검정 배경
- 네온 핑크 (`#FF3C8B`) + 시안 (`#00E5FF`) 글씨
- 가게명 / 체크인·아웃 시간 / 가격
- 네온 깜빡임 애니메이션 (옵션) — `text-shadow` + `@keyframes` 활용
- 한자 표기: 旅館(여관) / 모텔

### 5. hangover.html — 해장
- **컨셉**: 해장국집 메뉴판
- 따뜻한 베이지 + 빨강 포인트
- 메뉴 추천: 콩나물국밥 / 황태해장국 / 선지국 / 뼈해장국 등
- 가게 정보, 영업시간 (아침 일찍 여는 곳)
- 한자: 解酒(해주)

## 공통 요소

- 모바일 420px 컨테이너 + `box-shadow`
- 상단 바: 검정 바탕 + 빨강/노랑 포인트 + 뒤로가기 버튼
- favicon: SVG data URI (페이지별 다른 이모지 — hogu 사이트 패턴 그대로)
- 모든 페이지에 index.html 돌아가는 버튼

## 디테일 아이디어 (참고용)

- **한자 병기**: 영화(映畵), 고기(肉), 술(酒), 모텔(旅館), 해장(解酒)
- **옛 광고 카피 톤**: "이 집 김치 끝내줍니다", "맛 좀 아는 사람만 옴" 같은 느낌
- **벽지/종이 텍스처**: `radial-gradient`로 점박이 노이즈
- **형광등 떨림**: `@keyframes`로 `opacity` 미세 변화
- **노포 광고지**: 빨간 도장 + 검정 글씨 + 누런 종이
- **간판 박스**: `border: 4px solid #1A1A1A` + 안쪽 그림자

## 주의점

- **을지로의 분위기는 "촌스러움 + 정겨움"이지 진짜 촌스러운 게 아님**
  → 컬러 대비는 강하게, 폰트는 일관성 있게, 정렬은 깔끔하게.
  과하게 욱여넣으면 "구려" 보일 수 있음.
- **각서 페이지는 진지한 척하는 게 포인트**
  → 옛 한자 문체 + 도장 + 손글씨로 권위 있는 척 → 내용은 우스움.
  컬러로 농담하지 말고 양식의 진지함으로 농담할 것.
- **모텔 페이지는 너무 야하지 않게**
  → 네온 사인 = 80년대 영화 미장센. 핑크/시안 두 색이면 충분.
