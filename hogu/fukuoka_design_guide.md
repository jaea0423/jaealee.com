## 한 줄 요약
**"혼자 야타이에 앉은 도피자" — 차분한 야간 후쿠오카.**
야타이의 키치함을 빼고 절제된 빛과 어둠으로. 무라카미 하루키 / 왕가위 영화 무드.

---

## 무드 키워드
- 차분한 도피 (충동 여행이지만 들뜬 게 아니라 가라앉은)
- 야간 (밤 9시~새벽 2시 사이 시간대)
- 따뜻한 빛 vs 차가운 어둠의 대비
- 적막, 강물, 등불, 골목
- 절제 — 빨강·노랑은 포인트로만, 메인은 검정/네이비/미색

- 검정/네이비가 80% 차지

- 빨강은 5% (등불, 도장, 강조 한 단어)

## 폰트 (Google Fonts)

- **Shippori Mincho** — 일본 명조, 한자 표시 핵심
- **Gowun Batang** — 한국 명조, 본문에 잘 어울림
- **Hahmlet** — 한국 명조 대안
- **Black Han Sans** — 굵은 한글, 메인 타이틀 (절제해서)
- **Single Day** — 손글씨, 메모/낙서
- **Noto Serif JP** — Shippori Mincho 대체 가능

**기본 조합 추천:**
- 타이틀: Black Han Sans + Shippori Mincho (한자)
- 본문: Gowun Batang
- 한자 디스플레이: Shippori Mincho
- 손글씨: Single Day

## INDEX (메인 페이지)

### 헤더 (화면 상단 ~ 50%)
- 어두운 밤 배경 (`#0E0E12` → `#1A2535` 그라데이션)
- 가운데 빨간 야타이 등불(提灯) SVG 1~2개 — 살짝 흔들리는 애니메이션
- 따뜻한 노란 빛이 등불 주변에 번지듯 (`radial-gradient`)
- 멀리 강물 반사 효과 (수평으로 옅은 빛 줄)
- 타이틀:
  - 메인: 한자 "眠覺福岡" 또는 "目覚めたら福岡" (작게, 상단)
  - 한글: "눈떠보니 후쿠오카" (Black Han Sans, 절제)
- 날짜 박스: 미색 종이 위에 묵빛 글씨

### 카드 그리드 (화면 하단 ~ 50%)
- 배경: 약간 더 밝은 네이비 또는 미색 종이
- 카드는 미니 야타이 천막 또는 노렌 모양
  - 어두운 베이스 + 위쪽에 빨간 띠 (등불의 잔영)
  - 한글 + 한자 병기 (예: 라멘 / 拉麺)
  - 카드 아이콘은 절제된 이모지 또는 SVG
- 호버/탭 시 살짝 밝아지는 느낌 (등불이 켜지듯)

### 분위기 디테일
- 헤더와 카드 영역 경계에 잔잔한 강물 표현 (수평선 옅은 그라데이션)
- 작은 별 또는 등불 입자 떠있음 (sparkle 살짝)
- 음향이라면 매미 또는 강물 — 코드 X (그냥 무드 참고)

## 일반적인 페이지 구성 (모든 페이지 공통)

### 상단 바
- 어두운 베이스 (`#0E0E12` 또는 `#1A2535`)
- 왼쪽: 뒤로가기 버튼 (등불 노랑 테두리)
- 가운데: 페이지 제목 (한글 + 한자)
- 하단 보더: 가는 빨강 또는 등불 노랑 1px

### 콘텐츠 영역
- 배경: 미색 종이 (`#E8DCC0`) 또는 어두운 네이비
- 텍스트 박스: 미색 종이 위 묵빛 글씨 (Gowun Batang)
- 카드: 어두운 배경에 미색 종이 카드가 떠있는 식

### 디테일
- 한자 병기를 모든 헤더에 사용 (절제)
- 노렌 모티프 (위쪽 천 늘어진 모양) 활용
- 도장 자국 (빨간 동그라미) 포인트로

## 페이지별 가이드

> 일정은 다음 채팅에서 사용자가 정함. 후쿠오카 일정 후보 예시만 적어둠.

후쿠오카 1박 2일 일정 후보:
- 비행기 도착 / 공항
- 하카타 라멘 (一蘭, 一風堂 등)
- 모츠나베 (もつ鍋)
- 멘타이코 (明太子) 쇼핑
- 캐널시티 하카타
- 나카스 야타이 (中洲屋台) — **이 페이지가 메인 무드**
- 다자이후 (太宰府)
- 후쿠오카 타워
- 마리노아 시티 (아울렛)
- 텐진 (天神) 쇼핑
- 해장 (라멘 또는 우동)

각 페이지 디자인 기본 규칙:
- 페이지마다 컨셉을 살짝 다르게 가져가되, 전체 무드는 통일
- 한자 메뉴판 느낌이면 미색 종이 + 묵빛 글씨
- 야간 일정(야타이, 술)이면 어두운 톤 + 등불 빛
- 낮 일정(다자이후, 쇼핑)이면 미색 + 빨간 포인트

## 디테일 아이디어

- **야타이 등불(提灯) SVG**: 빨간 원기둥 + 검정 글씨 한자, 위아래 검정 띠
- **노렌(暖簾)**: 위에서 늘어진 천 — `border-top` + `linear-gradient`로 구현 가능
- **종이 텍스처**: `radial-gradient`로 점박이 노이즈, 가장자리는 약간 그을린 느낌
- **도장 자국**: 빨간 원 (`border-radius: 50%`) + 한자 또는 이니셜 + 회전 살짝
- **강물 반사**: 수평 그라데이션 (`linear-gradient` 90deg)
- **등불 깜빡임**: `@keyframes`로 `opacity` 0.85~1 사이 미세 변화 (3~5초 주기, 너무 자주 X)
- **한자 음각**: `text-shadow`로 살짝 들어간 느낌

## 주의점

- **야타이 야간 = 키치하지 않게**
  → 빨강·노랑을 절제. 메인은 검정/네이비. 빛은 작게.
  과하게 쓰면 "중국집 인테리어" 느낌이 됨.

- **차분한 톤 = 어둠과 빛의 대비**
  → 그냥 어둡기만 하면 우울함. 따뜻한 등불 한 점이 핵심.

- **한자는 양념**
  → 한국어 사이트라 한자 도배하면 읽기 어려움. 타이틀과 헤더에만 작게.

- **일본 폰트는 무료 사용 가능 여부 확인**
  → Shippori Mincho, Noto Serif JP는 Google Fonts에 있어 OK.

- **하루키·왕가위 무드의 함정**
  → 너무 진지하게 가면 약속 사이트 분위기가 무거워짐.
  카드 디자인이나 짧은 카피로 가볍게 균형 잡을 것.
  예: "오늘 밤은 우리 다 도망자야"
