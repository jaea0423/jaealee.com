# Supabase 연결 설정 가이드

목표: R(독서)·S(영화/드라마) 기록을 **인터넷 DB(PostgreSQL)** 에 저장해서
**로그인하면 어느 기기에서든** 보고 수정할 수 있게 만들기.

아래 1~6번은 재아님이 직접 하시고, 마지막에 나오는 **두 개의 값**만 저한테 주시면
앱 코드는 제가 붙입니다. 전부 무료 플랜으로 됩니다.

---

## 1. 프로젝트 만들기

1. https://supabase.com 접속 → **Start your project** → GitHub 계정으로 로그인
2. **New project** 클릭
3. 입력:
   - **Name**: `jaealee-archive` (아무거나)
   - **Database Password**: 아무 강한 비밀번호(메모해두기 — 자주 쓸 일은 없음)
   - **Region**: `Northeast Asia (Seoul)` 또는 `Tokyo` (가까울수록 빠름)
4. **Create new project** → 1~2분 기다리면 준비 완료

---

## 2. 테이블 만들기 (SQL 실행)

1. 왼쪽 메뉴 **SQL Editor** 클릭 → **New query**
2. 같은 폴더의 **`schema.sql`** 파일 내용을 통째로 복사해서 붙여넣기
3. 오른쪽 아래 **Run** (또는 Ctrl+Enter)
4. 왼쪽 **Table Editor** 에 `reading_books`, `screen_items` 두 테이블이 보이면 성공

---

## 3. 이메일 로그인 켜기

1. 왼쪽 **Authentication** → **Providers** (또는 Sign In / Providers)
2. **Email** 이 켜져 있는지 확인 (기본으로 켜져 있음)
3. 편의를 위해 **"Confirm email"(이메일 확인)** 을 잠시 **끄기**
   - 나 혼자 쓰는 계정이라, 확인 메일 기다리지 않고 바로 로그인하려는 것
   - (보안이 신경 쓰이면 켜둔 채로 확인 메일 한 번 클릭해도 됩니다)

---

## 4. 내 계정 하나 만들기

두 방법 중 편한 것:

- **간단**: **Authentication → Users → Add user → Create new user**
  - 이메일 / 비밀번호 입력해서 계정 생성 (이게 앞으로 로그인할 계정)
- 또는 나중에 앱 로그인 화면에서 "가입"으로 만들어도 됩니다.

> "나만 보기"는 이 계정으로 로그인했을 때만 데이터가 보이도록 이미 SQL(RLS)에서 잠가놨습니다.

---

## 5. 연결 값 두 개 복사

1. 왼쪽 맨 아래 **Project Settings**(톱니바퀴) → **API**
2. 아래 두 개를 복사:
   - **Project URL** — 예: `https://abcdxyz.supabase.co`
   - **anon public** 키 — `eyJ...` 로 시작하는 긴 문자열

---

## 6. 저에게 전달

위 **Project URL** 과 **anon public 키** 를 채팅에 붙여주세요.
그러면 R·S 앱에 로그인 화면을 붙이고, DB에서 데이터를 읽고 쓰도록 바꾼 뒤,
지금 브라우저에 저장돼 있던 기존 기록도 옮겨 넣어 드립니다.

### anon key, 공개해도 되나요?
네, 괜찮습니다. `anon`(익명 공개) 키는 **원래 웹페이지에 넣으라고 만든 공개용 키**입니다.
실제 데이터 보호는 3~4번에서 켠 **로그인 + RLS(행 수준 잠금)** 이 담당합니다.
로그인하지 않으면 이 키가 있어도 아무 데이터도 못 봅니다.
(반대로 Project Settings에 있는 **`service_role` 키는 절대 공개 금지** — 그건 저한테도 주지 마세요.)

---

## 앞으로 어떻게 동작하나 (미리보기)

- 앱을 열면 → 로그인 화면 → 로그인하면 내 기록이 DB에서 불러와짐
- 추가/수정/삭제하면 → 그 즉시 DB에 저장 → 다른 기기에서 열어도 똑같이 보임
- 표지/포스터 이미지도 함께 저장됨 (지금처럼 자동 압축해서 용량 절약)
