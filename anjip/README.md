# 안집 사이트 — jaealee.com/anjip

한옥반점 사이트(`../hanok/`)를 바탕으로 2026-09-20 에 만든 첫 판. 정적 파일, 빌드 없음.
룸 없음(1층·지하 홀), 온라인 예약 없음(전화만 — 한옥반점을 끝낸 뒤 시스템과 함께). 소식 장도 아직 없음.

| 파일 | 무엇 |
|---|---|
| `index.html` `about.html` `menu.html` `visit.html` | 네 장 |
| `data/site.js` | 글·사진·차림·가격·영업시간 전부의 기본값. **"(확인)" 이 붙은 값은 임시** — 주소·전화·영업시간·좌석 수·지도 링크·대표·사업자번호 |
| `js/site.js` | 상단·바닥·장별 그리기(한옥반점 것을 줄임). `js/content.js` 는 한옥반점과 같고 매장 키만 `anjip`(서버 값은 아직 없음) |
| `css/site.css` | 한옥반점 css 복사본 + 맨 아래 "안집" 구역(간장빛 갈색 테마, 대표 셋·방송·차림 목록) |
| `img/` | 고모가 준 사진(webp → jpg). 메뉴판 포스터의 글은 `data/site.js` 로 옮기고 사진만 오려 씀 |

로컬 확인: 저장소 루트에서 `python -m http.server 8768` → `http://127.0.0.1:8768/anjip/` (`.claude/launch.json` 의 "root").
