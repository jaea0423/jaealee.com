## 5. 시스템 — 예약 등록 마법사 (7단계)

'＋ 예약 등록'(폰은 둥근 ＋). 각 단계 점을 눌러 **건너뛰기 시도** → 한 단계씩 검사됨.

| # | 단계 | 확인 | 기대 |
|---|---|---|---|
| 5-1 | 0 경로 | 전화/방문/네이버/기타 | 기타는 상세 칸 |
| 5-2 | 1 날짜·시각 | 달력 | 날짜별 건수. 지난 날짜도 등록됨(경고) |
| 5-3 | | 시각 칸 | 점심/저녁, 각 칸 아래 "룸 N · 테이블 가능". 접수 마감이 30분 단위 아니면 '마지막 19:50' 따로 |
| 5-4 | | 5분 조절 | 설정 켜져 있으면 분 레일, 끄면 없음 |
| 5-5 | | 라스트오더 뒤 | 확인창 "안내했습니다 / 시간 다시 고르기" — 진행 가능 |
