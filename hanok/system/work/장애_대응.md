# 장애 대응 매뉴얼 (사장님·직원용 + 재아용)

시스템은 두 조각입니다. **화면**(jaealee.com/test/hanok/v6 — GitHub Pages 에 올라간 파일 하나)과 **데이터**(Supabase). 둘은 따로 죽습니다.

## 1. 화면에서 무엇이 보이나

| 상황 | 화면 | 뜻 |
|---|---|---|
| 정상 | 평소 화면 | — |
| **데이터 서버(Supabase) 안 됨** | 상단 회색 띠 "오프라인 · 마지막 갱신 HH:MM · 30초마다 다시 연결" + 본문에 **"서버에 연결되지 않아 예약을 보여 드리지 않습니다"** 카드 | 인터넷이 끊겼거나 Supabase 장애. 예약 목록은 일부러 숨깁니다(오래된 목록을 믿고 받으면 이중 예약) |
| 저장이 안 됨 | 상단 붉은 띠 "저장하지 못했습니다 · 다시 시도" | 방금 한 조작이 서버에 안 올라감. 인터넷 돌아오면 자동으로 다시 보냄. **탭을 닫지 마세요** |
| **화면 서버(GitHub Pages) 안 됨** | 새로 열면 GitHub 의 404 또는 흰 화면. **이미 열려 있는 탭은 계속 됩니다** | 우리가 대신 보여 줄 화면은 없습니다(그 서버 자체가 안 뜨는 것). 이미 열린 탭을 닫지 말 것 |
| 로그인 안 됨 | PIN 넣으면 "로그인 실패" | Supabase 인증 장애 또는 PIN 변경. 5회 틀리면 잠시 잠김 |
| 기기 시계 틀림 | 띠 "이 기기의 시계가 틀립니다" | 태블릿 날짜 설정 확인. 자동 방문 처리가 멈춤 |

## 2. 직원이 할 일 (순서대로)

1. **다른 기기**(사장님 폰)에서 열어 본다. 거기서 되면 → 이 기기의 인터넷 문제. 와이파이 껐다 켜기.
2. 어디서도 안 되면 → **종이·화이트보드로 받는다.** 시각·이름·전화·인원·룸/테이블만 적는다. 나중에 마법사로 넣으면 된다.
3. 이미 열려 있는 탭이 있으면 **절대 닫지 않는다.** 오프라인 카드가 떠도 30초마다 스스로 다시 붙는다.
4. 30분 넘게 안 되면 재아에게 연락.

## 3. 재아가 할 일

1. https://status.supabase.com 확인. Supabase 전체 장애면 기다리는 것 말고 할 게 없다(보통 수십 분).
2. Supabase 대시보드에서 프로젝트가 **일시정지(paused)** 인지 확인 — 무료 플랜은 7일간 요청이 없으면 멈춘다. Restore 버튼.
3. GitHub Pages 장애면 https://www.githubstatus.com. 급하면 `v6/dist/hanok-admin.html` 파일을 카톡으로 보내 태블릿에서 파일로 열게 한다(서버 없이 열림. 데이터는 Supabase 에서 읽음).
4. 데이터가 깨졌거나 지워졌으면 → `supabase/checklist.md` 의 복구 절차. 백업은 hanok-backup 저장소에 매일 새벽 JSON(`stores.json`, `reservations.json`, `logs-30d.json`).
   - 확인: GitHub → hanok-backup → 최근 커밋 날짜가 어제/오늘인지.
   - 복구 리허설을 prod 전환 전에 한 번 해 둘 것(아직 안 해봄).
5. 캐시에서 목록 뽑기(서버가 오래 죽었을 때): 열려 있는 기기의 브라우저 개발자 도구 → 콘솔 →
   `JSON.parse(localStorage.getItem(Object.keys(localStorage).find(k=>k.indexOf("hanok.cache")===0))).data.hanok.reservations.filter(r=>r.date>=new Date().toISOString().slice(0,10)&&r.status==="확정").map(r=>r.date+" "+r.time+" "+r.name+" "+r.people+"명").join("\n")`
   → 오늘 이후 확정 예약이 글로 나온다. 복사해서 카톡으로.

## 4. 미리 해 둘 것

- 태블릿·사장님 폰 둘 다 로그인해 두기(캐시가 두 군데).
- `dist/hanok-admin.html` 최신 파일을 태블릿에 저장해 두기(GitHub 장애 대비).
- 백업 저장소 커밋이 매일 찍히는지 한 달에 한 번 보기.
