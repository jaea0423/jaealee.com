핵심 1확률의 정의

확률 (Probability) 불확실한 정도를 0~1 사이 수치로 측정하는 도구. 0=불가능, 1=확실, 0.5=가장 불확실.
★ 자세 ★ "내가의 확률" vs "누군가의 확률" 구분. 로또 800만 분의 1은 "내가" 당첨될 확률.

핵심 2조건부 확률 (Conditional Probability)

P(A|X) = P(A ∩ X) / P(X)

"X가 주어졌을 때 A가 일어날 확률". 조건이 있는지 없는지에 따라 확률이 달라진다.

예 P(둘 다 딸) = 1/4, P(둘 다 딸 | 첫째가 딸) = 1/2.

핵심 3베이즈 정리 (Bayes' Theorem)

결과로부터 원인을 거꾸로 추론하는 정리.
P(Aᵢ | X) = [ P(X|Aᵢ) · P(Aᵢ) ] / [ Σⱼ P(X|Aⱼ) · P(Aⱼ) ]
용어영어의미
사전확률PriorP(Aᵢ) — 증거 보기 전 원인의 확률
우도LikelihoodP(X|Aᵢ) — 원인 있을 때 결과의 확률
증거EvidenceP(X) — 결과 자체의 확률
사후확률PosteriorP(Aᵢ|X) — 증거 본 후 갱신된 원인 확률
현대 응용 스팸 필터, 의료 진단, 음성 인식, 나이브 베이즈 분류기. 머신러닝의 기초.

핵심 5암 진단 사례 — 정확성의 함정

"검사 정확성 99%" = P(양성|암) = 0.99. 그러나 환자는 P(암|양성)을 알고 싶다.

암 발병률 1%일 때 베이즈 정리:

P(암|양성) ≈ 1%

거짓 양성(False Positive)이 많아 양성 후 실제 암일 확률은 의외로 낮다.

핵심 6퍼지 이론 (Fuzzy Theory)

언어의 모호함을 수학화. 1965 Lotfi Zadeh.
구분확률퍼지
다루는 것사건의 가능성경계의 모호함
예"비 올 확률 30%""키가 큰 편"
0~1의 의미발생 가능성속하는 정도
★ 빈출 ★ 확률 = "일어날 가능성" / 퍼지 = "속하는 정도".

핵심 7퍼지 집합과 멤버십 함수

퍼지 집합 (Fuzzy Set) 원소가 집합에 속하는 정도를 0~1 사이 실수로 표현. 일반 집합은 이진(속한다/안 속한다).
멤버십 함수 (Membership Function, μ) μ_A(x) = 원소 x가 퍼지 집합 A에 속하는 정도. 0 ≤ μ ≤ 1.
예: μ_큼(175cm) = 0.8 → "175cm는 큰 집합에 80% 속한다".

핵심 8퍼지 추론 4단계

  1. 퍼지화 (Fuzzification) — 수치 값을 멤버십 함수값으로 변환
  2. 규칙 적용 (Rule Application) — IF-THEN 퍼지 규칙 적용
  3. 집계 (Aggregation) — 여러 규칙 결과 결합
  4. 비퍼지화 (Defuzzification) — 무게중심(Center of Gravity)으로 수치 출력
시험 포인트 퍼지 추론은 4단계: 퍼지화 → 규칙 적용 → 집계 → 비퍼지화(무게중심).

응용: 퍼지 세탁기, 퍼지 에어컨, 자동초점 카메라, 일본 센다이 지하철 자동 운행 등 1990년대부터 광범위 응용.

1주차와의 연결 "딱딱함 vs 부드러움"의 부드러움(Soft) 영역. 강태원 교수 전공인 계산지능(CI) / 소프트 컴퓨팅(Soft Computing)의 핵심 분야.
