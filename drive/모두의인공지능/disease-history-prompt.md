### 2. 가장 중요한 원칙

> **강의 마지막 연습문제(Practice Problems)에서 시험 90% 이상 출제됨.**

- 문제집은 **전체를 연습문제 변형 중심**으로 구성할 것
- 고난도 응용 문제는 거의 출제되지 않으므로 **최소화**
- 단, 비연습문제(개념 보강용)도 일부 포함하여 완전성 확보
- 연습문제 기반 문제에는 `🔥 강의 연습문제` 배지를 시각적으로 표시

### 3. 디자인 (테마)

**고서적(古書籍) 느낌 — 다크브라운 + 크림**

- 텍스트: 다크브라운 (`#3d2817`, `#5a3a22`)
- 강조: 빈티지 레드(`#8b2c1f`) 또는 골드(`#a8843a`)
- 박스/구분선: 양피지·고문서 분위기의 테두리
- 폰트: `Noto Serif KR`, `Nanum Myeongjo` 등 명조체
- 모두의인공지능(보라/핑크) 및 AI윤리(아이보리/울트라마린)와 명확히 구분

### 5. 주차별 파일 작성 가이드

#### 5-1. `N주차_교과서.html` (강의 핵심 내용 완전 정리)

- 강의 스크립트를 책처럼 정리한 본문
- **사용 박스 종류**:
  - `.definition` — 개념 정의 박스
  - `.exam-point` — 시험 출제 포인트 강조 박스
  - `.quote` — 교수님의 인상적 발언 인용
  - `.section-tldr` — 각 섹션 시작에 1~3줄 요약
  - `.summary-box` — 섹션/주차 끝의 종합 정리
  - `.connect` — 다른 주차·다른 과목과의 연결 학습 박스
  - `.img-placeholder` — 그림이 필요한 자리 표시 (실제 이미지 없이 텍스트 설명)
  - `.watch-rec` — 관련 영상/문서 추천 (있는 경우)
- 학술용어는 한국어(English) 병기, 예: 흑사병(Black Death), 코흐의 가설(Koch's Postulates)
- 차시 표시는 본문 안에서 자연스럽게(예: "이번 주차 ①차시에서…") 하되 **주차 단위로 통합 구성**

#### 5-2. `N주차_학습서.html` (시험 직전 압축 정리본)

- 교과서를 압축한 시험 대비용 요약
- **필수 섹션**:
  1. **이 주차 한 줄 정리** (제목 바로 아래)
  2. **핵심 개념 카드** (정의·인물·사건을 카드 형태로)
  3. **시험 빈출 포인트** (`🎯 시험 출제` 표시)
  4. **💯 연습문제 완벽 정리** (이 주차에서 가장 중요한 섹션)
     - 강의 마지막 연습문제를 **문제·정답·해설** 모두 포함
     - 출제 가능성이 높음을 시각적으로 강조
  5. **연결 학습** (다른 주차와의 관계)

#### 5-3. `N주차_문제.html` (시험 대비 문제집)

- **문항 구성**: 객관식 5문 + 주관식 10문 + 서술형 5문
- **출제 비중**:
  - 70~80%: 강의 연습문제 그대로 또는 미세 변형 (배지: `🔥 강의 연습문제`)
  - 20~30%: 개념 보강용 문제 (난이도는 평이하게)
- 각 문항에 **펼치기/접기 토글**로 정답·해설 제공
- 고난도 응용 문제 / 트릭 문제 / 함정 문제는 **만들지 말 것**
- 문항 상단에 "이 문제는 강의 연습문제 ○번 기반" 같은 출처 표시 권장

### 6. `index.html` (메인 허브) 사양

- 완전히 새로 작성 (기존 파일 덮어쓰기)
- **구성**:
  1. 사이트 타이틀: "전염병과 인류의 역사"
  2. 시험 정보 카드 (기말고사 일정·범위·유형 표시)
  3. 주차 카드 6개 (9, 10, 11, 12, 13, 14주차)
     - 9~12주차: 활성 카드 (각 주차의 3개 파일로 링크)
     - 13·14주차: "준비 중" 비활성 카드
  4. 각 카드에 주차 핵심 키워드 2~3개 미리보기
- 다크브라운 + 크림 고서적 테마 일관 적용
- 반응형(모바일) 고려
