핵심 1인공 뉴런 (Artificial Neuron) 구조

생물학적 뉴런을 단순화한 계산 모델. 입력 여러 개, 출력 단 하나.
인공 뉴런 5요소 ① 입력 (X₁ ~ Xₙ) — 여러 개
② 가중치 (W₁ ~ Wₙ) — 시냅스에 해당
③ 가중치 합 (Σ Wᵢ·Xᵢ)
④ 활성함수 (Activation Function)
⑤ 출력 (y) — 단 하나
생물학적인공 뉴런
수상돌기 (Dendrite)입력 (X)
축색돌기 (Axon)출력 (y)
시냅스 (Synapse) 수용체 수가중치 (W)
몸통/핵활성함수 (Activation)
★ 시험 핵심 ★ 인공 뉴런 = n:1(입력 여러 개, 출력 단 하나). 출력 1개가 다음 뉴런 여러 개로 갈라지는 것은 별개.

핵심 2가중치와 가중치 합

가중치 (Weight, W) 인공 뉴런의 매개변수(Parameter). 생물학적 시냅스의 신호 강도 조절에 해당. 학습 = 가중치 조정.
가중치 합(Weighted Sum) = X₁·W₁ + X₂·W₂ + … + Xₙ·Wₙ = Σᵢ Wᵢ·Xᵢ
매개변수란? ChatGPT의 "수천억 개 매개변수" = 신경망의 가중치 수.

핵심 3활성함수 (Activation Function) 3종류

이름식출력 범위특징
계단함수 (Step Function) x ≥ 0이면 1, 아니면 0 {0, 1} 가장 단순. 초기 신경망에 사용
시그모이드 (Sigmoid) 1 / (1 + e⁻ˣ) (0, 1) S자 곡선. 연속적
ReLU max(0, x) [0, ∞) 딥러닝 시대의 표준
시험 포인트 시그모이드 식 1/(1+e⁻ˣ)은 빈출. e는 오일러 상수(≈2.71828) — π처럼 자연상수.

핵심 4바이어스(Bias) 입력

항상 정해진 값(보통 -1)이 들어가는 추가 입력. 학습에 필수.

외부 입력과 무관하게 뉴런 내부에서 자동 적용. 사람의 무의식 정보에 비유. 모든 실용 신경망에 포함되어 있음.

가중치 합 (바이어스 포함) = Σᵢ Wᵢ·Xᵢ + (-1)·θ = Σᵢ Wᵢ·Xᵢ − θ

핵심 5다층 신경망 (Multi-Layer Neural Network)

실제 뇌는 자유분방하게 얽혀 있지만, 컴퓨터 계산을 위해 층 단위로 줄을 맞춘 구조.
층이름역할
맨 앞입력층 (Input Layer)"헛개비" — 가중치 없음. 그냥 다음 층으로 값 전달
중간중간층/은닉층 (Hidden Layer)1개 이상
맨 뒤출력층 (Output Layer)최종 결과 출력
★ 빈출 ★ 입력층은 헛개비: 가중치 없음. 외부 입력값을 그대로 다음 층 모든 뉴런으로 뿌려준다. Keras 등에서도 입력층은 개수만 지정하고 별도 계산 없음.

핵심 6전진 전파(Feed Forward) · 완전 연결(Fully Connected)

두 가지 핵심 규칙 ① 전진 전파 (Feed Forward) — 한 층 → 다음 층 방향으로만 정보 전달
② 완전 연결 (Fully Connected, FC) — 한 뉴런의 출력이 다음 층 모든 뉴런으로 빠짐없이 전달

이를 "이웃에만 공평하게"라 부른다. 강의 부제이기도 함.

핵심 7출력 계산 절차

한 뉴런 = 활성함수(가중치 합). 입력층부터 출력층까지 차례로.

한 뉴런의 출력 식

yⱼ = activation( Σᵢ Wᵢⱼ · Xᵢ )

예제 — B 아기 (입력 2 / 중간 2 / 출력 1)

가중치: W₁₃=0.5, W₁₄=0.9, W₂₃=0.4, W₂₄=1.0, W₃₅=-1.2, W₄₅=1.0. 활성함수: 시그모이드. 입력: (1, 1).

단계가중치 합출력
Y₃ (중간)1·0.5 + 1·0.4 = 0.91/(1+e⁻⁰·⁹) ≈ 0.7
Y₄ (중간)1·0.9 + 1·1.0 = 1.91/(1+e⁻¹·⁹) ≈ 0.9
Y₅ (출력)0.7·(-1.2) + 0.9·1.0 = 0.061/(1+e⁻⁰·⁰⁶) ≈ 0.5
★ 빈출 ★ 이런 출력 계산은 직접 풀이 시험으로 자주 출제. ① 중간층부터 차례로 계산 ② 시그모이드 = 1/(1+e⁻ˣ) ③ 마지막은 출력층.
자료구조와의 연결 다층 신경망 = 방향성 비순환 그래프(DAG). 자료구조의 그래프 위상정렬(Topological Sort) 순서로 출력 계산.
