표기: B 블랙, R 레드. 난이도·유형은 중간고사 족보 기준입니다.
Q1객관식

일반 BST의 약점과 그로 인해 균형 검색 트리가 필요한 이유로 옳은 것은?

  1. BST는 정렬이 불가능하다.
  2. 삽입 순서에 따라 한쪽으로 치우치면 높이가 O(n)이 되어 연산이 O(n)으로 느려질 수 있다.
  3. BST는 중복 키를 저장할 수 없다.
  4. BST는 항상 O(n²)이다.
정답 / 풀이 보기

정답: 2번

BST의 모든 연산은 O(h)인데 균형이 보장되지 않습니다. 정렬된 순서(1,2,3,…)로 삽입하면 한 줄로 치우쳐 연결 리스트처럼 되어 h = O(n) → 탐색도 O(n). 그래서 높이를 O(log n)으로 강제하는 균형 트리가 필요합니다.

Q4빈칸 채우기

정답 / 풀이 보기

Q7객관식

AVL 회전의 암기 패턴으로 옳은 것은?

  1. LL → 좌회전, RR → 우회전
  2. LL → 우회전, RR → 좌회전 (이름과 회전 방향이 반대)
  3. 모든 유형이 좌회전
  4. 회전 방향은 무작위로 정한다
정답 / 풀이 보기

정답: 2번

이름과 회전 방향이 반대입니다. LL(왼쪽 무거움)은 우회전으로 오른쪽으로 넘기고, RR은 좌회전. 꺾인 LR/RL은 자식을 먼저 회전해 직선형으로 만든 뒤 같은 규칙을 적용합니다.

Q8코드 · 서술

좌회전(t) 의사코드이다. 회전 후 두 노드의 높이를 갱신할 때, t와 RChild 중 어느 쪽을 먼저 갱신해야 하며 그 이유는?

def 좌회전(t):
    RChild = t.right
    RLChild = RChild.left
    RChild.left = t
    t.right = RLChild
    # 높이 갱신: ?  먼저, 그 다음 ?
정답 / 풀이 보기

정답: t(아래쪽)를 먼저, 그 다음 RChild(위로 올라간 노드)

회전 후 t는 RChild의 자식이 됩니다. 부모의 높이는 자식 높이로 계산(height = max(left,right)+1)하므로, 자식 t의 높이가 먼저 확정돼야 부모 RChild의 높이를 올바로 계산할 수 있습니다. 각 회전은 포인터 4번 조작이라 O(1).

Q9객관식

연쇄 회전(Cascade Rotation)에 대한 설명으로 옳은 것은?

  1. 삽입에서 항상 발생하며 삭제에서는 없다.
  2. 삭제에서 자주 발생하며, 최악의 경우 루트까지 올라가며 최대 O(log n)번 회전할 수 있다.
  3. 한 번 회전하면 절대 다시 깨지지 않는다.
  4. 연쇄 회전이 일어나면 전체 시간복잡도가 O(n)이 된다.
정답 / 풀이 보기

정답: 2번

하위에서 회전하면 그 트리 높이가 변해 상위에서 새 불균형이 생길 수 있고, 특히 삭제에서 자주 일어납니다. 경로 길이가 O(log n)이라 최대 O(log n)번. 각 회전 O(1)이므로 전체는 여전히 O(log n)입니다. (삽입은 회전 1~2회로 끝.)

Q10객관식

레드블랙 트리의 NIL(리프) 약속에 대한 설명으로 옳은 것은?

  1. RB 트리에서 "리프 노드"는 실제 데이터를 담은 노드를 뜻한다.
  2. 모든 NULL 자리에 NIL 노드를 두며, RB에서 "리프 노드"는 이 NIL을 가리킨다. 실제 데이터 노드는 내부 노드라 부른다.
  3. NIL 노드는 레드이다.
  4. NIL은 루트에만 존재한다.
정답 / 풀이 보기

정답: 2번

모든 빈 자리에 NIL 노드(항상 블랙)를 둡니다. RB에서 리프 = NIL, 실제 값 노드 = 내부 노드. NIL을 두면 NULL 체크가 줄고 경로 길이 비교가 통일적으로 쉬워집니다.

Q11객관식 · 복수선택

  2. 모든 리프(NIL)는 블랙이다.
  3. 루트~리프 경로에 레드 노드가 두 개 연속 나올 수 없다.
  4. 루트~리프 경로의 블랙 노드 수가 모두 같다.

정답: 1, 2, 3, 4 (모두)

① 루트 블랙 ② NIL 블랙 ③ 레드 연속 금지 ④ 블랙 높이 일정. ③+④가 균형의 비결입니다(블랙만 보면 균형, 레드는 연속 불가라 너무 길어질 수 없음 → h ≤ 2·log₂n).

Q12계산 · 블랙 높이

다음 RB 트리에서 NIL은 생략되어 있다. 루트 30에서 임의의 NIL까지 경로의 블랙 노드 수(NIL 포함)를 구하고, 모든 경로가 같은지 확인하시오.

30(B) / \ 20(R) 40(B) / \ 10(B) 25(B)
정답 / 풀이 보기

정답: 3개로 모두 동일

30(B)→40(B)→NIL(B) = 3개. 30(B)→20(R)→10(B)→NIL(B): 20은 레드라 빼면 30,10,NIL = 3개. 30→20→25→NIL도 3개. 모든 경로가 블랙 3개 → 특성 ④ 만족.

Q13서술

RB 트리 삽입의 3단계 절차를 쓰고, 새 노드를 (블랙이 아니라) 레드로 칠하는 이유를 설명하시오.

정답 / 풀이 보기

정답 요지

절차: ① 일반 BST처럼 빈 자리에 삽입 → ② 새 노드 x를 레드로 칠함 → ③ x의 좌우에 NIL 리프 달기.

레드로 칠하는 이유: 블랙으로 칠하면 그 경로의 블랙 수가 1 늘어 특성 ④(블랙 높이 일정)를 거의 무조건 위반합니다. 레드는 블랙 수를 안 바꾸므로 ④는 유지되고, 최악이라도 특성 ③(레드 연속)만 깨질 수 있어 처리가 쉽습니다.

Q14객관식

RB 트리에 레드 노드 x를 삽입했는데 부모 p가 블랙이었다. 이때 필요한 후속 작업은?

  1. 회전 2번이 필요하다.
  2. p를 레드로 바꿔야 한다.
  3. 아무 작업도 필요 없다 (특성 모두 유지).
  4. x를 블랙으로 바꿔야 한다.
정답 / 풀이 보기

정답: 3번

x(레드)+p(블랙)은 레드 연속이 아니고(③ OK), 블랙 수도 안 변하므로(④ OK) 특성이 그대로 유지됩니다. 수선이 필요한 건 p가 레드일 때(레드 연속 위반)뿐입니다.
