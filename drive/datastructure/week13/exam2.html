문제은행 — 그래프 순회 (DFS · BFS)

트리 순회 · DFS/BFS · pre/post · DFS 트리·back edge · DFSALL · DAG · 위상 정렬

이 문제집은 13주차 2차시 강의노트(그래프 순회) 범위입니다. 위상 정렬은 강의에서 ★★ 시험 핵심으로 강조됐습니다.
난이도·유형은 중간고사 족보 기준입니다 (객관식 · 추적 · 빈칸 채우기 · 표 채우기 · 서술 · 코드).
Q1객관식

그래프 순회(traversal)의 목표로 옳은 것은?

  1. 모든 모서리(엣지)를 빠짐없이 한 번씩 지나는 것
  2. 모든 정점(노드)을 일정한 순서로 한 번씩 읽는 것
  3. 두 정점 사이의 가장 짧은 경로만 찾는 것
  4. 정점들을 키 값 순서대로 정렬하는 것
정답 / 풀이 보기

정답: 2번

순회는 모든 "정점"을 한 번씩 읽는 것입니다. 이미 방문한 노드로 가는 엣지는 무시하므로 모든 엣지를 다 지나는 것은 아닙니다. (visited 표시 필요.)

Q2빈칸 채우기

트리 순회 3가지를 "자신을 언제 읽느냐" 기준으로 채우고, inorder가 이번 예시에서 다뤄지지 않은 이유를 쓰시오.

• preorder: 순서 ______ → L → R
• inorder: L → ______ → R
• postorder: L → R → ______

정답 / 풀이 보기

정답: preorder = 자신 먼저 / inorder = 자신 가운데 / postorder = 자신 나중

inorder는 자신을 "왼쪽과 오른쪽 사이"에 넣는데, 이는 자식이 최대 2개인 이진 트리에서만 명확합니다. 예시 트리는 자식이 3개인 노드(a)가 있어 자신을 어디 둘지 모호하므로 inorder를 다루지 않습니다.

Q3추적 · 트리 순회

다음 트리(이진 트리 아님)의 preorder와 postorder 결과를 쓰시오. (자식은 왼쪽부터)

a / | \ b d g | / \ c e f | h
정답 / 풀이 보기

정답: preorder = a b c h d e f g / postorder = h c b e f d g a

preorder(자신→자식): a → (b→c→h) → (d→e→f) → g. postorder(자식→자신): 가장 깊은 h→c→b → e→f→d → g → 마지막 루트 a.

Q4객관식

DFS(깊이 우선 탐색)에 대한 설명으로 옳은 것은?

  1. 가까운 노드부터 한 겹씩 넓게 방문하며 큐로 구현한다.
  2. 갈 수 있는 데까지 깊이 들어간 뒤 backtrack하며 스택으로 구현한다.
  3. 시작점에서 모든 정점까지 최단 경로를 보장한다.
  4. 사이클이 없으므로 방문 표시(visited)가 필요 없다.
정답 / 풀이 보기

정답: 2번

DFS는 깊이 우선 + backtrack, 스택/재귀로 구현합니다. 1번은 BFS(큐)입니다. 그래프는 사이클이 있을 수 있어 visited 표시가 필수입니다.

Q5추적 · DFS

다음 무방향 그래프에서 a부터 DFS를 수행한 방문 순서를 쓰시오. (안 가본 인접 정점 중 알파벳 빠른 순)

인접: a:{b,c}  b:{a,c,e,h}  c:{a,b,d}  d:{c,f}
      e:{b,g}  f:{d}        g:{e}      h:{b}
정답 / 풀이 보기

정답: a, b, c, d, f, e, g, h

a→b(빠른 쪽)→c→d→f(막힘) → backtrack → b의 남은 이웃 e→g(막힘) → backtrack → b의 h. 깊이 우선이라 한 길을 끝까지 판 뒤 되돌아옵니다.

Q6코드 빈칸 채우기

DFS 재귀 의사코드의 빈칸을 채우시오.

def DFS(v):
    mark[v] = "visited"
    pre[v] = curr_time;  curr_time += 1   # ⓐ ____에 들어간 시각
    for each edge (v, w):
        if mark[w] != "visited":
            parent[w] = ____               # ⓑ w의 부모 기록
            DFS(w)
    post[v] = curr_time;  curr_time += 1   # ⓒ v를 ____ 시각
정답 / 풀이 보기

정답: ⓐ v에 처음 들어간   ⓑ parent[w] = v   ⓒ 완전히 끝낸(떠나는)

pre[v]는 진입(발견) 시각, post[v]는 종료 시각. parent[w]=v로 부모를 기록해 나중에 경로(DFS 트리)를 복원합니다. pre 값을 순서대로 늘어놓으면 방문 순서가 됩니다.

Q7객관식

DFS를 재귀 대신 스택으로 구현할 때 옳은 설명을 고르시오.

  1. LIFO라 알파벳 빠른 순 방문을 원하면 느린 이웃부터 push한다.
  2. 스택에는 같은 노드가 두 번 이상 들어가는 일이 없다.
  3. 스택 버전은 노드의 부모 정보를 저장할 방법이 없다.
  4. 스택 버전은 재귀 버전과 방문 순서가 항상 달라진다.
정답 / 풀이 보기

정답: 1번

LIFO라 마지막에 push한 게 먼저 pop됩니다. 알파벳 빠른 순으로 방문하려면 느린 것부터 push해야 합니다. 스택에는 같은 노드가 여러 번 들어갈 수 있지만(여러 이웃이 push) 실제 방문은 한 번만(이미 visited면 버림). (부모, 현재) 쌍을 저장해 부모 정보도 유지하며, 결과는 재귀와 같습니다.

Q8객관식

각 노드의 구간 [pre, post]를 막대로 그렸을 때, 두 노드 u, v의 관계 해석으로 옳은 것은?

  1. u가 v의 조상이면 u의 막대가 v의 막대를 완전히 포함한다.
  2. u와 v가 형제 관계여도 두 막대는 서로를 포함한다.
  3. 두 노드의 막대가 겹치면 그 그래프엔 사이클이 있다.
  4. 한 노드의 pre 값과 post 값은 언제나 서로 같다.
정답 / 풀이 보기

정답: 1번

DFS가 u→v로 들어가면 v는 u보다 늦게 진입하고 먼저 끝나므로 [pre(v),post(v)] ⊂ [pre(u),post(u)]. 즉 조상이면 막대 포함, 형제면 겹치지 않습니다. 이 포함 관계가 곧 DFS 트리의 부모-자식 구조이며, 콜스택의 push-pop과 같습니다.

Q9객관식

DFS 트리에 대한 설명으로 옳은 것은? (정점 n개 그래프)

  1. parent 관계의 선만 모아 시작 노드를 루트로 한 트리이다.
  2. 원래 그래프의 모든 엣지를 그대로 포함하는 트리이다.
  3. 노드가 n개일 때 트리 엣지는 항상 n개가 된다.
  4. 시작 노드를 어디로 잡든 항상 같은 모양이 된다.
정답 / 풀이 보기

정답: 1번

DFS 트리는 parent[] 관계 선만 추출, 시작 노드가 루트입니다. 노드 n개 → 트리 엣지 n−1개. 원래 그래프 엣지 중 트리에 안 들어간 것이 back edge입니다.

Q10서술

Back Edge(역방향 간선)란 무엇이며, back edge의 존재가 그래프에 대해 무엇을 의미하는가?

정답 / 풀이 보기

정답 요지: back edge 존재 ⇔ 사이클(순환) 존재

back edge는 원래 그래프엔 있지만 DFS 트리에는 없는 간선으로, 이미 방문한 조상으로 돌아가는 모양입니다. 조상으로 되돌아가는 간선이 있으면 그 경로가 닫혀 사이클이 생깁니다. 따라서 DFS 중 back edge가 하나라도 발견되면 사이클이 있고, 없으면 순환이 없습니다 (사이클 검사에 활용).

Q11객관식

DFSALL(G)에 대한 설명으로 옳은 것은?

  1. 그래프가 하나로 연결되어 있을 때만 정상 동작한다.
  2. 안 가본 노드마다 DFS를 새로 시작하며 모든 정점을 읽는다.
  3. 그래프와 무관하게 항상 DFS를 정확히 한 번만 호출한다.
  4. 내부적으로 DFS가 아니라 BFS로만 구현된다.
정답 / 풀이 보기

정답: 2번

DFS(v)는 v가 속한 덩어리만 훑으므로, 비연결 그래프는 안 가본 노드마다 DFS를 다시 시작해야 모든 정점을 읽습니다. DFS가 호출된 횟수가 곧 연결 요소의 개수입니다.

Q14빈칸 채우기

DAG의 약자를 풀어 쓰고, 그 핵심 성질과 대표 용도를 쓰시오.

정답 / 풀이 보기

정답: Directed Acyclic Graph (방향이 있고 사이클이 없는 그래프)

모든 간선에 방향이 있고, 어느 노드에서 출발해도 자기 자신으로 돌아오는 경로가 없습니다. "앞 일이 끝나야 뒤 일을 한다"는 선후(의존) 관계 모델링에 적합합니다.

Q15객관식

위상 정렬(Topological Sort)의 정의로 옳은 것은?

  1. 간선 u→v가 있으면 u가 v보다 앞에 오도록 정점을 줄세우는 것
  2. 정점들을 키(이름) 알파벳 순서대로 줄세우는 것
  3. 간선 u→v가 있으면 v가 u보다 앞에 오도록 줄세우는 것
  4. 사이클이 있는 그래프에서만 수행할 수 있는 정렬
정답 / 풀이 보기

정답: 1번

위상 정렬은 DAG의 정점을 "선행 작업 → 후행 작업" 순서로 줄세우는 것입니다. 간선 u→v는 "u가 먼저"를 뜻하므로 u가 v보다 앞에 와야 합니다. 사이클이 있으면 순서를 정할 수 없어 DAG에서만 가능합니다.

Q16객관식 · 시험 핵심

DFS의 pre/post 값으로 그래프를 분석할 때 옳은 것은?

  1. PRE 오름차순 = 위상 정렬 / POST 오름차순 = DFS 방문 순서
  2. PRE 오름차순 = DFS 방문 순서 / POST 내림차순 = 위상 정렬
  3. POST 오름차순 = 위상 정렬
  4. PRE와 POST는 분석에 쓸 수 없다
정답 / 풀이 보기

정답: 2번

PRE 값을 오름차순으로 늘어놓으면 DFS가 노드를 방문한 순서이고, POST 값을 내림차순(역순)으로 늘어놓으면 위상 정렬이 됩니다.

정점ABCDFGHI
post1613159126118

Q18서술 · 시험 핵심

"POST 값을 내림차순으로 늘어놓으면 위상 정렬이 된다"가 왜 성립하는지 간선 u→v 기준으로 설명하시오.

정답 / 풀이 보기

정답 요지: 간선 u→v가 있으면 post[u] > post[v]

DFS가 u에서 v로 들어가면 v를 완전히 끝낸(post 찍은) 뒤에야 u가 끝납니다. 즉 간선 u→v에 대해 항상 post[u] > post[v]. 따라서 post가 큰 노드부터 줄세우면 모든 간선이 "앞→뒤"를 향하게 되어, 선행 작업 u가 후행 작업 v보다 앞에 오는 위상 정렬이 됩니다.
