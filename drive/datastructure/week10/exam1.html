문제은행 — 레드-블랙 트리

5가지 조건 · 블랙 높이(Black Height) · h = O(log n) 증명 · 삽입 4경우

이 문제집은 10주차 1차시 강의노트(레드-블랙 트리: 정의·증명·삽입) 범위에서 출제했습니다.
표기: B 블랙 노드, R 레드 노드. 난이도·유형은 중간고사 족보 기준입니다.
Q1객관식 · 복수선택

레드-블랙 트리의 5가지 조건으로 옳은 것을 모두 고르시오.

  1. 루트 노드는 항상 블랙으로 유지된다.
  2. 리프 노드(None)는 모두 레드로 칠해진다.
  3. 레드 노드의 두 자식은 모두 블랙이어야 한다.
  4. 어느 노드에서든 리프까지 경로의 블랙 노드 수가 같다.
✎ 나의 답안
정답 / 풀이 보기

정답: 1, 3, 4

2번 틀림 — 리프(None)는 정의상 항상 블랙입니다. 나머지 조건: 모든 노드는 레드 또는 블랙, 루트는 블랙(1), None은 블랙, 레드의 두 자식은 블랙(3), 모든 경로 블랙 수 동일(4, =블랙 높이).

BST·AVL과 달리 레드블랙 트리는 자식이 없어도 (______) 노드를 명시적으로 표시하며, 이것을 리프 노드로 본다. 이 리프 노드의 색은 항상 (______)이다. 실제 값을 가진 노드는 (______) 노드라 부른다.

✎ 나의 답안
정답 / 풀이 보기

정답: None(=Null=NIL) / 블랙 / 내부(Internal)

이렇게 정의하면 모든 내부 노드가 정확히 두 자식(내부 노드 또는 None)을 갖게 되어 알고리즘이 깔끔해집니다.

Q3서술 · 비교

AVL 트리와 레드블랙 트리는 둘 다 O(log n)을 보장한다. 균형을 잡는 방식과 유리한 상황의 차이를 비교하시오.

✎ 나의 답안
정답 / 풀이 보기

정답 요지

AVL: 엄격한 균형(높이차 ≤ 1) → 탐색이 더 빠름, 삽입/삭제 시 회전이 잦음 → 읽기(탐색) 위주에 유리.

레드블랙: 느슨한 균형(색 규칙으로만) → 탐색은 약간 느리지만 삽입/삭제가 효율적 → 쓰기(삽입·삭제) 잦은 곳에 유리. 실무에서 "균형 BST"라 하면 보통 레드블랙입니다.

정답 / 풀이 보기

Q7객관식

레드블랙 트리 삽입에서 새 노드를 RED로 칠하고 시작하는 이유로 가장 알맞은 것은?

  1. RED 노드가 BLACK 노드보다 메모리를 덜 차지하기 때문
  2. 조건 5(블랙 높이)는 그대로 두고 조건 4만 점검하면 되기 때문
  3. RED로 칠한 노드는 이후 회전 대상에서 빠지기 때문
  4. 레드블랙 트리는 루트가 항상 RED여야 하기 때문
✎ 나의 답안
정답 / 풀이 보기

정답: 2번

RED는 블랙 높이 계산에 안 세이므로 RED로 넣으면 조건 5가 그대로 유지됩니다. 남은 점검은 조건 4(부모가 RED면 레드 연속)뿐입니다. BLACK으로 시작하면 모든 경로의 블랙 수가 깨져 훨씬 복잡해집니다.

Q10객관식

Case c-2(p RED, u BLACK)에서 회전 횟수에 대한 설명으로 옳은 것은?

  1. 일직선이면 회전 1번, 꺾이면 회전 2번
  2. 모양과 무관하게 항상 회전 1번
  3. 모양과 무관하게 항상 회전 3번
  4. 일직선이면 회전 2번, 꺾이면 회전 1번
✎ 나의 답안
정답 / 풀이 보기

정답: 1번

일직선이면 rotateRight(g)(또는 좌우 대칭) + 색 swap = 1번. 꺾이면 먼저 rotateLeft(p)로 일직선을 만든 뒤 처리 = 2번. (AVL의 LL/LR 발상과 동일.)

Q11빈칸 채우기 · 증명

h = O(log n) 증명의 사실 1을 완성하고, 어떤 증명 기법을 쓰는지 쓰시오.

v의 서브트리 내부노드 수 ≥ 2(______) − 1  ,  증명 기법: (______)

✎ 나의 답안
정답 / 풀이 보기

정답: 2bh(v) − 1 / 수학적 귀납법(Mathematical Induction)

높이 h(v)에 대한 귀납법으로 증명합니다. Base: h(v)=0이면 0 ≥ 20−1=0. 귀납 단계에서 두 자식의 bh가 bh(v)−1 이상임을 이용해 (2bh(v)−1−1)×2+1 = 2bh(v)−1을 얻습니다.

Q12서술 · 증명

증명의 사실 2는 "bh(루트) ≥ h/2"이다. 이것이 성립하는 이유를 5가지 조건 중 하나와 연결해 설명하시오.

✎ 나의 답안
정답 / 풀이 보기

정답 요지: 조건 4(레드 연속 금지)

루트에서 가장 깊은 리프까지의 경로(길이 h)에서 레드는 절대 연속할 수 없습니다(조건 4). 따라서 최악이라도 블랙·레드가 교대로 나타나 블랙이 적어도 절반 이상을 차지합니다. 그래서 그 경로의 블랙 수, 즉 bh(루트)는 h/2 이상이 됩니다.

Q13계산 · 도출

사실 1(n ≥ 2bh(r) − 1)과 사실 2(bh(r) ≥ h/2)를 결합하여, 높이 h의 상한을 n에 대한 식으로 나타내시오.

✎ 나의 답안
정답 / 풀이 보기

정답: h ≤ 2·log₂(n+1) ⟹ h = O(log n)

n ≥ 2bh(r)−1 ≥ 2h/2−1 → 2h/2 ≤ n+1 → 양변 log₂ → h/2 ≤ log₂(n+1) → h ≤ 2·log₂(n+1). (AVL은 약 1.44·log₂n으로 더 짧지만 레드블랙도 O(log n) 보장.)
