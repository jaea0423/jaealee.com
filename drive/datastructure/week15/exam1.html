Q1객관식

그래프 용어 "인접(adjacent)"과 "부속(incident)"의 구분으로 옳은 것은?

  1. 인접은 정점↔정점 관계, 부속은 정점↔간선 관계이다
  2. 인접은 정점↔간선 관계, 부속은 정점↔정점 관계이다
  3. 인접과 부속은 완전히 같은 뜻이다
  4. 인접은 방향 그래프, 부속은 무향 그래프에서만 쓴다
✎ 나의 답안
정답 / 풀이 보기

정답: 1번

간선 하나로 직접 이어진 두 정점은 서로 인접(adjacent)하다고 합니다. 정점과 간선 사이의 관계는 부속(incident)이라는 다른 용어를 씁니다("정점 v는 간선 e에 부속한다").

Q3객관식

방향 그래프에서 두 정점 A, B가 양방향으로 오갈 수 있을 때, 간선을 세는 방식으로 옳은 것은?

  1. 무향 간선 하나로 본다
  2. 방향이 반대인 간선 2개(A→B, B→A)로 본다
  3. 가중치가 있을 때만 2개로 센다
  4. A→B 하나만 있으면 B→A는 자동으로 생긴다
✎ 나의 답안
정답 / 풀이 보기

정답: 2번

방향 그래프에서 A↔B는 A→B와 B→A 두 개의 간선입니다. A→B가 있다고 B→A가 자동 생기지 않습니다(일방통행·팔로우 비유). 무향과 헷갈리지 않게 주의합니다.

Q4객관식

가중 방향 그래프에서 정점 i, j에 대해 옳은 것은?

  1. A[i][j]와 A[j][i]는 언제나 같은 값이다
  2. A[i][j]와 A[j][i]가 서로 다른 값일 수 있다 (방향마다 가중치 다름)
  3. 가중치는 두 방향이 항상 0이다
  4. 가중치는 무향 그래프에서만 가질 수 있다
✎ 나의 답안
정답 / 풀이 보기

정답: 2번

방향마다 가중치가 다를 수 있어 A[i][j](i→j)와 A[j][i](j→i)가 다른 숫자일 수 있습니다(오르막/내리막 비유: 영희→철수 9, 철수→영희 8). "같은 두 정점인데 가중치가 둘"이면 방향 그래프 신호입니다.

Q5객관식

인접 행렬의 대칭성으로 그래프를 구분하는 방법은?

  1. 대각선이 모두 0이면 방향, 아니면 무향이다
  2. 대칭(A[i][j]=A[j][i])이면 무향, 비대칭이면 방향이다
  3. 비대칭이면 무향, 대칭이면 방향이다
  4. 대칭성은 가중치 유무로만 결정된다
✎ 나의 답안
정답 / 풀이 보기

정답: 2번

무향은 i–j 연결이 곧 j–i 연결이라 A[i][j]=A[j][i]로 대각선 대칭입니다. 방향은 한 방향만 1일 수 있어 비대칭입니다. 표가 대칭이면 무향, 비대칭이면 방향으로 한눈에 구분합니다.

Q6객관식

가중치가 "거리·비용"을 뜻할 때, 인접 행렬에서 연결 안 된 칸과 대각선을 적는 규칙으로 옳은 것은?

  1. 연결 안 됨 = 0, 자기 자신 = ∞
  2. 연결 안 됨 = ∞, 자기 자신 = 0
  3. 연결 안 됨 = −1, 자기 자신 = 1
  4. 둘 다 0으로 적는다
✎ 나의 답안
정답 / 풀이 보기

정답: 2번

거리 맥락에서 0은 "아주 가까움"을 뜻하므로, 못 가는 길을 0으로 적으면 알고리즘이 최단으로 착각합니다. 그래서 "못 감"은 ∞로, 자기 자신까지 거리는 0으로 적습니다. 이 ∞ 행렬이 곧 Floyd-Warshall의 시작 행렬 d₀입니다.

Q7객관식

인접 리스트로 그래프를 저장할 때 옳은 것은?

  1. 방향 그래프는 들어오는 간선만 리스트에 넣는다
  2. 방향 그래프는 나가는 간선만 리스트에 넣는다
  3. 무향 그래프는 간선 1개가 리스트 노드 1개가 된다
  4. 가중치는 인접 리스트에 저장할 수 없다
✎ 나의 답안
정답 / 풀이 보기

정답: 2번

방향 그래프 인접 리스트는 각 정점의 나가는 간선(out-edge)만 담습니다. 무향은 양쪽이 통하므로 간선 1개가 양쪽 리스트에 들어가 노드 2개가 됩니다. 가중치는 정점 번호 옆에 같이 기록합니다.

Q8계산

간선이 m개인 무향 그래프를 인접 리스트로 저장하면, 모든 리스트의 노드 총개수는 몇 개인가? 그 이유도 쓰시오.

✎ 나의 답안
정답 / 풀이 보기

정답: 2m 개

무향 간선 하나(i–j)는 i의 리스트에 j, j의 리스트에 i로 양쪽에 들어갑니다. 그래서 간선 1개당 노드 2개 → 총 2m개. (방향 그래프라면 m개.)

Q11추적 · BFS/DFS

다음 무향 그래프에서 정점 0부터의 BFS와 DFS 방문 순서를 각각 쓰시오. (이웃은 번호 오름차순)

0: 1,2    1: 0,3,4    2: 0,4
3: 1      4: 1,2,5    5: 4
✎ 나의 답안
정답 / 풀이 보기

정답: BFS = 0 1 2 3 4 5 / DFS = 0 1 3 4 2 5

BFS(큐): 0 → 이웃 1,2 → 1의 새 이웃 3,4 → 4의 새 이웃 5. DFS(스택/재귀): 0→1→3(막힘)→4→2(막힘)→5. 같은 그래프·시작점이라도 큐는 옆으로, 스택은 아래로 퍼져 순서가 다릅니다.

  2. 재귀도 내부적으로 호출 스택(call stack)을 쓰므로 둘은 같은 알고리즘이다
  3. 스택 구현은 BFS와 같은 결과를 낸다
  4. 재귀 구현은 큐를 사용한다
✎ 나의 답안
정답 / 풀이 보기

  2. 미확정 정점 중 cost가 가장 작은 것을 deleteMin으로 골라 확정한다
  3. 임의의 정점을 골라 확정한 뒤 나중에 되돌린다

Q15추적 · 음수 간선

다음 방향 그래프에 s=A로 다익스트라를 돌린다. (간선: A→B = 8, A→C = 9, C→B = −15)

(1) 다익스트라가 내는 dist[B]는? (2) 진짜 최단 dist[B]는? (3) 왜 틀리는가?

✎ 나의 답안
정답 / 풀이 보기

정답: (1) 8   (2) −6   (3) 확정한 거리를 다시 안 보기 때문

A 확정 → B=8, C=9. 더 작은 B를 8로 확정(도장). 이후 C 확정 후 C→B 완화: 9+(−15)=−6 < 8이지만 B는 이미 확정이라 다익스트라는 안 고침 → 답 8(진짜는 −6). 음수 간선이 "갈수록 줄어드는" 상황을 만들어 그리디 가정을 깨므로, 이런 경우 벨만-포드를 써야 합니다.

Q16객관식

벨만-포드(Bellman-Ford)에 대한 설명으로 옳은 것은? (n = 정점 수)

  1. 모든 간선을 n−1번 완화하고, 한 번 더 돌려 음의 사이클을 검사한다
  2. 가장 가까운 정점부터 deleteMin으로 하나씩 확정한다
  3. 음수 가중치가 있으면 동작하지 않는다
  4. 모든 정점 쌍의 최단 경로를 한 번에 구한다
✎ 나의 답안
정답 / 풀이 보기

정답: 1번

벨만-포드는 확정 도장 없이 모든 간선을 n−1번 완화하고(최단 경로는 간선 최대 n−1개), 마지막에 한 번 더 돌려 여전히 줄어드는 간선이 있으면 음의 사이클로 판정합니다. 음수 가중치를 허용합니다.

Q17계산 · 음의 사이클

방향 그래프에 사이클 1→2→3→1이 있고 가중치가 각각 w(1,2)=−2, w(2,3)=−1, w(3,1)=−1이다. (1) 사이클의 가중치 합을 구하고 (2) 이 그래프에서 최단 경로가 정의되는지 답하시오.

✎ 나의 답안
정답 / 풀이 보기

정답: (1) −4 (음수)   (2) 정의되지 않음 (해 없음)

합 = (−2)+(−1)+(−1) = −4 < 0 → 음의 사이클. 이 사이클을 돌수록 거리가 무한히 작아져(−∞로 발산) "최소"가 존재하지 않으므로 최단 경로가 성립하지 않습니다. 벨만-포드는 이를 "해 없음"으로 알려줍니다.
