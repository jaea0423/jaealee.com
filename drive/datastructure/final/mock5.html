  1. s가 빨강이면 회전 2번, s가 검정이면 색만 변경한다
  2. s가 빨강이면 색만 변경(재귀 가능), s가 검정이면 회전 + 색 변경한다
  3. s의 색과 무관하게 항상 회전 2번 한다
  4. s의 색과 무관하게 항상 색만 변경한다
정답 / 풀이 보기

정답: 2번

Case 1(s 빨강): p·s를 검정, g를 빨강으로 색만 바꿈 → g 위쪽에서 또 깨질 수 있어 재귀. Case 2(s 검정): 회전(1~2번) + 색 교환으로 한 번에 해결.

  2. successor(또는 predecessor)와 교체한 뒤 리프에서 삭제한다

정답: 2번

정답 / 풀이 보기

정답 요지

부모의 키(2-노드와 형제 사이 키)가 2-노드로 내려오고, 형제의 인접 키가 부모로 올라갑니다(회전과 비슷). 형제 키를 바로 가져오면 BST 키 순서가 깨지므로, 부모를 거쳐서 가져와야 "왼쪽 < 부모 < 오른쪽" 순서가 유지됩니다.

Q10그래프객관식 · 알고리즘 선택

상황에 맞는 최단 경로 알고리즘 선택으로 잘못된 것은?

  1. 양수 가중치, 단일 출발점 → Dijkstra
  2. 음수 가중치 있음, 단일 출발점 → Bellman-Ford
  3. 모든 정점 쌍의 거리표가 필요 → Floyd-Warshall
  4. 음수 가중치 있음, 단일 출발점 → Dijkstra
정답 / 풀이 보기

정답: 4번 (잘못된 선택)

음수 가중치에서는 Dijkstra가 틀린 답을 낼 수 있어 Bellman-Ford를 써야 합니다. 1·2·3은 올바른 선택입니다(양수 단일→Dijkstra, 음수 단일→BF, 모든 쌍→Floyd).
