그래프 — 집중 예상문제

표현 · DFS/BFS · 위상정렬 · 최단경로(BF·Dijkstra·Floyd)

그래프는 기말 범위에서 비중이 가장 큰 단원입니다. 표현(행렬·리스트) · 순회(DFS/BFS) · 위상정렬 · 최단경로(Bellman-Ford·Dijkstra·Floyd-Warshall)를 30문제로 집중 점검합니다.
유형은 족보 기준입니다 — 추적·계산·표 채우기·빈칸·코드·서술. 직접 풀어 답을 적은 뒤 풀이로 대조하세요.

그래프는 "어떤 노드가 있는지(V)"와 "어떤 노드끼리 연결됐는지(E)" 두 집합으로 정의됩니다. 각 간선은 두 정점의 쌍 (u, v)입니다. 표기로 n = 정점 개수, m = 간선 개수를 씁니다.

✎ 나의 답안
정답 / 풀이 보기

정답: 3번

enqueue 직전에 visited를 찍어야 같은 정점이 여러 이웃에게 동시에 발견돼도 중복으로 큐에 들어가지 않습니다. 꺼낼 때 표시하면 같은 노드가 큐에 여러 번 쌓일 수 있습니다.

Q15그래프코드 빈칸 · pre/post

DFS 재귀 의사코드의 빈칸 ⓐⓑⓒ를 채우시오.

def DFS(v):
    mark[v] = "visited"
    pre[v] = curr_time;  curr_time += 1   # ⓐ v에 ____한 시각
    for each edge (v, w):
        if mark[w] != "visited":
            parent[w] = ____               # ⓑ w의 부모 기록
            DFS(w)
    post[v] = curr_time;  curr_time += 1   # ⓒ v를 ____ 시각
✎ 나의 답안
정답 / 풀이 보기

정답: ⓐ 처음 진입(발견)한   ⓑ parent[w] = v   ⓒ 완전히 끝낸(떠나는)

pre[v]는 진입(발견) 시각, post[v]는 종료 시각. parent[w]=v로 부모를 기록해 나중에 경로(DFS 트리)를 복원합니다. pre 값을 순서대로 늘어놓으면 DFS 방문 순서가 됩니다.

Q16그래프객관식 · 막대 포함

각 노드의 구간 [pre, post]를 막대로 그렸을 때, 두 노드 u, v의 관계 해석으로 옳은 것은?

  1. u와 v가 형제 관계여도 두 막대는 서로를 포함한다
  2. 두 노드의 막대가 겹치면 그 그래프엔 사이클이 있다
  3. 한 노드의 pre 값과 post 값은 언제나 서로 같다
  4. u가 v의 조상이면 u의 막대가 v의 막대를 완전히 포함한다
✎ 나의 답안
정답 / 풀이 보기

정답: 4번

DFS가 u→v로 들어가면 v는 u보다 늦게 진입하고 먼저 끝나므로 [pre(v),post(v)] ⊂ [pre(u),post(u)]. 즉 조상이면 막대 포함, 형제면 겹치지 않습니다. 이 포함 관계가 곧 DFS 트리의 부모-자식 구조이며 콜스택의 push-pop과 같습니다.

✎ 나의 답안
정답 / 풀이 보기

정답 요지: back edge 존재 ⇔ 사이클(순환) 존재

back edge는 원래 그래프엔 있지만 DFS 트리에는 없는 간선으로, 이미 방문한 조상으로 돌아가는 모양입니다. 조상으로 되돌아가는 간선이 있으면 그 경로가 닫혀 사이클이 생깁니다. 따라서 DFS 중 back edge가 하나라도 발견되면 사이클이 있고, 없으면 순환이 없습니다(사이클 검사에 활용).

Q18그래프객관식 · DFS 트리

  2. parent 관계의 선만 모아 시작 노드를 루트로 한 트리이며 간선은 n−1개이다
  3. 시작 노드를 어디로 잡든 항상 같은 모양이 된다
  4. 노드가 n개일 때 트리 간선은 항상 n개가 된다
✎ 나의 답안
정답 / 풀이 보기

정답: 2번

DFS 트리는 parent[] 관계 선만 추출하고 시작 노드가 루트입니다. 노드 n개 → 트리 간선 n−1개. 원래 그래프 간선 중 트리에 안 들어간 것이 back edge입니다.

Q19그래프객관식 · POST 역순

  1. PRE 오름차순 = 위상 정렬 / POST 오름차순 = DFS 방문 순서
  2. POST 오름차순으로 늘어놓으면 위상 정렬이 된다
  3. PRE 오름차순 = DFS 방문 순서 / POST 내림차순 = 위상 정렬
  4. PRE와 POST 값은 그래프 분석에 쓸 수 없다
✎ 나의 답안
정답 / 풀이 보기

정답: 3번

PRE 값을 오름차순으로 늘어놓으면 DFS가 노드를 방문한 순서이고, POST 값을 내림차순(역순)으로 늘어놓으면 위상 정렬이 됩니다. 간선 u→v가 있으면 항상 post[u] > post[v]이기 때문입니다.

  2. 최단 경로의 일부 구간도 반드시 그 구간의 최단 경로이다

Q24그래프객관식 · Bellman-Ford

  1. 한 라운드에 간선 하나만 검사하기 때문이다
  2. 그래프의 간선 수가 항상 n−1개이기 때문이다
  3. 최단 경로가 쓰는 간선이 최대 n−1개이고 라운드마다 한 칸씩 전파되기 때문이다
  4. n−1번이면 모든 정점을 정확히 한 번씩 방문하기 때문이다

Q25그래프계산 · 음의 사이클

✎ 나의 답안
정답 / 풀이 보기

정답: (1) −4 (음수)   (2) 정의되지 않음 (해 없음)   (3) n−1 라운드 후 한 번 더 돌려 검출

합 = (−2)+(−1)+(−1) = −4 < 0 → 음의 사이클. 이 사이클을 돌수록 거리가 무한히 작아져(−∞로 발산) "최소"가 존재하지 않습니다. Bellman-Ford는 n−1 라운드를 마친 뒤 한 번 더 모든 간선을 완화해서 여전히 줄어드는 간선이 있으면 음의 사이클(해 없음)로 판정합니다.

Q26그래프계산 · BF 시간복잡도

Bellman-Ford의 시간복잡도를 정점 수 n(=V), 간선 수 E로 나타내고, 가장 조밀한(완전) 그래프에서의 최악 복잡도를 쓰시오.

✎ 나의 답안
정답 / 풀이 보기

정답: O(VE) = O(nE), 최악 O(n³)

바깥 루프 n−1번 × 안쪽 모든 간선 E번 = O(nE). 완전 그래프는 E ≈ n²이므로 최악 O(n·n²) = O(n³)입니다.

Q27그래프객관식 · Dijkstra 그리디

Dijkstra 알고리즘의 핵심 전략으로 옳은 것은?

  1. 매 라운드 그래프의 모든 간선을 빠짐없이 다시 검사한다
  2. 가장 멀리 있는 노드부터 골라 하나씩 확정해 나간다
  3. 미확정 노드 중 dist가 가장 작은 노드를 deleteMin으로 골라 확정하고 그 이웃만 relax한다
  4. 임의의 노드를 무작위로 골라 relax를 반복한다
✎ 나의 답안
정답 / 풀이 보기

정답: 3번

Dijkstra는 미확정 노드 중 가장 가까운(dist 최소) 노드를 min-heap에서 deleteMin해 확정하고, 그 노드의 이웃만 relax합니다. relax로 dist가 줄면 heap 안 위치를 decreaseKey로 갱신합니다. 한 번 확정된 노드는 다시 보지 않아 BF보다 빠릅니다(양수 가중치 전제).

(1) 다익스트라가 내는 dist[B]는? (2) 진짜 최단 dist[B]는? (3) 왜 틀리는가?
