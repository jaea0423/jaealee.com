Q1AVL계산 · 점화식

높이 h인 AVL 트리의 최소 노드 수 점화식은 Nh = Nh−1 + Nh−2 + 1 (N₀=1, N₁=2)이다. N₂부터 차례로 구해 N₅를 쓰시오.

정답 / 풀이 보기

정답: N₅ = 20

N₂=4, N₃=7, N₄=12, N₅ = N₄+N₃+1 = 12+7+1 = 20. 이 점화식에서 Nh ≥ 2h/2를 유도해 h = O(log n)을 증명합니다.

Q2AVL추적 · 회전

비어 있는 AVL 트리에 30, 20, 10 순서로 삽입하면 균형이 깨진다. (1) 불균형 유형(LL/RR/LR/RL)과 (2) 필요한 회전, (3) 회전 후 루트가 되는 키를 쓰시오.

정답 / 풀이 보기

정답: LL 유형 / 30에서 우회전 / 루트 = 20

30(루트)→20(왼쪽)→10(왼쪽)으로 왼쪽-왼쪽 일직선 = LL. 위반 노드 30에서 우회전하면 20이 루트가 되고 10·30이 양쪽 자식이 됩니다.

Q3R-B객관식

레드-블랙 트리 삽입에서 새 노드를 빨강으로 칠하고 시작하는 이유는?

  1. 빨강 노드가 검정보다 메모리를 덜 차지하기 때문이다
  2. 블랙 높이 규칙은 그대로 두고 레드 연속 규칙만 점검하면 되기 때문이다
  3. 빨강으로 칠한 노드는 회전 대상에서 빠지기 때문이다
  4. 레드블랙 트리는 루트가 항상 빨강이어야 하기 때문이다
정답 / 풀이 보기

정답: 2번

빨강은 블랙 높이 계산에 안 세이므로, 빨강으로 넣으면 블랙 높이 규칙이 그대로 유지됩니다. 남은 점검은 레드 연속(부모가 빨강) 뿐이라 처리가 쉽습니다. 검정으로 시작하면 모든 경로의 검정 수가 깨집니다.

Q52-3-4복수선택

2-3-4 트리가 만족해야 하는 조건으로 옳은 것을 모두 고르시오.

  1. 모든 노드의 자식 수는 2, 3, 4 중 하나이다
  2. 모든 리프 노드는 같은 레벨에 위치한다
  3. 한 노드는 키를 최대 2개까지만 가질 수 있다
  4. 자식이 최대 2개인 이진 트리의 일종이다
정답 / 풀이 보기

정답: 1, 2

3번 틀림(키 최대 3개), 4번 틀림(자식 최대 4개라 이진 트리 아님). 조건은 ① 자식 수 2~4 ② 모든 리프 같은 레벨(균형)입니다.

Q62-3-4객관식 · fusion

삭제 중 처리할 2-노드의 인접 형제도 2-노드여서 키를 빌릴 수 없을 때 수행하는 연산과 그 결과로 옳은 것은?

  1. Redistribution — 트리 높이가 1 증가한다
  2. Merge — 부모가 키 하나와 자식 하나를 잃는다
  3. Split — 가운데 키가 올라가 새 루트가 생긴다
  4. 별도 처리 없이 그대로 삭제하면 된다
정답 / 풀이 보기

정답: 2번

형제도 2-노드면 빌릴 게 없어 Merge(병합): 부모 키 1개를 끌어내려 두 형제를 4-노드로 합칩니다. 그래서 부모는 키와 자식을 하나씩 잃습니다(루트 2-노드면 높이 1 감소).

Q7그래프계산 · 인접 리스트

간선이 7개인 무향 그래프를 인접 리스트로 저장하면 모든 리스트의 노드 총개수는 몇 개인가? 이유도 쓰시오.

정답 / 풀이 보기

정답: 14개 (= 2 × 7)

무향 간선 1개(i–j)는 i의 리스트에 j, j의 리스트에 i로 양쪽에 들어가 노드 2개를 만듭니다. 간선 m개 → 2m개. (방향 그래프라면 나가는 것만이라 m개.)

Q8그래프객관식 · back edge

DFS 중 발견되는 back edge(역방향 간선)에 대한 설명으로 옳은 것은?

  1. back edge가 하나라도 있으면 그래프에 사이클이 존재한다
  2. back edge는 DFS 트리에 반드시 포함되는 간선이다
  3. back edge가 많을수록 DFS 트리 높이가 낮아진다
  4. back edge는 무방향 그래프에서만 나타난다
정답 / 풀이 보기

정답: 1번

back edge는 이미 방문한 조상으로 되돌아가는 간선이라, 존재하면 그 경로가 닫혀 사이클이 생깁니다(back edge ⇔ 사이클). DFS로 사이클을 검사할 수 있습니다.

Q9그래프계산 · Bellman-Ford

출발점 a에서, a로 들어/나가는 간선이 다음과 같다: a→b = 5, a→c = 1, c→b = 3. b까지의 최단 거리 dist[b]를 구하고 경로를 쓰시오.

정답 / 풀이 보기

정답: dist[b] = 4 (a → c → b)

직접 a→b = 5, 경유 a→c→b = 1+3 = 4. min(5, 4) = 4이므로 c를 경유하는 게 더 짧습니다. (relax(a,c)로 dist[c]=1 → relax(c,b)로 dist[b]=4.)

Q10그래프빈칸 + 계산 · Floyd

(1) Floyd-Warshall 점화식의 빈칸을 채우고 (2) 주어진 값으로 dk(i, j)를 계산하시오.

dk(i,j) = min( dk−1(i,j),  dk−1(i,__) + dk−1(__,j) )
주어진 값: dk−1(i,j)=9,  dk−1(i,k)=2,  dk−1(k,j)=5
정답 / 풀이 보기

정답: (1) dk−1(i, k) + dk−1(k, j)   (2) dk(i,j) = 7

min( 9, 2+5 = 7 ) = 7. k를 거치는 경로(7)가 기존(9)보다 짧아 갱신됩니다.
