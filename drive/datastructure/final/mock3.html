Q1AVL서술 · 증명

"AVL 트리의 높이가 O(log n)임을 증명하라." 최소 노드 수 점화식 Nh = Nh−1 + Nh−2 + 1 에서 시작해 h = O(log n)에 도달하는 핵심 흐름을 순서대로 쓰시오.

정답 / 풀이 보기

정답 요지 (흐름)

① Nh = Nh−1 + Nh−2 + 1 → ② Nh−1 ≥ Nh−2 이용해 Nh ≥ 2Nh−2 (+1 떼냄) → ③ 반복 적용 Nh ≥ 2k·Nh−2k → ④ k=h/2 대입 Nh ≥ 2h/2 → ⑤ 2h/2 ≤ Nh ≤ n에 log₂ 취함 → h ≤ 2 log₂ n → ⑥ h = O(log n).

Q2AVL객관식 · 연쇄 회전

AVL 연쇄 회전(cascade rotation)에 대한 설명으로 옳은 것은?

  1. 삽입에서 항상 발생하고 삭제에서는 일어나지 않는다
  2. 삭제에서 자주 일어나며 최악의 경우 O(log n)번 회전한다
  3. 한 번 회전하면 위쪽이 다시 깨지는 일은 없다
  4. 연쇄 회전이 생기면 전체 시간복잡도가 O(n)이 된다
정답 / 풀이 보기

정답: 2번

하위에서 회전하면 트리 높이가 변해 상위에서 새 불균형이 생길 수 있고, 특히 삭제에서 자주 일어납니다. 경로 길이 O(log n)이라 최대 O(log n)번. 각 회전 O(1)이라 전체는 여전히 O(log n)입니다(삽입은 1~2회로 끝).

Q7그래프객관식 · 방향

방향 그래프와 그 인접 행렬에 대한 설명으로 옳은 것은?

  1. A↔B 양방향은 무향 간선 하나로 세고 행렬이 대칭이다
  2. A↔B 양방향은 간선 2개로 세고, A[i][j]와 A[j][i]가 다를 수 있다
  3. 방향 그래프 행렬은 항상 대각선 대칭이다
  4. A→B가 있으면 B→A가 자동으로 생긴다
정답 / 풀이 보기

정답: 2번

방향 그래프에서 A↔B는 A→B, B→A 두 간선입니다. 한 방향만 있을 수 있어 A[i][j](i→j)와 A[j][i]가 다를 수 있고, 그래서 행렬이 비대칭입니다. 대칭이면 무향, 비대칭이면 방향으로 구분합니다.

Q8그래프객관식 · pre/post

DFS의 각 노드 구간 [pre, post]를 막대로 그렸을 때, 두 노드 u, v 관계 해석으로 옳은 것은?

  1. u가 v의 조상이면 u의 막대가 v의 막대를 완전히 포함한다
  2. u와 v가 형제 관계여도 두 막대는 서로를 포함한다
  3. 두 막대가 겹치면 그 그래프엔 사이클이 있다
  4. 한 노드의 pre 값과 post 값은 언제나 서로 같다
정답 / 풀이 보기

정답: 1번

DFS가 u→v로 들어가면 v는 더 늦게 진입하고 먼저 끝나므로 [pre(v),post(v)] ⊂ [pre(u),post(u)]. 조상이면 막대 포함, 형제면 안 겹칩니다. 이 포함 관계가 곧 DFS 트리의 부모-자식 구조입니다.

Q9그래프계산 · 음수 간선

방향 그래프 간선이 A→B = 8, A→C = 9, C→B = −15 이다. s=A로 다익스트라를 돌릴 때 (1) dist[B]는 얼마로 나오며 (2) 진짜 최단은? (3) 틀리는 이유는?

정답 / 풀이 보기

정답: (1) 8   (2) −6   (3) 확정한 거리를 다시 안 보기 때문

A 확정 → B=8, C=9. 더 작은 B를 8로 확정. 이후 C 확정 후 C→B 완화: 9+(−15)=−6 < 8이지만 B는 이미 확정이라 안 고침 → 답 8(진짜 −6). 음수 간선이 그리디 가정을 깨므로, 이 경우 벨만-포드를 씁니다.
