Q1AVL복수선택

AVL 트리에 대한 설명으로 옳은 것을 모두 고르시오.

  1. AVL 트리는 이진 탐색 트리(BST)이다
  2. 모든 노드에서 좌우 서브트리 높이 차가 1 이하이다
  3. 최악의 경우 탐색 시간이 O(n)이다
  4. 탐색·삽입·삭제가 모두 O(log n)으로 보장된다
정답 / 풀이 보기

정답: 1, 2, 4

3번 틀림 — AVL은 균형이 강제되어 높이가 O(log n)이라 최악도 O(log n)입니다(최악 O(n)은 일반 BST). 1·2·4는 모두 옳습니다.

Q2AVL코드 분석

좌회전(t) 의사코드에서 회전 후 두 노드의 높이를 갱신할 때, t와 RChild(t의 오른쪽 자식, 위로 올라가는 노드) 중 어느 쪽을 먼저 갱신해야 하며 이유는?

정답 / 풀이 보기

정답: t(아래쪽)를 먼저, 그 다음 RChild

회전 후 t는 RChild의 자식이 됩니다. 부모 높이는 자식 높이로 계산(height = max(left,right)+1)하므로, 자식 t의 높이가 먼저 확정돼야 부모 RChild 높이를 올바로 구할 수 있습니다. 각 회전은 포인터 4번 조작이라 O(1).

Q3R-B계산 · 높이 상계

레드블랙 높이 상계 개선 분석에서 worst case(모두 3-노드)는 h' ≤ 2·log₃ n 이다. (1) log₂ 3의 범위를 부등식으로 구하고 (2) 이를 이용해 h'을 log₂ n 계수로 나타내시오.

정답 / 풀이 보기

정답: (1) 1 < log₂ 3 < 2 (≈ 1.585)   (2) h' ≤ (2/log₂3)·log₂ n ≈ 1.26·log₂ n

2 < 3 < 4에 log₂를 씌우면 1 < log₂3 < 2. 밑 변환으로 2·log₃ n = (2/log₂3)·log₂ n, 2/1.585 ≈ 1.26. 기존 2·log₂ n보다 타이트한 상계입니다.

Q4R-B객관식 · NIL

레드-블랙 트리의 NIL(리프) 약속으로 옳은 것은?

  1. RB 트리의 "리프 노드"는 실제 데이터를 담은 노드를 뜻한다
  2. 모든 NULL 자리에 NIL을 두고 그 NIL을 리프 노드로 본다
  3. NIL 노드는 빨강으로 칠해진 빈 자리 노드이다
  4. NIL 노드는 트리의 루트 자리에만 존재한다
정답 / 풀이 보기

정답: 2번

모든 빈 자리에 NIL(항상 검정)을 둡니다. RB에서 리프 = NIL, 실제 값 노드 = 내부 노드. NIL을 두면 NULL 체크가 줄고 경로 길이 비교가 통일적으로 쉬워집니다.

Q52-3-4객관식

2-3-4 트리에서 트리의 높이가 1 증가하는 유일한 경우는?

  1. 리프에 빈 자리가 있어 그냥 끼워 넣을 때
  2. 중간 노드를 split해 가운데 키를 올릴 때
  3. 루트가 가득 차 split되며 새 루트가 생길 때
  4. 내부 노드를 successor와 교체해 삭제할 때
정답 / 풀이 보기

정답: 3번

가운데 키를 올릴 부모가 없을 때(루트 가득 참) 새 루트가 생기며 높이가 1 증가합니다. 이것이 높이가 늘어나는 유일한 경로라 모든 리프가 같은 레벨을 유지합니다.

Q62-3-4추적 · insert

리프 노드 [35](2-노드, 빈 자리 있음)에 36을 삽입하면 결과는? split이 필요한가?

정답 / 풀이 보기

정답: [35, 36] (split 불필요)

[35]는 키가 1개뿐이라 빈 자리가 있습니다. 36을 정렬 상태로 그냥 끼워 넣어 [35, 36]이 됩니다. 가득 찬 4-노드가 아니므로 split은 필요 없습니다.

Q7그래프계산 · 인접 행렬

n=5, m=6인 무향 그래프를 인접 행렬(주대각 1 약속)로 표현했다. 값이 1인 칸의 총 개수를 구하시오.

정답 / 풀이 보기

정답: 17개

1의 개수 = (주대각) n + (무향 간선 양방향) 2m = 5 + 2×6 = 17. 전체 칸은 n²=25이므로 사용률 약 68%입니다.

Q8그래프객관식 · DFSALL

DFSALL(G)을 어떤 그래프에 돌렸더니 DFS가 총 3번 호출되었다. 이로부터 알 수 있는 것은?

  1. 그래프의 정점이 정확히 3개이다
  2. 그래프의 연결 요소(component)가 3개이다
  3. 그래프에 사이클이 3개 있다
  4. 위상 정렬 결과의 길이가 3이다
정답 / 풀이 보기

정답: 2번

DFS(v)는 한 덩어리만 훑으므로 안 가본 노드마다 새로 호출됩니다. 따라서 DFS 호출 횟수 = 연결 요소(컴포넌트)의 개수 = 3입니다.

Q9그래프추적 · Dijkstra

다음 방향 그래프에 s부터 Dijkstra를 돌린다. (간선: s→a=2, s→b=5, a→b=1, a→c=7, b→c=3) (1) 노드 확정 순서와 (2) dist[c]를 구하시오.

정답 / 풀이 보기

정답: (1) s, a, b, c   (2) dist[c] = 6

s(0) 확정 → a=2, b=5. 더 작은 a(2) 확정 → a→b: 2+1=3<5 → b=3, a→c: 2+7=9. b(3) 확정 → b→c: 3+3=6<9 → c=6. c(6) 확정. 경로 s→a→b→c = 6.

Q10그래프계산 · 음의 사이클

방향 그래프에 사이클 1→2→3→1이 있고 가중치가 w(1,2)=−2, w(2,3)=−1, w(3,1)=−1 이다. (1) 사이클 가중치 합과 (2) 이 그래프에서 최단 경로가 정의되는지 답하시오.

정답 / 풀이 보기

정답: (1) −4 (음수)   (2) 정의되지 않음 (해 없음)

합 = (−2)+(−1)+(−1) = −4 < 0 → 음의 사이클. 돌수록 거리가 무한히 작아져(−∞ 발산) "최소"가 없습니다. 벨만-포드는 n번째 라운드에서도 갱신이 일어나면 이를 "해 없음"으로 검출합니다.
