Q15R-B계산 · 증명

h = O(log n) 증명에서 사실 1(n ≥ 2bh(r) − 1)과 사실 2(bh(r) ≥ h/2)를 결합하여, 높이 h의 상한을 n에 대한 식으로 유도하시오.

✎ 나의 답안
정답 / 풀이 보기

정답: h ≤ 2·log₂(n+1) ⟹ h = O(log n)

n ≥ 2bh(r)−1 ≥ 2h/2−1 → 2h/2 ≤ n+1 → 양변 log₂ → h/2 ≤ log₂(n+1) → h ≤ 2·log₂(n+1). 사실 2는 레드 연속 금지 규칙에서 나옵니다(레드가 연속 불가라 블랙이 경로의 절반 이상 차지).

Q16R-B계산 · 부등식

개선된(타이트한) 상계 유도에 쓰이는 log₂ 3의 범위를 부등식으로 유도하시오. (단조증가성과 log₂4 = 2를 이용)

✎ 나의 답안
정답 / 풀이 보기

정답: 1 < log₂ 3 < 2 (≈ 1.585)

2 < 3 < 4 에 단조증가 함수 log₂를 씌우면 log₂2 < log₂3 < log₂4, 즉 1 < log₂3 < 2. (log₂4 = log₂2² = 2.) 이로써 2/log₂3 < 2가 보장되어 개선 상계가 기존보다 항상 작습니다.

Q17R-B계산 · 결론

(1) 개선된 레드블랙 높이 상계를 log₂ n에 대한 계수로 나타내시오. (2) n = 1,000,000(log₂n ≈ 20)일 때 기존 상계(2·log₂n)와 개선 상계의 최악 연산 횟수를 비교하시오.

✎ 나의 답안
정답 / 풀이 보기

정답: (1) h ≤ (2/log₂3)·log₂n ≈ 1.26·log₂n   (2) 기존 40번 → 개선 약 25번

2/log₂3 ≈ 2/1.585 ≈ 1.26. 유도: 최악 케이스는 모두 3-노드인 2-3-4 트리(h = log₃n)를 변환한 경우로 h' ≤ 2·log₃n = (2/log₂3)·log₂n. n=10⁶: 기존 2×20 = 40번, 개선 1.26×20 ≈ 25번. log₂3 > 1이라 항상 기존보다 타이트합니다(빅오는 둘 다 O(log n)).
