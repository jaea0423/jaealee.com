문제은행 — 최단 경로 알고리즘

dist 점화식 · relax · Bellman-Ford · Dijkstra · parent / 최단 경로 트리(SPT)

이 문제집은 14주차 1차시 강의노트(최단 경로: Bellman-Ford & Dijkstra) 범위에서 출제했습니다.
아래 여러 문제에서 강의노트의 예제 그래프 A(방향+가중치, s=a)를 사용합니다. 간선 목록:
a→b 5 a→c 1 b→d 4 b→f 1 c→b 3 d→c 2 d→e 9 d→f 1 e→c 2 e→h 5 f→e 7 f→g 3 g→e 1 g→h 3 g→i 4 h→g 2 h→i 1 (s=a 기준 최종 dist: a0 b4 c1 d8 e9 f5 g8 h11 i12)
Q1객관식

최단 경로 문제와 가중치 그래프에 대한 설명으로 옳은 것은?

  1. 간선의 유무만 따지며 간선마다 숫자(비용)는 붙지 않는다
  2. 여러 경로 중 거치는 간선 수가 가장 적은 경로를 찾는다
  3. 여러 경로 중 간선 가중치의 합이 가장 작은 경로를 찾는다
  4. 모든 정점을 한 번씩 방문하는 순서를 찾는 문제이다
정답 / 풀이 보기

정답: 3번

가중치 그래프는 각 간선에 거리·시간·비용 등 숫자(weight)가 붙은 그래프이고, 최단 경로 문제는 가중치 합이 최소인 경로를 찾는 것입니다. 간선 수 최소(2번)는 무가중치 그래프(BFS)의 경우입니다.

Q2계산

다음 무방향 도시 그래프에서 서울 → 원주 최단 거리와 경로를 구하시오.

서울—수원 10   수원—원주 70   서울—춘천 30
춘천—원주 10   서울—대전 40   대전—수원 20
정답 / 풀이 보기

정답: 40 (서울 → 춘천 → 원주)

서울→수원→원주 = 10+70 = 80, 서울→춘천→원주 = 30+10 = 40, 서울→대전→수원→원주 = 40+20+70 = 130. 최단은 40.

Q3객관식

"부분 경로 최단성(Optimal Substructure)"의 의미로 옳은 것은?

  1. 최단 경로의 일부 구간도 반드시 그 구간의 최단 경로이다
  2. 최단 경로는 항상 가장 적은 수의 간선을 사용한다
  3. 최단 경로는 그래프에서 단 하나만 존재한다
  4. 부분 경로의 합은 항상 전체 경로보다 크다
정답 / 풀이 보기

정답: 1번

a→…→g→i가 a→i 최단이면 그 일부인 a→…→g도 a→g 최단입니다. 아니라면 a→g를 더 짧게 바꿔 전체도 더 짧아져 모순. 이 성질 덕에 큰 문제를 작은 문제로 쪼개 풀 수 있습니다.

Q4빈칸 채우기

최단 거리 dist[v]의 점화식을 완성하시오. (v로 들어오는 모든 간선 u→v에 대해)

dist[v] = min ( dist[____] + w(____, ____) )   for all u → v
정답 / 풀이 보기

정답: dist[v] = min ( dist[u] + w(u, v) )

v까지의 최단 거리 = "직전 노드 u까지의 최단 거리 + 마지막 간선 비용"의 최솟값. v로 들어오는 후보 u가 여럿이면 그중 가장 작은 합이 dist[v]가 됩니다. 모든 최단 경로 알고리즘의 뼈대입니다.

Q5코드 빈칸 채우기

relax(u, v) 연산을 완성하시오.

def relax(u, v):
    if dist[v] > dist[u] + w(u, v):
        dist[v] = ____________________
정답 / 풀이 보기

정답: dist[v] = dist[u] + w(u, v)

u를 거쳐 가는 게 지금까지의 dist[v]보다 짧으면 그 값으로 줄입니다(풀어준다). dist는 줄어들기만 하고 늘어나지 않습니다.

Q6계산 · relax

현재 dist[u] = 3, dist[v] = 10, 간선 w(u, v) = 4 이다. relax(u, v)를 수행하면 dist[v]는 어떻게 되는가? 또 dist[v]가 처음부터 5였다면?

정답 / 풀이 보기

정답: 10 → 7로 갱신 / 5이면 갱신 없음(5 유지)

dist[u]+w = 3+4 = 7. 10 > 7 이므로 dist[v]=7로 줄임. 만약 dist[v]=5였다면 5 > 7이 거짓이라 갱신하지 않습니다.

Q7객관식

Bellman-Ford가 최대 n−1 라운드만 돌면 충분한 이유로 옳은 것은? (n = 정점 수)

  1. 한 라운드에 간선 하나만 검사하기 때문이다
  2. 최단 경로가 사용하는 간선이 최대 n−1개이고 라운드마다 한 칸씩 전파되기 때문이다
  3. 그래프의 간선 수가 항상 n−1개이기 때문이다
  4. n−1번이면 모든 정점을 정확히 한 번씩 방문하기 때문이다
정답 / 풀이 보기

정답: 2번

최단 경로는 사이클을 포함하지 않으므로 간선을 최대 n−1개 사용합니다. 한 라운드마다 "한 칸 더 멀리"의 정보가 전파되므로 n−1 라운드면 모든 최단 거리가 확정됩니다.

Q8추적 · Bellman-Ford

그래프 A(s=a)에서 a→b로 가는 직접 간선은 가중치 5이다. 그런데 최종 dist[b] = 4이다. (1) 왜 5가 아니라 4인지 경로로 설명하고 (2) 어떤 relax가 이 갱신을 만드는지 쓰시오.

정답 / 풀이 보기

정답: a → c → b = 1 + 3 = 4 (직접 a→b=5보다 짧음)

relax(a, c)로 dist[c]=1이 된 뒤, relax(c, b)에서 dist[b]=5 > dist[c]+w(c,b)=1+3=4 이므로 dist[b]가 4로 갱신됩니다. c를 경유하는 게 더 짧습니다.

Q9계산 · 시간복잡도

Bellman-Ford의 시간복잡도를 정점 수 V(=n), 간선 수 E로 나타내고, 가장 조밀한(완전) 그래프에서의 최악 복잡도를 쓰시오.

정답 / 풀이 보기

정답: O(VE) = O(nE), 최악 O(n³)

바깥 루프 n−1번 × 안쪽 모든 간선 E번 = O(nE). 완전 그래프는 E ≈ n²이므로 최악 O(n·n²) = O(n³)입니다.

Q10객관식

Dijkstra 알고리즘의 핵심 전략으로 옳은 것은?

  1. 매 라운드 그래프의 모든 간선을 빠짐없이 다시 검사한다
  2. 미확정 노드 중 dist가 가장 작은 노드를 골라 확정하고 그 이웃만 relax한다
  3. 가장 멀리 있는 노드부터 골라 하나씩 확정해 나간다
  4. 임의의 노드를 무작위로 골라 relax를 반복한다
정답 / 풀이 보기

정답: 2번

Dijkstra는 미확정 노드 중 가장 가까운(dist 최소) 노드를 min-heap에서 deleteMin해 확정하고, 그 노드의 이웃만 relax합니다. 한 번 확정된 노드는 다시 보지 않아 BF보다 빠릅니다.

Q11코드 빈칸 채우기

Dijkstra(min-heap 버전) 의사코드의 빈칸을 채우시오.

Q = min_heap with dist[v] as keys
while Q ≠ ∅:
    u = Q.__________()              # ★ ⓐ 가장 가까운 노드 꺼내 확정
    for each edge u → v:
        if dist[v] > dist[u] + w(u, v):
            relax(u, v)
            Q.__________(v, dist[v]) # ★ ⓑ heap 속 v 위치 재정렬
정답 / 풀이 보기

정답: ⓐ deleteMin   ⓑ decreaseKey

deleteMin으로 dist 최소 노드를 꺼내 확정하고, relax로 dist[v]가 줄면 decreaseKey로 heap 안 v의 위치를 갱신합니다. 둘 다 O(log n).

Q12서술

Dijkstra에서 relax로 dist[v]를 줄인 뒤 decreaseKey(v, dist[v])를 호출해야 하는 이유를 쓰시오.

정답 / 풀이 보기

정답 요지

dist[v]가 바뀌면 min-heap Q 안에서 v의 위치(우선순위)도 다시 정렬해야 합니다. 갱신하지 않으면 다음 deleteMin이 잘못된(실제로는 더 가까운 노드가 아닌) 노드를 꺼내게 되어 알고리즘이 틀립니다.

Q13추적 · Dijkstra

그래프 A(s=a)에 Dijkstra를 돌릴 때, 노드가 확정되는(deleteMin되는) 순서의 처음 다섯 개를 쓰시오.

정답 / 풀이 보기

정답: a, c, b, f, d

dist 최소 순으로 확정: a(0) → c(1) → b(4) → f(5) → d(8). 이후 g(8) → e(9) → h(11) → i(12). 확정될 때의 dist가 곧 최종 최단 거리입니다.

Q14객관식

Dijkstra가 "가장 가까운 미확정 노드 u를 바로 확정해도 안전한" 이유로 옳은 것은? (모든 가중치 양수 가정)

  1. 다른 미확정 노드를 거쳐 u로 가면 항상 더 짧아지기 때문이다
  2. u보다 가까운 미확정 노드가 없어 u의 dist를 더 줄일 수 없기 때문이다
  3. u가 그래프에서 차수가 가장 큰 노드이기 때문이다
  4. 모든 노드의 dist가 처음부터 같기 때문이다
정답 / 풀이 보기

정답: 2번

u를 더 짧게 가려면 u보다 가까운 미확정 노드를 거쳐야 하는데, u가 이미 미확정 중 최소라 그런 노드가 없습니다(양수 가중치라 거쳐 가면 더 늘기만 함). 따라서 u의 dist는 확정값입니다. 음수 가중치가 있으면 이 논리가 깨집니다.

Q16계산 · 시간복잡도

(1) min-heap을 쓴 Dijkstra의 시간복잡도를 n, E로 쓰시오. (2) heap을 Fibonacci heap으로 바꾸면 어떤 복잡도로 개선되는가?

정답 / 풀이 보기

정답: (1) O((n+E) log n), 최악 O(n² log n)   (2) O(E + n log n)

각 노드 deleteMin(n번)과 각 간선마다 decreaseKey(E번)가 모두 O(log n)이라 O((n+E)log n). Fibonacci heap은 decreaseKey가 평균 O(1)이라 O(E + n log n)으로 개선됩니다(심화).

Q17객관식

SSSP(Single-Source Shortest Path)에 대한 설명으로 옳은 것은?

  1. 한 출발점에서 모든 정점까지의 최단 경로를 구하며, 출발점이 바뀌면 다시 돌려야 한다
  2. 모든 정점 쌍 사이의 최단 경로를 한 번에 구하는 문제이다
  3. 출발점과 도착점이 정해진 한 쌍만 풀 수 있는 문제이다
  4. Dijkstra로만 풀 수 있고 Bellman-Ford로는 풀 수 없다
정답 / 풀이 보기

정답: 1번

BF와 Dijkstra 모두 출발점 s 하나에 대해 모든 정점까지의 최단 거리를 한 번에 구하는 SSSP 알고리즘입니다. 출발점이 바뀌면 처음부터 다시 실행해야 합니다.

Q18추적 · parent / SPT

그래프 A(s=a) Dijkstra 종료 후 parent 배열이 다음과 같다. parent를 역추적해 a→i 최단 경로를 복원하시오. 또 모든 parent 관계를 모으면 어떤 구조가 되며 간선 수는 몇 개인가?

parent[a]=∅  parent[b]=c  parent[c]=a  parent[d]=b  parent[e]=g
parent[f]=b  parent[g]=f  parent[h]=g  parent[i]=g
정답 / 풀이 보기

정답: a → c → b → f → g → i / 최단 경로 트리(SPT), 간선 n−1개

i부터 거슬러: i←g←f←b←c←a. 뒤집으면 a→c→b→f→g→i (비용 12). parent 관계를 모두 모으면 s=a를 루트로 한 최단 경로 트리(SPT)가 되고, 정점 n개에 간선은 n−1개입니다.
