문제은행 — Floyd-Warshall

All-to-All 최단 경로 · 중간 노드 k 분해 · 점화식 · base case · 음수 가중치

이 문제집은 14주차 2차시 강의노트(All-to-All 최단 경로, Floyd-Warshall) 범위입니다.
추적 문제는 강의노트의 예시 그래프(노드 4개, 음수 가중치 포함)를 사용합니다. 간선: 2→1 (4), 1→3 (−2), 3→4 (2), 4→2 (−1), 2→3 (3)

Q1객관식

All-to-All 최단 경로 문제가 SSSP(단일 출발점)와 다른 점으로 옳은 것은?

  1. 한 출발점에서 모든 도착점까지의 거리만 구한다
  2. 모든 정점 쌍 (i, j)의 최단 거리를 구해 n×n 표를 채운다
  3. 출발점과 도착점이 정해진 한 쌍만 푼다
  4. 가중치가 없는 그래프에서만 풀 수 있다
정답 / 풀이 보기

정답: 2번

SSSP는 출발점 1개에 대한 n개 거리(배열)를 구하지만, All-to-All은 모든 출발점×도착점의 n×n 거리 표를 구합니다(예: 도시 간 거리표, 라우팅 테이블).

Q2계산 · 시간복잡도

방법 1(모든 출발점에 대해 Dijkstra를 반복)로 All-to-All을 풀 때의 시간복잡도를 구하시오. (Dijkstra 한 번 = O(n² log n) 가정)

정답 / 풀이 보기

정답: O(n³ log n)

n개 출발점 각각에 Dijkstra(O(n² log n))를 돌리므로 n × n² log n = O(n³ log n)입니다.

Q3객관식

Floyd-Warshall의 시간복잡도와 방법 1과의 비교로 옳은 것은?

  1. O(n²)이며 방법 1보다 n배 빠르다
  2. O(n³)이며 방법 1보다 log n 만큼 빠르다
  3. O(n³ log n)이며 방법 1과 같다
  4. O(n log n)이며 방법 1보다 n² 빠르다
정답 / 풀이 보기

정답: 2번

Floyd-Warshall은 O(n³)입니다. (i,j) 쌍 n²개 × 중간 노드 후보 n개 = n³. 방법 1의 O(n³ log n)보다 log n 만큼 빠릅니다.

Q4빈칸 채우기

i→j 최단 경로를 중간 노드 k 기준으로 분해한 식을 완성하시오. (이 성질의 이름도 쓰시오)

d(i, j) = d(i, ____) + d(____, j)      성질 이름: ____________
정답 / 풀이 보기

정답: d(i, j) = d(i, k) + d(k, j) / 부분 경로 최단성(Optimal Substructure)

i→j 최단 경로 중간에 k가 있으면 i→k, k→j 두 구간도 각각 최단입니다(14-1에서 증명). Floyd-Warshall은 이 분해를 활용하는 동적 계획법(DP)입니다.

Q5객관식

dk(i, j)의 정의로 옳은 것은?

  1. 정확히 k개의 간선을 쓰는 i→j 경로의 길이이다
  2. 중간 노드를 {1, …, k}에서만 골라 갈 때의 i→j 최단 거리이다
  3. i에서 k까지 가는 최단 거리이다
  4. k번째로 짧은 i→j 경로의 길이이다
정답 / 풀이 보기

정답: 2번

dk(i, j)는 중간 경유 노드를 {1, …, k}로 제한했을 때의 i→j 최단 거리입니다. k는 "쓸 수 있는 중간 노드의 최대 인덱스". k=n이면 제한이 없어 진짜 최단 거리가 됩니다.

Q6빈칸 채우기 · 핵심

Floyd-Warshall의 핵심 점화식을 완성하시오. (min을 빠뜨리지 말 것)

dk(i, j) = min ( dk−1(i, j),
                  dk−1(i, ____) + dk−1(____, j) )
정답 / 풀이 보기

정답: dk(i, j) = min( dk−1(i, j), dk−1(i, k) + dk−1(k, j) )

k를 안 거치는 경우(dk−1(i, j))와 k를 거치는 경우(dk−1(i, k)+dk−1(k, j)) 중 더 짧은 쪽을 택합니다. min이 빠지면 안 됩니다.

Q7서술

점화식의 두 항 dk−1(i, j) 와 dk−1(i, k) + dk−1(k, j) 가 각각 무엇을 뜻하는지 쓰시오.

정답 / 풀이 보기

정답 요지

앞 항은 k를 중간 노드로 쓰지 않는 경우의 최단 거리(이전 단계 그대로). 뒤 항은 k를 거쳐 가는 경우로, i→k 최단과 k→j 최단을 이어 붙인 비용입니다. 둘 중 짧은 쪽이 dk(i, j).

Q8빈칸 채우기

Base case d0(i, j)의 세 경우를 채우시오.

d₀(i, j) = ____   if i = j
d₀(i, j) = ____   if (i, j) ∈ E
d₀(i, j) = ____   otherwise
정답 / 풀이 보기

정답: 0 / w(i, j) / ∞

k=0은 중간 노드 없이 직접 간선만 사용. 자기 자신은 0, 직접 간선이 있으면 그 가중치, 없으면 ∞(도달 불가). 이 d0 표가 곧 가중치 인접 행렬입니다.

Q9객관식

모든 k에 대해 항상 성립하는 것은?

  1. dk(i, j) = dk(j, i) (대칭)
  2. dk(i, i) = 0 (대각선은 언제나 0)
  3. dk(i, j) ≥ 0 (항상 양수)
  4. dk(i, j) = k (인덱스와 같음)
정답 / 풀이 보기

정답: 2번

자기 자신으로 가는 비용은 0이므로 대각선 dk(i, i)는 모든 k에서 0입니다. 방향 그래프라 대칭(1번)은 일반적으로 성립하지 않고, 음수 가중치가 있으면 양수(3번)도 아닙니다.

Q10계산 · d₀

예시 그래프(간선: 2→1=4, 1→3=−2, 3→4=2, 4→2=−1, 2→3=3)에서 다음 d0 값을 구하시오.

(1) d0(1, 3)   (2) d0(1, 2)   (3) d0(3, 3)

정답 / 풀이 보기

정답: (1) −2   (2) ∞   (3) 0

d0(1,3)=−2 (1→3 직접 간선). d0(1,2)=∞ (1→2 직접 간선 없음). d0(3,3)=0 (대각선).

Q11추적 · k=1

예시 그래프에서 k=1 단계(노드 1을 중간 경유 허용)로 갈 때 d1(2, 3)을 점화식으로 계산하시오. (d0(2,3)=3, d0(2,1)=4, d0(1,3)=−2)

정답 / 풀이 보기

정답: d1(2, 3) = 2

d1(2,3) = min( d0(2,3)=3, d0(2,1)+d0(1,3)=4+(−2)=2 ) = 2. 2→1→3 경로(비용 2)가 직접 2→3(비용 3)보다 짧아 갱신됩니다.

Q12추적 · 갱신 후보

k 단계에서 갱신될 수 있는 칸 (i, j)를 빨리 찾는 방법은 "k열에 ∞ 아닌 값이 있는 행 i" × "k행에 ∞ 아닌 값이 있는 열 j"이다. d1 표를 기준으로 k=2 단계에서 검사해야 할 칸을 모두 쓰시오. (d1에서 2열의 ∞ 아닌 값: d1(4,2)=−1 / 2행의 ∞ 아닌 값: d1(2,1)=4, d1(2,3)=2)

정답 / 풀이 보기

정답: (4, 1)과 (4, 3)

i 후보 = 4 (2열에서 ∞ 아닌 행), j 후보 = 1, 3 (2행에서 ∞ 아닌 열). 조합은 (4,1), (4,3). 실제로 d2(4,1)=−1+4=3, d2(4,3)=−1+2=1로 갱신됩니다. (k행·k열 자체는 안 바뀜.)

Q13추적 · 음수 상쇄

k=3 단계에서 d3(1, 4)를 구하시오. (d2(1,4)=∞, d2(1,3)=−2, d2(3,4)=2) 결과가 그 값이 되는 이유도 한 줄로 쓰시오.

정답 / 풀이 보기

정답: d3(1, 4) = 0

min( ∞, d2(1,3)+d2(3,4) = −2+2 = 0 ) = 0. 경로 1→3→4에서 음수 −2와 양수 +2가 정확히 상쇄되어 비용 0이 됩니다(음수 가중치라 가능).

Q14객관식

음수 가중치에 대한 Floyd-Warshall의 특성으로 옳은 것은?

  1. Dijkstra처럼 음수 가중치가 있으면 동작하지 않는다
  2. 음수 가중치가 있어도 되지만, 음수 사이클이 있으면 안 된다
  3. 음수 가중치와 음수 사이클 모두 허용한다
  4. 가중치가 모두 0일 때만 동작한다
정답 / 풀이 보기

정답: 2번

Floyd-Warshall(과 Bellman-Ford)은 음수 가중치를 허용합니다. 단 음수 사이클이 있으면 돌수록 비용이 무한정 줄어 최단 경로가 정의되지 않아 안 됩니다. (Dijkstra는 음수 가중치 자체가 불가.)

Q15객관식

Floyd-Warshall이 k를 진행시키는 순서로 옳은 것은?

  1. k = n부터 시작해 0까지 줄여 간다
  2. k = 0(직접 간선)부터 시작해 n까지 늘려 가며, 답은 dn이다
  3. k를 무작위 순서로 한 번씩 적용한다
  4. k = 1 한 번만 적용하면 끝난다
정답 / 풀이 보기

정답: 2번

base case d0(직접 간선=가중치 인접 행렬)에서 시작해 k=1,2,…,n으로 중간 경유 가능 노드를 하나씩 늘려 갑니다. k=n에 도달하면 모든 노드를 경유할 수 있어 dn이 진짜 최단 거리 표가 됩니다.
