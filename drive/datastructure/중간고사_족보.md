## 2. 코드의 시간복잡도 (Big-O)

다음 코드들의 시간복잡도를 Big-O로 나타내시오.

**(a)**

```python
def func(n):
    for i in range(n):
        for j in range(i):
            print(i, j)
```

**(b)**

```python
def func(n):
    for i in range(n):
        j = 1
        while j < n:
            j = j * 2
```

**(c)**

```python
def func(n):
    i = n
    while i > 0:
        for j in range(i):
            ...
        i //= 2
```

> ⚠️ (c)는 전송 중 들여쓰기가 깨져서 의도대로 복원함. `for j` 루프 본문과 `i //= 2`의 위치가 위 형태가 맞는지 확인 필요.

## 5. 해시테이블 (Linear Probing + 삭제)

크기 7의 해시테이블의 해시함수는 다음과 같다.

$$f(x) = x \bmod 7$$

- 충돌은 **linear probing**으로 해결한다.
- 삭제 연산은 수업시간에 배운 삭제 알고리즘 `remove(key)`에 따라 **필요한 원소를 앞으로 이동시키는 방식**으로 수행한다.

빈 해시테이블에 다음 순서로 키를 삽입하였다.

```

```

## 7. 이진탐색트리(BST) 삭제 + preorder

다음 순서대로 키를 이진탐색트리에 삽입한 후 `delete(30)`과 `delete(70)`을 차례대로 수행하시오.
그 후의 **preorder 순회 결과**를 작성하시오.

**삽입 순서**

```
50, 30, 70, 20, 40, 60, 80, 35, 45, 65, 75
```

**조건**

- BST 삽입 규칙을 따른다.
- 삭제 시, 삭제할 노드가 두 자식을 가지는 경우 **오른쪽 서브트리에서 가장 작은 값**으로 대체한다.
- preorder 순회는 "루트 → 왼쪽 → 오른쪽" 순서로 방문한다.
