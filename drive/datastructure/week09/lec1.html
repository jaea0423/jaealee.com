AVL 트리 (1) — 정의와 높이 분석

균형 이진 탐색 트리(Balanced BST)는 왜 필요하고, 어떻게 h = O(log n)이 보장되는가

01 BST의 한계 — 왜 AVL이 필요한가

지각 보충 영역
이 단원은 수업 초반(약 30분) 놓친 부분을 채워 넣은 내용입니다. 강의에서 직접 언급되지 않았을 수 있어요.

이전에 배운 이진 탐색 트리 (Binary Search Tree, BST)는 탐색·삽입·삭제가 평균적으로 빠른 자료구조였습니다. 평균 시간 복잡도는 O(log n)이죠.

하지만 최악의 경우에는 문제가 생깁니다. 데이터가 정렬된 순서로 들어오면 트리가 한쪽으로만 쭉 늘어져서 사실상 연결 리스트 (Linked List)가 되어버립니다.

같은 7개 데이터지만, 삽입 순서에 따라 트리 모양이 완전히 달라집니다
BST의 치명적 약점
데이터를 누가, 어떤 순서로 넣을지 모르기 때문에 최악의 경우 O(n)이 될 수 있습니다. 이걸 막으려면 트리가 항상 균형을 유지하도록 강제해야 합니다 → 그래서 등장한 것이 AVL 트리입니다.

02 AVL 트리란?

지각 보충 영역
AVL의 정의 부분도 수업 초반에 다뤄졌을 가능성이 높습니다.
AVL 트리는 모든 노드에서 좌우 서브트리의 높이 차이가 최대 1인 BST입니다.

이름의 유래: 1962년 소련 수학자 Adelson-Velsky와 Landis가 제안한, 역사상 최초의 자가 균형 이진 탐색 트리 (Self-balancing BST)입니다.

균형 인수 (Balance Factor)

각 노드에서 다음 값을 계산합니다:

BF(v) = height(왼쪽 서브트리) − height(오른쪽 서브트리)

AVL 조건: 모든 노드 v에 대해 |BF(v)| ≤ 1 (즉, BF는 −1, 0, +1 중 하나여야 함)

핵심 직관
"왼쪽이랑 오른쪽이 너무 차이 나면 안 돼!"라는 규칙을 모든 노드에 강제하는 것. 이 조건만 지키면 트리가 마치 자동으로 균형을 잡는 것처럼 동작합니다.

03 높이와 노드 개수의 관계 — 여기서부터 강의 내용

AVL 트리의 핵심 질문: 높이 h와 노드 개수 n은 어떤 관계인가? 이걸 알아야 탐색 시간이 정말로 O(log n)인지 증명할 수 있어요.

접근 방법: "최소 노드 개수"를 보자

높이가 h일 때 가장 적은 노드를 가지는 AVL 트리를 생각해봅니다. 이 최소 개수를 Nh라고 부릅시다.

왜 최소를 보냐면, 최악의 경우(노드는 적은데 높이는 높은 경우)를 분석해야 빅오를 알 수 있기 때문입니다.

높이별 최소 트리 관찰

높이 h 최소 노드 수 Nh 관찰
01루트만 있음
12루트 + 자식 1개
24= N₁ + N₀ + 1 = 2 + 1 + 1
37= N₂ + N₁ + 1 = 4 + 2 + 1
412= N₃ + N₂ + 1 = 7 + 4 + 1
규칙 발견
높이 h의 최소 AVL 트리는 = (높이 h−1의 최소 트리) + (높이 h−2의 최소 트리) + (루트 1개)

04 점화식 세우기

왜 한쪽은 h−1, 다른 쪽은 h−2인가?

높이 h인 AVL 트리의 노드 수를 최소로 만들려면:

  • 한쪽 서브트리는 어쩔 수 없이 높이 h−1 (그래야 전체 높이가 h)
  • 다른 쪽은 최대한 작게 → AVL 조건상 높이 차가 1까지 허용되니까 높이 h−2까지 줄일 수 있음
점화식 (RECURRENCE)
Nh = Nh−1 + Nh−2 + 1
연결 학습 — 이산수학
이거 어디서 본 것 같지 않으세요? 이산수학(Discrete Mathematics)에서 배우는 피보나치 수열의 점화식(Fn = Fn−1 + Fn−2)과 거의 같은 모양이에요. 실제로 Nh를 피보나치 트리 (Fibonacci Tree)라고도 부릅니다.

05 h = O(log n) 증명

이제 점화식에서 출발해 단계별로 증명해봅시다.

점화식에서 부등식으로

높이가 클수록 노드 수도 많으니까, Nh−2 < Nh−1입니다. 따라서 Nh−1를 Nh−2로 바꿔치기하면 부등식이 성립해요.

Nh = Nh−1 + Nh−2 + 1  ≥  Nh−2 + Nh−2 + 1
⟹   Nh ≥ 2·Nh−2 + 1  >  2·Nh−2
재귀적으로 풀어내기

Nh ≥ 2·Nh−2를 계속 적용합니다. h에 h−2를 대입하면 Nh−2 ≥ 2·Nh−4가 되죠.

Nh ≥ 2·Nh−2 ≥ 2·(2·Nh−4) = 22·Nh−4
≥ 23·Nh−6 ≥ ... ≥ 2k·Nh−2k
몇 번 빼야 N0에 도달?

2씩 빼나가면 h, h−2, h−4, ... → 총 h2번 빼면 0이 됩니다. 즉 k = h2일 때 Nh−2k = N0 = 1.

Nh ≥ 2h/2 · N0 = 2h/2
n과 연결

n은 실제 노드 수, Nh는 최소 노드 수니까 당연히 n ≥ Nh입니다.

n ≥ Nh ≥ 2h/2
양변에 log₂ 씌우기

밑이 1보다 큰 로그는 증가함수이므로 부등호 방향이 그대로 유지됩니다. 그리고 log₂(2h/2) = h2입니다.

log2n ≥ log2(2h/2) = h2
⟹   h ≤ 2·log2n
최종 결과
h ≤ 2·log2n  ⟹  h = O(log n)
표기 주의
  • 빅오 표기에서는 보통 로그의 밑을 생략합니다 (밑이 달라져도 상수배 차이라 빅오에서는 같음)
  • 줄글로 쓸 때 log_2 n의 _는 "밑(base)"을 뜻함. log2n으로 읽기
  • 지수 2^(h/2)는 2h/2로 읽기

참고 — 완전 이진 트리의 경우

트리를 꽉 채워서(가장 균형 있게) 만들면 n = 2h+1 − 1이고, 대략 n ≈ 2h이므로 h ≈ log2n이 됩니다. AVL은 이 이상적인 경우보다 살짝 느슨하지만, 여전히 O(log n)을 보장하는 게 핵심이에요.

06 일반 BST vs AVL — 시간 복잡도 정리

탐색·삽입·삭제의 시간 복잡도는 모두 트리 높이 h에 비례합니다 (O(h)). 그러니까 결국 높이가 얼마나 잘 통제되는가가 모든 걸 결정해요.

자료구조 평균 최악 비고
일반 BST O(log n) O(n) 편향되면 망함
AVL 트리 O(log n) O(log n) 최악도 보장됨 ✓
실전 감각
n = 1,000,000일 때:
  • O(n) → 약 1,000,000번 비교
  • O(log n) → 약 20번 비교 (log2 1,000,000 ≈ 20)
50,000배 차이입니다.

07 AVL 트리 구현 — BST 상속하기

이전 BST 코드 복습

이전 시간 복습
  • Node 클래스: key, parent, left, right
  • BST 클래스: root, size (필드) + insert, search, deleteByMerging, deleteByCopying (메서드)
  • BST는 순서를 직접 저장하지 않고 링크(부모-자식 연결)로만 구조를 유지함
  • find_loc(key): 그 key를 가진 노드를 반환 (또는 들어갈 위치를 반환)
  • search는 find_loc을 활용
연결 학습 — 객체지향 복습
파이썬은 객체지향 프로그래밍 (Object-Oriented Programming, OOP)입니다. 클래스는 도면/껍데기이고, 객체는 그 도면으로 만든 실제 인스턴스예요. 클래스 안에는 필드(변수)와 메서드(함수)가 있습니다.

핵심 아이디어: 상속 + 오버라이딩

AVL은 BST에 "균형 조건"만 추가된 것이므로, BST 코드를 상속받아서 필요한 부분만 오버라이드하면 됩니다.

상속의 핵심 규칙
자식 클래스에서 같은 이름의 메서드를 정의하면, 그게 우선으로 호출됩니다 (오버라이딩). 그래서 avl.insert(5)를 호출하면 BST의 insert가 아닌 AVL의 insert가 실행돼요. 필요하면 내부에서 super().insert()로 부모 메서드를 호출할 수 있습니다.

08 다음 시간 예고 — 회전 (Rotation)

오늘은 "AVL이 왜 O(log n)인가"를 증명했고, 구현은 클래스 골격까지만 봤습니다. 실제 핵심인 균형이 깨졌을 때 어떻게 복구하는가는 다음 시간에 다룹니다.

예고편

  • 회전 (Rotation): 트리를 좌우로 살짝 돌려서 균형을 맞추는 연산
  • 4가지 케이스: LL, RR, LR, RL — 어디가 어떻게 기울었는지에 따라 다른 회전 적용
  • 회전 후에도 BST 조건(왼쪽 < 부모 < 오른쪽)이 유지되는 게 신기한 부분
오늘 꼭 기억할 것 (시험 포인트)
  1. AVL 정의: 모든 노드의 |BF| ≤ 1
  2. 점화식: Nh = Nh−1 + Nh−2 + 1
  3. 증명 흐름: 점화식 → Nh ≥ 2h/2 → 양변 log → h ≤ 2·log2n
  4. 결론: AVL의 높이는 O(log n), 따라서 모든 연산이 O(log n)
