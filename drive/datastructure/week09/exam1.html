문제은행 — AVL 트리 (1)

정의 · 균형 인수(Balance Factor) · 높이와 노드 개수 · h = O(log n) 증명

이 문제집은 9주차 1차시 강의노트 범위에서 출제했습니다. 회전(Rotation, LL/RR/LR/RL)은 2차시 내용이라 제외했습니다.
난이도·유형은 중간고사 족보를 기준으로 맞췄습니다 (복수선택 객관식 · 코드/시간복잡도 분석 · 빈칸 채우기 · 표 채우기 · 계산 · 서술).
Q1객관식 · 복수선택

다음 중 AVL 트리에 대한 설명으로 옳은 것을 모두 고르시오.

  1. 모든 노드에서 균형 인수 |BF| ≤ 1을 만족한다.
  2. AVL 트리는 이진 탐색 트리(BST)가 아니어도 된다.
  3. 최악의 경우에도 탐색 시간이 O(n)까지 늘어난다.
  4. 역사상 최초로 나온 자가 균형 이진 탐색 트리이다.
✎ 나의 답안
정답 / 풀이 보기

정답: 1, 4

2번 — AVL은 BST의 조건(왼쪽 < 루트 < 오른쪽)을 그대로 지키면서 균형 조건이 추가된 것이므로 반드시 BST입니다.

3번 — AVL은 높이가 항상 O(log n)으로 제한되어 최악에도 탐색이 O(log n)입니다. 최악 O(n)은 균형을 강제하지 않는 일반 BST의 약점입니다.

Q2빈칸 채우기

균형 인수(Balance Factor)의 정의를 완성하시오.

BF(v) = height(________ 서브트리) − height(________ 서브트리)

또한 AVL 조건을 만족하는 노드의 BF로 가능한 값을 모두 쓰시오.

✎ 나의 답안
정답 / 풀이 보기

정답: 왼쪽, 오른쪽 / 가능한 BF 값 = −1, 0, +1

BF(v) = height(왼쪽 서브트리) − height(오른쪽 서브트리). AVL 조건은 모든 노드 v에 대해 |BF(v)| ≤ 1이므로 BF는 −1, 0, +1 셋 중 하나입니다.

Q3계산

어떤 노드 v의 왼쪽 서브트리 높이가 2, 오른쪽 서브트리 높이가 3이다. (단, 잎 노드의 높이는 0, 빈 서브트리의 높이는 −1로 한다.)

(1) BF(v)를 구하시오.  (2) 이 노드는 AVL 조건을 만족하는가?

✎ 나의 답안
정답 / 풀이 보기

정답: BF(v) = −1, AVL 조건 만족

BF(v) = 2 − 3 = −1. |−1| ≤ 1 이므로 이 노드는 AVL 조건을 만족합니다.

Q4빈칸 채우기

높이가 h인 AVL 트리가 가질 수 있는 최소 노드 수를 Nh라 할 때, 점화식(Recurrence)을 완성하시오.

Nh = N____ + N____ + ____      (단, N₀ = 1, N₁ = 2)
✎ 나의 답안
정답 / 풀이 보기

정답: Nh = Nh−1 + Nh−2 + 1

전체 높이를 h로 만들려면 한쪽 서브트리는 높이 h−1이어야 하고, 다른 쪽은 노드를 최소로 줄이기 위해 AVL이 허용하는 한 가장 낮은 h−2까지 낮춥니다. 여기에 루트 1개를 더해 Nh−1 + Nh−2 + 1이 됩니다.

Q5계산

Q4의 점화식을 이용하여 N₂, N₃, N₄, N₅를 차례로 구하시오.

✎ 나의 답안
정답 / 풀이 보기

N₂ = N₁ + N₀ + 1 = 2 + 1 + 1 = 4

Q6객관식

비어 있는 일반 BST에 키를 1, 2, 3, …, n 순서(오름차순)로 삽입하였다. 이때 만들어지는 트리의 높이와 탐색의 최악 시간복잡도로 옳은 것은?

  1. 높이 O(log n), 탐색 O(log n)
  2. 높이 O(n), 탐색 O(n)
  3. 높이 O(1), 탐색 O(1)
  4. 높이 O(n), 탐색 O(log n)
✎ 나의 답안
정답 / 풀이 보기

정답: 2번

정렬된 순서로 넣으면 모든 노드가 오른쪽으로만 이어져 사실상 연결 리스트(Linked List)가 됩니다. 높이가 n−1 = O(n)이고, 탐색도 O(n)으로 떨어집니다. 바로 이 편향(skew) 때문에 AVL 같은 균형 트리가 필요합니다.

Q7계산 · 트리 판별

다음 트리가 AVL 트리인지 판별하고, 아니라면 위반이 일어난 노드와 그 BF 값을 쓰시오. (잎 높이 0, 빈 서브트리 −1)

10 / \ 5 15 / 3 / 1
✎ 나의 답안
정답 / 풀이 보기

정답: AVL 아님 — 노드 5에서 BF = +2

각 노드 높이: 1→0, 3→1, 5→2, 15→0, 10→3.

BF(5) = height(왼쪽=3, 높이1) − height(오른쪽=없음, −1) = 1 − (−1) = 2 → |2| > 1 이므로 AVL 조건 위반. (참고로 BF(10) = 2 − 0 = 2 도 위반입니다.)

탐색·삽입·삭제 연산에 대해 일반 BST와 AVL 트리의 시간복잡도를 빈칸에 채우시오. (n은 노드 개수)

자료구조평균최악
일반 BST??
AVL 트리??
✎ 나의 답안
정답 / 풀이 보기
자료구조평균최악
일반 BSTO(log n)O(n)
AVL 트리O(log n)O(log n)

모든 연산은 트리 높이 h에 비례(O(h))합니다. 일반 BST는 편향되면 h = O(n)이지만, AVL은 균형 조건으로 h = O(log n)이 보장되어 최악도 O(log n)입니다.

Q9서술

높이 h와 노드 개수 n의 관계를 분석할 때, 왜 "높이가 h인 AVL 트리의 최소 노드 수 Nh"를 따지는가? 그 이유를 한 문장으로 쓰시오.

✎ 나의 답안
정답 / 풀이 보기

정답 요지

노드는 가장 적은데 높이는 가장 높은 최악의 경우를 분석해야, 높이의 상한(즉 빅오)을 구할 수 있기 때문입니다. "같은 높이에서 노드가 최소" = "같은 노드 수에서 높이가 최대"라서 이 경우만 막으면 모든 경우가 O(log n)으로 보장됩니다.

Q10서술 · 증명

점화식 Nh = Nh−1 + Nh−2 + 1 에서 출발하여 Nh > 2·Nh−2 를 유도하는 핵심 아이디어를 설명하시오.

✎ 나의 답안
정답 / 풀이 보기

정답 요지

높이가 클수록 최소 노드 수도 크므로 Nh−2 < Nh−1 입니다. 점화식의 Nh−1을 더 작은 Nh−2로 바꿔치기하면 부등식이 성립합니다:

Nh = Nh−1 + Nh−2 + 1 ≥ Nh−2 + Nh−2 + 1 = 2·Nh−2 + 1 > 2·Nh−2.

Q11계산 · 증명 적용

Nh > 2·Nh−2 를 반복 적용하면 Nh ≥ 2h/2 가 유도된다. 이를 이용해, AVL 트리에서 노드 수 n과 높이 h 사이에 성립하는 부등식을 쓰고, 이로부터 h의 상한을 log를 이용해 나타내시오.

✎ 나의 답안
정답 / 풀이 보기

정답: n ≥ 2h/2 ⟹ h ≤ 2·log₂ n

실제 노드 수 n은 최소 노드 수보다 크거나 같으므로 n ≥ Nh ≥ 2h/2. 양변에 log₂(증가함수)를 씌우면 log₂ n ≥ h/2, 따라서 h ≤ 2·log₂ n = O(log n).

Q12계산

증명 결과 h ≤ 2·log₂ n 을 이용한다. 노드가 n = 1,048,576 (= 220)개인 AVL 트리의 높이 상한은 얼마인가?

✎ 나의 답안
정답 / 풀이 보기

정답: h ≤ 40

h ≤ 2·log₂(220) = 2 × 20 = 40. (이 한계는 다소 느슨한 상한이며, 실제 AVL 높이는 보통 이보다 낮습니다.)

Q14객관식 · 복수선택

다음 시간복잡도를 빠른(성능이 좋은) 것부터 느린 순서로 보았을 때, O(n)보다 빠른(더 좋은) 것을 모두 고르시오.

  1. O(n log n)
  2. O(log n)
  3. O(1)
  4. O(n²)
✎ 나의 답안

증가율 순서: O(1) < O(log n) < O(n) < O(n log n) < O(n²). O(n)보다 빠른(작은) 것은 O(log n)과 O(1)입니다.

Q20서술 · 핵심 정리

"AVL 트리의 모든 연산이 O(log n)이다"가 성립하는 논리 흐름을, 아래 4개의 키워드를 순서대로 사용해 한 줄로 설명하시오.

균형 조건(|BF|≤1) → 점화식 → Nh ≥ 2h/2 → h = O(log n)

✎ 나의 답안
정답 / 풀이 보기

정답 요지

모든 노드에 균형 조건 |BF| ≤ 1을 강제하면 최소 노드 수가 점화식 Nh = Nh−1 + Nh−2 + 1을 따르고, 이로부터 Nh ≥ 2h/2 가 유도되어 n ≥ 2h/2 ⟹ h ≤ 2·log₂ n = O(log n)이 된다. 모든 연산은 O(h)이므로 결국 모두 O(log n)으로 보장된다.
