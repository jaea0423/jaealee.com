학습 목표

  • 신경망 응용(Modeling)이 무엇인지 이해하고, 기호주의와 연결주의 접근의 차이를 안다.
  • 딥뉴럴 네트워크(Deep Neural Network, DNN)의 정의와 기울기 소실(Vanishing Gradient) 문제를 안다.

  • 2024년 노벨상 수상자(힌튼·호필드·하사비스)의 기여를 안다.

1차시신경망 응용 — 모델링과 일반화

신경망 응용 = "관계를 찾는 모델링". 학습된 신경망은 학습하지 않은 입력도 일반화로 처리한다.

신경망 응용이란

정의 — 모델링 (Modeling) 입력에서 출력으로의 관계를 찾는 일. 함수를 정의하는 작업으로 볼 수 있다. 강의의 비유 — "함수 = 공장(Factory)" : 재료(입력)를 넣으면 결과(출력)를 만들어 던져준다.

두 가지 접근법:

접근법특징예시
기호주의(Symbolism)명시적 규칙으로 관계 표현전문가 시스템, IF-THEN 규칙
연결주의(Connectionism)신경망이 데이터로부터 관계 학습딥러닝, GPT

모든 관계를 명시적 규칙으로 쓸 수 있는 것은 아닙니다. 예: 이미지에서 고양이를 인식하는 규칙을 IF-THEN으로 쓰기 어렵다. 신경망은 이런 관계를 학습으로 찾아낸다.

블랙박스(Black Box) 문제

신경망은 관계를 잘 찾지만 설명을 잘 못한다. 4주차에서 배운 전문가 시스템의 설명 기능과 대조적. 강의 비유: "휴대폰을 쓰면서도 내부가 어떻게 작동하는지 모르듯, GPT도 블랙박스지만 잘 작동한다".

"인공지능이 그러라고 했기 때문에 — 이건 위험한 생각. 오히려 인공지능 결과를 더 의심해야 한다." — 강태원 교수

일반화 능력(Generalization)

일반화 (Generalization) 학습되지 않은 새로운 입력에 대해서도 신경망이 적절한 출력을 내는 능력. 좋은 학습 = 좋은 일반화.

예: 손글씨 숫자(MNIST 비슷) 학습 후, 학습한 적 없는 사람의 글씨도 인식. 단, 학습 데이터에 오류가 있으면 그 오류를 학습해 일반화 성능이 떨어진다.

6주차와의 연결 6주차의 과적합(Overfitting) = 일반화 실패. 일반화 잘 되는 모델이 좋은 모델이며, 정규화·드롭아웃 등이 일반화를 돕는다.

2차시깊은 관계 — 딥러닝과 CNN/RNN

중간층이 4개 이상인 신경망 = 딥뉴럴 네트워크(DNN). 깊으면 학습이 어려워지는 기울기 소실 문제를 ReLU·드롭아웃 등으로 해결한 것이 딥러닝.

딥뉴럴 네트워크(DNN)와 딥러닝

정의 딥뉴럴 네트워크(Deep Neural Network, DNN) = 중간층(은닉층)이 4개 이상인 깊은 신경망. "심층 신경망"이라고도 함.

딥러닝(Deep Learning) = DNN을 효과적으로 학습시키기 위한 기술과 기법들의 총칭.

기울기 소실 (Vanishing Gradient) 문제

기울기 소실 역전파(Backpropagation)에서 출력층의 오차가 입력층 방향으로 거꾸로 전파될 때, 층이 깊을수록 기울기가 0에 가까워져 가중치 수정이 거의 일어나지 않는 현상.

강의 비유: 거리에서 멀리 떨어진 사람에게 "파인애플과 사과 중 뭐?"라고 외치면, 뒤에 있는 사람은 무슨 말인지 안 들리듯, 깊은 층의 가중치는 학습되지 않는다.

주된 원인은 시그모이드(Sigmoid) 활성함수. 시그모이드는 큰 입력값에서 기울기가 매우 작아진다(포화).

해결책 1 — ReLU 활성함수

ReLU (Rectified Linear Unit) f(x) = max(0, x). 0 이하는 0, 양수는 그대로. 양수 영역에서 기울기가 1로 일정해 기울기 소실 문제를 크게 완화한다. 딥러닝 시대의 표준 활성함수.

해결책 2 — 드롭아웃 (Dropout)

드롭아웃 (Dropout) — 힌튼 제안 학습 중 뉴런들을 무작위로 비활성화(0으로 만들기)하는 정규화 기법. 신경망이 특정 경로에만 의존하지 않고 더 견고하게 학습하게 만들어 과적합을 방지한다.
시험 포인트 · 빈출 딥러닝 핵심 기술 — ReLU(기울기 소실 해결) + 드롭아웃(과적합 방지). 둘 다 힌튼과 그 제자들의 기여.

합성곱 신경망 (CNN, Convolutional Neural Network)

CNN 영상(이미지) 처리에 특화된 신경망 구조. 1989년에 등장(Yann LeCun). 알파고에도 사용됨.

핵심 연산:

  • 합성곱 (Convolution): 작은 필터(Filter, Kernel, Mask)를 이미지 위에 슬라이딩하면서 특징 추출
  • 특징지도 (Feature Map): 합성곱 결과로 나온 2D 배열
  • 풀링 (Pooling): 특징지도 크기 줄이기 (Max Pooling, Average Pooling)
  • 마지막에 완전 연결층(Fully Connected Layer)으로 분류

계층적 특징 추출: 저수준(선·곡선) → 중간수준(부분 모양) → 고수준(객체 전체). 이는 사람 시각 시스템의 작동 원리와 닮았다.

[강의 시청 권장] CNN 합성곱 연산 시각화 — 필터 슬라이딩으로 특징지도 생성 7주차 2차시 강의 영상 — CNN 동작 시각화 부분 출처: 7주차 강의 슬라이드

순환 신경망 (RNN, Recurrent Neural Network)

RNN 출력을 다시 자기 입력으로 되먹임(Feedback)하는 신경망. 시계열(Time Series)·언어 같은 순서가 있는 데이터 처리에 적합.
구조특징
피드포워드(Feed-Forward)한 방향으로만 정보 흐름. 일반 신경망
순환(Recurrent)출력이 다시 입력으로 되먹임

LSTM (Long Short-Term Memory): RNN의 변형. 장기 의존성(Long-term Dependency) 학습 능력 개선. 현대 언어 모델의 토대.

호필드 네트워크(Hopfield Network)

존 호필드(John Hopfield)가 1982년 제안한 순환 신경망. 연관 기억(Associative Memory)을 모델링. 2024년 노벨 물리학상 수상의 근거 중 하나.

자료구조와의 연결 CNN의 합성곱은 2차원 행렬 슬라이싱, RNN의 순환은 그래프의 사이클(Cycle)에 해당. 자료구조의 행렬·그래프·재귀가 모두 사용됨.

생성 AI (Generative AI)

GPT (Generative Pre-trained Transformer) OpenAI가 만든 대규모 언어 모델. 트랜스포머(Transformer) 구조와 어텐션(Attention) 메커니즘을 사용. 다음 단어를 순차 생성.

주요 개념:

  • 트랜스포머(Transformer) — 2017년 Google 제안. 어텐션 기반 신경망 구조
  • 어텐션(Attention) — 입력의 어떤 부분이 중요한지에 "집중"하는 메커니즘
  • GAN(Generative Adversarial Network, 생성적 적대 신경망) — 생성자(Generator)와 판별자(Discriminator)가 경쟁하며 학습. 이미지 생성에 강력

예시 프로젝트 — 동화책 자동 생성

강의에서 소개된 학생 프로젝트:

  1. 이미지 입력
  2. CNN으로 이미지 특징 추출
  3. GPT로 동화 문장 생성
  4. TTS(Text-to-Speech)로 음성 변환
  5. 아이에게 자동 동화책 읽어주기

생성 AI의 윤리적 우려

딥페이크(Deepfake), 저작권 분쟁, 신원 위조, 가짜 뉴스, 일자리 대체 등. 일본에서는 AI가 쓴 장편 소설이 등장해 일부 문학상이 폐지되기도.

7주차 핵심 정리 (12가지)

  1. 신경망 응용 = 모델링(관계 찾기). 함수 = 공장 비유.
  2. 기호주의(명시적 규칙) vs 연결주의(데이터 학습). 신경망은 연결주의.
  3. 신경망의 블랙박스 문제: 잘 작동하지만 설명을 못함.
  4. 일반화(Generalization): 학습되지 않은 데이터도 잘 처리.
  5. DNN: 중간층이 4개 이상인 깊은 신경망. 딥러닝은 DNN을 학습시키는 기술.
  6. 기울기 소실(Vanishing Gradient): 깊은 층의 가중치가 학습되지 않는 문제.
  7. 해결책 ① ReLU(max(0,x)): 시그모이드 대신 사용해 기울기 소실 완화.
  8. 해결책 ② 드롭아웃(Dropout): 무작위로 뉴런 비활성화. 과적합 방지. 힌튼 제안.
  9. CNN(합성곱 신경망): 이미지 처리. 필터·합성곱·풀링·완전연결.
  10. RNN(순환 신경망): 출력을 입력으로 되먹임. 시계열·언어. LSTM이 발전형.
  11. 생성 AI: GPT(트랜스포머·어텐션), GAN. 이미지 캡셔닝(CNN+RNN), 스타일 전송 등.
  12. 2024년 노벨상: 힌튼·호필드(물리학상), 하사비스(화학상, 알파폴드).
