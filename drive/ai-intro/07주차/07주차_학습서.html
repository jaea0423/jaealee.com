핵심 1신경망 응용 (Modeling)

신경망 응용 = "관계를 찾는 모델링". 함수 = 공장.
접근법특징
기호주의(Symbolism)명시적 규칙으로 관계 표현
연결주의(Connectionism)신경망이 데이터로부터 관계 학습

일반화(Generalization): 학습되지 않은 새 입력도 적절히 처리하는 능력.
블랙박스: 신경망은 잘 작동하지만 결정 이유 설명이 어렵다.

핵심 2딥뉴럴 네트워크(DNN)와 딥러닝

정의 DNN (Deep Neural Network): 중간층이 4개 이상인 깊은 신경망. = 심층 신경망.
딥러닝(Deep Learning): DNN을 효과적으로 학습시키는 기술 총칭.

핵심 3기울기 소실 (Vanishing Gradient)

역전파에서 층이 깊을수록 기울기가 0에 가까워져 가중치 수정이 안 되는 문제.

주된 원인: 시그모이드(Sigmoid) 활성함수의 포화. 큰 입력에서 기울기가 매우 작아진다.

★ 빈출 ★ 딥러닝 등장 전 신경망의 핵심 한계 = 기울기 소실. 6주차 역전파의 한계점.

핵심 4ReLU와 드롭아웃 (Dropout)

기술역할
ReLU (Rectified Linear Unit) f(x) = max(0, x). 양수 영역 기울기 1로 일정 → 기울기 소실 완화. 딥러닝 시대 표준 활성함수
드롭아웃 (Dropout) 학습 중 뉴런을 무작위로 비활성화 → 과적합 방지. 힌튼 제안
시험 포인트 딥러닝 핵심 기술 두 가지: ReLU + 드롭아웃. 둘 다 힌튼과 그 제자들의 기여.

핵심 5CNN — 합성곱 신경망

이미지 처리에 특화. 1989년 Yann LeCun. 알파고에도 사용.
CNN의 핵심 연산 ① 합성곱 (Convolution) — 필터(Kernel)로 이미지 슬라이딩하며 특징 추출
② 특징지도 (Feature Map) — 합성곱 결과 2D 배열
③ 풀링 (Pooling) — 특징지도 크기 줄이기 (Max/Average)
④ 완전 연결층 (Fully Connected Layer) — 마지막에 분류 수행

계층적 특징 추출: 저수준(선/곡선) → 중간(부분) → 고수준(객체). 사람 시각 시스템 모방.

시험 포인트 · 빈출 CNN의 4단계: 합성곱(필터) → 풀링 → 합성곱 → 풀링 → ... → 완전연결층. 영상 처리(이미지 분류·객체 검출·자율주행 등)의 표준.

핵심 6RNN과 LSTM

출력을 입력으로 되먹임(Feedback). 시계열·언어 데이터에 적합.
구분구조용도
피드포워드(Feed-Forward)한 방향일반 분류
RNN(Recurrent)되먹임 있음시계열·문장 등 순서 데이터
LSTMRNN 변형. 장기 의존성 학습장문 처리, 언어 모델
호필드 네트워크1982 Hopfield. 연관 기억2024 노벨 물리학상 근거

핵심 7생성 AI (Generative AI)

모델/기술설명
GPTGenerative Pre-trained Transformer. OpenAI. 트랜스포머·어텐션 기반
트랜스포머Transformer. 2017 Google. 어텐션 메커니즘 기반
어텐션Attention. 입력의 어떤 부분에 "집중"할지 결정
GANGenerative Adversarial Network. 생성자 vs 판별자 경쟁 학습. 이미지 생성에 강력
이미지 캡셔닝CNN(이미지 이해) + RNN(문장 생성). 자율 동화책 생성 등
스타일 전송Style Transfer. 사진을 반 고흐 스타일 등으로 변환
