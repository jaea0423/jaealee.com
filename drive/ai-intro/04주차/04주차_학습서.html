핵심 1데이터·정보·지식의 차이

데이터(재료) → 정보(가공) → 지식(체계적 조직) → 이론 → 원리.
수준영어의미
데이터Data재료. 단순한 사실
정보Information가공된 데이터. 다시 입력으로 쓰이면 데이터 역할
지식Knowledge체계적으로 잘 조직된 정보 덩어리로서 알고 있는 것
이론Theory여러 지식이 모인 것 (상대성 이론 등)
원리Principle이론보다 더 일반적·상위 개념 (불확정성 원리 등)
시험 포인트 지식 = "체계적으로 잘 조직된 정보의 덩어리로서 우리가 알고 있는 것".

핵심 2지식 표현 (Knowledge Representation)

지식을 컴퓨터가 처리할 수 있는 형태로 나타내는 것. 두 대표 방법: 의미망 / 규칙.
방법형태예시
의미망 (Semantic Net) 그래프 (노드=개념, 간선=관계 ISA/HAS 등) 바이올린 ─ISA→ 현악기 ─ISA→ 악기
규칙 (Rule) IF-THEN 형태 IF 호흡곤란 AND 발열 AND 기침 THEN COVID

그 외에도 프레임(Frame), 스크립트(Script) 등이 있음. 1980~90년대 초반 활발히 연구됨.

자료구조 / 이산수학과의 연결 의미망 = 그래프(자료구조). 규칙 = 명제 논리(이산수학)의 함의(P→Q).

핵심 3지식 병목과 전문가 시스템 등장

사람 지식의 양이 너무 방대 → 전체는 못 다루니 특정 분야만 잘 다루는 시스템 = 전문가 시스템.
지식 병목 (Knowledge Bottleneck) 인공지능이 처리해야 할 사람의 지식 양이 너무 많아 한꺼번에 처리할 수 없는 한계. 마치 병의 좁은 목으로 물이 잘 흘러나가지 못하는 것에 비유.

해결책: 전체 지식이 아니라 특정 분야(전문가의 영역)만 잘 처리하는 시스템 — 이것이 전문가 시스템(Expert System)이다.

예상 출제 전문가 시스템은 ANI(약 인공지능)에 해당. 모든 분야를 다 잘하는 범용 전문가 시스템이 곧 AGI(일반 인공지능)이다.

핵심 4규칙 기반 전문가 시스템 5대 구성

전문가는 자기 지식을 규칙(Rule)으로 표현하는 데 능숙 → Rule-Based Expert System.
5대 구성 요소 ① 지식베이스(Knowledge Base) — IF-THEN 규칙 모음
② 데이터베이스(Database) — 사실(Facts), 환자 증상 같은 입력 데이터
③ 추론엔진(Inference Engine) — 사실 + 규칙으로 결론 도출
④ 사용자 인터페이스(User Interface) — 질의·응답 채널
⑤ 설명 기능(Explanation Facility) — 결론의 근거 설명

의사 진료 사례

환자 → "숨쉬기 어렵습니다" (DB에 호흡곤란 추가) → R57 매칭 → "발열?" → "38도 넘음" → DB에 발열 → "기침?" → 콜록콜록 → DB에 마른 기침 → R57 모든 조건 충족 → "COVID 의심" → 환자 "왜?" → 설명 기능이 추론 과정 설명.

두뇌 우성 판별 예시 (Brain Expert)

1주차의 허먼 두뇌우성 모델을 판별. 16개 규칙으로 구성. 행동 유형 → 성격 유형, 학습 유형 → 사고 유형, 그 둘 + 부분/전체 태도 → A·B·C·D 유형 판별.

★ 핵심 ★ 전문가 시스템 프레임 = 지식베이스만 바꿔 끼우면 다양한 분야 시스템을 만들 수 있다.

핵심 5설명 기능과 XAI

전문가 시스템의 큰 강점 = 설명 가능. 딥러닝의 약점이 그것.
구분설명 가능성이유
전문가 시스템 (규칙 기반)★★★★★논리적 추론 과정을 그대로 보여줄 수 있음
딥러닝★☆☆☆☆가중치들이 학습한 것이라 사람이 해석하기 어려움
XAI (Explainable AI, 설명 가능한 인공지능) 딥러닝의 설명 부재 문제를 해결하기 위한 연구 분야. AI가 왜 그런 결론을 내렸는지 사람이 이해할 수 있게 만드는 것.

핵심 6뉴런(Neuron) 구조

뇌 = 뉴런 100억~1000억 개의 네트워크. 한 뉴런 = 몸통 + 수상돌기 + 축색돌기 + 시냅스.
부위영어역할
몸통(핵)Soma / Nucleus세포체. AI에서는 별로 중요하지 않음
수상돌기Dendrite입력을 받는 부분 (수상=나무 모양)
축색돌기Axon출력을 내보내는 부분 (마디 있음)
시냅스Synapse한 뉴런의 축색돌기 끝 ↔ 다른 뉴런의 수상돌기 접합부. 끊어져 있다(틈 있음)
★ 빈출 ★ 뉴런 4부위 — 몸통 / 수상돌기(입력) / 축색돌기(출력) / 시냅스(접합부). "수상=Dendrite, 축색=Axon, 시냅스=Synapse" 영어 정확히 외우기.

핵심 7시냅스에서의 학습

전기→화학→전기로 변환되며 신호 강도가 조절됨. 이것이 학습.

시냅스에서 신호가 전달되는 과정:

  1. 축색돌기에서 전기 신호가 시냅스 끝까지 이동
  2. 시냅스가 끊어져 있어 → 신경전달물질(Neurotransmitter) 분비
  3. 건너편 수상돌기의 수용체(Receptor)가 화학물질을 받음
  4. 다시 전기 신호로 변환되어 다음 뉴런으로

수용체 수가 많아지면 → 더 많은 전기 신호 전달, 적으면 적게. 이 변화가 곧 학습이다.

★ 핵심 ★ "시냅스에서의 신호 강도 조절 = 학습". 이것이 딥러닝의 거의 전부이며 인공 신경망의 가중치(Weight)에 해당.
5~7주차(신경망/딥러닝) 예고 인공 신경망에서 뉴런 = 노드(Node), 시냅스 = 가중치(Weight). 가중치를 학습하는 것이 곧 딥러닝.
