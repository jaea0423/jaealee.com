학습 목표

  • 머신러닝(Machine Learning, ML)의 정의와 인공지능·신경망·딥러닝과의 포함 관계를 안다.
  • 지도학습(Supervised Learning)의 두 알고리즘 — 회귀(Regression)와 분류(Classification)의 차이를 안다.
  • 비지도학습(Unsupervised Learning)의 대표 알고리즘인 군집화(Clustering)와 k-Means를 이해한다.
  • 추천 시스템(Recommendation System)의 두 가지 관점과 협업 필터링(Collaborative Filtering)의 유사성 측정 원리를 안다.

1차시선생님, 고맙습니다 — 회귀와 분류

지도학습 = "정답을 알려주는 선생님이 있다". 회귀는 관계식 찾기, 분류는 어디 속하는지 가려내기.

머신러닝(Machine Learning)이란

머신러닝 정의 (Wikipedia) 인공지능의 한 분야로, 학습 능력이 있는 알고리즘 시스템을 만드는 연구 분야. 데이터로부터 명시적 명령 없이 무언가를 배우고, 그것을 일반화(Generalization)하여 새 상황에서도 결론을 낼 수 있게 한다.

AI 포함 관계

가장 큰 범위부터: 인공지능(AI) ⊃ 머신러닝(ML) ⊃ 신경망(NN) ⊃ 딥러닝(DL).

다만 오늘날 딥러닝이 너무 발전하여 일반인 사이에서는 "딥러닝 = 인공지능"으로 통용되기도 합니다. 강의는 두 갈래 도구를 정리합니다:

접근법대표 도구
연결주의(Connectionism)TensorFlow, Keras — 딥러닝 중심
기호주의(Symbolism)Scikit-learn — 분류·회귀·군집화·KNN 등 머신러닝 알고리즘 집대성

머신러닝 vs 데이터 마이닝

두 분야는 방법이 많이 겹치지만 초점이 다릅니다.

  • 머신러닝: 예측(Prediction)에 초점. 학문/과학적 방법.
  • 데이터 마이닝(Data Mining): 이전에 모르던 새 사실(Unknown Property)을 알아내는 데 초점. "쓸모없는 광석을 금으로 만드는 행위" (9주차 비유).

회귀 (Regression)

회귀 — 한 줄 정의 "관계식을 알아내는 것". 입력과 출력 사이의 함수 관계를 찾는 것.

예: 공부 시간(T)과 학점(G) 사이의 관계 → G = f(T). 선형회귀(Linear Regression)는 Y = mx + b 형태로 기울기(m)와 절편(b)을 구함.

전통적 방법신경망 방법
최소자승법(Least Squares)
미적분으로 m, b를 직접 계산		 데이터만 주고 오류역전파(Backpropagation)로 가중치 학습 → 자동으로 관계식 학습
사례 "키 175cm 소개팅 상대 몸무게 예측" — 키와 몸무게 사이 회귀선으로 추정. 다만 상관관계 ≠ 인과관계(9주차)임에 주의.

분류 (Classification)

분류 — 한 줄 정의 "어디에 속하는지 가려내는 것". 데이터가 어느 클래스(Class)에 속하는지 결정.

예: "너 몇 반이야?" / 스팸 메일 필터(스팸 vs 햄(Ham) — 정상 메일을 부르는 ML 용어).

베이즈 정리 기반 스팸 필터

P(스팸|단어) = P(단어|스팸) × P(스팸) / P(단어)

8주차의 베이즈 정리가 그대로 적용됩니다. 단어가 들어있을 때 스팸일 확률을 계산.

이미지 분류는 과거에는 어려웠으나 CNN(합성곱 신경망)(7주차) 등장으로 가능해짐.

★ 면접 단골 질문 ★ "분류와 군집화의 차이를 설명하시오" — 입사 면접 단골. 분류는 정답이 있는 지도학습, 군집화는 정답이 없는 비지도학습.

레이블링(Labeling)

군집화 후 만들어진 덩어리에 이름을 붙이는 작업. 교수님 강조: "라벨링이 아니라 레이블링" — 영어 발음 정확히 쓰자.

2차시선생님 어디 계세요? — 군집화 (비지도학습)

정답을 알려주는 선생님이 없다. 비슷한 것끼리 덩어리를 묶는 게 군집화. 대표 알고리즘은 k-Means.

군집화 (Clustering)

군집화 — 한 줄 정의 "덩어리를 묶어내는 것". 같은 성질을 갖는 것들을 한 묶음(Cluster)으로 모음. 정답이 없으므로 비지도학습.

인간의 가장 기본적인 인지 작용입니다. 갓 태어난 아기도 "얼음"이라는 단어는 몰라도 흰색 덩어리들을 한 묶음으로 인식할 수 있는 능력 — 이것이 군집화. 분류보다 더 낮은 수준의 인식.

k-Means 알고리즘

k-Means K개의 덩어리가 있다고 가정하고 그 개수만큼 묶어내는 알고리즘. k = 덩어리 개수, means = 평균.

작동 순서:

  1. K개의 중심(Centroid)을 임의로 배치
  2. 각 데이터에서 K개 중심까지 거리 측정 → 가까운 쪽으로 소속
  3. 각 그룹의 무게중심(평균)으로 중심점 이동
  4. 변동이 없을 때까지 2~3 반복
k-Means의 한계 K값(덩어리 개수)을 사람이 미리 정해야 한다. 어떤 K가 적절한지 알기 어렵다.

계층적 알고리즘(Hierarchical)

처음에 데이터 개수(N개)만큼 각자 한 덩어리로 시작 → 가까운 것끼리 묶어가며 K를 줄여나감.

K=N → K=4 → K=3 → K=2 → K=1(전체 하나). 거리는 물리적 거리일 수도 있고, 색깔 같은 유사성일 수도 있음.

MDS — Multi-Dimensional Scaling

색깔 선호도 같은 다차원 데이터를 2D/3D로 시각화하는 머신러닝 기법(9주차에서도 언급).

자료구조와의 연결 k-Means는 거리 계산이 핵심. 자료구조의 유클리드 거리(Euclidean Distance) 계산과 동일. 또한 무게중심 이동은 반복문(iteration) 기반 알고리즘.

3차시이 영화 보세요! — 추천 시스템과 협업 필터링

넷플릭스·아마존의 성공 비결. 추천의 핵심은 유사성(Similarity) 측정이며, 협업 필터링이 대표 알고리즘.

추천 시스템 (Recommendation System)

두 가지 관점:

  • 사용자 기반(User-based): "너랑 취향이 비슷한 사람이 본 영화 → 너도 봐라"
  • 아이템 기반(Item-based): "이 책을 산 사람이 이 영화도 보더라"

활용 데이터:

  1. 상품 자체의 정적 데이터: 스펙·장르·감독 등 (전통적)
  2. 고객의 동적 데이터: 구매 행위·별점·사이트 활동 (오늘날 핵심)

협업 필터링 (Collaborative Filtering)

협업 필터링 추천 시스템의 가장 대표적 알고리즘. 사용자들의 평가를 모아서 비슷한 취향의 사람을 찾고, 그들이 좋아한 것을 추천. 유사성(Similarity) 측정이 시작이자 끝.

유사성 측정 방법

방법설명
유클리드 거리(Euclidean Distance)두 점 사이의 직선 거리. d = √(Σ(p−q)²)
상관계수(Correlation Coefficient, R)절대값보다 경향성이 중요할 때 사용
코사인 거리(Cosine Distance)벡터 사이 각도
맨해튼 거리(Manhattan Distance)축에 평행하게 측정한 거리

추천 점수 계산식

추천 점수 = Σ(유사성 × 평점) / Σ유사성
= Σ(Sᵢ · Mᵢ) / Σ Sᵢ

유사성과 평점을 모두 반영. 단순 유사성 1등만 보지 않고, 가까운 다른 사람들의 평점까지 비율적으로 반영합니다.

★ 시험 핵심 ★ 추천 시스템에서 유사성 측정이 시작이자 끝. 유클리드 거리는 절대값이 중요할 때, 상관계수는 경향성(패턴)이 중요할 때 사용.

집단지능 (Collective Intelligence)

불특정 다수의 행동·평가를 모으면 집단 지혜가 나타남. 9주차에서 다룬 페이지랭크와 같은 맥락. "딥러닝 이후의 핵심"으로 강의는 강조.

"이 교양 수업 듣는 학생 중에 노벨상 받는 학생이 나올 수도 있다. 데이터로부터 어떤 생각을 해내느냐가 경쟁력이다." — 강태원 교수
8·9주차와의 연결 8주차 베이즈 정리 → 스팸 필터에 그대로 적용. 9주차 페이지랭크/집단지능 → 추천 시스템에 그대로 적용. 모든 머신러닝의 토대.

10주차 핵심 정리 (10가지)

  1. 머신러닝(ML) = 데이터에서 학습하여 일반화하는 알고리즘 시스템.
  2. 포함 관계: AI ⊃ ML ⊃ NN ⊃ DL.
  3. 도구: 연결주의 = TensorFlow/Keras / 기호주의 = Scikit-learn.
  4. 지도학습 두 알고리즘: 회귀(관계식 찾기) + 분류(어디에 속하는지).
  5. 선형회귀 Y = mx + b. 전통은 최소자승법, 신경망은 역전파.
  6. 스팸 필터 = 베이즈 정리 응용. P(스팸|단어) 계산. 정상 메일은 햄(Ham).
  7. 비지도학습 = 군집화(Clustering). "덩어리 묶기".
  8. k-Means: K개 중심 → 가까운 데이터 모음 → 무게중심 이동 → 반복. K값 결정이 한계.
  9. 추천 시스템 = 사용자 기반 + 아이템 기반. 협업 필터링이 대표.
  10. 유사성 측정 = 시작이자 끝. 유클리드 거리, 상관계수 등. 추천 점수 = Σ(유사성×평점) / Σ유사성.
