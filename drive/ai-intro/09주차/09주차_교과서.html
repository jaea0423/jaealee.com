1차시인터넷과 월드와이드웹

인터넷 = TCP/IP 기반 글로벌 네트워크 / 웹 = 인터넷 위에서 동작하는 정보공유 시스템.

인터넷(Internet)

인터넷 (Internet) TCP/IP 프로토콜로 전 세계 컴퓨터 네트워크를 연결한 국제 네트워크 시스템. 고유명사로 대문자 'I' 표기.

TCP/IP(Transmission Control Protocol / Internet Protocol)는 인터넷의 표준 통신 규약. 프로토콜(Protocol)은 데이터 전송을 위한 약속·규칙.

월드와이드웹 (World Wide Web, WWW)

웹 (Web) 인터넷에 연결된 컴퓨터들이 하이퍼텍스트(Hypertext)를 공유할 수 있는 정보공유 시스템. HTTP/HTTPS 프로토콜로 동작.
구분인터넷웹
본질네트워크 인프라그 위의 정보 공유 시스템
프로토콜TCP/IPHTTP/HTTPS
등장1969 ARPANET1989 팀 버너스리(Tim Berners-Lee)
예이메일·FTP·웹 등 모두 포함웹페이지·웹앱
★ 빈출 ★ 인터넷 ≠ 웹. 인터넷이 더 큰 개념이며 웹은 인터넷 위에서 동작하는 한 서비스.

하이퍼텍스트와 HTML

하이퍼텍스트(Hypertext): 텍스트·이미지·음성·동영상이 하이퍼링크(Hyperlink)로 연결된 문서. HTML(Hypertext Markup Language)로 작성됨.

"조선시대 사람에게 하이퍼링크를 설명한다면? 호랑이 그림을 클릭하면 호랑이 사진이, 또 클릭하면 호랑이 울음소리가 나온다 — 깜짝 놀랄 것이다." — 강태원 교수의 비유

웹 브라우저와 검색엔진

  • 웹 브라우저(Web Browser): 웹페이지를 열람하는 소프트웨어. Chrome·Edge·Safari·Firefox 등.
  • 브라우징(Browsing): "소가 풀을 뜯어먹듯" 웹을 이리저리 탐색하는 행위.
  • 검색엔진(Search Engine): 사용자가 원하는 정보를 찾아주는 시스템. Google·Bing·Naver 등.

웹 크롤러와 인덱싱

크롤링 (Crawling) 웹 크롤러(Web Crawler)가 거미처럼 웹의 그물을 돌아다니며 문서를 자동 수집하는 과정. 크롤러는 봇(Bot)이라고도 부름.
인덱싱 (Indexing) 수집한 웹페이지에 번호를 매기고 어떤 단어가 어디 있는지 미리 기록하는 과정. 책 뒤의 "찾아보기"와 같은 원리. 검색 속도를 결정적으로 높여 준다.

예시 인덱스: 맥주 → [50, 10], [100, 5], [111, 11] = "맥주"는 50번 문서의 10번째 단어, 100번 문서의 5번째 단어, …

자료구조와의 연결 인덱싱은 자료구조의 해시 테이블(Hash Table)·역색인(Inverted Index)의 응용. 자료구조에서 배운 키-값 쌍이 단어→위치 매핑으로 그대로 적용됨.

2차시페이지 랭킹

검색 결과의 순위를 결정하는 알고리즘. 구글의 페이지랭크(PageRank)가 대표.

검색 결과의 순위 결정 요인

검색어와 매칭되는 페이지가 수만~수억 개일 때, 어떤 페이지를 위에 보일지 결정하는 알고리즘.

  1. 단어 개수(Frequency): 검색어가 페이지에 몇 번 나오는가
  2. 단어 거리(Distance): 여러 검색어가 페이지 안에서 가까이 있는가
  3. 단어 위치(Position): 페이지 앞쪽(제목·도입부)에 있을수록 중요
  4. 외부 링크(PageRank): 다른 신뢰할 만한 사이트가 이 페이지를 얼마나 많이 가리키는가

페이지랭크 (PageRank) 알고리즘

페이지랭크 (PageRank) 1996년 구글 창립자 래리 페이지(Larry Page)와 세르게이 브린(Sergey Brin)이 만든 알고리즘. 다른 페이지가 이 페이지를 링크하는 양과 질로 페이지의 "권위"를 측정. 구글의 성공 비결.

핵심 아이디어: "많은 신뢰할 만한 페이지가 가리키는 페이지일수록 중요하다". 학술 논문 인용 분석에서 영감.

"구글이 검색엔진에서 성공한 게 아니라 데이터 중심 사고로 성공했다." — 강태원 교수

컬렉티브 인텔리전스 (Collective Intelligence)

집단 지성 불특정 다수가 남긴 흔적(링크·검색·구매 기록)을 모으면 집단 지혜가 나타난다는 개념. 페이지랭크의 토대.

3차시빅데이터와 데이터 사이언스

단순히 큰 데이터가 아니라 3V를 만족하는 데이터. "모두 거짓말을 한다"의 통찰.

빅데이터(Big Data)란

빅데이터 기존의 데이터 처리 방법으로는 다룰 수 없을 만큼 크고·빠르고·다양한 데이터 집합. 단순히 "큰 데이터"가 아니다.

3V — 빅데이터의 3가지 특성

V의미설명
Volume용량TB(테라바이트) ~ PB(페타바이트) 규모. 저장하기 어려울 정도로 크다
Velocity속도실시간으로 처리할 수 없을 정도로 빠르게 쌓인다
Variety다양성텍스트·이미지·음성·영상·센서 데이터 등 형태가 다양

나중에 4V (Veracity, 진실성)나 5V (Value, 가치)를 추가하기도 함.

★ 시험 빈출 ★ 빅데이터 = 3V (Volume + Velocity + Variety). 단순히 크기만으로 빅데이터가 아니다.

데이터 사이언스 (Data Science)

데이터 사이언스 빅데이터로부터 과학적 방법으로 유용한 정보를 추출하는 학문 및 실천. 데이터 사이언티스트(Data Scientist)가 수행.

데이터 마이닝 vs 머신러닝

강의 비유 — 광산에서 금 캐기:

  • 머신러닝: 광산에 이미 묻힌 금을 캐내는 것. 데이터에 존재하는 패턴 발견.
  • 데이터 마이닝(Data Mining): 흙처럼 보이는 데이터에서 새로운 가치(금)를 만들어 내는 것. 더 높은 수준의 기술.
"데이터 마이닝은 단순히 데이터에서 패턴을 찾는 게 아니라 흙을 금으로 만드는 일이다. 다른 나라가 쓰레기인 줄 안 데이터에서 가치를 찾아내는 동안 이를 놓치면 그 부가가치를 구매해야 한다 — 국가 생존 경쟁이다." — 강태원 교수

"모두 거짓말을 한다" — Seth Stephens-Davidowitz의 통찰

2017년 책 "Everybody Lies"에서 빅데이터의 새로운 4가지 특성을 강조:

특성의미
① 새로운 유형과거에는 활용할 수 없던 형태의 데이터(검색·SNS·IoT 등)
② 솔직한 데이터익명성으로 인해 무의식적·솔직한 행동이 데이터에 남는다. SNS는 거짓이지만 검색은 솔직하다.
③ 작은 집단까지 분석과거에는 도·시 단위, 이제는 동·거리 단위까지 세밀 분석 가능
④ 인과관계 검증 가능실험적 데이터로 인과관계를 확인할 수 있는 기회가 늘어남
"모두 거짓말을 한다"의 핵심 페이스북에는 행복한 사진을 올리지만(거짓), 검색 키워드는 솔직하다(진짜 관심사가 드러남). 익명성이 솔직함을 만든다.

상관관계 vs 인과관계 (Correlation vs Causality)

정의 상관관계(Correlation): 두 변수가 함께 변하는 경향. 한쪽이 커지면 다른 쪽도 커지는 통계적 관계.
인과관계(Causality): 한쪽이 다른 쪽의 원인이 되는 관계. 단순한 통계적 동행 이상.

유명한 예: "주가와 출산율"의 우연적 상관관계를 인과관계로 해석하면 큰 오류. 상관이 있다고 해서 한쪽이 다른 쪽의 원인은 아니다.

★ 빈출 경고 ★ 상관관계 ≠ 인과관계. 이를 혼동하면 캐시 오닐(Cathy O'Neil)의 책 제목 그대로 "대량살상 수학무기(Weapons of Math Destruction)"가 된다. AI 윤리의 핵심 문제.

데이터 과학의 기법들

  • 워드 클라우드(Word Cloud): 단어 빈도를 시각화. 자주 쓰는 단어가 크게 표시.
  • 감성 분석(Sentiment Analysis): 텍스트의 감정(긍정·부정·분노·슬픔)을 수치화. 예: 해리포터 책의 페이지별 행복도 그래프.
  • Google NGram Viewer: 출판된 책에서 특정 단어가 시대별로 얼마나 쓰였는지 그래프. 예: "Tea → Coffee" 소비 패턴 변화 추적.
  • MDS(Multidimensional Scaling): 다차원 데이터를 2D/3D로 시각화.

예시 — Google NGram Viewer 사례

"United States" 옆에 are/is 중 어느 동사가 쓰였는지 시대별로 분석. 통념과 달리 "are → is" 변화는 남북전쟁 직후가 아니라 더 후대에 일어났다는 사실 발견.

[강의 시청 / 직접 사용 권장] Google NGram Viewer (https://books.google.com/ngrams) — 직접 단어 빈도 시각화 가능 9주차 3차시 출처: 9주차 강의 슬라이드

SaaS — Software as a Service

구글의 또 다른 혁신 — 소프트웨어를 패키지로 판매하는 게 아니라 서비스로 제공(SaaS, Software as a Service). Gmail·Docs·검색 모두 무료로 제공하면서 데이터로 수익화.

7주차 딥러닝과의 연결 인터넷·웹의 발전 → 빅데이터 축적 → 딥러닝의 학습 데이터 확보 → 2010년대 AI 폭발. 2주차에서 배운 AI 폭발의 두 동력(하드웨어 + 데이터) 중 데이터에 해당.
8주차 베이즈와의 연결 빅데이터로 베이즈 정리의 우도(Likelihood)가 더 정확해지고, 데이터 마이닝이 더 정밀해진다. 베이즈 + 빅데이터 = 현대 머신러닝의 기반.

9주차 핵심 정리 (12가지)

  1. 인터넷(TCP/IP 기반 네트워크) ≠ 웹(HTTP 기반 정보 공유 시스템). 인터넷이 더 큰 개념.
  2. 하이퍼텍스트·HTML·하이퍼링크가 웹의 핵심.
  3. 웹 크롤러(Web Crawler)가 웹을 돌아다니며 문서 수집.
  4. 인덱싱(Indexing) = 책의 "찾아보기"처럼 단어 위치 사전 기록. 검색 속도 결정.
  5. 페이지랭크(PageRank) — 래리 페이지·세르게이 브린(1996). 외부 링크로 페이지 권위 측정. 구글의 성공 비결.
  6. 빅데이터 = 3V: Volume(용량), Velocity(속도), Variety(다양성).
  7. 데이터 사이언스: 빅데이터에서 과학적 방법으로 가치 추출.
  8. 데이터 마이닝 ≠ 머신러닝: 마이닝은 흙을 금으로 만드는 것(가치 창출), 머신러닝은 묻힌 금 캐기(패턴 발견).
  9. "모두 거짓말을 한다" — 새로운 유형 / 솔직한 데이터 / 작은 집단 분석 / 인과관계 검증 4가지 특성.
  10. SNS는 거짓, 검색 키워드는 솔직하다. 익명성이 솔직함을 만든다.
  11. 상관관계 ≠ 인과관계. 혼동 시 "대량살상 수학무기"가 된다(AI 윤리).
  12. 데이터 과학 기법: 워드 클라우드, 감성 분석, NGram Viewer, MDS 등.

🎯 강의 끝 퀴즈 (시험 1순위)

강의 영상 마지막에 등장하는 빈칸 채우기 — 핑크 단어가 정답입니다.

1차시

모든 검색 엔진은 ( 인덱싱 )을 통해서 웹 페이지를 빠르게 검색할 수 있는 근거를 마련한다. 즉, 사람들이 검색하기 전에 이미 ( 인덱싱 )이라는 작업을 통해서 찾아보기를 만들어 놓는다.

2차시

WWW에 존재하는 웹 페이지들은 일반적인 문서와 다르다. 웹 페이지는 ( 하이퍼링크 )로 서로 연결되어 있다. 즉 연결에 의해 서로 관계를 맺고 있다. 구글은 이 정보를 활용해서 웹 페이지에 대한 사람들의 반응을 알아냈다.

3차시

빅데이터는 ( 솔직한 ) 데이터다. 모두가 볼 수 있는 페이스북 내용과 검색에 사용한 키워드가 일치하지 않는다. 사람들은 무심코, 때로는 자신도 알지 못하는, 자신의 은밀한 비밀을 익명의 공간에 던진다. 사람들의 자연스러운 일상은 모두 기록되고 우리는 그들이 원한다고 말하는 게 아니라 그들이 진실로 원하는 걸 알아낼 수 있다.
