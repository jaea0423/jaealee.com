1차시또 오 수정! — 학습 = 가중치 수정

신경망의 입출력 관계는 가중치(W)로 완전히 결정된다. 학습 = 가중치 수정.

학습이란 무엇인가

1주차에서 톰 미첼(Tom Mitchell)의 학습 정의를 배웠습니다 — 경험 E로 작업 T에서 성능 P가 개선되면 학습한 것. 신경망의 학습은 결국 "가중치(Weight)를 변화시키는 것"이며, 이는 4주차에서 배운 시냅스의 신호 강도 조절과 정확히 같은 의미입니다.

신경망 학습 (Neural Network Learning) 같은 입력에 대해 다른 출력을 내도록 가중치(Weight)가 변화하는 과정. 곧 시냅스의 강도 조정이며, "뇌가 달라지는 것"과 같다.

수도꼭지 비유

신경망의 가중치를 수도꼭지/밸브(valve)에 비유할 수 있습니다. 입력은 물줄기, 가중치는 흐름의 양을 조절하는 수도꼭지. 양수면 증폭, 음수면 역방향, 절대값이 클수록 강하게 작용. 학습은 곧 원하는 폭포 모양이 나오도록 수도꼭지들을 조절하는 일입니다.

"신경망은 배워서 남주는 착한 모델. 사람이 가중치를 일일이 정하는 게 아니라 신경망이 스스로 가중치를 조정한다." — 강태원 교수

매개변수(Parameter)의 규모

ChatGPT의 "1750억 매개변수"는 곧 1750억 개의 가중치를 의미합니다. 매개변수가 많을수록 더 복잡한 패턴을 학습할 수 있습니다.

★ 시험 핵심 ★ "신경망 학습 = 가중치(Weight) 수정". 가중치는 시냅스에 해당하며, 매개변수(Parameter)라고도 부른다.

2차시너 때문이닷! — 경사하강법과 역전파

오차의 기울기를 따라 가중치를 줄여 나가는 게 경사하강법. 중간층의 정답을 모르므로, 출력층 오차를 거꾸로 전파하는 역전파 알고리즘이 필요하다.

오차(Error)와 손실 함수(Loss Function)

정의 — 오차/손실 오차(Error) = 원하는 값(d, Desired) − 실제 출력(a, Actual). 보통 제곱하여 부호 상쇄를 막는다.
손실 함수(Loss Function) = 비용 함수(Cost Function) = 오차 함수(Error Function): 가중치들을 입력받아 오차를 출력하는 함수. 신경망 학습은 이 손실을 최소화하는 가중치를 찾는 일.
E = (d − a)²

경사하강법 (Gradient Descent)

오차 함수의 기울기(미분값)를 이용해 오차를 줄이는 방향으로 가중치를 수정하는 기법.

[강의 시청 권장] 오차 함수 곡선과 경사하강법 시각화 — 산을 내려가는 것에 비유 6주차 2차시 강의 영상 — 미분과 기울기 설명 부분 출처: 6주차 강의 슬라이드
가중치 수정 식 ΔW = −α · (∂E/∂W)
α: 학습률(Learning Rate), 작은 양수(예: 0.01)
∂E/∂W: 오차를 가중치로 미분한 기울기(Gradient)

해석: 기울기가 양수면 가중치를 감소시키고, 음수면 증가시킨다. 매 반복마다 학습률만큼 가중치를 조금씩 이동시켜 오차의 최솟값으로 향한다.

학습률(Learning Rate, α)

한 번에 "얼마나 배울 것인가"를 정하는 작은 양수. 너무 작으면 수렴이 느리고, 너무 크면 발산할 수 있음.

"겸손하게 조금씩 배워야 한다 — 학습률은 작아야 안정적이다." — 강태원 교수

경사하강법의 한계 — 중간층 문제

출력층 뉴런은 "원하는 출력 d"가 명시되어 있어 오차를 알 수 있다. 그런데 중간층(은닉층) 뉴런이 내보내야 할 "정답 출력"은 무엇인지 알 수 없다. 따라서 중간층의 가중치를 어떻게 업데이트할지 모르는 문제가 발생한다.

시험 포인트 — XOR 문제 1969년 민스키와 페퍼트(Minsky & Papert)가 XOR 문제(Exclusive OR)는 단층 신경망으로 해결할 수 없다고 지적했다. 이는 신경망 연구를 약 20년간 침체시켰고(연결주의 겨울), 1986년 역전파 알고리즘으로 극복되었다.

역전파 알고리즘 (Backpropagation, 1986)

정의 — 역전파 (Backpropagation) 출력층의 오차를 입력층 방향(거꾸로)으로 전파하면서 각 층의 가중치를 수정하는 학습 알고리즘. 1986년 Rumelhart 등이 제시. 딥러닝의 핵심 기술.

비유: "너 때문이닷!". 출력층 뉴런이 자기 오차를 만든 책임을 중간층에 거꾸로 추궁한다. 중간층은 자신이 받은 오차들을 모아 자신의 가중치를 수정한다.

역전파의 수학적 토대 — 연쇄 법칙(Chain Rule)

역전파는 미분의 연쇄 법칙(Chain Rule)을 사용해 출력층 오차의 기울기를 입력층 방향으로 차례차례 계산해 나갑니다. 강의의 비유는 "치타 → 사자 → 곰 → 사람"의 속도 비교 — 마지막 사람의 속도(=출력층의 오차)를 알면 그것을 거꾸로 전파해 나머지의 속도를 알 수 있다는 식.

이산수학·자료구조와의 연결 역전파는 방향성 비순환 그래프(DAG) 위에서 위상정렬의 역순으로 동적 계획법(Dynamic Programming)처럼 진행된다. 이산수학의 함수 합성·미분 연쇄 법칙이 본질이다.

XOR 문제 — 비선형 분리 불가능

XOR(Exclusive OR): 두 입력이 같으면 0, 다르면 1을 출력하는 논리 연산.

X₁X₂X₁ XOR X₂
000
011
101
110

이 분포는 하나의 직선으로는 분리할 수 없습니다(선형 분리 불가능, Non-linearly Separable). 따라서 단층 퍼셉트론(중간층 없음)으로는 학습 불가능 → 중간층이 필수.

3차시신경망과 놀아보자 — TensorFlow Playground

구글의 TensorFlow Playground로 중간층 수·뉴런 수·하이퍼파라미터를 바꿔 가며 학습을 시각적으로 체험.

하이퍼파라미터 (Hyperparameter)

하이퍼파라미터 가중치(매개변수)를 수정하기 위한 매개변수들. 사람이 직접 설정해야 하며 정답이 정해져 있지 않다.
하이퍼파라미터의미
학습률 (Learning Rate)한 번에 가중치를 얼마나 수정할지
중간층 수 (Number of Hidden Layers)은닉층 개수
각 층의 뉴런 수레이어 폭(width)
활성함수Sigmoid, Tanh, ReLU 중 선택
정규화 (Regularization)과적합 방지

과적합 vs 과소적합

현상설명원인
과소적합 (Underfitting) 학습 데이터에도 잘 맞지 않음 모델이 너무 단순(중간층/뉴런 부족)
과적합 (Overfitting) 학습 데이터엔 잘 맞지만 새 데이터엔 약함 모델이 너무 복잡 / 학습이 너무 길어짐

과적합 해결책: 정규화(Regularization), 적절한 신경망 구조 선택, 학습 조기 종료(Early Stopping).

활성함수의 진화 — Sigmoid → ReLU

  • 로지스틱 함수 / 시그모이드 (Sigmoid): 1/(1+e⁻ˣ)
  • 쌍곡탄젠트 (Tanh): 출력 범위 (-1, 1)
  • ReLU (Rectified Linear Unit): max(0, x). 딥러닝 시대의 주류

특성 엔지니어링 (Feature Engineering)

원본 입력 X₁, X₂에 sin(X₁), sin(X₂), X₁², X₂² 같은 함수값을 추가 입력으로 제공하면 학습이 쉬워질 수 있음. TensorFlow Playground에서 직접 토글 가능.

📍 강의 시청 / 실습 강력 권장 TensorFlow Playground (playground.tensorflow.org)는 브라우저에서 직접 실행할 수 있는 신경망 시뮬레이터. 강의 3차시 영상에서 교수님이 직접 시연하는 부분을 보고 따라해 보면 다층 신경망의 동작이 직관적으로 이해됩니다.
웹프로그래밍과의 연결 TensorFlow Playground는 HTML/CSS/JavaScript와 D3.js로 구현된 웹 페이지. 웹프로그래밍 수업의 SVG·Canvas·이벤트 처리 같은 기술이 결합되어 있다.

6주차 핵심 정리 (10가지)

  1. 신경망 학습 = 가중치(Weight) 수정. 가중치 = 시냅스 = 매개변수(Parameter).
  2. 오차(Error) = 원하는 값(d) − 실제 출력(a). 손실/비용/오차 함수가 모두 같은 의미.
  3. 경사하강법(Gradient Descent): ΔW = −α·(∂E/∂W). 기울기 반대 방향으로 가중치 이동.
  4. 학습률(Learning Rate, α): 작은 양수. 너무 작으면 느리고 너무 크면 발산.
  5. 경사하강법만으로는 중간층의 정답을 모르므로 다층 신경망 학습이 어려움.
  6. 1969 XOR 문제(Minsky & Papert): 단층 신경망의 한계 → 약 20년 침체기.
  7. 1986 역전파 알고리즘(Backpropagation): 출력층 오차를 입력층 방향으로 거꾸로 전파해 가중치 수정. 딥러닝의 핵심.
  8. 역전파는 연쇄 법칙(Chain Rule)으로 미분을 거꾸로 계산.
  9. 하이퍼파라미터: 학습률·중간층 수·뉴런 수·활성함수·정규화 등. 사람이 설정.
  10. 과적합(Overfitting) vs 과소적합(Underfitting). 정규화·구조 조정으로 해결.

🎯 강의 끝 퀴즈 (시험 1순위)

강의 영상 마지막에 등장하는 빈칸 채우기 — 핑크 단어가 정답입니다.

1차시

생물학적 뉴런의 시냅스는 두 뉴런 사이에 전송되는 정보의 양을 조절하는 역할을 한다. 따라서 뉴런 사이의 연결선을 생화학적 신호가 지나가는 통로라고 가정하면 시냅스는 통로 중간에 있는 ( 밸브 (혹은 수도꼭지) )로 생각할 수 있다.

2차시

사용자는 입력층으로 데이터를 보내면 출력층에서 나오는 결과에만 관심이 있지 중간층에서 일어나는 일들에는 관심이 없다. 또 그래야 마땅하다. 그래서 중간층을 은닉층이라 부르는 중간층 뉴런의 ( 목표 ) 출력이란 건 애초에 존재하지 않는 값이다. 따라서 중간층 뉴런이 출력해야 할 값, 즉 정답이란 건 애초부터 존재하지 않는 값이기 때문에 경사 강하를 이용해서 중간층 뉴런으로의 연결 가중치를 수정할 수 없다.

3차시

신경망에 관심이 있다면 텐서플로 플레이그라운드 (https://playground.tensorflow.org/)에 반드시 들어가서 놀아 볼 필요가 있다. 잘 노는 사람이 성공한다. 잘 놀 수 있도록 중요한 힌트를 주겠다. 푸른색은 ( 양수 ), 붉은색은 음수고, 색이 진하거나 선이 두꺼울수록 절댓값이 크다는 걸 알면 이해하는 데 크게 도움이 된다. 흰색에 가까울수록 0이다.
