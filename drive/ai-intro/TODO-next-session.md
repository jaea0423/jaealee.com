# 다음 세션 작업 목록

사용량 회복 후 "진행해" 신호 받으면 1번부터 순차 진행.

---

## 용어 통일
- **"강의 퀴즈"** = 각 차시 영상 마지막의 빈칸 채우기 문제 (시험 출제 1순위)
- **"강의 정리"** = 강의 퀴즈 직후 나오는 "이번 시간 학습한 내용을 정리해보겠습니다" 부분

---

## 1️⃣ 강의 퀴즈 — 페이지·HTML 반영

- **데이터**: `confirmed-quizzes.json` (42개 차시 전부 사용자 캡쳐로 확인 완료)
- **반영 대상**:
  - `quiz-collection.html` 전면 갱신 (현재는 빈 상태 + 1-3, 1-2만 들어있음)
  - 각 주차 학습서 + 교과서에도 "🎯 강의 퀴즈" 섹션 추가 (해당 주차 차시 1·2·3을 모아서)
  - `index.html`은 이미 quiz-collection 카드가 있으니 라벨/설명만 갱신
- **카드 색상**: 핑크(시험 1순위 강조)

## 2️⃣ 강의 정리 — 별도 페이지 + 학습서 반영

- **데이터 위치**: 각 주차 강의 스크립트 끝 "이번 시간 학습한 내용을 정리해보겠습니다" 직후 문장
- **현재 자료 반영 여부**: 부분적으로만 들어있는 것으로 추정 (확인 필요)
- **할 일**:
  - 각 차시별 "강의 정리" 텍스트를 스크립트에서 추출
  - 빠진 곳은 학습서·교과서에 보강
  - 별도 페이지 `lecture-summary.html` 생성 (강의 퀴즈와 동일 형식, 검색 용이)
  - `index.html`에 카드 추가

## 3️⃣ 강의 사진(슬라이드) 리스트 — 사용자 캡쳐 요청

- **방법**: 강의 스크립트에서 "이 그림", "여기 보시면", "이렇게 생긴" 같은 시각 의존 부분 추출
- **PDF 활용**: 각 주차 폴더의 강의 교안 PDF에서 슬라이드 직접 사용도 검토
- **파일명 규칙 (제안)**: `NN주차/img/NN-X-키워드.png` 형식
- **워크플로우**: Claude가 리스트 → 사용자가 캡쳐 → Claude가 받아서 저장 + 해당 학습서·교과서에 자동 삽입

## 4️⃣ PDF 강의 교안 링크 — index에서 바로 접근

- **현재**: 각 주차 폴더에 `모두의인공지능_N주차_제목.강태원.pdf` 있음
- **할 일**: 주차 카드의 "교과서·학습서·문제" 버튼 아래에 가로 3칸 길이의 "📑 강의 교안 (PDF)" 버튼 추가
- **기술**: `<a href="NN주차/파일명.pdf" target="_blank">` — 브라우저 내장 뷰어로 열림
- **주의**: 한글 파일명 URL 인코딩 자동 처리

## 5️⃣ 전체 검토 + 키워드 재점검 — 별도 신호 후 진행

- ⚠️ **이건 4번 끝나면 사용자에게 "진행할까요?" 다시 물어볼 것**
- 시간 오래 걸리는 작업
- 점검 대상:
  - 현재 271개 키워드 (1~14주차 전체) 누락·중복·부실 점검
  - 핵심 인물·개념·이론은 모두 들어가야 함 (예: 톰 미첼, 앨런 튜링, 튜링 테스트, 튜링 모두)
  - 무의미한 단어(조사·"무엇인가요" 등)는 추가 X
- 결과물: `keywords-data.js` 갱신 + 각 주차 `keywords.json` 동기화
