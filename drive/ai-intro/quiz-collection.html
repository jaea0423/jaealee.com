01주차

인공지능이 인문학

1차시
✅ 이 차시에는 강의 끝 빈칸 채우기 퀴즈가 없습니다
2차시

학문 분야로써 인공지능은 지능적인 시스템을 만드는 컴퓨터 과학의 한 분야인데, 시스템이 지능적이란 건 그게 지능적인 사람이나 할 수 있는 동작을 보인다는 것이고, 사람이 하는 지능적인 행동이란 건 ( 언어 ), ( 학습 ), ( 추론 ), ( 문제 해결 ) 등이다.

3차시

인공지능은 "아직은 사람이 더 잘하는 일을 컴퓨터 즉, 기계가 잘 할 수 있게 하려는 노력 혹은 그 결과"라고 정의할 수 있다. 그리고 그것이 사람보다 더 잘할 것을 모두가 우려하고 있다. 그래서 인공지능은 ( 인문학 )이다!

02주차

내 이상형은 기계

1차시

어떤 과학자가 "생각하는 기계"를 만들었다고 가정해 보자. 그 기계가 정말 생각이라는 걸 할 수 있다는 건 어떻게 판단할 수 있을까? 과학과 수학이 발달하면서 인간의 사고 과정을 기계적으로 대체할 수 있다는 희망의 시절에 튜링이라는 위대한 수학자가 "생각하는 기계"에 대해 논문을 발표한다. 여기에서 튜링은 기계가 생각하는지를 ( 판단하는 기준 )를 최초로 제안한다.

2차시

설은 사고실험을 통해서 영어만 할 수 있는 사람은 중국어를 모른다고 주장한다. ( 시스템 응답 ) 역시 그것에 동의하지만, 시스템 전체 즉 중국어 방은 중국어를 이해한다고 주장한다. 이는 사람의 언어 능력이 뇌에서 비롯되지만, 뇌 안의 뉴런이 언어를 이해하지 못하는 상황과 잘 비교된다. 사람의 뇌는 뉴런이라는 CPU 수백억 개의 네트워크 즉 신경망이다.

3차시

인공지능 연구 방향은 크게 ( 기호주의 )와 ( 연결주의 )로 구분할 수 있다. ( 연결주의 ) 학자들은 기호와 규칙에 관한 연구로 인공지능을 구현하려 시도했다. ( 연결주의 ) 학자들은 사람의 뇌 구조와 신경계를 구성하는 뉴런의 상호작용에 기초를 두고 경험으로부터 학습을 통해 인공지능을 구현할 수 있다고 보았다.

03주차

바둑, 다음 수는 어딜까!

1차시

초기 인공지능 연구자들은 문제 풀이를 ( 상태공간 ) 탐색이라는 개념으로 추상화하여 체계적으로 다룬다. 세상의 모든 문제는 문제를 해결해야 할 시점에 특정 상태에 있으며 해결되었을 때를 나타내는 상태가 있다. 문제를 푼다는 건 현재 상태를 해결되었을 때를 나타내는 상태로 바꾸는 방법이나 과정을 알아내는 것과 같다.

2차시

문제를 추상화하여 상태공간을 정의하면 상태공간 탐색 시스템은 초기 상태에 일련의 연산자를 적용해서 목적 상태에 도달하는 방법을 찾는다. 목적 상태에 도달하면 문제는 해결된 것이다. 시스템이 목적 상태에 도달하기 위해 일련의 연산자를 적용하는 과정을 그림으로 나타내면 나뭇가지가 뻗어 나가는 모양을 얻을 수 있다. 이것을 ( 탐색 트리 )라고 부른다.

3차시

바둑이나 장기처럼 교대로 자기 수를 두는 게임에서 생성되는 탐색 트리를 특히 ( 게임 ) 트리라 부른다. 이 트리는 보통 and-or 형태를 취한다. 자기 차례에서는 자기가 이길 수 있는 상태를 선택할 수 있으므로 or 형태의 가지로 표시하고, 상대 차례에서는 (항상 실수 없이) 상대가 자신이 이길 수 있는 상태를 선택할 것이 분명함으로 and 형태의 가지로 나타낸다.

04주차

지식? 네가 뭘 알아!

1차시

컴퓨터 같은 정보처리 장치는 데이터를 가공해서 정보를 생성한다. 즉, 컴퓨터에 전달하는 재료를 데이터라고 부르고 처리된 결과를 정보라고 부른다. 이렇게 생성된 정보가 다른 처리를 위해 입력으로 전달된다면 데이터가 되고 다시 정보를 생성한다. 가공된 데이터가 정보인 셈인데, 정보가 쌓여 체계를 갖추면 ( 지식 )이 되고, 더 높은 수준으로 추상화되어 이론과 원리로 발전한다.

2차시

전문가 시스템의 구성요소 중에서, 사용자 관점에서는 상호작용을 위한 사용자 인터페이스가 가장 중요하고, 특히 사용자 인터페이스는 추론한 것을 ( 설명 )하는 기능이 있어야 한다.

3차시

뉴런의 몸체는 핵, 다수의 ( 수상돌기 ), 하나의 ( 축색돌기 )로 구성되어 있으며 ( 시냅스 )는 다른 뉴런으로부터 입력을 받는 부위이고, ( 시냅스 )는 다른 뉴런으로 출력을 내보내는 부위이다. 뉴런은 ( 시냅스 )라 부르는 뉴런들 사이의 접합 부위를 통해서 생체 신호를 전달한다.

05주차

뇌세포가 카톡을!

1차시

뉴런은 시냅스를 통해서 신호를 조절한다. 사실 그 조절 능력이 신경망 학습의 가장 중요한 요소다. 생물학적 뉴런의 시냅스 역할에 대응하는 것이 인공 뉴런의 ( 가중치 )이다.

2차시

데이터가 입력되는 첫 번째 층을 입력층, 최종 출력을 산출하는 마지막 층을 출력층이라 부르며, 중간에 있는 층을 중간층 혹은 감춰져 있다는 의미에서 ( 은닉 )층이라 부른다.

3차시

다층 신경망은 입력을 층 단위로, 차례로 다음 층으로 전파하기 때문에 다층 ( 전진전파 ) 신경망이라도 부른다.

06주차

배워서 남주자!

1차시

생물학적 뉴런의 시냅스는 두 뉴런 사이에 전송되는 정보의 양을 조절하는 역할을 한다. 따라서 뉴런 사이의 연결선을 생화학적 신호가 지나가는 통로라고 가정하면 시냅스는 통로 중간에 있는 ( 밸브 (혹은 수도꼭지) )로 생각할 수 있다.

2차시

사용자는 입력층으로 데이터를 보내면 출력층에서 나오는 결과에만 관심이 있지 중간층에서 일어나는 일들에는 관심이 없다. 또 그래야 마땅하다. 그래서 중간층을 은닉층이라 부르는 중간층 뉴런의 ( 목표 ) 출력이란 건 애초에 존재하지 않는 값이다. 따라서 중간층 뉴런이 출력해야 할 값, 즉 정답이란 건 애초부터 존재하지 않는 값이기 때문에 경사 강하를 이용해서 중간층 뉴런으로의 연결 가중치를 수정할 수 없다.

3차시

신경망에 관심이 있다면 텐서플로 플레이그라운드 (https://playground.tensorflow.org/)에 반드시 들어가서 놀아 볼 필요가 있다. 잘 노는 사람이 성공한다. 잘 놀 수 있도록 중요한 힌트를 주겠다. 푸른색은 ( 양수 ), 붉은색은 음수고, 색이 진하거나 선이 두꺼울수록 절댓값이 크다는 걸 알면 이해하는 데 크게 도움이 된다. 흰색에 가까울수록 0이다.

07주차

인공지능이 노벨상을!

1차시

데이터를 입력받아 처리하는 정보처리 시스템은 보통 ( 블랙박스 )로 생각할 수 있다. 사용자로서는 안에서 무슨 일이 일어나는지 관심 없고 단지 원하는 결과가 출력되면 그만이다. 반면에 시스템을 개발하는 사람은 그 내부를 직접 만들어야 한다. 신경망이 좋은 점은 그 내부를, 학습 데이터만 주면, 스스로 배운다는 것이다.

2차시

보통 중간층이 4개 이상인 신경망을 딥 뉴럴네트워크 혹은 깊은 혹은 ( 심층 ) 신경망이라 한다.

3차시

딥러닝으로 이미지를 입력받아 그 내용을 텍스트로 출력하는 작업을 이미지 ( 캡셔닝 )이라고 한다.

08주차

엄마는 고등어를 좋아해!

1차시

비는 올 수도 있고 아닐 수도 있다. 확실하지 않다. 하지만 확실하지 않은 정도가 다르다. 하늘이 푸를 때와 먹구름이 끼었을 때가 다르고 인근에 비가 오는 경우와 그렇지 않은 경우가 다르다. 이럴 때 사람은 가능성의 차이 즉, 확률을 생각한다. 확률이란 이렇듯 가능성의 차이를 측정하는 척도 즉, 일종의 저울 혹은 ( 자 )다.

2차시

특정 사건이 발생하고 해당 사건의 원인이 여러 개인 상황에서, 그 사건의 원인을 찾을 때 ( 베이즈 ) 추론을 사용한다.

3차시

퍼지 집합을 이용해서 퍼지 규칙을 정의할 수 있고, 이 규칙을 이용해서 추론할 수 있다. 퍼지 추론은 특히 ( 제어 ) 분야에서 아주 많이 응용된다.

09주차

모두 거짓말을 한다

1차시

모든 검색 엔진은 ( 인덱싱 )을 통해서 웹 페이지를 빠르게 검색할 수 있는 근거를 마련한다. 즉, 사람들이 검색하기 전에 이미 ( 인덱싱 )이라는 작업을 통해서 찾아보기를 만들어 놓는다.

2차시

WWW에 존재하는 웹 페이지들은 일반적인 문서와 다르다. 웹 페이지는 ( 하이퍼링크 )로 서로 연결되어 있다. 즉 연결에 의해 서로 관계를 맺고 있다. 구글은 이 정보를 활용해서 웹 페이지에 대한 사람들의 반응을 알아냈다.

3차시

빅데이터는 ( 솔직한 ) 데이터다. 모두가 볼 수 있는 페이스북 내용과 검색에 사용한 키워드가 일치하지 않는다. 사람들은 무심코, 때로는 자신도 알지 못하는, 자신의 은밀한 비밀을 익명의 공간에 던진다. 사람들의 자연스러운 일상은 모두 기록되고 우리는 그들이 원한다고 말하는 게 아니라 그들이 진실로 원하는 걸 알아낼 수 있다.

10주차

이 영화 보세요!

1차시

데이터에 내포된, 숨어서 보이지 않지만, 의미 있는 지식을 찾기 위해 데이터를 뒤지고 분석하는 것이 ( 데이터마이닝 )이다.

2차시

대상을 관련 있는 것들의 덩어리로 묶는 게 ( 군집화 )다. 분류와 짝을 이루면서 분류보다 더 근본적인 작업이다. 분류를 못 할 수 있는 갓난아이도 이것을 할 수 있다는 뜻이다.

3차시

영화든 책이든 상품에 대한 선호도 데이터로부터 사람들 사이의 유사성 혹은 상품들 사이의 유사성을 추출하는 방법이 ( 협업 필터링 ) 알고리즘이다.

11주차

개미의 길찾기

1차시

40,000년 역사를 가진 우리 인간은 13,800,000,000년 역사의 ( 자연 )에서 배울 게 너무 많다.

2차시

칼 심스가 고안한 ( 버추얼 ) 크리처라는 이름의 컴퓨터 속 생명체는 내부에 신경망을 가지고 있고 이것이 관절을 통제한다. 일단 자신의 형태가 결정되면 가장 효율적인 동작을 생성하는 신경망을 진화 과정을 통해 스스로 구성한다. 쉽게 말해서 이렇게 생겨 먹었으면 어떻게 몸을 비틀어야 빠르게 이동할 수 있는지 스스로 터득한다는 뜻이다.

3차시

개미의 길 찾기는 떼(혹은 집단) 지능의 특징을 잘 보여주는 사례다. 개체들은 조직을 통제하는 지도자의 ( 지시 )를 받지 않는다. 개체 하나하나의 역량도 소박하다. 개체들은 자신의 환경 전체를 파악할 수 없으며 단지 자신의 주변에 대한 지역 정보에 의존한 간단한 규칙을 사용한다.

12주차

발가락이 닮았네

1차시

혁명 revolution과 진화 evolution의 같은 점은 변화고 다른 점은 속도다. 둘 다 달라지는 건데 하나는 아주 빠르고 급격하게 다른 하나는 느리고 완만하다는 거다. 그렇다면 변화와 진화의 차이는 무엇일까? ( (자연) ___ )과 ( (자연) 선택 ) 2가지가 작용하면서 달라지는 게 진화다.

2차시

유전 알고리즘은 잠재적 후보 해를 생성한 후, 진화를 통해 최적의 해결책을 생성한다. 생명은 DNA로 자신을 표현하고 자연은 그 DNA로 만들어진 생명의 적합도를 평가한다. 그렇다면 우리가 해결하려는 문제의 답 즉 후보 해를 DNA 형태로 표현하는 방법 ( 인코딩 )과 그것의 적합도를 측정할 수 있는 수단, 적합도 함수를 설계해야 한다.

3차시

( 최적화 )는 가능한 경우의 수가 많은 가운데 가장 적합한 무엇인가를 찾는 작업으로 그 활용 범위가 무궁하다. 이 작업은 답을 찾기 위해 다양한 가능성을 모두 계산해야 하는 까다로운 문제다.

13주차

단순한 복잡함

1차시

시간에 따라 상태가 변하는 시스템을 ( 동역학 ) 시스템이라고 한다. 날씨, 주식, 부동산 그리고 인생 자체가 이 시스템이다.

2차시
