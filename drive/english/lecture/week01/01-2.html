핵심 1

LaTeX는 워드프로세서가 아니라 문서 마크업 언어(document markup language)이며, 전문(preamble)·명령(command)·본문(body) 구조로 이루어집니다.

핵심 2

표는 tabular, 수식은 $...$(인라인)·\[...\](디스플레이), 참고문헌은 BibTeX로 관리합니다.

핵심 3

실습 과제는 위키백과 문서를 LaTeX로 재현하는 것과 팀 소개 포스터 제작입니다.

01LaTeX 소개

LaTeX란

  • 문서 조판 소프트웨어(software for typesetting documents)이자 문서 준비 시스템(document preparation system).
  • 워드프로세서가 아니라 문서 마크업 언어(document markup language)로 사용됨.
  • 무료·오픈소스 소프트웨어이며, Leslie Lamport가 만들었고 Donald Knuth의 TeX 조판 엔진을 기반으로 함.
  • 발음은 "Lah-tech" 또는 "Lay-tech" 둘 다 쓰임.

LaTeX vs Word

Word는 화면에 보이는 대로 결과가 나오는 방식(WYSIWYG)인 반면, LaTeX는 \section{Introduction}처럼 명령어로 구조를 표시하고 이를 컴파일해서 결과물을 만듭니다.

장점 (Benefits)

  • 과학·기술 문서, 특히 수학 수식 조판에 강함.
  • 문서가 아무리 커도 고품질·안정적인 출력을 유지.
  • 상호 참조·번호 매기기·목차/그림 목록/참고문헌 목록 등을 자동 생성.
  • 다국어 지원, PostScript·PDF·DVI·HTML 등 다양한 출력 형식 지원.
  • 편지·발표자료·악보·체스 기보 등 다양한 템플릿에 유연하게 대응.
  • Windows·Linux·Mac 등에서 동일한 출력을 보장(플랫폼 간 일관성).
  • 일반 텍스트로 작업하므로 읽기·편집이 쉬움.

단점 (Disadvantages)

  • 학습 곡선이 김.
  • 큰 문서일수록 구조 파악이 어려움.
  • 표를 만들고 디자인하기 까다로움.
  • 디버깅(오류 수정) 비용이 큼.

배포판 (Distributions)

구분목록
TeX 배포판TeX Live, MikTeX
제공 엔진pdfLaTeX(전통적·호환성 좋음), XeLaTeX(유니코드·시스템 폰트 지원), LuaLaTeX(유니코드+Lua 프로그래밍)
기타 제공물LaTeX 패키지, 폰트, 지원 도구

에디터 (Editors)

  • 독립 에디터: TeXstudio, TeXworks, TexMaker, TeXnicCenter, Gummi, Lyx
  • VS Code 플러그인: LaTeX Workshop
  • IntelliJ 계열(오프라인) 플러그인: TeXiFy IDEA, PDF Viewer
  • 온라인 에디터: Overleaf, Papeeria, CoCalc, Authorea

02문서 구조 · 명령어 문법

기본 문서 구조

tex기본 구조
% Preamble(전문)
\documentclass[a4paper, 12pt]{article}
% Packages(패키지)
\usepackage{amsmath}
\usepackage{graphicx} % Required for inserting images
% Variables(변수)
\title{Introduction to LaTeX}
\author{Author Name}
\date{\today}
% Document Body(본문)
\begin{document}
\maketitle
Hello, world!
\end{document}

문서는 크게 전문(preamble) — 문서 종류·패키지·변수 선언, 명령(command), 본문(body) — \begin{document}~\end{document} 세 부분으로 이루어집니다.

명령어 문법

  • 명령은 백슬래시(\)로 시작하고 대소문자로 이어집니다.
  • 인자는 중괄호{}(필수) 또는 대괄호[](선택)로 전달합니다: \command[선택인자]{필수인자}
  • 여러 인자를 가질 수도 있습니다: \command[opt1][opt2]{arg1}{arg2}{arg3}

공백·줄바꿈·문단

  • 여러 칸 띄어쓰기는 한 칸과 동일하게 처리됨.
  • 줄바꿈 한 번은 공백 한 칸과 같은 효과.
  • 에디터에서 어떻게 줄을 배치하든 출력 결과는 같음.
  • 빈 줄 하나가 문단 구분을 만들며, 여러 개의 빈 줄도 하나로 처리됨.

주석 (Comments)

퍼센트 기호(%) 뒤부터 그 줄 끝까지는 주석으로 처리되어 컴파일 시 무시됩니다.

03텍스트 서식

특수문자 (Special Characters)

#, %, $, &, _, {, } 같은 기호는 LaTeX에서 특별한 의미를 가지므로, 그대로 쓰려면 앞에 백슬래시(\)를 붙입니다. 예: \#, \%, \$, \&. 백슬래시 자체는 \textbackslash로 씁니다.

굵게 · 기울임 · 밑줄

명령어효과
\emph{}강조(문맥에 따라 기울임으로 표시)
\textit{}기울임(italic)
\textbf{}굵게(bold)
\textsl{}슬랜트체(slanted)
\textsc{}소형 대문자(Small Caps)

명령은 \textit{\textbf{nested}}처럼 중첩해서 쓸 수 있습니다.

글꼴 크기 · 글꼴 · 색상

  • 글꼴 크기 명령은 스위치 명령(switch command)이라, 명령이 속한 블록 끝까지 뒤 텍스트에 적용됩니다. 예: {\tiny 이 글자는 작습니다.}
  • 글꼴 종류: \texttt{}(고정폭, 코드 표기용) 등.
  • 색상: \usepackage{xcolor} 후 \color{colorname}(스위치 명령, 이후 전체 적용) 또는 \textcolor{colorname}{text}(괄호 안 텍스트만 적용).
  • 색상 팔레트: 기본 19색, dvipsnames(68색), svgnames(151색), x11names(317색). 여러 옵션을 동시에 불러올 수도 있음.
  • 직접 색 정의: \definecolor{이름}{모델}{값} — 모델은 rgb(0~1), RGB(0~255), cmyk(0~1), gray(0~1).

정렬 (Text Alignment)

환경(environment)스위치 명령효과
flushleft\raggedright왼쪽 정렬
flushright\raggedleft오른쪽 정렬
center\centering가운데 정렬
—\justifying(ragged2e 패키지)양쪽 정렬

04리스트

환경용도
itemize글머리표(순서 없는) 목록
enumerate번호(순서 있는) 목록 — 각 enumerate는 1부터 자동으로 번호가 매겨짐
description용어 설명 목록 — \item[표제어] 형태로 씀
texitemize 예시
\begin{itemize}
\item start with the \verb|\item| command.
\item Entries start with bullets.
\end{itemize}

05이미지

이미지 삽입

  • graphicx 패키지가 필요하며, \graphicspath{{./images/}}로 기본 경로를 지정할 수 있음.
  • \includegraphics{[경로/]이름} — 확장자는 생략 가능.
  • 크기·회전: \includegraphics[width=0.8\linewidth]{galaxy}, \includegraphics[scale=0.5, angle=45]{galaxy}

figure 환경

이미지·차트·의사코드 등 시각 자료는 figure 환경으로 감싸고, \caption{}(캡션)과 \label{}(참조용 이름표)을 함께 씁니다. 본문에서는 \ref{label}로 번호를 참조합니다.

texfigure 예시
\begin{figure}[h]
\centering
\includegraphics[width=0.3\linewidth]{galaxy}
\caption{A nice plot.}
\label{fig:mesh1}
\end{figure}
The following Figure~\ref{fig:mesh1} is a nice photo.

배치 · 여러 이미지

  • 두 단(\twocolumn) 레이아웃에서는 figure*로 모든 단에 걸치는 그림을 만들 수 있음(*는 다단 환경의 확장 버전을 뜻함).
  • 여러 장을 나란히 배치할 때는 subcaption 패키지의 subfigure 환경을 사용.
  • 간격 조정: \hspace{}/\vspace{}(수평/수직 여백 추가), \hfill/\vfill(남는 공간 채우기).

06표

tabular 환경 — 기본

  • 열 정렬 지정: l(왼쪽), c(가운데), r(오른쪽). |는 세로선.
  • 셀 구분은 &, 줄 구분은 \\, 가로선은 \hline.
textabular 예시
\begin{tabular}{|c|c|c|}
\hline
title1 & title2 & title3 \\
\hline
cell1 & cell2 & cell3 \\
cell4 & cell5 & cell6 \\
\hline
\end{tabular}

booktabs — 고급 표

ACM/IEEE 논문 형식의 표에 쓰이는 booktabs 패키지는 세로선 대신 깔끔한 가로선을 권장합니다.

명령어역할
\toprule표의 맨 위 선
\midrule제목과 본문 구분선
\bottomrule표의 맨 아래 선
\cmidrule{a-b}a~b 열에 걸친 부분 선

열 · 행 합치기

  • \multicolumn{개수}{정렬}{내용} — 열 합치기.
  • \multirow{개수}{너비}{내용}(multirow 패키지) — 행 합치기. 합쳐진 칸은 비워 둬야 함.

table 환경

table 환경으로 tabular를 감싸면 \caption{}(제목)과 \label{}(참조)을 붙일 수 있고, 표 번호는 그림·수식 번호와 독립적으로 매겨집니다.

07레이아웃

여백 (Margins)

geometry 패키지로 \geometry{left=20mm, right=20mm, top=20mm, bottom=20mm}처럼 여백을 직접 지정합니다.

챕터 · 섹션

명령어수준
\chapter{}book 문서 종류에서만 사용
\section{}1단계 섹션
\subsection{}2단계 섹션
\subsubsection{}3단계 섹션

뒤에 *를 붙이면(\section*{}) 번호가 매겨지지 않는 섹션이 됩니다.

목차 (Table of Contents)

\tableofcontents 명령이 위치한 곳에 목차가 생성됩니다. 번호 없는 섹션도 \addcontentsline{toc}{section}{이름}으로 목차에 추가할 수 있습니다.

다단 레이아웃

  • \twocolumn / \onecolumn — 페이지 단위로 단을 나눔(새 페이지 시작).
  • multicols 환경(multicol 패키지) — 문단 단위로 여러 단을 나눔.

여러 파일 합치기

  • \input{파일명} — 다른 .tex 파일의 내용을 그대로 불러옴.
  • \include{파일명} — \input과 비슷하지만 앞뒤로 페이지 나눔(\clearpage)이 자동으로 들어감.

인용문 (Quote Environment)

quote 환경으로 긴 인용문을 들여쓰기해서 표시할 수 있습니다.

08수학

시험 ★★☆

수학 모드 — 인라인 vs 디스플레이

  • 인라인(inline) — 문단 속에 섞여 들어가는 수식. \(...\), $...$, \begin{math}...\end{math} 세 가지 표기는 결과가 같으며, \( \)와 $ $가 가장 널리 쓰임.
  • 디스플레이(display) — 별도 줄에 놓이는 수식. 번호 없는 형태는 \[...\], $$...$$, displaymath 환경, 번호 있는 형태는 equation 환경.

첨자 · 합·적분

  • 아래첨자(subscript) _: 합·적분의 시작점, 로그의 밑 등을 표시.
  • 위첨자(superscript) ^: 합·적분의 끝점, 지수를 표시.
  • {}로 여러 문자를 하나로 묶음. \sum(합), \int(적분), \prod(곱), \infty(무한대).
  • 분수: \frac{분자}{분모}.

괄호 크기 조절

\left( ... \right)처럼 \left/\right를 붙이면 내용 크기에 맞춰 괄호 크기가 자동으로 커집니다.

여러 줄 수식 정렬 — amsmath

  • align 환경: & 기준으로 여러 줄 수식을 세로로 정렬. & 왼쪽은 오른쪽 정렬, 오른쪽은 왼쪽 정렬되며 각 줄마다 번호가 매겨짐.
  • align* 환경: 번호 없이 정렬. &를 여러 번 써서 다열 정렬도 가능.
  • 보이지 않는 괄호 \left. / \right. — 여러 줄에 걸친 괄호 쌍을 맞출 때, 실제로는 표시되지 않는 괄호로 짝을 맞춰줌.

행렬 (matrix)

amsmath의 행렬 환경(pmatrix 등)은 반드시 equation류 수식 환경 안에 있어야 합니다.

tex행렬 예시
\usepackage{amsmath}
\[
A=
\begin{pmatrix}
1 & 2 & 3 \\
a & b & c
\end{pmatrix}
\]

09사용자 정의 명령어

  • \newcommand{\이름}{내용} — 새 명령 정의. 선택 인자는 하나만 허용됨.
  • 선택 인자가 있는 경우 \newcommand{\note}[2][TODO]{...}처럼 대괄호 안에 기본값을 지정.
  • \ (백슬래시+공백): 줄바꿈이 가능한 공백. ~: 줄바꿈이 되지 않는 공백.
tex매크로 예시
\newcommand{\keyword}[1]{\textbf{#1}}
\begin{document}
\keyword{Grouping} by curly braces limits the
\keyword{scope} of \keyword{declarations}.
\end{document}

10소스코드 · 참고문헌

소스코드 — listings 패키지

listings는 소스코드를 조판하기 위한 내장 패키지로, 구문 강조(키워드/주석/문자열)·줄번호·테두리·파일 불러오기를 지원하며 스타일을 커스터마이즈할 수 있습니다.

texlstlisting 예시
\usepackage{listing}
\begin{lstlisting}[
  language=C,
  caption={Simple sum},
  label={lst:sum}
]
#include <stdio.h>
int main(void){
  int a=10, b=20;
  printf("%d\n", a+b);
  return 0;
}
\end{lstlisting}

\lstinputlisting[firstline=1, lastline=10]{code/main.c}처럼 외부 파일의 특정 줄 범위만 불러올 수도 있습니다.

참고문헌 — BibTeX

  • LaTeX는 BibTeX 도구로 참고문헌을 관리합니다.
  • 작동 방식: main.tex의 \cite{key1}이 ref.bib의 항목과 연결되고, BibTeX 컴파일러가 이를 조합해 최종 참고문헌 목록을 만듭니다.
  • bib 파일은 유형별 블록으로 구성: @book(단행본), @article(저널 논문), @inproceedings(학회 논문), @phdthesis(학위논문), @misc(기타).
  • 인용: \cite{key}. 여러 문헌은 \cite{key1, key2, ...}처럼 한 번에 쓰고, 여러 개의 \cite를 나열하지 않습니다.
  • 문서 끝에서 \bibliographystyle{plain}(인용 스타일 선택)과 \bibliography{references}(references.bib 불러오기)로 목록을 출력합니다.

11템플릿 · 요약 · 실습

교수님 강조

템플릿 선택

클래스(class, 문서 종류)는 문서의 정해진 디자인을 제공합니다(예: article, book).

요약 (Summary)

  • LaTeX로 표·그림을 조판할 수 있음.
  • 사용자 정의 명령·파일 불러오기로 작업을 간소화할 수 있음.
  • LaTeX는 수학 수식 조판에 특히 강함.
  • BibTeX로 인용을 관리함.

실습 과제 (Practices)

슬라이드에 제시된 실습 안내
  • 1페이지 팀 소개 포스터 제작.
  • 개념을 설명하는 문서 제작 — 수식·표·그림이 포함된 위키백과 문서를 하나 골라(예: Factorial 문서) LaTeX로 재현.
    • 참고문헌 3개 이상 포함
    • 섹션 4개 이상 포함
    • 표·그림을 언급하는 문장을 추가하고 색으로 강조
    • 문서의 모든 섹션을 다 재현할 필요는 없음
  • 각 결과물은 eRuri의 해당 제출란에 제출.
