핵심 1

LaTeX는 워드프로세서가 아니라 문서 마크업 언어(document markup language)이며, 문서는 전문(preamble)과 본문(body)으로 나뉩니다.

핵심 2

중괄호 {}는 필수 인자, 대괄호 []는 선택 인자입니다. 명령 뒤 별표(*)는 번호를 붙이지 않는 등의 변형 버전을 뜻합니다.

핵심 3

환경(environment)은 \begin{}~\end{} 안에서만, 스위치 명령(switch command)은 블록 끝까지 계속 적용됩니다.

01LaTeX 소개

LaTeX란

  • 문서 조판 소프트웨어(software for typesetting documents)이자 문서 준비 시스템(document preparation system).
  • 워드프로세서가 아니라 문서 마크업 언어(document markup language)로 사용됨.
  • 무료·오픈소스 소프트웨어이며, Leslie Lamport가 만들었고 Donald Knuth의 TeX 조판 엔진을 기반으로 함.
  • 발음은 "Lah-tech" 또는 "Lay-tech" 둘 다 쓰임.

LaTeX vs Word

Word는 화면에 보이는 대로 결과가 나오는 방식(WYSIWYG)인 반면, LaTeX는 \section{Introduction}처럼 명령어로 구조를 표시하고 이를 컴파일해서 결과물을 만듭니다.

장점 (Benefits)

  • 과학·기술 문서, 특히 수학 수식 조판에 강함.
  • 문서가 아무리 커도 고품질·안정적인 출력을 유지.
  • 상호 참조·번호 매기기·목차/그림 목록/참고문헌 목록 등을 자동 생성.
  • 다국어 지원, PostScript·PDF·DVI·HTML 등 다양한 출력 형식 지원.
  • 편지·발표자료·악보·체스 기보 등 다양한 템플릿에 유연하게 대응.
  • Windows·Linux·Mac 등에서 동일한 출력을 보장(플랫폼 간 일관성).
  • 일반 텍스트로 작업하므로 읽기·편집이 쉬움.

단점 (Disadvantages)

  • 학습 곡선이 김(long learning curve).
  • 큰 문서일수록 구조 파악이 어려움(difficulty of understanding large documents).
  • 표를 만들고 디자인하기 까다로움(challenging to create and design tables).
  • 디버깅(오류 수정) 비용이 큼(expensive troubleshooting/debugging effort).

02LaTeX 기본 — 문서 구조 · 명령어 문법

기본 문서 구조

tex기본 구조
% Preamble(전문)
\documentclass[a4paper, 12pt]{article}
% Packages(패키지)
\usepackage{amsmath}
\usepackage{graphicx} % Required for inserting images
% Variables(변수)
\title{Introduction to LaTeX}
\author{Author Name}
\date{\today}
% Document Body(본문)
\begin{document}
\maketitle
Hello, world!
\end{document}

문서는 크게 두 부분으로 나뉩니다.

구역범위들어가는 것
전문(Preamble)\documentclass부터 \begin{document} 직전까지문서 종류(\documentclass), 패키지(\usepackage), 변수(\title, \author, \date)
본문(Body)\begin{document}~\end{document}실제 문서 내용, \maketitle 등

\documentclass처럼 백슬래시로 시작하는 것이 명령(command)이고, \today는 컴파일하는 날짜로 자동 치환됩니다. \maketitle은 전문에 선언한 title·author·date를 실제 제목 블록으로 그려줍니다.

실제 출력

Introduction to LaTeX
Author Name
September 5, 2026

Hello, world!

명령어 문법

  • 명령은 백슬래시(\)로 시작하고 대소문자로 이어집니다.
  • 인자는 중괄호{}(필수) 또는 대괄호[](선택)로 전달합니다: \command[선택인자]{필수인자}
  • 여러 인자를 가질 수도 있습니다: \command[opt1][opt2]{arg1}{arg2}{arg3}

공백·줄바꿈·문단

  • 여러 칸 띄어쓰기는 한 칸과 동일하게 처리됨(multiple spaces = a single space).
  • 줄바꿈 한 번은 공백 한 칸과 같은 효과(a single line break = a single space).
  • 에디터에서 어떻게 줄을 배치하든 출력 결과는 같음.
  • 빈 줄 하나가 문단 구분을 만들며(a blank line denotes a paragraph break), 여러 개의 빈 줄도 하나로 처리됨.
tex소스 코드
LaTeX treats     multiple spaces just like a single space.

A single line break
has the same effect like a single space.


Multiple empty lines are treated as one.
실제 출력 — 띄어쓰기와 줄바꿈이 정리됨

LaTeX treats multiple spaces just like a single space.

A single line break has the same effect like a single space.

Multiple empty lines are treated as one.

주석 (Comments)

퍼센트 기호(%) 뒤부터 그 줄 끝까지는 주석으로 처리되어 컴파일 시 무시됩니다.

탭(Tab)은 어떻게 처리되나 — 교수님이 설명하신 내용 아님

소스 코드의 탭은 스페이스와 똑같이 공백 한 칸으로 처리되어 결과물에는 영향이 없습니다. 실제로 간격이나 들여쓰기를 넣으려면 아래 명령을 씁니다.

목적명령어

정확한 길이 지정\hspace{1cm}
문단 첫 줄 들여쓰기 켜기/끄기\indent, \noindent
탭 정지점처럼 여러 열 맞추기tabbing 환경 (\=로 위치 지정, \>로 이동)

03LaTeX 기본 — 텍스트 서식

특수문자 (Special Characters)

#, %, $, &, _, {, } 같은 기호는 LaTeX에서 특별한 의미를 가지므로, 그대로 쓰려면 앞에 백슬래시(\)를 붙입니다. 예: \#, \%, \$, \&. 백슬래시 자체는 \textbackslash로 씁니다.

헷갈리기 쉬운 것 — \\는 특수문자 이스케이프가 아님

\\는 텍스트 안의 특정 기호를 이스케이프하는 게 아니라, 강제 줄바꿈(forced line break)을 만드는 별도 명령어입니다. 슬라이드 예문에서도 문장 끝마다 \\를 붙여 줄을 바꿨습니다.

tex특수문자 예시
\begin{document}
\maketitle
\section{Writing Special Characters}
Statement \#1: 50\% of \$100 makes \$50. \\
More special symbols are \&, \_, \{ and \}. \\
\textbackslash
\end{document}
실제 출력

Statement #1: 50% of $100 makes $50.
More special symbols are &, _, { and }.
\

직접 색 정의 (Creating Your Own Colors)

\definecolor{색이름}{모델}{값}으로 원하는 색을 직접 만들 수 있습니다. 모델은 rgb(0~1 세 값), RGB(0~255 세 값), cmyk(0~1 네 값), gray(0~1 흑백 하나) 중 선택합니다.

texdefinecolor 예시
\usepackage{xcolor}
\definecolor{mypink1}{rgb}{0.858, 0.188, 0.478}
\definecolor{mypink2}{RGB}{219, 48, 122}
\definecolor{mypink3}{cmyk}{0, 0.7808, 0.4429, 0.1412}
\definecolor{mygray}{gray}{0.6}
\begin{document}
\textcolor{mypink1}{Pink with rgb} \\
\textcolor{mypink2}{Pink with RGB} \\
\textcolor{mypink3}{Pink with cmyk} \\
\textcolor{mygray}{Gray with gray}
\end{document}
실제 출력

1. Pink with rgb

2. Pink with RGB

3. Pink with cmyk

4. Gray with gray

방법 1 — 환경(environment)으로 정렬

\begin{}~\end{} 블록 안에 넣으면 그 블록 안에서만 정렬이 적용됩니다.

tex환경 예시
\begin{flushleft}
This is left-aligned.
\end{flushleft}

\begin{center}
This is center-aligned.
\end{center}

\begin{flushright}
This is right-aligned.
\end{flushright}
실제 출력

This is left-aligned.

This is center-aligned.

This is right-aligned.

방법 2 — 스위치 명령으로 정렬

\raggedright 등은 스위치 명령이라, 별도 표시 없이 그 블록(또는 문서) 끝까지 계속 적용됩니다.

tex스위치 명령 예시
\raggedright % "right"가 이름에 붙지만 왼쪽 정렬을 뜻함
This is left-aligned.\\
\raggedleft % "left"가 이름에 붙지만 오른쪽 정렬을 뜻함
This is right-aligned.\\
\centering
This is center-aligned.\\
\justifying % 원래 상태(양쪽 정렬)로 되돌리기 — ragged2e 패키지 필요
This is a justified text.
스위치 명령에서 원래대로 되돌리는 법

\raggedright·\raggedleft·\centering은 켜면 문서 끝까지 계속 적용되므로, 되돌리려면 둘 중 하나를 씁니다.

  • \justifying 명령으로 원래(양쪽 정렬) 상태로 되돌리기 — \usepackage{ragged2e}가 필요합니다.
  • 영향을 주고 싶은 범위를 중괄호{}로 감싸서 그 안에서만 적용되게 하기: {\centering 이 부분만 가운데 정렬됩니다.}

05레이아웃 (Layout)

여백 (Margins)

geometry 패키지로 여백을 지정합니다. 두 가지 방식이 있고 결과는 같습니다.

tex방식 1 — \geometry{}로 따로 지정

\usepackage{blindtext}
\usepackage{geometry}
\geometry{
    a4paper,
    left=20mm,
    right=20mm,
    top=20mm,
    bottom=20mm
}
\begin{document}
    \blindtext[5]
\end{document}
tex방식 2 — 패키지 옵션으로 한 번에
\documentclass[a4paper, 12pt]{article}
\usepackage[english]{babel}
\usepackage{blindtext}
\usepackage[a4paper,
    left=20mm,
    right=20mm,
    top=20mm,
    bottom=20mm]{geometry}
\begin{document}
    \blindtext[5]
\end{document}

left/right/top/bottom은 각각 왼쪽·오른쪽·위·아래 여백이고, mm 외에 cm, in, pt도 쓸 수 있습니다.

챕터 · 섹션

명령어수준
\chapter{}book 문서 종류에서만 사용 (chapter)
\section{}1단계 섹션 (first-level section)
\subsection{}2단계 섹션 (second-level section)
\subsubsection{}3단계 섹션 (third-level section)
별표(*) 붙은 명령 — 번호 없는 버전

명령 뒤에 *를 붙이면(\section*{}, \subsection*{}) 번호가 매겨지지 않고 목차에도 자동으로 들어가지 않는 버전이 됩니다. 서문·감사의 글처럼 번호를 붙이고 싶지 않은 절에 씁니다.

LaTeX 전반에서 *는 "그 명령/환경의 변형 버전"을 뜻합니다. 예를 들어 figure*는 다단 레이아웃에서 모든 단을 가로지르는 그림, align*는 번호 없는 수식 정렬입니다.

article 클래스에서의 절 (Sections in Article)

tex번호 있는 절
\documentclass[a4paper, 12pt]{article}
\usepackage[english]{babel}
\usepackage{blindtext}
\begin{document}
    \section{List}
        \subsection{Unordered List} \blindtext[1]
            \subsubsection{Shape}
            \subsubsection{Margin}
        \subsection{Ordered List} \blindtext[1]
        \subsection{Detailed List} \blindtext[1]
\end{document}
실제 출력 — 번호가 자동으로 매겨짐

1 List 1.1 Unordered List Hello, here is some text without a meaning. ... 1.1.1 Shape 1.1.2 Margin 1.2 Ordered List Hello, here is some text without a meaning. ...

번호 없는 절 (Unordered Section)

같은 코드에서 모든 명령 뒤에 *만 붙이면 됩니다.

tex별표(*) 붙인 절
\begin{document}
    \section*{List}
        \subsection*{Unordered List} \blindtext[1]
            \subsubsection*{Shape}
            \subsubsection*{Margin}
        \subsection*{Ordered List} \blindtext[1]
        \subsection*{Detailed List} \blindtext[1]
\end{document}
실제 출력 — 번호가 사라짐

List Unordered List Hello, here is some text without a meaning. ... Shape Margin Ordered List Hello, here is some text without a meaning. ...

book 클래스에서의 절 (Sections in Book)

book 클래스에서만 \chapter{}를 쓸 수 있고, 챕터는 새 페이지에서 시작하며 번호가 1.1, 1.1.1처럼 챕터 번호부터 붙습니다.

texbook 클래스
\documentclass[a4paper, 12pt]{book}   % ← article이 아니라 book
\usepackage[english]{babel}
\usepackage{blindtext}
\begin{document}
    \chapter{Book Chapter}
        \section{List}
            \subsection{Unordered List} \blindtext[1]
                \subsubsection{Shape}
                \subsubsection{Margin}
            \subsection{Ordered List} \blindtext[1]
\end{document}
실제 출력

Chapter 1 Book Chapter 1.1 List 1.1.1 Unordered List Hello, here is some text without a meaning. ...

\tableofcontents 명령이 위치한 곳에 목차가 생성됩니다.

tex목차 생성
\begin{document}

\tableofcontents          % ← 이 위치에 목차가 생성된다

\chapter{Book Chapter}
   \section{List}
      \subsection{Unordered List}  \blindtext[1]
         \subsubsection{Shape}

실제 출력

번호 없는 절을 목차에 넣기

\section*{}는 목차에 자동으로 안 들어가므로, \addcontentsline으로 직접 추가해야 합니다.

texaddcontentsline
\section*{Acknowledgments}                        % ← 번호 없는 절
\addcontentsline{toc}{section}{Acknowledgments}   % ← 목차에 수동 추가

인자는 순서대로 {toc}(목차 파일), {section}(어느 수준으로 넣을지), {이름}(목차에 표시할 글자)입니다.

다단 레이아웃

\twocolumn — 페이지 단위

\twocolumn은 새 페이지를 시작하고 그 페이지부터 2단으로 만듭니다. \onecolumn도 마찬가지로 새 페이지를 시작하며 1단으로 되돌립니다.

textwocolumn
\documentclass[a4paper,12pt]{article}
\usepackage{blindtext}
\begin{document}
    \twocolumn
    \blindtext[5]
\end{document}

multicols — 문단 단위

multicols는 환경이라서 \begin{}~\end{} 사이 부분만 다단이 되고, 단 개수를 숫자로 지정합니다. multicol 패키지가 필요합니다.

texmulticols
\documentclass[a4paper,12pt]{article}
\usepackage{blindtext}
\begin{document}
    \section{Multiple Columns Example}
    This is a document with 3 columns.
    \begin{multicols}{3}      % ← 문단 단위 다단 설정, 숫자가 단 개수
        \blindtext[2]
    \end{multicols}
\end{document}

여러 파일 합치기

논문처럼 긴 문서는 절마다 파일을 나눠 두고 메인 파일에서 불러옵니다.

  • \input{파일명} — 다른 .tex 파일의 내용을 그대로 불러옴. 확장자 .tex는 생략.
  • \include{파일명} — \input과 비슷하지만 앞뒤로 페이지 나눔(\clearpage)이 자동으로 들어감.
tex메인 파일 (main.tex)
\documentclass[a4paper, 12pt]{article}
% Body
\begin{document}
    \maketitle
    \input{section1}
    \input{section2}
    \input{section3}
\end{document}
tex불러오는 각 파일
% section1.tex
\section{Section1}
This section explains how to write C code.
\blindtext[15]

% section2.tex
\section{Section2}
This section explains how to write Pseudo-code.
\blindtext[15]

% section3.tex
\section{Section3}
This section explains how to write Java code.
\blindtext[15]
명령실제 출력 차이
\inputFirst file(7절)과 Second file(8절)이 한 페이지 안에 이어서 조판됨
\includeFirst file과 Second file이 각각 새 페이지로 나뉘어 조판됨

quote 환경으로 감싸면 인용문이 좌우 여백을 두고 들여쓰기되어 본문과 구분됩니다. 논문에서 다른 문헌의 문장을 그대로 인용할 때 씁니다.

06사용자 정의 명령어 (Custom Commands)

  • \newcommand{\이름}{내용} — 새 명령 정의. 선택 인자는 하나만 허용됨.
  • 선택 인자가 있는 경우 \newcommand{\note}[2][TODO]{...}처럼 대괄호 안에 기본값을 지정.

인자 없는 명령 — 반복되는 문구 줄이기

같은 표현을 문서 곳곳에 반복해서 쓸 때, 이름을 붙여두면 나중에 표현을 바꿔도 정의 한 줄만 고치면 됩니다.

tex인자 없는 매크로
\newcommand{\TUG}{\textit{TeX Users Group}}
\begin{document}
\section{Creating Custom Commands}
The \TUG\ is an organization for people who are
interested in \TeX\ or \LaTeX.
\end{document}
실제 출력

3  Creating Custom Commands

The TeX Users Group is an organization for people who are interested in TEX or LATEX.

명령 뒤 공백 처리 — \ 와 ~

LaTeX는 명령 이름 뒤의 공백을 명령의 끝을 알리는 표시로 먹어버립니다. 그래서 \TUG is라고 쓰면 "TeX Users Groupis"처럼 붙어버립니다. 위 예시에서 \TUG\ is처럼 쓴 이유입니다.

표기뜻
\ (백슬래시 + 공백)공백을 명시적으로 넣음. 필요하면 그 자리에서 줄바꿈 허용.
~ (물결표)공백을 명시적으로 넣지만 줄바꿈을 허용하지 않음. Figure~\ref{}처럼 번호와 단어가 갈라지면 안 될 때 씀.
tex매크로 예시
\newcommand{\keyword}[1]{\textbf{#1}}
\begin{document}
\keyword{Grouping} by curly braces limits the
\keyword{scope} of \keyword{declarations}.
\end{document}

\newcommand 문법 상세

\newcommand{command}[arguments][optional]{definition}

인자설명
command새 명령의 이름. 백슬래시 뒤에 대소문자 알파벳, 또는 백슬래시 뒤에 알파벳이 아닌 기호 하나. 이미 정의된 이름은 쓸 수 없고, \end로 시작할 수 없음.
arguments1~9 사이 정수로, 새 명령이 받는 인자의 개수. 생략하면 인자 없는 명령이 됨.
optional이 값이 있으면 첫 번째 인자가 선택 인자가 되고, 여기 적은 값이 기본값이 됨. 없으면 모든 인자가 필수.
definitioncommand가 나올 때마다 이 내용으로 치환됨. #n 형태는 n번째 인자로 치환됨.
tex선택 인자 예시 — \note
\usepackage{xcolor}
% 인자 2개, 첫 번째 인자의 기본값은 TODO
\newcommand{\note}[2][TODO]
  {\textbf{\color{red}[#1]} \textit{#2}}
\begin{document}
\note{Need to fix consistency.}
\note[DISCUSS]{This is a command test.}
\end{document}
실제 출력

[TODO] Need to fix consistency.

[DISCUSS] This is a command test.

08이미지 (Images)

이미지 삽입

  • graphicx 패키지가 필요하며, \graphicspath{{./images/}}로 기본 경로를 지정할 수 있음.
  • \includegraphics{[경로/]이름} — 확장자는 생략 가능.
  • 크기·회전: width는 너비 지정, scale은 배율, angle은 회전 각도(도 단위).
tex크기·회전
% 본문 너비(linewidth)의 80% 크기로
\includegraphics[width=0.8\linewidth]{galaxy}

% 원본의 50% 크기로 줄이고 45도 회전
\includegraphics[scale=0.5, angle=45]{galaxy}

\linewidth는 본문 한 줄의 너비를 뜻하는 값이라, 0.8\linewidth는 "본문 폭의 80%"가 됩니다. 창 크기나 다단 설정이 바뀌어도 비율이 유지됩니다.

figure 환경

이미지·차트·의사코드 등 시각 자료는 figure 환경으로 감싸고, \caption{}(캡션)과 \label{}(참조용 이름표)을 함께 씁니다. 본문에서는 \ref{label}로 번호를 참조합니다.

texfigure 예시
\begin{figure}[h]
\centering
\includegraphics[width=0.3\linewidth]{galaxy}
\caption{A nice plot.}
\label{fig:mesh1}
\end{figure}
The following Figure~\ref{fig:mesh1} is a nice photo.
실제 출력
[galaxy 이미지]

Figure 1: A nice plot.

Q1LaTeX 명령어에서 중괄호 {}와 대괄호 []의 차이는?객관식
  1. 중괄호는 선택 인자, 대괄호는 필수 인자
  2. 중괄호는 필수 인자, 대괄호는 선택 인자
  3. 둘 다 필수 인자
  4. 둘 다 주석 처리용

Q2다음 코드에서 "This text is tiny." 이후의 문장 크기는 어떻게 되는가?코드
tex
{\tiny This text is tiny.} The effects only apply to
the text in the brackets.
정답원래 크기로 돌아옵니다. \tiny는 스위치 명령이지만 중괄호로 범위가 제한되어, 중괄호 밖의 문장에는 적용되지 않습니다.
Q3명령 뒤에 붙는 별표(*)가 무엇을 뜻하는지, \section*과 figure*를 예로 들어 설명하시오.서술형
모범답안별표는 해당 명령·환경의 변형 버전을 뜻한다. \section*는 번호를 붙이지 않고 목차에도 자동으로 들어가지 않는 절을 만들고, figure*는 다단 레이아웃에서 그림이 모든 단을 가로질러 배치되게 한다.
Q4다음 중 스위치 명령(switch command)이 아닌 것은?객관식
  1. \centering
  2. \raggedright
  3. \color{red}
  4. \textcolor{red}{text}
정답 ④\textcolor는 두 번째 인자(괄호 안 텍스트)에만 색을 적용합니다. 나머지는 모두 블록 끝까지 효과가 이어지는 스위치 명령입니다.
Q5본문에서 그림 번호를 자동으로 참조하려면 어떤 명령들을 써야 하는가?서술형
모범답안figure 환경 안에 \label{fig:이름}으로 이름표를 붙이고, 본문에서 \ref{fig:이름}으로 참조한다. 그러면 그림 번호가 자동으로 채워지고, 그림 순서가 바뀌어도 번호가 알아서 갱신된다.
