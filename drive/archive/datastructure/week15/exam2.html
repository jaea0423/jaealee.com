이 문제집은 15주차 2차시 강의노트(기말 총망라) 범위로, 한 학기 전체를 아우르는 기말 모의고사 형태입니다. 9~14주차 핵심을 통합 점검합니다.
난이도·유형은 중간고사 족보 기준이며, 객관식 보기는 길이를 비슷하게 맞췄습니다.

  4. B-트리 (자식 수가 더 큼)

정답: 1, 2

AVL·레드블랙은 자식이 최대 2개라 BST입니다. 2-3-4와 B-트리는 한 노드에 자식이 2개를 넘을 수 있어 이진 트리가 아닙니다. (셋 다 O(log n)은 보장.)

Q2계산 · AVL 높이

높이 h인 AVL 트리의 최소 노드 수 점화식은 Nh = Nh−1 + Nh−2 + 1 (N₀=1, N₁=2)이다. N₆을 구하시오.

✎ 나의 답안
정답 / 풀이 보기

정답: N₆ = 33

N₂=4, N₃=7, N₄=12, N₅=20, N₆ = N₅+N₄+1 = 20+12+1 = 33. (이 점화식에서 Nh ≥ 2h/2를 유도해 h ≤ 2 log n, 즉 h = O(log n)을 증명합니다.)

Q3서술 · 증명 흐름

"AVL 트리의 높이가 O(log n)임을 증명하라"는 빈출 문제이다. Nh 점화식에서 시작해 h = O(log n)에 도달하는 핵심 흐름을 순서대로 쓰시오.

✎ 나의 답안
정답 / 풀이 보기

정답 요지 (6단계)

① Nh = Nh−1 + Nh−2 + 1 → ② Nh−1 ≥ Nh−2 이용해 Nh ≥ 2Nh−2 (+1 떼냄) → ③ 반복 적용 Nh ≥ 2k·Nh−2k → ④ k = h/2 대입 Nh ≥ 2h/2 → ⑤ 2h/2 ≤ Nh ≤ n에 log 취함 → h ≤ 2 log n → ⑥ h = O(log n).

  3. 레드 노드가 두 개 연속으로 올 수 없다

Part 2. 그래프 표현·순회

Q7객관식

인접 행렬과 인접 리스트의 공간복잡도로 옳은 것은? (n=정점, m=간선)

  1. 행렬 O(n+m), 리스트 O(n²)
  2. 행렬 O(n²), 리스트 O(n+m)
  3. 둘 다 O(n²)이다
  4. 둘 다 O(n+m)이다
✎ 나의 답안
정답 / 풀이 보기

정답: 2번

행렬은 간선 수와 무관하게 n×n 칸을 잡아 O(n²), 리스트는 실제 간선만 저장해 O(n+m). 희소 그래프에선 리스트가 공간 효율적입니다.

Q8객관식

  1. back edge가 하나라도 있으면 그래프에 사이클이 존재한다
  2. back edge는 DFS 트리에 반드시 포함되는 간선이다
  3. back edge가 많을수록 트리 높이가 낮아진다
  4. back edge는 무방향 그래프에서만 나타난다
✎ 나의 답안
정답 / 풀이 보기

정답: 1번

back edge는 이미 방문한 조상으로 되돌아가는 간선이라, 존재하면 그 경로가 닫혀 사이클이 생깁니다(back edge ⇔ 사이클). DFS로 사이클을 검사할 수 있습니다.

Part 3. 최단 경로

Q12빈칸 채우기

if dist[v] > dist[u] + w(u, v):
    dist[v] = ____________________
    parent[v] = ____
✎ 나의 답안
정답 / 풀이 보기

정답: dist[v] = dist[u] + w(u, v) / parent[v] = u

Q13객관식

"부분 경로 최단성(Optimal Substructure)"의 의미로 옳은 것은?

  1. 최단 경로의 일부 구간도 반드시 그 구간의 최단 경로이다
  2. 최단 경로는 항상 가장 적은 간선을 사용한다
  3. 그래프에는 최단 경로가 항상 하나뿐이다
  4. 부분 경로의 합은 전체 경로보다 항상 크다
✎ 나의 답안
정답 / 풀이 보기

정답: 1번

i→…→k→j가 최단이면 i→k, k→j도 각각 최단입니다. 이 성질 덕에 큰 문제를 작은 문제로 쪼개 풀 수 있고, BF·Dijkstra·Floyd 모두 이를 활용합니다.

Q14객관식

다익스트라가 음수 가중치 그래프에서 틀린 답을 낼 수 있는 이유로 옳은 것은?

  1. 음수 가중치를 더할 때 오버플로가 발생하기 때문이다
  2. 한 번 확정한 거리를 다시 보지 않는데, 음수 간선이 나중에 더 짧게 만들 수 있기 때문이다
  3. min-heap이 음수를 정렬하지 못하기 때문이다
  4. 음수 가중치는 인접 행렬에 저장할 수 없기 때문이다
✎ 나의 답안
정답 / 풀이 보기

정답: 2번

Dijkstra의 그리디는 "갈수록 거리는 늘기만 한다(양수)"는 가정에 기댑니다. 음수 간선은 나중에 거리를 더 줄일 수 있어 이미 확정한 값이 틀려집니다. 이런 경우 벨만-포드를 씁니다.

Q15객관식

벨만-포드의 동작과 음의 사이클 검출에 대한 설명으로 옳은 것은? (n=정점 수)

  1. 모든 간선을 n−1번 완화하고, 한 번 더 돌려 갱신되면 음의 사이클로 판정한다
  2. 가장 가까운 정점부터 deleteMin으로 확정해 나간다
  3. 음의 사이클이 있어도 항상 정확한 최단 거리를 낸다
  4. n²번 라운드를 돌아야 끝난다
✎ 나의 답안
정답 / 풀이 보기

정답: 1번

최단 경로는 간선을 최대 n−1개 쓰므로 n−1 라운드면 완성됩니다. 그 후 한 번 더 돌렸는데도 거리가 줄면 "돌수록 짧아지는" 음의 사이클이 있다는 증거입니다(이 경우 최단 경로 없음).

Q20객관식 · 종합

다음 중 알고리즘과 특성이 잘못 짝지어진 것은?

  1. 위상 정렬 — DAG에서 POST 값 내림차순으로 정렬
  2. Dijkstra — 음수 가중치 그래프에서도 항상 정확
  3. Floyd-Warshall — 모든 정점 쌍 최단 경로를 O(n³)에 계산
  4. DFS / BFS — 인접 리스트에서 O(n + m) 시간
✎ 나의 답안
정답 / 풀이 보기

정답: 2번 (잘못된 짝)

Dijkstra는 음수 가중치에서 정확하지 않습니다(음수 간선엔 벨만-포드). 나머지는 모두 맞는 설명입니다. 위상 정렬=POST 역순, Floyd=All-pairs O(n³), DFS/BFS=O(n+m).
