1차시확률의 기초

불확실성을 0과 1 사이의 수치로 측정하는 도구가 확률. 조건부 확률은 "어떤 조건이 주어졌을 때의 확률".

불확실성과 확률

정의 — 확률 (Probability) 불확실한 정도를 0과 1 사이의 수치로 측정하는 수학적 도구. 0에 가까울수록 불가능, 1에 가까울수록 확실, 0.5가 가장 불확실한 상태.
"차이가 있는 곳에는 그 차이를 재는 자가 따라온다. 불확실성에 차이가 있으니 그것을 측정하기 위해 확률이 필요하다." — 강태원 교수

"내가" vs "누군가"의 확률

로또 645의 1등 당첨 확률은 약 800만 분의 1(8,145,060분의 1). 그러나 이 확률은 "내가" 당첨될 확률이다. 매주 누군가는 1등에 당첨된다는 사실은 다른 의미.

시험 포인트 — 자세의 중요성 "내가의 확률"과 "누군가의 확률"을 구분해야 한다. 이를 혼동하면 큰 오류에 빠진다.

조건부 확률 (Conditional Probability)

정의 — 조건부 확률 "X라는 조건이 주어졌을 때 A가 일어날 확률". 기호: P(A|X). "|"는 "given"으로 읽음.
P(A|X) = P(A ∩ X) / P(X)

예시 — 쌍둥이 성별 문제

두 자녀가 있는 가정에서:

  • 두 자녀 모두 딸일 확률 P(둘 다 딸) = 1/4 (4가지 경우 중 1가지: 딸딸/딸아들/아들딸/아들아들)
  • "첫째가 딸"이라는 조건이 있을 때 둘 다 딸일 확률 P(둘 다 딸 | 첫째가 딸) = 1/2

같은 사건도 조건이 있느냐 없느냐에 따라 확률이 달라진다.

이산수학과의 연결 조건부 확률은 이산수학의 집합론·확률 공리의 응용이다. 표본 공간(Sample Space), 사건(Event), 합집합·교집합 개념이 그대로 사용된다.

2차시베이즈 정리 — 엄마는 고등어를 좋아해

관찰된 결과(고등어가 식탁에 있다)로부터 원인(어느 마트에서 사왔는가)을 추론하는 베이즈 정리.

베이즈 규칙 (Bayes' Rule)

베이즈 규칙 P(X|A)를 알 때 P(A|X)를 계산하는 식.
P(A|X) = P(X|A) · P(A) / P(X)

베이즈 정리 (Bayes' Theorem) — 일반화

여러 가능한 원인(A₁, A₂, …, Aₙ) 중 하나가 결과 X를 만들어 냈을 때, 각 원인의 확률을 계산:

P(Aᵢ | X) = [ P(X|Aᵢ) · P(Aᵢ) ] / [ Σⱼ P(X|Aⱼ) · P(Aⱼ) ]
용어영어의미
P(Aᵢ)Prior (사전확률)증거 보기 전 원인의 초기 확률
P(X|Aᵢ)Likelihood (우도)원인이 있을 때 결과가 나타날 확률
P(X)Evidence (증거)결과의 전체 확률
P(Aᵢ|X)Posterior (사후확률)증거를 본 뒤 원인의 갱신된 확률

"엄마는 고등어를 좋아해" 사례

엄마가 4개 마트(M1, M2, M3, M4) 중 하나에 가서 고등어를 사왔습니다. 어떤 마트에서 샀을 가능성이 가장 높을까?

입력 데이터:

마트P(마트i) — 방문 비율P(고등어|마트i) — 그 마트에서 고등어를 살 확률
M10.10.5
M20.20.2
M30.30.2
M40.40.1

계산 과정:

  1. 분모 P(고등어) = Σ P(고등어|Mᵢ)·P(Mᵢ) = 0.5·0.1 + 0.2·0.2 + 0.2·0.3 + 0.1·0.4 = 0.19
  2. P(M1|고등어) = 0.5·0.1 / 0.19 ≈ 0.26
  3. P(M2|고등어) = 0.2·0.2 / 0.19 ≈ 0.21
  4. P(M3|고등어) = 0.2·0.3 / 0.19 ≈ 0.32 ← 가장 높음
  5. P(M4|고등어) = 0.1·0.4 / 0.19 ≈ 0.21
★ 빈출 ★ 위 계산 결과 — 엄마가 자주 가는 마트는 M4(40%)지만, 고등어를 사왔다는 사실로부터 가장 가능성 높은 곳은 M3(32%). 사후확률이 사전확률을 뒤집을 수 있다.

암 진단 사례 — 정확성의 함정

"검사 정확성 99%"의 의미: P(양성 | 암) = 0.99. 암 환자 100명 중 99명을 정확히 진단.

그러나 환자가 정말 알고 싶은 것은: P(암 | 양성) — 양성 판정이 나왔을 때 실제로 암일 확률.

이 둘은 매우 다르다. 암 발병률이 1%라고 가정하고 베이즈 정리로 계산하면:

P(암 | 양성) = P(양성|암) · P(암) / P(양성) ≈ 1%

거짓 양성(False Positive) 때문에 실제 암일 확률은 의외로 낮다.

"검사 정확성 99%라고 해도 양성 판정 후 실제 암일 확률은 1%일 수 있다. 모든 답은 문제에 있다." — 강태원 교수

베이즈 정리의 현대적 응용

  • 스팸 필터(Spam Filter): 스팸 메일에서 자주 나오는 단어 학습 → 새 메일이 스팸일 확률 계산
  • 의료 진단: 증상으로 질병 추정
  • 음성 인식: 발음에서 단어 추정
  • 나이브 베이즈 분류기(Naive Bayes Classifier): 머신러닝의 기본 알고리즘
2주차 중국어 방과의 연결 "프로그램이 진짜로 이해하는가"에 대해 베이즈 추론은 또 다른 답을 준다 — 패턴 누적으로 미래를 예측하는 능력이 곧 학습이며 추론의 본질일 수 있다.

3차시퍼지 이론 (Fuzzy Theory) — 애매모호함의 수학화

"가깝다", "높다", "많다" 같은 언어적 모호함을 컴퓨터가 직접 처리하게 만드는 이론.

퍼지(Fuzzy)의 의미

"Fuzzy" = 영어로 흐릿한, 경계가 모호한. 1965년 Lotfi Zadeh(자데)가 제안한 이론. 인간 언어의 자연스러운 모호함을 수학적으로 표현.

[강의 시청 권장] 퍼지 멤버십 함수 그래프 — 키 vs "크다"의 멤버십 8주차 3차시 강의 영상 출처: 8주차 강의 슬라이드

확률 vs 퍼지

구분확률 (Probability)퍼지 (Fuzzy)
다루는 것사건 발생의 가능성경계의 모호함
예시"내일 비 올 확률 30%""키가 큰 편이다"
0~1의 의미발생 가능성의 정도집합에 속하는 정도
★ 시험 핵심 ★ 확률은 "일어날 가능성", 퍼지는 "속하는 정도". 다른 종류의 불확실성을 다룬다.

퍼지 집합 (Fuzzy Set)

퍼지 집합 원소가 집합에 속하는 정도를 0과 1 사이의 실수로 표현하는 집합. 일반 집합은 "속한다(1)/안 속한다(0)"의 이진 판단이지만, 퍼지 집합은 그 사이의 모든 값을 허용.

예 — "크다(Tall)" 집합에 속하는 정도:

키일반 집합 (170cm 기준)퍼지 집합
165cm0 (안 큼)0.2
170cm1 (큼)0.5
175cm1 (큼)0.8
185cm1 (큼)1.0

멤버십 함수 (Membership Function, μ)

멤버십 함수 μ_A(x) 원소 x가 퍼지 집합 A에 속하는 정도를 나타내는 함수. 0 ≤ μ_A(x) ≤ 1.
예: μ_큼(175cm) = 0.8 → "175cm는 '크다'에 80% 정도 속한다".

언어 변수 (Linguistic Variable)

변수의 값을 자연 언어 표현으로 나타냄. 예 — "온도"라는 언어 변수의 값:

  • "낮다(Low)", "중간(Medium)", "높다(High)"
  • 각각이 멤버십 함수로 정의됨

퍼지 추론 (Fuzzy Inference)

퍼지 규칙(Fuzzy Rule)과 입력값으로 출력을 도출하는 과정. 4단계:

  1. 퍼지화(Fuzzification): 구체적 수치(33℃) → 멤버십 함수값 (높다=0.8, 중간=0.2)
  2. 규칙 적용(Rule Application): 퍼지 규칙들을 적용
    • 예: IF 온도가 높고 AND 습도가 높으면 THEN 냉방을 강하게
  3. 집계(Aggregation): 여러 규칙의 결과 결합
  4. 비퍼지화(Defuzzification): 퍼지 결과 → 구체적 수치 출력. 보통 무게중심(Center of Gravity) 방식 사용

퍼지 추론 예시 — 냉난방기 제어

입력: 온도 33℃, 습도 58%, 밀폐도 4. 퍼지 규칙들 적용 후 출력: 냉방 강도 -2(약하게 냉방).

📍 강의 시청 권장 — 퍼지 추론 풀이 퍼지 추론의 단계별 풀이는 강의에서 시각적 자료로 설명됩니다. 퍼지화·집계·무게중심 비퍼지화는 영상으로 따라가는 것이 효과적입니다.

퍼지의 응용 — 가전제품

1990년대부터 일본·한국에서 퍼지 가전이 보편화:

  • 퍼지 세탁기 — 빨래의 양·종류·더러움 정도에 따라 자동 조절
  • 퍼지 에어컨 — 온도·습도·인원 수에 따라 자동 조절
  • 퍼지 자동초점 카메라
  • 지하철 자동 운행 — 일본 센다이 지하철(1980년대)
"퍼지 이론은 새로운 것이 아니다. 30년 전부터 퍼지 세탁기·에어컨 등이 상용화되었다. 다만 요즘은 '퍼지'라는 말을 덜 쓸 뿐이다." — 강태원 교수
1주차와의 연결 1주차에서 배운 "딱딱함 vs 부드러움"의 부드러움(Soft) 쪽이 곧 퍼지의 영역. 퍼지가 속한 분야를 강태원 교수의 메인 전공인 계산지능(Computational Intelligence) / 소프트 컴퓨팅(Soft Computing)이라고 부른다.

8주차 핵심 정리 (10가지)

  1. 확률(Probability): 불확실한 정도를 0~1 사이 수치로 측정. 0.5가 가장 불확실.
  2. "내가의 확률"과 "누군가의 확률"을 구분해야 함.
  3. 조건부 확률 P(A|X) = P(A∩X) / P(X). 조건이 있느냐 없느냐로 확률이 달라진다.
  4. 베이즈 규칙: P(A|X) = P(X|A)·P(A) / P(X). 역확률 계산.
  5. 베이즈 정리: 여러 원인 중 하나를 선택할 때 사후확률 계산. P(Aᵢ|X) = P(X|Aᵢ)·P(Aᵢ) / Σ P(X|Aⱼ)·P(Aⱼ).
  6. "엄마는 고등어를 좋아해" — 자주 가는 마트(M4, 40%)와 고등어를 사왔을 때 가장 가능성 높은 마트(M3, 32%)는 다를 수 있다.
  7. 암 진단 99% 정확성도 베이즈 정리로 보면 양성 후 실제 암일 확률은 매우 낮을 수 있다.
  8. 베이즈 정리 응용: 스팸 필터, 의료 진단, 음성 인식, 나이브 베이즈 분류기.
  9. 퍼지(Fuzzy): 언어의 모호함을 멤버십 함수로 수학화. 확률 ≠ 퍼지 (가능성 vs 속하는 정도).
  10. 퍼지 추론 4단계: 퍼지화 → 규칙 적용 → 집계 → 비퍼지화(무게중심). 가전 제어에 광범위 응용.
