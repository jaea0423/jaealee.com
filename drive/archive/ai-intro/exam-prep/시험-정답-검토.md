## 📖 상세 (문제·정답·근거·신뢰)

### 1. 서술형 — 유전형 vs 표현형 (라면 예시)
- **정답**: 유전형(Genotype)=라면의 DNA(0·1 이진코드, 예 0001) / 표현형(Phenotype)=그 코드가 발현돼 실제 만들어진 라면(예 0001→김 한 장, 0011→파 하나). 유전형을 해석(디코딩)하면 표현형이 되고, 표현형으로 맛(적합도)을 계산.
- **출처**: ALL-LECTURES 12주차
- **근거**: 사람 몸이 염색체 값으로 만들어지듯, 라면의 이진 DNA(유전형)→눈에 보이는 라면 모양(표현형). 유전 알고리즘 인코딩 개념.
- **신뢰**: C

### 2. AI 특징 중 옳지 않은 것
- **정답**: ④ 인공지능은 상황이 변해도 동일하게 반응한다
- **출처**: ALL-LECTURES 1주차
- **근거**: 강의 직접 — "똑같은 상황이 돼도 다음엔 다르게 둬서 승률을 높이는" 게 AI. 학습·적응이 핵심이라 "동일 반응"은 모순. ①②③⑤ 강의와 일치.
- **신뢰**: C *(원래 D → 강의 전문 확인 후 상향)*

### 3. 전문가 시스템 중 옳지 않은 것
- **정답**: ③ 모든 문제를 전문가 수준으로 해결하는 시스템이다
- **출처**: ALL-LECTURE-SUMMARIES 4주차
- **근거**: "모든 걸 잘하는 AI가 어려워서 특정 분야만 잘 처리하도록" 만든 게 전문가 시스템. '모든 문제' 아님.
- **신뢰**: B

### 4. 신경망·의미망 중 옳지 않은 2가지
- **정답**: ② 신경망은 논리식 형태의 규칙을 추출하는 최상의 기술 / ④ 의미망은 지식을 직관적으로 나타낼 수 없다
- **출처**: ALL-LECTURES 4주차
- **근거**: ② 신경망(연결주의)=블랙박스, 규칙추출은 기호주의 영역. ④ 의미망은 오히려 관계를 직관적으로 그림처럼 표현하는 게 장점.
- **신뢰**: C

### 5. 매개변수에 대응하는 것
- **정답**: ④ 가중치의 개수
- **출처**: ALL-LECTURES 5~7주차
- **근거**: "딥러닝 매개변수 = 가중치", "GPT 매개변수 1750억 개 = 가중치 개수" (교수 직접 표현).
- **신뢰**: C

### 6. 딥러닝과 가장 거리가 먼 것
- **정답**: ② k-means
- **출처**: ALL-LECTURES (개념 종합)
- **근거**: dropout·pooling(풀링)·convolution(중첩)·DNN 모두 강의에 딥러닝 용어로 등장. k-means는 군집화(10주차).
- **신뢰**: C *(원래 D → 드롭아웃·풀링·중첩이 강의에 직접 나옴 확인)*

### 7. 딥러닝 중 옳지 않은 것 ⚠️ 검토 필요
- **정답**: ⑤ 딥러닝은 잘못된 입력은 학습하지 못한다
- **출처**: 외부 (강의 직접 언급 없음)
- **근거**: 딥러닝은 입력 옳고그름을 가리지 않고 그대로 학습(garbage in, garbage out). ①②④는 강의와 일치. ③(프로그래밍 조금 알면 쉽다)은 강의가 도구 접근성을 강조해 참에 가까움.
- **신뢰**: D *(동일 문항 없음. ⑤가 가장 명백한 거짓이지만 단독 확정 근거 약함)*

### 8. 확률·퍼지 중 옳지 않은 것
- **정답**: ② 모든 불확실한 정도가 다르므로 불확실함의 차이를 측정할 수 없다
- **출처**: ALL-LECTURES 8주차 1차시
- **근거**: 강의 정반대 — "다르니까 오히려 재는 자(척도)가 생긴다". ①(베이즈) ③(퍼지 제어) ④(확률 1·0 둘다 확실) ⑤(퍼지=모호함 수학) 모두 맞음.
- **신뢰**: C

### 9. 유전 알고리즘 단계 순서
- **정답**: ③ 인코딩-모집단 구성-적합도 계산-선택
- **출처**: ALL-LECTURE-SUMMARIES 12주차
- **근거**: 교수 정리 — "인코딩 → 모집단 구성 → 적합도 계산 → 선택 연산 → 유전 연산".
- **신뢰**: B

### 10. 단순규칙 복잡성과 거리 먼 것
- **정답**: ④ 지역
- **출처**: ALL-LECTURES 13~14주차
- **근거**: 프랙털·보이드·생명게임·(세포)자동전파 모두 '간단한 규칙→창발' 예시. '지역'만 무관.
- **신뢰**: C

### 11. 생명 특징으로 옳지 않은 것
- **정답**: ① 생명체는 특정한 물질적 존재다
- **출처**: ALL-LECTURES 14주차
- **근거**: 인공생명은 생명을 물질이 아닌 정보·조직으로 봄. 강의도 "물질적 측면만 아니라 그 안의 정보". ②(작은 변화 둔감=자기회복력) ③(정보 저장소) ④(상호 종속) ⑤(성장) 모두 강의가 든 특징.
- **신뢰**: C
