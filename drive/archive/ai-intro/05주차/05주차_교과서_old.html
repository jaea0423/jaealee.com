1차시인공 뉴런 : 뼈만 추리자!

생물학적 뉴런은 너무 복잡해 모르는 게 더 많다. 공학적으로는 핵심만 추려낸 계산 모델이 인공 뉴런이다.

생물학적 뉴런 복습 → 인공 뉴런

4주차에서 배운 뉴런 = 몸통 + 수상돌기(Dendrite, 입력) + 축색돌기(Axon, 출력) + 시냅스(Synapse, 접합부). 인공 뉴런은 이를 단순화한 계산 모델(Computational Model)로 만들어진다 — "뼈만 추리자!".

[PDF 슬라이드 추출 가능] 인공 뉴런 다이어그램 (입력 X1...Xn, 가중치 W1...Wn, 출력 y) 5주차 1차시 7:00~12:00 출처: 5주차 강의 PDF

인공 뉴런의 구조

인공 뉴런 구성 요소 ① 입력 (X₁, X₂, …, Xₙ) — 여러 개
② 가중치 (Weight, W₁, W₂, …, Wₙ) — 시냅스에 해당. 각 입력에 곱해짐
③ 가중치 합 (Weighted Sum) — Σ Wᵢ·Xᵢ
④ 활성함수 (Activation Function) — 가중치 합을 출력으로 변환
⑤ 출력 (y) — 단 하나
★ 핵심 강조 ★ 입력은 여러 개, 출력은 단 하나(n:1). 출력 하나가 다음 뉴런 여러 개에 갈라져 가는 것은 별개. 한 뉴런이 내보내는 값은 1개.

가중치(Weight) = 시냅스

4주차에서 배운 시냅스의 신호 강도 조절이 인공 뉴런에서는 가중치(Weight)로 표현된다. 가중치를 매개변수(Parameter)라고도 부르며, ChatGPT 같은 모델의 "매개변수 수천억 개"라는 표현이 바로 이 가중치 수를 의미한다.

시냅스 ↔ 가중치 매핑 생물학적 시냅스의 수용체 수 → 인공 뉴런의 가중치 W. 학습 = 가중치 조정.

가중치 합 (Weighted Sum)

가중치 합 = X₁·W₁ + X₂·W₂ + ⋯ + Xₙ·Wₙ = Σᵢ Wᵢ·Xᵢ

각 입력에 가중치를 곱한 뒤 모두 더한 값. 이것이 뉴런이 받아들이는 "총 입력".

활성함수 (Activation Function)

가중치 합을 그대로 출력으로 보낼 수도 있지만, 보통은 활성함수를 거쳐서 출력한다. 대표적인 3가지:

활성함수형태설명
계단함수 (Step Function) 0 또는 1 (또는 -1) 입력이 임계값 이상이면 1, 아니면 0. 가장 간단
시그모이드 (Sigmoid) 1 / (1 + e⁻ˣ) S자 곡선. 출력은 항상 0~1 사이의 값
ReLU (Rectified Linear Unit) max(0, x) 0 이하는 0, 양수는 그대로. 딥러닝 시대의 표준

바이어스(Bias) 입력

인공 뉴런에는 항상 정해진 값(보통 -1)이 들어가는 추가 입력이 있는데, 이를 바이어스(Bias) 입력이라 한다. 외부 입력과 무관하게 뉴런 내부에서 자동 적용되며, 사람의 무의식 정보에 비유됨. 학습에 매우 중요한 역할을 하므로 모든 실제 신경망에 포함되어 있다.

가중치 합(바이어스 포함) = Σᵢ Wᵢ·Xᵢ + (-1)·θ = Σᵢ Wᵢ·Xᵢ − θ

여기서 θ(theta)는 바이어스 가중치. 출력 y = 활성함수(가중치 합).

시험 포인트 · 빈출 인공 뉴런 4용어: 가중치(Weight) / 가중치 합(Weighted Sum) / 활성함수(Activation Function) / 바이어스(Bias). ChatGPT의 "매개변수" = 가중치 수.

2차시인공신경망 : 줄을 잘 서야 들어가요!

실제 뇌의 뉴런은 자유분방하게 얽혀 있지만, 컴퓨터 계산을 위해 층(layer) 단위로 줄을 맞춰 연결한 것이 다층 신경망.

간단한 인공 뉴런 출력 계산 — A 아기

예시: 입력 2개, 가중치 W₁=1, W₂=1, θ=1.5, 활성함수=Step Function인 뉴런 1개를 가진 "A 아기".

가중치 합 = X₁·W₁ + X₂·W₂ − θ = X₁·1 + X₂·1 − 1.5
입력 (X₁, X₂)계산출력 y
(1, 1)1+1−1.5 = 0.5 ≥ 01
(0, 0)0+0−1.5 = -1.5 < 00
(1, 0)1+0−1.5 = -0.5 < 00
(0, 1)0+1−1.5 = -0.5 < 00

이는 사실 AND 게이트와 같은 동작 — X₁ AND X₂일 때만 1을 출력.

"3살 버릇 여든 간다" — 뇌의 가소성과 한계

강의에서 신생아 → 1개월 → 9개월 → 2세 → 성인의 뇌 사진을 비교. 약 3살까지 뇌의 구조가 활발히 발달하고 그 이후로는 구조가 거의 변하지 않는다. 학습은 시냅스의 변화로 일어남. 한국 속담 "3살 버릇 여든 간다"는 이를 시사한다.

다층 신경망 (Multi-Layer Neural Network)

실제 뇌는 자유분방하게 연결되어 있지만, 컴퓨터로 처리하려면 줄(층)을 맞춰야 효율적이다. 그래서 층 단위로 뉴런을 배치한 것이 다층 신경망.

3종류의 층 ① 입력층(Input Layer) — 외부 입력을 받음. "헛개비"(가중치 없음, 그냥 다음 층으로 값을 뿌려줌)
② 중간층/은닉층(Hidden Layer) — 입력층과 출력층 사이의 층. 1개 이상
③ 출력층(Output Layer) — 최종 결과를 내보냄

전진 전파 (Feed Forward)

한 층의 뉴런 출력이 다음 층의 모든 뉴런으로 전달된다. "이웃(다음 층)에만 공평하게" 모두 보낸다 — 이것이 완전 연결(Fully Connected, FC)이다.

★ 시험 빈출 ★ ① 전진 전파(Feed Forward): 한 층 → 다음 층으로만 정보 전달
② 완전 연결(Fully Connected): 한 뉴런의 출력이 다음 층 모든 뉴런으로 빠짐없이 전달
③ 입력층은 헛개비: 가중치가 없고 값을 그대로 다음 층으로 전달

출력 계산 원리

한 뉴런의 출력 = 활성함수(가중치 합). 여러 뉴런이 층을 이뤘을 때는 입력층 → 중간층 → 출력층 순서로 차례차례 계산한다.

자료구조와의 연결 다층 신경망은 방향성 비순환 그래프(Directed Acyclic Graph, DAG)의 일종 — 자료구조에서 배운 그래프 표현이 그대로 적용됨.

3차시다층신경망의 출력 계산 — B 아기

중간층 1개를 가진 작은 다층 신경망에 입력을 넣어 출력을 직접 계산해 본다.

예제 신경망 구조

구조: 입력층 2개 + 중간층 2개 + 출력층 1개. 뉴런 번호 1, 2(입력), 3, 4(중간), 5(출력).

X₁(1) ──→ ●3 (Y₃) ──→ ╲ ╲ ╲ ╲ X₂(2) ──→ ●4 (Y₄) ──→ ●5 (Y₅) ── 출력

가중치:

  • 입력층 → 중간층: W₁₃ = 0.5, W₁₄ = 0.9, W₂₃ = 0.4, W₂₄ = 1.0
  • 중간층 → 출력층: W₃₅ = -1.2, W₄₅ = 1.0
  • 활성함수: 시그모이드(Sigmoid) — y = 1 / (1 + e⁻ˣ)
  • 입력: X₁ = 1, X₂ = 1

단계 1 — Y₃ 계산

가중치 합 = X₁·W₁₃ + X₂·W₂₃ = 1·0.5 + 1·0.4 = 0.9
Y₃ = 1 / (1 + e-0.9) ≈ 0.7

단계 2 — Y₄ 계산

가중치 합 = X₁·W₁₄ + X₂·W₂₄ = 1·0.9 + 1·1.0 = 1.9
Y₄ = 1 / (1 + e-1.9) ≈ 0.9

단계 3 — Y₅ 계산 (최종 출력)

가중치 합 = Y₃·W₃₅ + Y₄·W₄₅ = 0.7·(-1.2) + 0.9·1.0 = -0.84 + 0.9 = 0.06
Y₅ = 1 / (1 + e-0.06) ≈ 0.5

최종 결과: 입력 (1, 1) → 출력 ≈ 0.5.

시험 포인트 — 계산 절차 ① 한 뉴런의 출력 = 활성함수(가중치 합)
② 가중치 합 = Σ Xᵢ·Wᵢⱼ
③ 시그모이드 = 1/(1+e⁻ˣ), 출력 0~1 사이
④ 입력층부터 출력층까지 차례로 계산 (Feed Forward)

오일러 상수 e

시그모이드 함수의 e는 오일러 상수(Euler's number, e ≈ 2.71828). π(원주율)처럼 무한소수의 자연상수. Windows 계산기의 공학용 모드에서 e와 거듭제곱(xʸ) 기능으로 계산 가능.

ChatGPT와의 연결 ChatGPT에 프롬프트를 넣으면 결과가 나오는 것 → 사실은 신경망 내부에서 이런 가중치 합·활성함수 계산이 수천억 번 일어나는 것. 매개변수(가중치) 수가 그만큼 많기 때문.

5주차 핵심 정리 (10가지)

  1. 생물학적 뉴런 → 단순화한 계산 모델 = 인공 뉴런("뼈만 추리자").
  2. 인공 뉴런: 입력 여러 개, 출력 단 하나(n:1).
  3. 가중치(Weight) = 시냅스의 신호 강도. 신경망 학습 = 가중치 조정.
  4. 가중치 합(Weighted Sum) = Σ Wᵢ·Xᵢ.
  5. 활성함수: 계단함수(Step) / 시그모이드(Sigmoid, 1/(1+e⁻ˣ)) / ReLU.
  6. 바이어스(Bias) 입력 = 항상 -1 같은 고정값. 학습에 필수. 모든 실용 신경망에 포함.
  7. 매개변수(Parameter) = 가중치 수. ChatGPT의 "수천억 매개변수"가 이것.
  8. 다층 신경망(MLNN): 입력층(헛개비) → 중간층(은닉층) → 출력층.
  9. 완전 연결(Fully Connected) + 전진 전파(Feed Forward)가 표준 구조.
  10. 출력 계산은 입력층부터 출력층까지 층 단위로 차례차례 가중치 합 + 활성함수 적용.
