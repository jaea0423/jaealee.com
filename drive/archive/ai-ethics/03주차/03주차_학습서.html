1. 편향성 (Bias)

★★★ 족보 출제 · 편향 vs 편견 ★★★ 출제
편견(Prejudice)편향(Bias)
본질심리적 고정관념구조적 기울어짐
발생개인 경험시스템 자체
행동태도 수준자동으로 행동 성향 야기

족보 정답 보기: "편향은 특정 행동 성향을 자동으로 야기할 수 있다."

알고리즘 편향 (Algorithmic Bias)
데이터의 선택·수집·분류·활용 또는 알고리즘 구성 과정에서 공평하지 않은 기준이 개입되는 것.

대표 사례

사례핵심
구글 이미지 (2015)흑인 여성을 고릴라로 분류 — 백인 중심 데이터
니콘 카메라아시아인 눈을 감긴 눈으로 오판 — 서구인 중심
COMPAS (플로리다 재범예측)인종 변수 없음에도 흑인 고위험 분류 확률 2배 — 대리 변수(Proxy) 작동
EVAAS (교사 평가)블랙박스로 점수 이유 불명, AI 점수만으로 교사 해임
애플카드 (2019)여성 한도가 남성의 1/10. 골드만삭스도 설명 불가

편향 완화

  • 맥락 기반 설계: 어디서·누구를 위해·무슨 목적인지 설계 단계부터 고려
  • 설명 가능 AI(XAI): 코넬대 연구
  • GDPR (2018, EU): AI 결정 근거 요구권 + 데이터 삭제권

2. 투명성 (Transparency)

블랙박스 (Black Box)
입력과 출력은 보이지만 그 사이의 과정은 어둠 속에 가려진 존재. 딥러닝의 본질적 한계.

투명성-성능 딜레마

AI가 정교해질수록 내부는 복잡 → 설명 어려움. 단순화하면 성능 하락. 복잡한 모델일수록 설명 가능성 낮아짐(강의 확인문제 출제).

3. 설명 가능한 AI (XAI · Explainable AI)

XAI (Explainable AI)
AI의 판단 이유를 사람이 이해할 수 있는 방식으로 제시하는 인공지능. 블랙박스 AI의 반대 개념. 2017년 미국 DARPA(국방고등연구계획국)가 공식 제안.
★★★ 족보 출제 · XAI 효과 ★★★ 출제

XAI의 효과 (적절한 것):

  • ✅ AI 의사결정뿐 아니라 인공지능 모형에 대해 이해 가능해진다
  • ✅ 판단의 강점·약점을 분석할 수 있다
  • ✅ 인간 개입 시점을 계획할 수 있다
  • ✅ 인간 간의 이해를 증진할 수 있다 (인간↔AI 상호이해)
  • ✅ 오류를 지속 수정해 AI 학습 향상

⚠️ 족보 함정 — 적절하지 않은 것: "주어진 알고리즘을 예측할 수 있다" → 정답. XAI는 결과·판단의 '이유'를 설명하는 기술이지, 알고리즘 자체의 출력을 예측하는 기술이 아님.

AI 신경과학 (AI Neuroscience)

  • 유전자 연구처럼 AI 내부를 해부.
  • Optimizing Mind: AI 신경망을 인간 뇌에 대응시켜 시각화.
  • 조지아 공대 실험: 두 AI로 인간 언어 ↔ 기계 언어 번역 훈련.

4. 책임(Responsibility) vs 책무성(Accountability)

★★★ 족보 출제 · 책무성 ★★★ 출제
책임 (Responsibility)책무성 (Accountability)
본질법적·제도적 귀속행위·결정의 설명·정당화 의무
시점사후 (잘못 발생 후)사전 (사고 예방)
질문"누가 잘못했나""왜·어떻게 판단했나"

족보 단답: "인공지능이 자율 시스템이 되면서 ( ? )의 측면이 더 중요해진다. ( ? )이란 특정 이해 당사자가 자신의 행위와 관련한 책임과 의무를 식별하고 설명하거나 행위의 정당성에 대한 물음에 답하는 것이다." → 답: 책무성

★★★ 족보 단답 · 설명 가능한 ★★★ 출제

"( ? ) 인공지능은 판단에 대한 이유를 사람이 이해할 수 있는 방식으로 제시하는 인공지능을 일컫는다. 특정한 판단에 대해 알고리즘의 설계자조차도 그 이유를 설명할 수 없는 '블랙박스' 인공지능과 대비되는 개념이다." → 답: 설명 가능한

5. 투명성 ↔ 책무성 관계 (★★★ 족보)

★★★ 족보 출제 · 투명성·책무성 옳지 않은 것 ★★★ 출제

옳은 진술 (정상적 관계):

  • ✅ 투명성과 책무성은 '관련성'만 있을 뿐 '인과 관계'는 아니다.
  • ✅ 투명성이 높아진다고 자동적으로 책무성이 확보되는 것은 아니다.
  • ✅ 학습 과정의 문제보다 데이터의 내용이 편향될 수 있으므로 알고리즘 공개를 해도 어느 부분이 잘못인지 잘 설명되지 않을 수 있다.

⚠️ 옳지 않은 진술 (정답): "투명성이 높아지면 책무성과 책임 부여가 오히려 어려워진다."

→ 투명성이 책무성을 어렵게 만드는 게 아님. 다만 자동 보장하지 않을 뿐.

6. AI 발명자 인정 (★★★ 족보)

★★★ 족보 객관식 · 정답 두 개 ★★★ 출제

인공지능이 발명자로 인정받기 위해 고려해야 할 두 가지 사항:

  1. ✅ 인공지능이 법인격(Legal Personhood)을 가질 수 있는가?
  2. ✅ 인공지능의 창작이 발명이 될 수 있는가?

오답: "발명품이 고부가가치 제품인가" / "인간 같은 지능을 갖고 있는가"

7. 책임 분산 + DEKA Arm

책임 분산 (Distributed Responsibility)

  • 지능형 재산(Intelligent Property): 보조형 AI(자율주행 레벨 2~3) — 인간 책임. IEEE 권고.
  • 인간-AI 결합: 인공지능 의수(DEKA Arm) — 누구 행위인지 구분 불가.
  • 분산: 설계자·제작자·데이터 제공자·운영자에 책임 흩어짐.

DEKA Arm 법적 쟁점

  • 물건이면 → 손상 시 기물파손
  • 신체 확장이면 → 과실치상(인체 상해)

8. 책무성 6조건 + 점검 6항목

책무성 부여 6조건

  1. 사용 목적 — 의료용·광고용 등
  2. 데이터 소스 — 출처·품질 기록
  3. 알고리즘 구조 — 논리·절차 설명
  4. 프로세스 그래프 — 활동 로그
  5. 사용자 인터페이스 — 인간 개입 지점
  6. 출력 단계(Actuator) — 행동 결과 기록

책임 평가 점검 6항목

  1. 판단 근거
  2. 데이터 선택 기준
  3. 데이터 한계
  4. 의도하지 않은 편향
  5. 데이터 분류 개입자
  6. 숨겨진 불확실성
