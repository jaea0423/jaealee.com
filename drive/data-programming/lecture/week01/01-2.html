02데이터 분석의 이해

데이터(Data)는 객관적 사실(Fact) 혹은 정보를 표현(Representation)한 것입니다. 숫자·문자·이미지·오디오·동영상 등 우리가 표현할 수 있는 것은 모두 데이터가 될 수 있습니다 — 키, 몸무게, 텍스트, BMI, 우리가 하는 말(음성 데이터)까지도 수집해서 분석할 수 있으면 전부 데이터입니다.

데이터 자체만으로는 가치가 없습니다

데이터를 가공하고 분석해서 인사이트를 도출해야 실제로 문제를 해결하거나 의사 결정에 쓸 수 있는 가치가 생깁니다. 데이터 분석이란 문제 해결 또는 인사이트 도출을 위한 목적으로 데이터 수집, 전처리(가공), 정형화를 통해 현상을 분석하는 과정입니다.

교수님 말씀 — 데이터와 정보의 차이

데이터는 석유와 같은 원재료입니다. 석유 자체를 자동차에 넣으면 고장 나지만, 정제해서 휘발유·등유가 되면 쓸 수 있는 것처럼, 데이터도 가공하고 분석해야 비로소 정보로서 가치가 생깁니다.

데이터 분석은 다양한 기술을 조합해 비즈니스, 과학, 사회과학 등 여러 분야에 쓰이며, 의사 결정을 더 과학적이고 효율적으로 만드는 데 중요한 역할을 합니다.

필기 원문
데이터는 객관적 사실 혹은 정보를 표현한 것을 말함 (데이터라는 건 우리가 표현할 수 있는건 모두 데이터라고 할 수 있음.(키,몸무게,텍스트,BMI, 우리가 하는 말(음성데이터) 등))(수집해서 분석할 수 있는 건 모두 데이터) 데이터 자체만으론느 가치가 있지는 않음(가공, 분석, 인사이트 도출을 해야 실제로 문제에 대해서 해결하거나 의사결정에 사용한다던지 가치가 생기게 됨) 데이터와 정보의 차이는? 데이터는 석유와 같이 원재료라고 볼 수 있음. 석유 자체를 넣으면 자동차가 고장나지만 가공해서 휘발유, 등유 등이 돼서 사용할 수 있게 되는 것 처럼 데이터도 가공하고 분석해야 정보로서 가치가 생기게 됨 (교안 PDF: 데이터 분석의 이해 — 데이터 분석 정의, 참고문헌: 데이터 분석을 위한 전처리와 시각화 with 파이썬)

04인공지능의 발전

하드웨어 발전과 더불어 알고리즘, 즉 인공지능 자체의 발전도 함께 일어났습니다. 데이터가 너무 많아지면서 사람이 직접 하나하나 분석하는 것은 사실상 불가능해졌고, 이 지점에서 LLM, Stable-Diffusion 같은 인공지능 기술이 등장했습니다.

LLM이란? — 교수님이 이름만 언급, 제가 풀어씀

거대언어모델(LLM, Large Language Model)은 방대한 양의 텍스트 데이터를 학습해 사람이 쓰는 자연어를 이해하고 생성할 수 있는 인공신경망 모델입니다. 질문에 답하거나 글을 쓰는 등, 이전에는 사람이 직접 해야 했던 언어 작업을 대신 수행할 수 있습니다. ChatGPT, Claude 같은 서비스가 LLM을 기반으로 합니다.

Stable-Diffusion이란? — 교수님이 이름만 언급, 제가 풀어씀

텍스트로 된 설명을 입력하면 그에 맞는 이미지를 생성해주는 확산 모델(Diffusion Model) 기반의 생성형 AI입니다. 노이즈(무작위 잡음)로 가득 찬 이미지에서 점차 노이즈를 제거해나가며 원하는 이미지를 만들어내는 방식으로 작동합니다.

스케일링 법칙 (Scaling Law)

모델의 사이즈와 학습 데이터의 크기를 키울수록 모델의 성능이 증가한다는 경향을 스케일링 법칙이라 부릅니다. 실제로 자연어처리(NLP) 모델의 크기는 매년 약 10배씩 증가해왔습니다.

05데이터 분석의 필요성

교수님 강조

1. 현상의 이해

데이터를 분석하면 현상이나 현재 상황, 트렌드를 파악할 수 있습니다. 예를 들어 사람들의 검색 키워드를 분석해 지금 어떤 트렌드가 뜨고 있는지 파악할 수 있습니다.

2. 인사이트 도출

인사이트(Insight)는 데이터의 기본적인 통계를 넘어 잠재적인 의미를 분석해 찾아낸 지식과 지혜를 뜻합니다. 관련 유튜브 영상이 교안에 링크돼 있었지만 비공개 처리되어 수업에서는 재생하지 못하고 넘어갔습니다.

3. 의사결정 판단 — A/B Test

A/B Test는 회사에서 널리 쓰이는 검증 방법입니다. 신제품이나 신기능(UI/UX 변경 포함)을 버전 2로 내놨을 때, 사람들이 실제로 좋아할지 아니면 오히려 더 싫어할지는 미리 알기 어렵습니다. 그래서 일부 사용자를 무작위로 샘플링해 테스트합니다.

진행 방식 예시

사용자 1만 명을 샘플링(당사자는 모름)해 절반은 구버전, 절반은 신버전을 사용하게 한 뒤, 그룹별 사용 시간 등을 분석해서 전체 배포 여부를 결정합니다. 모든 유저에게 한 번에 배포하지 않고, 이렇게 검증 과정을 거치는 것이 핵심입니다.

4. 문제 해결

2차 세계대전 당시의 전투기 생존 분석은 데이터 분석에서 대표적인 문제 해결 사례로 꼽힙니다. 전투기가 피격되더라도 아군 기지까지 무사히 돌아오게 하려면 어디에 장갑을 더 둘러야 할지가 문제였습니다. 처음에는 "귀환한 전투기의 피격 부위를 분석해서, 그 부위에 장갑을 보강하자"는 접근이 나왔습니다.

확증(생존자) 편향 — 실제로는 반대가 정답

이 접근은 생존자 편향(Survivorship Bias)에 빠진 것으로 밝혀졌습니다. 분석 대상이 귀환에 성공한 전투기였기 때문에, 그 전투기들이 피격당한 부위는 오히려 맞아도 추락하지 않는 부위였습니다. 진짜 보강해야 할 곳은 귀환한 전투기에서 피격 흔적이 거의 없는 부위 — 즉 그곳을 맞은 전투기는 애초에 돌아오지 못했을 가능성이 높은 부위입니다. 데이터를 잘 수집·분석했다고 믿어도, 편향이 있으면 엉뚱한 결론에 이를 수 있다는 것을 보여주는 사례입니다.

추천 시스템(알고리즘)을 통한 매출 증대도 문제 해결의 예입니다. 예를 들어 유튜브 영상 추천 시스템의 성능이 10%(추천 10개 중 1개를 실제로 시청)라고 할 때, 이 성능이 단 1%p만 올라가도 유튜브·구글의 매출이 수천억 원 단위로 증가할 수 있습니다.

상품 메타데이터상품, 비디오, 상품 상세 내용
사용자 메타데이터나이, 위치

5. 데이터의 가공

데이터를 가공한 뒤 분석하는 것이 일반적이지만, 가공된 데이터가 올바른지 확인하고 다시 가공(수정)하는 과정이 반복적으로 순환됩니다. 노이즈 데이터 필터링, 전처리 코드 개선 등을 거치며 데이터 분석의 품질이 높아집니다.

편향도 가공 과정에서 제거할 수 있습니다

여론조사처럼 랜덤 샘플링을 했더라도, 특정 지역 응답자가 표본의 70%를 차지하는 식으로 샘플링이 한쪽으로 쏠릴 수 있습니다. 이런 편향은 가공·재검토 과정에서 발견하고 바로잡아야 합니다.

6. 인공지능 모델 학습

학습 데이터가 편향되거나 노이즈가 심하거나 이상 데이터가 많이 섞여 있으면 AI 모델의 성능이 떨어질 수 있습니다. 그래서 데이터 분석은 AI 모델 학습에도 필수적입니다.

정형 · 비정형 · 반정형 데이터

데이터는 크게 정형 데이터와 비정형 데이터로 나눌 수 있습니다.

구분정의예시
정형 데이터(Structured)각 특성이 정해진 데이터 타입·카테고리·크기로만 구성학생 성적, 키·몸무게 데이터, 위 선수 테이블
비정형 데이터(Unstructured)정형 데이터가 아닌 데이터. 타입·크기가 가변적뉴스 텍스트, 이미지, 음성 데이터
반정형 데이터(Semi-structured)정형과 비정형이 혼재된 데이터영화 리뷰(리뷰 텍스트는 비정형 + 평점은 정형)
교수님 말씀 — 정형/비정형의 경계는 딱 자르기 애매합니다

테이블 데이터는 넓은 범주에서 정해진 행·열로 이루어져 있어 정형 데이터로 봅니다. 하지만 같은 테이블 안에서도 이름처럼 자유롭게 바뀌는 문자열은 비정형에 가깝고, 팀 이름처럼 카테고리 종류가 정해져 있으면 정형으로 볼 수 있습니다. 이미지 데이터도 크기가 고정돼 있다면 정형 데이터로 볼 수 있습니다 — 이미지 안의 각 셀(픽셀)마다 정해진 타입의 값이 들어가기 때문입니다.

비정형 데이터는 정형 데이터에 비해 다루기가 까다롭습니다(전처리 코드가 더 복잡해짐). 텍스트 데이터의 경우 길이가 가변적이고, 최소 정보 단위를 규정하기 어렵다는 특징이 있습니다.

필기 원문
Sample(Instance)는 데이터 각각의 표본(테이블에서 행) Feature(Attributes)는 각 표본의 특성(키, 몸무게 등)(테이블에서 열) 데이터는 크게 정형 데이터와 비정형데이터로 나눌 수 있음 정형 데이터 : 정해진 타입으로만, 정해진 길이, 크기, 카테고리등으로 이루어져있음(테이블 데이터가 정형데이터라고 볼 수 있음(학생 성적, 키, 몸무게 등)(무조건은 아니고 넓은 범주 안에서 정해진 행과 열로 이루어져있기 때문에 정형데이터라고 볼 수느 ㄴ있음. 근데 이름 같은 가변적인 스트링이라고 볼 수 있는데 이건 비정형이라고도 볼 수 있음)(팀 이름처럼 팀 종류나 이름이 딱 정해져있다면 이건 정형데이터라고 볼 수 있음)(테이블 말고도 대표적으로 이미지 데이터도 정형 데이터라고 할 수 있음(크기가 정해져있다면)(이미지 안에 있는 셀들마다 정해진 타입으로 값이 들어가기 때문에) 비정형 데이터는 정형 데이터가 아닌 데이터 타입과 크기가 가변적임 대표적으로 문자열(SNS에 올리는 글 등), 음성 데이터 등이 있음 비정형데이터는 정형데이터에 비해 다루기가 조금 까다로움(전처리 코드 등) 반정형데이터 : 정형과 비정형이 혼재돼있는 경우(아까 말한 이름 같은 경우) 영화 리뷰도 반정형(리뷰 텍스트는 비정형, 평점은 정형) (교안 PDF: "데이터의 이해" — Sample/Feature 표, GDP 표, ratings_train 표)

09데이터의 표현

교수님 강조

데이터를 컴퓨터로 분석하려면 컴퓨터에 넣을 수 있는 형태 — 즉 수치 데이터로 변환해야 합니다. 특히 AI 모델에 입력으로 넣을 때는 벡터로 변환해서 넣습니다. 이렇게 컴퓨터가 읽을 수 있게 데이터를 처리하는 것을 데이터 표현(Data Representation)이라 부릅니다.

벡터란? — 제가 간단히 풀어씀

벡터(Vector)는 숫자를 순서대로 나열한 목록입니다. 예를 들어 (0.33, 1.00, −1.23)처럼 여러 개의 숫자가 정해진 순서로 묶인 것이 벡터입니다. 데이터 분석에서는 하나의 샘플이 가진 여러 특성값을 이 순서대로 나열해서 벡터로 표현합니다.

Data Representation은 데이터를 설명하거나 사용 가능하게 표현하는 것입니다. 컴퓨터로 데이터를 분석하려면 컴퓨터가 이해할 수 있게 표현해야 하고, 서로 다른 데이터는 서로 다르게 표현될 수 있어야 합니다. 그래서 각 sample 혹은 feature를 숫자, 특히 벡터(Vector)·행렬(Matrix)로 표현하는 것이 중요합니다.

원본 정보벡터화 결과(예시)
이름: 김철수 / 나이: 25 / 성별: 남 / 국적: 대한민국 / 키: 170 / 몸무게: 75 …(0.3331, 0.2323, 1.0093, −1.2322, −0.4431, 2.3331, 0.3571, 0.3315, 0.9961)

텍스트 데이터 표현

텍스트 데이터를 표현하는 방법에는 여러 가지가 있으며, Bag-of-words(BoW), 임베딩(Embedding), 모델 기반 표현 등이 있습니다.

"나는 학교에 간다"라는 문장은 먼저 '나', '는', '학교', '에', '간다'로 나뉩니다. 이를 단어 빈도로 표현하면 다음과 같은 Bag-of-words 표가 됩니다.

Bag-of-words 벡터의 한계

이 표부터도 벡터라고 할 수 있지만, 실제로는 0이 아주 많은 희소 벡터(sparse vector)가 됩니다. 이런 벡터를 그대로 쓰기는 어려워서, 머신러닝 등 별도 기법을 거쳐 더 조밀한(dense) 벡터로 다시 표현합니다.

이미지 데이터 표현

이미지는 픽셀 단위로 숫자를 표현합니다. 디스플레이에는 RGB(Red, Green, Blue — 빛의 삼원색처럼 섞을수록 밝아짐), 인쇄물에는 CMYK(Cyan, Magenta, Yellow, Black — 물감처럼 섞을수록 어두워짐) 방식을 주로 사용합니다.

채널6×6 예시 값(일부)
R-channel51, 23, 81, 143, 201, 154, 77 …
G-channel10, 127, 51, 123, 251, 14, 76 …
B-channel15, 27, 51, 143, 201, 14, 76, 53 …

이미지 데이터를 표현할 때는 주로 RGB 방식을 사용합니다. 가로·세로 6×6 이미지라면 R·G·B 각 채널마다 6×6 행렬이 하나씩 있어 총 3개 층(channel)으로 표현됩니다. 이 수치 데이터를 머신러닝 등 과정을 거쳐 이미지를 대표하는 벡터 값으로 변환합니다. (출처: researchgate.net)

벡터 공간 — 교수님이 선형대수 선행지식을 전제로 넘어가심, 제가 풀어씀

벡터 공간(Vector Space)은 벡터들이 놓이는 좌표 공간을 뜻합니다. 각 데이터는 이 벡터 공간 상의 한 점(또는 화살표)으로 위치할 수 있으며, 비슷한 특성을 가진 데이터끼리는 벡터 공간에서 서로 가까운 위치에 놓이게 됩니다.

데이터 시각화 — 벡터 공간을 눈으로 보기

고차원 벡터를 2차원으로 차원 축소(Dimension Reduction)하면 데이터를 시각적으로 확인할 수 있습니다. t-SNE로 손글씨 숫자 데이터를 2차원에 시각화한 예시를 보면, 같은 숫자는 서로 매우 가까운 위치에, 많이 다른 글씨체는 멀리, 비슷하게 헷갈리는 필기(3과 9 등)는 비교적 가까운 위치에 모입니다.

같은 방식으로 이미지를 벡터화해 시각화한 예시(비슷한 주제의 사진끼리 군집)와, 논문 기사를 벡터화해 시각화한 예시(토픽 모델링 후 t-SNE로 2차원 축소, 비슷한 토픽의 기사끼리 군집)를 함께 살펴봤습니다.
