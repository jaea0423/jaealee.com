AVL 트리 — 집중 예상문제

정의·균형인수 · 회전 4유형 · 높이 증명 · 삽입/삭제

AVL 단원 전 범위를 다룹니다. 추적·계산·표 채우기 유형이 많으니 직접 손으로 풀어 답을 적고, 정답/풀이로 대조하세요. (잎 노드 높이 0, 빈 서브트리 높이 −1 약속)
Q1AVL복수선택

다음 중 AVL 트리에 대한 설명으로 옳은 것을 모두 고르시오.

  1. 모든 노드에서 균형 인수 |BF| ≤ 1을 만족한다.
  2. 균형 조건만 만족하면 BST가 아니어도 된다.
  3. 최악의 경우에도 탐색 시간은 O(log n)이 보장된다.
  4. 역사상 최초로 나온 자가 균형 이진 탐색 트리이다.
✎ 나의 답안
정답 / 풀이 보기

정답: 1, 3, 4

2번 틀림 — AVL은 BST 조건(왼쪽 < 루트 < 오른쪽)을 그대로 지키면서 균형 조건이 추가된 것이므로 반드시 BST입니다. AVL은 높이가 O(log n)으로 제한돼 최악에도 탐색이 O(log n)이고(3번), Adelson-Velsky & Landis(1962)가 만든 최초의 자가 균형 BST입니다(4번).

Q2AVL빈칸 채우기

균형 인수(Balance Factor)의 정의를 완성하시오.

BF(v) = height(________ 서브트리) − height(________ 서브트리)

또한 AVL 조건을 만족하는 노드의 BF로 가능한 값을 모두 쓰시오.

✎ 나의 답안
정답 / 풀이 보기

정답: 왼쪽, 오른쪽 / 가능한 BF 값 = −1, 0, +1

BF(v) = height(왼쪽 서브트리) − height(오른쪽 서브트리). AVL 조건은 모든 노드 v에 대해 |BF(v)| ≤ 1이므로 BF는 −1, 0, +1 셋 중 하나입니다.

Q3AVL계산

어떤 노드 v의 왼쪽 서브트리 높이가 4, 오른쪽 서브트리 높이가 2이다. (1) BF(v)를 구하고 (2) 이 노드가 AVL 조건을 만족하는지 판별하시오.

✎ 나의 답안
정답 / 풀이 보기

정답: BF(v) = +2, AVL 조건 위반

BF(v) = height(왼쪽) − height(오른쪽) = 4 − 2 = 2. |2| > 1 이므로 AVL 조건(|BF| ≤ 1)을 위반합니다. 왼쪽이 무거우므로(L) 이 노드에서 회전으로 균형을 잡아야 합니다.

Q4AVL추적 · 판별

다음 트리가 AVL 트리인지 판별하고, 아니라면 위반이 일어난 노드와 그 BF 값을 쓰시오.

10 / \ 5 15 / 3 / 1
✎ 나의 답안
정답 / 풀이 보기

정답: AVL 아님 — 노드 5에서 BF = +2 (노드 10에서도 +2)

각 노드 높이: 1→0, 3→1, 5→2, 15→0, 10→3.

BF(5) = height(왼쪽=3, 높이1) − height(오른쪽=없음, −1) = 1 − (−1) = 2 → |2| > 1 이므로 위반. BF(10) = 2 − 0 = 2 도 위반. 가장 깊은 위반 노드는 5입니다.

Q5AVL빈칸 채우기

높이가 h인 AVL 트리가 가질 수 있는 최소 노드 수를 Nh라 할 때, 점화식을 완성하시오.

Nh = N____ + N____ + ____      (단, N₀ = 1, N₁ = 2)
✎ 나의 답안
정답 / 풀이 보기

정답: Nh = Nh−1 + Nh−2 + 1

전체 높이를 h로 만들려면 한쪽 서브트리는 높이 h−1이어야 하고, 다른 쪽은 노드를 최소로 줄이기 위해 AVL이 허용하는 한 가장 낮은 h−2까지 낮춥니다. 여기에 루트 1개를 더해 Nh−1 + Nh−2 + 1이 됩니다. (피보나치 트리)

Q6AVL계산

Q5의 점화식 Nh = Nh−1 + Nh−2 + 1 (N₀=1, N₁=2)을 이용하여 N₂, N₃, N₄, N₅를 차례로 구하시오.

✎ 나의 답안
정답 / 풀이 보기

정답: N₂ = 4, N₃ = 7, N₄ = 12, N₅ = 20

N₂ = N₁ + N₀ + 1 = 2 + 1 + 1 = 4
N₃ = N₂ + N₁ + 1 = 4 + 2 + 1 = 7
N₄ = N₃ + N₂ + 1 = 7 + 4 + 1 = 12
N₅ = N₄ + N₃ + 1 = 12 + 7 + 1 = 20

Q7AVL서술 · 증명

점화식 Nh = Nh−1 + Nh−2 + 1 에서 출발하여, AVL 트리의 높이가 h = O(log n)임을 보이는 증명의 흐름을 아래 키워드를 순서대로 사용해 서술하시오.

Nh−1 > Nh−2 → Nh > 2·Nh−2 → Nh ≥ 2h/2 → h ≤ 2·log₂ n

✎ 나의 답안
정답 / 풀이 보기

정답 요지

① 높이가 클수록 최소 노드 수도 크므로 Nh−1 > Nh−2. ② 점화식의 Nh−1을 더 작은 Nh−2로 바꿔치기하면 Nh = Nh−1 + Nh−2 + 1 > 2·Nh−2. ③ 이를 반복 적용하면 Nh ≥ 2h/2. ④ 실제 노드 수 n ≥ Nh ≥ 2h/2 이므로 양변에 log₂를 씌우면 h/2 ≤ log₂ n, 즉 h ≤ 2·log₂ n = O(log n). 모든 연산은 O(h)이므로 결국 O(log n)으로 보장됩니다.

Q8AVL계산 · 적용

증명 결과 h ≤ 2·log₂ n 을 이용한다. 노드가 n = 65,536 (= 216)개인 AVL 트리의 높이 상한은 얼마인가?

✎ 나의 답안
정답 / 풀이 보기

정답: h ≤ 32

h ≤ 2·log₂(216) = 2 × 16 = 32. (이 한계는 다소 느슨한 상한이며, 실제 AVL 높이는 보통 이보다 낮습니다.)

Q11AVL추적 · x·y·z 찾기

키 10, 5, 15가 있고 5의 오른쪽 자식으로 7이 있는 AVL 트리에 9를 삽입했더니 균형이 깨졌다.

10 / \ 5 15 \ 7 \ 9 ← 새로 삽입

이때 z, y, x에 해당하는 노드와 케이스(LL/RR/LR/RL)를 각각 쓰시오.

✎ 나의 답안
정답 / 풀이 보기

정답: z = 5, y = 7, x = 9 / RR 케이스

9를 넣은 자리에서 위로 올라가면 7(OK) → 5에서 BF=−2로 처음 깨짐 → z=5. z에서 올라온 방향(오른쪽)의 자식 7 → y, 그 방향(오른쪽)의 자식 9 → x. z-y-x가 우-우로 이어지므로 RR 케이스, rotateLeft(5)로 복구합니다.

Q12AVL추적 · 케이스 판별

비어 있는 AVL 트리에 30, 10, 20 순서로 삽입하면 균형이 깨진다. (1) z, y, x를 쓰고 (2) 케이스(LL/RR/LR/RL)와 (3) 필요한 회전과 (4) 회전 후 루트가 되는 키를 쓰시오.

✎ 나의 답안
정답 / 풀이 보기

정답: z=30, y=10, x=20 / LR 케이스 / rotateLeft(10) → rotateRight(30) / 루트 = 20

30 삽입 → 10은 30의 왼쪽 자식 → 20은 10의 오른쪽 자식. 30에서 BF=2로 깨짐(z=30). z의 왼쪽 10이 y, y의 오른쪽 20이 x → 좌-우 꺾임 = LR. 결과적으로 20이 루트, 10과 30이 양쪽 자식이 됩니다.

✎ 나의 답안
정답 / 풀이 보기

10·20·30: 10-20-30 우-우 = RR → rotateLeft(10), 루트 20 (20을 중심으로 10·30). 40 삽입: 30의 오른쪽, 균형 유지. 50 삽입: 30-40-50 우-우 = RR → rotateLeft(30), 40이 올라가 20의 오른쪽 자식이 됨. 최종: 루트 20, 왼쪽 10, 오른쪽 40(자식 30·50).

Q15AVL단일선택

회전(Rotation)을 해도 BST 조건이 깨지지 않는 이유로 가장 알맞은 것은?

  1. 회전이 노드들의 키 값 자체를 새로 바꾸기 때문
  2. 회전 후에도 중위 순회 결과의 순서가 그대로이기 때문
  3. 회전이 항상 잎 노드 근처에서만 일어나기 때문
  4. 회전 후 전체 트리를 처음부터 다시 정렬하기 때문
✎ 나의 답안
정답 / 풀이 보기

정답: 2번

회전은 키 순서(중위 순회 결과)를 보존한 채 트리 모양만 바꿉니다. in-order 결과가 그대로이므로 "왼쪽 < 루트 < 오른쪽"이라는 BST 조건이 유지됩니다.

    update_height(_____)   # ★ 나중
