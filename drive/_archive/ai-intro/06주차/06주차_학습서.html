핵심 1신경망 학습 = 가중치 수정

학습은 가중치(Weight)를 변화시키는 것. 시냅스 강도 조절과 같다.
신경망 학습 (Neural Network Learning) 같은 입력에 대해 다른 출력을 내도록 가중치(W)를 수정하는 과정. 4주차 시냅스 학습 원리와 동일.

비유: 가중치 = 수도꼭지/밸브. 학습 = 원하는 폭포 모양이 나오도록 수도꼭지들을 조절하는 일.

★ 빈출 ★ "신경망 학습은 ( )를 수정하는 것이다" → 답: 가중치(Weight). ChatGPT의 1750억 매개변수 = 1750억 개 가중치.

핵심 2오차와 손실 함수

오차 = 원하는 값(d) − 실제 출력(a). 손실 함수는 가중치를 입력으로 오차를 출력.
Error = (d − a)² (보통 제곱하여 부호 상쇄 방지)

손실 함수(Loss Function) = 비용 함수(Cost Function) = 오차 함수(Error Function) — 셋 다 같은 의미. 신경망 학습은 이 함수를 최소화하는 가중치를 찾는 일.

핵심 3경사하강법 (Gradient Descent)

오차 함수의 기울기를 따라 가중치를 줄여 나간다. 산을 내려가는 것에 비유.
ΔW = −α · (∂E/∂W)
기호의미
ΔW가중치 변화량 (수정값)
α학습률(Learning Rate). 작은 양수
∂E/∂W오차 E를 가중치 W로 미분한 기울기

해석:

  • 기울기가 양수 → 가중치 감소
  • 기울기가 음수 → 가중치 증가
  • 매 반복마다 학습률 α만큼 조금씩 이동

핵심 4학습률 (Learning Rate)

학습률 α 한 번에 가중치를 얼마나 수정할지 결정하는 작은 양수(예: 0.01, 0.1).
너무 작으면 → 수렴이 느림 / 너무 크면 → 발산할 수 있음.
시험 포인트 학습률이 부적절하면 학습이 잘 안 된다. 적절한 값 찾기는 하이퍼파라미터 튜닝의 일부.

핵심 5XOR 문제와 신경망의 겨울

1969년 Minsky & Papert가 단층 신경망의 한계를 지적 → 약 20년의 신경망 침체기.
X₁X₂X₁ XOR X₂
000
011
101
110
선형 분리 불가능 (Non-linearly Separable) 하나의 직선/평면으로는 두 클래스(0과 1)를 분리할 수 없는 데이터. XOR이 대표적. 중간층(은닉층)이 필수.
★ 시험 빈출 ★ "XOR 문제는 단층 신경망(=중간층 없는 퍼셉트론)으로 해결 불가능" → 1969년 민스키와 페퍼트가 지적 → AI 1차 겨울 → 1986년 역전파 알고리즘으로 극복.

핵심 6역전파 알고리즘 (Backpropagation, 1986)

출력층 오차를 입력층 방향으로 거꾸로 전파하여 가중치를 수정. 딥러닝의 핵심.
역전파 (Backpropagation) 1986년 Rumelhart, Hinton, Williams가 정립. 중간층 가중치 학습 문제를 해결한 결정적 알고리즘.

흐름:
① 입력 → 출력층까지 전진 전파(Feed Forward)
② 출력층에서 오차 계산
③ 오차의 기울기를 출력층 → 중간층 → 입력층으로 거꾸로 전파
④ 각 층의 가중치를 동시에 수정

비유: "너 때문이닷!". 출력층이 자기 오차의 책임을 중간층에 거꾸로 묻고, 중간층은 그것을 모아 자기 가중치를 수정.

수학적 토대 — 연쇄 법칙

역전파는 미분의 연쇄 법칙(Chain Rule)을 사용:

∂E/∂W₁ = (∂E/∂y) · (∂y/∂z) · (∂z/∂W₁)
자료구조와의 연결 역전파는 방향성 비순환 그래프(DAG) 위에서 위상정렬의 역순으로 동적 계획법(Dynamic Programming) 방식으로 진행. 자료구조 수업의 그래프 알고리즘과 같은 본질.

핵심 7하이퍼파라미터 (Hyperparameter)

정의 가중치(매개변수)를 수정하기 위한 매개변수들. 사람이 직접 설정하며 정답이 정해져 있지 않다.
하이퍼파라미터의미
학습률 (Learning Rate)한 번에 얼마나 학습할지
에폭 (Epoch)전체 학습 데이터를 몇 번 반복할지
중간층 수은닉층 개수
뉴런 수각 층의 폭(width)
활성함수Sigmoid / Tanh / ReLU
정규화율 (Regularization Rate)과적합 방지 강도

핵심 8과적합과 과소적합

현상설명원인해결
과소적합 (Underfitting) 학습 데이터에도 잘 안 맞음 모델이 너무 단순 층/뉴런 추가, 학습 시간 늘림
과적합 (Overfitting) 학습 데이터엔 OK, 새 데이터엔 약함 모델이 너무 복잡 / 학습 과다 정규화, 조기 종료, 데이터 증강
시험 포인트 과적합은 일반화 성능 저하가 핵심. 학습 데이터 외의 새 데이터에 대해 성능이 떨어진다. 정규화(Regularization)로 해결.

🎯 강의 끝 퀴즈 (시험 1순위)

강의 영상 마지막에 등장하는 빈칸 채우기 — 핑크 단어가 정답입니다.

1차시

생물학적 뉴런의 시냅스는 두 뉴런 사이에 전송되는 정보의 양을 조절하는 역할을 한다. 따라서 뉴런 사이의 연결선을 생화학적 신호가 지나가는 통로라고 가정하면 시냅스는 통로 중간에 있는 ( 밸브 (혹은 수도꼭지) )로 생각할 수 있다.

2차시

사용자는 입력층으로 데이터를 보내면 출력층에서 나오는 결과에만 관심이 있지 중간층에서 일어나는 일들에는 관심이 없다. 또 그래야 마땅하다. 그래서 중간층을 은닉층이라 부르는 중간층 뉴런의 ( 목표 ) 출력이란 건 애초에 존재하지 않는 값이다. 따라서 중간층 뉴런이 출력해야 할 값, 즉 정답이란 건 애초부터 존재하지 않는 값이기 때문에 경사 강하를 이용해서 중간층 뉴런으로의 연결 가중치를 수정할 수 없다.

3차시

신경망에 관심이 있다면 텐서플로 플레이그라운드 (https://playground.tensorflow.org/)에 반드시 들어가서 놀아 볼 필요가 있다. 잘 노는 사람이 성공한다. 잘 놀 수 있도록 중요한 힌트를 주겠다. 푸른색은 ( 양수 ), 붉은색은 음수고, 색이 진하거나 선이 두꺼울수록 절댓값이 크다는 걸 알면 이해하는 데 크게 도움이 된다. 흰색에 가까울수록 0이다.
