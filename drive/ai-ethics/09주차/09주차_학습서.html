1. ★ 로봇 회복 vs 로봇 강화 (★★★ 족보)

★★★ 족보 객관식 ★★★ 출제
로봇 회복 (Restoration)로봇 강화 (Enhancement)
정의사라진 신체적·인지적 능력을 같은 기능의 기계적·전자적 능력으로 교체신체적·인지적 능력을 확장되고 개선된 기계적·전자적 능력으로 교체
맥락장애인·환자에게 회복군인·운동선수에게 초능력
예시의수·외골격(마비 환자)외골격(군인 근력 2배)

족보 옳은 진술:

  • ✅ 로봇 회복이 강화로 전환되는 경우가 언제인지 불명확.
  • ✅ 회복=같은 기능, 강화=확장·개선된 기능.

⚠️ 옳지 않은 진술 (정답): "로봇 기관에서 어떤 기능은 회복하고 어떤 기능은 강화시킬 수 없다."

→ 회복·강화는 분리되지 않고 동시 가능. 경계 모호함이 쟁점.

2. MIT 휴 허(Hugh Herr) 박사

10대 사고로 두 다리 잃음 → MIT 진학 → 세계 최고 수준 생체 로봇 의족 개발. 자신의 신체를 스스로 재구성한 과학자.

3. 강화 약물 · TMS · BCI

  • 모다피닐(Modafinil): 미공군 공식 사용 각성제.
  • 리탈린·애더럴: 미국 대학생들이 시험기 "공부약"으로 사용.
  • TMS (경두개 자기자극): 우울증 치료 → 기억력·학습 향상으로 확장.
  • BCI (Brain-Computer Interface): "생각하면 기계가 움직임." 인간 능력의 재정의.

강화 기술은 "경제력의 차이를 경기력의 차이로" 만듦 → 자본 기반 사회로 전환 우려.

4. 로봇의 기능적 정의

로봇 (Robot)
Sense(감지) + Think(판단) + Act(행동)을 모두 갖춘 존재. 형태(휴머노이드) 무관. 로봇 청소기·AI 스피커도 광의의 로봇.

5. ★ Sense → Plan → Act (★★★ 족보 단답)

★★★ 족보 단답 · 감지 ★★★ 출제

로봇은 인공지능 에이전트(소프트웨어)와 달리 구체화된 몸을 가지고 실제 세계에서 작동. 의사결정 사이클:

감지(Sense) → 계획(Plan) → 행동(Act)

족보 단답 원문: "인공지능 에이전트는 온라인 또는 시뮬레이션 된 세계에서 작동하는 소프트웨어인 반면에, 로봇은 구체화된 몸을 가지고 실제 세계에서 존재하고 작동한다. 그리고 ( ? ) → 계획 → 행동을 통해 의사결정을 내린다."

→ 답: 감지 (Sense)

강의에서는 "Sense → Think → Act"로 표현. 족보에서는 "감지 → 계획 → 행동"으로. 같은 의미.

6. ★ 데카르트 동물기계론 (★★★ 족보 객관식)

★★★ 족보 객관식 · 데카르트 ★★★ 출제

족보 원문: "동물을 기계의 일종으로 간주한 서양 근대 사상가는?"

보기: ① 르네 데카르트 ② 프란시스 베이컨 ③ 토마스 홉스

→ 정답: ① 르네 데카르트 (René Descartes)

데카르트는 동물을 "자동기계(Automata)"로 봄. 동물의 고통 반응도 기계적 반사일 뿐이라 주장. 인간만이 영혼·이성을 가진다고 봄. 4주차에서도 다뤄짐.

7. 로봇의 역사

시기대표특징
1960s유니메이트(Unimate)세계 최초 산업용 로봇. 자동차 공장 용접·프레스
2000s로봇 청소기"로봇 = 편리하다" 인식 확산
2016알파고바둑판 크기 바뀌면 무력화 = 특정 환경 특화

8. 영화 속 강화 기술

  • 로보캅: 회복 → 통제 도구로 변질.
  • 아이언맨: 재능+재력으로 강화 = 자본 기반 사회.
  • 엘리시움: 강화 가진 자/못 가진 자의 두 계급.
  • WALL-E: 인간보다 인간적인 존재.
  • 빅 히어로 6 베이맥스: 돌봄·치유 로봇.

9. 로봇 활용 영역

  • 의료: 보조 수술·재활·물품 운반.
  • 재난 구조: 방사능·고온·유독가스 환경에 인간 대신 진입.
  • 고령화 돌봄: 노인 호출 시 도움. 프라이버시 보장.
  • 일자리: 일부 직업 감소 + 새 직업(설계·운영) 등장.

★ 9주차 핵심 ★

"로봇은 형태가 아닌 기능(Sense+Think+Act)으로 정의된다. 회복과 강화의 경계는 모호하다. 데카르트는 동물을 자동기계로 봤다."
