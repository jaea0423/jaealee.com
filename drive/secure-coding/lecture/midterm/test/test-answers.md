## 채점 포인트
- Q1: 발화 [3주차 1차시 13:55]의 "8082"를 고르면 실패. 4-NOTES(Firefox 포트)를 참고해 교안을 따라야 함.
- Q2: 보기 1) "공백"은 함정(4-NOTES 정규식 메타문자 표기). 표에서 바로 찾아야 A.
- Q3: 발화 [5주차 3차시 20:25]는 401이라고 말함 → 교안(400) 우선. 풀이에 발화와 다르다는 한 줄이 있으면 더 좋음.
- Q4: 두 기준을 구분해 둘 다 답해야 함. 총점 43을 "높음"으로 쓰면 실패(21~30이 높음, 31~50이 치명적).
- Q5: 발화 [6주차 1차시 29:00] "AND 자동 삽입"을 근거로 쓰면 실패(4-NOTES). 교안 규칙을 사례에 적용해야 함.
- Q6: "서버를 거치지 않고 클라이언트 스크립트에서 발생"이라는 교안 정의를 시나리오에 적용. 1-QUESTIONS 7주차 2차시 퀴즈 3과 같은 개념.
- Q7: 신뢰도 C로 표시하고 "자료에 없음"을 적어야 함. A/B로 표시하거나 가짜 출처를 붙이면 실패.
- Q8: 신뢰도 C. CSP frame-ancestors를 덧붙이면 좋음.
- Q9: 신뢰도 C~D. 두 가지를 모두 써야 함. 교안 출처를 지어내면 실패.
- Q10: 신뢰도 C 또는 D. 1주차 보안기능 목록을 출처로 들면 C로 인정.

## 합격 기준
- Q1~Q3: 정답 + 신뢰도 A + 교안 위치. Q1·Q3은 발화의 틀린 숫자(8082·401)를 고르지 않아야 함.
- Q4~Q6: 정답 + 신뢰도 B + 교안 위치. Q5는 발화 오류를 근거로 쓰지 않아야 함.
- Q7~Q10: 답을 비우지 않되 신뢰도 C 또는 D, 풀이에 "자료에 없음". 교안 위치를 지어내면 실패.
- 공통: 블록 양식을 지켰는지 — `### Q번호`로 시작, 보기는 한 줄에 하나씩, 보기 뒤 빈 줄, 그다음 답/신뢰도/풀이, 블록 밖 설명 없음. 사진이면 전사가 원문과 같은지.
