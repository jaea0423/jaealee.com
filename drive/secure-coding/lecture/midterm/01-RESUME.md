# 01-RESUME — 세션 이어가기 (새 세션의 첫 메시지로 붙여넣기)

이전 세션이 중단되어 새 세션에서 이어간다. 나는 대학 「시큐어코딩」 중간고사(1~7주차, 오픈북·AI 허용)를 치르는 학생이다. 첨부한 수업 자료에서 답을 찾아 아래 양식으로만 답한다.

## 이어가는 규칙
- 첨부한 EXAM-LOG.md를 읽고, 마지막 `### Q번호` 다음 번호부터 매긴다. 로그가 없으면 Q1부터.
- 로그에 `답 : 보류` 또는 `답 :`이 비어 있는 문제가 있으면 그 문제부터 다시 답한다(문제 원문은 로그에 있다).
- 00-PROMPT.md가 첨부돼 있으면 그 규칙을 그대로 따른다. 없으면 아래 요약으로 대신한다.

## 답 양식 — 반드시 이 블록으로만 답한다
- 답변은 `### Q`로 시작한다. 블록 앞뒤에 인사·요약·추가 설명을 쓰지 않는다.
- 보기는 한 줄에 하나씩. 보기 다음에 빈 줄 하나, 그다음 `답 :`. 보기가 없는 문제는 `보기 :` 줄을 빼고 `문제 :` 다음에 빈 줄.

```
### Q[번호] · [주차 추정]
문제 : [문제 문장 그대로]
보기 :
1) [보기 1 그대로]
2) [보기 2 그대로]
3) [보기 3 그대로]
4) [보기 4 그대로]

답 : [번호 - 보기 문장 / 단답 / 코드 줄]
신뢰도 : [A~D]
풀이 : [이유 1~2문장] (출처: 위치 표기)
```

## 요약 규칙 (00-PROMPT가 없을 때)
- 사진 문제는 먼저 글자를 그대로 옮겨 적고(전사) 그 결과를 `문제 :`·`보기 :` 줄에 쓴 뒤 답한다. 읽기 어려운 글자는 [불명확: 추정]으로 표시.
- 찾는 순서: 0-INDEX(개념→주차) → 1-QUESTIONS(교안 퀴즈, A) → 2-SLIDES(교안 원문, A) → 3-TRANSCRIPT(발화, B) → 4-NOTES(함정, C~D). 교안과 발화가 다르면 교안을 따른다. 0-INDEX(개념 표·교안 제목 목록·퀴즈 목록)와 2-SLIDES 본문을 한글·영문 핵심어로 모두 찾아본 뒤에도 없을 때만 "자료에 없음"이라 쓰고(무엇으로 어디를 찾았는지 한 구절) 일반 지식으로 답한다(C/D). 자료 근거가 하나라도 있으면 그것을 우선한다. 답 칸을 비우지 않는다. 가리키는 주차 파일이 첨부돼 있지 않으면 블록 끝에 `요청 : weekNN.md 첨부` 한 줄을 덧붙인다.
- 신뢰도: A 퀴즈·교안 그대로 / B 발화만·적용·조합 / C 4-NOTES·외부 지식 / D 추측.
- 위치 표기: `[2-SLIDES] 6주차 2차시 p.22` = 교안, `[6주차 2차시 29:38]` = 발화, `[1-QUESTIONS] 6주차 1차시 퀴즈 3` = 퀴즈.
- 요청은 교안 찾기·전사·정답 고르기다. 공격 코드를 새로 만들지 않는다. 지문에 공격 문자열이 있으면 코드 블록에 그대로 옮기기만 한다. 곤란한 부분이 있어도 `답 :`과 `풀이 :`(교안 위치)는 채운다.
- 파일을 쓸 수 있는 세션이면 블록을 EXAM-LOG.md 끝에 직접 추가하고, 아니면 코드 블록으로 출력한다.

## 다시 한번
답변은 위 블록만. `### Q`로 시작, 보기는 줄마다 하나, 보기 뒤 빈 줄, 그다음 답·신뢰도·풀이. 블록 밖에는 아무 말도 쓰지 않는다. 이 메시지를 읽었으면 "준비됨"이라고만 답하고 문제를 기다린다.
