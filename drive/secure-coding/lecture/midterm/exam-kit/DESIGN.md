# 시험 검색 페이지 — 디자인 명세

목표: **시험 시간에 개념·조문·교수님 질문을 몇 초 안에 찾는 것.** 꾸밈보다 읽기 속도가 우선입니다.

## 1. 기본 원칙
- **확대 없이 읽히는 크기.** 기본 글자 17px, 본문 창 17.5px, 결과 제목 17px, 작은 글자도 12.5px 이상.
- **본문은 불투명.** 배경·카드는 반투명 유리 느낌이어도 되지만, 오래 읽는 본문 창과 목차는 불투명 흰 바탕에 진한 글자로 둡니다(뒤 글자가 비치지 않게).
- **글꼴은 하나.** Noto Sans KR 하나로 굵기(400·500·600·700·800·900)만 바꿉니다. 장식 글꼴·외곽선 글자는 쓰지 않습니다.
- **다크 모드 없음.**
- **입력칸 안내 문구는 항목 이름만** (`검색`). 예시 문구를 넣지 않습니다.
- 줄바꿈은 `word-break: keep-all` — 한국어 단어가 중간에서 끊기지 않게.

## 2. 화면 구성 (위 → 아래)
1. **헤더** — 과목·교수 배지, 큰 제목 `{시험} 검색`(900 굵기, 38~62px), 범위 한 줄, 시험 일시 알약.
2. **검색 영역 (화면 위 고정)** — 🔍 + 입력칸 + 위치 표시(`3 / 47`) + 지우기(×) + `Enter 다음 · Esc 닫기` 안내 + `☰ 목차` 버튼.
   - 아래에 **필터 칩 한 줄**: 종류(전체·교수님 질문·개념·조문·강조·주의·용어·확인·차이·교안 원문·강의 발화) | 주차(1주…). 넘치면 옆으로 밀어서 봅니다(줄바꿈 안 함). 검색 중에는 칩마다 결과 수 표시.
   - 검색을 시작하면 검색 영역이 화면 맨 위에 붙도록 자동 스크롤.
3. **결과 목록 (검색창 아래 펼침)** — 종류별 묶음, 항목마다 `제목 + [N주차 · 종류] 알약 + 요약 2줄`. 교수님 질문은 **답까지 목록에 바로 표시**. 종류마다 처음엔 일부만(질문 20 · 개념 12 · 조문 10 …) 보이고 "더 보기".
4. **큰 버튼 2개** — 🎯 교수님 질문(질문 목록으로 이동) / ⚖️ 조문 모음(조문 필터 켜기).
5. **주차 카드** — 큰 주차 번호, 제목, 날짜, 섹션 목록(누르면 본문 창), `정리 페이지` · `교안 PDF` 링크.
6. **교수님 질문 카드** — 주차 필터, 질문(굵게) / 답(흰 상자) / 근거 / "관련 개념 열기".
7. **시험 정보 카드** — 일시·방식·범위·AI 사용 4칸 + "교안 기준" 안내.
8. **AI에게 줄 파일** — 어두운 상자 안에 `PROMPT.md`, `1~4` 카드. **누르면 열리지 않고 저장**(파일 내용을 페이지에 넣어 두고 Blob으로 내려받기).

## 3. 본문 창 (결과를 열면 위에 겹쳐 뜸)
- 검색 영역 바로 아래부터 화면 아래까지, 최대 너비 1080px, 글 영역 860px.
- 상단 띠: `◀ 이전` `다음 ▶` `결과 목록` · `본문 N곳 ▲▼` · `본문 복사 (AI용)` · `N주차 정리 페이지 ↗` / `PDF N쪽 ↗` · `✕ 닫기`.
- 머리: 경로(`N주차 · 제목 › N번 섹션`), 제목 28px, 출처 배지.
- 본문 안 검색어는 노랑 표시, 현재 위치는 보조 색 테두리. 열면 첫 위치로 자동 이동.
- 종류별 내용: 개념·조문·강조 → 해당 섹션 전체(조문·강조는 그 상자로 스크롤 + 잠깐 테두리) / 질문 → 질문 상자 + 관련 섹션 / 교안 원문 → 그 쪽 내용 + PDF 해당 쪽 링크 / 강의 발화 → 앞뒤 8줄.
- 휴대폰: 상단 띠는 한 줄 가로 스크롤, 닫기 버튼을 맨 앞에.

## 4. 본문 상자 종류
| 클래스 | 용도 | 색 |
|---|---|---|
| `.call` | 조문 원문 | 파랑 왼쪽 띠 |
| `.call.warn` | 강조(교수님 강조, 시험 포인트) | 보조 색 |
| `.call.quote` | 교수님 말씀 | 청록 |
| `.call.ask` | 주의·확인 필요 | 주황 |
| `.call.extra` | 보충(교안 밖) | 점선 |
| `.ext` | 문장 안 보충 표시 (앞에 "보충 ·") | 회색 |
| `mark` | 핵심어 강조 | 주 색 연한 배경 |

## 5. 검색 동작
- **띄어쓰기 무시**: `제 17 조` = `제17조` (글자 사이에 `\s*`).
- 입력 전체를 한 덩어리로 먼저 찾고, 없으면 단어별로 나눠 **모두 포함**된 것을 찾습니다.
- 점수: 제목 +20, 키워드·배지 +8, 본문 등장 횟수(최대 6) + 종류 가중치(질문 6 · 개념 5 · 조문 5 · 용어 4 · 강조 3 · 확인 2 · 교안 1 · 발화 0).
- 입력 후 110ms 뒤 검색(타자 중 깜빡임 방지).

## 6. 키보드
| 키 | 동작 |
|---|---|
| `Enter` | 첫 결과 열기 → 누를 때마다 다음 결과 (끝나면 처음으로) |
| `Shift+Enter` | 이전 결과 |
| `↑` `↓` | 목록에서 선택만 이동 |
| `Esc` | 본문 창 → 목차 → 검색어 → 목록 순서로 닫기 |
| `/` 또는 `Ctrl+K` | 검색창으로 |

## 7. 반응형
- 목차는 모든 너비에서 서랍(왼쪽에서 겹쳐 뜸). `☰ 목차`로 열고 닫음. 목차를 열면 본문 창은 닫힘.
- 760px 이하: 글자 16px, 단일 열 카드, `Enter 다음` 안내 숨김, 필터 가로 스크롤.
- 모든 너비에서 가로 넘침 0을 확인합니다(1440 · 1024 · 390px).
