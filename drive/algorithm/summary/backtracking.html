3. N-Queens11-1

표기 · 답 · 대각선→ 개념노트 p.5

X[k]
k 행 퀸의 열 인덱스 (행은 하나씩이라 같은 행 없음)
4-Queens
[1, 3, 0, 2], [2, 0, 3, 1] — 2개
대각선
|X[i] − c| == |i − k| (밑변 = 높이)
pseudocodenqueens(k) · is_safe(k, c)
def nqueens(k):
    if k == N: print(X); return
    for c in range(N):
        if is_safe(k, c):
            X[k] = c
            nqueens(k + 1)
def is_safe(k, c):
    for i in range(k):
        if X[i] == c:          # 같은 열
            return False
        if abs(X[i]-c) == abs(i-k):  # 대각선
            return False
    return True
시험 포인트
  • 첫 해는 [1, 3, 0, 2] — 0열부터 놓아 보는 순서 (과제 4 트리)
  • is_safe 빈칸: 같은 열 · 대각선 두 조건

4. Subset Sum11-1 · 12-1

문제 · subsetsum1 · 트리→ 개념노트 p.7

문제
A 의 부분집합 중 합이 S. A = [8, 6, 7, 5, 3, 10, 9], S = 15 → {8, 7}, {7, 5, 3}, {5, 10}, {6, 9}
경우
원소마다 넣음 / 안 넣음 → 2|A|
pseudocodesubsetsum1(A, S)
if S == 0: return True
if S < 0 or len(A) == 0: return False
z = A[0]; B = A[1:]
return subsetsum1(B, S-z) or subsetsum1(B, S)

A = [8, 6, 7], S = 15 트리: 15 → (8 ○) 7 → (6 ○) 1 → −6 ✕, 1 ✕ → (6 ✕) 7 → (7 ○) 0 = True

헷갈리는 점 · 판서 정정
  • 판서 A 의 4 → 3 (답 {7, 5, 3})
  • 노드 = 남은 목표 S (넣으면 줄어듦)

subsetsum2 · DP · O(nS)→ 개념노트 p.9

DP[i][S] = DP[i−1][S−A[i]] or DP[i−1][S]
  • subsetsum2(A, i, S): A[0] ~ A[i] 만 봄, i == −1 이면 False, 호출 subsetsum2(A, len(A)−1, S)
  • 표 n × (S + 1), 칸마다 or → O(nS)
  • 문제: S 처럼 입력의 값이 들어감 → 값이 크면 (20억) 비정상적으로 큼 → 바람직하지 않음

답 구하기 · 가지치기→ 개념노트 p.9

  • sol: 넣고 성공하면 return [z] + result, 실패면 안 넣고 시도, 불가능 None
  • sol2(k): X[k] = 1 → (k+1), X[k] = 0 → (k+1), k == n 에서 합 == S 면 print(X) — 답 모두
  • 가지치기: A 오름차순 + current_sum + A[k] ≤ S 일 때만 넣음 → 호출 255 → 93
헷갈리는 점 · 판서 정정
  • sol 판서: return 과 + 빠짐
  • sol2 판서: if i in range → for, k == n 뒤 return
  • 교체 줄의 current_sum 은 인자로 넘겨야 함 (보충)

def Backtrack(k):
    if k >= n:
        output solution; return
    for each candidate c for X[k]:
        if B(X[0], ..., X[k-1], c) == True:
            X[k] = c
            Backtrack(k + 1)

6. Knapsack 문제12-2

정의 · 두 종류→ 개념노트 p.13

문제
무게 합 ≤ K (조건 1) 이면서 가치 합 최대 (조건 2)
예시
K = 16, S = [2, 5, 10, 5], P = [40, 30, 50, 10]
fractional0/1
쪼개기가능불가 (1 / 0)
풀이가성비 그리디백트래킹
예시 답2 + 5 + 9 → 1152 + 10 → 90
fractional 최적 ≥ 0/1 최적 (항상)
헷갈리는 점 · 판서 정정
  • 0/1 을 가성비 순으로: 2, 5, (10 넘침), 5 → 80 — 최적 아님
  • 판서 K-=16 → K = 16
시험 포인트
  • 부등식을 기억 — 0/1 백트래킹의 상한으로 쓰임 (교수님)

7. 0/1 Knapsack 백트래킹12-2 · 13-1

한계함수→ 개념노트 p.15

p(v), s(v)
v 까지 넣은 가치 합, 무게 합 (v 에서 X[i] 결정)
MP
지금까지 찾은 답 중 최대 가치
상한
X[i] = 1p(v) + P[i] + frac(i+1, K − s(v) − S[i])≤ MP 면
안 감
X[i] = 0p(v) + frac(i+1, K − s(v))

거르기: ① 넘침 ② 안 넣는 가지 (상한 ≤ MP) ③ fractional 상한 ≤ MP (가장 중요)

예시 P = [15, 16, 6], S = [3, 4, 2], K = 5→ 개념노트 p.16

가지상한판단
[ ] → X[0]=115 + 8 = 23감
[1] → X[1]=14 > 남은 2① ✕
[1] → X[1]=015 + 6 = 21감
[1,0] → X[2]=121답 MP = 21
[1,0] → X[2]=015 + 0 = 15② ✕
[ ] → X[0]=016 + 3 = 19③ ✕

결과 MP = 21, X = [1, 0, 1]

헷갈리는 점 · 판서 정정
  • 19 는 답이 아니라 상한 (쪼갠 값)
  • 판서는 중간 노드에서도 MP 갱신 (15), 코드는 잎 · 꽉 참일 때만 — 이 예는 결과 같음
  • frac(a, b): a = 다음 아이템, b = 남은 용량

코드 핵심→ 개념노트 p.17

pythonknapsack(i, size, profit)
if i >= n or size == 0:
    update_best(profit); return
if S[i] <= size:          # 넣는 가지
    B = frac_knapsack(i+1, size-S[i])
    if profit + P[i] + B > MP:
        X[i] = 1
        knapsack(i+1, size-S[i],
                 profit+P[i])
        X[i] = 0
B = frac_knapsack(i+1, size)  # if 밖
if profit + B > MP:
    X[i] = 0
    knapsack(i+1, size, profit)
헷갈리는 점 · 판서 정정
  • 필기는 안 넣는 가지가 if 안쪽 → 답 21 이 6 으로 틀림
  • update_best: profit > MP 면 MP, best_X (= X.copy()) 갱신. 실행 knapsack(0, K, 0)
시험 포인트
  • 빈칸: 두 상한 식, size − S[i], i + 1
  • 변수 이름 바꿔 출제 대비: size = K − s(v), profit = p(v)
