분할 정복 · 점화식

3주차 1·2차시, 4주차 2차시 — max 분할 · 거듭제곱 · 피보나치 · 카라츠바 · 이진탐색 · 점화식 풀기. 자세한 설명은 개념노트(3-1, 3-2, 4-2).

1풀이 도구시험 ★★★

전개 순서 (과정 서술 필수)

  1. T( ) 안을 같은 식으로 2~3번 대입해 펼친다
  2. 규칙이 보이게 쓰고 일반항 (k번 펼친 꼴)을 적는다
  3. n = 2k 가정 → n2k = 1, T(1) = C
  4. 남은 합을 계산 (C가 k개 / 등비수열) → k = log₂ n 대입 → 최고차항만 남겨 O( )
등비수열의 합 (초항 a, 공비 r, 항 k개)   =   a(rk − 1)r − 1  (r > 1)   =   a(1 − rk)1 − r  (r < 1)
성질쓰는 곳
(ab)c = (ac)b → 4k = (2k)² = n²4T(n2) + Cn
alogb c = clogb a → 3log₂ n = nlog₂ 3카라츠바
loga b + loga c = loga bc → log₂32 + 1 = log₂32 + log₂2 = log₂3카라츠바
n = ck ⟺ k = logc n재귀 횟수
로그의 밑 생략
O(log₂ n), O(log₃ n) → O(log n) 으로 써도 됨 (밑이 바뀌어도 상수배). O(nlog₂3) 은 생략 금지 (지수 안이라 밑이 바뀌면 차수가 바뀜).

2max(A) — 두 가지 분할

분할재귀식점화식결과
하나 vs 나머지max(A[0], max(A[1:]))T(n − 1) + CO(n)
반씩max(max(A[:4]), max(A[4:]))2T(n2) + CO(n)
2T(n2) + C = 2kT(1) + C(2k−1 + ⋯ + 2 + 1) 등비 합 = 2k − 1
= Cn + C(n − 1) = 2Cn − C → O(n)
두 max 는 다르다
바깥 max(·, ·) = 두 수 중 큰 값을 고르는 비교 연산. 안쪽 max(A[…]) = 지금 만드는 알고리즘 함수. 슬라이싱 A[:4] 는 인덱스 0~3.

3거듭제곱 aⁿ — power1 · 2 · 3시험 ★★★

쪼개기재귀 호출점화식결과
power1n → n − 11번T(n − 1) + CO(n)
power2n → n22번 (같은 값)2T(n2) + CO(n)
power3n → n21번 + 재사용T(n2) + CO(log n)
 
def power3(a, n):
    if n == 1:
        return a
    x = power3(a, n//2)        # 재귀는 딱 한 번 — 결과를 x 에 담아 둠
    if n % 2 == 0:
        return x * x           # 짝수: x 를 두 번 쓰기만
    else:
        return x * x * a       # 홀수: 나머지 1 때문에 a 한 번 더
power3: T(n2) + C = T(n2k) + kC = C + C·log₂ n → O(log n)

4피보나치 — O(γn) → O(log n)시험 ★★★

F0 = 0, F1 = 1, Fn = Fn−1 + Fn−2 → 0, 1, 1, 2, 3, 5, 8, 13, 21, …

방법점화식 · 핵심결과
fibo1 (그대로 재귀)T(n − 1) + T(n − 2) + C — 같은 값을 계속 다시 계산 (F(3) 2번, F(2) 3번 …)O(γn)
행렬 + power3피보나치를 행렬의 거듭제곱 문제로 바꿈O(log n)
( Fn , Fn−1 )T = A · ( Fn−1 , Fn−2 )T,   A = [ [1, 1], [1, 0] ]
⟹ ( Fn+1 , Fn )T = An · ( F1 , F0 )T   →   An = power3(A, n) : O(log n)
확인 (행 × 열)계산결과
위쪽1·Fn−1 + 1·Fn−2= Fn (정의) ✓
아래쪽1·Fn−1 + 0·Fn−2= Fn−1 ✓
행렬 곱 규칙
결과의 i행 j열 = (왼쪽 i행) 과 (오른쪽 j열) 을 짝지어 곱해 더한 값. 예: A² = [[2, 1], [1, 1]], A³ = [[3, 2], [2, 1]] → F4, F3, F2 가 들어 있음.

교수님: "어떻게 이 식을 찾았나요? 외울 필요 없음." — 식을 확인하고 왜 빨라지는지를 설명할 수 있으면 됨.

5큰 수의 곱셈 — 세로식과 단순 분할

수가 아주 크면 곱셈·덧셈 한 번을 상수로 볼 수 없다 (자료형 범위를 넘음) → 자리 단위로 센다.

세로식개수
곱셈 (가로) — 한 줄 n번 × 줄 n개n²
덧셈 (세로) — 한 열 최대 n개 × 열 최대 2n개2n²
합계3n² → O(n²)

반으로 쪼개기

u = x · 10n/2 + y,   v = w · 10n/2 + z   (1487 → x = 14, y = 87)
u · v = xw · 10n + (xz + yw) · 10n/2 + yz n2자리 곱셈 4번
T(n) = 4T(n2) + Cn 자리 밀기 · 2n자리 덧셈이 n 에 비례 → C 가 아니라 Cn
= 4kT(1) + Cn(20 + 21 + ⋯ + 2k−1) = C·4k + Cn(2k − 1)
= Cn² + Cn² − Cn = 2Cn² − Cn → O(n²) 4k = n², 2k = n
나아진 게 없다
크기 절반(이득 2배)을 곱셈 4번(손해 4배)이 까먹음 → 여전히 O(n²). 이 4 를 줄인 것이 카라츠바.

6카라츠바 — 곱셈 4번 → 3번시험 ★★★

xz + yw = (x + y)(w + z) − xw − yz

xw, yz 는 맨 앞·맨 뒤 항에 어차피 필요해서 계산함 → 가운데 항은 곱셈 한 번((x + y)(w + z))과 뺄셈으로. 사라지는 게 아니라 재활용.

1487 × 2356: xw = 322, yz = 4872, (x + y)(w + z) = 101 × 79 = 7979 → 가운데 = 7979 − 322 − 4872 = 2785
→ 3,220,000 + 278,500 + 4,872 = 3,503,372 ✓
T(n) = 2T(n2) + T(n2 + 1) + Cn ≈ 3T(n2) + Cn (x + y) 는 n2 + 1 자리 — +1 은 차수에 영향 없음
= 3kC + Cn((3/2)0 + ⋯ + (3/2)k−1) 공비 32 → 합 = 2((3/2)k − 1)
= C·3k + 2Cn(3/2)k − 2Cn
= C·nlog₂3 + 2C·n · nlog₂(3/2) − 2Cn alogb c = clogb a
= C·nlog₂3 + 2C·nlog₂3 − 2Cn n · nlog₂(3/2) = nlog₂2 + log₂(3/2) = nlog₂3
= 3C·nlog₂3 − 2Cn → O(nlog₂3)
왜 더 빠른가
log₂2 < log₂3 < log₂4 → 1 < log₂3 < 2 (≈ 1.585) → nlog₂3 은 n² 보다 차수가 낮다.

7이진탐색시험 ★★★

입력: 오름차순 정렬된 리스트, 찾을 값 k. 가운데와 비교해 한쪽 절반을 통째로 버림 (업다운 게임).

def bs(A, a, b, k):
    if a > b:
        return -1                    # 범위가 뒤집힘 = 없음
    m = (a + b) // 2
    if A[m] == k:
        return m                     # 값이 아니라 인덱스
    elif A[m] > k:
        return bs(A, a, m - 1, k)    # 왼쪽 절반만
    else:
        return bs(A, m + 1, b, k)    # 오른쪽 절반만
A = [2, 5, 7, 8, 15, 20, 32, 44], k = 32abmA[m]다음
1회07388 < 32 → 오른쪽
2회4752020 < 32 → 오른쪽
3회67632찾음 → 6 반환
T(n) = T(n2) + C = T(n2k) + kC = C + C·log₂ n → O(log n) 단순히 앞에서부터 찾으면 O(n)

8그림으로 풀기 — 세로식 · 나무 그림시험 ★★★

n2 는 연산이 아니라 줄어든 입력의 크기. 연산은 옆에 붙은 C, Cn. 층마다 드는 연산을 더하고 맨 아래(크기 1) 를 더하면 T(n).

점화식그림층 합맨 아래T(n)
T(n2) + C한 줄C (같음)CC·log₂ n + C
T(n2) + Cn한 줄Cn, Cn2, … (½배)C2Cn − C
2T(n2) + Cn두 갈래Cn (같음)n · CCn·log₂ n + Cn
3T(n2) + Cn세 갈래32배씩3kC = nlog₂3C3C·nlog₂3 − 2Cn
1 + ½ + ¼ + ⋯ < 2
가로 2 · 세로 1 직사각형을 매번 남은 칸의 절반씩 채우는 것과 같아서 2 를 넘지 못함 → T(n2) + Cn ≤ 2Cn + C → O(n).

10셀프 체크

답을 떠올린 뒤 눌러서 확인.

power2 와 power3 의 점화식과 결과, 차이가 나는 이유는?
power2: 2T(n2) + C → O(n). power3: T(n2) + C → O(log n). power2 는 같은 인자로 같은 값을 두 번 계산하고, power3 는 한 번 구해 x 에 담아 재사용한다.
T(n) = 2T(n2) + C 를 전개해 결과를 구하면?
2kT(1) + C(2k−1 + ⋯ + 1) = Cn + C(n − 1) = 2Cn − C → O(n).
큰 수 단순 분할 곱셈의 점화식에 + C 가 아니라 + Cn 이 붙는 이유는?
10n, 10n/2 곱하기(뒤에 0 붙이기)와 최대 2n자리 덧셈이 모두 자리 수 n 에 비례하기 때문.
카라츠바에서 곱셈 3번은 무엇무엇인가?
xw, yz, (x + y)(w + z). 가운데 항 xz + yw = (x + y)(w + z) − xw − yz.
3T(n2) + Cn 에서 등비수열의 초항·공비·항 수와 합은?
초항 1, 공비 32, 항 k개 → 합 = (3/2)k − 13/2 − 1 = 2((3/2)k − 1).
[[1, 1], [1, 0]] × [[2, 1], [1, 1]] 은?
[[3, 2], [2, 1]] (= A³). 1행 1열 = 1·2 + 1·1 = 3, 1행 2열 = 1·1 + 1·1 = 2, 2행 1열 = 2, 2행 2열 = 1.
A = [3, 9, 14, 21, 30, 41, 55, 68] 에서 bs(A, 0, 7, 55) 의 m 순서와 반환값은?
m = 3 (21) → 5 (41) → 6 (55) → 6 반환.
2T(n2) + Cn 나무 그림에서 층 합이 모두 Cn 인 이유는?
갈래 수가 2배가 될 때 갈래 하나의 크기는 절반 → 곱이 항상 Cn. 층이 log₂ n 개 + 맨 아래 n·C → Cn·log₂ n + Cn = O(n log n).
