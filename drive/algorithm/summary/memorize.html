자주 틀리는 것

✗ 2T(n2) + C = O(n log n)O(n). n log n 은 + Cn 일 때
✗ 반씩 쪼개면 무조건 빨라진다power2 처럼 같은 값을 2번 부르면 O(n) 그대로
✗ Quick Select 최악 O(n log n)O(n²). n log n 은 좋은 피벗 + a ≤ n 가정
✗ MoM 의 X 원소 < m*≤ m* (m* 자신 포함)
✗ 선택 정렬 교환은 최악 n − 1항상 n − 1 (조건 없이 매 라운드 교환)
✗ 버블 · 삽입은 무조건 stable부등호가 >= 면 stable X
✗ 병합 정렬 최악 O(n²)항상 반반 → 항상 O(n log n)
✗ A[i] = B[i]A[i] = B[i − first]
✗ heapify_down 은 작은 자식과 교환큰 자식과 교환
✗ n! ≤ (n2)n2n! ≥ (n2)n2 — 작은 값으로 바꿔 아래에서 받침
✗ 하한 3 = 모든 입력에서 3번최악의 경우 3번 필요 (트리 높이)
✗ max(S) 대신 S[n − 1] 이 답어느 칸에서 끝날지 모르므로 S 전체의 최댓값
✗ low · high 를 0 으로 시작1 로 시작 (수 하나도 길이 1)
