그리디 Greedy9-2 ~ 10-2

출제 가능성이 높은 순서. 빨간 글씨가 외울 답 — 빨간 셀로판지로 가리면 그대로 빈칸 문제가 된다.

01
Huffman 코딩이 항상 최적임을 증명하시오.
기말 확정 (11/9 교수님) — 결론보다 과정
  1. 보조 1: 빈도가 가장 작은 x, y 를 가장 깊은 형제로 갖는 최적 트리가 존재 — 가장 깊은 a 와 x 를 바꿔도 (f(x) − f(a))(dT(x) − dT(a)) ≥ 0 이라 비용이 늘지 않음
  2. 보조 2: 가장 깊은 형제 u, v 를 부모 w 로 합치면 cost(B) − cost(B′) = f(u) + f(v)
  3. 귀납: n = 2 자명 / n < k 이면 최적이라고 가정 / n = k 를 보인다
  4. n = k: x, y 를 합친 T′ 은 cost(T′) = cost(T) − f(x) − f(y). T 가 최적이 아니라면 더 싼 T″ 에서 같은 합치기를 하면 cost(T″ − {x, y}) < cost(T′) — 그런데 T′ 은 귀납 가정으로 최적 → 모순
02
빈도가 주어질 때 허프만 트리를 그리고 코드와 전체 비트 수를 구하시오.
중간고사 유형 (트리 그리기 · 계산)
  1. 빈도가 가장 작은 두 개를 합친다 → 합친 노드의 빈도 = 두 빈도의 합 → 한 개 남을 때까지
  2. 왼쪽 0, 오른쪽 1 → 루트에서 리프까지 경로 = 코드
  3. 전체 비트 = Σ 빈도 × 깊이  /  고정 길이와 비교: 문자 6개면 3비트 × 총 빈도

예: a43 b13 c12 d16 e9 f7 → 16, 25, 32, 57, 100 → a 0, b 101, c 100, d 111, e 1101, f 1100 → 230비트 (고정 300비트)

03
허프만 의사코드의 빈칸을 채우고 수행시간을 쓰시오.
중간고사 유형 (빈칸 · 시간복잡도)
while len(T) > 1: x = extract_min(T); y = extract_min(T) z = Node(left = x, right = y) f(z) = f(x) + f(y); insert(T, z)

extract_min · insert = O(log n) (min heap 높이) → 반복 n 번 → 전체 O(n log n)

04
강의 시작 · 끝 시간이 주어질 때 그리디로 배정되는 강의를 구하시오.
중간고사 유형 (결과값 추적)
  1. 끝나는 시간(F) 오름차순 정렬 → 첫 강의 선택
  2. 마지막으로 고른 강의 k 에 대해 F[k] ≤ S[i] 이면 i 선택, k = i

예: S = [1, 3, 0, 5, 3, 5, 6, 8, 8, 2, 12], F = [4, 5, … , 14] → L = [0, 3, 7, 10], 4개

05
빨리 끝나는 강의부터 고르는 전략이 최적임을 증명하시오.
교수님: 그리디는 동작 이해 + 귀류법 증명이 출제 대상
  1. 가정: 그리디 해(0, 3, 7, 10)는 최적이 아니다 → 5개짜리 a1 ~ a5 가 있다
  2. 0번이 가장 먼저 끝나므로 a1 → 0 으로 바꿔도 안 겹침. A1 ⊂ G1 이므로 a2 → 3, … , a4 → 10 도 가능
  3. 남은 a5 는 10번 뒤에 시작 → for 문이 모든 강의를 훑으므로 그리디가 놓칠 수 없음 → 모순
06
강의실 배정 알고리즘의 빈칸과 수행시간
중간고사 유형 (빈칸 · 시간복잡도)
L = [0], k = 0 for i in range(1, n): if F[k] <= S[i]: L.append(i), k = i

정렬 O(n log n) + for 문 O(n) → 전체 O(n log n)

07
짧은 일부터 하는 전략이 최적임을 증명하시오.
필기 증명 (9-2)

가정: 3개는 최적이 아님 → 4개 b1 ~ b4 가능. X = a1 + a2 + a3, Y = b1 + b2 + b3

X + a4 > T (그리디가 멈춤) · Y + b4 ≤ T (가정) · X ≤ Y, a4 ≤ b4 (가장 짧음) → X + a4 ≤ T 모순

08
큰 동전부터 주는 전략이 항상 최적인가? 아니라면 반례를 드시오.
필기 (9-2) — 단위만 바꿔 출제 가능

단위가 서로 약수 관계일 때만 최적. 반례: 동전 1, 5, 7원으로 10원 → 그리디 4개 (7 + 1 + 1 + 1) vs 최적 2개 (5 + 5)

09
prefix-free code 를 설명하고, 주어진 코드가 prefix-free 인지 판정하시오.
필기 (10-1)

어떤 문자의 코드도 다른 문자 코드의 앞부분(prefix)이 아닌 코드. 이진 트리에서 문자를 리프에만 두면 자동으로 만족. 반례: 0, 00 → 00 을 aa 로 읽을지 c 로 읽을지 모름
