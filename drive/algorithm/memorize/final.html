Huffman 코딩이 항상 최적임을 증명
보조 1
최소 빈도 x, y 가 가장 깊은 형제인 최적 트리 존재x ↔ 가장 깊은 a 교환: (f(x) − f(a))(dT(x) − dT(a)) ≥ 0
교환 결과
T′ 도 최적 (비용이 늘지 않으므로)
보조 2
cost(B) − cost(B′) = f(u) + f(v)형제 u, v → 부모 w
부모 깊이
dB′(w) = dB(u) − 1
귀납
n = 2 자명 → n < k 가정 → n = k 증명
n = k
cost(T′) = cost(T) − f(x) − f(y)T′ = T 의 x, y 를 합친 트리
모순
cost(T″ − {x, y}) < cost(T′)T′ 은 귀납 가정으로 최적인데 더 작은 트리가 있음

허프만 트리 · 코드 · 전체 비트 수
합치기

코드

Σ 빈도 × 깊이고정 길이 = 문자 수를 표현하는 비트 × 총 빈도

허프만 의사코드 빈칸 · 수행시간
while len(T) > 1: x = extract_min(T); y = extract_min(T) z = Node(left = x, right = y) f(z) = f(x) + f(y); insert(T, z)

전체
O(n log n)n 번 반복
