01점화식 연습 ① — 이진탐색을 직관으로 풀기

시험 ★★★

오늘은 점화식 연습입니다. 첫 번째는 이진탐색의 T(n) = T(n2) + C 입니다. 이번에는 식을 한 줄씩 전개하지 않고, 문제가 줄어드는 과정을 세로로 그려서 드는 연산을 세는 방식으로 풉니다.

식을 읽는 법

기호뜻
T(n)입력이 n개일 때 걸리는 전체 시간
T(n2)반으로 줄어든 문제를 푸는 시간. n2 은 연산이 아니라 줄어든 문제(입력)의 크기
Cn개를 n2개로 한 번 줄이는 과정에서 드는 연산

이진탐색에서 C 는 가운데 자리 m 을 계산하고 A[m] 과 k 를 비교하는 일입니다. 입력 크기와 상관없이 몇 번으로 끝나서 상수입니다.

세로식 — 줄어드는 크기와 그때마다 드는 연산

다 더하기

오른쪽 영역 :  C 가 k 개               →  C·k
아래 영역   :  T(1) = C

T(n) = C·k + C

가정 : n = 2k   →   k = log₂ n

T(n) = C·log₂ n + C
     = O(log₂ n) = O(log n)
필기 오타 — 고쳐서 반영

필기에 n/2^k = T(1) = C 로 되어 있었는데, 왼쪽의 n2k 은 크기이고 T(1) 은 시간이라 등호로 바로 이을 수 없습니다. 정확히는 두 줄입니다.

크기 :  n2k = 1
시간 :  T(n2k) = T(1) = C
지난 시간의 전개 풀이와 비교
전개 (지난 과제 대비)세로식 (오늘)
하는 일T( ) 안에 식을 계속 대입줄어드는 크기를 세로로 적고 옆에 드는 연산을 적음
C·k 가 나오는 곳일반항 T(n2k) + k·C오른쪽 영역의 C 개수
마지막 C 가 나오는 곳T(n2k) = T(1) = C 대입아래 영역
결과C·log₂ n + C = O(log n) — 같음

세로식은 같은 계산을 그림으로 본 것입니다. 오른쪽 한 칸 = 전개에서 한 번 대입할 때 붙는 C 하나입니다.

02점화식 연습 ② — Quick Select 최선의 경우

시험 ★★★

Quick Select 의 best case 는 T(n) = T(n2) + Cn 입니다. 이진탐색과 모양이 같은데, 뒤에 붙는 것이 상수 C 가 아니라 Cn 입니다. 한 번 줄일 때 리스트 전체를 한 번씩 훑어 A/M/B 로 나누기 때문에, 드는 연산이 그때의 크기에 비례합니다.

세로식

이진탐색(01)과 무엇이 다른가
01 이진탐색02 Quick Select 최선
점화식T(n2) + CT(n2) + Cn
오른쪽 칸C, C, …, C (모두 같음)Cn, C·n2, …, C·n2k−1 (절반씩 작아짐)
오른쪽 합C·k — 개수를 셈Cn × 등비수열 — 등비수열 합을 구함
결과O(log n)O(n)

풀이 ① — 등비수열 합 공식으로 정확히

T(n) = Cn·( 1 + 12 + 12² + … + 12k−1 ) + C

밑줄 : 초항 a = 1 ,  공비 r = 12 ,  항 k 개인 등비수열의 합

등비수열의 합 = a(1 − rk)1 − r          ← r < 1 일 때 쓰는 꼴

     = 1·(1 − (12)k)1 − 12 = 2·(1 − 12k)

가정 : n = 2k   →   2·(1 − 1n)

T(n) = Cn · 2·(1 − 1n) + C
     = 2Cn − 2C + C
     = 2Cn − C

⇒ O(n)
공식의 n 과 입력 크기 n 을 섞지 않기

필기에는 등비수열 합이 a(1-r^n)/(1-r) 로 적혀 있습니다. 공식 자체는 맞지만 여기서 항의 개수는 k 이므로 rk 로 써야 합니다. 이 문제에는 입력 크기 n 이 따로 있어서, 공식에 n 을 그대로 쓰면 두 n 이 섞입니다. 위 풀이에는 k 로 바꿔 적었습니다.

풀이 ② — 아무리 더해도 2 를 넘지 않는다

괄호 안 1 + 12 + 14 + … 는 넓이로 보면 가로 2, 세로 1 인 직사각형을 채우는 것과 같습니다.

1 + 12 + 12² + … + 12k−1  ≤  2

T(n) ≤ Cn · 2 + C = 2Cn + C

⇒ O(n)
두 풀이의 관계

① 은 정확한 값(2Cn − C), ② 는 위로 막은 값(2Cn + C 이하)입니다. Big-O 는 상한이라 ② 만으로도 O(n) 이 됩니다. 실제로 ① 의 2Cn − C 는 ② 의 2Cn + C 보다 작아서 두 결과가 맞습니다. n = 2 ~ 128 을 직접 넣어 보면 T(n) = 2n − 1 (C = 1) 로 ① 과 일치합니다.

03점화식 연습 ③ — 정렬: T(n) = 2T(n2) + Cn

Q3T(n) = T(n2) + Cn 에서 (1) 등비수열 합 공식으로 T(n) 을 정확히 구하고, (2) 공식 없이 O(n) 임을 보이시오.계산+서술응용
모범답안(1) T(n) = Cn(1 + 12 + … + 12k−1) + C. 초항 1, 공비 12, 항 k개 → 합 = 2(1 − 12k) = 2(1 − 1n). T(n) = 2Cn − 2C + C = 2Cn − C.
(2) 1 + 12 + 14 + … 는 매번 남은 부분의 절반만 더하므로 2 를 넘지 못한다. 따라서 T(n) ≤ 2Cn + C → O(n).
Q4T(n) = 2T(n2) + Cn 을 나무 그림으로 풀 때, 모든 층의 합이 Cn 으로 같은 이유를 쓰고 T(n) 을 구하시오.서술+계산응용
