01DP 로 푸는 순서 — 지난 시간 정리

시험 ★★교수님 강조

DP 문제는 다음 순서로 접근합니다.

단계할 일7-1 최대 구간 합에서는
1해를 분석 — 큰 문제를 작은 문제(부 문제, subproblem)로 나누어 생각A[k] 로 끝나는 최대 구간 합 S[k] 로 쪼갬
2부 문제의 해로 큰 문제의 해를 만드는 점화식S[k] = max(S[k − 1] + A[k], A[k])
3DP 테이블(해를 저장하는 리스트·배열)을 순서대로 채움S[0] 부터 S[n − 1] 까지
4정확성 판별—

4단계는 1·2단계를 제대로 하면 해결되므로, 실제로 신경 쓸 과정은 1 ~ 3단계입니다. 함수를 계속 다시 부르지 않고 DP 테이블에서 해를 꺼내 쓰기 때문에 시간이 크게 줄었습니다 (피보나치 O(1.6n) → O(n)).

오늘은 이 순서를 더 복잡한 문제에 적용합니다.

필기 원문
지난시간에 이어서 계속 진행 DP에서는 처음에 먼저 1. 해를 분석 : 큰 문제 → 작은 문제로 나누어서 생각 2. 부 문제(그 작은 문제)의 해를 이용해서 큰 문제의 해 (점화식) 3. DP TABLE (해를 저장하는 리스트/배열) 을 순서대로 채워넣기 (1/2로 다시) 4. 정확성 판별(사실 1-2에서 해결되기 때문에 신경써야할 과정은 1-3임) 계속 불러오는게 아니라 DP TABLE에서 해를 가져와서 사용했기 때문에 시간이 굉장히 줄어들었음 오늘은 좀 더 복잡하게 어떤 문제들을 DP로 풀 수 있는지 살펴봄

02LCS 문제 — 최장 공통 부문자열

시험 ★★★새 문제

LCS(Longest Common Subsequence) 문제 — 두 문자열에 공통으로 들어 있는 부문자열 중 가장 긴 것을 찾습니다.

X = ABCBDAB      Y = BDCABA      (길이가 달라도 됨)
부문자열 = 순서만 맞으면 됨

글자들이 꼭 붙어 있을 필요는 없고, 순서만 지키면 됩니다. 예: BB 는 X 의 2번째 B 와 4번째 B 를 고른 것.

길이공통 부문자열
1A, B, C, D
2AB, BB, BD, … (전체 10개: AA, AB, BA, BB, BC, BD, CA, CB, DA, DB)
3… (전체 10개: ABA, BAB, BBA, BCA, BCB, BDA, BDB, CAB, CBA, DAB)
4BCAB, BDAB, … (전체 3개: BCAB, BCBA, BDAB)
5존재하지 않음

가장 긴 길이 4 를 찾는 것이 LCS 문제입니다. 묻는 형태는 세 가지 — ① 길이 구하기, ② 해당 문자열 전부 찾기, ③ 문자열 1개만 찾기. 오늘 표로 구하는 것은 ① 길이입니다.

표의 괄호 속 목록은 모든 경우를 프로그램으로 확인한 것입니다. 길이 4 짜리가 여러 개이므로 LCS 는 하나로 정해지지 않을 수 있습니다 (길이는 하나).

필기 확인 — 이름과 용어

필기의 "Longest Common Sequence" → 정식 명칭은 Subsequence. 또 일반적으로 "부분 문자열(substring)" 은 붙어 있는 것만 뜻하는데, 여기서 말하는 부문자열은 붙어 있지 않아도 되는 부분수열(subsequence) 입니다. 노트에서는 교수님 표현대로 "부문자열" 로 씁니다.

필기 원문
Longest Common Sequence (LCS) 문제 최장 공통 부문자열 문제 잘 이해가 안되니까 예시로 문자열 X가 존재 한다고 해보자 X : ABCBDAB Y : BDCABA 문자열의 길이는 달라도 상관 없음 공통으로 존재하는 문자열을 찾으면 됨 꼭 붙어있을 필요는 없고 순서만 맞으면 됨 → 길이가 1인 공통 부문자열 : A, B, C, D → 길이가 2인 " : AB, BB(꼭 붙어있지 않아도 됨), BD, ... → 길이가 3인 " : ... → 길이가 4인 " : BCAB, BDAB, ... → 길이가 5인 " : 존재하지 않음(확인해보면 아무튼 그럼) 여기서 길이가 가장 긴 길이 4에 대하여 찾는 문제임 이런 알고리즘임 ⇒ LCS 문제 : 가장 긴 길이의 공통 부문자열을 찾는 문제, (길이를 찾는 혹은 문자열을 전부 찾는 혹은 문자열을 1개만 찾기)

03LCS 점화식

시험 ★★★

기호 정의 — 1단계 "작은 문제로 나누기"

Xn = x1 x2 … xn
Ym = y1 y2 … ym
Xi = x1 x2 … xi   (X 의 앞 i 글자)
Yj = y1 y2 … yj   (Y 의 앞 j 글자)

LCS(i, j) = Xi 와 Yj 의 LCS 길이 (LCS(Xi, Yj) 를 줄여 쓴 것). 구하려는 답은 LCS(n, m).

예: X3 = ABC, Y2 = BD → LCS(3, 2) = 1 (B).

규칙 — 맨 끝 글자 xi, yj 를 비교

경우LCS(i, j) 와 이유
xi = yjLCS(i − 1, j − 1) + 1
같은 끝 글자를 LCS 의 마지막 글자로 쓸 수 있음 → 그 글자를 뺀 앞부분들의 LCS 에 1 글자 추가. 길이를 구하므로 + 1
xi ≠ yjmax(LCS(i, j − 1), LCS(i − 1, j))
두 끝 글자가 동시에 LCS 의 끝일 수는 없음 → yj 를 빼 보거나 xi 를 빼 보고 더 긴 쪽
LCS(i, j) ={
LCS(i − 1, j − 1) + 1if xi = yj
max(LCS(i, j − 1), LCS(i − 1, j))if xi ≠ yj

바닥 조건: 한쪽이 빈 문자열이면 공통 글자가 없으므로 LCS(0, j) = LCS(i, 0) = 0 (다음 섹션).

필기 확인 — 오타 두 곳

LCS(X_n, Y_n) → LCS(Xn, Ym) (Y 의 길이는 m). if x_i 1= y_j → xi ≠ yj. 또 "맨 끝에 있는 수" 는 문자열이므로 "글자" 로 읽으면 됩니다.

"xi = yj 이면 LCS 에 xi 가 포함된다" 는 정확히는 "xi 를 마지막 글자로 하는 LCS 가 적어도 하나 있다" 는 뜻입니다. 앞의 예처럼 LCS 가 여러 개일 수 있기 때문입니다. 길이를 구하는 데는 차이가 없습니다.

필기 원문
X_n : x_1 x_2 ... x_n Y_m : y_1 y_2 ... y_m 이라고 정의 LCS(X_n, Y_n) ⇒ X_n, Y_m의 최장 길이 공통 부문자열의 길이 (라고 해보자) → LCS(i, j) 이렇게 간단히 하자 ⇒ X_i와 Y_j의 LCS 길이(축약한거임) X_i = x_1 x_2 ... x_i Y_j : y_1 y_2 ... y_j 규칙을 생각해보자 1. 맨 끝에 있는 수 x_i == y_j일 때 LCS에 x_i가 포함됨. LCS(i, j) = LCS(i-1, j-1)+1 과 같음. 길이구하는 거기 때문 2. x_i != y_j를 생각해보면 LCS(i, j) = max(LCS(i, j-1), LCS(i-1, j)) 가 됨 LCS(i, j) [ LCS(i-1, j-1)+1 if x_i = y_j max(LCS(i, j-1), LCS(i-1, j)) if x_i 1= y_j 대괄호 [는 LCS(i, j)가 두 경우로 나뉜다는 걸 표현한거임(묶은거야 두 식을. 텍스트라서 저렇게 표현했어)

04DP 테이블 채우기 — "순서대로"

시험 ★★★교수님 강조

LCS(i, j) 를 2차원 표 LCS[i][j] 에 저장합니다. 행 = X 의 i, 열 = Y 의 j. 한 칸을 채우려면 좌 · 좌상 · 상 세 칸만 있으면 됩니다.

필기 확인 — 2×2 칸 배치

필기는 [i-1, j-1][i, j-1] / [i-1, j][i, j] 로 i 가 열 방향인 배치인데, 아래 큰 표는 i 가 행(X 가 세로)입니다. 큰 표 기준으로는 위 그림처럼 좌 = [i][j − 1], 상 = [i − 1][j]. 또 필기의 "LCS[4][1] 보면 A 로 같아서 좌상 + 1" 은 LCS[1][4] (A 행 i = 1, A 열 j = 4) 입니다.

순서

  1. 바닥 조건 — 0 행과 0 열을 모두 0 으로 (예: LCS[0][3] = 0 — X 쪽이 빈 문자열이라 공통 글자가 있을 수 없음)
  2. 1 행을 왼쪽 → 오른쪽으로, 다음 2 행, 3 행, … 순서로 채움 — 이렇게 해야 지금 칸을 채울 때 좌·상·좌상이 항상 이미 채워져 있음
  3. 마지막 칸 LCS[n][m] 이 답
X = ABCBDAB, Y = BDCABA — 한 칸씩 채우기
지금 칸좌상 (같을 때)좌 · 상 (다를 때)비교하는 두 글자
필기 원문
DP Table을 순서대로 채우기("순서대로"!!) ⇒ LCS[i][j] 입력 [i-1, j-1][i, j-1] [i-1, j][i, j] 2*2 표임 이런식으로 할 수 있음 표 속 특정 물음표를 채우려면 그 좌, 좌상, 상 값이 필요함(체스판 같은 느낌) 시각화가 필요해 표를 그려보자(각각의 칸은 LCS[i][j]를 채울거임 X/Y None B D C A B A None | A | B | C | B | D | A | B | 바닥조건부터 채워보자(ex. 05완성된 표와 답

시험 ★★★

구하려는 것은 LCS(7, 6) → 표의 가장 오른쪽 아래 칸 4 가 답입니다. 02 번에서 직접 찾은 길이 4 와 같습니다.

표의 값은 오른쪽·아래로 갈수록 줄지 않습니다 (글자가 늘어나면 공통 부문자열이 짧아질 수 없음). 손으로 채울 때 검산용으로 쓸 수 있습니다.

필기 원문

06부문자열 찾기 — 화살표를 거꾸로

시험 ★★★판서

"그럼 길이만 구할 수 있나요? — 아니요, 이 표로 부문자열도 구할 수 있어요."

칸을 채울 때 그 값이 어디서 왔는지 화살표를 함께 기록해 둡니다.

채운 방법화살표거꾸로 갈 때
xi = yj → 좌상 + 1↖대각선으로 이동하고 그 글자를 기록
xi ≠ yj, 상이 더 큼↑위로 이동 (기록 없음)
xi ≠ yj, 좌가 더 큼←왼쪽으로 이동 (기록 없음)
xi ≠ yj, 좌 = 상↑←둘 다 가능 → 부문자열이 여러 개일 수 있는 이유

4 에서 거꾸로 따라가기

LCS[7][6] 에서 출발 — 대각선마다 글자 기록
이동기록지금까지
위로 1칸 → 대각선AA
위로 1칸 → 대각선BBA
왼쪽 1칸 → 대각선CCBA
왼쪽 1칸 → 대각선BBCBA

거꾸로 가므로 새 글자는 지금까지 모은 글자의 앞에 붙습니다 (A → BA → CBA → BCBA). 필기의 "뒷자리에 채운다" 는 완성될 문자열 기준으로 뒤쪽 자리부터 채운다는 뜻입니다.

이 경우는 부문자열 하나를 찾는 예시입니다. 첫 칸 LCS[7][6] 에서 좌 = 상 = 4 라 위 대신 왼쪽으로 가는 쪽을 고르면 (이후에도 같을 때 왼쪽) BDAB 가 나옵니다 — 프로그램으로 확인.

필기 원문
그럼 길이만 구할 수 있나요? 아니요 이 표로 부문자열도 구할 수 있어요 우리가 방금 구한 4부터 온 방향을 반대로 되찾아가면(좌랑 상이 같으면 방향이 여러개일 수 있음. 부문자열이 여러개일 수 있기 때문)(같은지 다른지에 따라서 대각선인지 좌 또는 상인지 알 수 있음) 이 때 대각선으로 갈 때마다 그 때의 문자열을 채워주면 됨 4에서 위로 한칸 가고 대각선으로 가면 이 때 A를 맨 뒷자리에 채워주면 됨 이후 위로 한칸, 대각선으로 가면 이 때 B를 뒷자리에 채워주면 됨(BA) 왼쪽으로 한칸, 대각선으로 한칸 가면 이 때 C를 뒷자리에 채워주면 됨(CBA) 왼쪽으로 한칸, 대각선 한 칸 가면 이 때 B를 뒷자리에 채워주면 됨(BCBA) (과정별 시각화 필요) 이렇게 화살표를 같이 기록하면 길이만 찾는게 아니라 실제 부문자열을 찾을 수 있다. (이 경우엔 부문자열 하나를 찾을 수 있는 예시임)

07수행시간 — O(nm)

시험 ★★★

길이 4 를 찾는 과정과 실제 부문자열을 찾는 과정의 수행시간은 같습니다 — 칸을 채울 때 화살표만 함께 기록하면 되기 때문입니다.

채울 칸 수n × m 개 (0 행·0 열 제외)
한 칸 채우는 시간점화식의 두 경우 중 하나만 계산 — 좌상 + 1 또는 max(좌, 상) → 각 O(1)
전체n × m × O(1) = O(nm)
n 과 m 이 같거나 비슷하면O(n²)

거꾸로 따라가는 과정은 한 번 이동할 때마다 i 나 j 가 1 이상 줄어 최대 n + m 번이므로 O(n + m) — O(nm) 에 묻힙니다.

필기 확인

점화식의 x_i 1= y_j 는 이번에도 xi ≠ yj 입니다.

필기 원문

09작은 문제 — A[k] 로 끝나는 가장 긴 지그재그

시험 ★★★

1단계(나누기): A[k] 로 끝나는 가장 긴 지그재그 길이를 k = 0, 1, …, 8 각각에 대해 구합니다. 전체 답은 그중 최댓값입니다 (어떤 지그재그든 어느 A[k] 에서는 끝나므로).

A[k] 바로 앞에 오는 수를 A[j] (j < k) 라 하면 두 경우로 나뉩니다.

상태조건길이
lowA[j] > A[k] — A[k] 가 내려오며 끝남A[j] 는 올라가며(high) 끝났어야 함 → high[j] + 1
highA[j] < A[k] — A[k] 가 올라가며 끝남A[j] 는 내려오며(low) 끝났어야 함 → low[j] + 1
 
low[k]  = max( high[j] + 1 )   (j < k, A[j] > A[k])
high[k] = max( low[j] + 1 )    (j < k, A[j] < A[k])
A[k] 로 끝나는 가장 긴 길이 = max(low[k], high[k])
답 = 모든 k 에 대해 max(low[k], high[k]) 의 최댓값   (Max 들 중 Max)

2단계(점화식)에서 두 리스트 low, high 가 DP 테이블입니다. LCS 는 2차원 표 하나, 지그재그는 1차원 리스트 둘.

필기 원문
예시로 이런 리스트가 있음 A = [3, -1, 2, 5, 7, 4, 5, 9, 8 ] (각 값 위에 인덱스 위치 작게 써주면 좋을듯 0 1 2 3 4 5 6 7 8) Q. 가장 긴 zigzag 길이 먼저 A[8]로 끝나는 가장 긴 zigzag = a(라고 하자) A[7]로 끝나는 가장 긴 zigzag = b A[6]로 끝나는 가장 긴 zigzag = c ... A[0]로 끝나는 가장 긴 zigzag = i 이렇게 순서대로 생각해볼 수 있음 max(a, b, ..., i)를 구하면 그 zigzag가 전체에서 가장 긴 zigzag가 될 것임 작은 문제로 분할해서 하나씩 봄 작은 문제 : A[k]로 끝나는 가장 긴 zigzag 길이? A[k]로 끝나려면 그 앞에 올 친구(A[j]라고 하자)가 더 크거나 작거나 두 경우로 나뉨 ㅇ A[j] / \ / \ ㅇ ㅇ A[k] ㅇ ㅇ A[k] / \ / \ / ㅇ ㅇ A[j] 이런 모양 두 개고 위에거를 low 상태 아래 거를 high 상태라고 해보자 low 상태 먼저 보면 high인 A[j]로 끝나는 zigzag 최대 길이 +1 high 상태 보면 low인 A[j]로 끝나는 zigzag 최대 길이 + 1 이렇게 됨 A[k]로 끝나는 가장 긴 zigzag길이 = max(A[k] low상태, A[k] high상태)

10지그재그 코드와 DP 테이블

시험 ★★★판서
Pythonlongest zigzag
# A : 수 n 개가 들어 있는 리스트
# low[k]  : A[k] 가 low 상태로(앞 수보다 작게, 내려오며) 끝나는 가장 긴 지그재그 길이
# high[k] : A[k] 가 high 상태로(앞 수보다 크게, 올라가며) 끝나는 가장 긴 지그재그 길이
low  = [1] * n                # 시작값 1 — A[k] 하나만으로도 길이 1 짜리 수열 (필기에 없어 추가)
high = [1] * n                # 0 으로 두면 모든 답이 1 씩 작게 나옴
final_max = 0                 # 지금까지 본 것 중 가장 긴 길이 (Max 들 중 Max)

for k in range(n):                        # A[k] 로 "끝나는" 경우를 k = 0 부터 차례로 — DP 테이블 순서
    for j in range(k):                    # A[k] 바로 앞에 올 친구 A[j] 후보를 전부 (j < k)
        if A[j] > A[k]:                      # A[j] 가 더 큼 → A[k] 는 내려오며 끝남 = low 상태
            low[k] = max(low[k], high[j] + 1)   # A[j] 는 올라가며 끝났어야 함 → high[j] 뒤에 A[k] 하나 추가
                                                # j 를 바꿔 가며 더 길면 갱신
        if A[j] < A[k]:                      # A[j] 가 더 작음 → A[k] 는 올라가며 끝남 = high 상태
            high[k] = max(high[k], low[j] + 1)  # A[j] 는 내려오며 끝났어야 함 → low[j] 뒤에 A[k] 추가
        # A[j] == A[k] 는 지그재그가 안 되므로 아무것도 안 함 (교수님: 제외)
    # 여기까지 오면 low[k], high[k] 확정 → A[k] 로 끝나는 가장 긴 길이 = 둘 중 큰 값
    final_max = max(final_max, max(low[k], high[k]))

return final_max                              # = max(a, b, …, i) — 전체에서 가장 긴 지그재그 길이

1. 시작값이 없음. low, high 를 1 로 채워 두어야 합니다. 0 으로 두면 수 하나짜리 수열을 세지 못해 답이 1 씩 작아집니다 (이 예에서 6 대신 5 — 프로그램으로 확인).

2. 마지막 줄 끝의 \ 는 오타로 보고 뺐고, 함수 결과로 return final_max 를 붙였습니다.

11지그재그 수행시간 — O(n²)

시험 ★★★
바깥 for (k)n 번
안쪽 for (j)k 번 — 상한으로 보면 n 번
for 안의 연산비교 · max · 대입 → 전부 O(1)
전체n × n × O(1) = O(n²)

정확히 세면 안쪽 반복은 0 + 1 + ⋯ + (n − 1) = (n − 1)n2 번이고, 이것도 O(n²) 입니다.

DP 테이블(low, high)을 두면 메모리를 조금 더 쓰지만(리스트 2개, O(n)), 수행시간을 O(n²) 으로 줄일 수 있습니다. 비교 대상은 모든 부분수열을 다 만들어 보는 방법 — 부분수열이 2n 개라 지수 시간.

12용어 정리

LCSlongest common subsequence

최장 공통 부문자열. 두 문자열에 공통으로 들어 있는, 순서를 지킨 글자 모음 중 가장 긴 것.

부문자열 (부분수열)subsequence

글자를 순서만 지키며 고른 것. 붙어 있을 필요 없음.

부분 문자열substring

붙어 있는 구간. LCS 의 "부문자열" 과 다름.

부 문제subproblem

큰 문제를 나눈 작은 문제. LCS 에서는 Xi, Yj 의 LCS.

DP 테이블DP table

부 문제의 해를 저장하는 표. LCS 는 2차원 LCS[i][j].

바닥 조건base case

LCS[0][j] = LCS[i][0] = 0.

지그재그 수열zigzag sequence

커졌다 작아졌다를 번갈아 반복하는 수열.

low · high 상태—

A[k] 가 앞 수보다 작게(내려오며) / 크게(올라가며) 끝나는 상태. low[k] = high[j] + 1, high[k] = low[j] + 1.

역추적traceback

LCS[n][m] 에서 기록한 화살표를 거꾸로 따라가며 대각선마다 글자를 모아 부문자열을 얻는 과정.
