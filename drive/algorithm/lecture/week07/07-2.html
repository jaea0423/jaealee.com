01DP 로 푸는 순서 — 지난 시간 정리

시험 ★★교수님 강조

DP 문제는 다음 순서로 접근합니다.

단계할 일7-1 최대 구간 합에서는
1해를 분석 — 큰 문제를 작은 문제(부 문제, subproblem)로 나누어 생각A[k] 로 끝나는 최대 구간 합 S[k] 로 쪼갬
2부 문제의 해로 큰 문제의 해를 만드는 점화식S[k] = max(S[k − 1] + A[k], A[k])
3DP 테이블(해를 저장하는 리스트·배열)을 순서대로 채움S[0] 부터 S[n − 1] 까지
4정확성 판별—

4단계는 1·2단계를 제대로 하면 해결되므로, 실제로 신경 쓸 과정은 1 ~ 3단계입니다. 함수를 계속 다시 부르지 않고 DP 테이블에서 해를 꺼내 쓰기 때문에 시간이 크게 줄었습니다 (피보나치 O(1.6n) → O(n)).

오늘은 이 순서를 더 복잡한 문제에 적용합니다.

필기 원문
지난시간에 이어서 계속 진행 DP에서는 처음에 먼저 1. 해를 분석 : 큰 문제 → 작은 문제로 나누어서 생각 2. 부 문제(그 작은 문제)의 해를 이용해서 큰 문제의 해 (점화식) 3. DP TABLE (해를 저장하는 리스트/배열) 을 순서대로 채워넣기 (1/2로 다시) 4. 정확성 판별(사실 1-2에서 해결되기 때문에 신경써야할 과정은 1-3임) 계속 불러오는게 아니라 DP TABLE에서 해를 가져와서 사용했기 때문에 시간이 굉장히 줄어들었음 오늘은 좀 더 복잡하게 어떤 문제들을 DP로 풀 수 있는지 살펴봄

02LCS 문제 — 최장 공통 부문자열

시험 ★★★새 문제

LCS(Longest Common Subsequence) 문제 — 두 문자열에 공통으로 들어 있는 부문자열 중 가장 긴 것을 찾습니다.

X = ABCBDAB      Y = BDCABA      (길이가 달라도 됨)
부문자열 = 순서만 맞으면 됨

글자들이 꼭 붙어 있을 필요는 없고, 순서만 지키면 됩니다. 예: BB 는 X 의 2번째 B 와 4번째 B 를 고른 것.

길이공통 부문자열
1A, B, C, D
2AB, BB, BD, … (전체 10개: AA, AB, BA, BB, BC, BD, CA, CB, DA, DB)
3… (전체 10개: ABA, BAB, BBA, BCA, BCB, BDA, BDB, CAB, CBA, DAB)
4BCAB, BDAB, … (전체 3개: BCAB, BCBA, BDAB)
5존재하지 않음

가장 긴 길이 4 를 찾는 것이 LCS 문제입니다. 묻는 형태는 세 가지 — ① 길이 구하기, ② 해당 문자열 전부 찾기, ③ 문자열 1개만 찾기. 오늘 표로 구하는 것은 ① 길이입니다.

표의 괄호 속 목록은 모든 경우를 프로그램으로 확인한 것입니다. 길이 4 짜리가 여러 개이므로 LCS 는 하나로 정해지지 않을 수 있습니다 (길이는 하나).

필기 확인 — 이름과 용어

필기의 "Longest Common Sequence" → 정식 명칭은 Subsequence. 또 일반적으로 "부분 문자열(substring)" 은 붙어 있는 것만 뜻하는데, 여기서 말하는 부문자열은 붙어 있지 않아도 되는 부분수열(subsequence) 입니다. 노트에서는 교수님 표현대로 "부문자열" 로 씁니다.

필기 원문
Longest Common Sequence (LCS) 문제 최장 공통 부문자열 문제 잘 이해가 안되니까 예시로 문자열 X가 존재 한다고 해보자 X : ABCBDAB Y : BDCABA 문자열의 길이는 달라도 상관 없음 공통으로 존재하는 문자열을 찾으면 됨 꼭 붙어있을 필요는 없고 순서만 맞으면 됨 → 길이가 1인 공통 부문자열 : A, B, C, D → 길이가 2인 " : AB, BB(꼭 붙어있지 않아도 됨), BD, ... → 길이가 3인 " : ... → 길이가 4인 " : BCAB, BDAB, ... → 길이가 5인 " : 존재하지 않음(확인해보면 아무튼 그럼) 여기서 길이가 가장 긴 길이 4에 대하여 찾는 문제임 이런 알고리즘임 ⇒ LCS 문제 : 가장 긴 길이의 공통 부문자열을 찾는 문제, (길이를 찾는 혹은 문자열을 전부 찾는 혹은 문자열을 1개만 찾기)

03LCS 점화식

시험 ★★★

기호 정의 — 1단계 "작은 문제로 나누기"

Xn = x1 x2 … xn
Ym = y1 y2 … ym
Xi = x1 x2 … xi   (X 의 앞 i 글자)
Yj = y1 y2 … yj   (Y 의 앞 j 글자)

LCS(i, j) = Xi 와 Yj 의 LCS 길이 (LCS(Xi, Yj) 를 줄여 쓴 것). 구하려는 답은 LCS(n, m).

예: X3 = ABC, Y2 = BD → LCS(3, 2) = 1 (B).

규칙 — 맨 끝 글자 xi, yj 를 비교

경우LCS(i, j) 와 이유
xi = yjLCS(i − 1, j − 1) + 1
같은 끝 글자를 LCS 의 마지막 글자로 쓸 수 있음 → 그 글자를 뺀 앞부분들의 LCS 에 1 글자 추가. 길이를 구하므로 + 1
xi ≠ yjmax(LCS(i, j − 1), LCS(i − 1, j))
두 끝 글자가 동시에 LCS 의 끝일 수는 없음 → yj 를 빼 보거나 xi 를 빼 보고 더 긴 쪽
LCS(i, j) ={
LCS(i − 1, j − 1) + 1if xi = yj
max(LCS(i, j − 1), LCS(i − 1, j))if xi ≠ yj

바닥 조건: 한쪽이 빈 문자열이면 공통 글자가 없으므로 LCS(0, j) = LCS(i, 0) = 0 (다음 섹션).

필기 확인 — 오타 두 곳

LCS(X_n, Y_n) → LCS(Xn, Ym) (Y 의 길이는 m). if x_i 1= y_j → xi ≠ yj. 또 "맨 끝에 있는 수" 는 문자열이므로 "글자" 로 읽으면 됩니다.

"xi = yj 이면 LCS 에 xi 가 포함된다" 는 정확히는 "xi 를 마지막 글자로 하는 LCS 가 적어도 하나 있다" 는 뜻입니다. 앞의 예처럼 LCS 가 여러 개일 수 있기 때문입니다. 길이를 구하는 데는 차이가 없습니다.

필기 원문
X_n : x_1 x_2 ... x_n Y_m : y_1 y_2 ... y_m 이라고 정의 LCS(X_n, Y_n) ⇒ X_n, Y_m의 최장 길이 공통 부문자열의 길이 (라고 해보자) → LCS(i, j) 이렇게 간단히 하자 ⇒ X_i와 Y_j의 LCS 길이(축약한거임) X_i = x_1 x_2 ... x_i Y_j : y_1 y_2 ... y_j 규칙을 생각해보자 1. 맨 끝에 있는 수 x_i == y_j일 때 LCS에 x_i가 포함됨. LCS(i, j) = LCS(i-1, j-1)+1 과 같음. 길이구하는 거기 때문 2. x_i != y_j를 생각해보면 LCS(i, j) = max(LCS(i, j-1), LCS(i-1, j)) 가 됨 LCS(i, j) [ LCS(i-1, j-1)+1 if x_i = y_j max(LCS(i, j-1), LCS(i-1, j)) if x_i 1= y_j 대괄호 [는 LCS(i, j)가 두 경우로 나뉜다는 걸 표현한거임(묶은거야 두 식을. 텍스트라서 저렇게 표현했어)

04DP 테이블 채우기 — "순서대로"

시험 ★★★교수님 강조

LCS(i, j) 를 2차원 표 LCS[i][j] 에 저장합니다. 행 = X 의 i, 열 = Y 의 j. 한 칸을 채우려면 좌 · 좌상 · 상 세 칸만 있으면 됩니다.

필기 확인 — 2×2 칸 배치

필기는 [i-1, j-1][i, j-1] / [i-1, j][i, j] 로 i 가 열 방향인 배치인데, 아래 큰 표는 i 가 행(X 가 세로)입니다. 큰 표 기준으로는 위 그림처럼 좌 = [i][j − 1], 상 = [i − 1][j]. 또 필기의 "LCS[4][1] 보면 A 로 같아서 좌상 + 1" 은 LCS[1][4] (A 행 i = 1, A 열 j = 4) 입니다.

순서

  1. 바닥 조건 — 0 행과 0 열을 모두 0 으로 (예: LCS[0][3] = 0 — X 쪽이 빈 문자열이라 공통 글자가 있을 수 없음)
  2. 1 행을 왼쪽 → 오른쪽으로, 다음 2 행, 3 행, … 순서로 채움 — 이렇게 해야 지금 칸을 채울 때 좌·상·좌상이 항상 이미 채워져 있음
  3. 마지막 칸 LCS[n][m] 이 답
X = ABCBDAB, Y = BDCABA — 한 칸씩 채우기
지금 칸좌상 (같을 때)좌 · 상 (다를 때)비교하는 두 글자
필기 원문
DP Table을 순서대로 채우기("순서대로"!!) ⇒ LCS[i][j] 입력 [i-1, j-1][i, j-1] [i-1, j][i, j] 2*2 표임 이런식으로 할 수 있음 표 속 특정 물음표를 채우려면 그 좌, 좌상, 상 값이 필요함(체스판 같은 느낌) 시각화가 필요해 표를 그려보자(각각의 칸은 LCS[i][j]를 채울거임 X/Y None B D C A B A None | A | B | C | B | D | A | B | 바닥조건부터 채워보자(ex. 05완성된 표와 답

시험 ★★★

LCS[7][6] = 4 → X = ABCBDAB, Y = BDCABA 의 LCS 길이는 4. 02 번에서 찾은 길이 4 와 같습니다.

표의 값은 오른쪽·아래로 갈수록 줄지 않습니다 (글자가 늘어나면 공통 부문자열이 짧아질 수 없음). 손으로 채울 때 검산용으로 쓸 수 있습니다.

보충 — 문자열 1개 찾기 (거꾸로 따라가기)

수업에서 아직 안 다룸

LCS[7][6] 에서 출발해 거꾸로 갑니다. xi = yj 이면 그 글자를 기록하고 좌상으로, 다르면 값이 같은 상(또는 좌)으로. 기록한 글자를 뒤집으면 LCS 하나가 나옵니다.

시간복잡도는 칸 (n + 1)(m + 1) 개를 각각 O(1) 에 채우므로 O(nm) 입니다 (수업에서 아직 언급 전).

06용어 정리

LCSlongest common subsequence

최장 공통 부문자열. 두 문자열에 공통으로 들어 있는, 순서를 지킨 글자 모음 중 가장 긴 것.

부문자열 (부분수열)subsequence

글자를 순서만 지키며 고른 것. 붙어 있을 필요 없음.

부분 문자열substring

붙어 있는 구간. LCS 의 "부문자열" 과 다름.

부 문제subproblem

큰 문제를 나눈 작은 문제. LCS 에서는 Xi, Yj 의 LCS.

DP 테이블DP table

부 문제의 해를 저장하는 표. LCS 는 2차원 LCS[i][j].

바닥 조건base case

LCS[0][j] = LCS[i][0] = 0.

모범답안LCS[i][j] 는 LCS[i − 1][j − 1], LCS[i − 1][j], LCS[i][j − 1] 이 있어야 계산된다. 행 순서·왼쪽부터 채우면 이 세 칸(위 행, 같은 행의 왼쪽)이 항상 먼저 채워져 있으므로, 함수를 다시 부르지 않고 표에서 꺼내 쓸 수 있다.
Q6xi ≠ yj 일 때 LCS(i − 1, j − 1) 만 보면 안 되는 이유를 예를 들어 설명하시오.서술심화
모범답안끝 글자 중 하나는 다른 쪽의 앞 글자와 짝지어질 수 있기 때문. 예: X = AB, Y = BA 에서 x2 = B ≠ y2 = A. LCS(1, 1) = 0 (A vs B) 이지만 실제 LCS 길이는 1 (A 또는 B). max(LCS(2, 1), LCS(1, 2)) = max(1, 1) = 1 이 맞다.
