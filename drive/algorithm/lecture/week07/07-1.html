01동적 계획법 ⇄ 분할정복법

시험 ★★★새 단원

오늘부터 동적 계획법(Dynamic Programming, DP) 을 배웁니다. 분할정복법(Divide & Conquer)과 짝으로 비교하며 봅니다.

분할정복법동적 계획법
Sum(n) = 1 + … + nSum(n) = Sum(n − 1) + nS[1] = 1, S[n] = S[n − 1] + n
특징답을 저장하지 않고, 필요할 때마다 함수를 다시 호출과정에서 얻은 답을 리스트·배열에 저장해 두고 재사용
의사코드Sum(n)
# 분할정복 — 저장하지 않고 다시 호출
def Sum(n):
    if n == 1: return 1
    return Sum(n - 1) + n

# 동적 계획법 — 구한 답을 S 에 저장해 두고 꺼내 씀
S[1] = 1                        # 바닥 조건
S[n] = S[n - 1] + n             # 저장된 S[n-1] 을 재사용

Sum 처럼 간단한 문제에서는 둘이 거의 같아 보이지만, 복잡한 문제에서 차이가 분명해집니다 → 다음 섹션 피보나치.

필기 확인

S = [None] 은 칸이 1개라 그대로면 S[1] = 1 에서 오류가 납니다. "S 라는 리스트에 저장한다" 는 뜻으로 줄여 쓰신 것으로 보입니다 (실제 코드는 S = [None] * (n + 1) 처럼 칸을 만들어 둠). Sun(n-1) → Sum(n-1) 오타.

필기 원문
7-1 수업 시작 오늘부터는 새로운걸 함 동적 계획법(Dynamic Programming) ^ | (양방향 상하 화살표 표현한거야) v 분할정복법(Divide & Conquer) Sum(n) = 1 + ... + (n-1) + n 분할정복법에서는 1+...+(n-1)을 묶어서 Sum(n) = Sum(n-1) + n 이렇게 표현 반면 동적 계획법은 과정에서 얻은 답을 저장하는게 특징(리스트, 배열에 저장) 예를들면 Sum(n) 이 결과를 S[n]에 저장한다고 가정 그러면 처음에 선언을 할 때 S = [None] S[1] = 1 (바닥조건) S[n] = S[n-1] + n 생긴건 굉장히 비슷 같은거 아닌가 생각할 수 있지만 문제가 간단해서 그래보이는거고 복잡한 문제를 접하면 차이점이 명확히 보임 분할정복법 Sum(n) = Sun(n-1) + n 은 저장하지 않고 호출하면서 함수를 계속 다시 재생하는데 동적 계획법은 그렇지 않음 오늘부터는 동적계획법을 배울거임

02피보나치 수 — 분할정복 vs DP

시험 ★★★

앞 수와 앞앞 수를 더해 지금 수를 정합니다. 바닥 조건 F0 = 0, F1 = 1 → 0, 1, 1, 2, 3, 5, 8, …

Fn = Fn−1 + Fn−2

분할정복 방식

Pythonfibonacci — 분할정복
def f(n):
    if n == 0 or n == 1:
        return n                # 바닥 조건 F0 = 0, F1 = 1
    return f(n - 1) + f(n - 2)   # 두 번 호출 — 같은 값을 또 계산

시간복잡도는 O(1.6n) 입니다 (1.6xxx — 증명 없이 "그렇다" 고만 하셨음, 계산하지 않음).

동적 계획법 방식

Pythonfibonacci — DP
def f(n):
    F = [0, 1]                       # 바닥 조건 포함해서 세팅 (F 는 함수 f 와 다른 리스트)
    for i in range(2, n + 1):         # i = 2 … n
        F.append(F[i - 1] + F[i - 2])  # 함수를 다시 부르지 않고 저장된 값을 재사용 — O(1)
    return F                         # 모든 피보나치 수가 들어 있음 — 원하는 건 인덱스로
필기 코드에서 고친 곳

1. return F 는 for 와 같은 높이. 필기처럼 for 안에 있으면 첫 반복(i = 2)만 하고 바로 끝납니다.

2. F = [0, 1] 은 칸이 2개라 F[i] = … 로 쓰면 i = 2 에서 인덱스 오류 → F.append(…) 로 썼습니다 (판서 의도: F[i] 에 저장).

3. range(2, n+1) 은 n번이 아니라 n − 1 번 반복. 어느 쪽이든 O(n).

분할정복동적 계획법
시간복잡도O(1.6n)O(n) — 반복 n번 × O(1)

n = 1 에서 이미 n(= 1) < 1.6 이고, n 이 커질수록 차이가 급격히 벌어집니다 (n 이 1 보다 작아지는 경우는 없음). 1.6xxx 는 황금비 ≈ 1.618 입니다.

필기 원문
피보나치수 Fibonacci number (앞 수와, 앞앞 수를 더해서 지금 수를 정하는거임) F_0 = 0 F_1 = 1 로 바닥 조건 제공 0 1 1 2 3 5 8 ... 점화식으로 나타내면 F_n = F_(n-1) + F_(n-2) 이걸 분할정복법 방식으로 하면 def f(n) : if n==0 or n==1: return n #바닥조건이 F_0 = 0, F_1 = 로 설정했기 때문에 return f(n-1) + f(n-2) ⇒ O((1.6xxx)^n) 이렇게 나옴(증명x 그냥 그렇다는거임. 우리가 계산하지 않음) F(5)부터 재귀적으로 트리처럼 뻗어나가는 걸 트리로 시각화 그 다음 레벨은 F(4) F(3) ... 부를때마다 다시 계산을 해줌 되게 불필요함 그래서 동적 계획법 기존에 계산한걸 리스트나 배열에 저장해놓는거임 DP 동적 계획법 def f(n): F = [ 0, 1 ] #바닥조건포함해서 배열 세팅 / F != f for i in range(2, n+1): ⇒ n번 반복 F[i] = F[i-1] + F[i-2] #함수를 다시 부르는게 아니라 재사용하는거임 ⇒ O(1) return F # 모든 피보나치 수가 들어감. 원하는건 인덱스로 꺼내오면 됨 동적계획법으로 피보나치수를 구하면 O(n) 좀전에 봤던 분할정복법 O((1.6xx)^n)보다 더 효율적임 그래프로 보면 제 1사분면 기준 O(?)가 y축 x축은 n O(n)은 원점을 지나는 일차함수 O(1.6xxx^n)은 해당 그래프 그려줘 근데 n = 1일 때를 확인해보면 O(n)이 더 작음. 즉 n=1일때만 봐도 시간복잡도는 동적계획법이 훨씬 나음(n=1보다 작아지는 경우는 사실 없음)

03계단 오르기

시험 ★★★판서

한 번에 1칸 또는 2칸 만 오를 수 있을 때, 1층에서 n층까지 오르는 경우의 수를 A[n] 에 저장해 구합니다.

n경로A[n]
1(이미 1층)1 (가정)
21-21
31-2-3, 1-32
41-2-3-4, 1-3-4, 1-2-43
 
A[n] = (1층 → n−1층 경우의 수) + (1층 → n−2층 경우의 수) = A[n − 1] + A[n − 2]

피보나치 수와 같은 구조입니다. A = 1, 1, 2, 3, 5, 8, 13, … (A[n] = Fn−1).

Python계단 오르기 — DP
def f(n):
    A = [None, 1, 1]                 # A[1] = 1, A[2] = 1 (0번 칸은 안 씀)
    for i in range(3, n + 1):
        A.append(A[i - 1] + A[i - 2])  # n-1 층에서 1칸 + n-2 층에서 2칸
    return A[n]
필기 오류 — A[3] = 2

필기에 "1-2-3 / 1-3 ⇒ 1개 → A[3] = 1" 로 되어 있는데, 경로가 2개이므로 A[3] = 2 입니다. 점화식 A[2] + A[1] = 1 + 1 = 2 와도 같습니다. 코드의 A[i] = … 는 피보나치와 같은 이유로 append 로 쓰고, 빠진 return A[n] 을 넣었습니다.

필기 원문
______ 다음 예시는 계단 오르기 (보낸 사진 시각화) 1칸 or 2칸 오르기만 가능 문제 : 1층에서 n층까지 오르는 경우의 수를 구하기 = A[n]에 저장해서 사용(동적계획법이기 때문) A[1] = 1 (가정) 1층 → 2층 : 1-2 ⇒ 1개 → A[2] = 1 1층 → 3층 : 1-2-3 / 1-3 ⇒ 1개 → A[3] = 1 A[n]의 경우 * n-1층에서 1칸 뛰어 n층에 오르거나 * n-2층에서 2칸 뛰어 n층에 오르는 두 경우의 수 밖에 없음 A[n] = 1층 → (n-1)층에 이르는 경우의 수 + 1층 → (n-2)층에 이르는 경우의 수 ⇒ A[n] = A[n-1] + A[n-2] 피보나치수와 같은 구조! def f(n) : A = [None, 1, 1] for i in range(3, n+1) : A[i] = A[i-1] + A[i-2] 이렇게 되는거임 이번엔 조금 더 어려운 문제

04최대 구간 합 문제

시험 ★★★

n 개의 숫자가 주어질 때 연속된 숫자의 합(A[i] + … + A[j], i ≤ j)이 최대가 되는 경우의 그 합을 구합니다. 같은 문제를 4가지 방법으로 풉니다.

방법 1 — 단순한 방법 O(n³)

모든 i, j 쌍에 대해 합을 직접 구해 비교합니다.

의사코드방법 1
max = 0
for all i:                         # n 번
    for all j (≥ i):               # n 번
        S_ij = A[i] + … + A[j]          # 더하기 최대 n 번
        if max < S_ij:
            max = S_ij
return max                         # → O(n³)
필기 원문
최대 구간 합 문제 : n개의 숫자가 주어질 때, 연속된 숫자의 합이 최대가 될 떄는? (그 합을 구하는 문제) A = [1, -1, 3, -4, 5, -4, 6, -2] 가 있다고 해보면 이 예시에서 최적의답은 5~6까지를 더하는 +7이 답임 이 "7"을 구하는게 이 문제의 목표 A[i] + ... + A[j], i<=j 에서 A[i] + ... + A[j]가 최대인 경우의 A[i] + ... + A[j]를 구함 (4가지 다른 방식으로 구해볼 예정) 1. 단순한 방법 : 모든 i, j에 대해 합 비교 max = 0 for all i : ⇒ n번 반복 for all j(>=i) : ⇒ n번 반복 S_ij = A[i] + ... + A[j] ⇒ n번 연산 if max < S_ij : max = S_ij return max ⇒ O(n^3)

05방법 2 — prefix sum O(n²)

시험 ★★★

P[i] = A[0] + … + A[i] (i 번째까지 더한 값) 를 먼저 구해 둡니다. P[0] = A[0], P[i] = P[i − 1] + A[i] 로 한 번 훑으면 되므로 O(n).

구간 합은 두 누적합의 차이입니다.

Sij = A[i] + … + A[j] = (A[0] + … + A[j]) − (A[0] + … + A[i − 1]) = P[j] − P[i − 1]
의사코드방법 2
# 1단계: prefix sum — O(n)
P[0] = A[0]
for i in range(1, n):
    P[i] = P[i - 1] + A[i]

# 2단계: 구간 합을 뺄셈 한 번으로 — O(n²)
max = 0
for all i:
    for all j (≥ i):
        S_ij = P[j] - P[i - 1]            # O(1) — i = 0 이면 P[j] 그대로
        if max < S_ij:
            max = S_ij
return max

안쪽에서 더하기 n 번이 뺄셈 1번(O(1))으로 바뀌어 O(n²) — 방법 1 보다 나아집니다.

필기 확인 — i = 0 일 때

식으로는 A[0] + … + A[−1] = 0 이라는 뜻입니다. 그런데 파이썬에서 P[-1] 은 0 이 아니라 마지막 값이라, 그대로 실행하면 A[0] 부터 시작하는 구간을 잘못 셉니다 (예: [5, −1, 2] 의 답 6 대신 2. 수업 예시는 답 구간이 A[0] 에서 시작하지 않아 우연히 7). i = 0 이면 P[j] 를 그대로 씁니다.

필기 원문
2. prefix sum A = [1, -1, 3, -4, 5, -4, 6, -2] 1. prefix Sum P를 계산. ⇒ O(n) P[i] = A[0] + ... + A[i] (i번째 까지 더한 값 = P[i]) P = [1,0,3,-1,4,0,6,4] ⇒ n번 반복 * P[0] = A[0] * P[i] = P[i-1] + A[i] O(n) ___ 2. 아까 식에서 S_ij = A[i] + ... + A[j] 를 (A[0] + ... + A[j] ) - (A[0] + ... + A[i-1]) 로 할 수 있꼬 이건 P[j] - P[i-1] 과 동일 max = 0 for all i : ⇒ n번 반복 for all j(>=i) : ⇒ n번 반복 S_ij = P[j] - P[i-1] ⇒ O(1) if max < S_ij : max = S_ij return max ⇒ O(n^2) 아까보다 시간복잡도가 더 나아짐 ___

06방법 3 — 분할정복 O(n log n)

시험 ★★★

가장 왼쪽 인덱스 l, 가장 오른쪽 r, 가운데 m = (l + r)//2 로 반을 나눕니다. 최대 구간은 세 곳 중 하나에 있습니다.

L왼쪽 절반 안의 최대 구간 합 (재귀)
R오른쪽 절반 안의 최대 구간 합 (재귀)
M가운데를 걸친 구간의 최대 — m 에서 왼쪽으로, m + 1 에서 오른쪽으로 퍼지며 각각 최대 블록을 찾아 합침
Python방법 3
def max_interval(A, l, r):
    if l >= r:                       # 원소 1개 → 그 값이 최대
        return A[l]
    m = (l + r) // 2
    L = max_interval(A, l, m)           # 왼쪽 절반의 최대
    R = max_interval(A, m + 1, r)       # 오른쪽 절반의 최대
    sum_left = max_left = A[m]          # m 에서 왼쪽으로 누적
    for i in range(m - 1, l - 1, -1):
        sum_left += A[i]
        if sum_left > max_left:
            max_left = sum_left
    sum_right = max_right = A[m + 1]    # m+1 에서 오른쪽으로 누적
    for i in range(m + 2, r + 1):    # A[m+1] 은 이미 넣었으므로 m+2 부터
        sum_right += A[i]
        if sum_right > max_right:
            max_right = sum_right
    M = max_left + max_right            # 가운데를 걸친 최대
    return max(L, M, R)
필기 코드에서 고친 곳

시험 ★★★
DP 설계 단계이 문제에서

핵심 성질

A[6] 으로 끝나는 최대 구간은 A[4..6] = 5, −4, 6 (합 7) 입니다. 이 구간에서 A[6] 을 뺀 A[4..5] 는 A[5] 로 끝나는 최대 구간(합 1) 이어야 합니다. 그보다 큰 A[5] 로 끝나는 구간이 있다면 거기에 A[6] 을 붙인 쪽이 더 커서 7 이 최대라는 데 모순이기 때문입니다.

A[k] 로 끝나는 최대 구간 합 = (A[k − 1] 로 끝나는 최대 구간 합) + A[k]   … 단, 앞이 음수가 아닐 때

max 가 들어가는 이유 — 수업에서 놓치신 부분

A[k] 로 끝나는 구간은 두 종류뿐입니다.

이어 붙이기A[k − 1] 로 끝나는 구간 뒤에 A[k] 를 붙임 → 그중 최대는 S[k − 1] + A[k]
새로 시작A[k] 혼자 (앞에 아무것도 안 붙임) → A[k]

S[k − 1] 이 음수면 앞을 붙이는 것이 손해이므로 버리고 A[k] 부터 새로 시작합니다. 그래서 둘 중 큰 쪽을 고르는 max 가 필요합니다. 교수님 배열의 k = 1 이 바로 그 경우입니다: S[0] = −1 이라 −1 + 1 = 0 보다 1 혼자가 큼 → S[1] = 1.

Python방법 4
def max_interval_DP(A):
    n = len(A)
    S = [0] * n                         # DP 테이블 — S[k] = A[k] 로 끝나는 최대 구간 합
    S[0] = A[0]                         # 바닥 조건
    for k in range(1, n):              # n − 1 번
        S[k] = max(S[k - 1] + A[k], A[k]) # 이어 붙이기 vs 새로 시작 — O(1)
    return max(S)                       # O(n)

for 문 n − 1 번 × O(1), 마지막 max(S) 가 O(n) → O(n). 네 방법 중 가장 빠릅니다.

09용어 정리

동적 계획법dynamic programming, DP

과정에서 얻은 답을 리스트·배열(DP 테이블)에 저장해 두고 재사용하는 방법.

분할정복법divide & conquer

큰 문제를 작은 문제로 쪼개 재귀로 풂. 답을 저장하지 않아 같은 계산을 반복할 수 있음.

바닥 조건base case

점화식이 시작하는 값. 예: F₀ = 0, F₁ = 1 / S[0] = A[0].

DP 테이블DP table

작은 문제의 답을 순서대로 저장하는 리스트·배열.

피보나치 수Fibonacci number

Fₙ = Fₙ₋₁ + Fₙ₋₂. 분할정복 O(1.6ⁿ), DP O(n).

최대 구간 합maximum subarray sum

연속된 구간의 합 중 최댓값.

누적 합prefix sum

P[i] = A[0] + … + A[i]. 구간 합 = P[j] − P[i − 1].
