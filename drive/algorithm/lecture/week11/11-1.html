03백트래킹의 특징

시험 ★★★

백트래킹은 사실 가능한 방식을 다 해 보는 것입니다. 막히면 되돌아가서 다른 방식으로 다시 시작.

특징내용
단점오래 걸릴 수 있다 — 가능한 길을 하나씩 다 시도하므로
장점시작 → 도착 경로가 1개 이상 존재하면 무조건 답을 찾는다
"무조건 찾는다" 의 조건

정확히는 허용된 방향(여기서는 남 · 동) 만으로 갈 수 있는 경로가 있을 때입니다. 백트래킹은 허용된 선택지를 빠짐없이 시도하므로 그런 경로가 있으면 반드시 만납니다. 남 · 동으로만 가면 같은 칸에 다시 올 일이 없지만, 네 방향을 모두 허용하면 이미 간 칸을 표시해 두어야 같은 곳을 맴돌지 않습니다.

필기 원문
사실, 백트랙은 가능한 방식을 다 해보는거임. 막힌다? 되돌아가서 다시 시작 * 오래 걸릴 수 있다 * 시작→ 도착 경로 1개 이상 존재한다면 ⇒ 무조건 답을 찾을 수 있다.

05의사코드 준비 — 미로판 M[x][y]

시험 ★★★
M미로판
x행 번호 0 ~ 4 (위 → 아래)
y열 번호 0 ~ 4 (왼쪽 → 오른쪽)
M[x][y]미로의 한 칸 (x 행 y 열)
safeM[x][y] 가 흰 칸 (갈 수 있는 칸)
unsafe막힌 칸 — 코드에서 필요 없어서 따로 정의하지 않음
헷갈리기 쉬운 점

여기서 x 는 행(세로 위치), y 는 열(가로 위치) 입니다 — 수학 좌표의 x(가로) 와 반대. 그래서 남쪽 = x + 1, 동쪽 = y + 1. 위 그림의 (행, 열) 표기와 같습니다.

필기 원문
이제 수도코드 작성 이 미로판을 M이라고 하고 행을 x, 열을 y라고 해보자. x는 0 1 2 3 4 y도 0 1 2 3 4 이렇게 되는거임 즉 미로 한칸한칸을 M[x][y] M[x][y]가 흰칸이면(갈 수 있는 칸) = safe M[x][y]가 막히는 칸이면(못가는칸) = unsafe라고할수는 있겠지만 코드에서 필요없기때문에 따로 정의하지 않음 이어서 수도코드 적을게

06의사코드 — find_way(x, y)

시험 ★★★

find_way(x, y) = (x, y) 에서 출발해 도착까지 가는 길이 있으면 true, 없으면 false 를 반환. 처음에는 find_way(0, 0) 으로 호출합니다. 미로 크기는 n × n.

의사코드find_way(x, y) — 들여쓰기 · 오타 · 범위 검사 반영
def find_way(x, y):
    if x >= n or y >= n:            # (보충) 미로 밖으로 나가면 갈 수 없음
        return false
    if x == n - 1 and y == n - 1:     # 도착 지점 (오른쪽 아래)
        return true
    if M[x][y] == safe:               # 현재 위치가 흰 칸이면
        try_down = find_way(x + 1, y)    # 1순위: 남쪽 (행 + 1) 으로 가 봄
        if try_down == true:
            return true                  # 남쪽으로 길이 있으면 끝
        try_east = find_way(x, y + 1)    # 남쪽이 막혔으면 = 백트랙해서 동쪽 (열 + 1)
        return try_east                  # 동쪽 결과가 곧 이 칸의 결과
    else:                               # 현재 위치가 검은 칸(벽) 이면
        return false
백트래킹은 어디서?find_way(x + 1, y) 가 false 를 돌려주면 (남쪽 길이 막힘) 그 호출이 끝나고 지금 칸으로 돌아와서 동쪽을 시도 — 재귀 호출이 끝나고 돌아오는 것이 곧 "최근 선택 지점으로 되돌아가기" 입니다.
벽 확인 시점이 코드는 일단 그 칸으로 호출해 본 뒤 벽이면 false 를 돌려줌 (들어가 보고 아니면 돌아옴).
필기 확인 — 그대로 실행하면 동작하지 않는 3곳

① 들여쓰기: 필기에서는 if M[x][y] == safe … 블록이 return true 아래에 들여 쓰여 있어서, 도착 지점이 아니면 아무것도 하지 않고, 도착 지점이면 그 전에 return 해 버려 이 블록은 절대 실행되지 않습니다. 첫 if 와 같은 높이로 써야 합니다.

② 오타: fine_way(x, y + 1) → find_way.

③ 미로 밖 검사: 맨 아래 행(x = n − 1)에서 find_way(x + 1, y) 를 부르면 M[n][y] 를 읽어 범위를 벗어납니다 (필기대로 파이썬으로 옮겨 두 미로에 돌리면 둘 다 인덱스 오류 — 코드로 확인). 맨 앞에 "x ≥ n 이거나 y ≥ n 이면 false" 를 넣었습니다. 교수님이 미로 밖을 unsafe 로 보고 넘어가셨는지 판서를 확인해 주세요.
