02강의를 수평선 위에 그리기

시험 ★★★

리스트만 보면 직관적이지 않아서, 문제를 풀기 위해 그림으로 다시 그립니다.

수평선0 부터 14 까지, 1칸씩 표시
강의 하나시작 ~ 끝을 수평선 위에 선(막대)으로 나타내고, 몇 번째 강의(인덱스)인지 표시 — 예: 0번 강의는 1 ~ 4
층겹치는 강의만 층을 다르게 — 아래 층부터 채움. 0번이 맨 아래, 0번과 겹치는 1번은 그 위, 둘 다와 겹치는 2번은 그 위, 3번(5 – 7)은 0번과 겹치지 않으니 0번과 같은 층

그림으로 보면 어떤 강의끼리 시간이 겹치는지 한눈에 보입니다. 예를 들어 0번(1 – 4)과 1번(3 – 5)은 3 ~ 4 가 겹치므로 한 강의실에 둘 다 배정할 수 없습니다.

필기 원문
이렇게 보면 직관적으로 보이지 않기 때문에 문제를 풀기 위해 시각적으로 다시 그림 0부터 14까지 있는 수평선을 만들고 0 1 2 3 4 이런식으로 1칸씩 표시 0번째 강의는 1~4까지 (수평선 위에 선으로 나타내고 그 선에 몇번째 인덱스인지 표시) 각 강의는 한 수평선이 아닌 층으로 구분(보기 쉽게) 여기까지 먼저 해보자 꼭 0부터 10인덱스까지 층이 점점 높아질 필요는 없어. 그냥 겹치지 않도록 층을 다르게 하는거야. 그리고 그릴 때 아래부터 채워줘. 0 인덱스가 가장 아래, 1이 그 위 등 2 그 위, 3은 자리 있으니까 0이랑 같은 층

03최적 답 — 최대 4개

시험 ★★★
답

한 강의실에 배정할 수 있는 강의는 최대 4개 — 예: 0, 3, 7, 10번 (1 – 4, 5 – 7, 8 – 11, 12 – 14).

다른 조합도 있습니다 (예: 1, 3, 7, 10번). 이 문제에서는 어떤 강의인지보다 개수가 중요하므로 답은 4개입니다.

끝 시간 = 시작 시간

1, 3, 7, 10번 조합에서 1번(3 – 5) 이 끝나는 5 에 3번(5 – 7) 이 시작합니다. 이 조합이 답이 되려면 앞 강의가 끝나는 시각에 다음 강의가 시작하는 것은 겹치지 않는 것으로 봅니다. 그림도 이 기준으로 그렸습니다.

4개가 최대인지 · 다른 조합

11개 중 겹치지 않는 조합을 모두 따져 보면 (코드로 확인) 최대는 4개이고, 4개짜리 조합은 0·3·7·10, 0·3·8·10, 1·3·7·10, 1·3·8·10 네 가지입니다. 아래부터 채운 그림의 맨 아래 층이 마침 0·3·7·10 입니다.

필기 원문
이렇게 했을 때 최적의 답은 0 3 7 10 강의를 하는 4개까지가 최대임(다른 경우의 수도 있음. 1 3 7 10 등. 근데 어떤 강의인지보다는 개수가 중요함. 개수 4개가 답)

054번 전략의 알고리즘 — O(n log n)

시험 ★★★
1F 의 오름차순으로 정렬 (빨리 끝나는 순서) → O(n log n). 비교 정렬은 이보다 빠를 수 없음 (6-2 정렬의 하한)
2L = [0], k = 0 — L: 선택한 강의의 집합, k: 가장 최근에 배정을 마친 강의의 인덱스. 정렬 후 0번(가장 빨리 끝나는 강의)은 무조건 배정
3i = 1 ~ n − 1 을 차례로 보며, F[k] ≤ S[i] (마지막으로 배정한 강의가 끝난 뒤에 시작) 이면 배정하고 k = i
4L 또는 len(L) 을 반환 (정하기 나름)
Python강의실 배정 (빨리 끝나는 강의부터)
# 1. 강의를 F(끝 시간) 오름차순으로 정렬해 두었다고 하자 — O(n log n)
L = [0]                          # 2. 가장 빨리 끝나는 0번은 바로 배정
k = 0                            #    k = 가장 최근에 배정한 강의
for i in range(1, n):            # 3. 나머지를 끝 시간 순서대로 한 번씩 — O(n)
    if F[k] <= S[i]:             #    마지막 강의가 끝난 뒤(같은 시각 포함)에 시작하면
        L.append(i)              #    배정하고
        k = i                    #    기준을 이 강의로 바꿈
return L                         # 4. 또는 len(L)
단계시간
1. 정렬O(n log n)
3. for 문 (i 마다 비교 한 번)O(n)
전체O(n log n) — 정렬이 지배

조건이 < 가 아니라 <= 라서, 앞 강의가 끝나는 시각에 시작하는 강의도 배정합니다 — 03 의 "끝 = 시작이면 겹치지 않음" 과 같은 기준.

필기 원문
4번 전략으로 알고리즘 동작 생각해보자 1. F값의 오름차순으로 정렬(Sorting) → O(nlogn)이 걸림.(소팅은 이게 최적. 이거보다 좋을 순 없음) *L은 선택한 강의의 집합이라고 해보자 2. L = [0] , k = 0 *k는 가장 최근에 배정을 마친 강의 인덱스라고 해보자 3. for i in range(1, n) : if F[k] <= S[i] : L.append(i), k=i 4. return L / len(L) (정하기 나름) 1번은 O(nlogn), 3번 for문이 O(n) 정도. 따라서 소요시간은 O(nlogn) 소요

074번 전략이 최적임을 귀류법으로 증명

시험 ★★★
시험에서 묻는 것 (교수님)

문제를 보고 그리디 전략을 찾아내라는 문제가 아닙니다. 그리디 전략이 주어졌다고 가정하고, ① 그 전략이 어떻게 동작하는지 이해하고, ② 그 전략이 최적임을 귀류법으로 증명하는 과정을 알면 됩니다.

그리디로 구한 해 (0, 3, 7, 10) 이 최적 해임을 귀류법으로 보입니다. 핵심 아이디어: 최적 해의 강의를 앞에서부터 하나씩 그리디 해의 강의로 바꿔도 여전히 겹치지 않는다 → 끝까지 바꾸면 모순이 드러난다.

단계내용
결론 부정가정: 그리디 해 (0, 3, 7, 10) 은 최적 해가 아니다 → 최적 해는 4개가 아니다 → 최소 5개. 그 최적 해를 끝나는 순서대로 a1, a2, a3, a4, a5 라 하자 (서로 겹치지 않음).
a1 → 0강의를 F 오름차순으로 정렬했으므로 0번이 전체에서 가장 빨리 끝남 → F[0] ≤ F(a1) (같아도 됨). a2 는 a1 이 끝난 뒤 시작하므로 S(a2) ≥ F(a1) ≥ F[0] → 0번과도 안 겹침 → (0, a2, a3, a4, a5) 도 겹치지 않는 5개.
집합 G1, A1G1 = 0번이 끝난 뒤에 시작하는(0번과 겹치지 않는) 강의들, A1 = a1 과 겹치지 않는 강의들. a1 보다 앞에서 끝나는 강의는 있을 수 없으므로 (아래 헷갈리는 곳 1) A1 은 a1 이 끝난 뒤에 시작하는 강의들. F[0] ≤ F(a1) 이므로 a1 뒤에 시작하는 강의는 0번 뒤에도 시작 → A1 ⊂ G1 (A1 이 G1 에 포함됨)
a2 → 3그리디가 0번 다음에 고른 3번 = G1 에서 가장 빨리 끝나는 강의. a2 는 A1 에 들어 있고 A1 ⊆ G1 이므로 a2 도 G1 의 원소 → F[3] ≤ F(a2). 3번은 0번 뒤에 시작하고, a2 보다 늦게 끝나지 않아 a3 와도 안 겹침 → (0, 3, a3, a4, a5)
연쇄같은 논리로 a3 → 7, a4 → 10 → (0, 3, 7, 10, a5) 도 겹치지 않는 5개
모순그러면 a5 는 10번이 끝난 뒤에 시작하는 강의. 그리디의 for 문은 모든 인덱스를 끝까지 훑으므로, F[10] ≤ S(a5) 인 a5 를 만났을 때 골랐어야 함. 그런데 그리디 해에는 10번 뒤에 아무 강의도 없음 → 모순 (예시에서도 14 이후에 시작하는 강의는 없음)
결론가정이 틀렸다 → 빨리 끝나는 강의부터 가능한 것을 넣는 전략 = 최적

헷갈리는 곳 1 — 왜 A1 ⊂ G1 인가

G1 은 "0번이 끝난 시각(F[0]) 이후에 시작하는 강의", A1 은 "a1 이 끝난 시각 F(a1) 이후에 시작하는 강의" 입니다. 0번은 가장 빨리 끝나므로 F[0] ≤ F(a1). 그래서 F(a1) 이후에 시작하는 강의는 자동으로 F[0] 이후에도 시작합니다 — A1 의 원소는 모두 G1 의 원소. 기준선이 더 이른(또는 같은) 쪽의 집합이 더 크거나 같습니다.

a1 보다 앞에서 끝나는 강의가 없는 이유: a1 ~ a5 는 최적 해(가장 많이 배정한 해)이고 a1 이 그중 가장 먼저입니다. 만약 a1 이 시작하기 전에 끝나는 강의 x 가 있다면 x, a1, …, a5 의 6개를 겹치지 않게 배정할 수 있어 "최적 해가 5개" 와 모순입니다. 그래서 A1 을 "a1 과 겹치지 않는 강의" 로 정의해도 실제로는 a1 뒤에 시작하는 강의만 남습니다.

예시로 확인기준 (이후에 시작)집합

a1 = 2번(0 – 6) 이라면 A1F(a1) = 6{6, 7, 8, 10} ⊂ G1
a1 = 1번(3 – 5) 이라면 A1F(a1) = 5{3, 5, 6, 7, 8, 10} = G1 (같을 수도 있음)

헷갈리는 곳 2 — 왜 3번이 A1 의 모든 강의보다 빨리 끝나는가

3번은 큰 집합 G1 전체에서 가장 빨리 끝나는 강의입니다 (예시: G1 의 끝 시간 7, 9, 10, 11, 12, 14 중 최솟값 7 = 3번). A1 은 G1 안에 들어 있는 일부이므로, A1 의 어떤 강의도 3번보다 빨리 끝날 수 없습니다 — 큰 집합의 최솟값은 그 안의 작은 집합의 모든 값 이하. 정확히는 "무조건 빨리" 가 아니라 "늦게 끝나지 않는다 (같을 수 있음)" 입니다.

필기 확인

① 포함 기호 방향: A1 ⊂ G1 (G1 ⊂ A1 이 아님) — 열린 쪽이 큰 집합 G1 을 향합니다. 여기서 ⊂ 는 부분집합(같은 경우 포함) 의 뜻으로 읽어야 합니다. 위 표처럼 a1 = 1번이면 A1 = G1 이라 "G1 보다 반드시 작다(진부분집합)" 는 성립하지 않습니다.

② "0번째가 먼저 끝나야 함 (같아도 되지 않나)" → 같아도 됩니다. F[0] ≤ F(a1).

③ "모든 A1 보다 3번이 무조건 빨리 끝남" → 같거나 빨리 끝남 (F[3] ≤ F(a2)).

④ A1 정의 (a1 과 겹치지 않는 강의) 는 판서대로 맞습니다. a1 보다 앞에서 끝나는 강의가 없는 이유는 그리디 전략 자체보다 a1 ~ a5 가 최적(최대 개수) 해라는 가정 때문입니다 — 그런 강의가 있으면 하나를 더 넣을 수 있어 모순.

ASCII 는 문자 하나를 무조건 8비트로 나타내므로 고정 길이 코드입니다. 영문 100자를 쓰면 100 × 8 = 800비트.

시험 ★★★

prefix-free 코드는 이진 트리 하나로 나타낼 수 있습니다.

○ (동그라미)중간 노드 — 문자 아님
□ (네모)리프 노드 = 문자 (문자와 1 : 1)
가지왼쪽 = 0, 오른쪽 = 1
코드 읽기루트에서 그 리프까지 온 길을 따라가며 0 · 1 을 이어 붙인 것
왜 이진 트리인가

문자를 리프 노드에만 1 : 1 로 두기로 했기 때문에, 루트에서 리프로 가는 중간에 지나는 노드는 문자가 아닙니다. 그래서 어떤 문자의 코드가 다른 문자 코드의 앞부분(prefix)이 될 수 없습니다 → 이렇게 만든 트리는 자동으로 prefix-free.

필기 확인 — 트리 그림의 층

필기 그림은 6층(깊이 0 ~ 5) 인데, 코드가 최대 4비트이므로 트리는 5층(깊이 0 ~ 4) 입니다. 필기의 세 번째 줄 "_, _, _, _, ○, ○" 가 한 층 더 들어가 있어서, c · b · ○ · d 가 한 층 아래(깊이 4)로 밀렸습니다.

깊이노드 (왼쪽 → 오른쪽)
0○ (루트)
1□ a(43) · ○
2○ (10) · ○ (11)
3□ c(12) · □ b(13) · ○ (110) · □ d(16)
4□ f(7) · □ e(9)

또 필기의 d(15) 는 빈도수 16 입니다 (빈도 합 100 에서도 16).

13용어 정리

강의실 배정 문제activity selection problem

한 강의실(자원)에 시간이 겹치지 않게 최대한 많은 강의를 배정하는 문제.

시작 시간 · 끝 시간start time · finish time

S[i] · F[i] — i 번째 강의가 시작하고 끝나는 시각.

정렬 기준 Fsort by finish time

강의를 끝 시간 오름차순으로 정렬 — 빨리 끝나는 강의부터 보기 위함. O(n log n).

L · k—

L = 선택한 강의 집합, k = 가장 최근에 배정한 강의의 인덱스.

고정 길이 코드fixed-length code

모든 문자를 같은 비트 수로 나타내는 코드. 예: ASCII 8비트.

가변 길이 코드variable-length code

많이 나오는 문자에 짧은 코드, 적게 나오는 문자에 긴 코드를 주는 코드.

prefix-free codeprefix-free code

어떤 문자의 코드도 다른 문자 코드의 앞부분이 아닌 코드 — 한 가지로만 읽힘.

빈도수frequency

문자가 나온 횟수.

리프 노드leaf node

자식이 없는 노드 — 코드 트리에서 문자가 놓이는 곳.

dT(x)depth

트리 T 에서 리프 x 의 깊이 = 문자 x 의 코드 길이(비트 수).

cost(T)—

Σ f(x) · dT(x) — 트리 T 로 부호화한 총 비트 수.

겹친다overlap

두 강의의 시간 구간이 일부라도 같은 시간을 차지하는 것. 겹치면 한 강의실에 둘 다 배정 불가.
