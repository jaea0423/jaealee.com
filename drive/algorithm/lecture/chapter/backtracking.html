1. 백트래킹 방법11주차 1차시

백트래킹
말 그대로 거슬러 올라가는 방법: 진행 → 막힌다 → 되돌아간다 (back-track) 를 반복
backtrack
되돌아가다, 거슬러 올라가다

지금까지 분할 정복법, 동적 계획법, 그리디 전략을 배웠고, 이번 단원은 백트래킹 알고리즘. 굉장히 직관적이고 쉬운 알고리즘이다.

특징

  • 사실 백트래킹은 가능한 방식을 다 해 보는 것 — 막히면 되돌아가서 다시 시작
  • 오래 걸릴 수 있다
  • 시작 → 도착 경로가 1개 이상 존재한다면 무조건 답을 찾을 수 있다
  • 그리디, 분할 정복법, DP 로 답이 없을 때 최후의 보루로 쓰는 알고리즘 (비효율적이기 때문)

2. 미로 탈출11주차 1차시, 예시 1

문제
미로의 왼쪽 위 (시작) 에서 오른쪽 아래 (도착) 까지 갈 수 있는 길 찾기
규칙
가능한 방향은 남쪽 (↓), 동쪽 (→) — 이 순서대로 탐방, 막히면 백트랙

4 × 4 미로

순서동작
1남 → (1, 0)
2남 → (2, 0) 벽 → 최근 선택으로 돌아와 동 → (1, 1)
3남 → (2, 1), 남 → (3, 1)
4남 → 막힘 (미로 밖) → 백트랙, 동 → (3, 2)
5남 → 막힘 → 백트랙, 동 → (3, 3) 도착

5 × 5 미로

  • 아래로 4번 → (4, 0) 에서 아래 막힘, 동 (4, 1) → 아래 막힘, 동 (4, 2) 벽 → 돌아감
  • (3, 0), (2, 0) 은 이미 아래를 해 봤고 동쪽이 벽 → 계속 돌아감
  • (1, 0) 에서 동 → (1, 1) → 아래 벽, 동 (1, 2) → 아래 (2, 2) → 아래 벽, 동 (2, 3) → 아래 (3, 3) → 아래 벽, 동 (3, 4) → 아래 (4, 4) 도착

의사코드 — M[x][y] 와 find_way(x, y)

미로판을 M, 행을 x, 열을 y 라 하면 한 칸은 M[x][y] (x, y = 0 ~ 4). 흰 칸 (갈 수 있는 칸) 은 safe. 막힌 칸을 unsafe 라 할 수도 있지만 코드에서 필요 없어서 따로 정의하지 않는다.

pseudocodefind_way(x, y) — 길이 있으면 true, 첫 호출 find_way(0, 0)
def find_way(x, y):
    if x == n - 1 and y == n - 1:     # 도착 지점
        return true
    if M[x][y] == safe:               # 현재 위치가 흰 칸
        try_down = find_way(x + 1, y)    # 1순위: 남쪽
        if try_down == true:
            return true
        try_east = find_way(x, y + 1)    # 남쪽이 막혔으면 동쪽
        return try_east
    else:                             # 현재 위치가 벽
        return false
  • 세 개의 if · if · else 는 같은 높이 — 도착이면 true, 아니면 흰 칸인지 보고, 벽이면 false
  • 남쪽이 실패해서 돌아오면 동쪽을 시도 = 백트랙

3. N-Queens11주차 1차시, 예시 2

문제
N × N 체스판에 퀸 N 개를 놓되 서로 같은 행, 열, 대각선에 있으면 안 됨
답의 표기
X[k] = k 행에 놓인 퀸의 열 인덱스

4-Queens 의 답 2가지

X[0] 부터 채운다: X[0] = 0 (0행 0열) 가능 → X[1] 은 0 안 됨, 1 안 됨, 2 가능 → … 이런 식으로 채워 나가고 막히면 백트랙.

대각선 판정

위쪽 i 행의 퀸 (X[i] 열) 과 새로 놓을 k 행 c 열을 이어 만든 직각삼각형의 밑변 |c − X[i]| 과 높이 |k − i| 가 같으면 같은 대각선. 왼쪽 위에 있으면 부호가 반대라서 절댓값으로 비교.

의사코드 — nqueens(k) · is_safe(k, c)

pseudocodenqueens(k) — X[k] 를 정함, 첫 호출 nqueens(0)
def nqueens(k):
    if k == N:                  # 0 ~ N-1 행을 모두 채움
        print(X)
        return
    for c in range(N):          # k 행의 0 ~ N-1 열을 차례로
        if is_safe(k, c):
            X[k] = c
            nqueens(k + 1)

def is_safe(k, c):              # X[0] ~ X[k-1] 은 이미 정해짐
    for i in range(k):
        if X[i] == c:           # 같은 열 (같은 행은 이미 걸러져 있음)
            return False
        if abs(X[i] - c) == abs(i - k):   # 같은 대각선
            return False
    return True
  • 행마다 퀸을 하나씩 놓으므로 같은 행은 처음부터 생기지 않는다
  • for 가 끝나면 이 행에는 더 놓을 곳이 없음 → 위 행으로 돌아감 = 백트랙

4. Subset Sum (부분집합의 합)11주차 1차시 ~ 12주차 1차시, 예시 3

문제
집합 A 의 부분집합 중 원소의 합이 S 가 되는 부분집합이 존재하는지 (혹은 그 부분집합이 무엇인지)
예시
A = {8, 6, 7, 5, 3, 10, 9}, S = 15 → 답 4개: {8, 7}, {7, 5, 3}, {5, 10}, {6, 9}
  • 예전에 한 부분합 최대 (연속된 구간) 와 다름 — 순서 상관없고 연속되지 않아도 됨 → 백트래킹으로 풀 수 있음
  • 원소마다 넣는다 / 안 넣는다 2가지 → 부분집합의 개수 2|A|개를 하나씩 체크

subsetsum1 — 있으면 True

pseudocodesubsetsum1(A, S) — 모든 원소는 양의 정수
def subsetsum1(A, S):
    if S == 0:                    # 딱 맞게 떨어짐
        return True
    if S < 0 or len(A) == 0:      # 넘쳤거나 더 가져올 원소가 없음
        return False
    z = A[0]                      # 0번째 원소를 넣을지 말지
    B = A[1:]
    with_z = subsetsum1(B, S - z)     # 포함: S 가 z 만큼 줄어듦
    without_z = subsetsum1(B, S)      # 제외: S 는 그대로
    return with_z or without_z        # 하나만 True 여도 True

필기의 with, without 은 파이썬 예약어 (with) 와 겹쳐 이름을 바꿨다.

재귀 탐색 트리 — A = [8, 6, 7], S = 15

  • 8 ○ → S = 7 → 6 ○ → S = 1 → 7 ○ 이면 S = −6 (가망 없음) → 백트랙 → 7 ✕ 이면 S = 1 인데 원소가 없음 → 백트랙
  • S = 7 로 돌아가 6 ✕ → S = 7 → 7 ○ → S = 0 → True, 더 백트래킹할 필요 없음
  • 루트의 8 ✕ 쪽 (S = 15) 은 선택한 쪽을 타고 가다 백트래킹할 것이므로 보류

subsetsum2 — 남은 원소를 인덱스 i 로

pseudocodesubsetsum2(A, i, S) — {A[0], …, A[i]} 중 합이 S 인 부분집합이 있는가
def subsetsum2(A, i, S):
    if S == 0:
        return True
    elif S < 0 or i == -1:
        return False
    else:                                # A[i] 를 넣을지 말지
        with_i = subsetsum2(A, i - 1, S - A[i])
        without_i = subsetsum2(A, i - 1, S)
        return with_i or without_i
# 호출: subsetsum2(A, len(A) - 1, S)

subsetsum1 과 하는 일은 같고, 배열을 잘라 넘기는 대신 인덱스 i 하나만 줄여 넘긴다 → 인자가 (i, S) 두 숫자라서 점화식 · DP 테이블로 옮길 수 있다.

점화식 → DP 테이블 · O(nS) 와 그 문제

DP[i][S] = DP[i − 1][S − A[i]] or DP[i − 1][S]

DP[i][S] = A[0] ~ A[i] 로 합 S 를 만들 수 있으면 True. 원하는 값은 마지막 칸 DP[n − 1][S].

i (A[i])0123456789101112131415
0 (8)TT
1 (6)TTTT
2 (7)TTTTTTT

A = [8, 6, 7], S = 15: 빈칸 = False. DP[2][15] = T. 표의 크기 = 행 n × 열 (S + 1), 칸마다 or 한 번 (기본 연산) → O(nS)

문제점 — 예: A = [1억, 5억, 1.5억, …, 7억] (10개), S = 20억 → O(nS) = O(10 × 20억). 수행시간에 입력의 크기가 아니라 값 (S) 이 들어가면 비정상적으로 크게 유추될 수 있다 → 바람직하지 않음.

subsetsum_sol — 답 하나를 반환

pseudocodesubsetsum_sol(A, S) — 답 부분집합 하나, 없으면 None
def subsetsum_sol(A, S):
    if S == 0:
        return []                    # 다 맞췄음
    if S < 0 or len(A) == 0:
        return None                  # 불가능
    z = A[0]
    B = A[1:]
    result = subsetsum_sol(B, S - z)     # z 를 넣고 시도
    if result is not None:
        return [z] + result              # 성공 → z 를 앞에 붙임
    return subsetsum_sol(B, S)           # 실패 → z 를 빼고 시도

z = 이번에 넣을지 정할 원소, B = 나머지 원소 (재귀에 넘기려고 나눈 것).

subsetsum_sol2 — 답을 모두 출력

X = 원소마다 넣으면 1, 안 넣으면 0. 예: [1, 0, 1, 0, 0, 0, 0] = {8, 7}, [0, 0, 0, 1, 0, 1, 0] = {5, 10}.

pseudocodesubsetsum_sol2(k) — X[k] 결정, 첫 호출 subsetsum_sol2(0)
def subsetsum_sol2(k):
    if k == n:                       # X 를 다 정함
        current_sum = 0
        for i in range(n):
            if X[i] == 1:
                current_sum += A[i]
        if current_sum == S:
            print(X)
        return
    X[k] = 1                         # A[k] 넣고
    subsetsum_sol2(k + 1)
    X[k] = 0                         # A[k] 빼고
    subsetsum_sol2(k + 1)

k == n 이면 넣기로 한 원소의 합을 구해 S 와 같을 때 출력하고 돌아간다.

더 효율적으로 — 정렬 + 가지치기

A 를 오름차순 정렬: [3, 5, 6, 7, 8, 9, 10]. 3 ○ 5 ✕ 6 ○ 에서 7 을 넣으면 15 를 넘음 → 오름차순이므로 그 뒤도 볼 필요 없음.

pseudocode넣는 부분 교체
    if current_sum + A[k] <= S:      # 넣어도 S 를 넘지 않을 때만
        X[k] = 1
        subsetsum_sol2(k + 1)

호출은 subsetsum_sol2(0). 재귀 호출 수 255 → 93 (보충, 코드로 확인).

5. 백트래킹 일반형 · 한계함수 · 상태 공간 트리12주차 1차시

일반형

해 X[0], X[1], …, X[n − 1] 를 차례로 다 해 보는 것.

pseudocodeBacktrack(k) — X[k] 결정, 첫 호출 Backtrack(0)
def Backtrack(k):
    if k >= n:
        output solution              # 해인지 확인하고 해면 출력
        return
    for each possible candidate c for X[k]:     # 후보를 하나씩
        if B(X[0], X[1], ..., X[k-1], c) == True:
            X[k] = c
            Backtrack(k + 1)

후보 c 는 subset sum 이면 0 / 1, N-Queens 면 0 ~ N − 1 처럼 문제마다 다르다.

한계함수 B (bounding function)

B
지금까지 정한 X[0] ~ X[k − 1] 에 후보 c 를 더했을 때 조건과 충돌하는지 체크하는 함수 — 문제마다 다름
문제B 가 검사하는 것
N-Queens같은 열 · 대각선에 있는지 (is_safe)
Subset Sum지금까지 합 + A[k] ≤ S 인지
미로벽 · 미로 밖인지
0/1 Knapsack무게 ≤ K 인지, 상한 > MP 인지 (7장)

백트래킹은 모든 가지 수를 고려해서 비효율적이지만, B 를 잘 설계해 쓸데없는 것을 제외하면 시간을 크게 줄여 쓸 만한 알고리즘이 된다.

상태 공간 트리 (State-Space Tree, SST)

재귀 탐색 트리의 각 노드 (예: S = 15) 를 상태 (state) 라 하고, 이 트리를 SST 라 부른다.

4 × 4 미로 (0 = 빈칸, 1 = 벽): 0111 / 0010 / 1011 / 0000. 왼쪽 가지 ↓, 오른쪽 가지 →. (2, 0) 처럼 갈 수 없는 가지를 판단하는 것이 한계함수.

6. Knapsack 문제12주차 2차시

문제
용량 K 인 배낭 (knapsack) 에 무게 합이 K 를 넘지 않게 아이템을 골라 담아 가치 합을 최대로
예시
K = 16, 무게 S = [2, 5, 10, 5], 가치 P = [40, 30, 50, 10]
조건내용
1 (제약)선택한 아이템의 무게 합 ≤ K
2 (목표)선택한 아이템의 가치 합 최대

두 종류

fractional knapsack0/1 knapsack
뜻아이템을 쪼개 담을 수 있음 (일부만 넣어도 됨)넣거나 (1) 안 넣거나 (0), 쪼갤 수 없음
예무게 2 · 가치 40 → 무게 1 · 가치 20 두 조각통째로만
풀이가성비 그리디백트래킹
fractional 최적 해의 가치 ≥ 0/1 최적 해의 가치 (항상)

쪼개서 빈칸 없이 꽉꽉 채울 수 있기 때문. 이 사실이 0/1 을 푸는 알고리즘에서 상한으로 쓰인다 (7장).

fractional — 가성비 그리디

가성비 P / S = 20, 6, 5, 2 (이미 가성비 순으로 나열). 가성비 좋은 것부터 최대로 넣음 = 그리디.

  • 1번 (2), 2번 (5) 통째로
  • 3번은 다 못 넣고 9 만큼 → 9 × 5 = 45
  • 가치 115

그리디 단원이 아니라서 최적성 증명은 생략 (그리디 증명은 귀류법).

0/1 — 가성비 순서로는 최적이 아님

가성비 순서로 넣으면 2 (40), 5 (30), 10 은 넘침, 5 (10) → 빈칸 4, 가치 80. 하지만 2 (40) 다음 바로 10 (50) 을 넣으면 90 이 더 크다 → 0/1 은 백트래킹으로 모든 가짓수를 보며 푼다.

7. 0/1 Knapsack 백트래킹12주차 2차시 ~ 13주차 1차시

상태 공간 트리와 노드 v · p(v) · s(v)

예시 P = [15, 16, 6], S = [3, 4, 2], K = 5, 가성비 5, 4, 3 (정렬되어 있지 않으면 먼저 정렬). 답의 형태 X = [_, _, _] → 23 = 8가지. 아이템 4개면 24 = 16가지를 봐야 하는 것이 백트래킹의 단점.

X = [] 에서 시작, 왼쪽 가지 X[0] = 1 (넣음), 오른쪽 가지 X[0] = 0 (안 넣음). [1] 의 자식은 [1, 1], [1, 0] …

v 에서 X[i] 를 정하고, v 의 두 자식 아래에서 X[i + 1] ~ X[n − 1] 를 정한다.

한계함수 — MP 와 두 가지의 상한

MP
maximum current profit — 지금까지 찾은 답 중 가장 큰 가치
상한
그 가지에서 얻을 수 있는 가치의 최댓값 = 남은 용량을 fractional 로 채운 값 (0/1 ≤ fractional 이므로)
왼쪽 X[i] = 1오른쪽 X[i] = 0
남은 용량K − s(v) − S[i]K − s(v)
상한p(v) + P[i] + fractional(i + 1, K − s(v) − S[i])p(v) + fractional(i + 1, K − s(v))
방문 안 함상한 ≤ MP상한 ≤ MP

거르는 3가지: ① 이미 넘쳐서 들어갈 수 없는 가지 ② 넣어도 되는데 굳이 안 넣는 가지 (상한 ≤ MP) ③ fractional 상한 ≤ MP — ③ 이 가장 중요.

예시 탐색 (판서)

단계가지계산판단
1[ ] → X[0] = 10 + 15 + frac(1, 2) = 15 + 8 = 2323 > MP 0 → [1] (p 15, s 3)
2[1] → X[1] = 1무게 4 > 남은 2① 넘침
3[1] → X[1] = 015 + frac(2, 2) = 15 + 6 = 2121 > MP → [1, 0] (p 15, s 3 그대로)
4[1, 0] → X[2] = 115 + 6 + frac(3, 0) = 21> MP → [1, 0, 1] → MP = 21
5[1, 0] → X[2] = 015 + frac(3, 2) = 15 + 0 = 1515 ≤ 21 → ②
6[ ] → X[0] = 00 + frac(1, 5) = 16 + 3 = 1919 ≤ 21 → ③
  • frac(a, b): a = 다음에 볼 아이템 (i + 1), b = 남은 용량. frac(1, 2) 는 아이템 1 (4, 16) 을 2 만큼 → 16 × 6 = 8, frac(1, 5) 는 16 + 아이템 2 반 (6 × 8 = 3) = 19
  • [1, 0] 의 s(v) 가 3 인 이유: fractional 은 상한을 본 것이지 실제로 넣은 것이 아님
  • 19 는 찾은 답이 아니라 상한 — 쪼갠 값이라 0/1 로는 만들 수 없음
  • 결과 MP = 21, X = [1, 0, 1]

코드 — frac_knapsack

B = 남은 아이템으로 더 얻을 수 있는 가치의 상한 (fractional). 변수: S[i] 크기, P[i] 가치, K 배낭 크기, n 아이템 수, size 남은 용량.

pythonfrac_knapsack(i, size) — B = 아이템 i ~ n-1 을 size 에 fractional 로
def frac_knapsack(i, size):
    B = 0
    items = sorted(range(i, n), key=lambda j: P[j] / S[j], reverse=True)   # 가성비 내림차순
    for j in items:
        if size == 0:
            break
        if S[j] <= size:              # 통째로
            B += P[j]
            size -= S[j]
        else:                         # 넘침 → 남은 만큼 잘라서
            B += P[j] * (size / S[j])
            size = 0
    return B

def knapsack(i, size, profit):
    if i >= n or size == 0:           # 다 정했거나 꽉 참
        update_best(profit)
        return
    if S[i] <= size:                  # X[i] = 1 (들어갈 때만)
        B = frac_knapsack(i + 1, size - S[i])
        if profit + P[i] + B > MP:
            X[i] = 1
            knapsack(i + 1, size - S[i], profit + P[i])
            X[i] = 0
    B = frac_knapsack(i + 1, size)    # X[i] = 0 (if 밖)
    if profit + B > MP:
        X[i] = 0
        knapsack(i + 1, size, profit)

def update_best(profit):              # MP 갱신
    if profit > MP:
        MP = profit
        best_X = X                    # 실제로는 X.copy()
