그리디 방법Greedy Method, 9주차 2차시 ~ 10주차 2차시

지금 이 순간 가장 좋아 보이는 것을 고르고, 그 선택을 되돌리지 않고 반복해서 답을 만든다. 그래서 그 전략이 항상 최적인지 증명하는 것이 이 단원의 전부다.

시험에 나옴 주어진 전략의 동작 추적, 귀류법 증명시험에 안 나옴 전략을 스스로 찾기기말 확정 Huffman 최적성 증명
거스름돈큰 동전부터단위가 약수 관계일 때만 최적반례 {1, 5, 7}원으로 10원 하루에 할 수 있는 일짧은 일부터최적짧은 k개의 합은 어떤 k개의 합보다도 작다 강의실 배정빨리 끝나는 강의부터최적, O(n log n)최적해를 그리디 해로 하나씩 바꿔치기 Huffman 코딩빈도가 가장 작은 두 개를 합치기최적, O(n log n)보조정리 두 개와 귀납법

그리디와 귀류법

그리디 답 = 증명이 붙어야 답. 증명 도구 = 귀류법.

그리디 방법

현재 상태에서 가장 좋은 선택을 반복해서 해를 구성

방법방식포인트
분할 정복큰 문제 → 작은 문제, 재귀 호출같은 계산 반복 가능
DP분할 + 작은 답을 테이블에 저장다시 계산 안 함
그리디지금 최선을 고르고 끝되돌리지 않음 → 최적 증명 필수

푸는 순서

교수님 안내전략을 찾는 문제는 안 나옴. 주어진 전략의 동작 이해 + 귀류법 증명만.
  1. 전략 세우기 (시험에선 주어짐)
  2. 전략대로 답 구하기 = 동작 추적
  3. 항상 최적임을 귀류법으로 증명

귀류법

헷갈리는 것부정하는 건 결론뿐. 전략(P)까지 부정하면 다른 명제.
귀류법의 틀
결론 부정 → 전개 → 모순 → 결론 참
"P 이면 Q" 증명 = P 유지, ¬Q 가정. 그리디에서 ¬Q = "그리디 해는 최적이 아니다"
답안 쓰는 법첫 줄 = 가정(결론 부정), 마지막 줄 = "가정이 모순 → 결론 성립".
예: √2 는 무리수
  1. 가정

    √2 = n / m  (n, m 서로소인 자연수)

  2. 전개

    2m2 = n2 → n = 2k → m2 = 2k2 → m 도 짝수

  3. 모순

    n, m 둘 다 짝수 ↔ 서로소

  4. 결론

    √2 는 무리수

거스름돈

큰 동전부터. 단, 동전 단위가 약수 관계일 때만 최적.

문제
동전 개수 최소
동전 1, 10, 50, 100원 / 입력 368원
전략
가장 큰 단위 동전부터
동전개수남은 금액
100원368
50원118
10원18
1원80
합계13개

최적인 이유

증명 생략수업에서 당연하다고 보고 넘어감.
  • 1, 10, 50 은 100 의 약수 → 작은 동전으로 100원을 1개보다 적게 못 만듦
  • 1, 10 은 50 의 약수 → 50원도 마찬가지

반례

시험 유형"항상 최적인가?" → 반례 하나로 답. 동전 단위만 바꿔서 나오기 쉬움.
동전 1, 5, 7원으로 10원
그리디 7 + 1 + 1 + 1 = 4개  vs  최적 5 + 5 = 2개
1, 5 가 7 의 약수가 아님 → 큰 것부터가 틀림
한 번에 정리
  • 368원 → 100 × 3, 50 × 1, 10 × 1, 1 × 8 = 13개
  • 최적 조건 = 단위가 약수 관계. 반례 {1, 5, 7}, 10원
9주차 2차시, 예제 2

하루에 할 수 있는 일

짧은 일부터 → 개수 최대. 증명 = 부등식 3개 충돌.

문제
일의 개수 최대
A = [2, 1, 4, 6, 3], T = 9
전략
소요시간 짧은 일부터
  • 답 = 개수 3 ← 1 + 3 + 4, 1 + 2 + 4 도 3개. 어떤 일인지는 상관없음

최적성 증명

왜 4개만?5개 이상이어도 그중 4개는 여전히 T 안. 4개가 불가능 → 그 이상도 불가능.
기호가 바뀐다중간고사에서도 바뀌어 나옴. a = 그리디 해, b = 가정한 더 큰 해, X · Y = 각각 앞 3개의 합.
짧은 일부터 = 최적a1, a2, a3 = 그리디 해, a4 = 그다음 짧은 일
  1. 가정

    그리디 3개는 최적 아님 → 4개 가능: b1 ≤ b2 ≤ b3 ≤ b4

    X = a1 + a2 + a3,  Y = b1 + b2 + b3
  2. ①

    X + a4 > T

    그리디가 4번째에서 멈춤
  3. ②

    Y + b4 ≤ T

    가정: b 4개는 T 안
  4. ③

    X ≤ Y,  a4 ≤ b4

    a = 가장 짧은 것들
  5. 모순

    ③ + ② → X + a4 ≤ T  ↔  ①

  6. 결론

    가정 거짓 → 짧은 일부터 = 최적 ■

그리디 해가 k 개면가정 "k + 1 개 가능", X, Y 는 앞 k 개의 합. 나머지 동일.
이 증명의 전부
X + a4 ≤ Y + b4 ≤ T  < X + a4
③ 으로 왼쪽, ② 로 가운데, ① 로 오른쪽 → 자기 자신보다 작다는 모순
채점 포인트
  1. 가정 = "최적 아님 = 하나 더 가능"
  2. 그리디가 멈춘 이유를 식으로: X + a4 > T
  3. "가장 짧은 것" 에서 부등식 두 개
  4. 충돌 → 가정 부정
한 번에 정리
  • [2, 1, 4, 6, 3], T = 9 → 1 + 2 + 3 → 3개
  • 멈춤(X + a₄ > T) + 가정(Y + b₄ ≤ T) + 가장 짧음(X ≤ Y, a₄ ≤ b₄) → 모순
