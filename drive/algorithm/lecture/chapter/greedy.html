그리디 방법Greedy Method

현재 상태에서 가장 좋은 선택을 반복해서 해를 구성한다. 선택을 되돌리지 않으므로 그 전략이 항상 최적인지 귀류법으로 증명하는 것이 핵심이다.

예제그리디 전략최적 여부수행시간증명의 핵심
거스름돈큰 단위 동전부터단위가 서로 약수 관계일 때만수업에서 안 다룸반례 {1, 5, 7}원으로 10원
하루에 할 수 있는 일소요시간 짧은 일부터최적수업에서 안 다룸그리디가 멈춤 + 가장 짧음 → 부등식 충돌
강의실 배정빨리 끝나는 강의부터최적O(n log n)최적해를 그리디 해로 하나씩 바꿔치기
Huffman 코딩빈도가 가장 작은 두 개를 합침최적O(n log n)보조정리 두 개 + 귀납법 (다음 판에 추가)
시험 안내 (교수님)
  • 그리디 전략을 찾아내라는 문제는 나오지 않는다. 전략이 주어졌을 때 동작을 이해하고 귀류법으로 증명하는 과정을 알면 된다. (11/5)
  • Huffman 코딩 최적성 증명은 기말고사에 꼭 나온다. (11/9)
  • 시험 문제는 필기 안에서 80% 정도 나온다. 기호(변수 이름)는 바뀌어 나올 수 있다.

1그리디 방법과 귀류법9주차 2차시

그리디 방법
현재 상태에서 가장 좋은(탐욕스러운) 선택(= greedy 전략)을 반복해서 해(= 답)를 구성하는 방법. greedy = 탐욕스러운.

지금까지 배운 방법과 비교

방법방식특징
분할 정복
Divide and Conquer		큰 문제 → 작은 문제로 나눠 재귀 호출호출 때 같은 것을 다시 계산 → 비효율
동적 계획법
Dynamic Programming		큰 → 작은 문제는 같음 + 작은 문제의 답을 DP 테이블에 저장 후 다시 사용다시 계산하지 않음 → 비효율 줄임
그리디 방법
Greedy Method		현재 상태에서 가장 좋은 선택을 반복선택을 되돌리지 않음 → 최적이라는 증명 필수

그리디로 푸는 순서

  1. 그리디 전략 유추: 어떤 선택이 최적일까?
  2. 그 전략대로 답 구하기 = 동작 추적
  3. 선택한 전략이 항상 최적 해를 보장함을 귀류법으로 증명 → 증명해야 그 방법이 최적이라고 말할 수 있음
선수 지식 — 귀류법 시험 범위가 아니라, 그리디 증명을 이해하기 위한 도구

귀류법 (proof by contradiction): 어떤 명제가 참임을 증명하고 싶을 때, 결론을 부정해서 모순이 발생함을 보임으로써 간접적으로 그 결론이 성립함을 보이는 방법.

결론 부정(가정) → 전개 → 모순 → 가정이 틀림 → 결론 참

"P 이면 Q" 를 증명할 때 P 는 그대로 두고 Q 만 부정한다 (P ∧ ¬Q). 그리디에서 가정은 항상 "그리디 전략으로 구한 해는 최적이 아니다".

유리수 = 분수 n / m 로 나타낼 수 있는 수 (n, m 은 자연수, 서로소)  |  무리수 = 분수로 나타낼 수 없는 수  |  서로소 = 약분이 안 되는 두 수 (최대공약수 1)

예: √2 는 무리수이다
  1. 가정
    √2 는 유리수 → √2 = n / m (n, m 은 자연수, 최대공약수 1)
    결론(무리수)을 부정
  2. 전개 1
    정리하면 2m2 = n2 → n2 은 2의 배수 → n 도 2의 배수
    자연수를 제곱한 것이 2의 배수면 그 수도 2의 배수
  3. 전개 2
    n = 2k 대입 → 2m2 = 4k2 → m2 = 2k2 → m2 은 2의 배수 → m 도 2의 배수
  4. 모순
    n, m 이 둘 다 2의 배수 ↔ 서로소(최대공약수 1)
  5. 결론
    가정이 잘못됨 → √2 는 무리수

문제

전략
가장 큰 단위 동전부터 거슬러 주기 — 단위가 가장 큰 것부터, 남은 금액으로 다시 큰 것부터
동전개수남은 금액
100원3368 → 68
50원168 → 18
10원118 → 8
1원88 → 0
합계13개

최적인 이유

  • 진짜 답이려면 이 전략이 항상 최적 해를 보장한다는 증명이 필요
  • 100원 = 100원 동전 1개 → 더 작은 1, 10, 50원으로 1개보다 적게 100원을 만들 수 있나? → No
  • 50원 = 50원 동전 1개 → 1, 10원으로 1개보다 적게 50원을 만들 수 있나? → No
  • 이유: 1, 10, 50 은 100 의 약수, 1, 10 은 50 의 약수 (50 은 1, 10 의 배수, 10 은 1 의 배수)

반례 — 그리디가 틀리는 경우

3하루에 할 수 있는 일의 개수9주차 2차시 · 예제 2

문제
일 5개의 소요시간 A = [2, 1, 4, 6, 3], 하루에 일하는 시간 T = 9 → 할 수 있는 일의 개수 최대
전략
소요시간이 적은 일부터 하기 — 최대한 많은 개수를 해야 하므로 짧은 것부터 하면 최대한 많이 할 수 있지 않을까?
  • 1 + 2 + 3 + 4 에서 4 는 불가능 (합 10, 하루 9시간 초과) → 1 + 2 + 3 만 가능 → 최적 답 3개
  • 다른 조합도 가능: 1 + 3 + 4 = 8시간, 1 + 2 + 4 = 7시간 → 그래도 일의 개수는 3개
  • 일의 시간이 아니라 일의 최대 개수가 중요

최적성 증명 (귀류법)

a1, a2, a3 = 그리디가 고른 일 (3개), a4 = 그다음(4번째)으로 짧은 일

전략: 적게 걸리는 일부터 → 최적기호는 시험에서 바뀔 수 있음
  1. 가정
    그리디로 나온 답은 최적해가 아니다 → 최적해 b1, b2, b3, b4 (3개보다 많음, 오름차순)
    a1, a2, a3 은 b1 ~ b4 가 아니다
  2. 기호
    X = a1 + a2 + a3 (전체 소요시간), Y = b1 + b2 + b3
  3. ①
    X + a4 > T
    그래서 그리디 전략으로 4번째를 못 넣음
  4. ②
    Y + b4 ≤ T
    b1 ~ b4 가 최적해라고 했으므로 성립해야 함
  5. ③
    X ≤ Y
    a1, a2, a3 은 시간이 가장 적게 걸리는 3개를 모은 것
  6. ④
    a4 ≤ b4
    그리디는 최소로 걸리는 것부터 고름 → a4 는 전체에서 4번째로 작은 값, b4 는 서로 다른 4개 중 가장 큰 값
  7. ⑤
    X + a4 ≤ Y + b4
    ③ 과 ④ 를 더함
  8. 모순
    ⑤ 와 ② → X + a4 ≤ T, 그런데 ① 은 X + a4 > T
  9. 결론
    모순 → 가정이 틀림 → 짧은 일부터 하는 그리디 해 = 최적해

핵심 한 줄: X + a4 ≤ Y + b4 ≤ T < X + a4 — 자기 자신보다 작다는 모순

시험 포인트
  1. 가정 = "그리디 해는 최적이 아니다 = 하나 더 할 수 있다"
  2. 그리디가 멈춘 이유를 식으로: X + a4 > T
  3. "가장 짧은 것부터" 라는 성질에서 X ≤ Y, a4 ≤ b4
  4. 세 식이 충돌 → 가정이 틀림 → 최적

4강의실 배정10주차 1차시 · 예제 3

문제
되도록 많은 강의를 한 강의실에 배정 = 강의의 개수를 최대로. 시작 시간 S 와 끝 시간 F 가 리스트로 주어짐 (i 번째 강의 = S[i] ~ F[i])
i012345678910
S130535688212
F4567891011121314

수평선 위에 그리면 직관적으로 보인다. 겹치는 강의만 층을 다르게, 아래부터 채운다 (0번이 가장 아래, 3번은 자리가 있어 0번과 같은 층).

최적의 답은 0, 3, 7, 10 강의를 하는 4개가 최대 (1, 3, 7, 10 등 다른 경우도 있음 — 어떤 강의인지보다 개수 4가 답).

그리디 전략 후보 (정답이 아니라 가능한 것을 생각)

번호전략판단
1소요시간이 적은 강의부터짧은 a 를 먼저 골라, 붙어 있는 b, c 두 개를 못 고르는 경우가 생김 → 반례 있음, 별로
2빨리 시작하는 강의부터먼저 오는 a 를 골라 b, c, d 를 못 고름 → 반례 있음, 별로
3가장 적게 겹치는 강의부터강의마다 몇 개가 겹치는지 세서 배정
4빨리 끝나는 강의부터이 문제의 답 (최적) — 남아 있는 시간이 많게

4번 전략의 알고리즘

pseudocode빨리 끝나는 강의부터 배정
1. F 값의 오름차순으로 정렬 (sorting)  # O(n log n)
2. L = [0], k = 0  # L: 선택한 강의의 집합, k: 가장 최근에 배정을 마친 강의 인덱스
3. for i in range(1, n):
       if F[k] <= S[i]:  # k 가 끝난 뒤에 i 가 시작하면
           L.append(i), k = i  # i 를 배정하고, 최근 강의를 i 로
4. return L / len(L)  # 무엇을 반환할지는 정하기 나름
  • 1번 정렬 = O(n log n) (정렬은 이것이 최적, 이보다 좋을 수 없음), 3번 for 문 = O(n)
  • 따라서 소요시간 = O(n log n)

최적성 증명 (귀류법)

그리디 전략으로 구한 해 = (0, 3, 7, 10). 강의는 끝나는 시간 순으로 정렬되어 있다.

빨리 끝나는 강의부터 → 최적
  1. 가정
    (0, 3, 7, 10) 은 최적해가 아니다 → 4개가 최적이 아님 = 최소 5개 → 최적해 a1, a2, a3, a4, a5 (서로 겹치지 않음, 끝나는 순)
    귀류법으로 증명하기 위해 부정으로 가정
  2. a1 → 0
    0번은 전체 중 가장 빨리 끝나는 강의 → 0번이 a1 보다 먼저(또는 같이) 끝남 → a1 을 0 으로 바꿔도 나머지와 안 겹침 → (0, a2, a3, a4, a5)
    그리디 전략이 가장 먼저 끝나는 강의를 골랐기 때문 (정렬되어 있으므로)
  3. 집합
    G1 = 0번과 겹치지 않는 강의들의 집합, A1 = a1 과 겹치지 않는 강의들의 집합 → A1 ⊂ G1
    a1 보다 앞에서 끝나는 강의는 있을 수 없음 (그리디가 가장 먼저 끝나는 0번을 골랐으므로) → a1 과 안 겹치는 강의는 0번과도 안 겹침
  4. a2 → 3
    3번 = G1 중 가장 빨리 끝나는 강의 → A1 ⊂ G1 이므로 A1 안의 어떤 강의보다도 3번이 먼저(또는 같이) 끝남 → a2 를 3 으로 바꿔도 됨
    그리디 전략이 그렇게 고르기 때문
  5. 연쇄
    같은 방법으로 a3 → 7, a4 → 10 → (0, 3, 7, 10, a5)
  6. 모순
    a5 는 10번이 끝난 뒤에 시작하는 강의 → 그리디는 for i in range(1, n) 으로 모든 강의를 훑으므로 a5 를 안 골랐을 수가 없음 → 그런데 그리디 해에 a5 가 없음
  7. 결론
    가정이 모순 → 빨리 끝나는 강의 순서로 가능한 것을 넣는 전략 = 최적
시험 포인트
  1. 가정: 그리디 해(k개)가 최적이 아님 → k + 1 개짜리 최적해
  2. 바꿔치기: 최적해의 강의를 앞에서부터 그리디 해의 강의로 하나씩 바꿔도 겹치지 않는 이유 (가장 먼저 끝남, A1 ⊂ G1)
  3. 모순: 마지막에 남은 강의를 그리디가 놓쳤을 리 없음 (모든 인덱스를 훑음)
