지금 이 순간 가장 좋아 보이는 것을 고르고, 그 선택을 되돌리지 않고 반복해서 답을 만든다. 그래서 그 전략이 항상 최적인지 증명하는 것이 이 단원의 전부다.

시험에 나옴 주어진 전략의 동작 추적, 귀류법 증명시험에 안 나옴 전략을 스스로 찾기기말 확정 Huffman 최적성 증명
거스름돈큰 동전부터단위가 약수 관계일 때만 최적반례 {1, 5, 7}원으로 10원 하루에 할 수 있는 일짧은 일부터최적짧은 k개의 합은 어떤 k개의 합보다도 작다 강의실 배정빨리 끝나는 강의부터최적, O(n log n)최적해를 그리디 해로 하나씩 바꿔치기 Huffman 코딩빈도가 가장 작은 두 개를 합치기최적, O(n log n)보조정리 두 개와 귀납법
9주차 2차시

그리디와 귀류법

그리디 답은 증명이 붙어야 답이 된다. 증명 도구는 귀류법.

정의

그리디 방법은 현재 상태에서 가장 좋은 선택(greedy 전략)을 반복해서 해를 구성하는 방법이다.

앞에서 배운 방법과의 차이

방법푸는 방식기억할 점
분할 정복큰 문제를 작은 문제로 나눠 재귀 호출같은 작은 문제를 다시 계산할 수 있다
동적 계획법나누는 것은 같고, 작은 문제의 답을 DP 테이블에 저장다시 계산하지 않아 효율적
그리디지금 가장 좋아 보이는 것을 고른다고른 것을 되돌리지 않는다 → 최적 증명이 필요

그리디 문제를 푸는 순서

교수님 안내그리디 전략을 찾아내라는 문제는 나오지 않는다. 전략이 주어졌을 때 동작을 이해하고, 귀류법으로 참임을 증명하는 과정을 알면 된다.
  1. 그리디 전략을 세운다. 시험에서는 주어진다.
  2. 그 전략대로 답을 구한다. 이것이 동작 추적 문제.
  3. 전략이 항상 최적 해를 낸다는 것을 귀류법으로 증명한다.
정의

귀류법은 결론을 부정해서 모순이 생기는 것을 보여, 간접적으로 결론이 성립함을 보이는 증명 방법이다.

헷갈리기 쉬운 것가정은 "결론의 부정" 이다. 전략까지 부정하면 다른 명제가 된다.

"P 이면 Q" 를 증명할 때 P 는 그대로 두고 Q 만 부정한다. 그리디 증명에서는 P = "이 전략으로 답을 구했다", Q = "그 답은 최적이다".

답안 쓰는 틀첫 줄에 가정(결론의 부정)을 쓰고, 마지막 줄에서 "가정이 모순이므로 결론이 성립한다" 로 닫는다. 그리디 증명도 이 네 칸을 그대로 쓴다.
√2 는 무리수이다귀류법 형식 익히기
  1. 가정

    √2 는 유리수다. 즉 √2 = n / m (n, m 은 서로소인 자연수)

  2. 전개

    2m2 = n2 → n 은 2의 배수 → n = 2k

    2m2 = 4k2 → m2 = 2k2 → m 도 2의 배수

  3. 모순

    n, m 이 둘 다 2의 배수 — 서로소라는 가정과 충돌

  4. 결론

    가정이 틀렸으므로 √2 는 무리수이다.

9주차 2차시, 예제 1

거스름돈

큰 동전부터 주면 최적이지만, 동전 단위가 서로 약수 관계일 때만이다.

문제
목표
거스름돈을 가장 적은 개수의 동전으로 준다
동전
1원, 10원, 50원, 100원
입력
368원
전략가장 큰 단위의 동전부터 거슬러 준다
동전개수남은 금액
100원368
50원118
10원18
1원80
합계13개

최적인 이유

증명 생략수업에서는 당연하다고 보고 증명하지 않았다.

100원은 100원 1개로 만든다. 1원, 10원, 50원으로 100원을 1개보다 적게 만들 수는 없다. 50원도 마찬가지다. 이렇게 되는 이유는 1, 10, 50 이 100 의 약수이고, 1, 10 이 50 의 약수이기 때문이다.

반례: 약수 관계가 아니면 틀린다

시험 유형"이 전략이 항상 최적인가?" 에는 반례 하나로 답한다. 동전 단위만 바꿔 나오기 쉽다.

동전이 1원, 5원, 7원이고 10원을 거슬러 줄 때.

방법동전개수
그리디 (큰 것부터)7 + 1 + 1 + 14
최적5 + 52

1원, 5원이 7원의 약수가 아니어서 큰 것부터 고르면 최적을 놓친다.

한 번에 정리
  • 큰 동전부터: 368원 → 100 × 3, 50 × 1, 10 × 1, 1 × 8 = 13개
  • 최적 조건은 동전 단위가 서로 약수 관계. 반례 {1, 5, 7}원, 10원 → 그리디 4개, 최적 2개
9주차 2차시, 예제 2

하루에 할 수 있는 일

짧은 일부터 하면 개수가 최대다. 증명은 부등식 세 개가 서로 충돌하는 것을 보이면 끝난다.

문제
목표
하루에 할 수 있는 일의 개수를 최대로
소요시간
A = [2, 1, 4, 6, 3]
하루
T = 9
전략소요시간이 짧은 일부터 한다

1 + 3 + 4 = 8, 1 + 2 + 4 = 7 처럼 다른 조합도 3개다. 어떤 일인지가 아니라 개수가 답이다.

최적성 증명

그리디가 고른 일을 짧은 순으로 a1, a2, a3, 그다음으로 짧은 일을 a4 라고 한다.

왜 4개만 잡나최적해가 5개, 6개여도 그중 4개만 떼어 내면 여전히 하루 안에 들어간다. 4개가 불가능하면 그보다 많은 것도 모두 불가능하다.
변수 이름이 바뀐다중간고사에서도 기호가 바뀌어 나왔다. a, b, X, Y 를 외우지 말고 "그리디 해, 가정한 더 큰 해, 각각의 앞부분 합" 이라는 역할로 기억할 것.
짧은 일부터 고르는 전략은 최적이다귀류법
  1. 가정

    그리디 해(3개) 는 최적이 아니다. 즉 4개 이상 할 수 있다. 그중 4개를 짧은 순으로 b1, b2, b3, b4 라 한다.

  2. 기호

    X = a1 + a2 + a3,   Y = b1 + b2 + b3

  3. ①

    X + a4 > T

    그리디가 4번째 일을 넣지 못하고 멈췄으므로
  4. ②

    Y + b4 ≤ T

    가정에서 b 네 개는 하루 안에 들어가므로
  5. ③

    X ≤ Y  그리고  a4 ≤ b4

    a₁, a₂, a₃ 은 가장 짧은 세 개, a₄ 는 네 번째로 짧은 일, b₄ 는 서로 다른 네 개 중 가장 긴 일이므로
  6. 모순

    ③ 과 ② 를 이으면 X + a4 ≤ Y + b4 ≤ T. 그런데 ① 은 X + a4 > T. 둘 다 참일 수 없다.

  7. 결론

    가정이 틀렸다. 짧은 일부터 고르는 그리디 해는 최적이다. ■

그리디 해가 k 개일 때가정은 "k + 1 개 가능", 기호는 X = a₁ + … + ak, Y = b₁ + … + bk. 나머지는 위와 똑같다.
① X + a4 > T② Y + b4 ≤ T③ X ≤ Y, a4 ≤ b4
③ + ②  ⇒  X + a4 ≤ T  ① 과 모순
이 증명에서 채점될 곳
  1. 가정을 "최적이 아니다 = 하나 더 할 수 있다" 로 쓴다.
  2. 그리디가 멈춘 이유를 식으로 쓴다: X + a4 > T
  3. 그리디의 성질(가장 짧은 것) 에서 부등식 두 개를 끌어낸다.
  4. 세 식이 충돌하는 것을 보이고 가정을 부정한다.
한 번에 정리
  • 짧은 일부터: [2, 1, 4, 6, 3], T = 9 → 1 + 2 + 3 → 3개
  • 증명: 그리디가 멈춤(X + a₄ > T), 더 큰 해가 가능(Y + b₄ ≤ T), 그리디가 가장 짧음(X ≤ Y, a₄ ≤ b₄) → 모순
