지금 이 순간 가장 좋아 보이는 것을 고르고, 그 선택을 되돌리지 않고 반복해서 답을 만든다. 그래서 그 전략이 항상 최적인지 증명하는 것이 이 단원의 전부다.

시험에 나옴 주어진 전략의 동작 추적, 귀류법 증명시험에 안 나옴 전략을 스스로 찾기기말 확정 Huffman 최적성 증명
거스름돈큰 동전부터단위가 약수 관계일 때만 최적반례 {1, 5, 7}원으로 10원 하루에 할 수 있는 일짧은 일부터최적짧은 k개의 합은 어떤 k개의 합보다도 작다 강의실 배정빨리 끝나는 강의부터최적, O(n log n)최적해를 그리디 해로 하나씩 바꿔치기 Huffman 코딩빈도가 가장 작은 두 개를 합치기최적, O(n log n)보조정리 두 개와 귀납법

그리디와 귀류법

그리디 답 = 증명이 붙어야 답. 증명 도구 = 귀류법.

그리디 방법 (greedy = 탐욕스러운)

현재 상태에서 가장 좋은(탐욕스러운) 선택(= greedy 전략)을 반복해서 해(= 답)를 구성하는 방법

지금까지 배운 방법과 비교

방법방식특징
분할 정복
Divide & Conquer		큰 문제 → 작은 문제로 나눠 재귀 호출호출 때 같은 것을 다시 계산 → 비효율
동적 계획법
Dynamic Programming		큰 → 작은 문제는 같음 + 작은 문제의 답을 DP 테이블에 저장 후 다시 사용다시 계산 안 함 → 비효율 줄임
그리디지금 상태에서 가장 좋은 선택을 반복선택을 되돌리지 않음 → 최적이라는 증명 필수

그리디로 푸는 순서

교수님 안내 (11/5)그리디 전략을 찾아내라는 문제는 안 나옴. 전략이 주어졌다고 가정하고, 동작을 이해하고 귀류법으로 참임을 증명하는 과정을 알면 됨.
  1. 그리디 전략 유추: 어떤 선택이 최적일까? (시험에선 주어짐)
  2. 그 전략대로 답 구하기 = 동작 추적
  3. 선택한 전략이 항상 최적 해를 보장함을 귀류법으로 증명 → 증명해야 그 방법이 최적이라고 말할 수 있음

귀류법

귀류법 (proof by contradiction)

어떤 명제가 참임을 증명하고 싶을 때, 결론을 부정해서 모순이 발생함을 보임으로써 간접적으로 그 결론이 성립함을 보이는 방법

헷갈리는 것부정하는 건 결론(Q)뿐. 전략(P)까지 부정하면 다른 명제가 됨.
귀류법의 틀
결론 부정(가정) → 전개 → 모순 → 가정이 틀림 → 결론 참
"P 이면 Q" 증명 = P 유지, ¬Q 가정 (P ∧ ¬Q). 그리디에서 ¬Q = "그리디 전략으로 구한 해는 최적이 아니다"

예: √2 는 무리수이다

  • 유리수 = 분수 n / m 로 나타낼 수 있는 수 (n, m 은 자연수, 서로소)
  • 무리수 = 분수로 나타낼 수 없는 수
  • 서로소 = 약분이 안 되는 두 수 = 최대공약수가 1
답안 쓰는 법첫 줄 = 가정(결론 부정), 마지막 줄 = "가정이 모순 → 결론 성립". 그리디 증명도 같은 틀.
√2 는 무리수이다귀류법
  1. 가정

    √2 는 유리수 → √2 = n / m  (n, m 자연수, 최대공약수 1)

    결론(무리수)을 부정
  2. 전개 1

    정리하면 2m2 = n2 → n2 은 2의 배수 → n 도 2의 배수

    자연수의 제곱이 2의 배수면 그 수도 2의 배수
  3. 전개 2

    n = 2k 대입 → 2m2 = 4k2 → m2 = 2k2 → m2 은 2의 배수 → m 도 2의 배수

  4. 모순

    n, m 둘 다 2의 배수 ↔ 서로소(최대공약수 1)

  5. 결론

    가정이 잘못됨 → √2 는 무리수 ■

9주차 2차시, 예제 1

거스름돈

큰 동전부터. 단, 동전 단위가 약수 관계일 때만 최적.

문제
거스름돈을 동전으로, 동전 개수 최소
동전 1, 10, 50, 100원 / 입력 368원
전략 (교수님)
가장 큰 단위 동전부터 거슬러 주기
  • 단위가 가장 큰 것부터 → 남은 금액으로 다시 큰 것부터
동전개수남은 금액
100원3368 → 68
50원168 → 18
10원118 → 8
1원88 → 0
합계13개

최적인 이유

  • 진짜 답이려면 → 이 전략이 항상 최적 해를 보장한다는 증명 필요
  • 100원 = 100원 동전 1개 → 더 작은 1, 10, 50원으로 1개보다 적게 100원을 만들 수 있나? → No
  • 50원 = 50원 동전 1개 → 1, 10원으로 1개보다 적게 50원? → No
  • 이유: 1, 10, 50 은 100 의 약수 / 1, 10 은 50 의 약수 (50 은 1, 10 의 배수, 10 은 1 의 배수)
증명 생략수업에서 당연하다고 보고 넘어감.

반례 — 그리디가 틀리는 경우

시험 유형"항상 최적인가?" → 반례 하나로 답. 동전 단위만 바꿔서 나오기 쉬움.
동전 1, 5, 7원으로 10원
그리디 7 × 1 + 1 × 3 = 4개  vs  최적 5 × 2 = 2개
1, 5 가 7 의 약수가 아님 → 큰 것부터 고르는 전략이 틀림
한 번에 정리
  • 368원 → 100 × 3, 50 × 1, 10 × 1, 1 × 8 = 13개
  • 최적 조건 = 단위가 서로 약수 관계. 반례 {1, 5, 7}, 10원 → 그리디 4개, 최적 2개
9주차 2차시, 예제 2

하루에 할 수 있는 일

짧은 일부터 → 개수 최대. 증명 = 부등식 3개 충돌.

문제
일 5개의 소요시간 A = [2, 1, 4, 6, 3]
하루 일하는 시간 T = 9 → 일의 개수 최대
전략
소요시간 적은 일부터 하기
  • 최대한 많은 개수 → 짧은 것부터 하면 최대한 많이 할 수 있지 않을까?
  • 1 + 2 + 3 (+ 4) → 4 는 불가능 (합 10, 하루 9시간 초과) → 1 + 2 + 3 만 가능 → 최적 답 3개
  • 다른 조합도 가능: 1 + 3 + 4 = 8시간, 1 + 2 + 4 = 7시간 → 그래도 개수는 3개
  • 일의 시간이 아니라 일의 최대 개수가 중요

최적성 증명 (귀류법)

왜 4개만?"최적이 아니다" = 3개보다 더 있다 = 4개 이상. 5개 이상이어도 그중 4개는 여전히 T 안 → 4개가 불가능하면 그 이상도 불가능.
기호가 바뀐다중간고사에서도 바뀌어 나옴. a = 그리디 해, b = 가정한 최적해, X · Y = 각각 앞 3개의 합 — 역할로 기억.
전략: 적게 걸리는 일부터a1, a2, a3 = 그리디 해 (3개), a4 = 그다음(4번째)으로 짧은 일
  1. 가정

    그리디로 나온 답은 최적해가 아니다 → 최적해 b1, b2, b3, b4 (3개보다 많음, 오름차순)

    a1, a2, a3 은 b1 ~ b4 가 아니다
  2. 기호

    X = a1 + a2 + a3 (전체 소요시간),  Y = b1 + b2 + b3

  3. ①

    X + a4 > T

    그래서 그리디 전략으로 4번째를 못 넣음
  4. ②

    Y + b4 ≤ T

    b1 ~ b4 가 최적해라고 했으므로 성립해야 함
  5. ③

    X ≤ Y

    a1, a2, a3 은 시간이 가장 적게 걸리는 3개를 모은 것
  6. ④

    a4 ≤ b4

    그리디는 최소로 걸리는 것부터 고름 → a4 는 전체에서 4번째로 작은 값, b4 는 서로 다른 4개 중 가장 큰 값
  7. ⑤

    X + a4 ≤ Y + b4

    ③ 과 ④ 를 더함
  8. 모순

    ⑤ 와 ② → X + a4 ≤ T, 그런데 ① 은 X + a4 > T

  9. 결론

    모순 → 가정이 틀림 → 짧은 일부터 하는 그리디 해 = 최적해 ■

그리디 해가 k 개면가정 "k + 1 개 가능", X, Y 는 각각 앞 k 개의 합, ak+1 ≤ bk+1. 나머지 동일.
이 증명의 핵심 한 줄
X + a4 ≤ Y + b4 ≤ T  < X + a4
③ + ④ 로 왼쪽 부등호, ② 로 가운데, ① 로 오른쪽 → 자기 자신보다 작다는 모순
채점 포인트
  1. 가정 = "그리디 해는 최적이 아니다 = 하나 더 할 수 있다"
  2. 그리디가 멈춘 이유를 식으로: X + a4 > T
  3. "가장 짧은 것부터" 라는 성질에서 X ≤ Y, a4 ≤ b4
  4. 세 식이 충돌 → 가정이 틀림 → 최적
한 번에 정리
  • [2, 1, 4, 6, 3], T = 9 → 1 + 2 + 3 → 3개 (다른 조합도 3개)
  • 멈춤(X + a₄ > T) + 가정(Y + b₄ ≤ T) + 가장 짧음(X ≤ Y, a₄ ≤ b₄) → 모순 → 최적
