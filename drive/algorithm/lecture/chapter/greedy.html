그리디 방법과 귀류법

9-2
정의 · 그리디 방법
현재 상태에서 가장 좋은 선택(greedy 전략)을 반복해서 해를 구성하는 방법.

지금까지의 방법과 비교

방법푸는 방식특징
분할 정복큰 문제 → 작은 문제로 나눠 재귀 호출같은 작은 문제를 다시 계산해 비효율적일 수 있음
동적 계획법 (DP)큰 문제 → 작은 문제 (분할 정복과 같음)작은 문제의 답을 DP 테이블에 저장해 다시 사용
그리디지금 가장 좋아 보이는 것을 고르고 끝고른 것을 되돌리지 않음 → 최적이라는 증명이 꼭 필요

그리디로 푸는 순서

  1. 그리디 전략을 세운다. (시험에서는 주어짐)
  2. 그 전략으로 답을 구한다. (동작 추적)
  3. 그 전략이 항상 최적 해를 낸다는 것을 귀류법으로 증명한다.
증명이 없으면 그리디 답은 "그럴듯한 답" 일 뿐이다. 거스름돈의 반례(2장)가 그 예.
정의 · 귀류법 (proof by contradiction)
어떤 명제가 참임을 보이고 싶을 때, 결론을 부정해서 모순이 생기는 것을 보여 간접적으로 결론이 성립함을 보이는 방법.
단계"P 이면 Q" 를 증명할 때그리디 증명에서
가정P 는 그대로, Q 만 부정 (P ∧ ¬Q)"그리디 전략으로 구한 해는 최적이 아니다"
전개가정에서 출발해 따라감더 좋은 해를 그리디 해와 비교
모순이미 아는 사실과 충돌그리디의 동작(가장 짧은 것 · 끝까지 훑음 등) 과 충돌
결론가정이 거짓 → Q 가 참"그리디 해는 최적이다"
예 · √2 는 무리수이다 귀류법 형식 연습
가정결론 부정
√2 는 유리수다 → √2 = n / m (n, m 은 자연수, 서로소)
전개

2m2 = n2 → n2 은 2의 배수 → n 도 2의 배수 → n = 2k

2m2 = 4k2 → m2 = 2k2 → m 도 2의 배수

모순
n, m 이 둘 다 2의 배수 → 서로소라는 가정과 충돌
결론
가정이 틀렸다 → √2 는 무리수
시험교수님 안내

그리디 전략을 찾아내라는 문제는 나오지 않는다. 전략이 주어졌다고 가정하고, 그 동작을 이해하고 귀류법으로 최적임을 증명하는 과정을 알면 된다.

증명 답안은 첫 줄에 가정(결론의 부정)을 쓰고, 마지막 줄에서 그 가정이 틀렸다고 닫는다.

거스름돈 — 동전 개수 최소

9-2 · 예제 1
문제
거스름돈을 동전으로 줄 때 동전의 개수를 최소로. 동전: 1원, 10원, 50원, 100원. 입력: 368원.
전략: 가장 큰 단위의 동전부터 거슬러 준다.
동전개수남은 금액
100원3368 − 300 = 68
50원168 − 50 = 18
10원118 − 10 = 8
1원80
합계13개

왜 최적인가 — 단위가 서로 약수 관계

100원은 100원 1개로 만든다. 더 작은 1 · 10 · 50원으로 1개보다 적게 100원을 만들 수 없다. 50원도 마찬가지.

이것이 되는 이유: 1, 10, 50 이 100 의 약수이고, 1, 10 이 50 의 약수이기 때문. (수업에서는 당연하다고 보고 증명 생략)

반례 — 약수 관계가 아니면 틀린다

동전 1 · 5 · 7원, 10원 거슬러 주기사용한 동전개수
그리디 (큰 것부터)7 + 1 + 1 + 14
최적5 + 52

1원, 5원이 7원의 약수가 아니라서 큰 것부터 고르는 전략이 최적을 놓친다.

2장 요약
  • 전략: 큰 단위부터. 368원 → 13개.
  • 최적 조건: 동전 단위가 서로 약수 관계. 반례 {1, 5, 7} / 10원 → 그리디 4개, 최적 2개.

하루에 할 수 있는 일의 개수

9-2 · 예제 2
문제
일 5개의 소요시간 A = [2, 1, 4, 6, 3], 하루에 일하는 시간 T = 9. 할 수 있는 일의 개수를 최대로.
전략: 소요시간이 짧은 일부터 한다.

1 + 3 + 4 = 8, 1 + 2 + 4 = 7 처럼 다른 조합도 3개다. 어떤 일인지가 아니라 개수가 답.

최적성 증명 (귀류법)

그리디가 고른 일을 짧은 순서로 a1, a2, a3, 다음으로 짧은 일을 a4 라고 한다.

짧은 일부터 고르는 전략은 최적이다 예시는 그리디 해 3개 · 시험에서는 개수 · 기호가 바뀔 수 있음
가정결론 부정
그리디 해(3개) 는 최적이 아니다 → 4개 이상 할 수 있다. 그중 4개를 짧은 순으로 b1, b2, b3, b4 라고 한다.
왜 4개만자주 헷갈림
5개 이상이어도 그중 4개만 떼어 내면 여전히 시간 안에 들어간다. 4개가 불가능하면 그보다 많은 것도 전부 불가능.
기호
X = a1 + a2 + a3,   Y = b1 + b2 + b3
사실 ①그리디가 멈춤
X + a4 > T — 그래서 그리디가 4번째를 못 넣었다.
사실 ②가정
Y + b4 ≤ T — b 4개는 시간 안에 들어간다.
사실 ③그리디 성질

a1, a2, a3 은 가장 짧은 3개 → X ≤ Y

a4 는 4번째로 짧은 일, b4 는 서로 다른 4개 중 가장 긴 것 → a4 ≤ b4

모순
③ 을 더하면 X + a4 ≤ Y + b4 ≤ T (②). 그런데 ① 에서 X + a4 > T. 둘 다 성립할 수 없다.
결론
가정이 틀렸다 → 짧은 일부터 고르는 그리디 해는 최적이다. ■
① X + a4 > T② Y + b4 ≤ T③ X ≤ Y,  a4 ≤ b4
③ + ② → X + a4 ≤ Y + b4 ≤ T  — ① 과 모순
개수가 k 개일 때 (시험에서 숫자가 바뀌어도 그대로 씀)
그리디 해가 k 개 → 가정: k + 1 개 이상 가능 → 그중 k + 1 개 b1 ~ bk+1. X = a1 + … + ak, Y = b1 + … + bk 로 두면 위 증명과 똑같이 X + ak+1 ≤ Y + bk+1 ≤ T < X + ak+1 모순.
시험이 증명에서 볼 것

① 가정을 "최적이 아니다 = 하나 더 할 수 있다" 로 쓰기 ② 그리디가 멈춘 이유 (X + a4 > T) ③ 그리디의 성질 (가장 짧은 것) 에서 부등식 두 개 ④ 두 식이 충돌.

변수 이름(a, b, X, Y) 은 바뀌어 나올 수 있으니 각 기호의 역할로 기억할 것.

3장 요약
  • 전략: 짧은 일부터. A = [2, 1, 4, 6, 3], T = 9 → 1 + 2 + 3 → 3개.
  • 증명: 그리디가 멈춤 (X + a4 > T) vs 최적해 가능 (Y + b4 ≤ T) vs 그리디가 가장 짧음 (X ≤ Y, a4 ≤ b4) → 모순.
