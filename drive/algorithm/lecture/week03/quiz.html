03외워 갈 공식

시험 ★★★

등비수열의 합 — 가장 많이 씀

초항 a, 공비 r, 항의 개수 k개 일 때

a + ar + ar² + … + ark−1 = a(rk − 1)r − 1
실제로 나오는 형태초항공비합
1 + 2 + 2² + … + 2k−1122k − 1
1 + 32 + (32)² + … + (32)k−11322((32)k − 1)
1 + 12 + 14 + … 1122 미만 (상수 취급)
공비가 1이면 이 공식을 못 씁니다

분모 r − 1 = 0 이 되기 때문입니다. 공비가 1이면 같은 값이 k번 반복되는 것이므로 합은 그냥 항의 개수 k 입니다. (여기서 log n 이 나옵니다.)

1부터 n까지의 합

1 + 2 + 3 + … + n = n(n+1)2

등차수열의 합 (일반형)

합 = 항의 개수 × (첫 항 + 끝 항)2

1 + 2 + … + n 은 이 공식에서 항 n개, 첫 항 1, 끝 항 n 인 경우일 뿐입니다 → n(1 + n)2.

왜 일반형도 알아야 하나 — 수업 식에는 없지만 변형이 나오면 필요

수업에 나온 빼기형은 전부 1부터 시작하는 합이라 위 공식만으로 충분했습니다. 그런데 2씩 줄거나 1부터 시작하지 않으면 1~n 공식을 그대로 못 씁니다.

T(n) = T(n−2) + n ,   T(1) = C

     = n + (n−2) + (n−4) + … + 3 + T(1)          ← n 이 홀수라고 가정
       항의 개수 = n − 12 ,  첫 항 n ,  끝 항 3

     = n − 12 · n + 32 + C = (n − 1)(n + 3)4 + C
⇒ O(n²)

항의 개수 세는 법: (첫 항 − 끝 항) ÷ 간격 + 1 = (n − 3) ÷ 2 + 1 = n − 12.

로그 성질 3개

성질어디에 쓰나
n = 2k ⟺ k = log₂ n거의 모든 문제의 마지막 치환
alogb c = clogb a3log₂n → nlog₂3 로 바꿀 때 (카라츠바)
loga b + loga c = loga (bc)log₂(32) + 1 = log₂3 으로 합칠 때

지수 성질 2개

na · nb = na+b
(ab)c = (ac)b        →  4k = (2²)k = (2k)² = n²
자주 쓰는 변환 — 외워두면 빠름
n = 2k 일 때

  2k = n
  4k = n²
  3k = nlog₂3
  k   = log₂ n

05유형 A · 빼기형

시험 ★★☆

n이 n−1, n−2처럼 빼기로 줄어드는 경우입니다. n = 2k 가정이 필요 없고, 항을 끝까지 그냥 더해 나가면 됩니다.

A-1. T(n) = T(n−1) + C

출처 — Sum(n) 재귀 / max 하나 vs 나머지 / power1

T(n) = T(n−1) + C ,   T(1) = C

     = T(n−2) + C + C
     = T(n−3) + C + C + C
     ⋮
     = T(n−k) + k·C            ← k 번 펼쳤을 때 (일반항)

     n − k = 1 이 되면 멈춤  →  k = n − 1

     = T(1) + (n−1)·C
     = C + (n−1)·C
     = Cn

⇒ O(n)
한 줄 내려가는 원리 — n 자리에 n−1 을 넣는다

T 는 함수입니다. T(n−1) 은 "T 곱하기 (n−1)" 이 아니라 입력 크기가 n−1 일 때 걸리는 시간입니다. 그리고 점화식 T(n) = T(n−1) + C 는 n 이 몇이든 성립하는 규칙이므로, n 자리에 무엇을 넣어도 성립합니다.

① 원래 식            T(n)   = T(n−1) + C
② n 대신 n−1 을 넣음   T(n−1) = T(n−2) + C       ← n 이 전부 n−1 로 바뀜
③ ①의 T(n−1) 을 ②의 오른쪽으로 바꿔 끼움
                     T(n)   = [ T(n−2) + C ] + C
                            = T(n−2) + C + C

다음 줄도 같습니다. n 대신 n−2 를 넣으면 T(n−2) = T(n−3) + C 이고, 이걸 바꿔 끼우면 T(n−3) + C + C + C 가 됩니다. 나누기형도 똑같습니다 — T(n) = T(n2) + C 에서 n 대신 n2 를 넣으면 T(n2) = T(n4) + C.

답안에는 ② 줄을 적어 두세요. 과정을 보는 과제라서, 대입 근거가 한 줄 있으면 "=" 가 어디서 나왔는지 채점자가 바로 확인할 수 있습니다.

T(1) + (n−1)·C 는 어디서 나오나 — 규칙 → 멈출 곳 → 대입

1단계 · 규칙 찾기. 한 번 펼칠 때마다 괄호 안은 1 줄고, C 는 1개 늘어납니다. 두 숫자가 항상 같습니다.

펼친 횟수 1 :  T(n−1) + 1·C
펼친 횟수 2 :  T(n−2) + 2·C
펼친 횟수 3 :  T(n−3) + 3·C
   ⋮
펼친 횟수 k :  T(n−k) + k·C        ← 일반항

2단계 · 멈출 곳 정하기. 값을 아는 건 T(1) = C 뿐입니다. 그래서 괄호 안이 1 이 될 때 멈춥니다.

n − k = 1   →   k = n − 1

3단계 · 대입. 일반항의 k 에 n−1 을 넣으면

T(n − (n−1)) + (n−1)·C  =  T(1) + (n−1)·C

숫자로 확인 (n = 5).

T(5) = T(4) + C
     = T(3) + C + C
     = T(2) + C + C + C
     = T(1) + C + C + C + C       ← C 4개 = (5−1)개

답안에도 일반항 줄(T(n−k) + k·C)과 n−k = 1 → k = n−1 줄을 쓰면 "⋮" 뒤의 결과가 어디서 나왔는지 설명됩니다.

A-2. T(n) = T(n−2) + C

출처 — reverse 방법2 (양 끝 교체)

T(n) = T(n−2) + C ,   T(1) = C

     = T(n−4) + C + C
     = T(n−6) + C + C + C
     ⋮
     = T(n−2k) + k·C           ← k 번 펼쳤을 때 (일반항)

     n − 2k = 1 이 되면 멈춤  →  k = n − 12     ( n 은 홀수라고 가정 )

     = T(1) + n − 12·C
     = C + n − 12·C

⇒ O(n)

2씩 줄어도 상수배 차이일 뿐이라 결과는 A-1과 같은 O(n)입니다.

교수님 필기는 n2·C 였는데 왜 n − 12·C 인가

T(1) 에서 멈추면 n 에서 1 까지 n−1 만큼 줄어야 하고, 한 번에 2씩 줄므로 펼친 횟수는 n − 12 번이 정확합니다. 괄호 안이 1 이 되려면 n 이 홀수여야 해서 "n 은 홀수" 가정이 필요합니다.

교수님이 쓰신 n2·C 는 "2개씩 빠져나가니 대략 n2 번" 이라는 뜻의 근사입니다 (n 이 짝수이고 T(0) 까지 내려가는 경우라면 정확히 n2). 둘 다 1차식이라 결과는 똑같이 O(n) 입니다.

답안에는 정확한 쪽(n − 12, n 홀수 가정)을 쓰는 것을 권합니다. 과정이 일반항 → 멈출 곳 → 대입으로 이어져 논리가 끊기지 않습니다.

A-3. T(n) = (n−1) + T(n−1)

출처 — Quick Select 최악의 경우

더해지는 값이 상수 C가 아니라 n에 따라 변합니다. 그래서 결과가 달라집니다.

T(n) = (n−1) + T(n−1) ,   T(1) = C

     = (n−1) + (n−2) + T(n−2)
     = (n−1) + (n−2) + (n−3) + T(n−3)
     ⋮
     = (n−1) + (n−2) + … + 2 + 1 + T(1)

     1부터 (n−1)까지의 합이므로  =  (n−1)·n2  + C

⇒ O(n²)
A-1과 A-3의 차이 — 여기서 많이 틀립니다
T(n−1) + C
같은 값 C 를 n−1번 더함
→ Cn → O(n)
T(n−1) + (n−1)
1, 2, 3 … 을 전부 더함
→ n(n−1)2 → O(n²)

더해지는 게 상수인지 n에 비례하는지를 먼저 보세요.

A-4. T(n) = T(n−1) + T(n−2) + C  전개 안 함

출처 — fibo1 (피보나치 그대로 재귀)

교수님이 "우리가 배우는 범위를 넘어선다"며 직접 풀지 않으셨습니다. 결과만 알면 됩니다.

T(n) = T(n−1) + T(n−2) + C ,   T(0) = C , T(1) = C

⇒ O(γn) ,   γ = 1 + √52 = 1.618…

이런 식으로 시간복잡도가 지수로 올라오면 exponential하게 걸린다고 하고, 성능이 나쁜 것입니다.

만약 이게 나온다면

전개를 요구하진 않을 것입니다. 나온다면 "결과가 O(γn)이고 지수 시간이라 나쁘다"와, 왜 그런지(같은 값을 중복 호출해서 호출 수가 단계마다 거의 두 배로 늘어남) 정도를 쓰면 됩니다.

06유형 B · 나누기형, 호출 1번

시험 ★★★

n이 n2로 줄고 재귀 호출이 한 번뿐인 경우입니다. 갈라지지 않고 한 줄로 내려가므로 더해지는 항이 k개가 됩니다.

B-1. T(n) = T(n2) + C  가장 유력

출처 — power3 / 이진탐색 · 교수님이 예시로 보여주신 바로 그 식

T(n) = T(n2) + C ,   T(1) = C

가정 : n = 2k

     = T(n2²) + C + C
     = T(n2³) + C + C + C
     ⋮
     = T(n2k) + k·C          ← C 가 k개

     n = 2k 이므로 n2k = 1,  T(1) = C

     = C + k·C
     = C + C·log₂ n            ← k = log₂ n

⇒ O(log n)
n = 2ᵏ 가정은 어디서 떠올리나 — 멈출 곳에서 나온다

외운 결과가 아니라 A-1, A-2 와 같은 절차(규칙 → 멈출 곳 → 대입)에서 나옵니다. 가정을 답안 맨 위에 쓰는 것은 결과를 정리해서 쓰는 순서일 뿐이고, 생각하는 순서는 아래와 같습니다.

① 2~3번 펼쳐서 T( ) 안을 본다     n2 → n2² → n2³
② 일반항                          T(n2k) + k·C
③ 멈출 곳 : 괄호 안 = 1             n2k = 1   →   n = 2k   ← 여기서 가정이 나옴

왜 "가정" 이라고 부르나. 모든 n 이 2k 꼴은 아니기 때문입니다. n = 6 이면 6 → 3 → 1.5 로 가다가 정확히 1 에 떨어지지 않습니다. 반으로 나눌 때마다 나누어떨어지고 끝이 정확히 1 이 되는 n 은 2의 거듭제곱뿐이라, 그런 n 만 다룬다고 미리 밝혀 두는 것입니다.

줄어드는 방식멈출 곳필요한 가정
1씩 빼기 (A-1)n − k = 1 → k = n − 1없음 (항상 1에 도착)
2씩 빼기 (A-2)n − 2k = 1 → k = n − 12n 은 홀수
반씩 나누기 (B, C)n2k = 1 → n = 2kn = 2k

가정해도 되는 이유. 2k 가 아닌 n 은 그보다 큰 가장 가까운 2k 사이에 끼어 있고, 그 2k 는 2n 보다 작습니다. 입력이 클수록 시간이 더 걸린다면 T(n) ≤ T(2n) 정도라서 Big-O 는 바뀌지 않습니다. 이 부분은 수업에서 다루지 않은 보충입니다.

B-2. T(n) = n + T(n2)

출처 — Quick Select 최선의 경우

더해지는 값이 상수가 아니라 n입니다. 그런데 단계마다 그 n도 절반이 됩니다.

T(n) = n + T(n2) ,   T(1) = C

가정 : n = 2k

     = n + T(n2)
         ↳ n 대신 n2 를 넣으면   T(n2) = n2 + T(n2²)
     = n + n2 + T(n2²)
         ↳ n 대신 n2² 를 넣으면  T(n2²) = n2² + T(n2³)
     = n + n2 + n2² + T(n2³)
     ⋮
     = T(1) + n·( 1 + 12 + 12² + … + 12k−1 )

     괄호 안은 초항 1, 공비 12 인 등비수열이라
     아무리 더해도 2 를 넘지 않는다 (상수 취급)

     = C + n·C′        (C′ 은 2 미만의 상수)

⇒ O(n)

C-1. T(n) = 2T(n2) + C

출처 — Sum(a,b) / max 반분할 / power2

T(n) = 2·T(n2) + C ,   T(1) = C

가정 : n = 2k

     = 2( 2T(n2²) + C ) + C
     = 2²·T(n2²) + 2C + C
     = 2²( 2T(n2³) + C ) + 2C + C
     = 2³·T(n2³) + 2²C + 2C + C
     ⋮
     = 2k·T(n2k) + C·( 2k−1 + … + 2 + 1 )

     n = 2k 이므로 T(n2k) = T(1) = C

     등비수열 : 초항 1, 공비 2, 항 k개  →  2k − 12−1 = 2k − 1

     = 2k·C + C·(2k − 1)
     = nC + C(n − 1)           ← 2k = n
     = 2Cn − C

⇒ O(n)

C-2. T(n) = 4T(n2) + C·n

출처 — 큰 수 곱셈의 단순 분할 정복 (카라츠바 이전)

T(n) = 4·T(n2) + C·n ,   T(1) = C

가정 : n = 2k

     = 4( 4T(n2²) + C·n2 ) + Cn
     = 4²·T(n2²) + 2Cn + Cn                    ← 4 × n2 = 2n
     = 4²( 4T(n2³) + C·n2² ) + 2Cn + Cn
     = 4³·T(n2³) + 2²Cn + 2¹Cn + 2⁰Cn
     ⋮
     = 4k·T(n2k) + Cn·( 2k−1 + … + 2 + 1 )

     = 4k·C + Cn·(2k − 1)                     ← 등비, 합 = 2k − 1
     = C·n² + Cn·(n − 1)                        ← 4k = (2k)² = n² ,  2k = n
     = 2Cn² − Cn

⇒ O(n²)
4k = n² 이 핵심

        ≤ 44(3n4) + 44(n5) + 11n5
        = 33n + 44n5 + 11n5
        = 33n + 55n5
        = 33n + 11n
        = 44n                         ← 가정과 같은 꼴로 닫힘 ✓

④ 결론  모든 n 에서 T(n) ≤ 44n
⇒ O(n)

모범답안시간복잡도 — O(γⁿ), 여기서 γ = 1+√52 ≈ 1.618. 이 점화식은 수업 범위를 넘어 직접 전개하지 않고 결과만 다뤘습니다.

문제점 — 시간복잡도가 지수(exponential)로 올라와 성능이 매우 나쁩니다. 원인은 중복 호출입니다. F(5)를 구할 때 F(3)이 2번, F(2)가 3번 등장하는 식으로 같은 값을 반복 계산하고, 호출 수가 단계마다 거의 두 배로 늘어납니다.

해결 — 피보나치를 행렬 A = [[1,1],[1,0]] 의 거듭제곱 문제로 바꾸면 (F(n+1), F(n))ᵀ = Aⁿ (F(1), F(0))ᵀ 이고, Aⁿ 을 power3 방식으로 구해 O(log n) 까지 내릴 수 있습니다.
