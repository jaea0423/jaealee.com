핵심 4

수업에서 선택·버블·삽입의 코드는 안 봤고, 정리 글은 말로만 설명했습니다. 이 페이지의 코드는 보충이므로 현장과제에서 주는 의사코드가 기준입니다. 삽입의 “자신보다 작은 게 나올 때까지 이동” 은 같을 때를 말하지 않으니, 실제 코드의 > / >= 로 판단하세요.

의사코드의 부등호(> / >=) 를 먼저 확인 — >= 면 버블·삽입도 X.

02판정하는 법 — 코드에서 볼 곳 두 군데

성질코드에서 찾을 것판정
in-place새 리스트를 만드는 줄이 있는가
(B = [], S, M, L = [], [], [], append 로 따로 모으기)		있으면 X (추가 메모리 O(n)) · 없으면 O
stable교환·이동하는 줄이
① 같은 값끼리도 바꾸는가 (>=)
② 멀리 떨어진 칸끼리 바꾸는가		①이나 ②가 있으면 X · 이웃끼리만, > 일 때만 바꾸면 O
가장 많이 틀릴 곳 — 부등호

버블·삽입은 비교가 > 면 stable O, >= 면 stable X 입니다. 같은 값도 바꾸거나 넘어가 버리기 때문입니다. 과제지 의사코드의 부등호를 먼저 확인하세요. 선택·제자리 퀵은 부등호와 상관없이 stable X 입니다.

이 수업은 재귀 호출에 쓰는 메모리는 따지지 않고 "새 배열을 만드는가" 로 in-place 를 판단하는 것으로 보입니다 — 교수님이 제자리 퀵 정렬(재귀 사용)을 in-place O 라고 하셨기 때문 (추측).

03① 선택 정렬

Pythonselection sort
def selection_sort(A):
    n = len(A)
    for last in range(n-1, 0, -1):      # 뒤에서부터 자리 확정
        m = 0
        for i in range(1, last+1):       # 최댓값 위치 찾기
            if A[i] > A[m]:
                m = i
        A[m], A[last] = A[last], A[m]    # ★ 멀리 떨어진 두 칸 교환
stableX — 교환이 멀리 떨어진 두 칸(최댓값 자리, 마지막 칸) 사이에서 일어나, 옮겨지는 값이 같은 값을 건너뛸 수 있다.
in-placeO — A 안에서 교환만 하고 새 리스트를 만들지 않는다 (변수 m, i, last 만 추가 → O(1)).
답안에 이렇게 쓰기

stable X — A[m], A[last] = A[last], A[m] 에서 멀리 떨어진 두 칸을 교환하므로 같은 값의 순서가 바뀔 수 있다. (예: [5₁, 5₂, 1] → [1, 5₂, 5₁])
in-place O — 새 리스트 없이 A 안에서 교환만 하므로.

04② 버블 정렬

Pythonbubble sort
def bubble_sort(A):
    n = len(A)
    for r in range(n-1):
        for j in range(n-1-r):
            if A[j] > A[j+1]:            # ★ 앞이 '더 클 때만' 교환
                A[j], A[j+1] = A[j+1], A[j]   # 이웃한 두 칸만
stableO — A[j] > A[j+1] 일 때만, 그리고 이웃한 두 칸끼리만 교환하므로 같은 값의 순서가 바뀌지 않는다.
in-placeO — A 안에서 이웃끼리 교환만 한다.
답안에 이렇게 쓰기

stable O — if A[j] > A[j+1] 로 앞이 더 클 때만 이웃끼리 교환하므로 같은 값은 순서가 유지된다.
in-place O — 새 리스트 없이 A 안에서 교환만 하므로.

05③ 삽입 정렬

Pythoninsertion sort
def insertion_sort(A):
    for i in range(1, len(A)):
        x = A[i]
        j = i - 1
        while j >= 0 and A[j] > x:     # ★ x 보다 '큰' 값만 뒤로 → 같으면 멈춤
            A[j+1] = A[j]
            j -= 1
        A[j+1] = x
stableO — A[j] > x 인 동안만 뒤로 밀고, 자신보다 작거나 같은 값을 만나면 멈추므로 같은 값의 뒤에 들어간다.
in-placeO — A 안에서 값을 한 칸씩 옮기기만 한다 (변수 x, j 만 추가).
답안에 이렇게 쓰기

stable O — while j >= 0 and A[j] > x 로 x 보다 큰 값만 뒤로 밀고 같은 값에서 멈추므로 순서가 유지된다.
in-place O — 새 리스트 없이 A 안에서 값을 옮기기만 하므로.

06④ 제자리 퀵 정렬

Pythonin-place quick sort
def quick_sort(A, first, last):
    if first >= last:
        return
    P = A[first]
    left, right = first + 1, last
    while left <= right:
        while left <= last and A[left] < P:
            left += 1
        while right > first and A[right] > P:
            right -= 1
        if left <= right:
            A[left], A[right] = A[right], A[left]   # ★ 멀리 떨어진 두 칸 교환
            left += 1
            right -= 1
    A[first], A[right] = A[right], A[first]       # ★ 피벗도 멀리 이동
    quick_sort(A, first, right-1)
    quick_sort(A, left, last)
stableX — left·right 교환과 마지막 피벗 교환이 멀리 떨어진 칸끼리 일어나 같은 값이 서로를 건너뛸 수 있다. 수업 예시 [4, 2₁, …, 2₂, …] 도 정렬 후 [2₂, 2₁, …] 이 된다.
in-placeO — 새 리스트 없이 A 안에서 자리를 계속 바꾼다 (교수님 설명).
답안에 이렇게 쓰기

stable X — A[left], A[right] = A[right], A[left] 와 A[first], A[right] = … 에서 멀리 떨어진 칸끼리 교환하므로 같은 값의 순서가 바뀔 수 있다. (예: [3, 2₁, 2₂] → [2₂, 2₁, 3])
in-place O — 새 리스트를 만들지 않고 A 안에서 자리를 바꾸므로.

S/M/L 퀵 정렬과 헷갈리지 않기

S/M/L 버전은 stable O · in-place X, 제자리 버전은 stable X · in-place O — 정반대입니다. 과제에 나오는 건 제자리 버전입니다.

이제 이 바뀐 in-place quick_sort에 대해서 생각해보면 * in-place? ⇒ O (새로운 배열을 만들지 않고 자리를 계속 바꿔준거기 때문) * stable? ⇒ 다들 각자 생각해서 이거까지가 10월 8일 과제(아니 그래서 quick_sort가 나온다는거같아. 총 4개) 즉 10월 8일에 Bubble, selection, insertion, in-place quick_sort 이 4가지의 알고리즘 수도코드를 제공해주고 각 문제별로 in-place인지 stable인지 OX풀고 간략한 이유 설명

08변형 연습 — 의사코드가 조금 다르게 나오면

과제 의사코드가 수업 것과 조금 다를 수 있어 만든 연습입니다. 답을 누르면 펼쳐집니다.

Q1버블 정렬의 조건이 if A[j] >= A[j+1]: 이면 stable 인가?O/X기본
정답X — 같은 값도 교환해 버린다. 예: [2₁, 2₂] → [2₂, 2₁].
Q2삽입 정렬의 조건이 while j >= 0 and A[j] >= x: 이면 stable 인가?O/X기본
정답X — 같은 값도 뒤로 밀어 x 가 같은 값 앞에 들어간다. 예: [2₁, 2₂] → [2₂, 2₁].
Q3선택 정렬을 "최솟값을 찾아 맨 앞 칸과 교환" 으로 바꾸면 stable 인가?O/X응용
정답X — 여전히 멀리 떨어진 칸끼리 교환한다. 예: [2₁, 2₂, 1] → 1라운드 최솟값 1 ↔ 맨 앞 2₁ → [1, 2₂, 2₁].
Q4삽입 정렬을 "정렬된 원소를 새 리스트 B 에 하나씩 끼워 넣고 마지막에 B 를 반환" 하도록 짜면 in-place 인가?O/X응용
정답X — 새 리스트 B (크기 n) 를 만들므로 추가 메모리 O(n), not in-place. stable 여부는 끼워 넣는 비교 부등호로 따로 판단.
Q5stable 인 정렬이 실제로 필요한 상황을 한 가지 들어 설명하시오.서술응용
모범답안학생을 이름순으로 정렬한 뒤 점수로 다시 정렬할 때, stable 정렬이면 점수가 같은 학생끼리는 이름순이 그대로 남는다. 여러 기준으로 차례로 정렬할 때 앞의 결과를 깨지 않는다.
Q6제자리 퀵 정렬은 재귀 호출을 하는데도 in-place 라고 한다. 재귀 때문에 쓰는 메모리는 얼마이며, 왜 in-place 로 보는가?서술심화
모범답안재귀 호출이 쌓이는 깊이만큼 메모리를 쓴다 — 반반으로 나뉘면 log n 층이라 O(log n), 한쪽으로 쏠리면 최악 O(n). 하지만 원소를 담는 새 배열은 만들지 않고 A 안에서 자리만 바꾸므로 in-place 로 본다 (이 수업의 판단 기준).
