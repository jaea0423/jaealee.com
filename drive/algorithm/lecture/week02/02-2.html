01좋은 피벗의 조건

교수님 강조

지난 시간 Quick Select의 결론은 피벗을 잘 정하는 것이 관건이라는 것이었습니다. 최악의 경우(O(n²))는 A나 B가 텅 비어서 크기가 1씩만 줄어들 때 생기므로, 그런 일이 없도록 양쪽이 지나치게 치우치지 않게 만들어야 합니다.

좋은 피벗의 조건

|A| ≤ nc ,  |B| ≤ nc

즉 어느 쪽으로 재귀를 타든 다음 리스트의 크기가 n/c 이하로 보장된다는 뜻입니다. 여기서 c는 1보다 큰 상수입니다.

필기 원문
저번 Quick Select에서 ⇒ pivot 잘 정하기!! → |A| <= n/c , |B| <= n/C

02재귀 횟수 = logc n

크기가 매번 1/c배로 줄어드니, 리스트 크기는 다음처럼 변합니다.

마지막에 n/ck = 1이 되므로, 곧 n = ck가 될 때까지 내려갑니다. 이걸 k에 대해 풀면:

log_c n = log_c c^k = k · log_c c = k · 1 = k

따라서 재귀 횟수 k = logc n번입니다.

필기 원문
n → n/C → n/C^2 → ... → n/C^k = 1 이 개수는 k+1개가 됨 그렇다면 재귀 횟수(화살표 개수)는 k번이 됨 n/C^k이 1이 될 때까지 감 즉 n이 C^k이 될 때까지 감 이걸 n에 대한 식으로 바꾸면(k에 대한 식으로 바꾸는건가) log_c n = log_c c ^k = k * log_c c = k * 1 = k 즉 k번 = log_c n번

03전체 비교 횟수

이제 한 번의 재귀마다 드는 비교 횟수를 봅니다. 두 가지가 듭니다.

하는 일비교 횟수비고
피벗 고르기a피벗을 잘 고르는 과정이라 상수 시간이 아니다 (지난 시간과 다른 점)
A / M / B 나누기n정확히는 단계마다 n, n/c, n/c² 로 줄지만 차수만 중요하므로 n으로 본다

단계 하나에 (a + n)번, 그런 단계가 logc n번이므로:

log_c n · (a + n)     (단, a ≤ n 으로 가정)
  ≤ log_c n · 2n
  = 2n · log_c n
  = O(n log n)          (계수 2, 로그의 밑 c 는 차수에 영향 없음)
logc n · (a + n) 이 왜 이렇게 되는가

"한 단계의 최대 비용 × 단계 수"로 읽으면 됩니다. 어느 단계든 다루는 리스트는 처음 크기 n을 넘지 않으므로 한 단계 비용은 아무리 커도 (a + n)입니다. 그런 단계가 logc n번 있으니 곱한 것입니다. 실제로는 뒤로 갈수록 리스트가 작아져 더 싸지지만, 상한만 구하면 되니 전부 가장 비싼 경우로 잡아버린 것입니다.

결론

피벗을 잘 고르면 O(n log n) — 지난 시간의 최악 O(n²)보다 빠릅니다.

참고: n² > n > log n

필기 원문
각 횟수당 필요한 비교 횟수 ??? 1. pivot 고르는데 a(pivot을 잘 고르는 과정에서 상수시간이 아닌 a번의 비교가 필요함. 기존과 다름) 2. A/B/M 나누는데 n번 비교가 필요(정확히는 a+n번, a+n/c번, a + n/c^2이지만 우리는 상한(차수)가 중요하기 때문에 n번이라고 함) log_c n * (a + n) 비교가 필요한 것임(잘 이해 안돼 나는) (* a <= n 가정) <= log_c n * 2n = 2n log_c n = O(n log n) (계수, log 밑 등은 중요하지 않음) 즉 이전 O(n^2)보다 빠름 (참고 : n^2 > n > log n)

04MoM 알고리즘 개요

앞에서 "피벗을 잘 고르자"고 했는데, 어떻게 잘 고를지가 바로 MoM(Median of Medians)입니다.

median과 mean

용어뜻1, 6, 3, 3, 4 의 경우
median중간값 — 정렬했을 때 가운데 오는 값3
mean평균값 — 다 더해서 개수로 나눈 값3.4  (= (1+3+3+4+6)/5)

MoM(L, k) — 네 단계

Quick Select와 동일하고, 피벗만 MoM 방식으로 구한다는 점만 다릅니다.

단계하는 일비교 횟수
1L의 원소를 5개씩 묶는다 (꼭 5개일 필요는 없고 예시일 뿐)0번
2각 그룹의 median을 구한다그룹당 6번 × 그룹 n/5개 = 6n/5번
3그 median들을 모아 medians를 만들고, 그중 median(= m*)을 구한다 → 피벗T(n/5)  (재귀)
4m*를 피벗으로 A/M/B 분할 후 재귀 호출, 또는 m* 반환n번 + T(n/c)
 
m* = MoM(medians, |medians| / 2)      ← 재귀!

m*를 구하는 이유는 오직 피벗으로 쓰기 위해서입니다. 이 과정만 빼면 나머지는 Quick Select와 똑같습니다.

055개의 median을 6번에 찾기

시험 ★★☆

a b c d e 다섯 개에서 median, 즉 3번째로 작은 값을 찾습니다. 핵심은 이미 비교한 결과를 버리지 않고 계속 재활용하는 것입니다.

1단계 — 비교 ①②③ : a를 탈락시킨다

왜 a가 탈락하는가

a보다 큰 원소가 최소 3개(b, c, d)입니다. e는 아직 모르지만, e가 어떻든 a보다 작을 수 있는 건 e 하나뿐이므로 a의 순위는 1등 아니면 2등입니다. 3번째 자리에는 절대 올 수 없으니 제외합니다.

2단계 — 비교 ④⑤ : 남은 넷 중 가장 작은 것

a가 1등 또는 2등이므로, 전체의 3번째 값은 남은 {b, c, d, e} 중 2번째로 작은 값입니다. 그런데 c < d는 ②에서 이미 알고 있으니 다시 비교하지 않습니다.

3단계 — 비교 ⑥ : median 확정

b가 남은 넷 중 1등이므로, 우리가 찾는 값은 {c, d, e} 중 가장 작은 것입니다. 그런데 c < d는 또 이미 알고 있으니 c와 e만 비교하면 끝납니다.

결론

5개의 median을 찾는 데 6번의 비교가 필요합니다. 그룹이 n/5개이므로 2단계 전체는 6 × (n/5) = 6n/5번입니다.

필기 원문
*각 그룹에서 median 찾기 : 3번째 찾기(이 내용 도식화로 잘 해줘) a b c d e가 있다면 두 개씩 비교(작은거)해서 a c가 나옴 a c 비교해서 a가 나옴(다 예시임) 여기까지 비교가 3번 이루어짐(도식화. 토너먼트식으로) = a b c d 중에서는 a가 가장 작다는 것 ⇒ a보다 큰 애들 최소 b c d 있음(e는 아직 모름) = a는 절대 3번째 자리에 위치할 수 없음. → a 제외 b c d e ⇒ 2번째 작은 수 찾기(a는 첫번째 아니면 두 번째이기 때문에 a가 빠져서) c d 는 이미 비교함 (c가 작음) b e 비교하면 b가 더 작음 b랑 c 비교하면 b가 더 작음(여기까지 비교 총 5번(3+2)) ⇒ b가 4개 중 가장 작다 c d e 중 가장 작은 값을 찾으면 되고 c e만 비교하면 됨(c d 중 이미 c가 작은걸 했기 때문)(6번째 비교가 여기서 이루어짐) ⇒ c가 작으니까 c가 3번째로 작은 Median 이 됨 ⇒ Median을 찾으려면 6번의 비교가 필요하다. b e 를 비교하면(b가 작음)

네 단계의 비용을 그대로 더합니다.

단계비용이유

3T(n/5)medians의 원소 개수가 n/5개라 그 크기로 재귀
4n + T(n/c)둘 다입니다. 분할하는 데 비교 n번, 그리고 A 또는 B로 넘어가는 재귀에 T(n/c). 피벗을 잘 잡아 |A|, |B| ≤ n/c 이므로 재귀 대상 크기가 n/c 이하다
 
T(n) = 0 + 6n/5 + T(n/5) + n + T(n/c)
     = T(n/c) + T(n/5) + 11n/5        (6n/5 + n = 6n/5 + 5n/5 = 11n/5)
그래서 c는 얼마인가?

점화식에 c가 남아 있으니 아직 풀 수 없습니다. MoM 방식이 c를 얼마까지 보장해 주는지를 알아내야 하고, 그게 다음 섹션의 증명입니다.

필기 원문

07c 구하기 — |A|, |B| ≤ 3n/4 증명

교수님 강조시험 ★★★

준비 — 그림을 만드는 법

원소를 5개씩 묶었다고 합시다. 예: [ooooo] [ooooo] [ooooo] [ooooo] [ooo] (마지막은 딱 안 떨어질 수 있음)

각 그룹에서 median을 구하고(색칠된 동그라미), 그 median들 중에서 다시 median을 구한 것이 m*입니다. 이제 그림을 두 번 정리합니다.

  1. 각 그룹을 세로로 세우고, 위쪽이 작은 값, 아래쪽이 큰 값이 되도록 정렬합니다. 그러면 median은 자연히 가운데 줄에 옵니다.
  2. 그룹(세로줄)들을 median이 작은 순서대로 왼쪽부터 늘어놓습니다. 그러면 m*은 정확히 한가운데에 옵니다.

왜 X의 원소들이 m*보다 작다고 확신할 수 있나

X 영역에 있는 원소 하나를 집어 봅니다. 그 원소는 두 단계를 거쳐 m*보다 작습니다.

단계근거
① 자기 그룹의 median보다 작거나 같다세로줄을 정렬했으므로, 가운데 줄(median)보다 위에 있으면 그보다 작다
② 그 median은 m*보다 작거나 같다세로줄을 median 순서로 늘어놓았으므로, m*보다 왼쪽 줄의 median은 m*보다 작다

①과 ②를 이으면 X의 원소 ≤ 그 그룹의 median ≤ m*입니다. W도 부등호 방향만 뒤집어 똑같습니다.

X의 크기 세기

m*는 median들의 median이므로, 전체 그룹(n/5개)의 절반은 median이 m* 이하입니다. 그런 그룹 하나마다 X에 들어가는 원소는 위쪽 3개(median 본인 + 그 위 2개)입니다.

X 의 크기  ≥  (그룹 수의 절반) × 3
           =  (n/5 ÷ 2) × 3
           =  3n/10
           ≥  n/4          ← 여유 있게 내려 잡은 값
n/4 로 내려 잡는 이유

3n/10 = 0.3n 이고 n/4 = 0.25n 이므로, n/4는 확실히 성립하는 더 느슨한 값입니다. 큰 쪽(3n/10)이 보장되면 작은 쪽(n/4)은 자동으로 보장되니 틀린 말이 아니고, 차수만 보면 되니 손해도 없습니다. 3n/10을 그대로 쓰면 c = 10/7이 나오는데, 교수님은 n/4로 잡아 c = 4/3으로 가셨습니다. 시험에는 4/3으로 답하면 됩니다.

여기서 |A|, |B|의 범위가 나온다

X는 곧 A(m*보다 작은 값들), W는 곧 B(m*보다 큰 값들)에 들어갑니다. 그리고 A와 B는 서로를 밀어냅니다 — 전체가 n개인데 한쪽이 최소 n/4를 차지하면 반대쪽은 나머지 3n/4를 넘을 수 없습니다.

|X| ≥ n/4  →  m* 이하가 최소 n/4개  →  |B| ≤ n − n/4 = 3n/4
|W| ≥ n/4  →  m* 이상이 최소 n/4개  →  |A| ≤ n − n/4 = 3n/4

동시에 X ⊆ A, W ⊆ B 이므로 아래쪽도 막힙니다.

n/4 ≤ |A| ≤ 3n/4
n/4 ≤ |B| ≤ 3n/4
우리가 원했던 것

필요한 건 위쪽 한계입니다. |A|, |B| ≤ 3n/4 이므로 n/c = 3n/4, 즉 c = 4/3이 보장됩니다. 최악의 경우에도 한쪽이 통째로 비는 일이 없다는 뜻입니다.

교수님 정리

08귀납법 복습

MoM의 점화식 T(n) = T(3n/4) + T(n/5) + 11n/5는 지금까지 풀던 점화식과 모양이 다릅니다. 항이 두 개이고 줄어드는 비율도 서로 달라서, 앞처럼 쭉 펼쳐 나가는 방법이 잘 통하지 않습니다. 그래서 수학적 귀납법(mathematical induction)을 씁니다.

귀납법의 구조

단계하는 일
1. 기저제일 작을 때(보통 n = 1) 성립함을 직접 확인한다
2. 가정n = k일 때 성립한다고 가정한다 (증명하는 게 아니라 그냥 놓고 시작)
3. 귀납2번 가정을 재료로 써서 n = k+1일 때도 성립함을 보인다
4. 결론따라서 모든 n에서 성립한다
4번이 왜 성립하는가 — 놓치신 부분

1번에서 n = 1이 성립한다는 사실을 확보했습니다. 3번에서는 "어떤 수에서 성립하면 그다음 수에서도 성립한다"는 규칙을 확보했습니다. 이 둘을 이어 붙이면:

1이 성립 → (3번 규칙) → 2도 성립 → (3번 규칙) → 3도 성립 → …

어떤 자연수 n을 가져오든 1에서 출발해 유한 번만 이 규칙을 적용하면 n에 도달합니다. 그래서 "모든 n"이라고 말할 수 있습니다. 3번만 있고 1번이 없으면 출발점이 없어서 아무것도 못 하고, 1번만 있고 3번이 없으면 n = 1 하나밖에 말할 수 없습니다. 둘 다 있어야 합니다.

예시 — 1 + 2 + … + n = n(n+1)2

1단계 (기저) — n = 1을 직접 대입합니다.

좌변 = 1
우변 = 1 · (1+1) / 2 = 2/2 = 1        →  같다. 성립 ✓

2단계 (가정) — n = k일 때 성립한다고 둡니다.

1 + 2 + … + k = k(k+1) / 2            ← 이게 참이라고 가정

3단계 (귀납) — 이 가정만 써서 n = k+1일 때를 보입니다.

먼저 보여야 할 목표를 확실히 해 둡니다. 원래 공식에 n = k+1을 넣으면:

목표 :  1 + 2 + … + (k+1)  =  (k+1)·((k+1)+1) / 2  =  (k+1)(k+2) / 2

이제 좌변을 직접 계산해서 이 목표와 같아지는지 봅니다.

1 + 2 + … + k + (k+1)
  = [ 1 + 2 + … + k ] + (k+1)
  = k(k+1)/2 + (k+1)            ← 여기서 2단계 가정을 사용 (이 대입이 귀납법의 핵심)
  = (k+1) · ( k/2 + 1 )         ← (k+1) 로 묶음
  = (k+1) · (k+2)/2
  = (k+1)(k+2) / 2              ← 목표와 일치 ✓
오타 수정

필기의 마지막 줄이 ((k+1)+(k+2))/2였는데, 덧셈이 아니라 곱셈인 (k+1)(k+2)/2가 맞습니다. 덧셈이면 (2k+3)/2가 되어 목표와 달라집니다.

4단계 (결론) — 1에서 성립하고, 성립하면 다음도 성립하므로 모든 자연수 n에서 성립합니다.

같은 귀납법, 다른 표현

2번과 3번을 이렇게 바꿔 쓸 수도 있습니다.

원래 표현바꾼 표현
2. 가정n = k 일 때 성립k < n 인 모든 k에서 성립
3. 증명n = k+1 일 때 성립k = n 일 때 성립

교수님 말씀대로 같은 귀납법이고 표현법만 다릅니다.

이 표현을 쓰는 이유

MoM 점화식에는 T(3n/4)와 T(n/5)가 같이 들어 있는데, 둘 다 "바로 직전 값"인 T(n−1)이 아닙니다. 그래서 직전 하나만 가정하는 원래 표현으로는 쓸 재료가 없습니다. 반면 "n보다 작은 건 전부 성립"이라고 가정해 두면 3n/4든 n/5든 n보다 작기만 하면 바로 갖다 쓸 수 있어서 편합니다.

필기 원문
* 귀납법 복습 ex) 1+2+...+n= n(n+1) / 2 를 증명한다면 1. 제일 작을 때 성립함을 보임(n이 1일 때. 1 = 1*(1+1) = 2/2 = 1. ok 성립) 2. n이 임의의 k일 때 성립한다고 가정(1+2+...+k = k(k+1) / 2 . 이게 성립한다고 가정) 3. k + 1 일 때도 성립함을 보인다.(가정이 아닌 2번 가정을 통해서 증명)(1+2+...+k+(k+1) = (여기서 (k+1 앞 수식은 2번 가정에 의해 k(k+1) / 2) . 그렇다면 k(k+1) / 2 + (k+1) = ((k+1)+(k+2)) /2 여기서 귀납법 내용 더 채워줘. 4번 과정이랑 어떻게 이게 성립하는건지 등 이해하기 쉽게(필기를 놓쳤어) 이를 다른 표현법으로 2번 3번을 다시 쓸 수 있는데 2. k < n : 성립 가정 3. k = n : 성립한다 증명 (이전과 같은 귀납법인데 표현법만 다른거래)

09귀납법으로 MoM 풀기

시험 ★★★

c = 4/3을 대입하면 n/c = 3n/4 이므로:

T(n) = T(3n/4) + T(n/5) + 11n/5

가정 세우기

T(n) ≤ Cn, 즉 n에 대한 1차식을 상한으로 두고 시작합니다. 그런데 미지수 C를 그대로 끌고 가면 헷갈리니, 아예 T(n) ≤ 44n이라고 구체적인 수를 박고 시작합니다.

왜 하필 44인지는 계산 끝에 드러납니다.

1단계 (기저)

n = 1 :  T(1) = 1  ≤  44 · 1 = 44        →  성립 ✓

2단계 (가정)

k < n 인 모든 k 에 대해  T(k) ≤ 44k        ← 가정

3단계 (귀납) — 3n/4도 n/5도 n보다 작으므로 2단계 가정을 그대로 적용할 수 있습니다.

T(n) = T(3n/4) + T(n/5) + 11n/5
     ≤ 44·(3n/4) + 44·(n/5) + 11n/5     ← 3n/4 < n, n/5 < n 이라 가정 적용 가능
     = 33n + 44n/5 + 11n/5
     = 33n + 55n/5
     = 33n + 11n
     = 44n                              ← 가정과 똑같은 꼴로 닫힌다 ✓
결론

T(n) ≤ 44n, 즉 T(n) = O(n). MoM을 피벗 선택에 쓰면 최악의 경우에도 선형 시간입니다.

03번의 O(n log n)과 모순 아닌가?

03번에서는 피벗 고르는 비용 a를 매 단계 그냥 n으로 잡고 logc n 단계를 곱해서 O(n log n)을 얻었습니다. 이건 느슨하게 잡은 상한입니다. 반면 여기서는 피벗 고르는 비용을 T(n/5)라는 재귀 항으로 정확히 반영했고, 두 재귀 항의 크기 합이 19/20으로 매 단계 줄어든다는 점까지 살렸습니다. 그래서 더 조여진 O(n)이 나옵니다. 둘 다 참이고, O(n) 쪽이 더 정확한 답입니다.

왜 하필 44인가

보충 설명

일반적으로 T(n) ≤ Cn 이라 두고 3단계를 그대로 계산하면 C·(3n/4) + C·(n/5) + 11n/5 이 나오고, 이것이 Cn 이하여야 증명이 닫힙니다.

C·(3/4) + C·(1/5) + 11/5  ≤  C
C·(19/20) + 11/5  ≤  C
11/5  ≤  C − 19C/20 = C/20
C  ≥  44

즉 44는 이 부등식을 만족하는 가장 작은 정수입니다. 그래서 44로 잡으면 계산이 정확히 44n으로 딱 떨어집니다. 45나 100으로 잡아도 증명 자체는 성립하지만, 44보다 작은 수로는 닫히지 않습니다.

이게 되는 진짜 이유

두 재귀 항이 줄어드는 비율을 더해 보면:

3/4 + 1/5 = 15/20 + 4/20 = 19/20  <  1

재귀로 넘기는 두 조각을 합쳐도 원래 크기보다 작습니다. 매 단계 총량이 조금씩 줄어들기 때문에, 단계마다 드는 11n/5의 비용을 전부 더해도 n의 상수배를 넘지 않습니다.

Q3T(n) = T(3n/4) + T(n/5) + 11n/5 이다. 귀납법으로 T(n) ≤ Cn 을 증명할 때 성립하는 가장 작은 정수 C를 구하고, 그 C로 3단계 전개가 닫히는 것을 보이시오.계산응용
정답 44귀납 가정을 대입하면 C(3n/4) + C(n/5) + 11n/5 ≤ Cn 이어야 한다. n으로 나누면 C(3/4 + 1/5) + 11/5 ≤ C → 19C/20 + 11/5 ≤ C → 11/5 ≤ C/20 → C ≥ 44.
C = 44로 전개하면 44(3n/4) + 44(n/5) + 11n/5 = 33n + 44n/5 + 11n/5 = 33n + 11n = 44n 으로 가정과 같은 꼴로 닫힌다.
Q4MoM 구조도에서 X 영역(왼쪽 위)의 원소가 m*보다 작다는 것이 보장되는 이유를 설명하고, |X|의 하한을 n에 대한 식으로 구하시오. 또 거기서 |A|의 상한이 어떻게 나오는지 쓰시오.서술형응용
모범답안보장 이유 — 두 단계를 잇는다. ① 각 세로줄을 작은 값이 위로 오도록 정렬했으므로, 가운데 줄(그 그룹의 median)보다 위에 있는 원소는 그 median보다 작다. ② 세로줄을 median이 작은 순서로 늘어놓았으므로, m*보다 왼쪽 줄의 median은 m*보다 작다. 이어 붙이면 X의 원소 ≤ 그 그룹의 median ≤ m*.
|X|의 하한 — m*는 median들의 median이므로 전체 n/5개 그룹 중 절반(n/10개)은 median이 m* 이하다. 그런 그룹마다 위쪽 3개가 X에 들어가므로 |X| ≥ 3 × n/10 = 3n/10. 수업에서는 더 느슨하게 n/4로 잡았다.
|A|의 상한 — W(m*보다 큰 것이 보장되는 영역)도 대칭으로 최소 n/4개다. A는 그 원소들을 포함할 수 없으므로 |A| ≤ n − n/4 = 3n/4. 따라서 c = 4/3.
Q5다음 중 옳은 것을 모두 고르시오. (복수 선택 가능)복수선택응용
  1. MoM에서 m*를 구하는 이유는 전체의 정확한 중앙값이 필요해서다
  2. MoM은 |A|, |B| ≤ 3n/4 를 보장한다
  3. 3/4 + 1/5 < 1 이라는 점이 T(n) = O(n)이 되는 근거다
  4. 피벗을 L[0]으로 고정한 quick_select의 최악은 O(n log n)이다
  5. MoM의 3단계는 자기 자신을 호출하므로 재귀다
정답 ②③⑤① m*는 오직 피벗으로 쓰기 위해 구하며 정확한 중앙값일 필요가 없다. ④ 최악은 O(n²)이다. ⑤ m* = MoM(medians, |medians|/2) 로 자기 자신을 호출한다.
Q6MoM에서 5개씩이 아니라 3개씩 묶는다고 하자. (1) 이때 |A|의 상한을 유도하시오. (2) 점화식을 세우시오. (단, 3개의 median은 3번 비교로 찾고, 분할은 n번으로 본다.) (3) 이 점화식에 T(n) ≤ Cn 을 대입했을 때 증명이 닫히는지 판단하고, 그 이유를 쓰시오.유도+판단심화
모범답안 (1) 그룹은 n/3개. m*는 그 median들의 median이므로 절반인 n/6개 그룹의 median이 m* 이하다. 3개짜리 그룹에서 median 이하인 원소는 median 본인과 그 위 1개, 즉 2개. 따라서 |X| ≥ 2 × n/6 = n/3. 대칭으로 |W| ≥ n/3 이므로 |A| ≤ n − n/3 = 2n/3.
(2) 2단계 비용은 3 × (n/3) = n, 3단계는 T(n/3), 4단계는 n + T(2n/3). 합치면 T(n) = T(2n/3) + T(n/3) + 2n.
(3) 닫히지 않는다. T(n) ≤ Cn 을 대입하면 C(2n/3) + C(n/3) + 2n = Cn + 2n 이 되어, 목표인 Cn 을 항상 2n 만큼 초과한다. 두 재귀 항의 비율 합이 2/3 + 1/3 = 1이라 여유가 전혀 남지 않기 때문이다. 5개일 때는 3/4 + 1/5 = 19/20 < 1 이라 매 단계 n/20 만큼 줄어드는 여유가 생기고, 그 여유가 있어야 선형에 머문다. 3개로 묶으면 O(n)이 보장되지 않고 O(n log n)이 된다.
정리 "5개가 아니어도 된다"는 말은 맞지만 아무 수나 되는 것은 아니고, 비율 합이 1보다 작아야 한다는 조건이 붙는다.
