# 개념노트 A4 인쇄판 — 규칙과 사용법

차시별 필기 페이지(`lecture/weekNN/NN-N.html`)와 별도로, **한 단원을 출력해서 공부하기 위한 정리본**을 만든다.
첫 적용: 알고리즘 그리디 (`drive/algorithm/lecture/chapter/greedy.html`, 2026-11-19 확정).

## 파일 구성

| 파일 | 역할 |
|---|---|
| `chapter.css` | 공통 스타일 (쪽, 글자 5단계, 표, 증명, 코드, 그림, 각주, 표지) |
| `chapter.js` | 공통 배치기 — 장·소제목 단위로 A4 쪽에 자동 배치, 각주 번호, 표지 목차 쪽 번호 |
| `tools/chapgen.py` | HTML 생성 도우미 (`unit`, `proof`, `table`, `code`, `fn`, `hl`, `v`, `frac`, 그림 함수, `build`) |
| `tools/build_<단원>.py` | 단원 내용 (예: `build_greedy.py`) — 계산·추적 값은 여기서 코드로 검증한 뒤 넣는다 |
| `tools/export_pdf.js` | HTML 과 같은 폴더에 PDF 저장, 넘친 쪽이 있으면 알려 줌 |

```
cd drive/chapter-engine/tools
python3 build_greedy.py
NODE_PATH=$(npm root -g) node export_pdf.js ../../algorithm/lecture/chapter/greedy.html
```

결과물은 과목 `lecture/chapter/<단원>.html` + `<단원>.pdf`. 강의 정리 목록(`lecture/index.html`)의 "개념노트" 줄에 연결한다.

## 1. 쪽

- A4 (210 × 297mm), 여백 위 12 · 좌우 17 · 아래 9mm.
- **첫 쪽 = 표지 + 목차**만 (장과 소제목, 쪽 번호는 자동).
- **머리말** 왼쪽: `과목 - 개념노트 - 단원명 English` (예: `알고리즘 - 개념노트 - 그리디 Greedy`), 오른쪽: 장 이름.
- **꼬리말** 왼쪽: `Kangwon National University, Dept. of CSE`, 가운데: 쪽 번호, 오른쪽: `이재아 202313564`.
- 화면 위 도구 막대: 강의 정리로 / 쪽 수 / **출력**(브라우저 인쇄) / **PDF 내려받기**(미리 만든 PDF).

## 2. 쪽 나눔

1. **장은 항상 새 쪽**에서 시작.
2. **소제목 하나 + 그 아래 전부 = 한 내용(`unit`)** — 남은 공간에 안 들어가면 통째로 다음 쪽. 빈 공간이 생겨도 자르지 않는다.
3. 한 내용이 한 쪽보다 길 때만 블록(표·그림·증명 단계) 경계에서 나누고, 이어지는 쪽 소제목 옆에 "(앞 쪽에서 이어짐)".
4. 선수 지식 회색 상자는 한 내용 — 자르지 않는다.

## 3. 글자 (5단계만)

| 용도 | 크기 | 굵기 |
|---|---|---|
| 장 제목 | 15pt | 800 |
| 소제목 | 11pt | 800 |
| 본문 · 증명 | 9.5pt, 줄 간격 1.6 | 400 |
| 표 · 그림 글자 · 증명 이유(←) · 캡션 · 장 출처 | 8.5pt | 400 |
| 각주 · 머리말 · 꼬리말 | 7.5pt | 400 |

- 표지 제목만 예외 (26pt).
- 글꼴: 본문 Pretendard, 코드 JetBrains Mono, 수식 변수 STIX Two Text 기울임.
- **강조는 크기가 아니라** 굵기 · 하이라이트로.

## 4. 표기

- **본문 = 필기 내용만.** 보충 · 판서 정정 · 확인 필요는 **각주**로.
- 각주: 본문에 `[1]`, 같은 쪽 아래에 모음. 종류 4가지 — `주의`(교수님 시험 안내 포함) / `보충` / `판서 정정` / `확인 필요`.
- 판서 오류는 본문에서 고친 값을 쓰고, 각주에 원래 판서와 고친 이유.
- 용어는 처음 나올 때 한글(English), 이후 한글. 비교표 등에서 나란히 나오면 모두 영어 병기 (한쪽만 영어 금지).
- 기호 · 변수 이름은 수업 그대로. 출처는 장 제목 오른쪽 (`9주차 2차시, 예제 1`).
- 시험 포인트 상자 · 예상 문제는 넣지 않는다 (요약 정리 · 문제은행은 따로).

## 5. 수식

- 변수는 기울인 세리프 (`v('X')`), 숫자 · 연산자 · O · log · cost 는 세운 글자.
- 첨자는 실제 첨자 (a₁, m²) — `a_1`, `m^2` 금지 (각주 안에서도 `<sub>`).
- **분수는 위아래** (`frac(a, b)`), 빗금 금지.
- 시간복잡도: O(*n* log *n*).
- 화살표: → 진행 · 결과, ↔ 충돌(모순).

## 6. 강조 · 색

- **노란 하이라이트(`hl`)**: 정의 핵심어 · 답 · 결론만, 장마다 3~5곳.
- **빨강**: 모순 · 반례에만. 과목 포인트 색은 쓰지 않는다.
- 굵게: 용어가 처음 나올 때, 표 머리.

## 7. 부품

| 부품 | 모양 | 쓰는 곳 |
|---|---|---|
| `dl.def` | 위아래 선만 있는 2칸 (왼쪽 이름, 오른쪽 내용) — 배경 상자 금지 | 정의, 문제 · 예시 · 전략 |
| `table` | **항상 본문 전체 폭**, 글자 왼쪽 · 숫자 가운데, 선은 위아래 굵은 선 + 행 사이 가는 선 | 비교, 추적 |
| `proof` | 세로 레일 — 가정(검은 점) → 단계(빈 점, 아래에 "← 이유") → 모순(빨강) → 결론(검은 마름모) | 모든 증명 |
| `.pre` | 회색 상자 "선수 지식: … (시험 범위가 아니라 …을 이해하기 위한 도구)" | 범위 밖 배경 지식 |
| `code` | 위에 언어(`pseudocode` / `python`)와 제목, 들여쓰기 4칸 유지, **주석은 초록색** | 의사코드 · 코드 |
| 그림 | 검정 + 노랑(선택) + 빨강(반례)만, 선 1.4pt 이상, 글자는 출력 크기 8pt 이상, 회색 글자 금지. 폭은 전체 또는 절반 2개 | 추적 · 트리 · 증명 도식 |

## 8. 만들기 전 확인

- 필기 원문(차시 페이지 RAW)을 처음부터 끝까지 다시 읽고 **생략 없이** 옮긴다 (문장은 줄이되 내용은 빼지 않음).
- 차시 페이지에서 정정한 판서 오류를 모두 반영하고 각주로 남긴다.
- 계산 · 추적 결과는 `build_*.py` 에서 `assert` 로 검증.
- `export_pdf.js` 출력에 "넘침 쪽" 이 없어야 하고, 쪽마다 스크린숏으로 확인 (제목이 쪽 끝에 혼자 남지 않음, 그림 글자 겹침 없음).

## 정리노트 (개념노트의 압축본)

개념노트를 시험 전에 훑을 수 있게 압축한 노트. 같은 부품 · 글자 5단계 · 색 규칙을 쓰고, 겉모습만 다르게 해서 출력물이 섞이지 않게 한다.

| 파일 | 역할 |
|---|---|
| `summary.css` | chapter.css 위에 덧씌움 — 검은 띠 머리말, 오른쪽 가장자리 탭 "정리", 2단 |
| `summary.js` | 2단 배치기 — 칸(`sunit`)을 단 단위로 배치, 첫 쪽 위쪽에 제목 · 목차(정리노트 쪽 + 개념노트 쪽) |
| `tools/build_<단원>_summary.py` | 내용 (예: `build_greedy_summary.py`) → `drive/<과목>/summary/<단원>.html` + PDF |

- **구분 장치**: 2단 / 머리말 = 검은 띠 "정리노트 \| 단원명" / 오른쪽 가장자리 검은 탭(출력물 옆면에서 보임) / 쪽 번호 "정리 n".
- **첫 쪽**: 표지 없이 위쪽 약 40% 에 제목 + 목차(장, 정리노트 쪽, 개념노트 쪽 — 쪽 칸은 숫자만), 그 아래부터 2단 본문.
- **칸(`sunit`)**: 단 하나 안에 들어가는 크기로 — 자르지 않는다. 칸 제목 오른쪽에 "→ 개념노트 p.n".
- **예제 하나당**: 문제 · 전략 · 결과(`dl.def`) / 수행시간 / 증명 뼈대(`proof`, 가정 → 핵심 식 → 모순) / 헷갈리는 점 · 판서 정정(`trap`, 연한 빨강 배경) / 시험 포인트(`exam`, 연한 노랑 배경) — 두 상자 모두 왼쪽 강조 띠 없이 배경색만 — 시험 포인트는 개념노트에는 넣지 않고 여기에만.
- 각주는 가능하면 쓰지 않고 `trap` 에 넣는다.
- 인쇄 시 브라우저 설정에서 **배경 그래픽**을 켜야 검은 띠 · 탭 · 하이라이트가 나온다 (PDF 내려받기 파일은 이미 포함).

## 암기노트 (외울 것만, 과목별 시험 범위 누적)

| 파일 | 역할 |
|---|---|
| `memorize.css` | chapter.css 위에 덧씌움 — 파란 띠 머리말, 오른쪽 가장자리 **아래쪽** 탭 "암기", 질문 \| 답 표 |
| `memorize.js` | 범위마다 새 쪽 (첫 범위는 첫 쪽 목록 아래), 묶음(`qa`)은 자르지 않고 한 쪽보다 길 때만 행 경계에서 나눔 |
| `tools/build_<과목>_memorize.py` | 내용 (예: `build_algorithm_memorize.py`) → `drive/<과목>/memorize/final.html` + PDF |

- **한 파일에 범위를 계속 추가** (그리디 → 백트래킹 → …), 범위마다 새 쪽. 첫 쪽 위쪽 = 제목 + 범위 목록(범위, 암기노트 쪽, 개념노트 쪽 — 숫자만).
- **출제자 시각으로 고른 것만** — 범위당 1~2쪽. 문장 금지, 단어 · 식 · 절차만. 이해하면 따라오는 것, 시험과 먼 것은 뺀다.
- **묶음마다 출제 우선순위 별표**: ★★★ 확정 · 반드시 / ★★ 유력 / ★ 짧게 묻는 것. 확정 출제(교수님 말씀)는 맨 위에 순서 · 이유까지.
- 묶음 종류 (범위에 맞게 고름):
  1. **증명 열쇠** (`keys`): 서술형에 그대로 쓸 식 · 단계, 모순은 빨강
  2. **동작 추적 · 계산** (`mtable`): 문제 유형 / 외울 절차 / 예시로 확인
  3. **시간복잡도** (`mtable`): 대상 / 시간 / 이유
  4. **빈칸 나올 줄** (`.mcode`): 의사코드 핵심 줄, 빈칸이 될 부분 형광
  5. **판서 정정** (`ul.fix`): 고친 값 (원래 판서는 취소선)
  6. **개념 판정** (`mtable`): 짧게 묻는 것 / 답
- 화면용 버튼(답 가리기 등)은 만들지 않는다 — 출력물로 쓴다.
- 세 자료 구분: 개념노트 = 탭 없음 · 1단 / 정리노트 = 검은 띠 · 위쪽 탭 "정리" · 2단 / 암기노트 = 파란 띠 · 아래쪽 탭 "암기" · 질문 \| 답 표. 컬러 출력 기준.
