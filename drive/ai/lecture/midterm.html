01큰 그림 — 배운 모델이 어디에 있나

시험 범위의 모든 내용은 아래 지도 한 장에 들어갑니다. 4-2에서 AI를 규칙기반과 머신러닝으로 나누고, 머신러닝을 다시 지도·비지도·강화로 나눴습니다. 6주차부터는 이 칸들을 하나씩 채운 것입니다.

  • 지도 학습 = 학습 데이터에 정답 y가 있음. y가 숫자면 회귀, 범주면 분류 (4-2의 14).
  • 로지스틱 "회귀"는 분류입니다. 이름만 회귀이고, 출력이 확률이라 0.5 기준으로 0/1을 정합니다 (6-1의 15).
  • 결정 트리는 분류와 회귀를 둘 다 합니다. 7-2 자료에 분류 트리와 회귀 트리가 모두 있습니다(회귀 트리는 8-1 수업 내용).
  • 비지도 학습 = 정답 y 없이 x만. 시험 범위에서는 군집화만 다룹니다 (7-1의 01).

05교수님이 직접 말씀하신 시험 관련 포인트

차시별 페이지의 "교수님 말씀" 상자 중 시험·범위·중요도에 관한 것만 모았습니다. 이 목록에 없는 구분(꼭 이해/보고 넘어가기)은 각 페이지에서 추측으로 표시해 두었습니다.

공통
  • 시험에서 식은 형태를 그대로 안내해 주고, 식 자체를 외워 쓰게 하는 문제는 내지 않는다. 식은 이해를 돕기 위한 것 (6-2)
★ 중요하다고 하신 것
  • 벌점 매개변수 C는 시험에 잘 나온다 — C 크기 ↔ 마진 폭 ↔ 과적합/과소적합 ↔ 편향/분산을 한 묶음으로 (6-2의 12)
  • SVM은 서포트 벡터를 어떻게 선정하고 마진을 어떻게 최대로 하는지를 배운다 (6-2의 01)
  • 회귀계수는 상관관계로 해석, 인과관계로 단정하면 안 됨 (6-1의 10)
  • 로그 오즈: p(x)는 y가 1일 확률, 1 − p(x)는 y가 0일 확률 (6-1의 15)
  • DBSCAN 이름에서 중요한 것은 Density와 Noise (7-1의 16)
  • K-평균은 K를 정해 줘야 하고, K가 바뀌면 cluster 번호는 같은 집단이 아님 (7-1의 04)
  • 실루엣: b는 커지고 a는 작아져야 좋은 군집 (7-1의 12)
  • 온라인 학습이 배치 학습보다 좋은 이유는 더 빠르다는 것 (4-2의 17)
가볍게 · 범위 밖이라고 하신 것
  • 6-1 최소제곱 공식: 직접 푸는 문제는 안 나올 것 같다, "이런 식으로 푼다"까지 이해 (6-1의 06)
  • 6-1 다항 회귀: "차수를 올리면 구불구불해질 수 있다" 정도, 그 이상은 심화라 안 다룸 (6-1의 11)
  • 6-2 교안 21–23쪽 힌지 손실: 심화, 시험에 직접 나오지 않음 (6-2의 14)
  • 6-2 교안 24–27쪽 특징 공간 확장: 그림으로 이해 (6-2의 15)
  • 6-2 교안 28–30쪽 커널: 심화, 사실상 공부 안 해도 되는 정도 — 이름 정도 (6-2의 16)
  • 6-2 교안 31–32쪽: 시험 범위 아님, 33쪽 SVR은 잘 안 씀 (6-2의 17)
  • 7-1 교안 24쪽 연결 방식: 외울 것 없음 (7-1의 15)
아직 확인되지 않은 것
  • 6-2 C의 방향: 교안 16·18쪽(예산 C, 크면 마진 넓음)과 19·22쪽(벌점 C, 크면 마진 좁음)이 반대 — 수업에서 쓰신 정의 확인 필요
  • "31–32쪽 시험범위 아님"이 6-2(SVM) 교안인지 군집화 교안(7-2의 03–04)인지 — 지금은 6-2로 적용
  • 8-1 앙상블은 아직 수업 필기·교수님 말씀을 받지 못함

  • 명제 = 참/거짓이 정해지는 문장 · 논리합은 둘 다 F일 때만 F · 논리곱은 둘 다 T일 때만 T · 조건은 p = T, q = F일 때만 F
  • 탐색: DFS(한 갈래 끝까지, 스택) · BFS(level 순서, 큐)는 무정보 탐색, 휴리스틱 탐색은 경험적 지식 사용, A*는 평가 함수 f로 최적 경로
  • 전문가 시스템 = 지식베이스 + 추론기구
  • AI ⊃ 머신러닝 ⊃ 딥러닝 ⊃ 생성형 AI
  • Mitchell: 경험 E로 작업 T의 성능 P가 좋아지면 학습 · 일반화 = 학습에 안 쓴 새 데이터에서도 잘 동작
  • 지도 {(xᵗ, yᵗ)}(분류·회귀) / 비지도 {xᵗ} / 강화(지연된 보상, 정책) · 배치(전부 한 번에) vs 온라인(미니배치로 점진적, 더 빠름)

05-1 — 머신러닝 개론(이어서) · AI 수학 (중간고사 범위 X — 참고용) (00 한눈에 보기 · 예상 문제)

  • 사례 기반 = 저장해 두고 거리로 비교(k-NN) / 모델 기반 = 모델을 만들어 예측(선형 회귀)
  • 데이터 문제 4가지: 양 부족 · 대표성 없음(잡음/편향) · 낮은 품질 · 관련 없는 특성
  • 과적합(너무 복잡 → 단순화·규제·데이터 늘리기) / 과소적합(너무 단순 → 강력한 모델·좋은 특성·제약 줄이기)
  • 훈련(학습) · 검증(고르기) · 테스트(마지막 평가), k-겹 교차 검증 / 공짜 점심 없음 = 평가해 봐야 앎
  • 시그모이드 f(x) = 1/(1 + e⁻ˣ) → 0~1, f(0) = 0.5 / MSE = 오차 제곱의 평균
  • 미분 = 접선의 기울기, 체인 규칙 = 바깥 미분 × 안쪽 미분 → 역전파 / 경사하강법 = 기울기 반대로
  • 내적 = 성분 곱의 합(숫자 하나), 유클리드 거리 = √∑(차이)², 행렬 곱 (m×n)(n×p) = m×p
  • 회귀직선 = y축 방향 거리 제곱합 최소(최소제곱법) → 6주차 선형 회귀

06-1 — 선형 회귀 · 로지스틱 회귀 (00 한눈에 보기 · 예상 문제)

  • 회귀 = 데이터만 보고 β(회귀계수)를 찾는 일. 선형은 RSS 최소, 로지스틱은 우도 최대.
  • R² = 1 − SSE/SST, 변수가 많으면 Adjusted R².
  • p(x) = P(y = 1), 1 − p(x) = P(y = 0), 로그 오즈 = log(p/(1−p)) = β₀ + β₁X, 0.5 넘으면 1.
  • 회귀계수는 상관관계로 해석. 비선형·다항은 "구불구불해질 수 있다"까지만.

06-2 — SVM (00 한눈에 보기 · 예상 문제)

  • SVM = 마진(경계와 가장 가까운 점의 거리)을 최대로 하는 초평면을 찾는 분류 모델
  • 서포트 벡터 = 마진 경계에 걸친 점(y·f(x) = M), 이 점들만 경계를 결정
  • y = +1이면 f ≥ M, y = −1이면 f ≤ −M → 합쳐서 y·f(x) ≥ M, ∑β² = 1로 거리를 정확히
  • 스케일링은 필수, 통계값은 학습 데이터에서만
  • 소프트 마진: 슬랙 ε로 위반 허용 (0 / 0~1 / 1 초과)
  • ★ 벌점 C 작음 = 넓은 마진·과소적합·고편향 / C 큼 = 좁은 마진·과적합·고분산

07-1 — 군집화 (00 한눈에 보기 · 예상 문제)

  • 비지도 학습 = x만 있고 y(라벨) 없음 → 군집화로 비슷한 것끼리 묶음
  • K-평균·계층적 = 거리 기반, DBSCAN = 밀도 기반
  • K-평균: K 지정 → (평균으로 중심 이동 ↔ 가까운 중심에 재배정) 반복, 목표는 WCV 합 최소
  • K-means++ = 초기화(1단계)만 개선
  • K 고르기: 엘보(이너셔 꺾이는 점), 실루엣(b ↑ a ↓, 점수 최대)
  • 계층적: 덴드로그램을 어디서 끊느냐 = 클러스터 개수
  • DBSCAN: Density + Noise, 떨어진 점은 노이즈

07-2 — DBSCAN · 결정 트리 (00 한눈에 보기 · 예상 문제)

  • DBSCAN: 반지름 ε 원 안에 MinPts개 이상이면 핵심점. 핵심점을 징검다리로 닿는 점까지 한 군집, 어디에도 안 닿으면 잡음. 군집 수는 저절로 정해짐
  • 직접 밀도 도달(1칸, 방향 있음) → 밀도 도달(여러 칸, 방향 있음) → 밀도 연결(공통 핵심점, 방향 없음)
  • 결정 트리: "특징 ≤ 기준값?" 질문을 반복, 나눈 뒤 불순도가 가장 많이 줄어드는 질문을 먼저 고름
  • 지니 G = 1 − ∑pₖ²·엔트로피 H = −∑pₖ log pₖ: 0 = 한 클래스뿐, 고르게 섞일수록 큼
  • CART: 지니 감소량 ΔG가 가장 큰 이진 분할을 고름 (예제: 0.490 → Age = Adolescent?, ΔG ≈ 0.26)
  • 과대적합 규제: max_depth ↓, min_samples_split·min_samples_leaf ↑
