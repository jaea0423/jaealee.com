01사례 기반 학습 vs 모델 기반 학습

Instance-based Learning / Model-based Learning

세 번째 분류 기준은 새 데이터가 들어왔을 때 어떻게 예측하느냐입니다. 머신러닝의 목적은 결국 처음 보는 데이터에 대해 좋은 예측을 하는 것(일반화)인데, 여기에 두 가지 방법이 있습니다.

사례 기반 (Instance-based)모델 기반 (Model-based)
방식예시들을 통째로 기억한 뒤, 유사도 측정(similarity measure)으로 새 사례에 일반화The system learns the examples by heart, then generalizes to new cases using a similarity measure.예시들로 모델을 만든 뒤, 그 모델로 예측build a model of examples, then use that model to make predictions
대표 알고리즘k-nearest neighbors 등Linear regression 등

그림의 두 방식을 단계별로 따라가 보겠습니다.

사례 기반 학습 (왼쪽)

  1. 훈련 데이터(△, □)를 전부 저장합니다. 이것이 "통째로 기억한다(learns by heart)"입니다.
  2. 새 사례(✖)가 들어오면 저장된 데이터와의 거리(유사도)를 잽니다.
  3. 가장 가까운 3개를 봅니다: △ 2개, □ 1개.
  4. 더 많은 쪽인 △로 판단합니다.

모델 기반 학습 (오른쪽)

  1. 훈련 데이터로 △ 영역과 □ 영역을 나누는 경계(모델, 보라 점선)를 만듭니다.
  2. 새 사례가 들어오면 경계의 어느 쪽에 있는지만 확인합니다.
  3. △ 쪽 안에 있으므로 △로 판단합니다.

차이를 정리하면, 사례 기반은 학습 단계에서 하는 일이 거의 없고 예측할 때마다 저장된 데이터 전체와 비교하므로 예측이 느립니다. 모델 기반은 학습 단계에서 경계를 만드는 데 시간이 들지만, 한 번 만들고 나면 훈련 데이터 없이 모델만으로 빠르게 예측할 수 있습니다.

k-NN 보충 — 교수님이 설명하신 내용 아님

k-최근접 이웃(k-nearest neighbors)은 새 샘플과 가장 가까운 훈련 샘플 k개를 찾아 다수결로 클래스를 정합니다. 교안 그림은 k=3에 해당합니다. 거리는 보통 유클리드 거리로 잽니다.

정리
  • 사례 기반: 예시를 통째로 기억 → 유사도로 가장 가까운 사례와 비교 (예: k-NN)
  • 모델 기반: 예시로 모델(경계)을 만들고 → 모델로 예측 (예: 선형 회귀)

02머신러닝의 주요 과제

Main Challenges of Machine Learning

머신러닝으로 좋은 모델을 만들지 못하는 원인은 크게 두 가지입니다. 데이터가 나쁘거나, 모델이 데이터에 맞지 않거나입니다. 아래 표가 데이터 쪽 문제이고, 뒤의 과적합·과소적합이 모델 쪽 문제입니다.

샘플링 잡음은 표본이 너무 작아 우연히 대표성이 없어지는 것, 샘플링 편향은 표본을 뽑는 방법 자체가 한쪽으로 치우쳐 표본이 커도 대표성이 없는 것을 말합니다.

표의 네 가지를 풀어 보면 다음과 같습니다.

  1. 양 부족: 사람은 사과 몇 개만 봐도 사과를 알아보지만, 대부분의 머신러닝 알고리즘은 간단한 문제에도 수천 개, 이미지·음성 같은 복잡한 문제에는 수백만 개의 예시가 필요합니다.
  2. 대표성 없음: 훈련 데이터가 실제로 예측할 데이터를 골고루 대표하지 못하면, 새 데이터에서 틀립니다. 원인은 두 가지입니다. 샘플링 잡음은 표본이 너무 작아서 우연히 치우친 경우이고, 샘플링 편향은 표본을 뽑는 방법 자체가 치우쳐서 표본이 아무리 커도 치우친 경우입니다. 예: 스마트폰 앱으로만 설문을 받으면 스마트폰을 쓰지 않는 사람의 의견은 몇 명을 모아도 빠집니다 → 샘플링 편향.
  3. 낮은 품질: 측정 오류나 이상치, 잡음이 많으면 모델이 진짜 패턴을 찾기 어렵습니다. 그래서 실제 작업에서는 이상치를 제거하거나 빠진 값을 채우는 데이터 정제에 많은 시간을 씁니다.
  4. 관련 없는 특성: 예측과 상관없는 특성이 많으면 성능이 떨어집니다. 쓸모 있는 특성만 고르거나(특성 선택), 기존 특성을 합쳐 더 쓸모 있는 특성을 만듭니다(특성 추출). 예: "키"와 "몸무게"를 합쳐 "BMI"라는 특성을 만드는 것이 특성 추출입니다.

과적합 Overfitting

모델이 훈련 데이터의 양과 잡음에 비해 너무 복잡할 때 일어납니다.

Overfitting happens when the model is too complex relative to the amount and noise of the training data.

과적합은 모델이 데이터에 담긴 일반적인 규칙이 아니라 훈련 데이터 자체(잡음까지 포함)를 외워 버린 상태입니다. 그래서 훈련 데이터에서는 성적이 아주 좋은데 새 데이터에서는 크게 틀립니다. 예: 훈련 데이터 10개를 하나도 빠짐없이 지나가는 복잡한 곡선을 그리면 훈련 오차는 0이 됩니다. 하지만 그 곡선은 데이터에 섞인 잡음까지 따라가느라 심하게 구불구불해서, 그 사이에 새 점이 들어오면 엉뚱한 값을 냅니다.

원인이 "데이터에 비해 모델이 너무 복잡하다"이므로, 해결책은 모델을 단순하게 하거나 데이터를 늘리고 깨끗하게 하는 쪽입니다.

해결책 (The possible solutions are):

  • 모델 단순화 — 파라미터 수가 더 적은 모델 선택, 훈련 데이터의 속성 수 줄이기, 모델에 제약 걸기(regularization, 규제) To simplify the model by selecting one with fewer parameters, by reducing the number of attributes in the training data, or by constraining the model (regularization).
  • 규제(regularization)는 모델의 파라미터 값이 너무 커지지 못하게 제한해서, 모델이 복잡한 모양을 만들기 어렵게 하는 방법입니다.
  • 훈련 데이터 더 모으기 (To gather more training data)
  • 훈련 데이터의 잡음 줄이기 (To reduce the noise in the training data)

과소적합 Underfitting

과적합의 반대로, 모델이 너무 단순해서 데이터의 내재된 구조를 학습하지 못할 때 일어납니다.

Underfitting is the opposite of overfitting: it occurs when your model is too simple to learn the underlying structure of the data.

과소적합은 모델이 데이터의 규칙을 담기에 표현력이 부족한 상태입니다. 그래서 새 데이터는 물론 훈련 데이터에서도 성적이 나쁩니다. 예: 곡선 모양으로 분포한 데이터를 직선 하나로 맞추려 하면, 아무리 학습해도 오차가 줄지 않습니다. 해결책은 과적합과 정반대 방향입니다.

해결책 (The main options to fix this problem are):

  • 파라미터가 더 많은 강력한 모델 선택 (Selecting a more powerful model, with more parameters)
  • 더 좋은 특성을 제공 = 특성 공학 (Feeding better features to the learning algorithm — feature engineering)
  • 모델의 제약 줄이기 (Reducing the constraints on the model)
과적합 (Overfitting)과소적합 (Underfitting)
원인모델이 너무 복잡모델이 너무 단순
모델파라미터 줄이기 · 규제 걸기파라미터 늘리기 · 제약 줄이기
데이터데이터 더 모으기 · 잡음 줄이기더 좋은 특성 제공(feature engineering)

그래프 읽기: 가로축은 학습 시간, 세로축은 손실(오차)입니다. 학습이 진행될수록 훈련 손실(검정)은 계속 줄어듭니다. 테스트 손실(빨강)은 처음엔 같이 줄다가, 어느 지점부터 다시 올라갑니다.

  • 최저점 왼쪽(파란 배경): 두 손실이 모두 큰 구간 = 아직 덜 배운 과소적합
  • 최저점 오른쪽(노란 배경): 훈련 손실은 계속 줄지만 테스트 손실은 커지는 구간 = 훈련 데이터에만 맞춰지는 과적합

따라서 "훈련 손실이 작다"는 것만으로는 좋은 모델이라고 할 수 없고, 반드시 학습에 쓰지 않은 데이터에서 손실을 확인해야 합니다. 그 방법이 다음 섹션의 테스트와 검증입니다.

손실 보충 — 교수님이 설명하신 내용 아님

손실(loss)은 모델 예측과 정답의 차이를 수치로 나타낸 값으로, 작을수록 좋습니다. 테스트 손실이 최저인 지점이 새 데이터에 가장 잘 일반화된 시점입니다.

정리
  • 데이터 문제 4가지: 양 부족 · 대표성 없음(잡음/편향) · 낮은 품질 · 관련 없는 특성
  • 과적합: 모델이 너무 복잡 → 훈련 데이터만 잘 맞춤 → 단순화 · 규제 · 데이터 늘리기 · 잡음 줄이기
  • 과소적합: 모델이 너무 단순 → 훈련 데이터도 못 맞춤 → 더 강력한 모델 · 좋은 특성 · 제약 줄이기

03테스트와 검증

Testing and Validation

모델이 새로운 사례에 얼마나 잘 일반화(generalize)될지 아는 방법은 실제로 새로운 사례에 적용해 보는 것입니다.

How well a model will generalize to new cases is to actually try it out on new cases.
  • 데이터셋을 훈련 세트(training set)와 테스트 세트(test set) 두 개로 나눈다 Split a dataset into two sets: the training set and the test set
  • 보통 데이터의 80%를 훈련에, 20%를 테스트용으로 떼어 둔다(holdout) Common to use 80% of the data for training and holdout 20% for testing.

왜 나눠야 할까요? 훈련에 쓴 데이터로 성능을 재면, 앞에서 본 과적합 모델도 점수가 높게 나옵니다. 모델이 이미 본 데이터이기 때문입니다. 그래서 학습에 한 번도 쓰지 않은 테스트 세트를 따로 떼어 두고, 거기서 잰 성능을 새 데이터에서의 실제 성능으로 봅니다. 테스트 세트에서 잰 오차를 일반화 오차(generalization error)라고 부릅니다.

그림 읽기: 레이블이 있는 원본 데이터를 셋으로 나눕니다(Split). 훈련 세트로 모델을 학습하고, 검증 세트로 여러 후보 모델 중 가장 나은 것을 고르고, 테스트 세트로 마지막에 성능을 확인합니다.

검증 세트의 역할 — 교수님이 설명하신 내용 아님

검증 세트는 여러 모델이나 하이퍼파라미터 중 무엇이 나은지 고르는 데 씁니다. 테스트 세트로 고르면 테스트 세트에 맞춰진 모델을 고르게 되어, 최종 성능을 부풀려 추정하게 됩니다. 그래서 테스트 세트는 마지막 평가에 한 번만 씁니다.

교차 검증 Cross Validation

훈련 세트를 서로 겹치지 않는 여러 부분집합(complementary subsets)으로 나눈 뒤, 각 모델을 서로 다른 부분집합 조합으로 학습시키고 나머지 부분으로 검증합니다.

The training set is split into complementary subsets, and each model is trained against a different combination of these subsets and validated against the remaining parts.

그림을 순서대로 따라가면 5-겹(5-fold) 교차 검증은 다음과 같이 진행됩니다.

  1. 전체 데이터에서 테스트 데이터를 먼저 떼어 둡니다(오른쪽 파란 칸). 이것은 끝까지 쓰지 않습니다.
  2. 나머지 훈련 데이터를 5조각(Fold 1~5)으로 나눕니다.
  3. Split 1: Fold 1을 검증용(파랑), 나머지 4개를 학습용(초록)으로 써서 학습하고 검증 점수를 잽니다.
  4. Split 2~5: 검증용 조각을 Fold 2, 3, 4, 5로 하나씩 바꿔 가며 같은 일을 반복합니다.
  5. 5번의 검증 결과를 종합해 가장 좋은 파라미터를 고릅니다(Finding Parameters).
  6. 떼어 둔 테스트 데이터로 최종 평가합니다(Final evaluation).

장점: 모든 데이터가 한 번씩 검증에 쓰이므로 검증 세트를 따로 크게 떼지 않아도 되고, 한 번 나눈 결과가 운 좋게(또는 나쁘게) 나오는 영향이 줄어듭니다. 단점: 학습을 5번 해야 하므로 시간이 그만큼 더 듭니다.

정리
  • 일반화 성능은 학습에 안 쓴 데이터로만 잴 수 있음 → 훈련/테스트 분리 (보통 80:20)
  • 검증 세트: 모델·파라미터 고르기 / 테스트 세트: 마지막 평가 1번
  • 교차 검증: 훈련 세트를 k조각으로 나눠 검증 조각을 바꿔 가며 k번 학습·검증

04공짜 점심은 없다 정리 No Free Lunch Theorem

David Wolpert (1996)

데이터에 대해 아무런 가정도 하지 않는다면, 어떤 모델을 다른 모델보다 선호할 이유가 없다.

If you make absolutely no assumption about the data, then there is no reason to prefer one model over any other.
  • 경험하기 전부터(a priori) 더 잘 작동한다고 보장된 모델은 없다 There is no model that is a priori guaranteed to work better.
  • 어떤 모델이 최선인지 확실히 아는 유일한 방법은 모두 평가해 보는 것이다 The only way to know for sure which model is best is to evaluate them all.

이 정리가 말하는 것은 모든 문제에서 항상 이기는 알고리즘은 없다는 것입니다. 어떤 데이터에는 선형 모델이 잘 맞고, 어떤 데이터에는 신경망이 잘 맞습니다. 데이터를 보기 전에는 무엇이 더 좋을지 알 수 없습니다.

그렇다고 세상의 모든 모델을 다 평가할 수는 없습니다. 그래서 실제로는 데이터에 대해 합리적인 가정을 하고(예: "이 데이터는 대략 직선 관계다"), 그 가정에 맞는 몇 개 모델만 골라 평가합니다. 그 평가 도구가 바로 앞 섹션의 검증 세트와 교차 검증입니다.

정리
  • 데이터에 대해 가정하지 않으면 어떤 모델도 다른 모델보다 낫다고 할 수 없음
  • 미리 더 좋다고 보장된 모델은 없음 → 평가해 봐야 앎

0611.2 인공지능과 함수

신경망의 뉴런 하나는 결국 입력을 받아 출력을 내는 함수입니다. 그래서 어떤 함수가 어떤 모양인지 알아야 뉴런이 어떻게 동작하는지 이해할 수 있습니다. 이 절은 지수·로그·삼각함수를 복습한 뒤, 신경망에서 직접 쓰는 활성 함수와 손실 함수로 넘어갑니다.

(1) 지수함수 exponential function

  • 변수가 거듭제곱의 지수에 들어 있는 함수입니다: y = aˣ (a는 1이 아닌 양의 상수, x는 모든 실수)
  • a > 1이면 증가함수, 0 < a < 1이면 감소함수입니다.
  • 두 경우 모두 그래프가 y = 0(x축)에 한없이 가까워지는 점근선을 가집니다.

두 그래프가 모두 (0, 1)을 지나는 이유는 a⁰ = 1이기 때문입니다. 또 aˣ는 항상 양수라서 그래프가 x축 아래로 내려가지 않습니다. 시그모이드 함수에 들어 있는 e⁻ˣ도 지수함수입니다(e ≈ 2.718).

(2) 로그함수 logarithmic function

  • y = logₐx (a > 0, a ≠ 1)를 a를 밑으로 하는 로그함수라 합니다.
  • 지수함수 y = aˣ의 역함수입니다. "a를 몇 번 거듭제곱하면 x가 되는가"를 답하는 함수입니다.
  • a의 값에 따라 두 가지로 나뉘며, 모두 (1, 0)을 지나고 y축에 가까워지는 점근선을 가집니다.

로그함수의 성질

logₐa = 1   ·   logb(xp) = p·logbx
logb(xy) = logbx + logby   ·   logbxy = logbx − logby

예: log₂16 = 4입니다. 16 = 2 × 2 × 2 × 2 = 2⁴이므로 log₂16 = log₂2⁴ = 4·log₂2 = 4 × 1 = 4입니다. 같은 방법으로 1/2 = 2⁻¹이므로 log₂(1/2) = −1입니다.

알고리즘 과목과 연결

알고리즘에서 이진 탐색이 O(log n)인 이유가 이 성질입니다. 크기 16인 배열을 절반씩 줄이면 16 → 8 → 4 → 2 → 1로 4번이면 끝나고, 4 = log₂16입니다.

(3) 삼각함수 trigonometric functions

  • 각의 크기에 따라 값이 달라지는 함수입니다. 대표적으로 sin(x), cos(x), tan(x)가 있습니다.
  • 보통 180° 같은 각도 대신 π, π/2 같은 호도법(radian)을 씁니다. π = 180°입니다.
  • sin(x)와 cos(x)는 −1에서 +1 사이의 값을 가지고, 2π를 주기로 같은 모양이 반복됩니다.
  • sin(0) = sin(2π) = 0, cos(0) = cos(2π) = 1, sin(π/2) = 1, sin(π) = 0, cos(π/2) = 0, cos(π) = −1
  • tan(x)는 π를 주기로 반복됩니다. tan(0) = 0, tan(π) = 0
  • tan(π/2), tan(−π/2) 등에서는 값이 정의되지 않습니다. tan(x) = sin(x)/cos(x)이고 이 위치에서 cos(x) = 0이기 때문입니다.

(4) 대표적인 비선형 활성 함수들

  • 신경망에서 뉴런에 해당하는 노드는 비선형적(non-linear)입니다.
  • 노드는 입력의 가중합을 그대로 내보내지 않고, 특정한 활성 함수(activation function)를 거쳐 출력합니다.
  • 0과 1 사이의 값을 가지는 시그모이드(sigmoid) 함수가 신경망에서 출력을 결정할 때 많이 쓰입니다.
f(x) = 11 + e−x

그래프를 읽으면, x가 크게 양수이면 e⁻ˣ가 0에 가까워져 f(x) → 1, 크게 음수이면 e⁻ˣ가 매우 커져 f(x) → 0입니다. x = 0이면 e⁰ = 1이라 f(0) = 1/2입니다. 그래서 출력을 확률처럼 해석할 수 있습니다. 4주차 2차시에서 로지스틱 회귀를 "확률을 계산해 분류"한다고 설명했는데, 그 확률 계산에 쓰는 함수가 이 시그모이드입니다.

활성 함수가 선형(예: y = 2x)이면 층을 아무리 많이 쌓아도 전체가 하나의 선형 함수와 같아져서, 층을 쌓는 의미가 없습니다. 비선형 활성 함수가 있어야 깊게 쌓은 신경망이 곡선 형태의 복잡한 경계를 표현할 수 있습니다.

(5) 손실 함수 loss function

  • 손실 함수는 예상한 값과 실제값의 차이를 함수로 정의한 것입니다. 신경망에서는 출력값과 실제값의 오차에 대한 함수입니다.
  • 신경망의 학습은 이 오차를 최소로 줄이는 방향으로 진행됩니다.
  • 대표적인 손실 함수는 평균제곱오차(MSE, Mean Squared Error)로, 예측값과 실제값의 오차를 제곱해 평균낸 값입니다.
  • MSE가 작으면 추정값이 정답에 가깝고, 크면 정답과 멀리 떨어져 있다고 봅니다. 그 외에 교차 엔트로피 오차(CEE, Cross Entropy Error) 등이 있습니다.
MSE = 1n ∑i=1n (Ŷᵢ − Yᵢ)²

Ŷᵢ: i번째 예측값 · Yᵢ: i번째 실제값 · n: 데이터 개수

계산 예: 실제값이 (3, 5), 예측값이 (2, 7)이면 오차는 (−1, 2), 제곱은 (1, 4), 평균은 (1 + 4) / 2 = 2.5입니다. 오차를 제곱하는 이유는 음수 오차와 양수 오차가 서로 지워지지 않게 하고, 큰 오차에 더 큰 벌점을 주기 위해서입니다. 02 섹션 과적합 그래프의 세로축 "손실"(Measured loss)이 바로 이런 값입니다.

정리
  • 지수함수 y = aˣ: (0, 1) 통과, x축이 점근선 / 로그함수 y = logₐx: 지수함수의 역함수, (1, 0) 통과, y축이 점근선
  • sin·cos: 주기 2π, 값 −1~1 / tan: 주기 π, ±π/2 등에서 정의 안 됨
  • 활성 함수: 계단 · 임계논리 · 시그모이드 f(x) = 1/(1 + e⁻ˣ) (출력 0~1)
  • 손실 함수: 예측과 실제의 차이 — 대표 MSE, 학습은 손실을 최소로 줄이는 방향

0711.3 미분과 델타 규칙

앞 절에서 "학습은 손실을 최소로 줄이는 방향으로 진행된다"고 했습니다. 그런데 어느 방향이 줄어드는 방향인지는 어떻게 알까요? 그 답이 미분입니다. 미분값(기울기)을 보면 가중치를 늘려야 손실이 줄어드는지, 줄여야 줄어드는지 알 수 있습니다. 이 절은 미분의 뜻에서 시작해 신경망 학습 규칙인 델타 규칙까지 이어집니다.

(1) 미분과 도함수

  • 미분(differentiation)은 어떤 운동이나 함수의 순간적인 움직임을 서술하는 방법입니다.
  • 함수의 미분이란 그 함수의 도함수를 도출하는 과정입니다. 미분 공식으로 지수·로그·삼각함수 등의 도함수를 구합니다.
  • 기하학적으로는 곡선의 접선을 구하는 문제와 같습니다. 접선은 곡선과 한 점에서 스치듯 만나는 직선입니다.

교안 p.20의 공식 그림: f(x) = xⁿ → f′(x) = nxⁿ⁻¹, 같은 내용을 y = xⁿ → dy/dx = nxⁿ⁻¹로도 씁니다(거듭제곱 미분 공식). 예: (x³)′ = 3x², (x²)′ = 2x.

(2) 도함수 derivative의 정의

  • 도함수는 정의역의 모든 x에 대해 f(x)의 미분계수를 대응시키는 함수입니다. 기호로 y′, f′(x), dy/dx로 씁니다.
  • f(x)의 도함수 f′(x)를 구하는 것이 미분, 그 계산법이 미분법입니다.
  • 각 입력값 x에서 f의 순간변화율을 구한 함수가 도함수입니다.
f′(x) = limh→0 f(x + h) − f(x)h

계산으로 확인: f(x) = x³, x = 2일 때 h = 0.1이면 (2.1³ − 2³)/0.1 = 12.61, h = 0.001이면 12.006으로, h를 0에 가깝게 할수록 f′(2) = 3·2² = 12에 가까워집니다. 위 그림에서 Q를 P에 가까이 가져가는 것과 같은 계산입니다.

순간변화율과 도함수

순간변화율은 각 점에서 그은 접선의 기울기입니다. 도함수는 입력값 x마다 그 점에서의 접선 기울기를 대응시켜 주는 함수입니다.

(3) 미분의 체인 규칙 chain rule

  • 합성함수의 미분에 적용합니다. 바깥 함수를 먼저 미분한 뒤 안쪽 함수를 미분하여 곱합니다.
  • y를 x에 관해 미분할 때, 먼저 y를 u에 관해 미분하고, u를 x에 관해 미분한 뒤 둘을 곱합니다.
  • 변수가 3개 이상이어도 연쇄적으로 적용할 수 있습니다.
  • 체인 규칙은 신경망의 학습 이론을 유도하는 바탕이 됩니다.
dydx = dydu · dudx     dydx = dydu · dudv · dvdx

예: y = sin(x²)이면 바깥 함수 y = sin(u), 안쪽 함수 u = x²입니다. dy/du = cos(u), du/dx = 2x이므로 dy/dx = cos(x²)·2x입니다. 신경망은 입력 → 은닉층 → 출력층 → 손실로 함수가 여러 겹 합성된 구조라서, 손실을 맨 앞 가중치로 미분하려면 이 규칙을 층마다 연쇄적으로 적용해야 합니다. 이것이 역전파입니다.

(4) 델타 규칙과 경사하강법 delta rule · gradient descent

  • 델타 규칙은 단층 신경망에서 쓰는 학습 방법 중 하나입니다.
  • 실제 출력과 기대 출력의 차이를 최소화하도록 뉴런 사이의 연결강도(가중치)를 바꾸는 방법입니다.
  • 델타 규칙을 확장한 것이 일반화 델타 규칙(generalized delta rule)입니다. 1986년 Rumelhart가 만든 다층 신경망을 학습시킬 수 있는 규칙으로, 가장 유명한 신경망 학습 규칙 중 하나입니다.
  • 델타 규칙에 따른 연결강도의 변화는, 연결강도 공간에서 오차의 제곱을 높이로 하는 곡면에 대해 경사하강법을 따릅니다. 즉 오차의 제곱이 가장 많이 감소하는 방향으로 연결강도가 바뀝니다.

"오차의 제곱을 높이로 하는 곡면"을 풀어 보면: 가로축을 가중치 w, 세로축을 그 가중치일 때의 오차²(손실)로 그린 그래프입니다. 경사하강법은 지금 위치에서 기울기(미분값)의 반대 방향으로 w를 조금 옮기는 것을 반복해 가장 낮은 곳을 찾습니다.

경사하강법의 갱신 식 — 교수님이 설명하신 내용 아님

w새 = w − η · (손실을 w로 미분한 값). η(에타)는 학습률(learning rate)로, 한 번에 얼마나 움직일지 정합니다. 기울기가 양수이면 w를 줄이고, 음수이면 w를 늘려서 손실이 작아지는 쪽으로 이동합니다. 델타 규칙은 이것을 단층 신경망에 적용한 식으로, 가중치 변화량이 (기대 출력 − 실제 출력) × 입력에 비례합니다.

(5) 인공지능과의 관련성

  • 신경망 연구는 단층 퍼셉트론의 학습 기법에 바탕을 둡니다.
  • 신경망을 근본적으로 이해하려면 도함수, 델타 규칙, 체인 규칙에 대한 기초적인 이해가 필요합니다.
  • 일반화 델타 규칙의 도함수 전개는 저자의 『신경망 이론과 응용(I)』에서 6쪽에 걸쳐 유도될 정도로 복잡합니다.
  • 델타 규칙과 경사하강법은 신경망 학습 규칙의 기반 이해에 필요합니다.
  • 전문가 코스가 아닌 분은 수학적 지식에 너무 스트레스 받지 않기 (교안 문구)
정리
  • 미분 = 순간변화율 = 접선의 기울기 / 도함수 f′(x) = lim(h→0) [f(x+h) − f(x)] / h
  • 체인 규칙: dy/dx = dy/du · du/dx — 신경망 학습(역전파) 이론의 바탕
  • 델타 규칙: 단층 신경망에서 출력 오차를 줄이도록 연결강도 변경 / 일반화 델타 규칙(1986, Rumelhart): 다층 신경망
  • 경사하강법: 오차 제곱이 가장 많이 감소하는 방향으로 연결강도를 바꿈

0811.4 벡터의 개념과 표현

신경망에 들어가는 데이터는 숫자 여러 개의 묶음입니다. 예를 들어 집 하나를 (면적, 방 개수, 역까지 거리)로 표현하면 숫자 3개짜리 묶음이 되는데, 이것이 벡터입니다. 이 절은 벡터의 정의, 덧셈, 내적, 거리를 다루고, 마지막에 이것이 신경망 계산과 어떻게 연결되는지 봅니다.

(1) 벡터의 정의

구분담는 정보예
스칼라(scalar)크기속력, 압력, 삼각형의 면적
벡터(vector)크기 + 방향속도, 힘, 가속도

벡터는 보통 u, v, w처럼 굵은 글씨체 소문자로 씁니다. 같은 "빠르기"라도 속력(시속 60km)은 스칼라이고, 속도(북쪽으로 시속 60km)는 방향이 붙어서 벡터입니다.

(2) 벡터의 개념과 표기법

  • 벡터는 방향 정보를 가지므로 그래프의 화살표(arrow)로 표현합니다.
  • 화살표의 방향이 벡터의 방향, 화살표의 길이가 벡터의 크기입니다.
  • 시작점 P를 시점, 끝점 Q를 종점이라 합니다.
  • PQ 위에 화살표를 그리거나, 굵은 글씨 a, b, u, v 등으로 표현합니다.

(3) 벡터의 크기와 기하학적 표현

  • x, y 평면으로 표현되는 유클리드 2차원 공간을 R²이라 합니다.
  • R² 위의 벡터 v = (v₁, v₂)는 원점을 시점으로, 종점 (v₁, v₂)에 이르는 화살표로 표현합니다.
  • 벡터의 크기는 화살표의 길이로 정의됩니다. 피타고라스 정리로 ‖v‖ = √(v₁² + v₂²)입니다. 예: v = (3, 4)이면 크기는 √(9 + 16) = 5

(4) 벡터의 연산 — 합

Rⁿ에서 v = (v₁, v₂, …, vₙ), w = (w₁, w₂, …, wₙ)일 때, 벡터의 합은 대응하는 성분끼리 더한 것입니다.

v + w = (v₁ + w₁, v₂ + w₂, …, vₙ + wₙ)

그림으로는 v와 w로 만든 평행사변형의 대각선이 v + w입니다. 예: (1, 2) + (3, 0) = (4, 2)

(5) 벡터의 내적 inner product, 內積

Rⁿ의 두 벡터 u, v의 내적은 스칼라값(숫자 하나)으로 정의되며 u · v로 씁니다. 같은 위치의 성분끼리 곱해서 모두 더합니다.

u₁u₂⋯uₙv₁v₂⋮vₙ = u₁v₁ + u₂v₂ + ⋯ + uₙvₙ
  • R²: u · v = u₁v₁ + u₂v₂
  • R³: u · v = u₁v₁ + u₂v₂ + u₃v₃

계산 예: u = (1, 2, 3), v = (4, 0, −1)이면 u · v = 1·4 + 2·0 + 3·(−1) = 4 + 0 − 3 = 1

(6) 유클리드 거리 Euclidean distance

  • 두 점 사이의 거리를 계산할 때 쓰는 방법입니다. 이 거리로 유클리드 공간을 정의할 수 있습니다.
  • 이 거리에 대응하는 노름(norm)을 유클리드 노름(Euclidean norm)이라 합니다.
d = √( (x₁ − x₂)² + (y₁ − y₂)² )

n차원 공간의 유클리드 거리

P(p₁, p₂, …, pₙ)와 Q(q₁, q₂, …, qₙ) 사이의 거리:

√( (q₁ − p₁)² + (q₂ − p₂)² + ⋯ + (qₙ − pₙ)² ) = √( ∑i=1n (qᵢ − pᵢ)² )

이 거리 개념은 신경망이나 머신러닝에서 K-means, K-NN 등 분류·클러스터링(군집화)에 쓰입니다. 05-1 앞부분 01 섹션의 k-NN에서 "가장 가까운 3개"를 고를 때 재는 거리가 바로 이것입니다.

교안 표기 주의 — K-mean

교안은 "K-mean"으로 적었지만 일반적인 이름은 K-means입니다. 또 K-means는 레이블 없이 묶는 군집화(비지도), K-NN은 레이블로 판단하는 분류(지도) 알고리즘이라 종류가 다릅니다.

(7) 인공지능과의 관련성

  • 신경망 학습에서 벡터에 대한 기초 이해가 필요합니다.
  • 뉴런으로 들어오는 입력과 연결강도의 곱은 벡터의 내적으로 연산됩니다.
  • 인공지능 관련 지식에는 문과와 이과의 구별이 없으므로 벡터에 대한 기초 지식이 필요합니다.
  • 유클리드 거리는 점 사이의 거리를 재서 신경망의 분류(classification) 작업에 활용됩니다.

그림을 따라가면: 출력 뉴런 a₁(파랑)이 받는 값은 파란 가중치 행벡터와 입력 벡터의 내적 + 편향 b이고, 여기에 활성 함수(예: 시그모이드)를 적용한 결과가 a₁입니다. a₂, a₃도 같은 방식이며, 세 내적을 한 번에 쓰면 왼쪽처럼 행렬 × 벡터가 됩니다. 이것이 다음 절에서 행렬을 배우는 이유입니다.

정리
  • 스칼라 = 크기 / 벡터 = 크기 + 방향, 화살표(시점 → 종점)로 표현
  • 벡터의 합 = 성분끼리 더하기 = 평행사변형의 대각선
  • 내적 u · v = u₁v₁ + ⋯ + uₙvₙ (결과는 스칼라) — 뉴런의 입력 × 연결강도 계산
  • 유클리드 거리 √∑(qᵢ − pᵢ)² — K-means, K-NN 등 분류·군집화에 활용

0911.5 행렬과 행렬의 연산

앞 절 마지막 그림에서 뉴런 여러 개의 내적을 한 번에 계산하려고 숫자를 직사각형으로 늘어놓았습니다. 그것이 행렬입니다. 이 절은 행렬의 용어(행, 열, 크기, 성분)와 두 가지 연산(합, 곱)을 다룹니다. 특히 행렬의 곱이 "행과 열의 내적"이라는 점이 핵심입니다.

(1) 행렬의 표현과 정의

  • 행렬(matrix, 行列)은 수 또는 문자를 배열 형태로 나타낸 것입니다.
  • 행(row)은 가로 방향, 열(column)은 세로 방향입니다.

행렬의 행과 열

  • 위 행렬을 간단히 A = [aᵢⱼ] (i = 1, …, m, j = 1, …, n)로 적습니다.
  • m × n 행렬 또는 (m, n) 행렬이라 부르고, m개의 행과 n개의 열을 가집니다.
  • 예: 제1행은 [a₁₁, a₁₂, …, a₁ₙ]이고, 제2열은 a₁₂a₂₂⋮aₘ₂입니다.

행렬의 항 entry 또는 성분 component

  • aᵢⱼ를 행렬의 ij-항(ij-entry) 또는 ij-성분(ij-component)이라 합니다.
  • aᵢⱼ는 위에서 i번째 행과 왼쪽에서 j번째 열이 만나는 자리의 값입니다. 행 번호가 먼저, 열 번호가 나중입니다.
A = a₁₁⋯a₁ⱼ⋯a₁ₙ⋮⋮⋮aᵢ₁⋯aᵢⱼ⋯aᵢₙ⋮⋮⋮aₘ₁⋯aₘⱼ⋯aₘₙ ← i번째 행과 j번째 열의 교차점
자료구조와 연결

C·Java의 2차원 배열 a[i][j]와 같은 순서(행, 열)입니다. 다만 배열은 보통 0부터, 행렬은 1부터 번호를 셉니다.

행렬의 크기

행의 개수 × 열의 개수 형태로 표현합니다.

A = 1−23 : 3×1    B = 123456 : 3×2    C = 1−23−67−145 : 4×2
예제 11.1 — 행렬 A가 2×3 행렬임을 알아보자
A = 11−2−14−5

풀이 행이 2개, 열이 3개이므로 2×3 행렬입니다. 행은 [1, 1, −2], [−1, 4, −5]이고, 열은 1−1, 14, −2−5입니다.

행벡터 row vector와 열벡터 column vector

  • 행렬의 각 행은 가로로 늘어선 n개 순서쌍, 각 열은 세로로 늘어선 m개 순서쌍으로 볼 수 있습니다.
  • 가로 순서쌍을 행벡터, 세로 순서쌍을 열벡터라 부릅니다.
  • 행벡터 [x₁, …, xₙ]은 1 × n 행렬, 열벡터 x₁⋮xₘ은 m × 1 행렬입니다. 즉 벡터는 크기가 특별한 행렬입니다.

(2) 행렬의 합

  • 행렬의 합은 같은 크기의 행렬일 때에만 정의됩니다.
  • 같은 위치의 성분끼리 더합니다.
예제 11.2 — A + B를 구해보자
A = 3−124, B = 21−32
A + B = 3 + 2(−1) + 12 + (−3)4 + 2 = 50−16

(3) 행렬의 곱 multiplication

A = [aᵢⱼ]가 m × n, B = [bᵢⱼ]가 n × p 행렬이면, 곱 AB = C = [cᵢⱼ]는 m × p 행렬입니다.

cᵢⱼ = ∑k=1n aᵢₖbₖⱼ = aᵢ₁b₁ⱼ + aᵢ₂b₂ⱼ + ⋯ + aᵢₙbₙⱼ

읽는 법: C의 i행 j열 값을 구하려면 A에서 i번째 행을, B에서 j번째 열을 꺼내 앞 절의 내적을 계산하면 됩니다. 그래서 A의 열 개수와 B의 행 개수가 같아야(n = n) 곱할 수 있고, 결과 크기는 바깥 두 숫자 m × p가 됩니다.

예제 11.3 — AB와 AC를 구해보자
A = 110201, B = 200113, C = 1−2−12−24

(1) A는 2×3, B는 3×2이므로 AB는 2×2입니다. 각 칸 = (A의 행) · (B의 열):

AB = (1)(2)+(1)(0)+(0)(1)(1)(0)+(1)(1)+(0)(3)(2)(2)+(0)(0)+(1)(1)(2)(0)+(0)(1)+(1)(3) = 2153

(2) 같은 방법으로

AC = 0000
예제 11.3에서 눈여겨볼 점

A도 C도 영행렬이 아닌데 AC는 영행렬입니다. 숫자의 곱에서는 "ab = 0이면 a = 0 또는 b = 0"이 성립하지만, 행렬의 곱에서는 성립하지 않습니다. 또 행렬의 곱은 일반적으로 AB ≠ BA입니다(교환법칙 불성립). 위 예에서 BA는 3×3이라 AB(2×2)와 크기부터 다릅니다.

(4) 인공지능과의 관련성

  • 행렬을 쓰면 신경망에서 벡터 형태의 연산을 매우 빠르게 처리할 수 있습니다.
  • 뉴런으로 들어오는 입력과 연결강도의 곱 계산에 행렬의 곱이 필요합니다. 이 곱은 주로 벡터의 내적으로 연산되며, 행렬의 곱 연산을 쓰면 매우 편리합니다.
  • 따라서 인공지능에서 행렬에 대한 기초 지식과 이해가 필요합니다.

교안 p.44 그림은 입력층 뉴런(+1(바이어스), 1, 2, …, N)과 출력층 뉴런(+1, 1, …, k)이 연결강도로 모두 연결된 신경망을, 한 번의 행렬 곱으로 바꿔 쓴 모습입니다. 뉴런 사이의 "입력 × 연결강도"를 하나하나 계산하지 않고 행렬 곱 한 번으로 표현한다는 점이 요지입니다.

교안 p.44 그림(신경망 연결과 행렬 곱의 대응)은 변환본 설명만으로는 정확한 배치를 알 수 없어 아직 그리지 않았습니다 — 이미지를 보내주시면 그리겠습니다.

정리
  • 행렬 = 수를 직사각형으로 배열 / 행 = 가로, 열 = 세로 / 크기 = 행 수 × 열 수
  • aᵢⱼ = i번째 행과 j번째 열이 만나는 성분 (행 먼저)
  • 합: 같은 크기끼리 성분별 덧셈
  • 곱: (m×n)(n×p) = m×p, cᵢⱼ = A의 i행 · B의 j열 (내적) / AC = O인데 A, C ≠ O인 경우도 있음

1011.6 확률, 통계, 회귀직선

신경망의 출력은 "이 사진은 고양이다"가 아니라 "고양이일 확률 0.92"처럼 나오는 경우가 많습니다. 그래서 확률을 알아야 결과를 해석할 수 있습니다. 또 데이터가 어떻게 퍼져 있는지(평균, 분산)를 알아야 데이터를 다룰 수 있고, 두 값의 관계를 직선으로 나타내는 회귀직선은 그 자체가 가장 단순한 예측 모델입니다.

(1) 확률 Probability

  • 확률은 어떤 사건 A가 나타날 가능성을 수로 나타낸 것입니다.
  • 사건 A가 나타날 경우의 수를 전체 경우의 수로 나눈 값입니다.
정의 11.1 — 확률의 기본 법칙
  1. 어떤 사건 A에 대하여 0 ≤ P(A) ≤ 1
  2. 전사건 S의 확률 P(S) = 1
  3. 공사건 ∅의 확률 P(∅) = 0
  4. 사건 A와 그 여사건 Aᶜ 사이: P(A) + P(Aᶜ) = 1, 즉 P(Aᶜ) = 1 − P(A)

확률의 계산

예제 11.4 — 주사위 2개를 던져 나온 수의 합이 3 또는 4일 확률

전체 경우의 수는 6 × 6 = 36입니다. 합이 3인 경우는 (1, 2), (2, 1)로 2가지 → 2/36, 합이 4인 경우는 (1, 3), (2, 2), (3, 1)로 3가지 → 3/36. 따라서 236 + 336 = 536

예제 11.5 — 주사위 2개를 던져 나온 수의 합이 3 이상일 확률

여사건으로 풀면 간단합니다. "3 이상"의 여사건은 "3 미만", 즉 합이 2인 경우 (1, 1) 하나뿐이라 1/36입니다. 따라서 1 − 136 = 3536

예제 11.5처럼 구하려는 경우가 많고 반대 경우가 적을 때는, 반대(여사건)를 세서 1에서 빼는 것이 빠릅니다. 정의 11.1의 ④를 그대로 쓴 것입니다.

확률 변수, 이산적 확률, 확률 분포

  • 정의 11.2 변수 X가 취할 수 있는 모든 값이 x₁, x₂, …, xₙ이고, 각 값을 취할 확률 p₁, p₂, …, pₙ이 정해져 있을 때 X를 확률 변수라 합니다. X가 이산적인 값(띄엄띄엄한 값)을 취할 때 이 확률을 이산적 확률이라 합니다.
  • 예: 주사위 한 개를 던져 나오는 수 X는 1~6의 값을 가지고, P(X ≤ 2)는 X가 1 또는 2일 확률입니다.
  • 정의 11.3 확률 변수 X가 취하는 값 xᵢ와 그 값을 취할 확률 pᵢ의 대응 관계를 X의 확률 분포라 합니다.

(2) 평균, 분산, 표준편차

개념정의뜻
평균(mean) = 기대값(expectation)
m 또는 E(X)		∑ xᵢpᵢ = x₁p₁ + x₂p₂ + ⋯ + xₙpₙ자료 전체의 합을 자료의 개수로 나눈 값 (정의 11.4)
분산(variance)
V(X) 또는 σ²(X)		E((X − m)²) = ∑ (xᵢ − m)² pᵢ평균에서 떨어진 거리의 제곱의 평균 (정의 11.5)
표준편차(standard deviation)
σ(X)		√V(X)분산의 양의 제곱근 — 평균으로부터 얼마나 퍼져 있는지 (정의 11.6)

분산은 평균과의 차이를 제곱해서 단위도 제곱이 됩니다(예: cm → cm²). 표준편차는 여기에 제곱근을 씌워 원래 단위로 되돌린 값이라 해석하기 쉽습니다. 11.1의 정규분포 그림에서 표준편차가 작을수록 곡선이 좁고 뾰족했던 것이 이 "퍼진 정도"입니다.

예제 11.6 — 주사위 하나를 던질 때 나오는 수 X의 평균, 분산, 표준편차

X는 1~6이고, 모든 경우의 확률이 1/6입니다.

m = 1×16 + 2×16 + 3×16 + 4×16 + 5×16 + 6×16 = 216 = 72
V(X) = { (1 − 72)² + (2 − 72)² + ⋯ + (6 − 72)² } × 16 = 3512
σ(X) = √3512 = √1056 ≈ 1.708
교안 표기 오류 — 표준편차

교안은 표준편차를 √(105/6)처럼 루트가 분모 6까지 덮도록 적었는데, 이렇게 계산하면 약 4.18이 되어 틀립니다. 올바른 값은 √(35/12) = √105 / 6 ≈ 1.708(루트는 분자에만)입니다. 분산 계산 과정: (−2.5)² + (−1.5)² + (−0.5)² + 0.5² + 1.5² + 2.5² = 17.5이고, 17.5 × 1/6 = 35/12입니다.

(3) 회귀직선 regression line

  • 회귀직선은 두 변수 X, Y 사이의 관계를 나타내는 직선 Y = a + bX입니다.
  • 각 점에서 직선까지의 수직 거리(y축 방향 거리)의 제곱의 총합이 최소가 되도록 a, b를 정합니다.
  • 이렇게 얻은 직선 y = a + bx를 x에 대한 y의 회귀직선이라 합니다. a는 y절편, b는 기울기입니다.

(4) 인공지능과의 관련성

  • 인공지능, 특히 신경망에서는 학습 결과가 확률적으로 나옵니다. 그래서 확률과 통계의 기초 지식이 필요합니다.

1111.7 인공지능용 프로그래밍 언어들

마지막 절은 인공지능을 실제로 구현하는 도구인 프로그래밍 언어를 정리합니다. 시대와 목적에 따라 주로 쓰인 언어가 다릅니다. 초기 규칙기반 AI에는 Lisp, 논리 추론에는 Prolog, 지금의 신경망·딥러닝에는 Python이 주로 쓰입니다.

(1) 인공지능용 프로그래밍 언어

  • 프로그래밍 언어(Programming Languages, PL): 인간과 컴퓨터 사이의 의사소통용 인공 언어
  • 인공지능의 초기 응용 분야에는 Lisp를 많이 사용했습니다.
  • 논리를 처리하는 데 편리한 Prolog도 많이 이용했습니다.
  • 신경망이나 딥러닝에는 Python이 많이 쓰입니다.

(2) Lisp

  • Lisp(리습)은 List processing의 약자입니다.
  • 1960년 매카시(McCarthy)가 개발했으며 지금도 활용됩니다.

Lisp의 주요 특징

  • 프로그램과 자료가 같은 형태로 취급됨 — 코드도 (+ 3 4)처럼 리스트 형태
  • Lisp으로 개발된 소프트웨어가 많아 활용도가 높음

(3) Prolog

  • 1972년 영국의 코왈스키(R. Kowalski)와 프랑스 연구진이 개발했습니다.
  • 논리에 기반을 두며, 자연어 처리나 전문가 시스템 개발에 매우 유용합니다.
  • 지식을 서술 논리로 표현하고 규칙(rule)에 따라 추론합니다.

Prolog의 주요 특징

  • 사실(fact), 규칙(rule), 질문(question)들로 구성
  • 인터프리터 언어이며 대화식 명령 방식으로 작동
  • 사실과 규칙들의 데이터베이스로 구성되고, 질문에 응답하는 형식으로 진행
  • 추론 엔진(inference engine)을 사용

4주차 2차시 6장의 소크라테스 예제가 바로 이 구조였습니다. 사실(Socrates is a human) + 규칙(If X is a human, then X dies) + 질문(Is Socrates die?) → 추론 엔진이 답을 만듭니다.

(4) Python

  • 문법이 비교적 간단해 빠르고 쉽게 배울 수 있습니다.
  • 인터프리터 언어라 실행 결과를 즉석에서 확인할 수 있습니다.
  • 플랫폼 독립적이며, 동적 타이핑 대화형 언어입니다.
  • 1991년 귀도 반 로섬(Guido van Rossum)이 발표했고, Python 소프트웨어 재단이 관리하는 개방형 무료 소프트웨어입니다.

교안 그림 11.26 왼쪽은 절대값을 구하는 Python 프로그램입니다.

Pythonabsolute.py — 그림 11.26 왼쪽
# absolute value — 명령행 인자로 받은 정수의 절대값 출력
from sys import argv   # 교안 코드에는 이 줄이 없어 그대로 실행하면 NameError가 난다 → 추가함

n = int(argv[1])           # argv[0]은 파일 이름이므로 첫 번째 인자는 argv[1]
if n < 0:
    abs = -n               # 음수면 부호를 뒤집는다
else:
    abs = n                # 0 이상이면 그대로
print(abs)                 # 실행 예: python absolute.py -5  →  5

참고: 변수 이름 abs는 Python 내장 함수 abs()와 이름이 같아서, 이 코드 뒤에서는 내장 함수를 쓸 수 없게 됩니다. 실제로 짤 때는 result 같은 다른 이름이 안전합니다.
