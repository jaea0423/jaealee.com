01한눈에 요약

  1. 결정 트리는 "특징 ≤ 기준값?" 분할 규칙으로 예측 변수 공간을 단순한 영역들로 쪼개는 지도 학습 모델이며, 분류와 회귀를 모두 합니다.
  2. 장점은 해석이 쉽다는 것, 단점은 예측 정확도가 최고 수준이 아니라는 것입니다 → 배깅·랜덤 포레스트·부스팅으로 이어집니다.
  3. 노드 = 분할 규칙·gini·samples·value·class. 리프 하나 = 직사각형 영역 하나, 경계는 축에 평행. 특징 스케일링이 필요 없습니다.
  4. 지니 G = 1 − Σpk2, 엔트로피 H = −Σpk log pk: 한 클래스뿐이면 0, 고르게 섞일수록 큽니다.
  5. 과대적합 규제(사전 가지치기): max_depth ↓, min_samples_split · min_samples_leaf ↑.
  6. CART: 지니 감소량 ΔG = 부모 지니 − 자식 지니 가중평균이 가장 큰 이진 분할을 고릅니다. 예제 루트 = Age = Adolescent?(ΔG ≈ 0.26).
  7. 8-1 수업 전 초안 ID3(엔트로피·정보 이득, 범주 수만큼 분할), 회귀 트리(리프 = y 평균, MSE 최소 분할, 계단 예측), 선형 vs 트리, 한계(회전·작은 변화에 민감).
  8. 시험에 나올 것: 노드 읽기, 지니·엔트로피 계산과 0/최댓값의 뜻, ΔG 계산으로 분할 고르기, 규제 방향.
범위 안내

7주차 2차시 수업은 교안 15쪽(CART 지니 예제)까지 진행했습니다. 16–35쪽(ID3 엔트로피 예제, 회귀 트리, 선형 vs 트리, 한계)은 8주차 1차시에 배울 예정이라, 그 부분은 8-1 수업 전 초안으로 표시했습니다. 교안만 보고 쓴 것이라 8-1 수업 후 내용·중요도가 바뀔 수 있습니다.

03반드시 외울 정의 시험 직결

트리 기반 방법Tree-based methods
예측 변수 공간(predictor space)을 여러 개의 단순한 영역으로 나누는(stratifying/segmenting) 방법입니다. 나누는 데 쓴 분할 규칙들을 나무 모양으로 정리할 수 있어 결정 트리라고 부릅니다.
결정 트리Decision tree
분류와 회귀를 모두(출력이 여러 개인 과제도) 할 수 있는 기계학습 알고리즘입니다. 각 단계에서 특징 하나와 기준값 하나로 데이터를 나누고, 마지막 영역마다 하나의 예측값을 냅니다.
루트 노드Root node
트리의 맨 위 노드, 깊이(depth) 0입니다.
자식 노드Child node
다른 노드(부모) 바로 아래에 연결된 노드입니다.
리프 노드Leaf node
자식이 없는 노드(끝 노드, terminal node)입니다. 최종 예측을 냅니다.
노드 표시 5줄
분할 규칙(참이면 왼쪽) · gini(불순도) · samples(도달한 학습 샘플 수) · value(클래스별 샘플 수) · class(가장 많은 클래스 = 예측)입니다.
결정 경계Decision boundary
리프 하나가 직사각형 영역 하나이고, 경계는 항상 축에 평행한 직선입니다. 한 번에 특징 하나만 보고 나누기 때문입니다.
특징 스케일링 불필요
결정 트리는 특징 스케일링이나 중심화(centering)가 전혀 필요 없습니다. 특징 하나를 기준값과 비교만 하므로 단위가 바뀌면 기준값만 바뀝니다.
불순도Impurity
노드 안에 클래스가 섞인 정도입니다. 0이면 한 클래스뿐인 순수(pure) 노드입니다. 분류는 지니·엔트로피, 회귀는 분산(MSE)으로 잽니다.
지니 다양성 지수Gini's diversity index
노드 불순도의 척도 Gi = 1 − Σpi,k2. 범위는 0(100% 순수) ~ 1 − 1/클래스 수(매우 불순). scikit-learn 기본값입니다.
엔트로피Entropy
노드의 불확실성(uncertainty) 척도입니다. 모든 클래스가 똑같은 비율일 때 최대, 한 클래스만 있으면 0입니다. criterion 하이퍼파라미터를 entropy로 두면 씁니다.
사전 가지치기 · 규제Pre-pruning · Regularization
과대적합을 막기 위해 학습 중에 결정 트리의 자유를 제한하는 것입니다. 결정 트리는 데이터에 대한 가정이 거의 없어, 제약이 없으면 학습 데이터에 맞춰 자라 과대적합하기 쉽습니다.
규제 하이퍼파라미터
max_depth(최대 깊이), min_samples_split(노드를 나누기 위한 최소 샘플 수), min_samples_leaf(리프가 가져야 하는 최소 샘플 수). max_ 는 줄이고 min_ 은 늘리면 규제가 강해집니다.
CARTClassification and Regression Trees
분류에서 지니 불순도를 쓰고, 불순도 감소량이 가장 큰 이진 분할을 고르는 알고리즘입니다.
지니 감소량Impurity reduction ΔG
부모 지니 G(D) − 나눈 뒤 자식 지니의 샘플 수 가중평균. 클수록 좋은 분할입니다.
배깅 · 랜덤 포레스트 · 부스팅
트리를 여러 개 키워 하나의 합의된 예측(consensus prediction)으로 합치는 방법. 정확도는 크게 좋아지지만 해석력을 일부 잃습니다.

ID3 · 회귀 트리 · 한계 8-1 수업 전 초안

교안 16–35쪽 기준. 8-1 수업 후 바뀔 수 있습니다.

ID3Iterative Dichotomiser 3
엔트로피로 정보 이득을 계산하고 정보 이득이 가장 큰 속성을 분할 속성으로 고릅니다. 이진 분할이 아니라 특징의 범주 수만큼 가지를 나눕니다.
정보 이득Information gain
엔트로피의 감소량: H(D) − 나눈 뒤 엔트로피의 샘플 수 가중평균.
회귀 트리Decision Tree Regression
리프가 숫자를 예측합니다. 노드의 value = 그 노드 학습 샘플 y값의 평균 = 예측값입니다.
회귀용 CART
불순도 대신 MSE(평균제곱오차)를 최소로 하도록 나눕니다(비용함수 J를 최소화).
직교 경계Orthogonal decision boundaries
모든 분할이 축에 수직인 경계입니다. 그래서 결정 트리는 학습 데이터의 회전에 민감합니다.

04공식과 절차 시험 직결

지니 다양성 지수

Gi = 1 − Σk=1Nclasses (Nk,iNi)2 = 1 − Σk pi,k2Nk,i: 노드 i의 클래스 k 샘플 수 · Ni: 노드 i의 전체 샘플 수 · pi,k: 노드 i에서 클래스 k의 비율
  • 범위: 0(100% 순수) ~ 1 − 1Nclasses → 2클래스 최대 0.5, 3클래스 최대 0.667.
  • Iris 루트 [50, 50, 50]: 1 − 3 × (13)2 = 0.667 · [0, 49, 5]: 0.168 · [0, 1, 45]: 0.043 · [50, 0, 0]: 0.

엔트로피

Hi = − Σk=1, pi,k≠0Nclasses pi,k log(pi,k)비율 0인 클래스는 합에서 뺌(log 0 정의 안 됨) · 앞의 −는 log p ≤ 0이라 H를 0 이상으로 만들기 위함 · 교안 7쪽은 밑을 안 적었고 예제(17쪽~)는 log2
  • 한 클래스만 있으면 확실성 ↑ → 엔트로피 = 0. 고르게 섞이면 불확실성 ↑ → 엔트로피 ↑.
  • log2 기준 계산 예 보충: [5, 5] → 1 · [10, 0] → 0 · [50, 50, 50] → log23 ≈ 1.585 · [9, 5] → 0.940.

CART 불순도 감소량

ΔG(D, s) = G(D) − ( |DL||D|G(DL) + |DR||D|G(DR) )s: 후보 이진 분할 · DL, DR: 나눈 뒤 왼쪽·오른쪽 자식 데이터 · 괄호 안 = 나눈 뒤 가중 지니(Gsplit)
  1. 부모 지니 G(D)를 구합니다. 예: 구매 4·비구매 3 → 1 − (47)2 − (37)2 = 2449 ≈ 0.490.
  2. 후보 이진 분할마다 자식 지니를 구해 샘플 수 비율로 가중평균합니다.
  3. ΔG = G(D) − 가중평균. ΔG가 가장 큰 분할을 고릅니다.
  4. 자식마다 같은 과정을 반복하고, G = 0(순수)이면 리프로 멈춥니다.

예제 값: s1 Adolescent vs 나머지 → 가중 지니 27·0 + 57·0.320 ≈ 0.229, ΔG ≈ 0.26 / s2 Adolescent·Young Adult vs Middle-aged → 1021 ≈ 0.476, ΔG ≈ 0.014 → s1(Age = Adolescent?)이 루트. 최종 트리: Age = Adolescent? → 오른쪽 5명은 Credit Rating → Excellent 2명은 Age로 나뉨. 모든 리프 gini 0.

규제 방향

max_depth ↓ · min_samples_split ↑ · min_samples_leaf ↑ ⇒ 규제 ↑ · 과대적합 위험 ↓교안 9쪽: "Reducing max depth will regularize the model and thus reduce the risk of overfitting."

정보 이득 (ID3) 8-1 수업 전 초안

Gain(D, A) = H(D) − Σv∈VA |Dv||D| H(Dv)A: 후보 특징 · VA: A의 범주 집합 · Dv: A = v인 샘플들
  • 14명(구매 9·비구매 5): H(D) ≈ 0.940. 정보 이득 Age 0.247 > Student 0.151 > Credit 0.048 > Income 0.029 → Age가 첫 분할 속성.
  • Young adult 4명은 모두 구매 → 바로 리프. Youth 그룹은 Student, Middle-aged 그룹은 Credit Rating으로 두 번째 분할 → 모든 리프 순수.

회귀용 CART 비용함수 8-1 수업 전 초안

J(k, tk) = mleftmMSEleft + mrightmMSErightk, tk: 나눌 특징과 기준값(xk ≤ tk?) · mleft, mright, m: 왼쪽·오른쪽·부모 샘플 수 · J가 가장 작은 분할을 고름
MSEnode = 1mnodeΣi∈node(ŷnode − y(i))2
ŷnode = 1mnodeΣi∈node y(i)ŷnode: 노드 y의 평균 = 그 노드의 예측값
주의 — 교안 30쪽 식

교안의 MSEnode 식에는 1mnode이 빠져 있어 그대로면 제곱오차의 합입니다. 원고에서 Python으로 확인한 결과 1mnode이 있어야 29쪽 트리의 기준값 0.197이 나옵니다(빼면 0.255). 시험에서는 주어진 식의 형태를 따르세요.

06그림으로 기억 자주 나옴

  • 각 줄(규칙·gini·samples·value·class)의 뜻을 말할 수 있어야 합니다. 루트 gini 0.667 = 3클래스 최대, setosa 리프 gini 0 = 순수.
  • 새 샘플을 넣어 리프까지 따라가기: 꽃잎 길이 5, 너비 1.5 → 5 ≤ 2.45 거짓(오른쪽) → 1.5 ≤ 1.75 참(왼쪽) → versicolor.
  • 굵은 실선 x1 = 2.45는 깊이 0(루트), 파선 x2 = 1.75는 깊이 1, 점선은 더 깊이 키우면 생기는 분할입니다.
  • 왼쪽 = 점 하나하나에 맞춘 복잡한 경계 = 과대적합. 오른쪽 = 경계가 단순해져 새 데이터에 더 잘 맞을 가능성이 큽니다.
  • 위 줄(대각선 경계)은 선형 모델이, 아래 줄(직사각형 경계)은 트리가 잘 맞습니다. 위 줄 트리의 계단 = 한계 ①(회전에 민감)의 예입니다.

07함정 O/X 시험 직결

  1. 지니 지수가 0이면 노드에 클래스들이 고르게 섞여 있다는 뜻이다.X — 0은 한 클래스만 있는 100% 순수 노드입니다.
  2. 클래스가 3개일 때 지니 지수의 최댓값은 1 − 1/3 ≈ 0.667이다.O — 범위 0 ~ 1 − 1/Nclasses.
  3. 엔트로피는 모든 클래스가 같은 비율일 때 최대이다.O — 고르게 섞일수록 불확실성 ↑, 한 클래스뿐이면 0.
  4. 지니보다 엔트로피가 계산이 약간 더 빨라 기본값으로 쓰인다.X — 지니가 약간 더 빠르고 기본값입니다. 엔트로피는 소수 클래스에 더 민감합니다.
  5. max_depth를 늘리면 규제가 강해져 과대적합 위험이 줄어든다.X — max_depth는 줄여야 규제가 강해집니다.
  6. min_samples_leaf를 늘리면 규제가 강해진다.O — min_ 값은 늘리면 규제 ↑.
  7. 결정 트리는 거리 기반 모델이라 특징 스케일링이 꼭 필요하다.X — 스케일링·중심화가 전혀 필요 없습니다(교안 3쪽).
  8. 결정 트리의 결정 경계는 축에 평행한 직선들로 이루어진다.O — 한 번에 특징 하나만 보고 나누기 때문입니다.
  9. CART는 불순도 감소량 ΔG가 가장 작은 분할을 고른다.X — 감소량이 가장 큰 이진 분할을 고릅니다(= 나눈 뒤 가중 지니가 가장 작은 분할).
  10. ΔG의 괄호 안은 두 자식 지니의 단순 평균이다.X — 샘플 수 비율 |DL|/|D|, |DR|/|D|로 가중평균합니다.
  11. 결정 트리는 데이터에 대한 가정이 많아 과대적합 위험이 작다.X — 가정이 거의 없어 제약이 없으면 과대적합하기 쉽습니다.
  12. 트리 기반 방법은 해석은 쉽지만 예측 정확도는 최고 수준의 지도 학습 방법보다 떨어진다.O — 그래서 배깅·랜덤 포레스트·부스팅을 다룹니다.
  13. 결정 트리는 분류에만 쓸 수 있다.X — 분류·회귀 모두, 다중 출력 과제도 가능합니다.
  14. 8-1 수업 전 초안 ID3도 CART처럼 항상 두 갈래로만 나눈다.X — ID3는 특징의 범주 수만큼 나눕니다(Age → 세 갈래).
  15. 8-1 수업 전 초안 회귀 트리 리프의 예측값은 그 리프에 속한 학습 샘플 y값의 평균이다.O — 그래서 예측이 구간마다 일정한 계단 모양입니다.
  16. 8-1 수업 전 초안 결정 트리는 학습 데이터를 회전시켜도 결과가 거의 변하지 않는다.X — 직교 경계만 만들어 회전에 민감하고, 데이터의 작은 변화에도 민감합니다.

08연습 문제 시험 직결

1. 노드 읽기 · 예측 (서술)

Iris 트리(루트: petal length ≤ 2.45, 오른쪽 자식: petal width ≤ 1.75)에서 꽃잎 길이 5cm, 너비 1.5cm인 꽃의 예측 클래스와 지나가는 노드를 쓰고, 결정 트리에 특징 스케일링이 필요 없는 이유를 쓰시오.

풀이 보기
모범 답안: 루트에서 5 ≤ 2.45가 거짓이므로 오른쪽 자식으로, 1.5 ≤ 1.75가 참이므로 왼쪽 리프로 가서 versicolor로 예측한다. 결정 트리는 한 번에 특징 하나를 기준값과 비교만 하므로, 단위를 바꾸면 기준값만 함께 바뀌고 나뉘는 방식은 같다. 따라서 특징 스케일링이 필요 없다.
2. 지니 계산

value = [0, 49, 5]인 노드(54개)의 지니를 소수 셋째 자리까지 구하시오. 클래스가 2개일 때 지니의 최댓값은?

풀이 보기
G = 1 − (4954)2 − (554)2 = 1 − 0.8234 − 0.0086 ≈ 0.168. 2클래스 최댓값 = 1 − 12 = 0.5(반반일 때).
3. CART 분할 선택 (교안 예제)

부모: 구매 4·비구매 3. 분할 s1: 왼쪽 (구매 0, 비구매 2), 오른쪽 (4, 1). 분할 s2: 왼쪽 (2, 2), 오른쪽 (2, 1). 각 ΔG를 구하고 CART가 고르는 분할을 쓰시오.

풀이 보기
G(D) = 2449 ≈ 0.490.
s1: G(DL) = 0, G(DR) = 1 − 0.64 − 0.04 = 0.320 → 가중 = 57 × 0.320 ≈ 0.229 → ΔG ≈ 0.261.
s2: G(DL) = 12, G(DR) = 49 → 가중 = 1021 ≈ 0.476 → ΔG ≈ 0.014.
ΔG가 더 큰 s1을 고른다(왼쪽 자식이 완전히 순수해짐).
4. 새 숫자로 ΔG 보충

부모 10개(A 6, B 4)를 왼쪽 4개(A 4, B 0), 오른쪽 6개(A 2, B 4)로 나누었다. ΔG를 소수 셋째 자리까지 구하시오.

풀이 보기
G(D) = 1 − 0.62 − 0.42 = 0.48. G(DL) = 0. G(DR) = 1 − (26)2 − (46)2 = 49 ≈ 0.444. 가중 = 0.4 × 0 + 0.6 × 0.444 ≈ 0.267. ΔG = 0.48 − 0.267 ≈ 0.213.

결정 트리가 과대적합되었다. 규제를 강하게 하는 조정이 아닌 것은? ① max_depth를 줄인다 ② min_samples_leaf를 늘린다 ③ min_samples_split을 늘린다 ④ max_depth를 늘린다

풀이 보기
④. max_ 값은 줄이고 min_ 값은 늘려야 규제가 강해진다. max_depth를 늘리면 트리가 더 깊어져 과대적합이 심해진다.
