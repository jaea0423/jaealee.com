01DBSCAN ① — ε-이웃, 핵심점과 경계점군집화 교안 26–27쪽

7주차 1차시에서 이어서

지난 시간은 군집화 교안 25쪽(DBSCAN 소개)까지 했습니다. DBSCAN이 무엇인지와 핵심 단어(Density, Noise)는 7-1의 16을 먼저 보세요. 이 1부(01–07)는 군집화 교안 26–35쪽입니다.

DBSCAN: ε-neighborhood of a point

정의 1 — ε-이웃(ε-neighborhood): 데이터 D의 점 p에 대해, p에서 거리 ε 이하인 점들의 집합입니다. 즉 p를 중심으로 반지름 ε인 원 안의 점들(자기 자신 포함)입니다.

Nε(p) = { q ∈ D | dist(p, q) ≤ ε }

단순한 방법과 그 문제: 군집 안의 모든 점이 ε-이웃 안에 최소 MinPts개 이상의 점을 갖도록 요구하는 방법을 생각할 수 있습니다. 그런데 군집의 가장자리 점(경계점)은 원의 절반쯤이 군집 바깥이라, 안쪽 점(핵심점)보다 이웃이 훨씬 적습니다. 그래서 이 조건으로는 가장자리 점이 군집에서 빠져 버립니다.

Problem of naïve approach: An ε-neighborhood of a border point contains significantly less points than an ε-neighborhood of a core point.

그래서 점을 두 종류로 나눕니다.

종류조건위치
핵심점
core point		|Nε(p)| ≥ MinPts
(ε-이웃 안에 자기 포함 MinPts개 이상)		빽빽한 영역의 안쪽Core points are the interior of dense regions.
경계점
border point		|Nε(p)| < MinPts 이지만
어떤 핵심점의 ε-이웃 안에 있음		군집의 가장자리Border points are on the edge of a cluster.
잡음
noise (보충: 20의 정의 6)		핵심점도 아니고 어떤 핵심점의 이웃도 아님홀로 떨어진 점

|Nε(p)|는 집합의 원소 개수입니다. 교안 그림(27쪽)은 개념도라 경계점 원 안에도 점이 4~5개 걸쳐 보여 정의와 정확히 맞지 않습니다. 위 그림은 점 위치를 다시 잡아 정의대로 판정되게 했습니다.

정리
  • Nε(p) = p에서 거리 ε 이내의 점들 (자기 포함)
  • 핵심점: |Nε(p)| ≥ MinPts / 경계점: 이웃은 적지만 핵심점의 이웃 안 / 잡음: 둘 다 아님

02DBSCAN ② — 직접 밀도 도달군집화 교안 28–29쪽

DBSCAN: Directly Density-Reachable

정의 2: 점 q가 점 p로부터 (ε, MinPts에 대해) 직접 밀도 도달 가능(directly density-reachable)하다는 것은 다음 두 조건을 모두 만족한다는 뜻입니다.

조건식뜻
도달 (reachability)q ∈ Nε(p)q가 p의 ε 원 안에 있다
핵심점 조건 (core point condition)|Nε(p)| ≥ MinPts출발점 p가 핵심점이다

성질 — 대칭인가?

  • 둘 다 핵심점이면 대칭입니다. 서로 상대의 원 안에 있고 둘 다 핵심점이므로 양쪽 방향 모두 성립합니다.Directly density-reachable is symmetric for pairs of core points.
  • 핵심점 하나와 경계점 하나이면 대칭이 아닙니다. 핵심점 → 경계점은 되지만, 경계점 → 핵심점은 출발점(경계점)이 핵심점 조건을 못 지켜 안 됩니다.Not symmetric if one core point and one border point are involved.

거리는 대칭(dist(p, q) = dist(q, p))이라 "원 안에 있다"는 양쪽이 같지만, "출발점이 핵심점"이라는 조건 때문에 방향이 생깁니다.

정리
  • q가 p로부터 직접 밀도 도달 = q ∈ Nε(p) 그리고 p가 핵심점
  • 핵심점끼리는 대칭, 핵심점–경계점은 비대칭 (핵심점 → 경계점만)

03DBSCAN ③ — 밀도 도달과 밀도 연결군집화 교안 30–31쪽

DBSCAN: Density-Reachable & Density-Connected

정의 3 — 밀도 도달(density-reachable): q가 p로부터 밀도 도달 가능하다는 것은, p에서 q까지 직접 밀도 도달을 여러 번 이어 붙인 사슬이 있다는 뜻입니다.

p = p₁, p₂, …, pm = q 가 있어서 모든 i = 1, …, m − 1에 대해
pi+1 ∈ Nε(pi) 이고 pi는 핵심점

사슬의 중간 점들은 모두 핵심점이어야 하고, 마지막 q만 핵심점이 아니어도 됩니다.

정의 4 — 밀도 연결(density-connected): p와 q가 밀도 연결되어 있다는 것은, 어떤 점 o로부터 p와 q가 둘 다 밀도 도달 가능하다는 뜻입니다.

어떤 o ∈ D가 있어서 p도 o로부터, q도 o로부터 밀도 도달 가능
개념대칭?왜 필요한가
직접 밀도 도달핵심–경계면 비대칭한 걸음 이웃 관계
밀도 도달비대칭핵심점을 징검다리 삼아 멀리까지 이어짐 → 길게 휘어진 군집도 하나로
밀도 연결대칭경계점 두 개(서로 도달 불가)도 같은 군집으로 묶기 위해

표의 "왜 필요한가"는 보충 설명입니다. 군집 가장자리의 경계점끼리는 둘 다 핵심점이 아니라서 서로 밀도 도달이 안 됩니다. 그래도 같은 군집이어야 하므로, 공통의 핵심점 o를 통해 "연결"되어 있다는 대칭적인 관계가 필요합니다.

정리
  • 밀도 도달: 핵심점들을 거치는 직접 도달의 사슬 (비대칭)
  • 밀도 연결: 어떤 o로부터 p, q 모두 밀도 도달 가능 (대칭)

04DBSCAN ④ — 군집과 잡음군집화 교안 32쪽

DBSCAN: Cluster & Noise

정의 5 — 군집: (ε, MinPts에 대한) 군집은 데이터 D의 비어 있지 않은 부분집합 C로, 다음 두 조건을 만족합니다.

조건식뜻
① 최대성
Maximality		p ∈ C이고 q가 p로부터 밀도 도달 가능하면 q ∈ C군집 안의 점에서 밀도 도달되는 점은 빠짐없이 군집에 넣는다 (더 넓힐 수 없을 때까지)
② 연결성
Connectivity		모든 p, q ∈ C에 대해 p와 q는 밀도 연결군집 안의 어떤 두 점도 밀도 연결되어 있다 (한 덩어리)

정의 6 — 잡음: C₁, …, Ck를 데이터 D의 (ε, MinPts에 대한) 군집들이라 할 때, 어느 군집에도 속하지 않는 점들의 집합을 잡음이라 합니다.

보충 — 실제 DBSCAN이 군집을 찾는 순서
  1. 모든 점의 ε-이웃을 세어 핵심점을 표시합니다.
  2. 아직 군집이 없는 핵심점 하나에서 시작해, 밀도 도달 가능한 점을 모두 모읍니다(핵심점이면 그 이웃으로 계속 넓히고, 경계점이면 거기서 멈춤). 이것이 군집 하나입니다(최대성).
  3. 남은 핵심점이 없을 때까지 2를 반복합니다.
  4. 어느 군집에도 들어가지 못한 점은 잡음입니다.

군집 수는 이 과정에서 저절로 정해지므로 K를 줄 필요가 없습니다. 대신 ε와 MinPts를 정해야 하고, 밀도가 서로 많이 다른 군집이 섞여 있으면 하나의 ε로 모두 잘 잡기 어렵습니다(23 그림 3번째 줄).

정리
  • 군집 = 밀도 도달로 닿는 점을 다 포함(최대성)하고, 안의 모든 점이 밀도 연결(연결성)
  • 잡음 = 어느 군집에도 속하지 않는 점

05가우시안 혼합 모델 (GMM)군집화 교안 33쪽

Gaussian Mixture Model

가우시안 혼합 모델(Gaussian Mixture Model, GMM)은 데이터 전체를 여러 개의 가우시안(정규분포)을 섞은 것으로 보고, 가우시안 하나하나를 군집(클래스) 하나로 해석하는 방법입니다.

Gaussian Mixture Model (GMM): can be understood simply as a number of Gaussians introduced into a population of data in order to classify each of the possible sample clusters, each of which could refer to classes.

그림 읽기: 실제 데이터 분포(검은 실선)는 봉우리가 세 개라 가우시안 하나로는 나타낼 수 없습니다. 이것을 평균·폭·높이가 다른 가우시안 세 개(파란 점선)의 합으로 나타내면, 각 가우시안이 하나의 군집이 됩니다.

보충 — K-평균과의 차이

K-평균은 각 점을 한 군집에 딱 잘라 배정하지만, GMM은 "이 점이 군집 1일 확률 0.7, 군집 2일 확률 0.3"처럼 확률로 배정합니다. 또 가우시안마다 폭(분산)과 기울어진 방향이 달라도 되므로, K-평균이 잘 못 찾는 길쭉한 군집도 찾을 수 있습니다(23 그림 4번째 줄 맨 오른쪽).

정리
  • GMM = 데이터를 가우시안 여러 개의 합으로 보고, 가우시안 하나 = 군집 하나

06군집화로 이미지 분할하기군집화 교안 34쪽

Using Clustering for Image Segmentation — With K-Means

원리: 사진의 픽셀 하나하나를 (R, G, B) 세 특징을 가진 데이터 점으로 봅니다. 이 점들에 K-평균을 적용하면 색이 비슷한 픽셀끼리 K개 군집으로 묶이고, 각 픽셀을 자기 군집의 중심색으로 바꾸면 K색짜리 그림이 됩니다.

그림 읽기: K가 줄어들수록 색이 단순해집니다. 무당벌레는 그림에서 차지하는 픽셀 수가 매우 적어서, K가 작아지면 빨강이 독자적인 군집을 얻지 못하고 주변 색(갈색·초록) 군집에 흡수됩니다. K-평균은 이너셔(거리 제곱 총합)를 줄이는 쪽으로 중심을 놓기 때문에 점이 많은 색 쪽에 중심이 배치되기 때문입니다(10의 한계 ①과 같은 이유).

정리
  • 픽셀 색 (R, G, B)를 점으로 보고 K-평균 → 각 픽셀을 중심색으로 = 색 K개로 분할
  • 작은 영역(무당벌레)의 색은 K가 작으면 사라짐

정리

  • K-평균: 둥근 군집에 강함 / DBSCAN 계열: 휘어진 모양·잡음에 강함

08트리 기반 방법결정 트리 교안 1쪽

Tree-based Methods

2부는 결정 트리(decision tree)입니다. 다시 지도 학습(x와 정답 y가 있음)으로 돌아옵니다.

트리 기반 방법은 입력 변수들이 이루는 공간(예측 변수 공간, predictor space)을 여러 개의 단순한 영역으로 쪼개는 방법입니다.

Tree-based methods involve stratifying or segmenting the predictor space into a number of simple regions.

공간을 쪼개는 데 쓴 분할 규칙(예: "꽃잎 길이 ≤ 2.45cm?")들을 나무(tree) 모양으로 정리할 수 있어서 결정 트리 방법이라고 부릅니다.

Since the set of splitting rules used to segment the predictor space can be summarized in a tree, these types of approaches are known as decision-tree methods.

결정 트리는 분류와 회귀를 모두 할 수 있고, 출력이 여러 개인 과제(multi-output)도 할 수 있습니다.

Decision trees are versatile machine learning algorithms that can perform both classification and regression tasks, and even multi-output tasks.

"스무고개"처럼 질문을 차례로 던지는 구조라고 흔히 설명하지만, 정확히 말하면: 각 단계에서 특징 하나와 기준값 하나로 데이터를 둘(또는 여러 개)로 나누고, 나뉜 각 부분에서 같은 일을 반복합니다. 마지막에 남은 각 부분(영역)마다 하나의 예측값(분류면 클래스, 회귀면 숫자)을 정합니다.

정리
  • 결정 트리 = 예측 변수 공간을 분할 규칙으로 단순한 영역들로 쪼갬, 규칙을 나무 모양으로 표현
  • 분류·회귀·다중 출력 모두 가능 (지도 학습)
필기 원문

09트리 기반 방법의 장단점결정 트리 교안 2쪽

Pros and Cons of Tree-based Methods
장점단점
단순하고 해석하기 쉽다 — 규칙을 그대로 읽을 수 있음Tree-based methods are simple and useful for interpretation.예측 정확도는 최고의 지도 학습 방법들보다 대체로 떨어진다However, they typically are not competitive with the best supervised learning approaches in terms of prediction accuracy.

그래서 배깅(bagging), 랜덤 포레스트(random forests), 부스팅(boosting)도 다룹니다. 이 방법들은 트리를 여러 개 키워서 하나의 합의된 예측으로 합칩니다.

These methods grow multiple trees which are then combined to yield a single consensus prediction.

트리를 많이 합치면 예측 정확도가 크게 좋아지는 대신, 해석하기 쉬운 장점은 일부 잃습니다.

Combining a large number of trees can often result in dramatic improvements in prediction accuracy, at the expense of some loss of interpretation.

트리 하나는 규칙 몇 줄로 읽을 수 있지만, 트리 수백 개의 다수결은 사람이 한 번에 읽을 수 없기 때문입니다. 배깅·랜덤 포레스트·부스팅은 이번 교안에 내용이 없어 뒤 수업에서 다룰 것으로 보입니다.

정리
  • 장점: 단순·해석 쉬움 / 단점: 정확도가 최고 수준은 아님
  • 해결: 트리 여러 개를 합침(배깅·랜덤 포레스트·부스팅) → 정확도 ↑, 해석력 ↓

13지니 다양성 지수결정 트리 교안 6쪽

Gini's Diversity Index

노드 i의 지니 지수는 다음과 같습니다.

Gi = 1 − ∑k=1Nclasses ( Nk,iNi )² = 1 − ∑k=1Nclasses pi,k²
  • Nk,i: 노드 i에 있는 클래스 k 샘플 수the number of data samples of class k in node i
  • Ni: 노드 i의 전체 샘플 수 → pi,k = Nk,i/Ni는 노드 i에서 클래스 k의 비율

읽는 법: 클래스 비율을 제곱해서 더한 값을 1에서 뺍니다. 한 클래스만 있으면 비율이 1이라 1 − 1² = 0(완전히 순수). 여러 클래스가 고르게 섞일수록 제곱합이 작아져 G가 커집니다.

범위는 0(100% 순수)부터 1 − 1/Nclasses(매우 불순)까지입니다.

The Gini's impurity index ranges from 0 (100% pure node) to 1 − 1/N_classes (very impure node).
Iris 노드value계산G
루트[50, 50, 50]1 − 3 × (1/3)²0.667 (= 1 − 1/3, 3클래스 최대)
setosa 리프[50, 0, 0]1 − 1²0
versicolor 리프[0, 49, 5]1 − (49/54)² − (5/54)²0.168
virginica 리프[0, 1, 45]1 − (1/46)² − (45/46)²0.043

최댓값 1 − 1/K: 클래스 2개면 0.5, 3개면 0.667, 4개면 0.75 (Python으로 확인).

정리
  • G = 1 − ∑ pₖ² (pₖ = 노드 안 클래스 k의 비율)
  • 0 = 순수, 최대 1 − 1/(클래스 수) = 고르게 섞임

14엔트로피결정 트리 교안 7쪽

Entropy

엔트로피는 노드의 불확실성(uncertainty)을 잽니다. 모든 클래스가 같은 비율로 섞여 있을 때 최대이고, 한 클래스만 있으면 0입니다.

Entropy is maximized when all classes are equally likely and equals zero when the node contains only one class.
Hi = − ∑k=1, pi,k ≠ 0Nclasses pi,k log(pi,k)
  • pi,k: 노드 i에서 클래스 k의 비율. 비율이 0인 클래스는 합에서 뺍니다(log 0은 정의되지 않음).
  • 한 클래스만 있으면 확실성 ↑ → 엔트로피 = 0If the node contains only one class, certainty ↑ ⇒ entropy value = 0.
  • 클래스가 고르게 섞이면 불확실성 ↑ → 엔트로피 ↑If the classes are evenly mixed, uncertainty ↑ ⇒ entropy value ↑.

앞의 마이너스 부호: 비율 p는 0~1이라 log p는 0 이하입니다. 그래서 −를 붙여 엔트로피를 0 이상으로 만듭니다.

계산 예 (보충, 밑 2 로그)

반반 [5, 5]: −(0.5 log₂ 0.5 + 0.5 log₂ 0.5) = 1. 순수 [10, 0]: 0. Iris 루트 [50, 50, 50]: −3 × (1/3) log₂(1/3) = log₂ 3 ≈ 1.585. 교안 7쪽은 log의 밑을 적지 않았지만 뒤 예제(18)는 log₂를 씁니다.

정리
  • H = −∑ pₖ log pₖ (pₖ = 0인 클래스 제외)
  • 순수하면 0, 고르게 섞이면 최대 (2클래스·log₂면 최대 1)

16사전 가지치기 — 규제 하이퍼파라미터결정 트리 교안 9–10쪽

[Pre-pruning] Regularization Hyperparameters

결정 트리는 학습 데이터에 대한 가정이 거의 없습니다. 선형 모델이 "데이터가 직선 관계"라고 가정하는 것과 반대입니다.

Decision trees make very few assumptions about the training data (as opposed to linear models, which obviously assume that the data is linear, for example).

그래서 아무 제약 없이 두면 트리 구조가 학습 데이터에 맞춰 계속 자라 데이터를 아주 가깝게 따라가고, 과대적합할 가능성이 큽니다. 과대적합을 막으려면 학습 중에 트리의 자유를 제한해야 합니다. 이것이 규제(regularization)이고, 다 자라기 전에 미리 막는다는 뜻에서 사전 가지치기(pre-pruning)라고 합니다.

If left unconstrained, the tree structure will adapt itself to the training data, fitting it very closely, and most likely overfitting it.
하이퍼파라미터 (scikit-learn 이름)제한하는 것
max_depth트리의 최대 깊이. 줄이면 규제가 강해져 과대적합 위험이 줄어든다Reducing max depth will regularize the model and thus reduce the risk of overfitting.
min_samples_split노드를 나누기 위해 필요한 최소 샘플 수the minimum number of samples a node must have before node can be split
min_samples_leaf리프 노드가 가져야 하는 최소 샘플 수the minimum number of samples a leaf node must have

max_로 시작하는 값은 줄이고, min_으로 시작하는 값은 늘리면 규제가 강해집니다. 6주차 SVM의 C처럼 이 값들도 교차 검증으로 고르는 하이퍼파라미터입니다.

정리
  • 결정 트리는 가정이 거의 없어 그대로 두면 과대적합
  • 규제(사전 가지치기): max_depth ↓, min_samples_split·min_samples_leaf ↑

CART uses Gini impurity for classification and selects the binary split with the largest impurity reduction.

1단계 — 부모 노드의 지니

부모 노드 D: 구매 4명, 비구매 3명 → pYes = 4/7, pNo = 3/7.

G(D) = 1 − (47)² − (37)² = 2449 ≈ 0.490

ΔG(D, s) = G(D) − ( |DL||D| G(DL) + |DR||D| G(DR) )

s는 후보 이진 분할, DL, DR은 나눈 뒤 왼쪽·오른쪽 자식입니다. 괄호 안은 나눈 뒤의 가중 지니로, 자식 노드 지니를 샘플 수 비율로 가중평균한 것입니다. 감소량이 가장 큰 분할을 고릅니다.

후보왼쪽 DL오른쪽 DR가중 지니ΔG

s₂: Adolescent·Young Adult vs Middle-aged4명 (2, 2) → G = 1/23명 (2, 1) → G = 4/9(4/7)(1/2) + (3/7)(4/9) = 10/21 ≈ 0.4760.014

s₁은 왼쪽 자식이 완전히 순수(비구매만)해져서 감소량이 큽니다. s₂는 나눈 뒤에도 양쪽이 거의 반반이라 감소량이 거의 없습니다.

4단계 — 나머지 특징도 같은 방법으로

Income, Student Status, Credit Rating에 대해서도 모든 이진 분할의 ΔG를 계산해 가장 큰 것을 고르고, 자식 노드마다 같은 과정을 반복합니다.

Repeat the same process for Income, Student Status, and Credit Rating.

Age{Adolescent} 0.261 > Age{Young Adult} 0.147 > Income{High}·Credit 0.085 > Income{Medium} 0.061 > Age{Middle-aged}·Income{Low}·Student 0.014 → 루트는 Age(Adolescent vs 나머지). 오른쪽 자식(G = 0.32)에서는 Credit Rating이 0.120으로 가장 커서 선택. Excellent 노드(ID 6, 7)는 Income·Student가 둘 다 같아 나눌 수 없고 Age로만 완전히 나뉩니다.

정리
  • CART = 지니 사용, 이진 분할 중 ΔG(불순도 감소량)가 가장 큰 것을 선택
  • ΔG = 부모 지니 − 자식 지니의 샘플 수 가중평균
  • 예: G(D) = 24/49 ≈ 0.490, Age(Adolescent vs 나머지)의 ΔG ≈ 0.26이 최대

Decision Tree Regression

결정 트리는 회귀도 할 수 있습니다. 구조는 분류 트리와 같고, 리프가 클래스 대신 숫자 값을 예측합니다.

Decision trees are also capable of performing regression tasks.
  • value: 그 노드에 속한 학습 샘플 y값의 평균 = 그 노드의 예측값
  • mse: 그 노드 샘플들의 평균제곱오차 = 노드 안 y값이 평균에서 얼마나 흩어져 있나 (분류 트리의 gini 자리)

부모의 value는 자식 value를 샘플 수로 가중평균한 값입니다. 예: (44 × 0.689 + 156 × 0.259)/200 ≈ 0.354.

정리
  • 회귀 트리: 리프 예측값 = 그 리프 샘플 y의 평균
  • 노드의 mse = 그 노드 y값의 흩어짐 (분류의 gini 역할)

20회귀용 CART 학습 알고리즘결정 트리 교안 30쪽

The CART Training Algorithm for Regression

분류에서는 불순도를 최소로 나눴는데, 회귀에서는 MSE(평균제곱오차)를 최소로 하도록 학습 데이터를 나눕니다.

Instead of trying to split the training set in a way that minimizes impurity, it now tries to split the training set in a way that minimizes the MSE (Mean Squared Error).
J(k, tk) = mleftm MSEleft + mrightm MSEright
MSEnode = 1mnode ∑i ∈ node (ŷnode − y(i))²,    ŷnode = 1mnode ∑i ∈ node y(i)
  1. k, tk: 나눌 특징 k와 그 기준값 tk ("xk ≤ tk?")
  2. mleft, mright, m: 왼쪽·오른쪽 자식과 부모의 샘플 수
  3. ŷnode: 노드의 예측값 = 노드 샘플 y의 평균
  4. J: 두 자식의 MSE를 샘플 수로 가중평균한 값. 모든 (k, tk) 후보 중 J가 가장 작은 것을 고른다

분류용 CART의 "가중 지니"(17) 자리에 MSE가 들어간 형태입니다.

교안 30쪽 식은 MSEnode에 1/mnode가 빠져 있어 실제로는 제곱오차의 합입니다. 평균이 되려면 위처럼 1/mnode가 있어야 하고, 그래야 앞 그림의 기준값(0.197)이 나옵니다(슬라이드 식 그대로 계산하면 0.255가 선택됨, Python으로 확인). 25에 적어 두었습니다.

정리
  • 회귀 CART: 두 자식 MSE의 가중평균 J(k, tₖ)가 최소인 특징·기준값을 선택
  • 노드 예측값 = 노드 y 평균

21회귀 트리의 예측과 규제결정 트리 교안 31–32쪽

Predictions of Decision Tree for Regression / Regularizing decision tree regression

그림 읽기: 회귀 트리의 예측은 계단 모양입니다. 리프 하나가 x₁의 구간 하나를 맡고, 그 구간에서는 항상 같은 값(그 구간 y의 평균)을 내기 때문입니다. 깊이 2면 리프 4개 → 계단 4단, 깊이 3이면 리프 8개 → 계단 8단입니다.

분류 트리와 마찬가지로 규제가 없으면 회귀 트리도 과대적합합니다. min_samples_leaf 같은 규제를 주면 훨씬 그럴듯한 모델이 됩니다(16).

정리
  • 회귀 트리 예측 = 계단 모양 (리프마다 구간 평균)
  • 깊이 ↑ → 계단 잘게, 규제 없으면 모든 점을 지나는 과대적합

24결정 트리의 한계결정 트리 교안 35쪽

Limitations of Decision Tree

결정 트리는 이해·해석이 쉽고, 쓰기 편하고, 분류·회귀 모두 되는 강력한 방법이지만 한계가 있습니다.

Decision trees are simple to understand and interpret, easy to use, versatile, and powerful. However, they do have a few limitations.
한계설명
① 직교 경계만 만든다 → 회전에 민감모든 분할이 축에 수직이라, 데이터를 회전시키기만 해도 결과가 크게 달라진다Decision trees love orthogonal decision boundaries (all splits are perpendicular to an axis), which makes them sensitive to training set rotation.
② 데이터의 작은 변화에 민감학습 데이터가 조금만 바뀌어도 트리 구조가 크게 바뀔 수 있다Decision trees are very sensitive to small variations in the training data.

①의 예: 두 클래스가 x₁ = 0 세로선으로 깔끔히 나뉘면 트리는 분할 한 번으로 끝나지만, 같은 데이터를 45° 돌리면 경계가 대각선이 되어 트리는 계단을 여러 개 만들어야 합니다(23 위쪽 그림과 같은 상황). ②는 루트에서 고른 특징이 바뀌면 그 아래 전체가 바뀌기 때문입니다. 트리를 여러 개 합치는 랜덤 포레스트 등(09)이 이 불안정성을 줄이는 방법입니다.

정리
  • 한계 ①: 축에 수직인 경계만 → 데이터 회전에 민감
  • 한계 ②: 학습 데이터의 작은 변화에도 트리가 크게 바뀜
