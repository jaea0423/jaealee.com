1단계 — 지도 학습과 비지도 학습

지금까지(회귀·SVM)는 입력 x와 정답 y가 함께 있는 지도 학습이었습니다. 오늘은 x만 있고 y(라벨)가 없는 비지도 학습입니다. 정답이 없으니 "맞혔다/틀렸다"가 아니라, 데이터의 패턴과 구조를 보고 비슷한 것끼리 부분 집단(군집)으로 나눕니다. 이것이 군집화입니다. → 01, 02

2단계 — 방법 세 가지와 기준

  • K-평균: 군집 수 K를 미리 정함 — 거리 기반
  • 계층적 군집화: K를 미리 정하지 않고 덴드로그램을 만듦 — 거리 기반
  • DBSCAN: 점이 빽빽한 곳을 군집으로 — 밀도 기반 (D = density)

→ 03

3단계 — K-평균이 하려는 일

  1. K는 사람이 정합니다. 같은 데이터도 K = 2, 3, 4에 따라 결과가 다르고, K가 바뀌면 "cluster 1"도 다른 집단입니다(번호를 같은 집단으로 해석하면 안 됨). → 04
  2. 모든 점은 정확히 한 군집에만 들어갑니다. 100개를 K = 3으로 나누면 30 + 40 + 30 = 100처럼 빠짐없이, 그리고 한 점이 C₁과 C₂에 동시에 들어가는 것은 불가능합니다(합집합 = 전체, 교집합 = 공집합). → 05
  3. 목표는 군집 내 변동(WCV)의 합을 최소로 만드는 것입니다. K = 3이면 WCV(C₁) + WCV(C₂) + WCV(C₃)를 줄입니다. WCV는 "같은 군집 안 점들이 서로 얼마나 다른가"이고, 거리의 제곱으로 잽니다. → 06, 07

4단계 — K-평균 알고리즘 (실제로 푸는 방법)

  1. 각 점에 1~K 번호를 무작위로 붙입니다.
  2. 군집마다 점들의 평균(mean)을 구해 중심(centroid)으로 삼습니다. → 그래서 이름이 K-means입니다.
  3. 각 점을 가장 가까운 중심의 군집으로 다시 배정합니다.
  4. 배정이 더 이상 바뀌지 않을 때까지 2–3을 반복합니다.

약점: 처음 중심을 어떻게 잡느냐에 따라 결과가 달라집니다. 이를 개선한 K-means++는 1번(초기화)만 똑똑하게 바꿉니다 — 첫 중심은 무작위, 다음 중심은 이미 고른 중심에서 멀리 있는 점일수록 잘 뽑히게. 나머지는 그대로입니다. → 08, 09

5단계 — K-평균의 한계

K-평균은 거리 기준으로는 잘 나누지만, 군집을 "중심 주변의 비슷한 크기의 둥근 덩어리"로 가정해서 ① 크기가 다른 군집 ② 밀도가 다른 군집 ③ 휘어진 모양을 잘 못 나누고 ④ K를 정하기 어렵습니다. → 10

7단계 — 계층적 군집화

K를 미리 정하지 않습니다. 점 하나하나를 군집으로 시작해서 가장 가까운 두 군집을 계속 합치면 덴드로그램(나무 그림)이 생깁니다. 이 그림을 어디서 끊느냐에 따라 클러스터 개수가 바뀝니다. 군집 사이 거리를 재는 방법(연결 방식)은 외울 것 없이 이런 것들이 있다는 정도로 봅니다. → 13–15

8단계 — DBSCAN 맛보기 (다음 주에 이어서)

핵심 단어는 Density(밀도)와 Noise(잡음)입니다. K-평균은 모든 점을 어떤 군집에든 반드시 넣었지만, DBSCAN은 빽빽한 영역에서 떨어져 나온 점을 억지로 넣지 않고 노이즈로 처리합니다. 그래서 K를 정할 필요가 없고 휘어진 모양도 찾을 수 있습니다. → 16

정리 — 이것만은 외우기
  • 비지도 학습 = x만 있고 y(라벨) 없음 → 군집화로 비슷한 것끼리 묶음
  • K-평균·계층적 = 거리 기반, DBSCAN = 밀도 기반
  • K-평균: K 지정 → (평균으로 중심 이동 ↔ 가까운 중심에 재배정) 반복, 목표는 WCV 합 최소
  • K-means++ = 초기화(1단계)만 개선
  • K 고르기: 엘보(이너셔 꺾이는 점), 실루엣(b ↑ a ↓, 점수 최대)
  • 계층적: 덴드로그램을 어디서 끊느냐 = 클러스터 개수
  • DBSCAN: Density + Noise, 떨어진 점은 노이즈

02군집화란교안 3쪽

Clustering

군집화(clustering)는 데이터 안에서 부분 집단, 즉 군집(cluster)을 찾는 여러 기법을 통틀어 부르는 말입니다.

Clustering refers to a broad set of techniques for finding subgroups, or clusters, in a data set.

목표는 데이터를 서로 겹치지 않는 몇 개의 집단으로 나누되(분할, partition), 같은 집단 안의 관측치끼리는 서로 매우 비슷하게 만드는 것입니다.

We seek a partition of the data into distinct groups so that the observations within each group are quite similar to each other.
교수님 말씀

데이터의 패턴(pattern)과 구조(structure)를 보고 부분 집단으로 나누는 것이 군집화입니다.

"비슷하다"를 먼저 정해야 한다

군집화를 하려면 두 관측치가 비슷하다/다르다는 것이 무슨 뜻인지 먼저 정의해야 합니다. 그리고 이 정의는 보통 분야(도메인) 지식에 따라 정해야 합니다.

We must define what it means for two or more observations to be similar or different. Indeed, this is often a domain-specific consideration that must be made based on knowledge of the data being studied.

예: 고객 데이터에서 "구매 금액"이 비슷한 고객을 묶을지, "구매 시간대"가 비슷한 고객을 묶을지는 데이터만 봐서는 정할 수 없고, 무엇을 하려는지(마케팅 대상 고르기 등)에 따라 정해집니다. 실제 계산에서는 "비슷함"을 보통 거리로 나타냅니다(07).

정리
  • 군집화 = 라벨 없이 데이터를 비슷한 것끼리 몇 개의 집단으로 나누는 기법
  • 같은 군집 안은 서로 비슷하게, "비슷함"의 정의(거리)를 먼저 정해야 함

Details of K-means Clustering

C₁, …, CK를 각 군집에 속한 관측치 번호(인덱스)들의 집합이라고 합시다. 예를 들어 i번째 관측치가 k번째 군집에 있으면 i ∈ Ck로 씁니다.

Let C₁, …, C_K denote sets containing the indices of the observations in each cluster.

이 집합들은 두 가지 성질을 만족합니다(1학기 이산수학의 집합 연산입니다).

성질식뜻
① 빠짐없이C₁ ∪ C₂ ∪ ⋯ ∪ CK = {1, …, n}모든 관측치는 K개 군집 중 적어도 하나에 속한다each observation belongs to at least one of the K clusters.
② 겹치지 않게Ck ∩ Ck′ = ∅ (k ≠ k′)어떤 관측치도 두 군집 이상에 동시에 속하지 않는다the clusters are non-overlapping: no observation belongs to more than one cluster.

두 성질을 합치면 모든 점이 정확히 하나의 군집에만 속한다는 뜻입니다. 이산수학 용어로 C₁, …, CK는 {1, …, n}의 분할(partition)입니다.

교수님 말씀 — 100개, K = 3 예

데이터 100개, K = 3이라고 해 봅시다. cluster 1에 30개, cluster 2에 40개, cluster 3에 30개가 있으면 총합은 100개입니다(성질 ①: 빠짐없이).

어떤 데이터든 C₁, C₂, C₃ 중 하나에는 무조건 들어가야 합니다. 하지만 "C₁일 수도 있고 C₂일 수도 있다"처럼 두 군집에 동시에 속하는 것은 불가능합니다(성질 ②: 겹치지 않게).

06K-평균의 정의 ② — 군집 내 변동을 최소로교안 7–8쪽

Details of K-means Clustering / How to Define Within-Cluster Variation?

K-평균의 생각은 간단합니다. 좋은 군집화란 군집 내 변동(within-cluster variation)이 가능한 한 작은 것입니다.

The idea behind K-means clustering is that a good clustering is one for which the within-cluster variation is as small as possible.

군집 Ck의 군집 내 변동 WCV(Ck)는 같은 군집 안의 관측치들이 서로 얼마나 다른지를 나타내는 값입니다. 그래서 K-평균은 다음 문제를 풉니다.

minC₁, …, CK { ∑k=1K WCV(Ck) }
교수님 말씀 — K = 3이면

K가 3이면 WCV(C₁) + WCV(C₂) + WCV(C₃)를 줄여 가야 합니다.

읽는 법: 점들을 K개 군집으로 나누는 모든 방법 중에서, 군집마다의 변동을 다 더한 값이 가장 작은 나누기를 고릅니다.

WCV를 구체적으로 — 유클리드 거리

보통 유클리드 거리를 써서 다음처럼 정의합니다.

WCV(Ck) = 1|Ck| ∑i, i′ ∈ Ck ∑j=1p (xij − xi′j)²
  1. (xij − xi′j)²: 관측치 i와 i′의 j번째 특징 값 차이의 제곱
  2. ∑j=1p: p개 특징(차원) 전부에 대해 더함 → 두 점 사이 유클리드 거리의 제곱
  3. ∑i, i′ ∈ Ck: 군집 안의 모든 점 쌍에 대해 더함
  4. 1/|Ck|: |Ck|는 k번째 군집의 관측치 수. 군집 크기로 나눔

합치면 K-평균의 최적화 문제는 다음과 같습니다.

minC₁, …, CK { ∑k=1K 1|Ck| ∑i, i′ ∈ Ck ∑j=1p (xij − xi′j)² }
보충 — 이 값은 "중심까지 거리 제곱합"의 2배

군집 중심(평균) x̄k를 쓰면 WCV(Ck) = 2 ∑i ∈ Ck ∑j (xij − x̄kj)²가 성립합니다. 예: 1차원 군집 {1, 3}이면 순서쌍 (1, 3), (3, 1)의 거리 제곱이 각각 4라 합이 8, |C| = 2로 나누면 4. 중심 2까지 거리 제곱합은 1 + 1 = 2이고, 2배하면 4로 같습니다. 그래서 "점들끼리 서로 가까운 군집"과 "점들이 중심에 가까운 군집"은 같은 말이고, 이 사실 때문에 다음 섹션의 알고리즘이 중심(평균)을 쓰게 됩니다. 또 교안은 "Euclidean distance"라고 했지만 실제로 더하는 것은 거리의 제곱입니다.

정리
  • K-평균 = 군집 내 변동(WCV)의 합을 최소화하는 분할을 찾는 문제
  • WCV = 군집 안 모든 점 쌍의 거리 제곱 합 ÷ 군집 크기 (= 중심까지 거리 제곱합 × 2)

K-Means Clustering Algorithm

06의 최적화 문제는 가능한 분할 방법이 너무 많아서(n개 점을 K개로 나누는 방법은 거의 Kⁿ가지) 전부 따져 볼 수 없습니다. 그래서 다음 반복 알고리즘으로 좋은 답(국소 최적)을 찾습니다.

  1. 무작위 배정: 각 관측치에 1부터 K까지 번호를 무작위로 붙입니다. 이것이 초기 군집 배정입니다.Randomly assign a number, from 1 to K, to each of the observations. These serve as initial cluster assignments for the observations.
  2. 배정이 더 이상 바뀌지 않을 때까지 반복합니다.Iterate until the cluster assignments stop changing:
    • 2.1 중심 계산: K개 군집 각각의 중심(centroid)을 구합니다. k번째 중심은 그 군집 관측치들의 p개 특징별 평균으로 이루어진 벡터입니다.The kth cluster centroid is the vector of the p feature means for the observations in the kth cluster.
    • 2.2 재배정: 각 관측치를 가장 가까운 중심의 군집에 배정합니다(가깝다 = 유클리드 거리).Assign each observation to the cluster whose centroid is closest (where closest is defined using Euclidean distance).
교수님 말씀 — K-평균이라는 이름과 초기 중심
  • 각 점을 centroid(중심)와 가까운 것끼리 나눌 수 있습니다.
  • 이때 centroid를 그 군집 점들의 평균으로 옮기는데, 그래서 이름이 K-means(K-평균)입니다.
  • centroid를 처음에 어떻게 잡느냐에 따라 결과가 달라집니다.
  • 이것을 개선한 것이 K-means++입니다. 1번 단계(초기화)만 스마트하게 바꾸고 나머지는 그대로입니다(09).

그림 읽기 (K = 3 네 단계): 교안 11쪽 인포그래픽은 1단계에서 무작위 번호 배정 대신 중심 K개를 먼저 고르는 방식으로 시작합니다(다음 섹션의 K-평균++도 중심을 먼저 고르는 방식). 2단계에서 각 점을 가장 가까운 중심에 배정하고, 3단계에서 중심을 그 군집의 평균 위치로 옮기면(빨간 화살표), 4단계에서 점 7이 Cluster 2보다 새 Cluster 3 중심에 더 가까워져 군집이 바뀝니다. 이 2–3단계를 배정이 바뀌지 않을 때까지 반복합니다.

보충 — 왜 반복하면 멈추나

2.1(중심을 평균으로 옮김)은 군집 배정이 고정됐을 때 "중심까지 거리 제곱합"을 가장 작게 만드는 위치이고, 2.2(가장 가까운 중심으로 재배정)도 그 합을 줄이거나 그대로 둡니다. 즉 매 단계 목적함수(06의 값)가 절대 커지지 않으므로 언젠가 배정이 바뀌지 않는 상태에서 멈춥니다. 다만 멈춘 곳이 전체에서 가장 좋은 답(전역 최적)이라는 보장은 없고 국소 최적일 수 있습니다. 그래서 초기 배정을 바꿔 여러 번 돌리고 가장 좋은 결과를 쓰거나, 다음 섹션의 K-평균++로 시작점을 잘 고릅니다.

  • 배정이 안 바뀌면 종료, 결과는 초기 중심에 따라 달라짐(국소 최적)

09K-평균++교안 12쪽

K-Means++

무작위 초기화의 문제: 시작점이 나쁘면 나쁜 국소 최솟값으로 수렴합니다. 예를 들어 처음 고른 중심 두 개가 같은 무리 안에 있으면, 그 무리는 쪼개지고 다른 두 무리는 합쳐진 채로 멈출 수 있습니다.

Problem with random initialization: Poor starting points ⇒ convergence to poor local minima.

K-평균++의 아이디어: 초기 중심을 더 똑똑하게 고릅니다. 교수님 말씀대로 08의 1번 단계(초기화)만 바꾸고 나머지(2.1–2.2 반복)는 그대로입니다.

  1. 첫 번째 중심은 데이터 점 중에서 균등하게 무작위로 하나 고릅니다.Choose the first centroid uniformly at random from the data points.
  2. 다음 중심부터는, 각 데이터 점을 이미 고른 가장 가까운 중심까지 거리의 제곱에 비례하는 확률로 뽑습니다. → 이미 고른 중심에서 멀리 있는 점일수록 뽑힐 확률이 크고, 가까운 점은 작습니다.select a data point with probability proportional to its squared distance from the nearest chosen centroid.
  3. K개의 중심을 고를 때까지 반복합니다. 그다음은 08의 반복(2.1–2.2)과 같습니다.
예 (보충)

1차원 점 0, 1, 10, 11에서 첫 중심으로 0을 뽑았다고 합시다. 나머지 점의 "가장 가까운 중심까지 거리 제곱"은 1, 100, 121이므로, 두 번째 중심으로 뽑힐 확률은 1/222, 100/222, 121/222입니다. 멀리 있는 10이나 11이 뽑힐 확률이 99% 이상이라 두 중심이 서로 다른 무리에 자리 잡습니다.

장점
초기 중심이 고르게 퍼진다Provides better spread-out initial centroids.
대체로 더 빨리 수렴한다Often leads to faster convergence.
나쁜 국소 최솟값에 빠질 가능성을 줄인다Reduces the chance of poor local minima.

scikit-learn의 KMeans는 기본값으로 K-평균++ 초기화를 씁니다. 이 페이지의 K-평균 그림도 모두 이 방식으로 계산했습니다.

정리

Finding the Optimal Number of Clusters 1: Inertia

이너셔(inertia)는 모든 군집의 군집 내 변동을 더한 값, 즉 각 점에서 자기 군집 중심까지 거리 제곱의 총합입니다.

Inertia = ∑k=1K WCV(Ck) = ∑k=1K ∑i ∈ Ck ∑j=1p (xij − x̄kj)²

x̄kj는 k번째 군집 중심의 j번째 특징 값입니다.x̄_kj: the j-th feature value of the centroid of cluster k

06의 WCV 정의(점 쌍의 합 ÷ |Ck|)를 그대로 쓰면 두 번째 등호는 정확히 2배 차이가 납니다(06 보충). 보통 "이너셔"는 오른쪽(중심까지 거리 제곱합, scikit-learn의 inertia_)을 말하고, 어느 쪽이든 가장 작게 만드는 군집 분할은 같습니다.

엘보 방법

이너셔는 k를 고르는 데 그대로 쓰면 좋은 기준이 아닙니다. k를 늘리면 항상 계속 작아지기 때문입니다(k = n이면 점 하나가 군집 하나라 0).

The inertia is not a good performance metric when trying to choose k since it keeps getting lower as we increase k.

그래서 그래프에서 이너셔가 급하게 줄다가 갑자기 완만해지는 꺾이는 점(팔꿈치, elbow)을 찾습니다. 그 지점까지는 k를 하나 늘릴 때마다 큰 이득이 있지만, 그 뒤로는 늘려도 이득이 작기 때문입니다. 위 그래프에서는 k = 4입니다. 다만 실제 덩어리는 5개였으므로(10의 ④), 엘보는 대략적인 방법이라는 점도 알 수 있습니다.

정리
  • 이너셔 = 각 점에서 자기 중심까지 거리 제곱의 총합
  • k가 커지면 항상 줄어듦 → 값 자체로는 k 선택 불가
  • 엘보: 감소가 갑자기 완만해지는 k를 고름 (그림에서는 4)

12최적의 군집 수 찾기 ② — 실루엣 점수교안 18–19쪽

Finding the Optimal Number of Clusters 2: Silhouette Score

k를 고르는 더 정확한 방법은 실루엣 점수(silhouette score)입니다. 실루엣 점수는 모든 샘플의 실루엣 계수(silhouette coefficient)를 평균한 값입니다.

A more precise approach for choosing k is to use the silhouette score, which is the mean silhouette coefficient over all instances.

한 샘플의 실루엣 계수는 다음과 같습니다.

s = b − amax(a, b)
기호뜻
a같은 군집의 다른 점들까지 평균 거리 (군집 내 거리)mean distance to other points in the same cluster (intra-cluster distance)
b가장 가까운 다른 군집의 점들까지 평균 거리mean distance to points in the nearest other cluster
s 값뜻
s ≈ +1자기 군집 안쪽 깊숙이 있고 다른 군집과 멀다 (a ≪ b)well inside its own cluster, far from others.
s ≈ 0군집 경계 근처 (a ≈ b)close to a cluster boundary.
s ≈ −1잘못 배정됐을 가능성, 다른 군집에 더 가깝다 (a ≫ b)possibly misclassified, closer to another cluster.
교수님 말씀 — 좋은 군집이 되려면

b는 커지고 a는 작아져야 합니다. 같은 군집 안은 가깝고(a ↓), 다른 군집과는 멀수록(b ↑) s가 +1에 가까워지기 때문입니다.

식 읽는 법: b − a는 "다른 군집이 자기 군집보다 얼마나 더 먼가"이고, max(a, b)로 나눠 −1~+1 사이로 맞춥니다.

계산 예 (보충, Python으로 확인)

군집 1 = {(0,0), (0,1), (1,0)}, 군집 2 = {(5,5), (5,6), (6,5)}. 점 (0,0)의 a = (1 + 1)/2 = 1, b = (7.07 + 7.81 + 7.81)/3 ≈ 7.56 → s = (7.56 − 1)/7.56 ≈ 0.87. 여섯 점의 s는 0.83~0.87이고 평균(실루엣 점수)은 0.84로 +1에 가깝습니다. 반대로 (5,5)를 일부러 군집 1에 넣으면 그 점의 s ≈ −0.85가 되어 "잘못 배정됐다"가 숫자로 드러납니다.

실루엣 다이어그램 읽기: 칼날 하나가 군집 하나입니다. 칼날의 두께(높이)는 군집 크기, 가로 길이는 각 점의 실루엣 계수, 빨간 점선은 평균(실루엣 점수)입니다. 좋은 k에서는 모든 칼날이 점선을 넘고 두께도 비교적 고릅니다. k = 3과 k = 6에는 점선에 못 미치는 칼날(나쁜 군집)이 있고, k = 4와 k = 5는 모두 넘습니다. 점수만 보면 k = 4가 가장 높지만, 다이어그램까지 보면 군집 크기가 고른 k = 5도 좋은 선택입니다(실제 덩어리는 5개).

정리
  • 실루엣 계수 s = (b − a) / max(a, b), −1 ~ +1 — b ↑, a ↓일수록 좋음
  • a = 같은 군집까지 평균 거리, b = 가장 가까운 다른 군집까지 평균 거리
  • 실루엣 점수(평균)가 높은 k를 고르고, 다이어그램으로 군집별 품질도 확인

Hierarchical Clustering / Idea of Hierarchical Clustering / Hierarchical Clustering Algorithm

K-평균은 군집 수 K를 미리 정해야 하는데, 이것이 단점이 될 수 있습니다(10의 ④). 계층적 군집화는 특정 K를 정하지 않아도 되는 다른 방법입니다.

Hierarchical clustering is an alternative approach which does not require that we commit to a particular choice of K.

교안은 가장 흔한 상향식(bottom-up) = 병합형(agglomerative) 군집화를 다룹니다. 덴드로그램을 잎(leaf, 아래)에서 시작해 군집을 합쳐 가며 줄기(trunk, 위)까지 쌓아 올리기 때문에 붙은 이름입니다.

알고리즘

  1. 각 점을 자기 혼자만의 군집으로 시작합니다.Start with each point in its own cluster.
  2. 가장 가까운 두 군집을 찾아 하나로 합칩니다.Identify the closest two clusters and merge them.
  3. 반복합니다.Repeat.
  4. 모든 점이 하나의 군집이 되면 끝납니다.Ends when all points are in a single cluster.

덴드로그램 읽기: 가로축은 잎(관측치), 세로축은 두 군집을 합칠 때의 거리(높이)입니다. 두 가지가 낮은 곳에서 합쳐질수록 그 둘은 비슷합니다. A–C처럼 아래에서 합쳐진 쌍이 가장 비슷하고, 맨 위의 검은 파선이 마지막 병합입니다. n개 점이면 병합이 n − 1번 일어납니다(그림은 5개 점, 4번 병합).

2단계의 "가장 가까운 두 군집"에서 군집과 군집 사이 거리를 어떻게 잴지는 15의 연결 방식(linkage)이 정합니다. 위 그림은 complete linkage로 계산했습니다.

정리
  • 계층적 군집화 = K를 미리 정하지 않음, 상향식(병합형)이 가장 흔함
  • 각 점 = 한 군집 → 가장 가까운 두 군집 병합 반복 → 하나가 되면 끝
  • 덴드로그램 높이 = 병합 거리 (낮을수록 비슷)

Types of Linkage
교수님 말씀 — 외울 것 없음

점과 점 사이 거리는 정했지만, 계층적 군집화는 군집과 군집 사이 거리 D(c₁, c₂)가 필요합니다. 그 정의 방법이 연결(linkage)입니다.

26예상 문제

이번 수업에서 배운 범위(교안 1–25쪽)에서 냈고, 외울 것 없다고 하신 연결 방식과 다음 주 내용(DBSCAN 정의)은 뺐습니다. 문제는 예상이며 실제 출제와 다를 수 있습니다.

Q1비지도 학습에 대한 설명으로 옳은 것은?객관식
  1. 입력 x와 정답 y가 모두 주어진다.
  2. 입력 x만 있고 정답 y(라벨)는 없다.
  3. 정답 y만 있고 입력 x는 없다.
  4. 로지스틱 회귀가 대표적인 비지도 학습이다.
정답 ②비지도 학습은 라벨 없이 x만으로 데이터의 패턴과 구조를 찾는다. ①은 지도 학습, ④ 로지스틱 회귀는 지도 학습(분류)이다.
Q2데이터 100개를 K = 3으로 군집화했더니 C₁ 30개, C₂ 40개, C₃ 30개가 되었다. K-평균 군집 C₁, C₂, C₃가 반드시 만족하는 두 성질을 쓰고, "어떤 점은 C₁이기도 하고 C₂이기도 하다"가 왜 불가능한지 설명하시오.서술형
모범답안① C₁ ∪ C₂ ∪ C₃ = {1, …, 100}: 모든 점은 적어도 한 군집에 속한다(30 + 40 + 30 = 100). ② k ≠ k′이면 Cₖ ∩ Cₖ′ = ∅: 군집끼리 겹치지 않는다. ②에 따라 한 점이 두 군집에 동시에 속할 수 없으므로 불가능하다.
Q3두 점 A = (1, 2), B = (4, 6) 사이의 유클리드 거리와 맨해튼 거리를 구하시오.계산
풀이가로 차이 3, 세로 차이 4. 유클리드 = √(3² + 4²) = 5, 맨해튼 = 3 + 4 = 7.
Q4K-평균 알고리즘의 단계를 쓰고, 이름에 "평균(means)"이 들어가는 이유와 K-means++가 무엇을 개선했는지 설명하시오.서술형
모범답안① 각 관측치에 1~K 번호를 무작위로 배정한다. ② 배정이 바뀌지 않을 때까지 반복한다: (2.1) 각 군집 점들의 특징별 평균으로 중심(centroid)을 구하고, (2.2) 각 점을 유클리드 거리로 가장 가까운 중심의 군집에 다시 배정한다. 중심을 군집의 평균으로 옮기기 때문에 K-means라 한다. 결과가 초기 중심에 따라 달라지는 문제가 있어, K-means++는 1단계(초기화)만 바꿔 첫 중심은 무작위로, 다음 중심은 이미 고른 중심에서 멀수록(거리 제곱에 비례) 잘 뽑히게 고른다. 나머지 단계는 같다.
Q5어떤 점의 a(같은 군집 점들까지 평균 거리) = 2, b(가장 가까운 다른 군집까지 평균 거리) = 8이다. 실루엣 계수를 구하고 의미를 쓰시오. 또 a = 6, b = 3인 점은 어떤가?계산
풀이s = (8 − 2)/max(2, 8) = 6/8 = 0.75 → +1에 가까워 자기 군집 안쪽에 잘 들어가 있다. a = 6, b = 3이면 s = (3 − 6)/6 = −0.5 → 다른 군집에 더 가까워 잘못 배정됐을 가능성이 있다. 좋은 군집이 되려면 b는 크고 a는 작아야 한다.
Q6군집 수(K)를 정하는 방법으로 엘보 방법, 실루엣 점수, 계층적 군집화의 덴드로그램을 각각 설명하시오. 이너셔 값 자체가 가장 작은 K를 고르면 안 되는 이유도 쓰시오.서술형
모범답안엘보: K에 따른 이너셔(각 점에서 중심까지 거리 제곱의 합) 그래프에서 감소가 급격히 완만해지는 꺾이는 지점의 K를 고른다. 실루엣: 모든 점의 실루엣 계수 평균이 가장 높은 K를 고른다. 덴드로그램: K를 미리 정하지 않고 병합 그림을 만든 뒤, 원하는 높이에서 끊어 그 아래 가지 수를 군집 수로 한다(어디서 끊느냐에 따라 군집 수가 바뀜). 이너셔는 K가 커질수록 항상 줄어들어 K = n이면 0이 되므로, 값이 가장 작은 K를 고르면 항상 가장 큰 K가 선택된다.
