핵심 1

왜 합성곱인가: 완전연결 계층은 이미지를 1차원으로 평탄화해서 받으므로 공간 구조를 무시합니다(국소 근접성 · 채널 간 상관 · 공간적 국소성을 잃음). 합성곱 계층은 이미지를 3차원으로 받고 3차원으로 넘겨 공간 구조를 보존합니다. CNN = Conv → ReLU → (Pooling) 반복 + 끝의 Affine → Softmax.

핵심 2

합성곱과 풀링의 계산: 한 칸 = 윈도와 필터를 같은 자리끼리 곱해 모두 더함(+ 편향). 출력 크기 OH = H + 2P − FHS + 1. 3차원은 채널마다 계산해 더해서 1장, 출력 채널 수 = 필터 개수 FN. 풀링은 최댓값(또는 평균)으로 높이·너비를 줄이고 매개변수 0 · 채널 수 그대로.

핵심 3

CNN이 보는 것과 대표 CNN: 앞층은 에지·블롭, 깊을수록 물체 수준의 추상적인 특징. LeNet(1998, tanh · 평균 풀링) → AlexNet(2012, ReLU · 드롭아웃 · 증강 · GPU 2대) → VGGNet(2014, 3 × 3 필터만 깊게) → ResNet(2016, 잔차 블록 · 스킵 연결로 성능 저하 해결).

미리 짚고 갈 개념 ② — 텐서와 모양 (C, H, W) · (N, C, H, W)

텐서(tensor): 숫자를 여러 방향으로 늘어놓은 배열 보충 정의. 방향의 개수를 차원이라고 합니다.

차원예모양
1차원MNIST 이미지 한 장을 편 것(784)
2차원흑백 이미지 (세로 H, 가로 W)(H, W)
3차원컬러 이미지: 채널 3장(C, H, W)
4차원이미지 N장 묶음(배치)(N, C, H, W)

C = 채널(channel) 수, H = 높이(height), W = 너비(width), N = 배치 크기.

순서에 주의: 교안 7쪽은 컬러 이미지를 H × W × 3(채널이 마지막)으로 쓰고, 20쪽부터는 (C, H, W)(채널이 처음)로 씁니다. 20쪽에 "(channels, height, width) 형식을 쓰겠다"고 밝혀 두었습니다. 계산 문제에서는 20쪽 형식 (C, H, W)를 기준으로 읽으면 됩니다 (추측).

예: MNIST 100장 묶음 = (100, 1, 28, 28). 흑백이라 C = 1입니다. 컬러 224×224 이미지 한 장 = (3, 224, 224). 원소 수는 모양의 숫자를 모두 곱한 것: 3 × 224 × 224 = 150,528개. Python 검산.

미리 짚고 갈 개념 ③ — 원소별 곱의 합 · 평탄화

원소별 곱의 합 보충 용어: 모양이 같은 두 배열에서 같은 자리끼리 곱한 뒤, 그 곱을 모두 더한 값 하나. 합성곱의 한 칸이 바로 이것입니다(→ 06).

1203 와 2011 → 1×2 + 2×0 + 0×1 + 3×1 = 2 + 0 + 0 + 3 = 5

행렬 곱(P1의 xW)과 다릅니다. 행렬 곱은 "행 × 열"로 곱하고 결과도 행렬이지만, 원소별 곱의 합은 같은 자리끼리 곱하고 결과는 숫자 하나입니다.

평탄화(flatten): 2차원·3차원 배열을 1차원 한 줄로 펴는 것. 행을 차례로 이어 붙입니다 보충 설명.

123456 → (1, 2, 3, 4, 5, 6)

왼쪽 배열에서 2와 5는 위아래로 붙어 있지만, 편 줄에서는 세 칸 떨어집니다. 줄만 보고는 어느 값이 어느 값의 위·아래였는지 알 수 없습니다 — 이것이 05의 "공간 정보를 잃는다"입니다. P2의 MNIST 784가 바로 28×28을 이렇게 편 것입니다.

Part 1 — 이미지와 CNN의 큰 그림 (교안 1–10쪽)

1단계 — 과제와 어려움

컴퓨터 비전의 대표 과제는 분류(무엇이) · 검출(무엇이 + 어디에, 바운딩 박스) · 분할(픽셀마다 클래스) · 캡셔닝(이미지 → 문장) · 텍스트로 이미지 생성입니다. 같은 고양이라도 시점·조명·배경·가려짐·변형·클래스 내 다양성·맥락에 따라 숫자가 완전히 달라져 인식이 어렵습니다. → 01–02

2단계 — 이미지 표현과 CNN 구조

흑백은 0(검정)~255(흰색)의 2차원 배열, 컬러는 R·G·B 3채널의 3차원 텐서입니다. 지금까지의 신경망(완전연결 = Affine)에 합성곱 계층과 풀링 계층을 더한 것이 CNN입니다. 완전연결 계층은 입력을 평탄화해야 해서 공간 구조를 무시합니다. → 03–05

Part 2 — 합성곱과 풀링 (교안 11–24쪽)

3단계 — 2차원 합성곱

필터의 윈도를 입력 위로 옮기며 같은 자리끼리 곱해 모두 더합니다. 교안 예 4 × 4 ⊛ 3 × 3 → [[15, 16], [6, 15]]. 필터는 학습되는 가중치이고 편향은 필터마다 하나를 모든 칸에 더합니다. 패딩은 출력을 키우거나 유지하고, 스트라이드는 줄입니다. → 06–10

4단계 — 출력 크기, 3차원, 블록, 풀링

출력 크기 OH = H + 2P − FHS + 1. 3차원 합성곱은 채널마다 계산해 같은 위치끼리 더해 1장. 블록으로는 (C, H, W) ⊛ (FN, C, FH, FW) → (FN, OH, OW). 풀링은 영역의 최댓값(또는 평균)으로 높이·너비를 줄입니다. → 11–14

Part 3 — CNN이 보는 것 (교안 25–27쪽)

5단계 — 층마다 다른 특징

학습한 1층 필터는 에지·블롭 모양이고, 층이 깊어질수록 low-level(에지) → mid-level(텍스처·부분) → high-level(물체)로 복잡하고 추상적인 특징을 뽑습니다. 사람의 시각 체계도 V1 → V2·V4 → IT로 계층적으로 처리합니다. → 15–16

Part 4 — 대표 CNN (교안 28–39쪽)

6단계 — 대회와 네 모델

ImageNet(1,500만 장 · 2만 2,000 클래스)과 ILSVRC에서 2012년 AlexNet이 Top-5 error를 25.8% → 16.4%로 낮췄습니다. LeNet은 합성곱 + 풀링 구조의 시작, AlexNet은 ReLU · 드롭아웃 · 증강, VGGNet은 3 × 3 필터를 깊게, ResNet은 잔차 블록으로 깊어질수록 성능이 떨어지는 문제를 풀었습니다. → 17–21

자주 헷갈리는 것
  • 검출 vs 분할: 검출 = 바운딩 박스(사각형), 분할 = 픽셀마다 클래스 라벨.
  • 0과 255: 0이 검정, 255가 흰색.
  • H × W × 3 vs (C, H, W): 7쪽은 채널이 마지막, 20쪽부터는 채널이 처음. 계산은 (C, H, W) 기준.
  • 원소별 곱의 합 ≠ 행렬 곱: 합성곱 한 칸은 같은 자리끼리 곱해 더한 숫자 하나.
  • 출력 크기: 패딩은 2P(양쪽), 끝의 + 1, S는 분자 전체를 나눔.
  • 출력 채널 수: 입력 채널 수가 아니라 필터 개수 FN. 3채널 입력도 필터 1개면 출력 1장.
  • FN: 필터의 개수(21쪽 "size of the filter (FN)" 표현에 주의). 높이는 FH.
  • 풀링: 채널 수를 그대로 둠(합성곱은 채널을 더함). 매개변수 0.
  • ResNet의 성능 저하: 과적합이 아님. 56층이 훈련 오류까지 더 높음.

Output Size Formula of Convolution

교안 17쪽은 09 패딩, 10 스트라이드를 한 식으로 묶습니다. 주어진 것(Given):

기호뜻
(H, W)입력 크기 — 높이 H, 너비 W Input size
(FH, FW)필터 크기 — 필터 높이, 필터 너비 Filter size
P패딩 — 입력 둘레에 0을 채운 폭(→ 09) Padding
S스트라이드 — 필터를 옮기는 간격(→ 10) Stride
(OH, OW)출력 특징 맵 크기 output feature map size
OH = H + 2P − FHS + 1     OW = W + 2P − FWS + 1

식을 읽는 법 — 한 방향(세로)만

식의 부분뜻
H + 2P패딩까지 넣은 입력의 높이(위아래에 P칸씩)
− FH필터가 첫 자리에서 움직일 수 있는 거리(칸)
(…) 전체를 S로 나눔: …SS칸씩 옮기므로, 옮기는 횟수

교안은 예 두 개(입력 (4, 4)·패딩 1·스트라이드 1·필터 (3, 3), 입력 (7, 7)·패딩 0·스트라이드 2·필터 (3, 3))만 적고 답은 적지 않았습니다. 답을 한 단계씩 구합니다.

따라가기 ① 입력 (4, 4) · P = 1 · S = 1 · 필터 (3, 3)

단계계산뜻
①H + 2P = 4 + 2 × 1 = 6패딩을 넣은 높이
②6 − FH = 6 − 3 = 3움직일 수 있는 거리
③3S = 31 = 3옮기는 횟수
④3 + 1 = 4놓이는 자리 수
OH = 4 + 2 × 1 − 31 + 1 = 4

너비도 같은 값이라 OW = 4 → 출력 (4, 4). 교안 15쪽 패딩 그림의 출력 4×4와 같습니다(→ 09). 패딩 1 덕분에 입력 크기 (4, 4)가 그대로 유지됩니다.

따라가기 ② 입력 (7, 7) · P = 0 · S = 2 · 필터 (3, 3)

단계계산뜻
①H + 2P = 7 + 2 × 0 = 7패딩 없음
②7 − FH = 7 − 3 = 4움직일 수 있는 거리
③4S = 42 = 22칸씩 옮기는 횟수
④2 + 1 = 3놓이는 자리 수
OH = 7 + 2 × 0 − 32 + 1 = 3

OW도 3 → 출력 (3, 3). 교안 16쪽 스트라이드 2 그림의 출력 3×3 격자와 같습니다(→ 10). 전체를 계산하면 [[15, 17, 15], [17, 15, 17], [15, 17, 15]]이고, 그림에 적힌 15, 17과 맞습니다(Python 검산). 스트라이드가 커지면 놓이는 자리가 줄어 출력이 작아집니다.

Thinking in Blocks
교안 문장뜻
For multidimensional array representation of 3-dimensional data, we will use the format (channels, height, width).3차원 데이터는 (채널, 높이, 너비) = (C, H, W) 순서의 다차원 배열로 씁니다.

필터 1개 (20쪽)

입력 = 큰 직육면체, 필터 = 작은 직육면체(깊이 C가 같음), 출력 = 두께 없는 판. 필터가 1개면 출력은 채널 1장이고, OH·OW는 11의 공식으로 구합니다. 7쪽 컬러 이미지는 H × W × 3(채널이 마지막)으로 적혀 있었습니다(→ 03). 여기서부터는 채널이 맨 앞입니다. 같은 데이터를 적는 순서만 다릅니다.

필터 FN개 → 출력 FN채널 (21쪽)

(C, H, W) ⊛ (FN, C, FH, FW) → (FN, OH, OW)
  • 필터 1개 → 출력 1장(12). 필터 FN개 → 출력 FN장. 필터 묶음은 4차원 (FN, C, FH, FW).

편향까지 넣은 처리 흐름 (22쪽)

(C, H, W) ⊛ (FN, C, FH, FW) → (FN, OH, OW) + (FN, 1, 1) → (FN, OH, OW)
  • 편향은 필터 하나에 값 하나 → 모두 FN개, 모양 (FN, 1, 1)의 가는 막대.
  • 각 채널의 OH × OW 모든 칸에 같은 값을 더합니다. 모양이 달라도 더할 수 있는 것은 넘파이의 브로드캐스트 덕분입니다(→ P1 23).
  • 교안 14쪽 예(→ 08): 합성곱 [[15, 16], [6, 15]] + 편향 3 → [[18, 19], [9, 18]]. 출력 모양은 편향을 더해도 (FN, OH, OW) 그대로입니다.
필터 2개일 때 — FN = 2, 편향 (2, 1, 1) = (3, −1)
출력 채널합성곱 결과 (2 × 2)+ 편향출력
1 (교안 11·14쪽 예)[[15, 16], [6, 15]]+ 3 (네 칸 모두)[[18, 19], [9, 18]]

배치 처리와 모양 따라가기 배치 N은 책 기준

신경망은 데이터를 N개씩 묶어 한 번에 처리합니다(미니배치, → P2 04). 모든 데이터에 맨 앞 차원 N이 붙어 4차원이 됩니다.

(N, C, H, W) ⊛ (FN, C, FH, FW) → (N, FN, OH, OW) + (FN, 1, 1) → (N, FN, OH, OW)

필터와 편향은 N이 붙지 않습니다. 배치 안의 모든 데이터가 같은 필터·편향을 함께 씁니다.

예: MNIST 100장(1채널 28×28), 5×5 필터 30개, P = 0, S = 1, 이어서 2×2 최대 풀링(S = 2)

  • 완전연결 계층은 입력을 1줄로 펴서(평탄화) 받으므로 공간 정보(위아래·좌우로 이웃한 픽셀 관계)를 쓰지 않습니다(→ 05).
  • 합성곱 계층은 작은 필터 하나를 이미지 전체에 다시 씁니다. 그래서 매개변수가 훨씬 적고, 어느 위치의 같은 무늬에도 같은 필터가 반응합니다.
주의
  • 이 비교는 교안에 없는 (보충) 계산입니다. 시험에 나온다면 "매개변수 수 = FN × C × FH × FW + FN" 꼴일 가능성이 높다고 봅니다 (추측).
  • FN은 필터의 개수(= 출력 채널 수). 필터 높이는 FH입니다.
정리

  • 출력 채널 수 = 필터 개수 FN. 매개변수 수 = FN × C × FH × FW + FN, 입력 크기와 무관

깊을수록 좋을까? — 성능 저하 문제 (38쪽)

While deeper networks usually improve performance, traditional architectures eventually suffer from performance degradation as depth increases, which ResNet effectively overcomes.

깊은 신경망은 보통 성능이 좋아지지만, 기존 구조는 깊이가 늘어나면 결국 성능 저하(degradation)를 겪습니다. ResNet은 이 문제를 효과적으로 극복했습니다.

Residual Block · Skip connections let the network reuse earlier information, helping deeper models learn without losing important signals.

스킵 연결(skip connection)은 신경망이 앞의 정보를 다시 쓰게 해서, 깊은 모델이 중요한 신호를 잃지 않고 학습하도록 돕습니다.
