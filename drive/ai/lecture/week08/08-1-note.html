앙상블 학습 (Ensemble Learning)

위에서부터 한 번 읽고, 외우기 모드를 켜서 가려진 정의·답을 말해 본 뒤 눌러 확인하세요. 항목 옆 슬라이드는 자세한 설명으로, 교안 p.는 교안 PDF 해당 쪽으로 갑니다.

01한눈에 요약

  1. 앙상블 학습은 여러 개의 개별 모델을 결합해 일반화 성능이 더 좋은 하나의 모델을 만드는 방법입니다. 대표 방법: 투표 · 배깅 · 부스팅 · 스태킹.
  2. 투표: 서로 다른 알고리즘을 같은 데이터로 학습. 하드 = 다수결, 소프트 = 클래스 확률 평균 중 최대. 70% 독립 분류기 5개 다수결 = 0.8369 — 분류기들이 독립일 때만 성립합니다.
  3. 배깅(복원 추출)·페이스팅(비복원 추출): 같은 알고리즘, 무작위로 뽑은 서로 다른 부분 집합. 편향은 비슷하고 분산은 낮아집니다(σ2 → σ2K).
  4. 랜덤 포레스트 = 결정 트리 배깅 + 노드마다 무작위로 고른 특징 일부 중 최선으로 분할 → 트리 다양성 ↑, 편향 약간 ↑, 분산 ↓. 특징 중요도: 불순도 감소 평균 / OOB 순열 vi = d̄isi.
  5. 부스팅 = 약한 학습기를 순서대로 학습해 앞 예측기의 잘못을 고침. AdaBoost: rj → αj = η log1 − rjrj → 틀린 샘플 × exp(αj) → 정규화 → 최종은 α 가중 다수결.
  6. 그래디언트 부스팅: 샘플 가중치 대신 잔차에 새 예측기를 학습해 예측에 더함. XGBoost = 규제·병렬·가지치기·결측값 처리를 더한 그래디언트 부스팅.
  7. 스태킹: 예측을 합치는 일 자체를 블렌더(메타 학습기)로 학습. 첫 층이 보지 않은 Subset 2의 예측으로 블렌더를 학습합니다.
  8. 시험에 나올 것: 하드/소프트 투표 구분·계산, 다수결 정확도(이항 확률)와 독립 조건, 배깅/페이스팅/OOB, 랜덤 포레스트의 추가 무작위성, AdaBoost r·α·가중치 갱신·가중 다수결 계산, 잔차 학습, 네 방법 비교표.

03반드시 외울 정의 시험 직결

앙상블 학습Ensemble learning
여러 개의 개별 모델을 결합해 일반화 성능이 개선된 최적의 모델을 만드는 방법입니다. 일반화 = 학습에 쓰지 않은 새 데이터에서도 잘 맞히는 것.
예측기Predictor
앙상블을 이루는 개별 모델입니다(분류에서는 분류기).
하드 투표Hard voting
각 분류기의 예측을 모아 가장 많은 표를 받은 클래스를 예측합니다(다수결). 앙상블 안의 가장 좋은 분류기보다 정확도가 높은 경우가 많습니다.
소프트 투표Soft voting
각 분류기의 클래스별 예측 확률을 평균하고, 평균 확률이 가장 높은 클래스를 최종 예측으로 고릅니다. 확률 출력을 쓰므로 하드 투표보다 더 정교합니다.
약한 학습기Weak learner
무작위 추측보다 조금 나은 정도의 모델입니다 보충.
강한 학습기Strong learner
정확도가 높은 모델입니다 보충. 약한 학습기가 충분히 많고 충분히 다양하면 앙상블은 강한 학습기가 될 수 있습니다.
배깅Bagging
모든 예측기에 같은 학습 알고리즘을 쓰고, 학습 세트에서 복원 추출(with replacement, 부트스트랩)로 뽑은 서로 다른 부분 집합으로 각각 학습시키는 방법입니다. Bootstrap AGGregatING 보충.
페이스팅Pasting
배깅과 같되 비복원 추출(without replacement)로 부분 집합을 뽑습니다.
배깅의 효과
원래 학습 세트로 학습한 예측기 하나와 비교해 앙상블은 편향은 비슷하고 분산은 더 낮습니다.
랜덤 포레스트Random forest
결정 트리의 앙상블로, 보통 배깅(가끔 페이스팅)으로 학습합니다. 노드를 나눌 때 모든 특징 중 최선을 찾지 않고 무작위로 고른 특징 일부 중에서 최선을 찾습니다 → 트리 다양성 ↑, 편향을 조금 내주고 분산을 낮춥니다.
특징 중요도 (불순도 기반)
그 특징을 쓴 트리 노드들이 불순도를 평균적으로 얼마나 줄였는지를 숲의 모든 트리에 걸쳐 본 값입니다.
OOB 샘플Out-of-Bag samples
부트스트랩 추출에서 뽑히지 않은 학습 샘플입니다. n이 크면 예측기마다 약 36.8%(1e) 보충. 그 트리가 보지 않았으므로 검증 데이터처럼 씁니다.
OOB 순열 중요도
OOB 데이터에서 그 특징 값을 무작위로 섞었을 때 예측 오차가 일관되게 늘면 중요한 특징입니다.
부스팅Boosting
약한 학습기 여러 개를 결합해 강한 학습기를 만드는 앙상블 방법을 통틀어 부르는 이름입니다. 대부분 예측기를 순서대로(sequentially) 학습시키고, 각 예측기는 바로 앞 예측기(predecessor)의 잘못을 고치려 합니다.
AdaBoostAdaptive Boosting
앞 예측기가 잘 맞히지 못한(과소적합된) 학습 샘플에 더 주의를 기울입니다 — 잘못 분류한 샘플의 가중치를 높여 다음 분류기를 학습하므로 새 예측기일수록 어려운 샘플에 집중합니다.
가중 오차율Weighted error rate rj
j번째 예측기가 틀린 샘플들의 가중치 합 ÷ 전체 가중치 합입니다.
예측기 가중치 αj
αj = η log1 − rjrj. 예측기가 정확하면 αj가 크고, 무작위 추측보다 나쁘면 αj < 0입니다. 최종 가중 다수결에서의 발언권입니다.
그래디언트 부스팅Gradient boosting
AdaBoost처럼 예측기를 순서대로 추가하지만, 샘플 가중치를 조정하는 대신 새 예측기를 앞 예측기가 남긴 잔차(residual errors)에 맞춰 학습합니다. 회귀·분류·순위에 쓸 수 있습니다.
잔차Residual
정답 − 지금까지의 예측(y − F)입니다. MSE 손실에서는 손실의 음의 기울기와 같습니다 보충.
XGBoostExtreme Gradient Boosting
트리를 순서대로 만들어 앞의 오류를 고치는 그래디언트 부스팅으로, 고급 최적화와 규제로 과대적합을 줄이고 성능을 높인 알고리즘입니다.
스태킹Stacking
다수결·평균 같은 단순한 함수 대신, 앙상블 예측기들의 예측을 합치는 일 자체를 모델로 학습합니다. 그 모델 = 블렌더(blender, 메타 학습기).
귀납적 편향Inductive bias
학습 알고리즘이 가진 가정입니다(예: 트리는 축에 평행한 경계) 보충. 배깅은 모든 모델이 같은 기본 알고리즘이라 같은 귀납적 편향을 공유합니다.

04공식과 절차 시험 직결

다수결 정확도 (이항 확률)

P(다수결 정답) = Σk > n2 nCk pk(1 − p)n−kn: 분류기 수(홀수) · p: 각 분류기의 정확도 · k: 맞힌 분류기 수 · 분류기들이 서로 독립일 때만 성립
  • n = 5, p = 0.7: 0.75 + 5(0.74)(0.3) + 10(0.73)(0.32) = 0.16807 + 0.36015 + 0.30870 = 0.8369. 계수 5 = 5C4, 10 = 5C3.
  • n이 커지면: 3개 0.784 · 11개 0.922 · 21개 0.974 · 101개 0.99999(교안 "0.99"는 "0.99 이상"의 뜻).
  • 조건: 교안 4쪽 경고 — 모든 분류기가 완전히 독립이어서 서로 상관없는 오류를 낼 때만 참. 실제로는 같은 데이터로 학습하므로 성립하지 않습니다.
  • p < 0.5이면 반대로 다수결 정확도가 0에 가까워집니다(101개, p = 0.45 → 0.156) 보충. 그래서 약한 학습기는 "무작위 추측보다 나아야" 합니다.

배깅이 분산을 줄이는 이유

E[x1 + x2 + ⋯ + xKK] = μ     Var(x1 + x2 + ⋯ + xKK) = Kσ2K2 = σ2Kx ∼ N(μ, σ2) · 측정 1번: E[x1] = μ, Var(x1) = σ2 · K: 측정 횟수 = 예측기 수 · 교안은 k와 K를 섞어 썼지만 같은 값
  • 기댓값(편향)은 그대로 μ, 분산은 1K배 → 배깅은 분산이 더 작은 모델을 만듭니다.
  • 근거: Var(aX) = a2Var(X)로 1K2, x들이 독립이면 합의 분산 = Kσ2. 교안 7쪽에는 독립 조건이 적혀 있지 않습니다.
  • 상관계수 ρ가 있으면 ρσ2 + 1 − ρKσ2 → K를 늘려도 ρσ2 아래로 안 줄어듭니다 보충. 랜덤 포레스트가 특징을 무작위로 골라 ρ를 낮추는 이유입니다.

OOB 순열 변수 중요도

  1. 원래 데이터로 OOB 오차를 구합니다 (e).
  2. 특징 xi의 값만 무작위로 섞은(permuted) 데이터로 OOB 오차를 구합니다 (pi).
  3. 모든 트리에서 (pi − e)의 평균과 표준편차로 중요도를 계산합니다.
di(t) = pi(t) − e(t)    d̄i = 1TΣt=1T di(t)    si2 = 1T − 1Σt=1T(di(t) − d̄i)2    vi = d̄isit: 트리 번호 · T: 트리 수 · e(t): 원래 OOB 오차 · pi(t): 특징 i를 섞은 뒤 OOB 오차 · d̄i: 오차 증가량 평균 · si: 표준편차(분모 T − 1)
  • 평균 증가가 크고 트리마다 고르게 늘수록(s 작음) vi가 큼 — "일관되게(consistently)"가 s로 나누는 이유입니다.
  • 예 보충: d = (0.05, 0.07, 0.04, 0.06) → d̄ = 0.055, s ≈ 0.0129, v ≈ 4.26.

AdaBoost 학습 절차

w(i) = 1m     rj = Σi=1m w(i) 𝟏(ŷj(i) ≠ y(i))Σi=1m w(i)     αj = η log1 − rjrjm: 학습 샘플 수 · ŷj(i): j번째 예측기가 i번째 샘플에 낸 예측 · 𝟏(조건): 참이면 1, 거짓이면 0 · η: 학습률 · log의 밑은 교안에 없음 → 자연로그(ln)로 계산
w(i) ← w(i) (ŷj(i) = y(i), 맞힘)  ·  w(i) ← w(i) · exp(αj) (ŷj(i) ≠ y(i), 틀림) → Σi=1m w(i) = 1로 정규화맞힌 샘플은 그대로, 틀린 샘플만 exp(αj)배 · 정규화하면 맞힌 샘플의 비중은 줄어듦
  1. 모든 샘플 가중치를 1m로 둡니다.
  2. 현재 가중치로 예측기를 학습하고 가중 오차율 rj를 구합니다.
  3. αj = η log1 − rjrj를 구합니다.
  4. 틀린 샘플만 × exp(αj) 한 뒤, 합이 1이 되게 정규화합니다.
  5. 원하는 예측기 수에 도달하거나 완벽한 예측기를 찾을 때까지 반복합니다.
  • α 값 (η = 1, ln): r = 0.1 → 2.197 · 0.2 → 1.386 · 0.3 → 0.847 · 0.5 → 0 · 0.6 → −0.405 · 0.9 → −2.197.
  • η = 1이면 정규화 후 직전 예측기의 가중 오차율이 정확히 0.5가 됩니다(틀린 쪽 합 = 맞힌 쪽 합) 보충.

AdaBoost 최종 예측 — 가중 다수결

ŷ(x) = arg maxk Σj=1, ŷj(x)=kN αjN: 예측기 총수 · k: 클래스 번호 · 클래스마다 그 클래스로 예측한 예측기들의 α를 더해 가장 큰 클래스
  • 하드 투표의 "한 표 = 1"을 "한 표 = αj"로 바꾼 것입니다. 표 수가 적어도 정확한 예측기 하나가 이길 수 있습니다.

그래디언트 부스팅

Fm = Fm−1 + Δm     (Δm = 잔차 y − Fm−1에 학습한 새 트리의 예측)Fm: m단계까지의 누적 예측 · f0(F0): 첫 예측 · 앙상블 예측 = 트리 예측의 합
  1. 첫 예측 F0을 둡니다(교안 21쪽 그림은 h1이 y를 바로 학습).
  2. 잔차 y − Fm−1을 구합니다.
  3. 새 트리를 잔차에 학습합니다(x는 그대로, 목표만 잔차로 바뀜).
  4. Fm = Fm−1 + 새 트리의 예측. 반복하면 잔차는 0 근처로 줄어듭니다.
  • 예 보충: y = (1, 2, 6, 7), F0 = 4 → 잔차 (−3, −2, 2, 3) → h1 = (−2.5, −2.5, 2.5, 2.5) → F1 = (1.5, 1.5, 6.5, 6.5), MSE 6.5 → 0.25.
  • 이름의 이유 보충: L = 12(y − F)2이면 −∂L∂F = y − F = 잔차 → 경사 하강법으로 오류를 최소화(교안 24쪽 "employs gradient descent algorithm").

스태킹 학습 절차

  1. 학습 세트를 Subset 1과 Subset 2(홀드아웃)로 나눕니다.
  2. 첫 층 학습: Subset 1로 예측기들을 학습합니다.
  3. 첫 층 예측기로 Subset 2를 예측 → 샘플마다 예측값 여러 개.
  4. 블렌딩 학습 세트: 입력 = 첫 층 예측값들, 정답 = Subset 2의 실제 y.
  5. 블렌더 학습: 이 세트로 "예측값들 → 최종 예측"을 학습합니다.

예측할 때: 새 샘플 → 첫 층 예측 3.1, 2.7, 2.9 → 블렌더 → 3.0(단순 평균 2.9가 아님 = 학습한 결합).

06그림으로 기억 자주 나옴

  • 왼쪽(트리 하나): 축에 평행한 경계가 점 하나하나를 따라가 작은 섬이 많음 = 과대적합, 분산 큼. 오른쪽(배깅): 경계가 매끄러움 = 분산 작음, 새 데이터에 더 잘 일반화됩니다.
  • 학습기 #1이 틀린 점이 다음 데이터에서 크게(가중치 ↑) 그려지고, 학습기 #2는 그 점을 맞히는 쪽으로 경계를 긋습니다. 결합하면 12개 모두 맞힙니다.
  • 숫자로 보충: r1 = 112, α1 = ln 11 ≈ 2.398, 정규화 후 틀린 점 가중치 0.5, 나머지 각 122.
  • 왼쪽 열 = 잔차와 그 잔차에 학습한 트리 h1, h2, h3. 오른쪽 열 = 앙상블 예측 h1, h1 + h2, h1 + h2 + h3. 아래로 갈수록 잔차는 0 근처, 예측은 U자 곡선에 가까워집니다.
  • 블렌더의 입력은 원래 특징이 아니라 첫 층 예측값이고, 블렌더는 첫 층이 보지 않은 Subset 2로 학습합니다. 출력 3.0 ≠ 평균 2.9 = 결합 방식을 학습했다는 뜻.

07함정 O/X 시험 직결

  1. 하드 투표는 각 분류기의 클래스 확률을 평균해 가장 큰 클래스를 고른다.X — 확률 평균은 소프트 투표, 하드 투표는 예측 클래스의 다수결입니다.
  2. 투표 분류기는 보통 서로 다른 알고리즘의 분류기를 같은 학습 데이터로 학습한다.O — 배깅은 반대로 같은 알고리즘 + 서로 다른 부분 집합입니다.
  3. 70% 분류기 5개의 다수결 정확도 0.8369는 분류기들이 같은 데이터로 학습해도 그대로 성립한다.X — 완전히 독립(상관없는 오류)일 때만 성립. 같은 데이터로 학습하면 성립하지 않습니다.
  4. 배깅은 비복원 추출, 페이스팅은 복원 추출로 부분 집합을 만든다.X — 반대입니다. 배깅 = 복원(부트스트랩), 페이스팅 = 비복원.
  5. 배깅 앙상블은 단일 예측기에 비해 편향은 비슷하고 분산은 낮다.O — 교안 7쪽 문장 그대로입니다.
  6. 예측기 K개의 평균의 분산이 σ2K가 되려면 예측들이 서로 독립이어야 한다.O — 상관이 있으면 ρσ2 아래로 줄지 않습니다.
  7. 랜덤 포레스트는 노드를 나눌 때 모든 특징 중 최선의 특징을 찾는다.X — 무작위로 고른 특징 일부 중에서 최선을 찾습니다.
  8. 랜덤 포레스트의 추가 무작위성은 편향을 낮추고 분산을 높인다.X — 편향을 조금 높이고(내주고) 분산을 낮춥니다.
  9. OOB 샘플은 부트스트랩 추출에서 뽑히지 않은 학습 샘플이다.O — 그 트리에게는 검증 데이터 역할을 합니다.
  10. OOB 순열 중요도에서 특징을 섞었을 때 오차가 거의 변하지 않으면 그 특징은 중요하다.X — 오차가 일관되게 늘어야 중요한 특징입니다.
  11. 부스팅의 예측기들은 서로 독립이라 병렬로 학습할 수 있다.X — 앞 예측기 결과가 있어야 다음을 학습하는 순차 방식입니다.
  12. AdaBoost는 맞힌 샘플의 가중치를 높여 다음 예측기를 학습한다.X — 잘못 분류한 샘플의 가중치를 높입니다(× exp(αj)).
  13. AdaBoost에서 예측기가 무작위 추측보다 나쁘면(rj > 0.5) αj는 음수이다.O — 1 − rr < 1이라 log가 음수입니다(이진 분류 기준).
  14. AdaBoost의 가중 오차율이 작을수록 예측기 가중치 αj도 작다.X — 정확할수록(r 작을수록) α가 큽니다.
  15. 그래디언트 부스팅은 샘플 가중치를 조정해 다음 예측기를 학습한다.X — 가중치 대신 앞 예측기의 잔차에 새 예측기를 맞춥니다(가중치 조정은 AdaBoost).
  16. 부스팅은 잡음·이상치에 민감하고, 배깅은 편향이 큰 학습기에는 효과가 제한적이다.O — 교안 26쪽 비교표의 한계 칸입니다.

08연습 문제 시험 직결

교안에는 퀴즈가 없습니다. 아래는 덱 원고의 예상 문제와 교안 예제를 바탕으로 만든 문제입니다(계산은 Python으로 검산, log는 자연로그).

1. 다수결 정확도 (계산 + 서술)

정확도가 각각 70%인 분류기 5개가 서로 독립이다. 하드 투표 앙상블의 정확도를 소수 넷째 자리까지 구하고, 이 계산이 실제로는 그대로 성립하지 않는 이유를 쓰시오.

풀이 보기
3개 이상 맞으면 다수결이 맞는다. 5C5(0.7)5 + 5C4(0.7)4(0.3) + 5C3(0.7)3(0.3)2 = 0.16807 + 0.36015 + 0.30870 = 0.8369.
모범 답안: 이 계산은 분류기들이 완전히 독립이어서 서로 상관없는 오류를 낸다고 가정한다. 실제로는 같은 데이터로 학습하므로 같은 샘플을 함께 틀리는 경향이 있어 정확도가 이만큼 오르지 않는다.
2. 분류기 3개의 다수결 보충

정확도 0.8인 독립 분류기 3개로 하드 투표를 한다. 앙상블의 정확도를 구하시오.

풀이 보기
2개 이상 맞으면 된다. 0.83 + 3C2(0.8)2(0.2) = 0.512 + 0.384 = 0.896.
3. 하드 vs 소프트 투표 (계산)

분류기 3개가 새 샘플이 클래스 A일 확률을 각각 0.9, 0.4, 0.4로 예측했다(클래스 A, B 두 개). 하드 투표와 소프트 투표의 결과를 각각 구하고, 결과가 다른 이유를 쓰시오.

풀이 보기
하드: 예측 A, B, B → B(2표). 소프트: P(A) 평균 = 0.9 + 0.4 + 0.43 ≈ 0.567 > P(B) 평균 ≈ 0.433 → A. 하드 투표는 확신 정도와 상관없이 한 표씩 세지만, 소프트 투표는 확률을 쓰므로 첫 분류기의 강한 확신(0.9)이 반영된다.
4. 평균의 분산 보충

각 예측기 예측의 분산이 σ2 = 4이다. 독립인 예측기 8개를 평균한 예측의 분산은? 예측기끼리 상관계수가 ρ = 0.25이면 (ρσ2 + 1 − ρKσ2)?

풀이 보기
독립: σ2K = 48 = 0.5. 상관 있음: 0.25 × 4 + 0.758 × 4 = 1 + 0.375 = 1.375. 상관이 있으면 분산이 덜 줄어든다 → 랜덤 포레스트가 트리 간 상관을 낮추는 이유.
5. 배깅·페이스팅·OOB (서술)

배깅과 페이스팅의 차이를 쓰고, OOB 샘플이 무엇인지와 n이 클 때 예측기마다 약 몇 %가 OOB 샘플이 되는지, 어디에 쓰는지 쓰시오.

풀이 보기
모범 답안: 둘 다 같은 알고리즘의 예측기를 학습 세트에서 무작위로 뽑은 서로 다른 부분 집합으로 학습시키는데, 배깅은 복원 추출(부트스트랩), 페이스팅은 비복원 추출이다. OOB 샘플은 부트스트랩에서 뽑히지 않은 학습 샘플이며, 특정 샘플이 n번 모두 안 뽑힐 확률 (1 − 1n)n → e−1 ≈ 0.368이므로 약 36.8%이다. 그 예측기가 보지 않은 데이터이므로 검증용 오차 측정과 순열 변수 중요도 계산에 쓴다.

랜덤 포레스트가 결정 트리 배깅과 다른 점을 쓰고, 그 차이가 편향과 분산에 주는 영향을 설명하시오.

풀이 보기
모범 답안: 랜덤 포레스트는 배깅에 더해, 노드를 나눌 때 모든 특징 중 최선을 찾지 않고 무작위로 고른 특징 일부 중에서 최선을 찾는다. 그래서 트리들이 더 다양해진다. 각 트리는 편향이 약간 높아지지만 트리끼리 상관이 낮아져 앙상블의 분산이 더 낮아지고, 대체로 전체적으로 더 좋은 모델이 된다.

8. AdaBoost 한 바퀴 (계산)

학습 샘플 10개, η = 1. 첫 예측기가 2개를 틀렸다. r1, α1, 정규화 후 틀린 샘플과 맞힌 샘플의 가중치를 구하시오.

11. 그래디언트 부스팅 (계산 + 서술)

정답 y = (1, 2, 6, 7), 첫 예측 F0 = 4, 첫 트리 h1의 예측 = (−2.5, −2.5, 2.5, 2.5)(학습률 1). h1이 학습한 목표값, F1, 다음 트리의 목표값을 구하고, AdaBoost와 다음 예측기를 학습시키는 방식의 차이를 쓰시오.

풀이 보기
h1의 목표 = 잔차 y − F0 = (−3, −2, 2, 3). F1 = F0 + h1 = (1.5, 1.5, 6.5, 6.5). 다음 목표 = y − F1 = (−0.5, 0.5, −0.5, 0.5).
모범 답안: AdaBoost는 같은 (x, y)에 샘플 가중치만 바꿔(틀린 샘플 가중치 증가) 다음 예측기를 학습하고, 그래디언트 부스팅은 가중치 대신 앞 예측이 남긴 잔차를 새 목표값으로 학습해 예측에 더한다.

스태킹에서 블렌더를 학습시키는 절차를 쓰고, 학습 세트를 두 부분으로 나누는 이유를 쓰시오.

모범 답안: 학습 세트를 Subset 1과 Subset 2로 나누고, Subset 1로 첫 층 예측기들을 학습한다. 첫 층 예측기로 Subset 2를 예측해, 예측값들을 입력으로 하고 Subset 2의 실제 y를 정답으로 하는 블렌딩 학습 세트를 만들어 블렌더를 학습한다. 첫 층이 학습에 쓴 데이터에 대한 예측은 실제보다 정확하게 나오므로, 첫 층이 보지 않은 데이터의 예측으로 블렌더를 학습해야 새 데이터에서도 올바르게 결합한다 보충.
