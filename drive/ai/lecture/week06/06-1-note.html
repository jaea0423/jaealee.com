회귀 (Regression)

위에서부터 한 번 읽고, 외우기 모드를 켜서 가려진 정의·답을 말해 본 뒤 눌러 확인하세요. 항목 옆 슬라이드는 자세한 설명으로, 교안 p.는 교안 PDF 해당 쪽으로 갑니다.

01한눈에 요약 시험 직결

  1. 회귀는 지도 학습입니다. 형식은 x → 모델 → y이고, 가진 것은 데이터(점)뿐이며 선형 회귀를 만든다는 것은 회귀계수 β₀, β₁을 찾는 것입니다.
  2. 분류: 독립변수 1개 = 단순, 2개 이상 = 다중. 맞추는 대상은 선 → 면 → 초평면. variable은 x의 개수, variate는 y의 개수. 수업은 선형만 다룹니다.
  3. 잔차 ei = yi − ŷi를 제곱해서 더한 RSS를 가장 작게 하는 β̂를 고릅니다 = 최소제곱법. 제곱하는 이유는 +와 −가 상쇄되지 않게 하기 위함입니다.
  4. 풀이는 편미분 = 0 → β̂₁ = Σ(x−x̄)(y−ȳ) / Σ(x−x̄)², β̂₀ = ȳ − β̂₁x̄. "직접 푸는 문제는 안 나올 것 같다, 이런 식으로 푼다까지 이해"(교수님).
  5. 평가: R² = 1 − SSE/SST = SSR/SST. 변수를 늘리면 R²는 내려가지 않으므로 다중 회귀에서는 변수 개수 p에 벌점을 주는 Adjusted R²를 씁니다.
  6. 회귀계수는 상관관계로 해석합니다(인과관계로 단정 금지). 다항 회귀는 "차수를 올리면 구불구불해질 수 있다"까지.
  7. y가 0/1이면 선형 회귀는 0 미만·1 초과 확률을 낼 수 있어 부적절 → 로지스틱 회귀: p(X) = 1 / (1 + e−(β₀+β₁X)), 항상 0~1.
  8. 로그 오즈 log(p/(1−p)) = β₀ + β₁X, p(x) = y가 1일 확률, 1 − p(x) = y가 0일 확률. 계수는 최대우도로 추정하고, p̂(X) > 0.5이면 1로 분류합니다.

02교수님이 짚은 포인트 시험 직결

교수님 말씀 · 범위

"이 식을 직접 푸는 문제는 안 나올 것 같다. 그냥 '이런 식으로 푼다'까지는 이해가 필요하다." (최소제곱 해 β̂₁, β̂₀)

교수님 말씀 · 범위

비선형 회귀는 다루지 않습니다(훑어만 보고 넘어감). 수업에서는 linear만. 매체끼리 시너지는 "이런 질문을 던질 수 있다" 정도이고 다루지 않습니다.

교수님 말씀 · 범위

다항 회귀는 "Non-linear할 수도 있구나", "degree 2, degree 5처럼 차수를 올리면 구불구불해질 수 있다" 정도만 알면 됩니다. 이 이상은 심화 과정이라 다루지 않으며, 편하게 들으라고 하셨습니다.

교수님 말씀

단순 선형 회귀에서 직접 식을 풀어서 구하는 것 정도만 해 봅니다. 경사하강법(gradient descent)도 하지만 뒤쪽에서 다룹니다.

교수님 말씀

저 동그라미들(데이터)을 가장 잘 설명할 수 있는 파란색 선을 찾고 싶은 것입니다. 실제로 우리가 알고 있는 것은 동그라미(데이터)뿐입니다.

교수님 말씀

기본 형식은 x → system(model) → y입니다. 변수 표기법은 순서대로 스칼라·벡터·확률변수·행렬이며, 무조건 지켜지지는 않지만 알고 있으면 좋습니다.

교수님 말씀

인공지능 ⊃ 기계학습 ⊃ 딥러닝 ⊃ 생성형 AI. 회귀에는 선형 회귀와 로지스틱 회귀가 있습니다.

교수님 말씀

단순 회귀의 입력은 x, 다중 회귀의 입력은 x = [x1, x2, …, xN]입니다. 선 → 면 → 초평면(3차원 이상부터)이 됩니다.

교수님 말씀

우리는 variable 위주로 공부할 예정입니다. 단순 선형 회귀는 input 하나, output 하나입니다.

교수님 말씀

Y = β₀ + β₁X + ε는 y = ax + b와 매치해서 생각해도 됩니다. ε는 에러텀입니다. β₀, β₁은 parameter, (learnable) parameter, weight 등 표기법이 다양합니다.

교수님 말씀

선형 회귀를 만들겠다는 것은 결국 β₀과 β₁을 찾겠다는 것입니다. X와 Y를 여러 개 보면서 찾습니다. 햇(^) 심볼은 예측하는 값입니다.

교수님 말씀

잔차를 제곱해서 더하기도 하고, 절댓값으로 더하기도 하고, 루트를 씌우기도 합니다. 공통점은 양수로만 한다는 것입니다. 이유: 오차가 +2인 것도 −2인 것도 있을 수 있는데, 그대로 더하면 오차가 없는 것처럼 계산되어 버리기 때문입니다.

교수님 말씀

줄이고자 하는 함수를 어떻게 정의할지에 따라 목적함수(objective)·손실함수(loss)·비용함수(cost)로 부릅니다(Step 2에 해당). x̄(x바), ȳ(y바)는 평균을 의미합니다.

교수님 말씀

예시 그래프의 회색선은 에러텀을 의미합니다. 회귀는 어디까지나 최적·최선을 찾는 것이라, 지금 데이터에 완벽하게 맞춰도 새로운 데이터가 들어오면 100% 맞지 않을 수 있습니다.

교수님 말씀 · 중요

회귀계수 해석은 상관관계로 해야 합니다. 인과관계라고 단정 지으면 안 됩니다. x → g(x) → y를 배우고 있어서 y가 나오니까 인과관계라고 생각하기 쉽지만, 사실은 x, y의 상관관계로 생각해야 합니다.

교수님 말씀 · 중요

로그 오즈에서 p(x)는 y가 1일 확률, 1 − p(x)는 y가 0일 확률입니다.

03반드시 외울 정의 시험 직결

회귀 분석Regression analysis
입력(예: 광고비)과 출력(예: 판매량)의 관계를 추정하고, 이를 이용해 출력을 예측하는 방법입니다.
선형 회귀 모델Linear Regression Model
출력 변수 Y를 입력 변수 X들의 선형 결합으로 나타내는 모델입니다. 목적은 ① X와 Y의 관계를 수학식으로 설명, ② 반응 변수 Y의 미래 값 예측입니다.
선형 결합Linear combination
여러 변수에 각각 계수를 곱한 뒤 더한 형태입니다.
독립변수 · 종속변수Independent / Dependent variable
독립변수 x = 입력·특징·속성·예측변수(predictor)·위험 요인, 종속변수 y = 출력·타깃·라벨·반응변수(response)·클래스·결과입니다.
단순 회귀 · 다중 회귀Simple / Multiple regression
단순 회귀는 독립변수가 1개, 다중 회귀는 독립변수가 2개 이상인 회귀입니다. 각각 선형·비선형으로 나뉩니다.
다변수 · 다변량Multivariable / Multivariate
Variable은 독립변수(x)의 개수, Variate는 종속변수(y)의 개수를 셉니다. Multivariable = x가 여러 개, Multivariate = y가 여러 개입니다.
절편 · 기울기Intercept / Slope
β₀(절편)은 X = 0일 때 Y의 값, β₁(기울기)은 X가 1 늘 때 Y가 변하는 양입니다. 둘 다 모르는 상수입니다.
회귀계수Coefficients = Parameters
β₀, β₁처럼 데이터로 추정해야 하는 모르는 상수입니다. parameter, learnable parameter, weight(가중치)로도 부릅니다.
오차항Error term, ε
직선으로 설명되지 않는 나머지입니다(에러텀).
햇 기호Hat symbol, ^
추정값(예측값)을 나타냅니다. ŷ는 X = x를 바탕으로 한 Y의 예측값, β̂는 β의 추정값입니다.
잔차Residual
ei = yi − ŷi. 실제 값에서 예측값을 뺀 값입니다.
잔차 제곱합Residual Sum of Squares, RSS
RSS = e12 + e22 + ⋯ + en2. 잔차를 제곱해서 모두 더한 값입니다(= SSE).
최소제곱법Least squares
RSS를 가장 작게 만드는 β̂₀, β̂₁을 찾는 방법입니다.
목적·손실·비용함수Objective / Loss / Cost function
줄이고자 하는 함수의 이름입니다. 선형 회귀에서는 C(β₀, β₁) = Σ{yi − (β₀ + β₁xi)}²입니다.
arg min
최솟값 자체가 아니라, 함수를 최소로 만드는 변수의 값입니다.
결정계수Coefficient of Determination, R²
회귀 모델이 데이터의 변동을 얼마나 잘 설명하는지 나타내는 척도로, y의 전체 분산 중 모델이 설명하는 비율입니다. 0 ≤ R² ≤ 1(모델이 매우 나쁘면 음수도 가능), 1이면 잘 맞고 0이면 못 맞습니다.
수정된 결정계수Adjusted R²
조정 항 (n − 1)/(n − p − 1)로 예측변수 추가에 벌점을 주어, 예측변수를 더 넣을 때 적합도가 과대평가되는 것을 막은 R²입니다.
균형 설계Balanced design
예측변수끼리 상관이 없는 이상적인 경우입니다. 각 계수를 따로 추정·검정할 수 있습니다.
시그모이드 함수Sigmoid function
φ(z) = 1 / (1 + e−z). 어떤 실수든 0~1로 바꾸며, z = 0에서 0.5입니다.
로그 오즈 · 로짓 변환Log odds / Logit transformation
log(p(X) / (1 − p(X))) = β₀ + β₁X로 바꾸는 변환입니다. 오즈 p/(1−p) = y가 1일 확률 ÷ y가 0일 확률입니다.
최대우도 추정Maximum likelihood
우도 ℓ(β₀, β₁) = Πyi=1 p(xi) · Πyi=0 (1 − p(xi))를 최대로 하는 계수를 고르는 방법입니다. 로지스틱 회귀의 계수 추정에 씁니다.

04공식과 절차 시험 직결

단순 선형 회귀

Y = β0 + β1X + ε   →   ŷ = β̂0 + β̂1xβ₀ 절편 · β₁ 기울기 · ε 오차항 · ^ 추정(예측)값

잔차와 RSS

ei = yi − ŷi
RSS = e12 + e22 + ⋯ + en2
= (y1 − β̂0 − β̂1x1)2 + ⋯ + (yn − β̂0 − β̂1xn)2ei: i번째 잔차(실제 − 예측)

최소제곱 추정 알고리즘 3단계

  1. Step 1 오차 제곱합을 식으로 씁니다: Σi=1n {yi − (β0 + β1xi)}2
  2. Step 2 이 값을 최소로 하는 β₀, β₁을 찾는 문제로 정의합니다(목적·손실·비용함수 C): C(β0, β1) = minβ₀, β₁ Σ{yi − (β0 + β1xi)}2,  (β̂0, β̂1) = arg minβ₀, β₁ C(β0, β1)
  3. Step 3 각 계수로 편미분해서 0으로 놓습니다(아래 두 식).
∂C∂β0 = −2Σ(yi − (β0 + β1xi)) = 0
∂C∂β1 = −2Σ(yi − (β0 + β1xi))xi = 0∂: 편미분(다른 계수는 상수로 고정하고 미분)
β̂1 = Σ(xi − x̄)(yi − ȳ)Σ(xi − x̄)2,    β̂0 = ȳ − β̂1x̄
x̄ = 1nΣxi,  ȳ = 1nΣyix̄, ȳ: 평균 · 직접 푸는 문제는 안 나올 것 같다(교수님) — "이런 식으로 푼다"까지 이해

판단 기준: 미분 = 0으로 놓는 이유는 C가 그릇 모양(아래로 볼록)이라 최소점에서 기울기가 0이기 때문입니다 보충. Step 3 첫 식은 "잔차의 합 = 0", β̂₀ = ȳ − β̂₁x̄는 "회귀직선은 평균점 (x̄, ȳ)를 지난다"는 뜻입니다 보충.

결정계수 R²

R2 = 1 − SSESST = SSRSST,    SST = SSR + SSESST = Σ(yi − ȳ)² 전체 변동 · SSR = Σ(ŷi − ȳ)² 모형이 설명하는 변동 · SSE = Σ(yi − ŷi)² 설명 안 되는 변동(= RSS)

다중 선형 회귀

Y = β0 + β1X1 + β2X2 + ⋯ + βpXp + ε
RSS = Σ(yi − β̂0 − β̂1xi1 − ⋯ − β̂pxip)2 최소βj: 다른 예측변수를 모두 고정했을 때 Xj가 1 늘면 Y가 평균적으로 변하는 양 · xij: i번째 데이터의 j번째 변수

Adjusted R²

Adjusted R2 = 1 − SSE / (n − p − 1)SST / (n − 1)n: 표본 크기 · p: 예측변수 개수 · 조정 항 (n − 1)/(n − p − 1)이 예측변수 추가에 벌점

로지스틱 회귀

p(X) = eβ₀ + β₁X1 + eβ₀ + β₁X = 11 + e−(β₀ + β₁X)
⇔  log(p(X)1 − p(X)) = β0 + β1Xp(X) = Pr(Y = 1 | X): y가 1일 확률 · 1 − p(X): y가 0일 확률 · 왼쪽 = 로그 오즈(로짓)
ℓ(β0, β1) = Πi: yi=1 p(xi) Πi: yi=0 (1 − p(xi))Π: 모두 곱함 · 우도를 최대로 하는 β₀, β₁을 고름(최대우도)

분류 규칙

Ŷ = 1 (Yes, Default)  if  p̂(X) > 0.5
Ŷ = 0 (No, Non-default)  if  p̂(X) ≤ 0.5교안 예: β̂₀ = −10.6513, β̂₁ = 0.0055 → balance 1000: p̂ = 0.006 → No Default / balance 2000: p̂ = 0.586 → Default

판단 기준: 로그 오즈 = 0 ⇔ p = 0.5, 로그 오즈 > 0 ⇔ p > 0.5. 따라서 0.5 기준 분류는 "β₀ + β₁X > 0인가"와 같습니다 보충.

교안 5쪽 다항 모델 식은 y = b0 + b1x + b2x12로 적혀 있으나, 독립변수가 x 하나인 단순 다항 모델이므로 b2x2로 읽습니다(첨자 1은 오타로 보임).

06그림으로 기억 자주 나옴

이 그림에서 답할 수 있어야 하는 것: 입력 3개·출력 1개인 모델의 이름(Multivariable). y가 2개 이상이면 Multivariate.

이 그림에서 답할 수 있어야 하는 것: 회색선이 무엇인지(잔차 ei = yi − ŷi), 파란 직선을 고르는 기준(RSS 최소).

이 그림에서 답할 수 있어야 하는 것: 세 거리(y − ȳ, ŷ − ȳ, y − ŷ)가 각각 SST·SSR·SSE에 해당한다는 것, R² = SSR/SST.

이 그림에서 답할 수 있어야 하는 것: 0/1 분류에 선형 회귀가 부적절한 이유(확률이 0 미만·1 초과 가능), 로지스틱 곡선이 S자이며 0~1 사이라는 것.

07함정 O/X 시험 직결

  1. 선형 회귀를 만든다는 것은 데이터로 회귀계수 β₀, β₁을 찾는 것이다.O — 가진 것은 데이터뿐이고 β₀, β₁을 추정합니다.
  2. 광고비 3개로 판매량 1개를 예측하는 회귀는 multivariate 회귀이다.X — x가 여러 개이므로 multivariable(다변수). Multivariate는 y가 여러 개입니다.
  3. 잔차는 예측값에서 실제 값을 뺀 값 ŷi − yi이다.X — 잔차 ei = yi − ŷi(실제 − 예측)입니다.
  4. 잔차를 제곱하는 이유는 +와 − 오차가 서로 상쇄되어 오차가 없는 것처럼 계산되는 것을 막기 위해서이다.O — 절댓값·루트도 쓰며, 공통점은 양수로 만든다는 것입니다.
  5. 최소제곱법은 RSS를 최대로 하는 β̂₀, β̂₁을 찾는다.X — RSS를 최소로 합니다. 최대로 하는 것은 로지스틱 회귀의 우도입니다.
  6. arg min C(β₀, β₁)는 C의 최솟값을 뜻한다.X — 최솟값을 만드는 변수 값(β̂₀, β̂₁)입니다.
  7. β̂₀ = ȳ − β̂₁x̄이고, x̄, ȳ는 평균이다.O — 교안 해(Solution) 그대로입니다.
  8. R² = SSE / SST이다.X — R² = 1 − SSE/SST = SSR/SST입니다.
  9. SST = SSR + SSE이다.O — y의 전체 변동 = 설명된 변동 + 설명되지 않은 변동.
  10. R²는 어떤 경우에도 음수가 될 수 없다.X — 교안: 모델이 매우 나쁘면 음수가 나오기도 합니다(sometimes negative).
  11. 쓸모없는 변수를 추가하면 R²는 내려간다.X — R²는 내려가지 않습니다. 내려갈 수 있는 것은 Adjusted R²입니다.
  12. 다중 회귀에서 βj는 다른 예측변수를 모두 고정했을 때 Xj가 1 늘면 Y가 평균적으로 변하는 양이다.O — 교안 14쪽 해석 그대로입니다.
  13. 회귀계수가 양수이면 x가 y의 원인이라고 해석할 수 있다.X — 상관관계로 해석해야 하며 인과관계로 단정하면 안 됩니다(교수님).
  14. 예측변수끼리 상관이 있으면 모든 계수의 분산이 커지는 경향이 있다.O — 때로는 매우 크게 커지고, 해석이 위험해집니다.
  15. 로지스틱 회귀에서 p(x)는 y가 0일 확률, 1 − p(x)는 y가 1일 확률이다.X — 반대입니다. p(x) = y가 1일 확률, 1 − p(x) = y가 0일 확률(교수님).
  16. 로지스틱 회귀의 계수는 최소제곱법으로 추정한다.X — 최대우도(maximum likelihood)로 추정합니다.
  17. 로지스틱 회귀는 p̂(X) > 0.5이면 Y = 1, p̂(X) ≤ 0.5이면 Y = 0으로 분류한다.O — 0.5와 같을 때는 0(No)입니다.

08연습 문제 자주 나옴

이 차시 교안에는 퀴즈가 없습니다. 아래는 덱의 예상 문제와 교안 예제를 바탕으로 한 문제입니다. 교수님이 "푸는 문제는 안 나올 것 같다"고 하셨으므로 개념·서술을 우선 연습하세요.

문제 1 · 객관식

광고비 TV·Radio·Newspaper 3개로 판매량 1개를 예측하는 회귀는? ① Univariable ② Multivariable ③ Multivariate ④ Univariate이면서 Multivariate

풀이 보기
정답 ②. variable은 입력(x)의 개수, variate는 출력(y)의 개수를 셉니다. 입력 3개, 출력 1개이므로 multivariable(다변수)입니다.
문제 2 · 서술형

RSS를 계산할 때 잔차를 그냥 더하지 않고 제곱해서 더하는 이유를 쓰시오.

풀이 보기
모범 답안 잔차는 +와 −가 모두 나오므로 그대로 더하면 서로 상쇄되어, 오차가 있는데도 합이 0에 가까워져 오차가 없는 것처럼 계산될 수 있습니다. 제곱하면 모든 값이 양수가 되어 상쇄가 사라집니다. 절댓값이나 루트를 쓰기도 하며, 공통점은 양수로 만든다는 것입니다.
문제 3 · 서술형

최소제곱 추정 알고리즘의 3단계를 순서대로 쓰시오.

풀이 보기
모범 답안 ① 오차 제곱합 Σ{yi − (β0 + β1xi)}²을 식으로 씁니다. ② 이 값을 최소로 하는 β₀, β₁을 찾는 문제 C(β₀, β₁)로 정의하고, (β̂₀, β̂₁) = arg min C(β₀, β₁)로 둡니다. ③ C를 β₀, β₁로 각각 편미분해 0으로 놓고 연립해서 풀면 β̂₁ = Σ(xi − x̄)(yi − ȳ) / Σ(xi − x̄)², β̂₀ = ȳ − β̂₁x̄를 얻습니다.
문제 4 · 계산

어떤 회귀 모델에서 SST = 50, SSE = 10이다. R²를 구하고 의미를 쓰시오.

풀이 보기
R² = 1 − SSE/SST = 1 − 10/50 = 0.8. y의 전체 변동 중 80%를 모델이 설명한다는 뜻입니다. (SSR = SST − SSE = 40, SSR/SST = 0.8로도 같습니다.)
문제 5 · 계산 보충

점 4개 (1, 1), (2, 3), (3, 2), (4, 4)에 단순 선형 회귀를 적합한다. β̂₁, β̂₀, 그리고 R²를 구하시오.

풀이 보기
x̄ = 2.5, ȳ = 2.5.
분자 Σ(xi − x̄)(yi − ȳ) = (−1.5)(−1.5) + (−0.5)(0.5) + (0.5)(−0.5) + (1.5)(1.5) = 4, 분모 Σ(xi − x̄)² = 2.25 + 0.25 + 0.25 + 2.25 = 5
→ β̂₁ = 0.8, β̂₀ = 2.5 − 0.8 × 2.5 = 0.5 → ŷ = 0.5 + 0.8x
예측값 1.3, 2.1, 2.9, 3.7 → 잔차 −0.3, 0.9, −0.9, 0.3 (합 0)
SSE = 0.09 + 0.81 + 0.81 + 0.09 = 1.8, SST = 2.25 + 0.25 + 0.25 + 2.25 = 5 → R² = 1 − 1.8/5 = 0.64 (SSR = 3.2, 3.2/5 = 0.64로 확인)
문제 6 · 계산 · 서술형

n = 11, 예측변수 p = 2, SST = 100, SSE = 20인 다중 회귀 모델의 R²와 Adjusted R²를 구하고, 다중 회귀에서 Adjusted R²를 쓰는 이유를 쓰시오.

풀이 보기
R² = 1 − 20/100 = 0.8. Adjusted R² = 1 − (20/8)/(100/10) = 1 − 2.5/10 = 0.75.
모범 답안 R²는 변수를 추가하면 그 변수가 쓸모없어도 내려가지 않으므로 변수가 많은 모델을 과대평가합니다. Adjusted R²는 조정 항 (n − 1)/(n − p − 1)로 예측변수 추가에 벌점을 주어, SSE가 충분히 줄지 않는 변수를 넣으면 값이 떨어지게 하여 적합도의 과대평가를 막습니다.
문제 7 · 서술형

"Can we simply perform a linear regression of Y on X and classify as Yes if Ŷ > 0.5?" (Y를 X에 선형 회귀하고 Ŷ > 0.5이면 Yes로 분류하면 안 되는가?) 교안의 답을 쓰시오.

풀이 보기
모범 답안 E(Y | X = x) = Pr(Y = 1 | X = x)이므로 회귀가 확률을 예측하는 것처럼 보이지만, 선형 회귀는 0보다 작거나 1보다 큰 확률을 낼 수 있습니다. 확률은 0~1 사이여야 하므로 출력이 항상 0~1인 로지스틱 회귀가 더 적절합니다.
문제 8 · 서술형

로지스틱 회귀에서 p(x)와 1 − p(x)는 각각 무엇이며, log(p(x) / (1 − p(x)))는 무엇이라 부르는가? 이 값이 0이면 p(x)는 얼마인가?

풀이 보기
모범 답안 p(x)는 y가 1일 확률, 1 − p(x)는 y가 0일 확률입니다. log(p(x)/(1 − p(x)))는 로그 오즈(로짓 변환)이며 β₀ + β₁X와 같습니다. 이 값이 0이면 오즈 = 1, 즉 p = 1 − p이므로 p(x) = 0.5입니다.
문제 9 · 계산

Default 데이터에서 β̂₀ = −10.6513, β̂₁ = 0.0055이다. balance = 1000, 2000일 때 p̂(X)를 구하고 각각 어떻게 분류하는지 쓰시오.

풀이 보기
balance 1000: 지수 −10.6513 + 5.5 = −5.1513, e−5.1513 ≈ 0.00579 → p̂ ≈ 0.00579/1.00579 ≈ 0.006 ≤ 0.5 → No Default
balance 2000: 지수 −10.6513 + 11 = 0.3487, e0.3487 ≈ 1.417 → p̂ ≈ 1.417/2.417 ≈ 0.586 > 0.5 → Default
문제 10 · 계산 보충

세 사람 A(Yes), B(No), C(Yes)에 대해 어떤 계수로 p(A) = 0.8, p(B) = 0.3, p(C) = 0.9를 얻었다. 우도 ℓ을 구하시오.

풀이 보기
Yes인 사람은 p, No인 사람은 1 − p를 곱합니다. ℓ = 0.8 × (1 − 0.3) × 0.9 = 0.8 × 0.7 × 0.9 = 0.504. 최대우도는 이 값이 가장 커지는 β₀, β₁을 고릅니다.
