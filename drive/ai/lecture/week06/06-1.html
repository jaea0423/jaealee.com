03회귀란 · 회귀의 분류

What is Regression? / Category of Regression

선형 회귀 모델(Linear Regression Model)은 출력 변수 Y를 입력 변수 X들의 선형 결합(linear combination)으로 나타냅니다.

Linear Regression Model represents the output variable Y as a linear combination of the input variables X.

선형 결합은 여러 변수에 각각 계수를 곱한 뒤 더한 형태입니다. 예: 3×TV + 0.5×Radio + 7. 5주차 11장에서 본 벡터의 일차결합과 같은 말입니다.

Linear combination is a form where several variables are multiplied by coefficients and then added together.

선형 회귀의 목적

  1. 변수 X와 Y의 관계를 수학식으로 설명한다 (Explain the relationship between variable X and variable Y in mathematical form.)
  2. 반응 변수 Y의 미래 값을 예측한다 (Predict the future value of the response variable Y.)
교수님 말씀 — 이번 수업의 회귀

회귀에는 선형 회귀와 로지스틱 회귀가 있습니다(로지스틱은 15 섹션부터).

회귀의 분류

독립변수 1개		y = b₀ + b₁x (직선)y = b₀ + b₁x + b₂x² (곡선, 다항 모델)
다중 회귀(Multiple regression)
독립변수 2개 이상		평면 (3차원에서)곡면
Simple regression: regression with a single independent variable / Multiple regression: regression with two or more independent variables
교수님 말씀 — 수업에서는 linear만

비선형 회귀는 다루지 않습니다(훑어만 보고 넘어감). 수업에서는 선형(linear) 회귀만 다룹니다. 위 분류표의 오른쪽 열(곡선·곡면)은 이런 종류가 있다는 정도로만 보면 됩니다.

교수님 말씀 — 입력 x의 모양과 회귀가 맞추는 대상
  • 단순 회귀: 입력이 x 하나 (스칼라)
  • 다중 회귀: 입력이 𝐱 = [x₁, x₂, …, xN] (벡터)
  • 선형 회귀가 맞추는 대상은 선 → 면 → 초평면(3차원 이상부터)으로 커집니다.

표에서 보듯 "3차원 이상부터 초평면"은 독립변수가 3개 이상이라 (x₁, x₂, x₃, y)처럼 공간이 4차원 이상이 되는 경우입니다. 02 섹션 표기법대로 단순 회귀의 x는 스칼라(소문자), 다중 회귀의 𝐱는 벡터(굵은 소문자)입니다.

헷갈리기 쉬운 지점 — 다항 모델은 왜 "선형 회귀"로도 부르나

y = b₀ + b₁x + b₂x²는 x에 대해서는 곡선(비선형)이지만, 계수 b₀, b₁, b₂에 대해서는 선형 결합입니다. x²를 새 변수 x₂로 보면 y = b₀ + b₁x + b₂x₂라는 다중 선형 회귀와 같은 식이 됩니다. 그래서 다항 회귀는 선형 회귀와 같은 방법(최소제곱)으로 계수를 구합니다. 교안 분류표에서는 그래프 모양 기준으로 비선형 쪽에 두었습니다.

정리
  • 선형 회귀 = Y를 X들의 선형 결합(계수 × 변수의 합)으로 표현
  • 목적: X–Y 관계를 식으로 설명 + Y의 미래 값 예측
  • 단순(X 1개) / 다중(X 2개 이상) × 선형 / 비선형

04Multiple (Multivariable) vs. Multivariate

"다중 회귀"를 영어로 multiple regression이라고 하는데, 비슷하게 생긴 multivariate와 자주 혼동됩니다. 교안은 기준을 이렇게 나눕니다.

용어한국어무엇의 개수
Univariate단변량종속변수(y) 1개
Multivariate다변량종속변수(y) 여러 개
Univariable단변수독립변수(x) 1개
Multivariable다변수독립변수(x) 여러 개

정리하면 variate는 출력(y) 쪽, variable은 입력(x) 쪽을 셉니다. 그래서 광고비 3개로 판매량 1개를 예측하는 다중 회귀는 multivariable(다변수)이지 multivariate가 아닙니다. Multivariate 회귀는 판매량과 고객 수처럼 y를 여러 개 동시에 예측하는 경우입니다.

정리
  • Multiple regression = Multivariable (독립변수 여러 개)
  • Multivariate = 종속변수 여러 개 — 둘은 다른 말

05단순 선형 회귀

Simple Linear Regression

독립변수가 하나일 때 다음 모델을 가정합니다.

We assume a model
Y = β₀ + β₁X + ε
기호이름뜻
β₀절편 (intercept)X = 0일 때 Y의 값
β₁기울기 (slope)X가 1 늘 때 Y가 변하는 양
β₀, β₁회귀계수 (coefficients) = 파라미터 (parameters)모르는 상수 — 데이터로 추정해야 함
ε오차항 (error term)직선으로 설명되지 않는 나머지(잡음)
β₀ and β₁ are two unknown constants that represent the intercept and slope, also known as coefficients or parameters, and ε is the error term.

실제 β₀, β₁은 모릅니다. 데이터로 구한 추정값 β̂₀, β̂₁이 있으면 다음 식으로 예측합니다.

ŷ = β̂₀ + β̂₁x
where ŷ indicates a prediction of Y on the basis of X = x. The hat symbol denotes an estimated value.

모자(hat, ^) 기호는 "추정한 값"이라는 표시입니다. β₁은 진짜 기울기(모름), β̂₁은 데이터로 계산한 기울기, y는 실제 값, ŷ는 모델이 예측한 값입니다. 이 구분이 다음 섹션의 "잔차"를 이해하는 열쇠입니다.

정리
  • 모델: Y = β₀ + β₁X + ε (β₀ 절편, β₁ 기울기, ε 오차)
  • 예측: ŷ = β̂₀ + β̂₁x — hat(^) = 추정값

06최소제곱법으로 계수 추정

Estimation of the Parameters by Least Squares

데이터에 가장 잘 맞는 직선, 즉 β̂₀과 β̂₁을 어떻게 고를까요? "가장 잘 맞는다"를 숫자로 정의해야 합니다. 그 정의가 잔차 제곱합입니다.

  • i번째 데이터의 예측값: ŷᵢ = β̂₀ + β̂₁xᵢ
  • 잔차(Residual): eᵢ = yᵢ − ŷᵢ — 실제 값과 예측값의 차이
  • 잔차 제곱합(Residual Sum of Squares, RSS):
RSS = e₁² + e₂² + ⋯ + eₙ²
RSS = (y₁ − β̂₀ − β̂₁x₁)² + (y₂ − β̂₀ − β̂₁x₂)² + ⋯ + (yₙ − β̂₀ − β̂₁xₙ)²

RSS를 가장 작게 만드는 β̂₀, β̂₁을 찾는 것이 최소제곱법(least squares)입니다. 5주차 11장 회귀직선에서 "각 점에서 직선까지 y축 방향 거리의 제곱합이 최소"라고 한 것과 같은 내용이고, 11장 손실 함수 MSE는 RSS를 n으로 나눈 값입니다.

최소제곱 추정 알고리즘

Least Squares Estimation Algorithm
  1. 오차 제곱합을 식으로 쓴다: ∑i=1n { yᵢ − (β₀ + β₁xᵢ) }²
  2. 이 값을 최소로 하는 β₀, β₁을 찾는 문제로 정의한다:
    C(β₀, β₁) = minβ₀, β₁ ∑i=1n { yᵢ − (β₀ + β₁xᵢ) }²    (β̂₀, β̂₁) = arg minβ₀, β₁ C(β₀, β₁)
    arg min은 "최솟값 자체가 아니라, 최솟값을 만드는 변수 값"을 뜻합니다.
  3. 각 계수로 편미분해서 0으로 놓는다:
    ∂C(β₀, β₁)∂β₀ = −2 ∑i=1n (yᵢ − (β₀ + β₁xᵢ)) = 0
    ∂C(β₀, β₁)∂β₁ = −2 ∑i=1n (yᵢ − (β₀ + β₁xᵢ)) xᵢ = 0

3단계가 왜 필요한지: C는 β₀, β₁에 대한 아래로 볼록한 2차 함수라서, 가장 낮은 지점에서는 기울기(미분값)가 0입니다. 그래서 "미분 = 0"인 지점을 풀면 최소점이 나옵니다. 5주차 11.3의 미분과 같은 원리입니다.

편미분(∂) — 교수님이 설명하신 내용 아님

C는 변수가 β₀, β₁ 두 개인 함수입니다. 편미분(partial derivative) ∂C/∂β₀은 β₁을 상수로 고정하고 β₀으로만 미분한 것입니다. 예: C = (y − β₀ − β₁x)²이면 체인 규칙으로 ∂C/∂β₀ = 2(y − β₀ − β₁x)·(−1) = −2(y − β₀ − β₁x)이고, ∂C/∂β₁ = 2(y − β₀ − β₁x)·(−x) = −2(y − β₀ − β₁x)x입니다. 교안 3단계 식의 −2와 xᵢ가 여기서 나옵니다.

해

Least Squares Estimation Algorithm Solution

두 식을 연립해서 풀면:

β̂₁ = ∑i=1n (xᵢ − x̄)(yᵢ − ȳ)∑i=1n (xᵢ − x̄)² ,    β̂₀ = ȳ − β̂₁x̄
x̄ = 1n ∑i=1n xᵢ ,    ȳ = 1n ∑i=1n yᵢ   (평균)
손으로 계산해 보기 (보충 예제)

점 3개 (1, 2), (2, 3), (3, 5)로 계산합니다. x̄ = 2, ȳ = 10/3.
분자 ∑(xᵢ − x̄)(yᵢ − ȳ) = (−1)(−4/3) + 0 + (1)(5/3) = 3, 분모 ∑(xᵢ − x̄)² = 1 + 0 + 1 = 2 → β̂₁ = 3/2 = 1.5
β̂₀ = 10/3 − 1.5 × 2 = 1/3 → ŷ = 0.333 + 1.5x
확인: 예측값 1.833, 3.333, 4.833 → 잔차 0.167, −0.333, 0.167 → 잔차의 합이 0 (3단계 첫 번째 식이 바로 "잔차의 합 = 0"이라는 조건입니다)

β̂₀ = ȳ − β̂₁x̄를 다시 쓰면 ȳ = β̂₀ + β̂₁x̄입니다. 즉 회귀직선은 항상 평균점 (x̄, ȳ)를 지납니다.

정리
  • 잔차 eᵢ = yᵢ − ŷᵢ, RSS = ∑eᵢ²
  • 최소제곱법: RSS를 최소로 하는 β̂₀, β̂₁ — 편미분 = 0으로 풀이
  • β̂₁ = ∑(xᵢ − x̄)(yᵢ − ȳ) / ∑(xᵢ − x̄)², β̂₀ = ȳ − β̂₁x̄ — 직선은 (x̄, ȳ)를 지남

07결정계수 R²

What is Coefficient of Determination, R²?

직선을 구했으면 "이 직선이 데이터를 얼마나 잘 설명하는가"를 숫자로 알고 싶습니다. 그 척도가 결정계수(coefficient of determination) R²입니다.

  • 회귀 모델이 데이터의 변동을 얼마나 잘 설명하는지 나타내는 척도 (A measure of how well the regression model explains the variation in the data.)
  • y의 전체 분산 중 모델이 설명하는 비율 (the proportion of the total variance in y explained by the model)
  • 범위: 0 ≤ R² ≤ 1 (모델이 매우 나쁘면 음수가 나오기도 함). R² = 1이면 잘 맞음, 0이면 못 맞춤
R² = 1 − SSESST = SSRSST

변동의 분해: SST = SSR + SSE

기호English식뜻
SSTTotal Sum of Squares∑i=1n (yᵢ − ȳ)²Y의 전체 변동 — 평균에서 얼마나 흩어져 있나
SSRRegression Sum of Squares∑i=1n (ŷᵢ − ȳ)²모형에 의해 설명되는 변동
SSEError Sum of Squares∑i=1n (yᵢ − ŷᵢ)²모형으로 설명되지 않는 변동 (= 06의 RSS)
The total variation of y can be decomposed into: SST = SSR + SSE

읽는 법: "회귀선을 쓰지 않고 그냥 평균 ȳ로 예측했을 때의 오차"가 SST입니다. 회귀선을 쓰면 그중 SSR만큼이 설명되고, SSE만큼이 여전히 남습니다. 그래서 R² = SSR/SST는 "평균만 쓸 때보다 오차를 몇 % 줄였나"입니다. R² = 0.8이면 Y의 변동 중 80%를 X로 설명한다는 뜻입니다.

06의 예제로 계산: y = (2, 3, 5), ȳ = 10/3. SST = (4/3)² + (1/3)² + (5/3)² = 42/9 ≈ 4.667. SSE = 0.167² + 0.333² + 0.167² ≈ 0.167. R² = 1 − 0.167/4.667 ≈ 0.964.

R²가 음수가 되는 경우 — 교수님이 설명하신 내용 아님

최소제곱으로 구한 직선을 같은 데이터에 쓰면 SSE ≤ SST라서 R²는 0 이상입니다. 그런데 다른 방법으로 만든 모델이나 테스트 데이터에서 R²를 재면, 평균 ȳ로만 예측하는 것보다 오차가 더 클 수 있습니다(SSE > SST). 그러면 1 − SSE/SST가 음수가 됩니다. 교안의 "sometimes negative if the model is very poor"가 이 경우입니다.

정리
  • R² = 1 − SSE/SST = SSR/SST: y 변동 중 모델이 설명하는 비율 (1에 가까울수록 좋음)
  • SST(전체 변동) = SSR(설명된 변동) + SSE(설명 못 한 변동)

08다중 선형 회귀

Multiple Linear Regression

01의 그래프는 매체를 하나씩 따로 봤습니다. 하지만 실제 판매량은 세 매체가 함께 만든 결과입니다. 독립변수를 여러 개 한꺼번에 넣는 모델이 다중 선형 회귀입니다.

Y = β₀ + β₁X₁ + β₂X₂ + ⋯ + βpXp + ε

βⱼ는 다른 예측변수를 모두 고정했을 때, Xⱼ가 1 늘면 Y가 평균적으로 얼마나 변하는지를 뜻합니다.

We interpret βⱼ as the average effect on Y of a one unit increase in Xⱼ, holding all other predictors fixed.

광고 예제에서는:

sales = β₀ + β₁ × TV + β₂ × radio + β₃ × newspaper + ε

추정과 예측

Estimation and Prediction for Multiple Regression

추정값 β̂₀, β̂₁, …, β̂ₚ가 있으면 다음 식으로 예측합니다.

ŷ = β̂₀ + β̂₁x₁ + β̂₂x₂ + ⋯ + β̂pxp

계수는 단순 회귀와 똑같이 잔차 제곱합을 최소로 하는 값으로 정합니다.

RSS = ∑i=1n (yᵢ − ŷᵢ)² = ∑i=1n (yᵢ − β̂₀ − β̂₁xi1 − β̂₂xi2 − ⋯ − β̂pxip)²
The values β̂₀, β̂₁, …, β̂ₚ that minimize RSS are the multiple least squares regression coefficient estimates.

xij는 i번째 데이터의 j번째 변수입니다. 5주차 11.5 행렬의 aᵢⱼ와 같은 순서(행 = 데이터, 열 = 변수)라서, 데이터 전체를 n × p 행렬로 놓고 행렬 계산으로 한 번에 풉니다.

그림 읽기: 독립변수가 2개면 입력 공간이 평면(X₁, X₂)이고 출력 Y가 높이가 되므로, 맞추는 대상이 직선이 아니라 평면입니다. 빨간 점은 실제 데이터, 검은 세로선은 잔차이고, 이 선 길이의 제곱합이 최소가 되는 평면을 찾습니다. 변수가 3개 이상이면 그림으로 그릴 수 없는 초평면(hyperplane)이 됩니다.

정리
  • 다중 선형 회귀: Y = β₀ + β₁X₁ + ⋯ + βₚXₚ + ε
  • βⱼ = 다른 변수를 고정했을 때 Xⱼ 1 증가에 따른 Y의 평균 변화
  • 추정은 같은 최소제곱(RSS 최소) — 2변수면 회귀 평면
필기 원문
(교안 p.15–18 기반 — 실시간 필기 없음)

09수정된 결정계수 Adjusted R²

Adjusted R²

다중 회귀에서 R²를 그대로 쓰면 문제가 있습니다. 변수를 하나 더 넣으면, 쓸모없는 변수라도 R²는 내려가지 않습니다. 최소제곱은 새 변수의 계수를 0으로 두는 선택지도 가지고 있어서 SSE가 커질 수 없기 때문입니다. 그래서 변수를 마구 늘리면 모델이 좋아 보이는 착시가 생기고, 이는 4주차에 본 과적합으로 이어집니다.

Adjusted R² = 1 − SSE / (n − p − 1)SST / (n − 1)
  • R²: 결정계수 / n: 표본 크기 (sample size) / p: 예측변수 개수 (number of predictors)
  • 조정 항 (n − 1)/(n − p − 1)이 예측변수를 추가하는 것에 벌점을 줍니다 (penalizes the addition of predictors)
  • 변수를 더 넣었을 때 적합도가 과대평가되는 것을 막습니다 (Prevents overestimation of model fit when more predictors are added)

식 읽는 법: R²의 SSE/SST를 각각 자유도로 나눈 "평균" 버전으로 바꾼 것입니다. p가 커지면 분모 n − p − 1이 작아져 SSE/(n − p − 1)이 커지므로, 변수를 넣어서 SSE가 그만큼 줄지 않으면 Adjusted R²는 오히려 떨어집니다.

숫자 예: n = 20, SST = 100. 변수 2개로 SSE = 30이면 Adjusted R² = 1 − (30/17)/(100/19) ≈ 0.665. 쓸모없는 변수를 하나 더 넣어 SSE가 29.8이 되면(R²는 0.700 → 0.702로 올라감) Adjusted R² = 1 − (29.8/16)/(100/19) ≈ 0.646으로 내려갑니다.

정리
  • R²는 변수를 추가하면 절대 줄지 않음 → 변수가 많은 모델을 과대평가
  • Adjusted R² = 1 − [SSE/(n−p−1)] / [SST/(n−1)] — 변수 추가에 벌점

10회귀계수 해석

Interpreting Regression Coefficients

08에서 βⱼ를 "다른 변수를 고정했을 때의 효과"라고 했습니다. 이 해석이 언제 가능하고 언제 위험한지를 다룹니다.

이상적인 경우: 예측변수끼리 상관이 없을 때 — 균형 설계 (balanced design)

  • 각 계수를 따로따로 추정하고 검정할 수 있습니다.
  • "Xⱼ가 1 변하면, 다른 변수가 그대로일 때 Y가 βⱼ만큼 변한다"는 해석이 가능합니다.
"a unit change in Xⱼ is associated with a βⱼ change in Y, while all the other variables stay fixed"

문제: 예측변수끼리 상관이 있을 때

  • 모든 계수의 분산이 커집니다. 때로는 매우 크게 커져서, 데이터가 조금만 달라져도 계수가 크게 바뀝니다.
  • 해석이 위험해집니다 — Xⱼ가 변하면 다른 변수도 같이 변하기 때문입니다.
Interpretations become hazardous — when Xⱼ changes, everything else changes.

예를 들어 TV 광고비를 늘리는 회사가 라디오 광고비도 같이 늘리는 경향이 있다면, 데이터에서 TV만 따로 늘어난 경우를 보기 어렵습니다. 그러면 "TV를 1 늘리고 라디오는 고정"이라는 상황 자체가 데이터에 거의 없어서, β_TV를 믿기 어렵습니다. 이렇게 예측변수끼리 강하게 상관된 상태를 다중공선성(multicollinearity)이라고 부릅니다.

인과관계 주장은 피하라

관찰 데이터(observational data)로는 인과관계를 주장하지 말아야 합니다. 회귀계수가 크다는 것은 "함께 움직인다(연관)"는 뜻이지 "X가 Y를 일으킨다(원인)"는 뜻이 아닙니다.

Claims of causality should be avoided for observational data.
정리
  • 예측변수끼리 무상관(균형 설계)이면 βⱼ를 "다른 변수 고정 시 효과"로 해석 가능
  • 상관이 있으면 계수 분산 증가 + 해석 위험
  • 관찰 데이터로 인과관계 주장 금지
필기 원문
(교안 p.20 기반 — 실시간 필기 없음)

관계가 직선이 아니면 어떻게 할까요? 예측변수의 제곱 항 등을 새 변수로 추가합니다. 자동차 연비(mpg)를 마력(horsepower)으로 예측하는 예:

mpg = β₀ + β₁ × horsepower + β₂ × horsepower² + ε
범위 확인 필요

교수님이 "비선형은 수업에서 다루지 않는다"고 하셨는데, 다항 회귀는 x에 대해 곡선(비선형 모양)이면서 계수에 대해서는 선형입니다. 이 섹션(교안 p.21)도 수업에서 다루셨는지, 아니면 비선형으로 보고 건너뛰셨는지 확인이 필요합니다(18 확인 필요).

13선형 회귀로 분류를 할 수 있을까?

Can We Use Linear Regression for Classification?

지금까지는 Y가 숫자(판매량, 연비)였습니다. 이번에는 Y가 예/아니오인 분류 문제입니다. 카드 사용자가 채무불이행(default)을 할지 예측하는 Default 데이터를 씁니다.

Y = { 0 (No 일 때),   1 (Yes 일 때) }

질문: Y를 0/1 숫자로 놓고 X로 선형 회귀를 한 뒤, Ŷ > 0.5이면 Yes로 분류하면 되지 않을까?

Can we simply perform a linear regression of Y on X and classify as Yes if Ŷ > 0.5?

그럴듯해 보이는 이유: Y가 0 또는 1이면 Y의 평균(기대값)이 곧 "Y = 1일 확률"입니다. 즉 E(Y | X = x) = Pr(Y = 1 | X = x)이므로, 평균을 예측하는 회귀가 확률을 예측하는 셈이 됩니다.

Since in the population E(Y | X = x) = Pr(Y = 1 | X = x), we might think that regression is perfect for this task.

문제: 선형 회귀는 직선이라서 0보다 작거나 1보다 큰 "확률"을 낼 수 있습니다. 확률은 반드시 0~1 사이여야 하므로 말이 안 됩니다. 그래서 로지스틱 회귀가 더 적절합니다.

However, linear regression might produce probabilities less than zero or bigger than one. → Logistic Regression is more appropriate.

E(Y | X = x)는 "X = x일 때 Y의 기대값(평균)", Pr(Y = 1 | X = x)는 "X = x일 때 Y = 1일 조건부 확률"로 읽습니다. 5주차 11.6의 기대값과 같은 개념입니다.

정리
  • 분류 문제(Y = 0/1)에 선형 회귀를 쓰면 0 미만·1 초과의 확률이 나올 수 있음 → 로지스틱 회귀 사용

15로지스틱 회귀

Logistic Regression

p(X) = Pr(Y = 1 | X)로 줄여 쓰고, balance로 default를 예측합니다. 로지스틱 회귀는 다음 형태를 씁니다.

p(X) = eβ₀ + β₁X1 + eβ₀ + β₁X = 11 + e−(β₀ + β₁X)

p(X)는 항상 0과 1 사이입니다 (p(X) will have values between 0 and 1). 두 번째 식은 첫 번째 식의 분자·분모를 eβ₀+β₁X로 나눈 것입니다.

구조 읽기: 괄호 안 β₀ + β₁X는 선형 회귀와 똑같은 직선입니다. 그 직선 값을 시그모이드 함수에 넣어서 0~1 사이로 눌러 준 것이 로지스틱 회귀입니다. 5주차 11.2의 시그모이드가 여기서 쓰입니다.

로그 오즈 (logit) 변환

식을 조금 정리하면:

log( p(X)1 − p(X) ) = β₀ + β₁X

이 변환을 p(X)의 로그 오즈(log odds) 또는 로짓(logit) 변환이라 합니다.

  • 오즈(odds) = p / (1 − p): "일어날 확률 ÷ 일어나지 않을 확률". p = 0.8이면 오즈 = 0.8/0.2 = 4 (4배 더 일어나기 쉬움).
  • 확률 p는 0~1이지만 오즈는 0~∞, 로그 오즈는 −∞~+∞입니다. 그래서 범위 제한이 없는 직선 β₀ + β₁X와 같다고 놓을 수 있습니다.
  • 즉 로지스틱 회귀는 "로그 오즈가 X에 대해 선형"이라고 가정한 모델입니다. β₁은 X가 1 늘 때 로그 오즈가 늘어나는 양입니다.
식 변형 과정 — 교수님이 설명하신 내용 아님

z = β₀ + β₁X로 두면 p = eᶻ / (1 + eᶻ). 1 − p = 1 / (1 + eᶻ)이므로 p / (1 − p) = eᶻ. 양변에 자연로그를 취하면 log(p / (1 − p)) = z = β₀ + β₁X. 여기서 log는 자연로그(ln, 밑 e)입니다.

정리
  • p(X) = e^(β₀+β₁X) / (1 + e^(β₀+β₁X)) = 1 / (1 + e^−(β₀+β₁X)) — 직선을 시그모이드에 넣음, 항상 0~1
  • 로그 오즈(logit): log(p/(1−p)) = β₀ + β₁X

16최대우도 추정

Maximum Likelihood

선형 회귀의 계수는 RSS 최소로 구했는데, 로지스틱 회귀의 계수는 최대우도(maximum likelihood)로 구합니다.

ℓ(β₀, β₁) = ∏i: yᵢ = 1 p(xᵢ)   ∏i: yᵢ = 0 (1 − p(xᵢ))

식 읽는 법: ∏는 모두 곱하라는 기호입니다. 실제로 Yes였던 사람(yᵢ = 1)에게는 모델이 준 Yes 확률 p(xᵢ)를, No였던 사람(yᵢ = 0)에게는 No 확률 1 − p(xᵢ)를 곱합니다. 이 곱 ℓ을 우도(likelihood)라 하며, "현재 계수라면 실제로 관찰된 결과가 나올 확률"입니다. 이 값을 최대로 만드는 β₀, β₁을 고릅니다.

예: 두 사람 중 A는 Yes, B는 No였을 때, 모델 1이 p(A) = 0.9, p(B) = 0.2를 주면 ℓ = 0.9 × 0.8 = 0.72이고, 모델 2가 p(A) = 0.6, p(B) = 0.5를 주면 ℓ = 0.6 × 0.5 = 0.30입니다. 실제 결과를 더 잘 설명하는 모델 1의 우도가 더 큽니다.

예제 — 추정된 계수로 확률 계산

Default 데이터에서 추정된 계수는 β̂₀ = −10.6513, β̂₁ = 0.0055입니다.

Balance가 $1000인 사람의 채무불이행 확률은?
p̂(X) = e−10.6513 + 0.0055 × 10001 + e−10.6513 + 0.0055 × 1000 = 0.006

지수: −10.6513 + 5.5 = −5.1513 → e−5.1513 ≈ 0.00579 → 0.00579 / 1.00579 ≈ 0.006 (0.6%)

Balance가 $2000이면?
p̂(X) = e−10.6513 + 0.0055 × 20001 + e−10.6513 + 0.0055 × 2000 = 0.586

지수: −10.6513 + 11 = 0.3487 → e0.3487 ≈ 1.417 → 1.417 / 2.417 ≈ 0.586 (58.6%)

잔액이 1000에서 2000으로 두 배가 됐는데 확률은 0.6% → 58.6%로 약 100배 뛰었습니다. 확률이 직선이 아니라 S자로 변하기 때문입니다. 14의 그래프에서 1500~2000 구간이 급하게 올라가던 부분입니다.

정리
  • 로지스틱 회귀계수는 최대우도로 추정: 관찰된 결과가 나올 확률(우도 ℓ)을 최대화
  • 예: β̂₀ = −10.6513, β̂₁ = 0.0055 → balance 1000: 0.006, 2000: 0.586

Logistic regression is not just about estimating probabilities, but also about making classification decisions.
4주차와 연결

4주차 2차시 지도 학습 알고리즘 표에서 "로지스틱 회귀는 이름과 달리 분류"라고 했던 이유가 이것입니다. 이름에 "회귀"가 붙은 것은 내부에서 확률(연속값)을 회귀로 구하기 때문이고, 최종 출력은 클래스입니다.

p̂(X) = 0.5가 되는 경계는 β̂₀ + β̂₁X = 0, 즉 X = 10.6513 / 0.0055 ≈ 1937입니다. 이 데이터에서는 잔액이 약 1937달러를 넘으면 Default로 예측합니다. 기준 0.5는 바꿀 수 있습니다. 채무불이행을 놓치는 것이 더 위험하면 0.2처럼 낮춥니다.

정리
  • p̂(X) > 0.5 → Yes(1), ≤ 0.5 → No(0)
  • 로지스틱 회귀 = 확률 추정 + 분류 결정
