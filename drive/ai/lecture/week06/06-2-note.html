서포트 벡터 머신 (SVM)

위에서부터 한 번 읽고, 외우기 모드를 켜서 가려진 정의·답을 말해 본 뒤 눌러 확인하세요. 항목 옆 슬라이드는 자세한 설명으로, 교안 p.는 교안 PDF 해당 쪽으로 갑니다.

01한눈에 요약

  1. SVM은 지도 학습 분류 모델이며, 클래스 사이의 마진을 최대로 하는 초평면을 결정 경계로 찾습니다.
  2. 초평면은 p차원 공간을 두 반쪽 공간으로 나누는 (p − 1)차원 평평한 부분공간이고, f(x) = β0 + β1x1 + ⋯ + βpxp의 부호로 분류합니다.
  3. 마진 = 초평면과 가장 가까운 학습 점까지의 거리, 서포트 벡터 = 초평면까지 거리가 마진과 같은 점입니다. 서포트 벡터만 경계를 결정합니다.
  4. 하드 마진: 레이블 −1/+1, 제약 y·f(x) ≥ M, ∑βj2 = 1(단위벡터). 선형 분리 가능할 때만 해가 있고, 점 하나에 민감해 과적합할 수 있습니다.
  5. SVM은 거리로 판단하므로 특징 스케일링이 필요하고, 스케일링 통계값은 학습 데이터에서만 계산합니다.
  6. 소프트 마진: 슬랙 변수 εi로 위반 허용 (0 / 0~1 / 1 초과).
  7. ★ 시험 직결: 벌점 매개변수 C — 작은 C = 넓은 마진·과소적합·고편향·저분산 / 큰 C = 좁은 마진·과적합·저편향·고분산 (교안 19쪽).
  8. 힌지 손실(21–23쪽)·커널(28–30쪽)은 심화, 특징 공간 확장(24–27쪽)은 그림으로 이해, 31–32쪽은 시험 범위 아님, SVR(33쪽)은 잘 안 씀.

02교수님이 짚은 포인트 시험 직결

교수님 말씀 — ★ 시험에 잘 나옴

"벌점 매개변수 C는 시험에 잘 나온다"는 식으로 언급하셨습니다. C 크기 ↔ 마진 폭 ↔ 과소적합/과적합 ↔ 편향/분산을 한 묶음으로 말할 수 있어야 합니다.

교수님 말씀 — 이번 수업의 범위

SVM이 서포트 벡터를 어떻게 선정하고 마진을 어떻게 최대로 하는지를 배웁니다. 커널 트릭은 심화라서 짚고 넘어가는 수준입니다.

교수님 말씀 — 식은 겁먹지 말 것

시험에 식은 형태를 그대로 안내해 줍니다. 식 자체를 내지는 않습니다. 교안에 식을 넣은 것은 이해를 위한 것이지 괴롭히기 위함이 아닙니다. → 식을 외우기보다 식의 각 부분이 무슨 뜻인지 말할 수 있어야 합니다.

교수님 말씀 — 교안 8쪽 제약식

y가 1일 때는 (f(x)가) M보다 커야 하고, −1일 때는 −M보다 작아야 한다. 그걸 보여 주는 식입니다.

교수님 말씀 — 범위 (심화·그림·범위 밖)

· 21쪽부터 심화 — 시험에 직접적으로 안 나온다는 뜻입니다(21–23쪽 힌지 손실을 말씀하신 것으로 보임).
· 24–25쪽(특징 공간 확장)은 어려우니 그림으로 이해하면 됩니다.
· 28–30쪽(커널)도 심화 — 사실 공부 안 해도 되는 정도입니다.
· 31–32쪽은 시험 범위 아님. 33쪽 SVR은 잘 안 쓴다고 하셨습니다.

03반드시 외울 정의 시험 직결

서포트 벡터 머신Support Vector Machine, SVM
클래스 사이의 마진을 최대로 하여 결정 경계를 만들고, 서포트 벡터를 사용하며, 커널 트릭으로 비선형 경계까지 확장되는 지도 학습 모델입니다.
초평면Hyperplane
p차원 공간의 (p − 1)차원 평평한 부분공간으로, 공간을 두 개의 반쪽 공간으로 나눕니다. 2차원에서는 직선, 3차원에서는 평면입니다.
결정 경계Decision boundary
서로 다른 클래스를 나누는 경계입니다. 초평면이 결정 경계 역할을 합니다.
선형 분리 가능Linearly separable
두 클래스를 선형 결정 경계(초평면) 하나로 나눌 수 있는 상태입니다. 이때 분리 초평면은 무한히 많습니다.
최대 마진 초평면Maximal margin hyperplane
분리 초평면 중 학습 데이터에서 가장 멀리 떨어진 초평면입니다.
마진Margin
학습 데이터와 초평면 사이 거리 중 가장 작은 거리, 즉 초평면에 가장 가까운 학습 점까지의 거리입니다(평균 거리 아님).
서포트 벡터Support vectors
초평면까지의 거리가 마진과 같은 학습 데이터입니다. 최적화 결과로 정해지며, 이 점들만 경계를 결정합니다.
하드 마진 SVMHard Margin SVM = Maximal margin classifier
오분류·마진 위반을 전혀 허용하지 않고 마진을 최대로 하는 분류기입니다. 선형 분리 가능할 때만 해가 있습니다.
법선벡터Normal vector
면(또는 면 위의 한 점)에 수직인 벡터입니다. 초평면의 β = (β1, …, βp)가 법선벡터입니다.
단위벡터Unit vector
크기(길이)가 1인 벡터입니다. 조건 ∑βj2 = 1이 β를 단위벡터로 고정합니다.
표준화Standardization (Z-score)
(x − μ)/σ로 특징을 평균 0, 분산 1로 만듭니다. 값의 범위를 고정하지 않습니다.
최소-최대 정규화Min–Max Normalization
학습 데이터의 특징 값을 [0, 1]로 옮기고, 학습 범위 안의 상대적 위치를 유지합니다.
소프트 마진 SVMSoft Margin SVM (Linear SVM)
초평면으로 분류하되, 학습 데이터가 마진이나 초평면의 반대쪽에 있는 것을 허용하는 SVM입니다. 클래스를 "거의" 나눕니다.
소프트 마진의 서포트 벡터
마진 위에 정확히 있는 점과, 자기 클래스 기준으로 마진의 반대쪽에 있는 점(마진 위반·오분류 점)입니다.
슬랙 변수Slack variable εi
점 i의 마진 위반을 허용하는 변수입니다. εi = 0 마진의 맞는 쪽 / 0 < εi ≤ 1 마진 위반 / εi > 1 오분류(초평면 반대쪽).
벌점 매개변수 C ★Penalty parameter C
마진 폭과 분류 오류 허용 사이의 균형(trade-off)을 조절하는 값입니다. 음수가 될 수 없는 하이퍼파라미터이며 교차 검증으로 고릅니다.
하이퍼파라미터Hyperparameter
학습으로 정해지지 않고 사람이 정하는 값(C 등)입니다. 교차 검증으로 고릅니다.
편향Bias
예측이 평균적으로 정답에서 벗어난 정도입니다. 모델이 너무 단순하면 커집니다(과소적합).
분산Variance
학습 데이터가 조금 바뀔 때 예측이 흔들리는 정도입니다. 모델이 너무 복잡하면 커집니다(과적합).
특징 공간 확장Expanding feature space
x2, x1x2 같은 새 특징을 추가해 고차원에서 선형으로 나누는 방법입니다. 원래 공간에서는 비선형 경계가 됩니다.
커널 함수 (심화)Kernel function K
내적의 일반화로, 두 입력을 받아 어떤 특징 공간에서의 내적을 암묵적으로 계산합니다. 선형·다항·RBF.

04공식과 절차 시험 직결

교수님이 식은 시험에서 형태를 안내한다고 하셨으므로, 아래 식은 각 부분의 뜻을 말할 수 있으면 됩니다.

① 초평면과 분류 규칙

f(x) = β0 + β1X1 + ⋯ + βpXp = 0f(x) > 0 → 한 클래스, f(x) < 0 → 다른 클래스, f(x) = 0 → 초평면 위. |f(x)|가 클수록 경계에서 멀어 분류를 더 믿을 수 있습니다.

교안 예: 1 + 2X1 + 3X2 = 0 → (0, 0)은 1 > 0 파란 영역, (−1, 0)은 −1 < 0 보라 영역, (1, −1)은 0 직선 위.

② 하드 마진 SVM (교안 8쪽)

maxβ0, …, βp M
subject to  Σj=1p βj2 = 1,
      y(i)(β0 + β1x1(i) + ⋯ + βpxp(i)) ≥ M,  ∀i y(i) ∈ {−1, +1}: i번째 데이터의 레이블 · M: 마진 · ∑βj2 = 1: β를 단위벡터로 고정 → y·f(x)가 실제 거리가 됨 · ∀i: 모든 학습 데이터
  • max M: 마진을 가장 크게 만드는 β를 찾습니다.
  • y·f(x) ≥ M: y = +1이면 f(x) ≥ M, y = −1이면 f(x) ≤ −M. 모든 점이 맞는 쪽에 있고 초평면에서 M 이상 떨어져 있다는 뜻입니다. 레이블을 −1/+1로 쓰기 때문에 두 조건이 한 줄로 합쳐집니다.
  • ∑βj2 = 1이 없으면: 같은 초평면(x1 + x2 − 5 = 0 과 2x1 + 2x2 − 10 = 0)인데 점 (2, 2), y = +1의 값이 −1, −2로 달라져 마진 값이 일관되지 않습니다.

③ 서포트 벡터가 정해지는 절차

  1. 마진 M을 키우면 경계 양쪽의 띠가 같은 폭으로 넓어집니다.
  2. 넓히다 보면 양쪽 클래스의 어떤 점에 먼저 닿고, 더 넓히면 그 점이 y·f(x) ≥ M을 어기므로 멈춥니다 → 최대 마진.
  3. 조건이 등호 y(i)·f(x(i)) = M으로 성립하는 점이 서포트 벡터입니다. 사람이 미리 고르지 않습니다.

④ 특징 스케일링 (교안 12쪽)

표준화: x̃j = xj − μjσj    최소-최대: x̃j = xj − xjminxjmax − xjminμj, σj: 특징 j의 학습 데이터 평균·표준편차 · xjmin, xjmax: 학습 데이터 최솟값·최댓값
  • 이유: 특징 범위가 다르면 법선벡터가 왜곡되어 마진이 잘못 정해집니다. 스케일 후에는 노름이 의미를 갖고 올바른 최대 마진 초평면을 찾습니다.
  • 통계값은 학습 데이터에서만 계산하고, 검증·테스트 데이터에 그대로 다시 씁니다. 교안: 표준화가 SVM의 흔한 출발점입니다.

⑤ 소프트 마진 SVM (교안 16–17쪽)

maxβ0, …, βp, ε1, …, εn M
subject to  Σj=1p βj2 = 1,
      y(i)(β0 + β1x1(i) + ⋯ + βpxp(i)) ≥ M(1 − εi),  ∀i
      Σi=1n εi ≤ C,   εi ≥ 0,  ∀i εi: 점 i의 슬랙 변수 · 이 식의 C는 위반 총량의 상한(예산) — 아래 ⑥의 주의 참고 · 교안 16쪽은 첫 제약 합이 j = 0부터로 적혀 있으나 8쪽과 같게 j = 1로 적음(원고 정정)
εi점의 위치 (교안 17쪽)
εi = 0마진의 맞는 쪽 (correct side of the margin)
0 < εi ≤ 1마진 위반 (초평면은 맞는 쪽)
εi > 1오분류 (초평면 반대쪽)

1이 기준인 이유: εi = 1이면 M(1 − εi) = 0이 되어 y·f(x) ≥ 0(초평면의 맞는 쪽 또는 위)이고, 1을 넘으면 y·f(x)가 음수(오분류)여도 됩니다.

⑥ ★ 벌점 매개변수 C (교안 18–19쪽)

  • C는 마진 폭과 분류 오류 허용 사이의 trade-off를 조절합니다.
  • C는 하이퍼파라미터, 교차 검증으로 고름, 음수 불가(non-negative).
  • C를 작은 값에서 큰 값으로 바꾸면 편향-분산 트레이드오프가 생깁니다.
  • 교안 19쪽(벌점 기준): 작은 C → 넓은 마진, 오류 어느 정도 허용, 단순한 모델(과소적합), 고편향·저분산 / 큰 C → 좁은 마진, 오류 최소화로 빡빡하게 분리(과적합), 저편향·고분산.
주의 — 교안 안에 C의 정의가 두 가지 섞여 있습니다

C를 무엇으로 정의하느냐에 따라 "C가 크면 마진이 넓다/좁다"가 정반대가 됩니다.

  • 예산(budget) C — 교안 16쪽 식 ∑εi ≤ C(위반 총량의 상한), 18쪽 "C = 0이면 최대 마진 분류기(해가 있다면)". C가 크면 위반을 많이 허용 → 마진 넓음. 하드 마진은 C = 0입니다.
  • 벌점(penalty) C — 교안 19쪽 표, 22쪽 식 min ½‖β‖2 + C∑εi(위반 1단위당 벌점). C가 크면 위반이 비쌈 → 마진 좁음. 하드 마진은 C → ∞입니다.

교수님이 쓰신 것: 필기에 남은 교수님 말씀은 "벌점 매개변수 C는 시험에 잘 나온다"뿐입니다(교안 18쪽 제목 Penalty Parameter C의 이름). 교수님이 C의 크기와 마진 방향을 어느 정의로 설명하셨는지는 필기에 없습니다. 원고도 이 점을 "확인 필요"로 남겨 두었습니다.

답안 기준: 교수님이 부른 이름(벌점)과 교안의 크기 비교 표(19쪽)가 모두 벌점 기준이므로 "작은 C = 넓은 마진 / 큰 C = 좁은 마진"으로 답합니다. 단, 문제에 ∑εi ≤ C(예산)가 주어지거나 "C = 0이면 하드 마진"을 묻는다면 예산 기준이므로 방향이 반대입니다.

⑦ 편향-분산 트레이드오프 (교안 20쪽)

  • 복잡도가 커질수록 Bias2는 줄고 Variance는 늘어 Total Error가 U자 → 가운데 최솟값이 최적 복잡도.
  • 왼쪽(단순) = 과소적합 영역, 오른쪽(복잡) = 과적합 영역. 편향을 줄이면 분산이 늘고, 분산을 줄이면 편향이 늡니다.

06그림으로 기억 자주 나옴

  • 마진은 화살표 길이(서포트 벡터에서 초평면까지의 수직 거리)이고, 실선은 두 점선의 정확히 가운데입니다.
  • 서포트 벡터가 아닌 점은 움직여도 경계가 바뀌지 않습니다.
  • 마진 위: 7, 9 / 2 · 마진 안쪽(초평면은 맞는 쪽): 1, 8 · 오분류: 11, 12 → 모두 서포트 벡터. 교안: margin을 위반한 점은 1, 8, 11, 12.
  • 자기 쪽 마진 바깥 3, 4, 5, 6 / 10은 서포트 벡터가 아닙니다(ε = 0).
  • 넓은 마진(작은 벌점 C) = 마진 안에 점이 많아 서포트 벡터가 많음, 좁은 마진(큰 벌점 C) = 서포트 벡터가 적음.
  • 원본 그림(ISLR)은 예산 C로 만든 것이므로, 그림 순서를 "C 값"으로 물으면 어느 정의인지 확인해야 합니다.
  • 과녁: 점의 중심이 가운데에서 떨어짐 = 편향, 점이 넓게 흩어짐 = 분산. 목표는 저편향·저분산.
  • U자 곡선의 왼쪽 = 과소적합(작은 벌점 C), 오른쪽 = 과적합(큰 벌점 C).

07함정 O/X

  1. 마진은 학습 데이터와 초평면 사이 거리의 평균이다.X — 가장 작은 거리(가장 가까운 점까지의 거리)입니다.
  2. 서포트 벡터는 초평면까지의 거리가 마진과 같은 학습 데이터이다.O — 교안 7쪽 정의 그대로입니다.
  3. 서포트 벡터는 학습 전에 사람이 골라 준다.X — 최적화 문제를 풀면 결과로 정해집니다(y·f(x) = M인 점).
  4. 서포트 벡터가 아닌 점을 조금 옮겨도 최대 마진 초평면은 바뀌지 않는다.O — 서포트 벡터만 경계를 결정합니다.
  5. p차원 공간의 초평면은 p차원이다.X — (p − 1)차원입니다. 2차원에서는 직선입니다.
  6. 하드 마진 제약에서 y = −1인 점은 f(x) ≥ −M이어야 한다.X — f(x) ≤ −M (−M보다 작아야) 합니다.
  7. ∑βj2 = 1 조건이 없으면 같은 초평면인데도 마진 값이 달라진다.O — β를 상수배하면 값도 상수배되어 일관되지 않습니다.
  8. 하드 마진 SVM은 선형 분리가 불가능한 데이터에도 해가 있다.X — 선형 분리 가능할 때만 해가 있습니다.
  9. 스케일링 통계값은 테스트 데이터에서 다시 계산해 테스트 데이터에 적용한다.X — 학습 데이터에서만 계산하고 검증·테스트에 재사용합니다.
  10. 0 < εi ≤ 1인 점은 오분류된 점이다.X — 마진 위반이지만 초평면은 맞는 쪽입니다. 오분류는 εi > 1.
  11. (교안 19쪽 기준) 벌점 C가 크면 마진이 좁아지고 과적합 경향이 생긴다.O — 저편향·고분산입니다.
  12. (교안 19쪽 기준) 작은 C는 편향이 낮고 분산이 높다.X — 작은 C는 편향 높음, 분산 낮음(과소적합)입니다.
  13. C는 학습 과정에서 β와 함께 자동으로 학습된다.X — 하이퍼파라미터로, 교차 검증으로 고릅니다.
  14. C는 음수가 될 수 없다.O — 교안 18쪽 "must be non-negative".
  15. 소프트 마진의 서포트 벡터는 마진 경계 위에 정확히 있는 점뿐이다.X — 자기 클래스 기준 마진 반대쪽에 있는 점(위반·오분류)도 포함합니다.

08연습 문제

이 차시 교안에는 퀴즈가 없습니다. 아래는 원고의 예상 문제와 계산 연습입니다(예상이며 실제 출제와 다를 수 있음).

1. (객관식) SVM의 서포트 벡터에 대한 설명으로 옳은 것은?

① 학습 데이터 전체를 말한다. ② 초평면에서 가장 멀리 떨어진 점들이다. ③ 초평면까지의 거리가 마진과 같은 점들이며, 이 점들만 경계를 결정한다. ④ 학습 전에 사람이 직접 골라 주는 점이다.

풀이 보기
정답 ③ — 서포트 벡터는 마진 경계 위에 있는 점(y·f(x) = M)입니다. 최적화 문제를 풀면 결과로 정해지며(④ 아님), 서포트 벡터가 아닌 점은 움직여도 경계가 바뀌지 않습니다.
2. (계산) 초평면 1 + 2X1 + 3X2 = 0에서 점 (0, 0), (−1, 0), (2, −2)는 각각 어느 쪽인가? (식 값 > 0 파란 영역, < 0 보라 영역)
풀이 보기
(0, 0): 1 + 0 + 0 = 1 > 0 → 파란 영역.
(−1, 0): 1 − 2 + 0 = −1 < 0 → 보라 영역.
(2, −2): 1 + 4 − 6 = −1 < 0 → 보라 영역.
값이 0이면 초평면 위의 점입니다.
3. (서술) 하드 마진 SVM의 제약 y(i)(β0 + β1x1(i) + ⋯ + βpxp(i)) ≥ M이 뜻하는 바를 y = +1일 때와 y = −1일 때로 나눠 설명하시오.
풀이 보기
모범 답안 — f(x) = β0 + β1x1 + ⋯ + βpxp라 하면, y = +1인 점은 f(x) ≥ M, y = −1인 점은 f(x) ≤ −M이어야 합니다. 즉 모든 점이 자기 클래스 쪽에 있으면서 초평면에서 M 이상 떨어져 있어야 합니다. y = −1인 경우 양변에 −1을 곱하면 −f(x) ≥ M이 되므로 두 조건을 y·f(x) ≥ M 하나로 쓸 수 있습니다.
4. (서술) 하드 마진 SVM에 ∑βj2 = 1(단위벡터) 제약이 필요한 이유를 쓰시오.
풀이 보기
모범 답안 — β와 β0에 같은 상수를 곱해도 같은 초평면입니다(예: x1 + x2 − 5 = 0과 2x1 + 2x2 − 10 = 0). 그런데 y(β⊤x + b) 값은 상수배만큼 달라져, 점 (2, 2), y = +1에서 −1과 −2처럼 같은 초평면인데 마진 값이 일관되지 않습니다. β의 길이를 1로 고정해야 y·f(x)가 점과 초평면 사이의 실제 거리가 되어 마진을 비교할 수 있습니다.
5. (객관식 ★) 소프트 마진 SVM에서 벌점 매개변수 C를 크게 했을 때의 변화로 옳은 것은? (교안 19쪽 벌점 기준)

① 마진이 넓어지고 과소적합 경향이 생긴다. ② 마진이 좁아지고 과적합 경향이 생기며, 편향은 낮고 분산은 높다. ③ 마진은 변하지 않고 서포트 벡터 수만 늘어난다. ④ C는 학습으로 자동으로 정해지므로 바꿀 수 없다.

풀이 보기
정답 ② — C가 크면 오류를 강하게 벌하므로 데이터를 빡빡하게 나누려 해서 마진이 좁아지고 과적합(저편향·고분산) 쪽이 됩니다. C가 작으면 반대입니다. C는 하이퍼파라미터라 교차 검증으로 고릅니다(④ 틀림). 주의: C를 위반 예산(∑εi ≤ C, 16·18쪽)으로 정의하면 방향이 반대입니다.
6. (서술) SVM 학습 전에 특징 스케일링이 필요한 이유와, 스케일링 통계값을 어떤 데이터에서 계산해야 하는지 쓰시오.
풀이 보기
모범 답안 — SVM은 점과 초평면 사이의 거리(마진)로 경계를 정하는데, 특징마다 범위가 크게 다르면(예: 0~6과 0~80) 범위가 큰 특징이 거리를 지배해 법선벡터가 왜곡되고 마진이 잘못 정해집니다. 그래서 표준화((x − μ)/σ) 등으로 범위를 맞춥니다. 통계값(평균·표준편차·최솟값·최댓값)은 학습 데이터에서만 계산하고, 검증·테스트 데이터에는 그 값을 그대로 다시 씁니다.
7. (계산) 하드 마진 SVM의 결과 경계가 f(x) = x1 − 1 (β = (1, 0), 길이 1)이다. +1 클래스 A(2, 0), B(3, 1), −1 클래스 C(0, 0), D(−1, 1)에서 마진 M과 서포트 벡터를 구하시오. 보충
풀이 보기
y·f(x): A = (+1)(1) = 1, B = (+1)(2) = 2, C = (−1)(−1) = 1, D = (−1)(−2) = 2.
가장 작은 값이 마진이므로 M = 1, 등호(y·f = M)가 성립하는 A와 C가 서포트 벡터입니다. B, D를 조금 옮겨도 경계는 그대로입니다.
8. (계산) 점 (2, 2), y = +1과 초평면 x1 + x2 − 5 = 0, 2x1 + 2x2 − 10 = 0. β를 단위벡터로 맞추면 y·f(x) 값은 각각 얼마인가?
풀이 보기
Case 1: ‖β‖ = √2 → −1√2 ≈ −0.707. Case 2: ‖β‖ = 2√2 → −22√2 ≈ −0.707.
같은 값이 되고, 이 값의 크기 0.707이 점과 초평면 사이의 실제 거리입니다. 음수이므로 이 점은 y = +1인데 f < 0 쪽, 즉 틀린 쪽에 있습니다.
9. (계산) 소프트 마진에서 M = 2일 때, 세 점의 y·f(x)가 각각 2.5, 1, −1이다. 제약 y·f(x) ≥ M(1 − εi)을 만족하는 가장 작은 εi와 각 점의 위치를 쓰시오. 보충
풀이 보기
가장 작은 εi = max{0, 1 − y·f/M}.
2.5: 1 − 1.25 < 0 → ε = 0 → 마진의 맞는 쪽.
1: 1 − 0.5 = 0.5 → 0 < ε ≤ 1 → 마진 위반(초평면은 맞는 쪽).
−1: 1 + 0.5 = 1.5 → ε > 1 → 오분류.
10. (계산) 학습 데이터 특징 값이 20, 40, 100이다. 최소-최대 정규화로 40은 얼마가 되는가? 테스트 데이터의 값 120은? 보충
풀이 보기
학습 데이터의 min = 20, max = 100.
40 → 40 − 20100 − 20 = 0.25.
테스트 120도 학습 통계값을 그대로 써서 120 − 2080 = 1.25. 테스트 데이터로 min·max를 다시 구하지 않습니다([0, 1] 범위는 학습 데이터 기준).
