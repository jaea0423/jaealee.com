01서포트 벡터 머신이란교안 1–2쪽

Support Vector Machine

오늘 주제는 서포트 벡터 머신(Support Vector Machine, SVM)입니다. 교안 첫 장은 SVM 원 논문 Support-Vector Networks(Cortes & Vapnik, Machine Learning 20권, 1995)의 첫 페이지입니다.

지난 차시(6주차 1차시 15)의 로지스틱 회귀는 "y = 1일 확률"을 구한 뒤 0.5를 기준으로 분류했습니다. SVM도 같은 지도 학습 분류 모델이지만 접근이 다릅니다. 확률을 구하지 않고, 두 클래스 사이에 경계를 어디에 그어야 가장 안전한가를 직접 찾습니다.

교수님 말씀 — 이번 수업의 범위

SVM이 서포트 벡터를 어떻게 선정하고 마진을 어떻게 최대로 하는지를 배웁니다(05–06, 10–11). 커널 트릭은 심화라서 짚고 넘어가는 수준입니다(16).

교안의 정의 한 문장에 오늘 배울 내용이 모두 들어 있습니다.

Support vector machine (SVM) is a supervised learning model that constructs a decision boundary by maximizing the margin between classes, using support vectors, and extends to nonlinear boundaries through the kernel trick.

02초평면이란교안 3–4쪽

What is Hyperplane?

초평면(hyperplane)은 데이터를 분류하는 결정 경계(decision boundary)입니다. 지난 차시 다중 회귀에서 "선 → 면 → 초평면"이라고 했던 그 초평면입니다(6주차 1차시 03).

Hyperplanes are decision boundaries that help classify data points.

정확한 정의는 p차원 공간 안의 (p − 1)차원 평평한 부분공간(subspace)이고, 공간을 두 개의 반쪽 공간(half-spaces)으로 나눕니다.

Hyperplane is an (p-1)-dimensional subspace of an p-dimensional space, which splits the space into two half-spaces.
공간 차원 p초평면 차원 p − 1모양식
21직선(line)β₀ + β₁X₁ + β₂X₂ = 0
32평면(plane)β₀ + β₁X₁ + β₂X₂ + β₃X₃ = 0
pp − 1초평면β₀ + β₁X₁ + ⋯ + βpXp = 0
보충 — "평평하다(flat)"의 뜻

초평면은 휘지 않습니다. 식이 변수들의 1차식(β₀ + β₁X₁ + ⋯)이라서 2차원에서는 곧은 직선, 3차원에서는 휘지 않은 평면입니다. 곡선 경계는 15–16의 비선형 SVM에서 나옵니다.

정리
  • 초평면 = p차원 공간을 둘로 나누는 (p − 1)차원 평평한 경계
  • 2D: 직선, 3D: 평면, 식은 β₀ + β₁X₁ + ⋯ + βₚXₚ = 0

03분리 초평면 — 2차원 예시교안 5쪽

Separating Hyperplane (2D example)

2차원에서 초평면은 직선입니다. 교안의 예는 다음 직선입니다.

1 + 2X₁ + 3X₂ = 0

이 직선 위의 점은 식 값이 정확히 0입니다. 직선에서 벗어난 점을 식에 넣으면 값이 0이 아니고, 부호로 어느 쪽인지 알 수 있습니다.

  • 파란 영역: 1 + 2X₁ + 3X₂ > 0 Blue region: 1 + 2X₁ + 3X₂ > 0
  • 보라 영역: 1 + 2X₁ + 3X₂ < 0 Purple region: 1 + 2X₁ + 3X₂ < 0
직접 확인

원점 (0, 0): 1 + 0 + 0 = 1 > 0 → 파란 영역. 점 (−1, 0): 1 − 2 + 0 = −1 < 0 → 보라 영역. 직선 위의 점 (1, −1): 1 + 2 − 3 = 0.

이것이 분류 규칙이 됩니다. 새 점 x*가 들어오면 f(x*) = β₀ + β₁x₁* + β₂x₂*를 계산해서 양수면 한 클래스, 음수면 다른 클래스로 분류합니다. 또 |f(x*)|가 클수록 점이 경계에서 멀리 있으므로 분류 결과를 더 믿을 수 있습니다.

정리
  • f(x) = β₀ + β₁X₁ + β₂X₂의 부호가 초평면의 어느 쪽인지를 알려 줌
  • 분류: f(x*) > 0 → 한 클래스, f(x*) < 0 → 다른 클래스

04분리 초평면으로 분류하기교안 6쪽

Separating Hyperplane for Classification

아이디어: 분리 초평면으로 이진 분류(binary classification)를 합니다. 초평면이 서로 다른 클래스를 나누는 결정 경계 역할을 합니다.

Idea: Use a separating hyperplane for binary classification.

핵심 가정: 두 클래스가 선형 결정 경계로 나뉠 수 있다(선형 분리 가능, linearly separable)고 가정합니다.

Key assumption: Classes can be separated by a linear decision boundary

문제: 선형 분리가 가능한 데이터라면 두 클래스를 나누는 초평면은 하나가 아니라 무한히 많습니다. 그림의 세 직선은 모두 학습 데이터를 100% 맞게 나눕니다. 그렇다면 어느 것을 골라야 할까요? 다음 섹션이 이 질문에 답합니다.

Notice that for a linearly separable dataset, there are many possible separating hyperplanes that divide the dataset into two classes (in fact, an infinite number).
정리
  • 가정: 클래스가 직선(초평면)으로 나뉠 수 있음 = 선형 분리 가능
  • 분리 초평면은 무한히 많음 → 그중 하나를 고르는 기준이 필요

05최대 마진 초평면교안 7쪽

Maximal Margin Hyperplane

무한히 많은 분리 초평면 중에서 자연스러운 선택은 최대 마진 초평면(maximal margin hyperplane), 즉 학습 데이터에서 가장 멀리 떨어진 분리 초평면입니다.

A natural choice is the maximal margin hyperplane, the separating hyperplane that is farthest from the training samples.
용어정의
마진
Margin		학습 데이터 중 초평면에 가장 가까운 점까지의 거리smallest distance between any training observation and the hyperplane
서포트 벡터
Support vectors		초평면까지의 거리가 마진과 같은 학습 데이터training observations whose distance to the hyperplane is equal to the margin

그림 읽기: 가운데 실선이 최대 마진 초평면, 양쪽 점선이 마진 경계입니다. 점선 위에 걸친 점(빨간 원)이 서포트 벡터이고, 주황 화살표 길이가 마진입니다. 실선은 두 점선의 정확히 가운데에 있습니다.

왜 마진을 최대로 할까

경계가 어느 한쪽 클래스에 붙어 있으면, 그 근처에 새 점이 조금만 다르게 들어와도 반대쪽으로 넘어가 오분류됩니다. 두 클래스 모두에서 가장 멀리 떨어진 경계는 이런 여유가 가장 크므로, 학습에 쓰지 않은 새 데이터에서도 잘 맞을 것(일반화)이라고 기대합니다.

서포트 벡터만 경계를 결정한다

최대 마진 초평면은 서포트 벡터에만 의존합니다. 서포트 벡터가 아닌 점은 마진 바깥에 있으므로, 조금 움직이거나 지워도 경계가 바뀌지 않습니다. 반대로 서포트 벡터가 움직이면 경계가 바뀝니다. 이름이 "서포트(support, 받치다) 벡터"인 이유입니다(벡터 = 점 하나의 좌표 묶음 (x₁, x₂, …)).

정리
  • 마진 = 초평면과 가장 가까운 학습 점 사이 거리
  • 최대 마진 초평면 = 마진이 가장 큰 분리 초평면
  • 서포트 벡터 = 마진 경계 위의 점, 이 점들만 경계를 결정

06최대 마진 분류기 찾기 (하드 마진 SVM)교안 8쪽

Finding Maximal Margin Classifier (Hard Margin SVM)

데이터 (x⃗(i), y(i))에서 레이블은 y(i) ∈ {−1, 1}로 둡니다. 로지스틱 회귀에서는 0/1이었지만 SVM은 −1/+1을 씁니다. 이유는 아래 "식 읽는 법"에 나옵니다. 위첨자 (i)는 i번째 데이터라는 뜻입니다.

최대 마진 초평면은 다음 최적화 문제의 해입니다.

maxβ₀, …, βₚ M
subject to   ∑j=1p βj² = 1
y(i)(β₀ + β₁x₁(i) + ⋯ + βₚxₚ(i)) ≥ M,   ∀i

식 읽는 법 — 한 줄씩

  1. max M: 마진 M을 가장 크게 만드는 β들을 찾습니다. "subject to"는 "다음 조건을 지키면서"라는 뜻입니다.
  2. ∑βj² = 1: 계수 벡터 (β₁, …, βₚ)의 길이를 1로 고정합니다(단위벡터). 이 조건이 있어야 아래 식의 값이 실제 거리가 됩니다. 필요한 이유는 07에서 봅니다.
  3. y(i)·f(x(i)) ≥ M (모든 i): f(x) = β₀ + β₁x₁ + ⋯는 03에서 본 식이고, 부호가 초평면의 어느 쪽인지를 알려 줍니다.
    • y = +1인 점은 f > 0 쪽에, y = −1인 점은 f < 0 쪽에 있어야 맞게 분류된 것입니다.
    • 그래서 y·f(x)는 맞게 분류되면 양수, 틀리면 음수입니다. 레이블을 −1/+1로 둔 덕분에 두 경우를 식 하나로 쓸 수 있습니다.
    • ∑βj² = 1이면 y·f(x)는 점과 초평면 사이의 거리입니다. 따라서 이 조건은 "모든 점이 맞는 쪽에 있고, 초평면에서 적어도 M만큼 떨어져 있다"는 뜻입니다.
보충 — 점과 초평면 사이 거리 공식

점 x에서 초평면 β₀ + β·x = 0까지의 거리는 |β₀ + β·x| / ‖β‖입니다(‖β‖ = √(β₁² + ⋯ + βₚ²), 벡터의 길이). ‖β‖ = 1로 고정하면 분모가 1이 되어 |f(x)| 자체가 거리가 됩니다. 고등학교에서 배운 "점 (x₀, y₀)과 직선 ax + by + c = 0 사이 거리 = |ax₀ + by₀ + c| / √(a² + b²)"를 p차원으로 넓힌 것입니다.

서포트 벡터는 어떻게 선정되나 — 수업 핵심

서포트 벡터는 사람이 미리 고르는 것이 아니라, 위 최적화 문제를 풀면 결과로 정해집니다.

  1. 마진 M을 키우려고 하면 경계 양쪽의 띠(마진)가 넓어지다가, 어느 순간 양쪽 클래스의 점에 닿습니다.
  2. 더 넓히면 그 점이 조건 y·f(x) ≥ M을 어기므로 더 이상 넓힐 수 없습니다. 이때의 M이 최대 마진입니다.
  3. 이 순간 조건이 등호로 성립하는 점, 즉 y(i)·f(x(i)) = M인 점(마진 경계 위의 점)이 서포트 벡터입니다. 나머지 점은 y·f(x) > M이라 여유가 있습니다.
  4. 경계가 이 점들에 "받쳐져" 있으므로, 서포트 벡터가 아닌 점을 지우거나 움직여도(마진 밖에 있는 한) 답이 그대로입니다(05).

05의 그림에서 마진을 넓히다 먼저 닿는 점이 빨간 원 2개였고, 그래서 그 2개가 서포트 벡터입니다. 2차원에서는 서포트 벡터가 보통 2~3개입니다(양쪽에 적어도 1개씩).

하드 마진의 전제

모든 점이 마진 바깥 맞는 쪽에 있어야 하므로, 데이터가 선형 분리 가능할 때만 해가 존재합니다. 한 점이라도 섞여 있으면 조건을 만족하는 β가 없습니다. 이 한계를 푸는 것이 10의 소프트 마진입니다.

정리
  • 레이블 y ∈ {−1, +1} → y·f(x) > 0이면 맞게 분류
  • 서포트 벡터 = 최적해에서 y·f(x) = M(등호)인 점 — 마진을 넓히다 먼저 닿는 점
  • 하드 마진: ‖β‖ = 1에서 모든 i에 대해 y·f(x) ≥ M, 이 M을 최대화
  • 선형 분리 가능할 때만 해가 있음

07법선벡터와 단위벡터 — 왜 ∑β² = 1인가교안 9–10쪽

Background: Normal Vector & Unit Vector / Why We Need Unit Vector?
법선벡터 (Normal Vector)단위벡터 (Unit Vector)
면(또는 면 위의 한 점)에 수직인 벡터A vector that is perpendicular to a surface or a point on a surface.크기(길이)가 1인 벡터A vector with a magnitude (or length) of 1.

초평면 β₀ + β₁X₁ + ⋯ + βₚXₚ = 0에서 계수 벡터 β = (β₁, …, βₚ)가 바로 법선벡터입니다. 그림처럼 한 면에 수직인 벡터는 길이가 다른 것이 여러 개 있습니다. 그중 길이가 1인 것을 고르겠다는 조건이 ∑βj² = 1입니다.

보충 — β가 법선벡터인 이유 (2차원)

직선 β₁x₁ + β₂x₂ + β₀ = 0 위의 두 점 a, b를 넣고 빼면 β₁(a₁ − b₁) + β₂(a₂ − b₂) = 0, 즉 β · (a − b) = 0입니다. a − b는 직선 방향의 벡터이고, 내적이 0이면 수직입니다. 따라서 β는 직선에 수직입니다. 벡터·내적은 5주차 1차시 11.4를 참고하세요.

단위벡터 조건이 없으면 생기는 문제 — 교안 예제

다음 두 경우는 같은 초평면입니다(두 번째 식은 첫 번째 식에 2를 곱한 것).

Case 1: β = (1, 1), b = −5  ⇒  x₁ + x₂ − 5 = 0
Case 2: β = (2, 2), b = −10  ⇒  2x₁ + 2x₂ − 10 = 0

학습 데이터 x(1) = (2, 2), y(1) = +1로 마진 값 y(βᵀx + b)를 계산하면:

Case 1: M = (+1)(2 + 2 − 5) = −1
Case 2: M = (+1)(4 + 4 − 10) = −2

초평면은 그대로인데 값이 −1과 −2로 다릅니다. β에 아무 수나 곱해도 같은 초평면이므로, β를 키우기만 하면 "마진"을 얼마든지 크게 만들 수 있게 됩니다. 이러면 max M 문제가 의미를 잃습니다.

While the hyperplane itself remains unchanged, the margin value varies, leading to an inconsistency.
보충 — 단위벡터로 맞추면

각 β를 자기 길이로 나누면 Case 1: ‖β‖ = √2 → −1/√2 ≈ −0.707, Case 2: ‖β‖ = √8 = 2√2 → −2/(2√2) = −1/√2 ≈ −0.707로 같아집니다. 이 값이 실제 거리(0.707)이고, 음수인 것은 점 (2, 2)가 y = +1인데 f < 0 쪽, 즉 틀린 쪽에 있다는 뜻입니다.

정리
  • β = (β₁, …, βₚ)는 초평면의 법선벡터 (초평면에 수직)
  • β에 상수를 곱해도 같은 초평면 → 길이를 1로 고정해야 y·f(x)가 실제 거리가 됨
  • 교안 예: 같은 초평면인데 M = −1, −2로 달라짐 → 정규화하면 둘 다 −1/√2

Importance of Data Scale / Feature Scaling Methods

SVM은 거리(마진)를 기준으로 경계를 정하므로, 특징마다 숫자 범위가 크게 다르면 문제가 생깁니다.

왜 그런가: 거리는 각 축 차이의 제곱을 더해서 계산합니다. x₀는 0~6, x₁은 0~80이면 x₁ 쪽 차이가 거리를 거의 다 차지합니다. 그래서 SVM은 사실상 x₁만 보고 경계를 긋게 되어 경계가 수평에 가까워집니다.

소프트 마진 SVM(soft margin SVM, support vector classifier)도 최대 마진 분류기처럼 초평면으로 분류합니다. 차이는 학습 데이터가 마진이나 초평면의 반대쪽에 있는 것을 허용한다는 점입니다. 이렇게 클래스를 "거의" 나누는 마진을 소프트 마진이라 합니다.

However, training samples are allowed to be on the wrong side of the margin or hyperplane. This hyperplane almost separates the classes using a soft margin.

몇 개를 틀리는 대신 얻는 것: 점 하나에 경계가 흔들리지 않고(09의 문제 해결), 선형 분리가 안 되는 데이터에도 쓸 수 있습니다.

11소프트 마진 SVM 찾기 — 슬랙 변수교안 16–17쪽

Finding Soft Margin SVM

하드 마진 문제(06)에 슬랙 변수(slack variable) εi를 더합니다.

maxβ₀, …, βₚ, ε₁, …, εₙ M
subject to   ∑j=1p βj² = 1
y(i)(β₀ + β₁x₁(i) + ⋯ + βₚxₚ(i)) ≥ M(1 − εi),   ∀i
∑i=1n εi ≤ C,   εi ≥ 0,   ∀i

교안 16쪽은 첫 제약의 합이 j = 0부터(∑j=0p)로 적혀 있는데, 8쪽 하드 마진은 j = 1부터이고 절편 β₀은 길이 조건에 넣지 않는 것이 표준이라 여기서는 j = 1로 적었습니다(18 고친 것).

하드 마진과 달라진 곳

  1. ≥ M → ≥ M(1 − εi): 점마다 εi만큼 조건을 느슨하게 해 줍니다. εi = 0이면 하드 마진과 같은 조건입니다.
  2. ∑εi ≤ C: 느슨하게 해 주는 양의 총합에 상한 C를 둡니다. 위반을 무한정 허용하면 아무 경계나 답이 되기 때문입니다.

εi 값으로 점의 위치 읽기

Slack variables εᵢ allow for violations of the margin.
εi점의 위치10의 그림에서
εi = 0마진의 맞는 쪽(마진 위 또는 바깥)training point is on the correct side of the margin2, 3, 4, 5, 6, 7, 9, 10
0 < εi ≤ 1마진을 위반했지만 초평면은 맞는 쪽training point violates the margin1, 8

왜 1이 기준인가: 조건의 오른쪽 M(1 − εi)은 εi = 1일 때 0이 됩니다. y·f(x) ≥ 0은 "초평면의 맞는 쪽 또는 위"라는 뜻이므로, εi가 1을 넘으면 y·f(x)가 음수여도 되어 오분류까지 허용됩니다.

  • ∑εᵢ ≤ C: 위반 총량의 예산

  • C는 음수가 될 수 없습니다.Note that it must be non-negative.
  • C = 0이면 (해가 있다면) 최대 마진 분류기로 돌아갑니다.If C = 0, we recover the maximal margin classifier (if one exists).

Bias-Variance Tradeoff

C가 왜 과소적합·과적합과 연결되는지 이해하려면 편향(bias)과 분산(variance)을 알아야 합니다.

용어뜻과녁 그림에서
편향 (bias)모델의 예측이 평균적으로 정답에서 벗어난 정도. 모델이 너무 단순해서 데이터의 패턴을 못 잡으면 커짐점들의 중심이 과녁 중앙에서 떨어짐
분산 (variance)학습 데이터가 조금 바뀔 때 모델(예측)이 흔들리는 정도. 모델이 너무 복잡해서 데이터의 잡음까지 따라가면 커짐점들이 넓게 흩어짐

그래프 읽기: 모델 복잡도가 커질수록 Bias²(하늘색)는 줄고 Variance(빨강)는 늘어납니다. 전체 오차(Total Error)는 둘을 더한 U자 곡선이라, 너무 단순(왼쪽, 과소적합 영역)해도 너무 복잡(오른쪽, 과적합 영역)해도 오차가 커지고 가운데에 최적 복잡도가 있습니다. 편향을 줄이면 분산이 늘고, 분산을 줄이면 편향이 느는 관계라서 "트레이드오프"라고 합니다.

정리
  • 편향 = 평균적으로 정답에서 벗어난 정도(단순할수록 큼), 분산 = 데이터에 따라 흔들리는 정도(복잡할수록 큼)
  • 총 오차 = Bias² + Variance (+ 잡음) → U자, 가운데가 최적
  • 벌점 C 작음 = 고편향·저분산(과소적합), C 큼 = 저편향·고분산(과적합)

14소프트 마진 SVM과 힌지 손실교안 21–23쪽

Soft Margin SVM and Hinge Loss

같은 소프트 마진 문제를 지난 차시의 "손실함수를 최소화한다"는 형태로 바꿔 쓸 수 있습니다. 먼저 기호를 정합니다.

fβ(x) = β₀ + ∑j=1p βjxj,    ‖β‖₂² = ∑j=1p βj²

1단계 — M = 1로 고정

11의 문제는 ‖β‖ = 1로 고정하고 M을 키웠습니다. 반대로 M = 1로 고정하고 β의 길이를 자유롭게 두어도 같은 초평면을 찾을 수 있습니다. 그러면 조건이 다음처럼 됩니다.

y(i) fβ(x(i)) ≥ 1 − εi,   εi ≥ 0   (∀i)
보충 — M = 1로 고정해도 되는 이유와 ½‖β‖²가 나오는 이유

07에서 봤듯이 β에 상수를 곱해도 초평면은 같습니다. 그래서 길이를 1로 맞추는 대신, 서포트 벡터에서 y·f(x) = 1이 되도록 크기를 맞출 수 있습니다. 이때 실제 거리(마진)는 1/‖β‖입니다(06의 거리 공식). 마진 1/‖β‖를 최대로 하는 것은 ‖β‖를 최소로 하는 것과 같고, 미분하기 편하게 ½‖β‖²를 최소화합니다.

2단계 — εi를 식으로 풀기

조건을 εi에 대해 정리하면 εi ≥ 1 − y f(x), 그리고 εi ≥ 0입니다. 둘을 합치면:

εi ≥ max{0, 1 − y(i) fβ(x(i))}

εi는 작을수록 좋으므로 최적해에서는 등호가 성립합니다. 이 오른쪽 식이 힌지 손실(hinge loss)입니다.

ℓhinge(y(i), fβ(x(i))) = max{0, 1 − y(i) fβ(x(i))}

3단계 — 같은 최적화 문제의 두 가지 모양

minβ₀, …, βₚ   ½‖β‖₂² + C ∑i=1n max{0, 1 − y(i) fβ(x(i))}
Equivalent optimization problem (without explicit εᵢ)
minβ, ε   ½‖β‖₂² + C ∑i=1n εi   s.t.   y(i) fβ(x(i)) ≥ 1 − εi,   εi ≥ 0
Equivalently, with slack variables

읽는 법: 첫 항 ½‖β‖²를 줄이면 마진이 넓어지고, 둘째 항(힌지 손실 합)을 줄이면 위반이 줄어듭니다. 두 목표가 충돌하고, C가 둘째 항의 무게입니다. C가 크면 위반을 줄이는 쪽을 중시해 마진이 좁아집니다. 여기서의 C가 12의 "벌점 C"입니다.

y·f(x)점의 상태힌지 손실
≥ 1맞게 분류, 마진 바깥0
0 ~ 1맞게 분류, 마진 안쪽1 − y·f(x) (0~1 사이)
< 0오분류1보다 크고, 틀린 정도에 비례해 커짐

예: y = +1, f(x) = 0.3 → max{0, 1 − 0.3} = 0.7. y = +1, f(x) = −0.5 → max{0, 1.5} = 1.5. y = −1, f(x) = −2 → y·f = 2 → 손실 0.

정리
  • 힌지 손실 = max{0, 1 − y·f(x)}: 마진 밖(≥ 1)이면 0, 안쪽이면 작게, 오분류면 크게
  • 소프트 마진 SVM = min ½‖β‖² + C·∑(힌지 손실)
  • ½‖β‖² ↓ = 마진 ↑, C가 클수록 위반을 강하게 벌함

15선형 경계의 한계와 특징 공간 확장교안 24–27쪽

Linear Boundary Can Fail / Expanding Feature Space

데이터에 따라서는 C를 어떻게 정해도 선형 경계가 아예 통하지 않습니다.

Sometimes, a linear boundary simply won't work, no matter what value of C.

해결 — 차원을 늘리면 선형으로 나뉜다

원래 공간에서는 선형으로 나뉘지 않아도, 더 높은 차원의 공간으로 옮기면 선형으로 나뉘는 데이터가 있습니다.

Some datasets are not linearly separable, but they become linearly separable when transformed into a higher-dimensional space.

XOR 예: 왼쪽 위·오른쪽 아래(×)는 x₁과 x₂의 부호가 다르므로 x₁·x₂ < 0, 오른쪽 위·왼쪽 아래(●)는 부호가 같으므로 x₁·x₂ > 0입니다. 새 특징 x₁·x₂를 세 번째 축으로 추가하면 평면 x₁·x₂ = 0 하나로 두 클래스가 나뉩니다.

원형 예: 가운데 점은 원점에서 가깝고 바깥 점은 멉니다. 원점에서 거리의 제곱 x₁² + x₂²를 새 축으로 쓰면 가운데 점은 낮고 바깥 점은 높아져 평면 하나로 나뉩니다. 이 평면 x₁² + x₂² = r²을 원래 2차원에서 보면 원, 즉 곡선 경계입니다.

일반적인 방법 — 제곱 특징 추가

원래 특징이 p개면 각 특징의 제곱을 추가해 2p개로 늘릴 수 있습니다.

X⃗ = (X₁, X₂, …, Xₚ)
→ X⃗ = (X₁, X₁², X₂, X₂², …, Xₚ, Xₚ²) = (X̃₁, X̃₂, …, X̃₂ₚ)

확장된 공간에서 소프트 마진 SVM은 선형 초평면을 찾습니다.

β₀ + β₁X̃₁ + β₂X̃₂ + ⋯ + β₂ₚX̃₂ₚ = 0

X̃를 원래 변수로 되돌리면 비선형 결정 경계가 됩니다.

β₀ + β₁X₁ + β₂X₁² + ⋯ + β₂ₚ₋₁Xₚ + β₂ₚXₚ² = 0

지난 차시 다항 회귀가 "x²를 새 변수로 보면 선형 회귀"였던 것과 같은 원리입니다(6주차 1차시 03). 새 공간에서는 선형, 원래 공간에서는 곡선입니다.

이 방법의 문제

제곱만이 아니라 x₁x₂ 같은 곱, 세제곱 등을 계속 추가하면 특징 수가 폭발적으로 늘어 계산량이 감당할 수 없게 됩니다. 예를 들어 특징 100개의 2차 항(제곱 + 두 개씩 곱)만 해도 100 + 100·99/2 = 5,050개가 추가됩니다. 이 문제를 피하는 것이 다음 섹션의 커널입니다.

다음 16의 커널은 이 "고차원으로 옮기기"를 계산으로 효율화하는 방법이고, 교수님이 심화라 짚고 넘어가는 수준이라고 하신 부분입니다.

정리
  • 선형으로 안 나뉘는 데이터 → 새 특징(x₁x₂, x², x₁² + x₂² 등)을 추가해 고차원으로
  • 고차원에서는 선형 초평면, 원래 공간에서는 곡선 경계
  • p개 특징 + 각 제곱 = 2p개 특징 (특징을 계속 늘리면 계산량 폭발)

(교안 24–27쪽 기반 — 실시간 필기 없음)

16비선형 SVM과 커널교안 28–30쪽

Nonlinear SVM / Linear SVM and Nonlinear SVM / SVM Kernels
교수님 말씀 — 이 섹션의 범위

커널 트릭은 심화라서 짚고 넘어가는 수준입니다. "커널로 데이터를 고차원으로 (암묵적으로) 옮겨 곡선 경계를 만든다"와 커널 3가지의 이름 정도를 알고 넘어가면 됩니다. 아래 보충 상자(내적 전개)는 읽고 넘어가도 됩니다.

비선형 SVM은 소프트 마진 SVM에 커널 함수(kernel function)를 써서 비선형 결정 경계를 만듭니다.

Extends the support vector classifier by using kernel functions to achieve non-linear decision boundaries.

커널 함수 K는 내적(inner product)을 일반화한 것입니다.

  • 두 개의 입력을 받아, 어떤 특징 공간에서의 내적을 암묵적으로(implicitly) 계산합니다.It takes in two arguments and implicitly computes their inner product in some feature space.
  • 비선형 결정 경계를 만드는 효율적인 계산 방법입니다.Kernels are an efficient computational approach to create non-linear decision boundaries.
  • 데이터를 (암묵적으로) 더 높은 차원으로 옮기고, 그 공간에서 선형 결정 경계(초평면)로 SVM을 적용합니다.They (implicitly) map data into a higher-dimensional space. We then apply a support vector classifier in this high-dimensional space with a linear decision boundary (hyperplane).
보충 — 내적

두 벡터 a = (a₁, …, aₚ), b = (b₁, …, bₚ)의 내적 ⟨a, b⟩ = a₁b₁ + ⋯ + aₚbₚ. 예: ⟨(1, 2), (3, 4)⟩ = 3 + 8 = 11. 두 벡터가 비슷한 방향일수록 크고, 수직이면 0입니다(5주차 1차시 11.4).

선형 SVM을 내적으로 쓰기

소프트 마진(선형) SVM의 결정함수는 다음처럼 쓸 수 있다는 것이 알려져 있습니다(유도는 교안 범위 밖).

f(x) = β₀ + ∑i ∈ S αi ⟨x(i), x⟩

S는 서포트 벡터의 인덱스 집합, αi는 학습으로 정해지는 계수입니다. 새 점 x를 분류할 때 서포트 벡터들과의 내적만 계산하면 됩니다. 서포트 벡터가 아닌 점은 αi = 0이라 식에서 빠지므로, 05에서 "서포트 벡터만 경계를 결정한다"고 한 것이 식으로도 보입니다.

비선형 SVM은 이 내적을 커널로 바꿉니다.

f(x) = β₀ + ∑i ∈ S αi K(x(i), x)
보충 — 커널 트릭이 계산을 줄이는 원리 (2차 다항 커널, 2차원)

x = (x₁, x₂), x′ = (x₁′, x₂′)일 때 (1 + ⟨x, x′⟩)²를 전개하면 1 + 2x₁x₁′ + 2x₂x₂′ + x₁²x₁′² + x₂²x₂′² + 2x₁x₂x₁′x₂′입니다. 이것은 6차원 특징 φ(x) = (1, √2x₁, √2x₂, x₁², x₂², √2x₁x₂)끼리의 내적 ⟨φ(x), φ(x′)⟩과 정확히 같습니다. 즉 6차원 특징을 만들지 않고 2차원 내적 하나를 계산해 제곱하는 것으로 6차원 내적을 얻습니다. 15에서 특징 수가 폭발하던 문제를 이렇게 피합니다. 이것이 "암묵적으로(implicitly) 고차원으로 옮긴다"의 뜻입니다.

  • 커널 K = 내적의 일반화, 고차원 특징 공간의 내적을 그 특징을 만들지 않고 계산

서포트 벡터 회귀 (SVR)

SVM의 아이디어를 회귀에 쓴 것이 SVR(Support Vector Regression)입니다. 분류 SVM은 마진 안에 점이 없도록 하지만, SVR은 반대로 점들이 마진 띠(튜브) 안에 최대한 들어오도록 직선을 맞춥니다.

띠의 폭 ±ε 안에 있는 점은 오차를 0으로 보고, 띠 밖으로 벗어난 만큼만 손실로 셉니다. 띠 경계 위나 밖의 점이 서포트 벡터가 되어 직선을 결정합니다. 6주차 1차시 선형 회귀가 모든 점의 오차 제곱을 다 더한 것(RSS)과 다른 점입니다.

정리
  • 장점: C로 과적합 방지, 커널로 유연한 경계, 볼록 최적화 → 해가 하나
  • 단점: C·커널 조정 필요, 이진 분류 전용, 해석 어려움
  • 다중 클래스: 일대다(K개) / 일대일(K(K−1)/2개)
  • SVR: 점들이 마진 띠 안에 들어오도록 맞추는 회귀
