01

논리 — 결론을 올바르게 끌어내는 법칙

규칙기반 AI가 "판단한다"는 것은 사실과 규칙에서 결론을 끌어내는 일입니다.

논리는 사람의 사고가 객관적이고 명확한 사고 법칙을 지키는지 판단하는 기준입니다. 교재 그림 6.1의 "달걀이 먼저야! / 닭이 먼저라니까!"처럼, 논쟁에서는 주장의 논리성이 중요합니다.

AI 학자들은 이 논리를 규칙기반 인공지능에 적용했고, 논리는 AI에서 지식 표현과 추론의 도구로 쓰입니다.

규칙기반 AI = 사실 + 규칙 → 결론

지금의 사실+if–then 규칙→결론
if APPROVED then INSTALL
if QA       then CONFIG
if OK       then START

"승인되면 설치한다" — 사실(APPROVED)이 조건에 맞는 규칙을 찾아 실행

교안 그림의 세 줄이 규칙기반 AI가 지식을 담는 기본 형태입니다. 조건과 행동을 짝지은 규칙을 여러 개 모아 두고, 현재 상황이 조건에 맞는 규칙을 찾아 실행합니다.

이 if–then 형태가 바로 다음 장에서 배울 조건 명제 p → q입니다.

그래서 6장은 이 순서로 갑니다

논리는 탐색 방법, 문제 해결 알고리즘, 지식처리, 전문가 시스템 같은 응용의 기반 지식입니다. 6장은 이 순서를 그대로 따라갑니다.

02

명제와 논리 연산

컴퓨터가 논리를 다룰 수 있는 이유: 참·거짓을 기계적으로 계산할 수 있어서

논리의 가장 작은 단위는 명제입니다. 명제 여러 개를 연산자로 묶어 더 복잡한 문장(합성 명제)을 만들고, 그 참/거짓을 계산하는 것이 명제 논리입니다.

문장 전체의 참/거짓을 따지면 명제 논리, 문장을 주어와 술어로 나눠 따지면 술어 논리(03)입니다.

이산수학의 명제 논리와 같은 내용입니다. 이산수학은 부정을 ¬p로, 교재는 ~p로 씁니다.

명제 = 참·거짓이 하나로 정해지는 문장

명제 ○
"2 × 7의 값은 홀수다."

틀린 말이지만 누구나 거짓이라고 판단 → 명제

명제 ×
"사과는 맛있다."

사람마다 판단이 다름 → 명제가 아님

기준은 "참인가"가 아니라 "참/거짓이 하나로 정해지는가"입니다. 거짓인 문장도 명제입니다.

둘 이상의 명제를 묶은 것은 합성 명제(compound proposition)라고 합니다.

논리 연산 4가지 — 예외 한 줄만 기억하면 됩니다

~p부정 · not참·거짓을 뒤집는다
p ∨ q논리합 · or둘 다 F일 때만 F
p ∧ q논리곱 · and둘 다 T일 때만 T
p → q조건 · if–thenp = T, q = F일 때만 F

p와 q는 각각 T/F 두 값을 가지므로 조합은 4줄입니다. 각 연산마다 예외인 한 줄만 외우면, 나머지 줄은 모두 그 반대입니다.

  • 논리합(∨): 하나만 T여도 T → 둘 다 F인 줄만 F
  • 논리곱(∧): 둘 다 T여야 T → 둘 다 T인 줄만 T
  • 조건(→): p가 T, q가 F인 줄만 F

진리표로 보면

pqp ∨ qp ∧ qp → q
TTTTT
TFTFF
FTTFT
FFFFT

노란 칸이 각 연산의 예외 한 줄

교재 〈표 6.2〉 논리합, 〈표 6.3〉 논리곱, 〈표 6.4〉 조건을 한 표로 합쳤습니다. 노란 칸 하나씩만 기억하면 나머지 칸은 그 반대입니다.

조건 p → q: 가정이 거짓이면 늘 참

"3 × 2 = 5라면, 런던은 미국의 수도이다."

F → F  =  T

p → q가 깨지는 경우는 "p가 참인데 q가 거짓"뿐 — p가 거짓이면 이 규칙이 말하는 상황이 아니라서 틀렸다고 할 수 없음

둘 다 틀린 말인데 결과가 T라서 가장 헷갈리는 부분입니다.

p → q는 "p가 참인 경우에는 q도 참이다"라는 주장입니다. 이 주장이 틀렸다고 확인되는 경우는 p가 참인데 q가 거짓인 경우 하나뿐입니다. p가 거짓이면 주장이 다루는 상황이 아니므로 T로 둡니다.

이산수학에서는 p를 전건(hypothesis), q를 후건(conclusion)이라 부릅니다.

예문은 3단계로 풉니다

"유채꽃이 노랗다면, 바다가 육지이다."

  1. 부분 명제마다 참·거짓   유채꽃이 노랗다 = T, 바다가 육지 = F

  2. 연결어를 기호로   "~라면" = →   즉 T → F

  3. 진리표에서 찾기   → F

연결어 바꾸기: "~이거나" = ∨, "~이고" = ∧, "~라면" = →

교안의 다른 예문

  • "사과는 채소이거나, 시금치는 채소이다." F ∨ T = T
  • "사과는 과일이고, 시금치는 채소이다." T ∧ T = T
  • "서울은 대한민국의 수도이고, 3 × 2 = 5이다." T ∧ F = F
교수님 말씀
교안 표 6.4의 머리글 "~p → q"는 오류입니다. p → q가 맞습니다.

수업에서 직접 짚어 주신 교안 오류입니다. 이 시안의 진리표는 p → q로 고쳐 두었습니다.

03

술어 논리

문장을 대상과 술어로 쪼개서 참·거짓을 따집니다.

이산수학의 술어 P(x)와 같은 개념입니다.

명제 논리로는 공통점을 못 적습니다

"영철이는 남자다."

= p

"민수는 남자다."

= q

둘 다 "남자"라는 같은 성질인데, 명제 논리에서는 서로 다른 기호 p, q일 뿐

명제 논리는 문장 전체를 기호 하나로 봅니다. 그래서 두 문장이 같은 성질을 말한다는 사실을 표현할 방법이 없습니다. 술어 논리는 이 문제를 풀기 위해 문장을 쪼갭니다.

괄호 밖은 술어, 괄호 안은 대상

남자(영철)
"영철이는 남자다"
대상 하나 → 성질
아버지(김춘추, 영철)
"영철의 아버지는 김춘추 씨다"
대상 둘 → 관계

대상이 두 개인 술어로는 대상들 사이의 관계도 나타낼 수 있습니다.

대상 자리에 x를 두면 규칙 하나로 여럿을 다룹니다

남자(x)

x에 누가 들어가느냐에 따라 T/F가 달라짐 → 그 자체로는 명제가 아님 (x² + 5x + 6 = 0도 x = −2, −3일 때만 T)

사람(x) → 죽는다(x)

"모든 사람은 죽는다"를 규칙 하나로 → 08의 소크라테스 예제

이렇게 쪼개 두면 "모든 사람은 죽는다"를 "x가 사람이면 x는 죽는다"라는 규칙 하나로 적고, 여러 사람에게 적용할 수 있습니다. 08 전문가 시스템의 소크라테스 예제가 바로 이 형태입니다.

여기까지 정리

  • 규칙기반 AI = 사실 + if–then 규칙 → 결론
  • 명제 = 참·거짓이 하나로 정해지는 문장 (거짓이어도 명제)
  • 예외 한 줄: ∨ 둘 다 F만 F · ∧ 둘 다 T만 T · → p = T, q = F만 F
  • 술어 논리 = 술어(대상) — 남자(영철), 아버지(김춘추, 영철)
