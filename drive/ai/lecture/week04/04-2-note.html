02교수님이 짚은 포인트 시험 직결

교수님 말씀 · 교안 오류

교안 〈표 6.4〉의 머리글 "~p → q"는 오류입니다. p → q가 맞습니다.

교수님 말씀 · 포함 관계

생성형 AI(generative AI)는 딥러닝 안에 들어가는 영역입니다. → AI ⊃ 기계학습 ⊃ 딥러닝 ⊃ 생성형 AI. 교안 그림에는 없고 수업에서 덧붙이신 내용입니다.

교수님 말씀 · 일반화

새로 들어오는 데이터를 처리할 수 있게 하는 것을 기계학습의 일반화(generalization)라고 합니다. 기계학습을 쓰는 이유 ③ 변화하는 환경(Fluctuating environments)을 설명하시며 언급하셨습니다.

교수님 말씀 · 용어

"Learning" in Machine Learning의 Induction을 추론이라고 부르셨습니다. 6장의 귀납 추론(induction)과 같은 개념입니다.

교수님 말씀 · 온라인 학습

배치 학습에 비해 온라인 학습이 좋은 이유는 더 빠르다는 것입니다. 교안 표현으로는 "Each learning step is faster and cheaper"(학습 단계 하나하나가 더 빠르고 더 저렴하다)입니다.

수업 범위 (필기)

이 차시는 Introduction to Machine Learning 교안의 배치·온라인 학습(교안 p.22)까지 진행했고, 그다음(사례 기반 학습부터)은 5주차 1차시에 이어서 했습니다.

주의 · 교수님 말씀이 아닌 것

참고 영상 2개(아틀라스, 메타 뮤즈)는 수업 시간에 보지 않았습니다. "시험 범위가 아닐 것"은 필기자의 추측이며 교수님이 하신 말씀은 아닙니다.

03반드시 외울 정의 시험 직결

Part 1 · 6장 규칙기반 인공지능

논리의 활용Logic in AI
규칙기반 인공지능에 이론적 기반을 제공하며, AI에서 지식 표현이나 추론(inference)의 도구로 쓰입니다.
명제Proposition
명확하게 참(T)/거짓(F)을 구분할 수 있는 문장이나 식입니다. 거짓인 문장("2 × 7의 값은 홀수다")도 명제이고, "사과는 맛있다"는 참/거짓이 구분되지 않아 명제가 아닙니다.
합성 명제Compound proposition
둘 이상의 명제가 결합된 명제입니다.
명제 논리 · 술어 논리Propositional / Predicate logic
명제 논리는 문장 전체의 참/거짓을 판별하는 법칙을, 술어 논리는 문장을 주어와 술어로 구분하여 참/거짓 법칙을 다룹니다. 술어 논리는 대상들 간의 관계도 나타낼 수 있습니다(예: 아버지(김춘추, 영철)).
추론Inference
알려진 사실이나 명제를 근거로 삼아 미지의 사실에 대한 판단이나 결론을 이끌어내는 사고 과정입니다. 추론에 주로 쓰이는 프로그래밍 언어는 Prolog입니다.
귀납 추론Induction
개별적인 사실들로부터 일반적인 결론을 이끌어내는 방법입니다. 연역보다 논리적 필연성이 적지만, 새로운 지식이나 이론의 발견과 확장에 쓰입니다.
연역 추론Deduction
전제로부터 다른 결론을 도출해내는 추론 방식으로, 가장 널리 쓰입니다. 최초의 대전제가 가장 중요한 근거이며, 확장성은 부족하나 논리의 일관성이 장점입니다(예: 삼단논법).
유비 추론Analogy
'유추'라고도 합니다. 두 대상에서 어떤 현상이 유사하거나 일치하기 때문에 다른 현상도 유사하거나 일치할 것이라고 추론하는 방법으로, 모르던 새로운 영역 이해에 도움이 됩니다.
순방향 · 역방향 · 양방향 추론Forward / Backward / Bidirectional
순방향은 출발 상태 → 목표 상태, 역방향은 목표 상태 → 출발 상태로 진행합니다. 양방향은 둘을 접합한 것입니다.
깊이 우선 탐색Depth-First Search, DFS
첫 정점을 방문한 뒤 왼쪽으로 이동하며 계속 탐색하고, 탐색할 정점이 없으면 되돌아와서 순환적으로 탐색합니다.
너비 우선 탐색Breadth-First Search, BFS
시작 정점 방문 후 시작 정점과 연결된 모든 정점을 왼쪽부터 차례로 방문하고, 그 후 level 0, 1, 2, … 순서로 탐색합니다.
무정보 탐색Uninformed search
사전 정보를 사용하지 않고 일정한 순서대로만 탐색합니다. DFS와 BFS는 무정보 탐색입니다.
휴리스틱 탐색Heuristic search
탐색 과정에서 경험적 지식을 활용하는 탐색입니다(최상 우선 탐색, 분기 한정 탐색, A*, 언덕 오르기, 빔 탐색 등).
최소최대 탐색Minimax search
주로 상대가 있는 2인용 게임(예: 틱택토)에서, 나의 가능성은 최대, 상대방의 가능성은 최소로 하는 전략을 탐색합니다. 탐색이 필요 없는 경로를 잘라내는 작업을 전지 작업(pruning)이라 합니다.
알고리즘Algorithm
문제 해결을 위한 단계들을 체계적으로 명시한 것, 문제를 해결하는 방법의 상세한 특징을 기술하는 것입니다. 순서도·유사 코드·언어적 표현으로 나타내며, 단 하나만 있는 것이 아닙니다.
휴리스틱Heuristic
비슷한 문제에 대한 과거의 경험들을 바탕으로 직관적으로 판단하여 선택하는 의사결정 방식입니다. 논리적이거나 최적의 방법을 보장하지는 않지만, 만족할 만한 해결책을 비교적 빠르게 찾는 실용적인 방법입니다.
A* 알고리즘A* algorithm
최상 우선 탐색 중 가장 잘 알려진 방법으로, 출발점에서 목표지점까지 최적 경로(가장 비용이 적거나 짧은 경로)를 찾습니다. 평가 함수 f를 사용하여 다음에 이동할 경로를 결정합니다.
8-Queens 문제8-Queens problem
체스에서 유래한 문제로, 서로를 공격하지 않는 위치에 8개의 퀸을 배치합니다. 경우의 수는 약 44억 가지이며 해답은 여러 개입니다.
의미 네트워크Semantic network
개념 간의 관계를 링크(link)로 연결한 것으로(예: 개–세퍼드, 개–진돗개), 지식을 체계화시켜 표현하기에 적합합니다.
규칙기반 시스템Rule-based system
사실(fact)을 나타내는 지식베이스와 "If ooo then xxx" 형태의 추론규칙으로 이루어지며, 질의에 대해 둘을 이용하여 추론한 후 결과를 알려줍니다.
전문가 시스템Expert System
컴퓨터 자문 시스템의 일종으로, 특정 분야 인간 전문가의 전문 지식과 인공지능의 추론 능력을 이용한 문제 해결 시스템입니다. 지식베이스를 구축하고, 사용자가 질문하면 추론기구가 지식베이스를 이용하여 추론해 결과를 전합니다.

Part 2 · Introduction to Machine Learning

인공지능 · 기계학습 · 딥러닝AI / ML / DL
인공지능: 사람이 하던 일을 기계가 수행하는 모든 자동화. 기계학습: 규칙을 명시적으로 프로그래밍하지 않아도 기계가 데이터에서 의사결정용 패턴을 학습. 딥러닝: 신경망 기반 모델로 비정형 데이터에서 특징 추출과 의사결정을 한 번에(end to end) 수행.
기계학습 (Samuel, 1959)Machine Learning
컴퓨터가 명시적으로 프로그래밍되지 않고도 학습하는 능력을 갖게 하는 연구 분야입니다.
학습 (Mitchell, 1997)Learn from experience E
어떤 작업 T에 대한 프로그램의 성능을 P로 측정했을 때, 경험 E로 인해 성능이 향상되면 그 프로그램은 작업 T와 성능 지표 P에 대해 경험 E로부터 학습한다고 말합니다.
일반화Generalization
새로 들어오는 데이터를 처리할 수 있게 하는 것(교수님). 정확히는 학습에 쓰지 않은 같은 종류의 새 데이터에서도 모델이 잘 동작하는 능력입니다 보충.
추론(귀납)Induction
특정한 예시들의 집합에서 일반적인 규칙을 뽑아내는 과정입니다.
학습Learning
데이터를 분석하고 거기서 자동으로 정보를 추출하는 컴퓨터 모델을 만드는 것입니다. 데이터에 대한 좋고 쓸모 있는 근사(approximation)인 모델을 만듭니다.
지도 학습Supervised Learning
관측값 {xt}와 함께 목표 출력 {yt}가 주어집니다 → {(xt, yt)}. 훈련 데이터에 원하는 답, 즉 라벨(label)이 포함됩니다.
분류 · 회귀Classification / Regression
지도 학습에서 분류는 이산적인 라벨(discrete label)을, 회귀는 연속적인 수(continuous number, 목표 수치)를 예측합니다.
비지도 학습Unsupervised Learning
목표 출력이 주어지지 않습니다 → {xt}. 훈련 데이터에 라벨이 없고, 시스템은 교사나 감독 없이 학습하려고 합니다.
군집Cluster
서로 '비슷한' 객체들의 모임이며, 다른 군집에 속한 객체와는 '비슷하지 않은' 집합입니다.
t-SNEt-distributed Stochastic Neighbor Embedding
데이터의 국소 구조(local structure)를 보존하면서 고차원 데이터를 2차원이나 3차원으로 줄여 시각화하는 데 쓰입니다.
차원 축소Dimension Reduction
고차원 데이터를 데이터의 본질을 담는 더 낮은 차원의 부분공간(lower dimensional subspace)으로 투영(projecting)해 차원을 줄이는 것입니다.
이상치 탐지Outlier (Anomaly) Detection
대다수 데이터에서 크게 벗어난 관측값이나 데이터 포인트를 찾아내는 과정입니다.
강화 학습Reinforcement Learning
지도 출력은 없고 지연된 보상(delayed reward)이 있습니다. 학습 시스템인 에이전트가 환경을 관찰하고 행동을 골라 수행하며 보상/벌점을 받고, 시간에 따라 보상을 최대화하는 최선의 전략인 정책(policy)을 스스로 학습합니다.
배치 학습Batch Learning
점진적으로 학습할 수 없어 가용한 데이터 전부로 훈련해야 합니다. 시간과 자원이 많이 들어 보통 오프라인에서 수행하며, 훈련 후 운영에 투입되면 더 학습하지 않고 배운 것만 적용합니다(= 오프라인 학습).
온라인 학습Online Learning
데이터를 미니배치로 나눠 순차적으로 모델에 공급합니다. 학습 단계 하나가 더 빠르고 저렴해 새 데이터를 점진적으로 반영할 수 있으며, 데이터가 연속적으로 들어오고 변화에 빨리 적응해야 하는 시스템에 좋습니다.
외부 메모리 학습Out-of-core learning
온라인 학습 알고리즘으로 한 컴퓨터의 주기억장치에 들어가지 않는 거대한 데이터셋을 학습하는 것입니다. 데이터 일부를 불러와 훈련 단계를 수행하고 전체를 다 돌 때까지 반복합니다(점진적 학습, incremental learning).

04공식과 절차 시험 직결

진리표 — 예외 한 줄만 외운다

pq~pp ∨ qp ∧ qp → q
TTFTTT
TFFTFF
FTTTFT
FFTFFT
  • 논리합 ∨: 두 명제가 모두 F인 경우에만 F
  • 논리곱 ∧: 두 명제가 모두 T인 경우에만 T
  • 조건 →: p가 T이고 q가 F일 때만 F, 그 외 모두 T. 가정이 F이면 결론은 항상 T
  • 읽는 법: ~p "p가 아니다(not p)", p ∨ q "p 또는 q", p ∧ q "p 그리고 q", p → q "p이면 q이다(if p, then q)"

예문의 진리값 구하기 (3단계)

  1. 부분 명제마다 T/F를 정합니다.
  2. 연결어를 기호로 바꿉니다: "~이거나" = ∨, "~이고" = ∧, "~라면" = →.
  3. 진리표에서 해당 줄을 찾습니다.

교안 예문: "유채꽃이 노랗다면, 바다가 육지이다" T → F = F · "3 × 2 = 5라면, 런던은 미국의 수도이다" F → F = T · "사과는 채소이거나, 시금치는 채소이다" F ∨ T = T · "서울은 대한민국의 수도이고, 3 × 2 = 5이다" T ∧ F = F

술어 논리 표기

술어(대상)  →  남자(영철) · 아버지(김춘추, 영철) · 사람(x) → 죽는다(x)괄호 밖이 술어(성질·관계), 괄호 안이 대상. 대상 둘이면 관계. x처럼 변수가 있으면 변수 값에 따라 T/F가 정해집니다(예: x2 + 5x + 6 = 0은 x = −2 또는 −3일 때만 T).

삼단논법 (연역 추론의 예)

소크라테스는 사람이다 · 사람은 모두 죽는다 · ∴ 소크라테스는 죽는다두 전제가 참이면 결론은 반드시 참(연역의 필연성).
주의 · 교안과 일반 정의가 다름 (미해결)

교안은 "대전제 - 소크라테스는 사람이다 / 소전제 - 사람은 모두 죽는다"로 적혀 있습니다. 일반적인 삼단논법은 대전제 = 일반 규칙(사람은 모두 죽는다), 소전제 = 개별 사실(소크라테스는 사람이다)입니다. 교수님 확인 전이므로, 답안에 대전제·소전제를 쓸 때는 문장 내용을 함께 적어 어느 기준인지 드러나게 쓰는 편이 안전합니다.

DFS · BFS 방문 순서 구하기

  1. DFS: 루트 방문 → 왼쪽 자식으로 계속 내려감 → 더 갈 정점이 없으면 되돌아와 다음 자식으로. (구현: 스택 또는 재귀) 보충
  2. BFS: 루트 방문 → 연결된 정점을 왼쪽부터 모두 → level 1, level 2 … 순서. (구현: 큐) 보충

전문가 시스템의 동작

  1. 전문가의 지식을 정리하여 지식베이스부터 구축합니다.
  2. 사용자가 질문합니다.
  3. 추론기구가 지식베이스(사실 + 규칙)를 이용하여 추론합니다.
  4. 결과를 사용자에게 전해 줍니다.

소크라테스 예: 사실 "Socrates is a human" + 규칙 "If X is a human, then X dies" → "Is Socrates die?"에 Yes. "Tell me what dies?" → Socrates, Daesukim, wurry. 김대수·워리가 죽는다는 사실은 지식베이스에 직접 없고 추론으로 만들어집니다.

기계학습 시스템의 분류 기준 3가지

  1. 사람의 감독을 받으며 훈련하는가 → 지도 · 비지도 · 준지도 · 강화 학습
  2. 실시간으로 점진적 학습이 가능한가 → 온라인 학습 vs 배치 학습
  3. 새 데이터를 알려진 데이터와 단순 비교하는가, 패턴을 찾아 예측 모델을 만드는가 → 사례 기반 vs 모델 기반 학습

강화 학습 6단계

  1. 관찰 Observe
  2. 정책으로 행동 선택 Select action using policy
  3. 행동 Action!
  4. 보상 또는 벌점 받기 Get reward or penalty (교안 예: 불에 닿아 −50점)
  5. 정책 갱신 Update policy (learning step)
  6. 최적이 될 때까지 반복 Iterate until optimal policy is found

기계학습을 쓰는 이유 4가지

  1. 기존 해법이 수작업 조정이나 긴 규칙 목록을 필요로 하는 문제 — ML 알고리즘 하나로 코드를 단순화하고 성능도 좋게
  2. 전통적 방식으로는 좋은 해법이 전혀 없는 복잡한 문제
  3. 변화하는 환경 — 새 데이터에 적응 (교수님: 일반화)
  4. 복잡한 문제와 대량의 데이터에서 통찰 얻기

06그림으로 기억 자주 나옴

  • 세 원의 포함 관계와 각 정의를 말할 수 있어야 합니다.
  • 전문가 시스템은 AI이지만 기계학습은 아닙니다(규칙을 사람이 작성). 보충
  • 다른 칸: 전통 = 규칙 작성(Write rules), ML = ML 알고리즘 훈련(Train ML algorithm) + 데이터 입력.
  • 평가 → 불만족이면 오류 분석 후 반복하는 구조는 두 방식이 같습니다.
  • 화살표 방향: 환경 → 관찰·보상 → 에이전트, 에이전트 → 행동 → 환경.
  • 에이전트가 학습하는 것은 보상을 최대화하는 정책입니다.
  • 새 데이터(실시간으로 유입)가 들어와 운영 중에도 계속 학습(Run and learn)한다는 점이 배치 학습과 다릅니다.

07함정 O/X 시험 직결

  1. "2 × 7의 값은 홀수다."는 거짓이므로 명제가 아니다.X — 참/거짓이 명확히 정해지면 거짓이어도 명제입니다.
  2. p → q는 p가 F이고 q가 T일 때 F이다.X — p가 T이고 q가 F일 때만 F입니다.
  3. "3 × 2 = 5라면, 런던은 미국의 수도이다."의 진리값은 T이다.O — F → F이므로 T. 가정이 F이면 결론은 항상 T입니다.
  4. p ∨ q는 두 명제가 모두 T일 때만 T이다.X — 그것은 논리곱 ∧. 논리합은 둘 다 F일 때만 F입니다.
  5. 귀납 추론은 연역 추론보다 논리적 필연성이 크다.X — 귀납은 필연성이 적고, 대신 새 지식의 발견·확장에 쓰입니다.
  6. 연역 추론은 확장성이 부족하지만 논리의 일관성이 장점이다.O — 교안 그대로입니다.
  7. DFS와 BFS는 휴리스틱 탐색이다.X — 사전 정보 없이 일정한 순서로 탐색하는 무정보 탐색입니다.
  8. 역방향 추론은 출발 상태에서 목표 상태로 진행한다.X — 목표 상태 → 출발 상태. 출발 → 목표는 순방향입니다.
  9. 휴리스틱은 최적의 방법을 보장한다.X — 보장하지 않지만 만족할 만한 해결책을 비교적 빠르게 찾습니다.
  10. 최소최대 탐색은 나의 가능성은 최대, 상대방의 가능성은 최소로 하는 전략을 탐색한다.O — 필요 없는 경로를 잘라내는 작업은 전지 작업(pruning)입니다.
  11. 전문가 시스템은 지식베이스와 추론기구로 질문에 답한다.O — 추론기구가 지식베이스를 이용해 추론합니다.
  12. 교수님 설명에 따르면 딥러닝은 생성형 AI 안에 포함된다.X — 반대. 생성형 AI가 딥러닝 안에 들어갑니다.
  13. 비지도 학습의 훈련 데이터는 {(xt, yt)}이다.X — 그것은 지도 학습. 비지도는 {xt}입니다.
  14. 회귀는 이산적인 라벨을, 분류는 연속적인 수를 예측한다.X — 반대. 분류 = 이산적 라벨, 회귀 = 연속적인 수.
  15. 배치 학습은 운영에 투입된 뒤에도 새 데이터로 계속 학습한다.X — 운영 중에는 더 학습하지 않고 배운 것만 적용합니다(오프라인 학습).

08연습 문제 자주 나옴

이 차시 교안(6장, Introduction to Machine Learning p.1–22)에는 퀴즈가 없습니다. 아래는 덱의 예상 문제와 계산·서술 연습입니다.

1. 조건 명제 p → q가 거짓(F)이 되는 경우는?

① p = T, q = T   ② p = T, q = F   ③ p = F, q = T   ④ p = F, q = F

풀이 보기
②. 조건 명제는 가정이 참인데 결론이 거짓일 때만 F입니다. ③·④는 가정이 F이므로 q와 관계없이 T입니다.
2. p = T, q = F일 때 다음 진리값을 구하시오. (가) ~p → q   (나) (p ∨ q) → (p ∧ q)
풀이 보기
(가) ~p = F이므로 F → F = T. (교안 〈표 6.4〉 머리글 오류 "~p → q"와 p → q는 다른 식임을 보여 줍니다.)
(나) p ∨ q = T, p ∧ q = F이므로 T → F = F.
3. "유채꽃이 노랗다면, 바다가 육지이다."의 진리값과 이유를 쓰시오.
풀이 보기
"유채꽃이 노랗다" = T, "바다가 육지이다" = F. "~라면"은 →이므로 T → F = F입니다. 조건 명제는 가정이 T이고 결론이 F일 때만 F이기 때문입니다.
4. 루트 A의 자식이 B, C이고, B의 자식이 D, E, C의 자식이 F이다. 왼쪽 자식부터 방문할 때 DFS와 BFS의 방문 순서를 쓰시오.
풀이 보기
DFS: A → B → D → E → C → F (한 갈래를 끝까지 간 뒤 되돌아옴)
BFS: A → B → C → D → E → F (level 0 → 1 → 2 순서)
5. 다음 중 귀납 추론에 해당하는 것은?

① 사람은 모두 죽는다. 소크라테스는 사람이다. 따라서 소크라테스는 죽는다.
② 관찰한 까마귀 100마리가 모두 까맣다. 따라서 모든 까마귀는 까맣다.
③ 양말이 발에 신는 것이듯, 장갑은 손에 끼는 것이다.
④ p → q이고 q → r이므로 p → r이다.

풀이 보기
②. 개별 사실들에서 일반적인 결론을 이끌어냈으므로 귀납입니다. ①·④는 연역(④는 가언적 삼단논법), ③은 유비 추론입니다.
6. 8-Queens 문제에서 64칸에 퀸 8개를 놓는 경우의 수는 약 몇 가지인가?
풀이 보기
약 44억 가지(교안). 계산 근거 보충: 64C8 = 4,426,165,368. 해답은 하나가 아니라 여러 개입니다.
7. (서술) 전문가 시스템을 이루는 핵심 요소 두 가지와 각각의 역할을 쓰시오.
모범 답안 보기
지식베이스는 전문가의 지식을 정리해 사실과 If–then 규칙 형태로 저장합니다. 추론기구(inference engine)는 사용자가 질문하면 지식베이스의 사실과 규칙을 이용하여 추론하고, 그 결과를 사용자에게 전해 줍니다.
8. (서술) Tom Mitchell의 기계학습 정의를 E, T, P를 사용해 쓰시오.
모범 답안 보기
어떤 작업 T에 대한 프로그램의 성능을 P로 측정했을 때, 경험 E로 인해 성능이 향상되면 그 프로그램은 작업 T와 성능 지표 P에 대해 경험 E로부터 학습한다고 말합니다. (E: experience, T: task, P: performance measure)
9. (서술) 지도·비지도·강화 학습을 학습 데이터의 형태로 구분하고, 배치 학습에 비해 온라인 학습이 갖는 장점을 쓰시오.
모범 답안 보기
지도 학습은 입력과 정답(라벨)의 쌍 {(xt, yt)}, 비지도 학습은 입력만 {xt}, 강화 학습은 정답 없이 행동 후 받는 지연된 보상으로 학습합니다. 온라인 학습은 데이터를 미니배치로 나눠 순차적으로 학습하므로 학습 단계 하나가 빠르고 저렴해, 새 데이터를 빠르게 반영하고 변화에 빨리 적응할 수 있습니다.
10. (서술) 교수님이 말씀하신 기계학습의 일반화를 설명하고, 기계학습을 쓰는 이유 중 어느 것과 관련되는지 쓰시오.
모범 답안 보기
일반화는 새로 들어오는 데이터를 처리할 수 있게 하는 것, 즉 학습에 쓰지 않은 새 데이터에서도 모델이 잘 동작하는 능력입니다. 기계학습을 쓰는 이유 중 ③ 변화하는 환경(새 데이터에 적응)과 관련됩니다.
