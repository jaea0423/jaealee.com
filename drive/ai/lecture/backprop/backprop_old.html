미리 짚고 갈 개념 ② — 합성 함수와 미분 규칙

합성 함수(composite function): 한 함수의 출력이 다른 함수의 입력이 되는 것. 예: t = x + y를 먼저 계산하고, 그 t로 z = t2을 계산하면 z = (x + y)2은 x, y의 합성 함수입니다(→ 04).

신경망도 합성 함수입니다. 입력 → Affine → 활성화 함수 → Affine → … → 소프트맥스 → 손실처럼 함수를 차례로 거쳐 손실 L이 나옵니다.

이 교안의 표기: exp(x) = ex (e ≈ 2.718). exp(−x) = e−x. log는 자연로그(밑 e)입니다(P2와 같음).

미리 짚고 갈 개념 ③ — 행렬 곱의 모양과 axis 0 합

행렬 곱의 모양 규칙: (a × b) · (b × c) → (a × c). 앞 행렬의 열 수와 뒤 행렬의 행 수(가운데 b)가 같아야 곱할 수 있고, 결과는 바깥 두 수의 모양입니다.

(2,) · (2, 3)(3,)
(N, 2) · (2, 3)(N, 3)
(3, 2) · (2, 3)(3, 3)

(2,)는 numpy 표기로 원소 2개짜리 1차원 배열입니다. 교안 13–14쪽이 이 표기를 씁니다(→ 12–13). 전치(ᵀ)는 행과 열을 맞바꿉니다: (2, 3)T = (3, 2) (P2 미리 짚을 개념 ③).

Part 1 — 계산 그래프 (교안 2–4쪽)

1단계 — 노드와 에지, 국소적 계산

계산 그래프는 계산 과정을 노드(연산)와 에지(값이 흐르는 선)로 나타냅니다. 사과 2개·귤 3개·소비세 1.1이면 200 + 450 = 650 → × 1.1 = 715. 각 노드는 자기와 직접 연결된 정보만으로 출력을 냅니다. → 01–02

2단계 — 역전파로 미분 구하기

오른쪽 끝에서 1로 시작해 1 → 1.1 → 2.2. 사과 가격에 대한 지불 금액의 미분 ∂L∂x = 2.2입니다. 역전파 한 번으로 모든 입력의 미분이 나옵니다. → 03

Part 2 — 연쇄 법칙과 덧셈·곱셈 노드 (교안 5–8쪽)

3단계 — 연쇄 법칙 = 계산 그래프의 역전파

합성 함수의 미분 = 각 함수 미분의 곱. z = t2, t = x + y → ∂z∂x = 2t · 1 = 2(x + y). 그래프에서는 오른쪽에서 온 값에 국소적 미분을 곱해 왼쪽으로 보냅니다. 덧셈 노드는 그대로, 곱셈 노드는 서로 바꾼 입력을 곱합니다. → 04–07

Part 3 — 활성화 함수 계층 (교안 9–12쪽)

4단계 — ReLU와 시그모이드

ReLU는 순전파 때 x > 0이었으면 상류 값을 그대로, x ≤ 0이었으면 0을 보냅니다. 시그모이드는 네 노드(× (−1) → exp → + 1 → 나눗셈(/))로 쪼개 역전파하면 ∂L∂y y2 exp(−x) = ∂L∂y y(1 − y). 순전파 출력 y만으로 계산합니다. → 08–11

Part 4 — Affine 계층과 Softmax-with-Loss 계층 (교안 13–17쪽)

5단계 — 행렬 곱의 역전파와 y − t

Y = XW + B의 역전파는 ∂L∂X = ∂L∂Y · WT, ∂L∂W = XT · ∂L∂Y. 전치와 순서는 "기울기 = 원래 값과 같은 모양"이 되도록 정해집니다. 배치면 ∂L∂B는 axis 0 합. 소프트맥스와 교차 엔트로피를 묶은 Softmax-with-Loss의 역전파는 y − t입니다. → 12–16

Part 5 — 학습 구현과 오차역전파의 장점 (교안 18–19쪽)

6단계 — 학습 4단계와 검증

학습 4단계는 P2 18과 같고, 그 2단계 기울기 계산에 오차역전파를 씁니다. 수치 미분은 느리지만 쉽고, 오차역전파는 빠르지만 복잡합니다. 수치 미분은 오차역전파가 맞는지 검증하는 데 씁니다(기울기 확인, gradient check — 교안에 없는 용어). P2 gradient()는 y − t(17쪽), XT · ∂L∂Y와 axis 0 합(14쪽), y(1 − y)(12쪽)의 조합입니다. → 17–19

01계산 그래프란교안 2쪽

Computational Graph — A computation graph represents a computational process as a graph, where nodes and edges express the relationships.

계산 그래프(computational graph)는 계산 과정을 그래프로 나타낸 것입니다. 노드와 에지가 관계를 표현합니다.

04연쇄 법칙교안 5쪽

Chain Rule
교안 문장뜻
The chain rule describes the property of differentiation for a composite function (a function composed of multiple functions).연쇄 법칙(chain rule)은 합성 함수(여러 함수로 이루어진 함수)의 미분에 관한 성질입니다.
The derivative of a composite function can be expressed as the product of the derivatives of the functions that compose it.합성 함수의 미분은 그것을 이루는 각 함수의 미분의 곱으로 나타낼 수 있습니다.
z = t2
t = x + y   (1)
∂z∂x = ∂z∂t ∂t∂x   (2)
∂z∂t = 2t,   ∂t∂x = 1   (3)
∂z∂x = ∂z∂t ∂t∂x = 2t · 1 = 2(x + y)   (4)

교안 그대로: 식 번호 (1)은 t = x + y 줄에 붙어 있고 z = t2 줄에는 번호가 없습니다.

식 읽기: z는 x를 바로 받지 않고 t를 거칩니다(x → t → z). 그래서 "x가 z에 주는 영향" = "x가 t에 주는 영향(∂t∂x)" × "t가 z에 주는 영향(∂z∂t)"입니다. 식 (2)의 오른쪽에서 ∂t를 위아래로 지우면 ∂z∂x가 되는 꼴로 기억할 수 있습니다.

식 (1)–(4)를 한 줄씩

식하는 일
(1)합성 함수를 두 단계로 나눔: 먼저 t = x + y, 다음 z = t2
(2)연쇄 법칙: 구하려는 ∂z∂x = 두 단계 미분의 곱
(3)단계마다 따로 미분: t2을 t로 미분하면 2t, x + y를 x로 미분하면 1 (00 미리 짚을 개념 ②)
(4)곱하고 t = x + y를 다시 넣음: 2t · 1 = 2(x + y)

핵심: 복잡한 함수를 직접 미분하지 않고, 간단한 단계로 쪼개 각 단계의 미분만 구해 곱합니다. 계산 그래프의 노드 하나 = 이 단계 하나입니다(→ 05).

  • 상류 기울기(upstream gradient): 노드의 출력 쪽(오른쪽)에서 들어오는 값 용어

06덧셈 노드와 곱셈 노드의 역전파교안 7쪽

Backward Propagation: Addition & Multiplication

덧셈 노드 (+, addition node)

z = x + y이면 ∂z∂x = 1, ∂z∂y = 1. 그래서 들어온 ∂L∂z에 1을 곱해 양쪽에 보냅니다 → 들어온 값을 그대로 흘려보냄.

곱셈 노드 (×, multiplication node)

z = xy이면 ∂z∂x = y, ∂z∂y = x. 그래서 x 쪽에는 ∂L∂z · y, y 쪽에는 ∂L∂z · x → 입력을 서로 바꿔 곱함.

두 노드를 한 표로

곱셈 노드는 순전파 입력을 저장해야 합니다

역전파 때 상대편 입력값 x, y가 필요합니다. 그래서 곱셈 노드는 순전파 때 받은 x, y를 기억해 둡니다. 덧셈 노드는 1만 곱하므로 기억할 것이 없습니다.

  • 곱셈 노드는 x 쪽으로 ∂L∂z · x를 보낸다 → X (· y, 상대편)
  • 곱셈 노드의 역전파에는 순전파 입력값이 필요 없다 → X
정리

  • 곱셈 노드: 입력을 서로 바꿔 곱함(x 쪽 · y, y 쪽 · x). 그래서 순전파 입력을 기억해야 함

08ReLU 계층의 역전파교안 9쪽

Backward Propagation: ReLU Activation Function
교안식
ReLU의 정의 Definition of ReLUy = 0 (x ≤ 0),   y = x (x > 0) — P1 16의 max(0, x)
y를 x로 미분 The derivative of y with respect to x∂y∂x = 0 (x ≤ 0),   ∂y∂x = 1 (x > 0)

x > 0이면 y = x라서 기울기 1, x ≤ 0이면 y = 0(수평)이라서 기울기 0입니다. x = 0에서는 원래 미분할 수 없지만 교안은 x ≤ 0 쪽(0)에 넣었습니다.

그림 읽기: 첫 그림(x > 0)은 들어온 빨간 ∂L∂y가 왼쪽에도 그대로 ∂L∂y로 나갑니다. 둘째 그림(x ≤ 0)은 같은 값이 들어와도 왼쪽으로 0이 나갑니다. → 순전파 때 x ≤ 0이었던 자리는 역전파 신호가 0이 되어 그 앞으로 전해지지 않습니다.

구현: 순전파 때 x ≤ 0인 자리를 기억해 둔다 책 기준

역전파에서 "그대로냐 0이냐"는 순전파 때의 x로 정해집니다. 그래서 참고서의 ReLU 계층은 순전파 때 x ≤ 0인 자리를 True로 표시한 배열 mask를 저장해 두고, 역전파 때 그 자리를 0으로 만듭니다.

PythonReLU 계층의 mask (보충, 참고서 방식 요약)
# 순전파
mask = (x <= 0)
out = x.copy();  out[mask] = 0
# 역전파
dx = dout.copy();  dx[mask] = 0

dout = 상류 기울기 ∂L∂y, dx = 하류 기울기 ∂L∂x. 교안에는 코드가 없습니다(참고서 『밑바닥부터 시작하는 딥러닝 1』의 구현 방식을 요약).

12Affine 계층 — 행렬 곱 + 편향을 한 계층으로교안 13쪽

Affine Layer — During the forward pass of a neural network, the matrix multiplication operation corresponds to an affine transformation in geometry. Refer to the component that performs this affine transformation as the affine layer.

신경망 순전파의 행렬 곱 연산은 기하학의 아핀 변환(affine transformation)에 해당합니다. 이 아핀 변환을 수행하는 부분을 Affine 계층이라고 부릅니다.

Y = X · W + B

P1에서 본 a = xW + b(→ P1 18)와 같은 식입니다. 지금까지는 식으로만 썼고, 이 교안은 이것을 계산 그래프의 노드 두 개(dot, +)로 그립니다. 기하학에서 아핀 변환 = 선형 변환(행렬 곱) + 평행 이동(편향 더하기). 교안 문장은 행렬 곱만 말하지만 그림에는 + B까지 들어 있습니다(→ 21).

왜 전치가 붙나 — 기울기는 원래 값과 모양이 같아야 함

∂L∂X는 X의 원소 하나하나에 대한 편미분을 모은 것이므로 X와 모양이 같습니다. W도 마찬가지입니다(→ P2 17). 모양만 맞춰 보면 식의 순서와 전치가 저절로 정해집니다.

구할 것목표 모양모양 계산
∂L∂X(2,) = X∂L∂Y (3,) · WT (3, 2) → (2,)
∂L∂W(2, 3) = WXT (2, 1) · ∂L∂Y (1, 3) → (2, 3)
∂L∂B(3,) = B∂L∂Y 그대로 (3,)

행렬 곱 (a, b) · (b, c) → (a, c): 앞의 열 수와 뒤의 행 수가 같아야 곱할 수 있습니다. W (2, 3)를 그대로 곱하면 (3,) · (2, 3)이 되어 곱할 수 없으므로 WT (3, 2)를 씁니다.

반대로 쓰면 틀리는 식

  • ∂L∂W = ∂L∂Y · XT → X (결과가 (3, 2)로 W와 모양이 다름)
  • "∂L∂W는 WT와 모양이 같다" → X (W와 같음)

X를 1차원 (2,)로 적으면 XT도 (2,)라 행렬 곱이 정의되지 않습니다. 위 표처럼 X를 1 × 2 행렬로 보면 XT가 2 × 1이 되어 식이 성립합니다(→ 21).

Batch Affine

입력이 X (2,) 하나가 아니라 N개를 쌓은 X (N, 2)입니다(P1 배치 처리, → P1 23). 빨간 식 위의 괄호가 각 항의 모양입니다.

식모양
∂L∂X = ∂L∂Y · WT(N, 3) · (3, 2) → (N, 2) = X
∂L∂W = XT · ∂L∂Y(2, N) · (N, 3) → (2, 3) = W
∂L∂B(N, 3)을 axis 0으로 합 → (3) = B

식의 꼴은 13쪽과 같고 N만 붙었습니다. ∂L∂W는 N이 몇이든 W와 같은 (2, 3)입니다. XT · ∂L∂Y의 곱 안에서 N개 샘플의 기여가 더해지기 때문입니다.

∂L∂B = ∂L∂Y를 axis 0으로 합한 것

the sum over the first axis (axis 0, column-wise)

첫 번째 축(axis 0, 열 방향)으로 더한 것. 즉 세로로(행을 따라 내려가며) 더해 열마다 하나씩 남깁니다.

  • 왜 더하나: 순전파에서 B (3,) 하나가 N개 행 모두에 더해졌습니다(→ P2 21의 b1처럼). B가 N개 샘플 모두에 영향을 주었으므로 N개 샘플의 기울기를 모두 더한 것이 B의 기울기입니다.
  • 평균이 아니라 합입니다. 평균(÷ N)은 손실을 배치 평균으로 정의할 때 맨 끝의 dy = (y − t) ÷ batch_num에서 이미 처리됩니다(→ 19, P2 23).

Implementing the Learning Algorithm — Neural network training typically consists of the following steps: 1. Mini-batch selection 2. Gradient computation 3. Parameter update 4. Iteration
  1. 미니배치 선택: 훈련 데이터에서 일부를 무작위로 고릅니다. 목표는 이 미니배치로 계산한 손실 함수 값을 최소화하는 것입니다.
  2. 기울기 계산: 미니배치로 각 매개변수에 대한 손실의 기울기를 구합니다. 기울기는 손실이 가장 빠르게 증가하는 방향입니다. 여기에 오차역전파를 씁니다.
  3. 매개변수 갱신: 각 매개변수를 기울기의 반대 방향으로 조금 옮깁니다.
  4. 반복: 1–3단계를 수렴할 때까지, 또는 정해 둔 에폭 수만큼 되풀이합니다.

P2 18쪽과 문장까지 같은 4단계입니다(→ P2 18). 달라진 것은 2단계의 방법입니다. P2에서는 수치 미분(numerical_gradient)과 오차역전파(gradient) 두 방법이 코드에 함께 있었고, 이 교안은 그중 오차역전파의 원리를 설명한 것입니다.
