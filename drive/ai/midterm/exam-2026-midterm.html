1.

선형회귀(Linear Regression)에 대한 설명으로 가장 적절한 것은?

  1. ①입력 데이터의 특성을 기반으로 데이터를 여러 그룹으로 분류하는 방법이다.
  2. ②입력 변수와 종속 변수 사이의 관계를 선형 함수로 모델링하여 연속적인 값을 예측하는 방법이다.
  3. ③입력 데이터의 유사성을 기반으로 정답 레이블 없이 군집을 형성하는 방법이다.
  4. ④여러 개의 결정 트리를 결합하여 예측 성능을 향상시키는 방법이다.
2.

과적합 (Overfitting)

로지스틱(Logistic) 회귀에서 사용하는 시그모이드(Sigmoid) 함수에 대한 설명으로 가장 적절한 것은?

  1. ①입력값을 0 또는 1로만 변환하여 출력한다.
  2. ②입력값을 0과 1 사이의 값으로 변환하여 클래스에 속할 확률을 표현할 수 있도록 한다.
  3. ③입력값과 출력값 사이의 관계를 직선으로 표현하여 연속적인 값을 예측한다.
  4. ④입력 데이터의 유사도를 계산하여 여러 군집으로 구분한다.
4.

회귀 모델의 성능 지표인 결정계수(Coefficient of Determination, R2)에 대한 설명으로 옳은 것을 모두 고르시오.

  1. ①R2는 모델이 데이터(종속 변수)의 변동을 얼마나 설명하는지 나타내는 지표이다.
  2. ②R2 = 1이면 모델의 예측값이 모든 실제값과 일치한다.
  3. ③R2 = 0이면 모델의 예측값이 모든 실제값과 일치한다.
  4. ④R2가 음수이면 모델의 예측 성능이 실제값의 평균만 예측하는 기준 모델보다 낮다는 의미이다.

9.

서포트 벡터 머신(Support Vector Machine, SVM)에 대한 설명으로 옳지 않은 것은?

  1. ①SVM은 결정 경계를 찾을 때 마진(Margin)을 최소화하는 것을 목표로 한다.
  2. ②서포트 벡터는 결정 경계의 위치를 결정하는 데 중요한 역할을 하는 데이터 샘플이다.
  3. ③Hard Margin SVM은 모든 훈련 데이터를 올바르게 분류하는 결정 경계를 찾는다.
  4. ④Soft Margin SVM은 일부 마진 위반이나 오분류를 허용한다.

K-means의 한계에 해당하는 설명을 모두 고르시오.

  1. ①군집 수 K를 사전에 정해야 한다.
  2. ②복잡한 형태를 가진 군집을 구분하는 데 어려움이 있을 수 있다.
  3. ③크기와 밀도가 크게 다른 군집을 구분할 때 어려움이 있을 수 있다.
  4. ④데이터에 이상치가 있어도 중심점은 전혀 영향을 받지 않는다.

DBSCAN에 대한 설명으로 가장 적절한 것은?

  1. ①데이터의 밀도를 이용하고, 군집에 속하지 않는 노이즈를 구분할 수 있다.
  2. ②항상 군집 수 K를 사전에 정해야 한다.

  4. ④각 군집의 평균 중심점을 반복적으로 갱신한다.

16.

분류 의사결정트리(Decision Tree)에서 좋은 분할(Split)에 대한 설명으로 옳은 것을 모두 고르시오.

  1. ①분할 후 자식 노드의 불순도(Impurity)가 높아지는 방향을 우선한다.
  2. ②지니(Gini) 불순도의 감소량이 큰 분할을 우선한다.
  3. ③엔트로피(Entropy)를 기반으로 계산한 정보이득이 큰 분할을 우선한다.
  4. ④분할할 때 클래스 레이블은 이용하지 않는다.
17.

다음은 고객의 대출 승인 여부를 예측하기 위해 학습된 의사결정트리(Decision Tree)이다. 의사결정트리와 고객 정보를 참고하여, 옳지 않은 설명을 고르시오.

  1. ①의사결정트리의 최대 깊이(Max Depth)는 3이다.
  2. ②고객 A(신용점수 680 / 월 소득 450만원 / 연체 이력 있음 / 부채 비율 30%)는 최종적으로 대출이 거절되는 것으로 예측된다.
  3. ③의사결정트리에서 좋은 분할은 일반적으로 자식 노드의 지니 불순도(Gini Impurity) 또는 엔트로피(Entropy)를 감소시키는 방향으로 이루어진다.
  4. ④이 의사결정트리의 모든 리프 노드(Leaf Node)는 동일한 깊이에 위치한다.
18.

랜덤 포레스트(Random Forest)에 대한 설명으로 옳은 것을 모두 고르시오.

  1. ①여러 결정트리를 결합하며, 분할 시 사용할 특성의 후보를 무작위로 제한할 수 있다.
  2. ②배깅(Bagging)을 이용하여 훈련 데이터에서 복원추출한 서로 다른 데이터 샘플로 각 트리를 학습시킨다.
  3. ③Out-of-Bag 샘플은 각 트리의 학습에 사용되지 않은 데이터이다.
  4. ④여러 결정트리의 예측 결과를 결합하면 개별 결정트리에 비해 일반적으로 예측의 분산이 증가한다.
19.

다음은 앙상블 학습(Ensemble Learning)의 여러 방법에 대한 설명이다. 각 설명에 해당하는 학습 방법을 쓰시오.

Hard voting  /  Soft voting  /  Bagging  /  Boosting
  1. 훈련 데이터에서 복원추출한 샘플로 여러 모델을 독립적으로 학습시키고, 각 모델의 예측 결과를 결합한다.( Bagging )
  2. 여러 모델이 예측한 클래스 중 가장 많은 표를 얻은 클래스를 최종 예측 결과로 선택한다.( Hard voting )
  3. 이전 모델의 예측 오류를 보완하도록 여러 모델을 순차적으로 학습시킨다.( Boosting )
  4. 여러 모델이 예측한 클래스별 확률을 평균하여 최종 예측 클래스를 결정한다.( Soft voting )
20.

Permutation Importance에 대한 설명으로 가장 적절한 것은?

  1. ①특정 특성(Feature)의 값을 무작위로 섞었을 때 모델의 예측 성능이 얼마나 감소하는지를 이용하여 특성 중요도를 평가한다.
  2. ②특정 특성(Feature)의 값이 클수록 해당 특성의 중요도가 높다고 판단한다.
  3. ③모델에서 가장 많이 사용된 특성을 항상 가장 중요한 특성으로 평가한다.
  4. ④특정 특성(Feature)의 값을 무작위로 섞었을 때 모델의 예측 성능이 향상되면 해당 특성의 중요도가 높다고 판단한다.
