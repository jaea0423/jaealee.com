# 비활성 보관함

사용 중단이 확인된 파일을 삭제 대신 보존하는 공간입니다. 실행 중인 서비스의 백업 복제본을 계속 쌓는 용도로 사용하지 않습니다.

## 보관 목록

| 위치 | 원래 위치 / 상태 | 보관 이유 |
|---|---|---|
| `reading/` | 이번 정리 이전부터 보관 중 | 기존 상태 유지. 최초 이동 시점·원래 공개 경로는 미확인 |
| `screen-archive.html` | 이번 정리 이전부터 보관 중 | 기존 상태 유지. 최초 이동 시점·원래 공개 경로는 미확인 |

## 보관 방법

1. 사용 중단 여부와 기존 링크·실행 경로를 확인합니다. 외부 공유 여부가 불명확한 공개 페이지는 유지합니다.
2. 관련 파일은 원래 내부 구조를 유지해 `_disabled/<기존 폴더명>/`으로 옮깁니다. 기존 보관 항목을 덮어쓰지 않습니다.
3. 위 목록에 원래 위치·이동 날짜·사유를 기록합니다. 복원할 때는 원래 위치의 새 파일과 충돌하지 않는지 확인합니다.
4. `/test`는 외부 공유 중이므로 명시적인 별도 요청 없이는 이곳으로 옮기지 않습니다.

이 폴더는 접근 제어가 아닙니다. 서버의 배포 방식에 따라 웹에서 접근할 수도 있으므로 비밀키·개인 설정·민감한 자료를 넣지 않습니다. 보관된 웹페이지의 동작은 보장하지 않으며, 복원할 때 링크와 외부 연동을 검증합니다.
