# 대경빌 주차 관리 시스템

정적 HTML + Supabase 로 만든 원룸 주차 등록 관리 도구입니다.

```
index.html   방문자용 - 등록 차량 번호 목록 (번호판 모양)
admin.html   관리자용 화면 구조
admin.js     관리자용 동작 (로그인·등록·관리·QR·기록)
config.js    Supabase 주소·키, 건물 이름
style.css    공용 디자인
setup.sql    Supabase 설정 SQL (내용이 바뀌면 다시 실행)
```

---

## 설정

### 1. Supabase 프로젝트
https://supabase.com → New project (Region: Northeast Asia / Seoul 권장)

### 2. 표 만들기
왼쪽 **SQL Editor** → `setup.sql` 통째로 붙여넣고 **Run**.
여러 번 실행해도 안전하므로, 이 파일이 갱신되면 다시 실행하면 됩니다.

### 3. 관리자 계정
**Authentication → Users → Add user → Create new user**

- Email: `config.js` 의 `ADMIN_EMAIL` 과 **똑같이**
- Password: 처음 쓸 PIN 6자리
- **Auto Confirm User 를 반드시 켜세요** (안 켜면 로그인이 막힙니다)

### 4. config.js
**Project Settings → API** 에서 `Project URL` 과 `anon public` 키를 복사해 넣습니다.
`BUILDING`(건물 이름), `CONTACT`(이동주차 요청 연락처)도 여기서 바꿉니다.
`CONTACT` 를 채우면 첫 화면 안내판에 전화 버튼이 생깁니다.

## 왜 PIN 을 Supabase 비밀번호로 쓰나요?

이 사이트는 **정적 사이트(static site)** 입니다.
브라우저가 받아 가는 건 HTML/CSS/JS 파일 그 자체라서,
`if (pin === "123456")` 같은 검사를 JS 안에 적으면 F12 로 그대로 보입니다.
**문에 자물쇠가 아니라 "들어오지 마세요" 팻말을 붙이는 것**과 같습니다.

그래서 PIN 을 **Supabase 계정의 비밀번호 자체**로 씁니다.

- PIN 검사는 브라우저가 아니라 **Supabase 서버**가 합니다
- DB 에 **RLS(Row Level Security, 행 수준 보안)** 가 켜져 있어,
  로그인하지 않은 사람은 `vehicles` 표를 읽지도 쓰지도 못합니다
- 방문자에게는 **차량번호만** 들어 있는 뷰(`vehicles_public`)만 열려 있습니다

`anon key` 가 소스에 보이는 것은 정상이며 원래 공개용 키입니다.
실제 권한은 RLS 정책이 정합니다.

## 사용법

**방문자** — `index.html`
지금 등록 기간 중인 차량 번호만 번호판 모양으로 보입니다.
5분마다 자동으로 새로 불러오므로 태블릿에 띄워 둬도 됩니다.

**관리자** — 제목 **"등록 차량"** 을 1.5초 안에 5번 연속 클릭 → `admin.html`

### 등록
호실 · 차량번호 · 시작일 · 종료일을 한 화면에서 입력합니다.
차량 종류와 메모는 아래 **선택 항목** 을 펼치면 나옵니다.
이미 등록된 번호를 입력하면 바로 경고가 뜹니다 (막지는 않습니다).

### 관리
- 위쪽에 **만료 임박 배너** — 7일 안에 끝나는 차량 수. `보기` 를 누르면 그 차량만 걸러집니다.
- **검색** — 차량번호 · 호실 · 차종 · 메모를 한 번에 찾습니다.
- **탭** — 등록 중 / 등록 예정 / 만료 / 삭제됨 (각각 대수 표시).
- **빠른 연장** — 만료됐거나 임박한 차량 오른쪽의 `＋1주` `＋1개월` 버튼.
  이미 지난 종료일에 붙지 않도록, 기존 종료일 다음 날과 오늘 중 **늦은 쪽**부터 셉니다.
- 차량을 누르면 수정 화면 → 저장 / 삭제 → (삭제됨 탭에서) 복구 · 영구 삭제
- **QR** — 첫 화면으로 연결되는 QR 을 만들어 PNG 로 저장합니다. 인쇄해서 주차장에 붙이면 됩니다.
- **기록** — 등록 · 수정 · 연장 · 삭제 · 복구 · 영구삭제 이력 (최근 200건).

### 로그인 방식
비밀번호 변경 화면에서 **PIN** 과 **비밀번호** 중 고르면, 그 설정이 저장되어
다음 로그인 화면이 바뀝니다.

- **PIN**: 숫자 키패드. 6자리를 누르면 자동으로 로그인됩니다.
  `새로고침` = 전부 지움, `지우기` = 한 글자 지움. PC 에서는 키보드 숫자도 됩니다.
- **비밀번호**: 8자 이상, 대문자·숫자·특수문자 포함. 입력칸 + 보기 버튼.
- 아래 `비밀번호로 입력` / `PIN 으로 입력` 링크로 그때그때 바꿔 쓸 수도 있습니다.

### 로그인 잠금
비밀번호를 틀리면 **이 기기에서** 대기 시간이 붙습니다.

| 누적 실패 | 대기 |
|---|---|
| 5회 | 30초 |
| 10회 | 1분 |
| 15회 | 3분 |
| 20회 | 10분 |
| 25회 | 1시간 |
| 30회 | 24시간 |
| 35회 | 잠김 |

성공하면 기록이 지워집니다.
이 기록은 그 브라우저에만 남으므로, **다른 기기나 시크릿 창에서는 처음부터 다시 셉니다.**
서버 쪽 차단이 아니라 "그 기기에서 막는" 방식이라는 점을 알고 쓰세요.
(Supabase 자체 요청 제한은 별개로 걸려 있습니다.)
잠긴 기기는 브라우저 저장 데이터를 지우면 풀립니다.

### 입력 규칙

- **호실**: `401` 만 넣으면 저장할 때 `401호` 가 됩니다. 목록은 호실 숫자 순으로 정렬됩니다.
- **차량 번호**: 띄어쓰기를 넣을 수 없습니다. `12가2132` 로 붙여 쓰면
  `12가 2132` 로 자동으로 띄웁니다.
- **종료일**: 비워 두면 **미정**으로 저장되고 만료되지 않습니다.
  빠른 버튼: 3주 / 1개월 / 3개월 / 6개월 / 12개월 / 미정
- **기간 계산**: n개월은 "n개월 뒤 같은 날의 하루 전" 입니다.
  10월 1일 + 1개월 → 10월 31일, 9월 4일 + 1개월 → 10월 3일.
  대상 월에 그 날짜가 없으면 말일로 맞춥니다 (1월 31일 + 1개월 → 2월 28일).
- **등록일 / 마지막 수정일**: 자동 기록. 수정 화면 아래 `기록` 칸에서 볼 수 있습니다.

로그인 상태는 브라우저에 유지됩니다. 공용 PC 에서 썼다면 **로그아웃** 을 눌러 주세요.

## 로그인이 안 될 때

로그인 화면 아래 **"연결 확인"** 을 누르면 어디가 막혔는지 보여 줍니다.
실패 시에는 Supabase 가 돌려준 **원문 오류**가 화면에 그대로 표시됩니다.

1. **계정이 "인증 대기" 상태** — 가장 흔합니다.
   Authentication → Users 에서 **Confirmed At** 이 비어 있으면 이 경우입니다.
   사용자를 지우고 **Auto Confirm User 를 켜고** 다시 만드세요.
2. **이메일 주소 불일치** — `config.js` 의 `ADMIN_EMAIL` 과 Supabase 계정 주소가 같아야 합니다.
3. **이메일 로그인 provider 꺼짐** — Authentication → Sign In / Providers → Email
4. **비밀번호가 다름** — Users → 해당 계정 → Reset password
