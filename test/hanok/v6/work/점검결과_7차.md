- 백업 `fetch.py`: `BACKUP_PAGE`>1000 이면 조용히 불완전 백업(assert 추가), `logs?order=at` 은 동시각 타이로 경계 중복/누락 가능(`order=at,id`). PII 가 git 히스토리에 영구 보존 → 2FA·보존기간·암호화 검토.
- `mask_name`: 한 글자 이름은 그대로 노출, 별 개수로 이름 길이 노출(`T * * * * * * * * e`). `length<=1→'*'`, 별 1개 고정 권장. `public_today` 는 오늘 시각·인원·도착 여부를 인터넷 어디서나 폴링 가능 → 시간 창(지금-1h 이후) 제한 검토.
- REST 로 하드 삭제된 행은 델타에 안 잡혀 다른 기기 화면에 남음(앱 정상 경로엔 없음. seed clear 뒤엔 새로고침).
- 로그 detail 에 전화번호 전체(`delRes`) → 마지막 4자리만.

## 7. 확인했고 문제 없던 것 (요약)

- XSS 텍스트 노드: 이름·전화·메모·요청·알러지·경로상세에 `<img onerror>` `<svg onload>` `'` `"` 넣어 등록 → 모든 화면에서 실행 0 (**재현**). `eval/new Function/document.write` 없음.
- 세션 갱신(refresh_token) 실동작, 연속 저장 3건 flush 겹침 정상, 검색 `includes`(정규식 주입 없음), 조건부 PATCH 충돌·삭제 처리, 델타 dirty 보호, 동일 결론 충돌 흡수(`canon`), `updated_at` 문자열 비교 안전(UTC 고정).
- RLS: anon 은 테이블 revoke + 정책 없음(이중), 뷰에 전화·메모 없음, service_role 은 Secrets 에만, build.py 가 JWT 형 service_role 차단.
- 금지 문법: `?. ?? .flat .replaceAll structuredClone inset backdrop-filter :has :is @container color-mix oklch` 전부 없음. `zoom` 규칙 준수. z-index 사다리 겹침 없음. @supports 폴백은 블록 안.
- 타이머 중복 없음(clear 후 재설정), 히스토리 보호(`{wz:1}` 보존, back 중복 방지), 마법사·시트·모달 열림 중 1분 갱신 건너뜀, 겹침 계산 대칭·경계 정확, 같은 번호·노쇼 정규화, 스냅샷·예약률 분모, 코스 키 정규화.
- 설정: 숫자 입력 NaN/0 방지, 룸 삭제 시 displayRows·zones 안전, 코스 삭제 후 렌더 안 깨짐.
