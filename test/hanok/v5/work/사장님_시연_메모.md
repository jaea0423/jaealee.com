## 2. 보여드릴 화면 순서 (링크: jaealee.com/test/hanok/v5 · PIN 은 재아가 알려 드림)

1. 폰에서 열기 → PIN → 오늘 목록. 한 건 눌러 상세(방문/취소/수정).
2. 오른쪽 아래 ＋ → 예약 등록 마법사 한 바퀴(경로 → 날짜·시각 → 인원 → 좌석 → 메뉴 → 예약자 → 요청). 마지막에 "한 화면으로 입력" 도 있음.
3. 상단 스위치로 타임라인. 홀·룸별 블록, 잠정(빗금)·경고(벽돌)·변동(파란 칩).
4. 📅 로 다른 날짜 → 상단이 검정으로 바뀜(오늘이 아니라는 표시).
5. ⋮ → 설정: 좌석, 운영시간, 코스, 문자 문구, 디스플레이 배치, 보안(PIN 변경).
6. PC 나 태블릿에서 같은 링크 → 같은 예약이 있는지. 한쪽에서 고치면 1분 안에 다른 쪽에 반영.
7. TV: `jaealee.com/test/hanok/v5/screen/` — 광고 영상 + 오늘 예약(가린 이름).

## 3. 아직 흉내이거나 없는 것 (솔직하게)

- **문자**는 화면에만 "보냄" 으로 표시되고 **실제로 안 나갑니다.** 실제 발송은 문자 업체 가입(건당 10~20원)과 발신번호 등록(사업자 서류)이 필요 → 결정 사항.
- 지금 링크는 **연습용 DB** 입니다. 실서비스로 갈 때 새 DB 로 바꾸고 더미는 안 가져갑니다.
- 안집은 화면만 있고 비활성.
- 예약금·대기 손님·발렛은 없음(1차 때 "다음에 물어볼 것").
- 업장 TV 브라우저에서 실제로 뜨는지는 **아직 확인 못 함**(2018~2020년 TV 는 안 될 수 있음). 매장 가서 한 번 열어 봐야 함.

## 5. 사장님 판단이 필요한 기능 (만들지 말지)

1차 "다음에 물어볼 것" 그대로 + 이번에 새로 생긴 것:
- 브레이크타임에 손님이 나가야 하는지 (지금은 브레이크에 걸치면 '경고' 만)
- 빈 방이 여러 개일 때 어느 룸부터 채울지 (지금은 작은 방부터)
- 주방에 코스 인원을 언제까지 알려 주는지 → 그 뒤 변동을 따로 표시할지
- 문자: 실발송 할지, 접수 때/전날 중 언제
- 예약 이력(누가 언제 뭘 고쳤는지)이 남는데, 직원에게 보여도 되는지
- **설정(좌석·영업시간)을 직원도 바꿔도 되는지** — 지금은 PIN 으로 들어온 누구나 가능. 사장님만 가능하게 하려면 관리자 비밀번호를 물어야 함(재아 결정: 일단 안 걸음)
