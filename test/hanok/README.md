# 한옥반점 예약 관리 시스템

식당 예약을 전화로 받아 관리하는 시스템입니다. HTML 파일 하나로 동작합니다.

## 빠르게 보기

`dist/hanok-admin.html` 을 브라우저로 열면 됩니다.
PIN은 **1234**, 관리자 비밀번호는 **admin1234** 입니다.

TV 화면은 주소 뒤에 `/screen` 을 붙이면 바로 열립니다.
파일로 열었을 때는 `#/screen` 을 씁니다.

## 고칠 때

```
src/index.html  ← 여기를 고칩니다
python3 build.py
dist/hanok-admin.html  ← 결과물 (직접 고치지 마세요)
index.html             ← 사이트 배포용. dist 와 같은 내용이 함께 만들어집니다
```

`build.py` 는 이미지를 넣으면서 **구형 브라우저 미지원 문법도 검사**합니다.
경고가 뜨면 스마트TV에서 흰 화면이 나오니 반드시 고쳐야 합니다.

## 문서

- `docs/인수인계.md` — 데이터 구조, 함수 지도, 설계 이유, 다음 할 일
- `docs/검토사항.md` — 사장님께 확인받을 목록 (자료 요청, 결정 필요 사항)
