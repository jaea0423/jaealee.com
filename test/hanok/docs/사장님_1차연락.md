## 답을 받으면 시스템에서 바꿀 곳

| 받는 것 | 반영 위치 |
|---|---|
| 룸 정원·층 | 설정 → 좌석 |
| 홀 테이블·구역·붙임 | 설정 → 좌석 → 테이블 구성 (zone) |
| 체류 시간 | 설정 → 예약 규칙 (룸/홀 × 점심/저녁 네 칸) |
| 좌석 사진 | **새 기능** — 좌석 고를 때 사진 띄우기 (지금은 이름만) |
| 문자 필요 여부·시점 | 설정 → 문자 안내 / 실제 발송은 **업체 가입·발신번호 등록 필요** |
| 안 쓰는 기능 | 화면에서 제거 — **코드 수정** |
| 없는 기능 | `점검결과.md` 6장 우선순위에 반영 |
