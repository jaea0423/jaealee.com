### 왜 체류 시간을 값까지 적어서 묻는가

"체류시간이 어떻게 되세요?" 라고 열어 놓고 물으면 **"글쎄, 한 두 시간?"** 하나가 옵니다.
지금 넣어둔 네 값을 보여주고 "많이 다른가요?" 로 물으면 틀린 것만 고쳐서 돌아옵니다.
**열린 질문보다 검증 질문의 답률이 높습니다.** 네 줄 늘어날 값어치가 있습니다.

지금 값 (`설정 → 예약 규칙`):

| | 점심 | 저녁 |
|---|---|---|
| 룸 | 2.5시간 | 3시간 |
| 홀 | 2시간 | 2.5시간 |

### "덜어낼 기능" 을 한 번 더 밀어 주는 이유

사람은 보통 **추가할 것만 말하고 뺄 것은 안 말합니다.** 빼자고 하면 만든 사람이
서운할까 봐서요. 그래서 "특히 안 쓸 것 같은 거" 를 따로 한 줄 더 붙였습니다.
이 답이 실제로는 더 값어치가 큽니다 — 화면에 안 쓰는 게 많으면 정작 필요한 걸 못 찾습니다.

넣고 싶었지만 **첫 문자에 부탁이 넷을 넘으면 답이 안 옵니다.** 다음 차례로 미뤘습니다.

| 뺀 것 | 왜 지금은 아닌가 |
|---|---|
| 룸 정원·층 확인 | 좌석 배치 답에 어차피 들어옵니다 |
| 영업시간 확인 | 화면에 떠 있으니 틀리면 먼저 말씀하십니다 |
| 예약 받는 순서 | 화면을 써보신 다음이라야 비교가 됩니다 |
| 주방 마감 시각 | 가장 중요하지만 설명이 길어집니다. 따로 물어야 합니다 |
| 문자를 실제로 붙일지 | "40원"만 흘려두고, 먼저 물어보시길 기다립니다 |
| 확인 필요 아홉 개 줄이기 | 써보셔야 뭐가 거슬리는지 압니다 |

## 답을 받으면 시스템에서 바꿀 곳

| 받는 것 | 반영 위치 |
|---|---|
| 룸 정원·층 | 설정 → 좌석 |
| 홀 테이블·구역·붙임 | 설정 → 좌석 → 테이블 구성 (zone) |
| 체류 시간 | 설정 → 예약 규칙 (룸/홀 × 점심/저녁 네 칸) |
| 좌석 사진 | **새 기능** — 좌석 고를 때 사진 띄우기 (지금은 이름만) |
| 문자 필요 여부·시점 | 설정 → 문자 안내 / 실제 발송은 **업체 가입·발신번호 등록 필요** |
| 안 쓰는 기능 | 화면에서 제거 — **코드 수정** |
| 없는 기능 | `점검결과.md` 6장 우선순위에 반영 |
