## 1. 이 프로젝트가 뭔가

강원도 춘천 중식당 **한옥반점**(고모 가게)의 예약 관리 시스템입니다.
재아(컴공 2학년)가 혼자, 무상으로 만듭니다.

- **쓰는 사람**: 사장님(고모)과 홀 직원. **개발자가 아닙니다.**
- **쓰는 기기**: 카운터 태블릿(주력) > 사장님 폰 > 손님용 TV > PC
- **형태**: HTML **파일 하나**. CSS·JS·이미지(base64)가 전부 안에 들어 있습니다. 약 1.4MB
- **현재 상태**: 한옥반점만 구현. 안집은 화면만 있고 비활성

## 2. 절대 어기면 안 되는 것

### 2-1. `src/index.html` 만 고칩니다

```
src/index.html      ← ★ 여기만 고칩니다
build.py            ← 이미지를 넣어 아래 둘을 만듭니다
dist/hanok-admin.html   ← 자동 생성. 손대지 마세요
index.html              ← 자동 생성(사이트 배포용). 손대지 마세요
```

`dist/` 와 루트 `index.html` 은 1.4MB base64 덩어리라 편집이 불가능합니다.
`src/index.html` 안의 `__BG1_B64__` ~ `__BG7_B64__`, `__ANJIP_B64__`, `__HANOK_B64__`
자리표시자를 **절대 지우거나 바꾸지 마세요.**

고친 뒤에는 반드시:

```bash
python build.py
```

`구형 브라우저 문법 검사 통과` 가 떠야 정상입니다.

### 2-2. 구형 스마트TV 문법 금지

손님용 화면을 2018~2020년 크롬이 도는 업장 TV에 띄웁니다. 다음을 쓰면 **화면이 통째로 죽습니다.**

| 금지 | 대신 |
|---|---|
| `?.` (옵셔널 체이닝) | `a && a.b` |
| `??` | `a != null ? a : b` |
| `.flat()` `.replaceAll()` | `.reduce(concat)` / `.split().join()` |
| `structuredClone` | `deepClone()` (이미 있음) |
| `:has()` `:is()` `@container` | 클래스를 직접 붙이기 |

`build.py` 가 이 중 일부를 잡아 주지만 전부는 아닙니다.

CSS 도 조심: `inset:` 단축은 지금 17군데 쓰이는데 **구형 TV 에서 안 먹습니다.**
새로 쓸 때는 `top/right/bottom/left` 를 풀어 쓰세요.
`backdrop-filter` `color-mix()` `oklch()` 도 안 됩니다 — 애플식 디자인에서 쓰고 싶어질 것들이라 미리 적어 둡니다.

### 2-3. 배율은 `zoom`, `transform:scale` 금지

`.shell`, `.lock`, `.modal-ov` 에 `zoom:var(--ui-zoom, 1.1)` 이 걸려 있습니다.
`transform:scale` 은 원래 자리를 그대로 차지해 화면이 잘립니다. **바꾸지 마세요.**

### 2-4. 경고는 막지 않고 알리기만 (설계 원칙, 예외 없음)

사장님이 판단할 일을 시스템이 막으면 안 됩니다.
자리 겹침, 정원 초과, 라스트오더 이후 — 전부 **빨갛게 알리되 진행은 됩니다.**
디자인을 바꾸면서 이 원칙이 흐려지지 않게 하세요. 경고는 눈에 띄어야 합니다.

### 2-5. 주석은 한국어로, '왜'를 씁니다

이 코드는 나중에 재아 혼자 읽습니다. `/* 여백 조정 */` 말고
`/* TV는 3~5m 떨어져서 봅니다. 작으면 그냥 안 보입니다 */` 처럼 이유를 남기세요.

## 3. 지금 CSS 가 어떤 상태인가 — **디자인 작업 전 필독**

| | 수치 |
|---|---|
| CSS 줄 수 | 약 2,500줄 (`src/index.html` 12~2511행) |
| 규칙 수 | 약 1,230개 |
| **3번 이상 재정의된 셀렉터** | **75개** |
| 최다 재정의 | `.tl-name` **13번**, `.tv` 8번, `.tl-rate` 8번 |
| `@media` | 61개 |

**왜 이렇게 됐나**: 요청이 올 때마다 파일 끝에 덮어쓰기 블록을 붙였습니다.
CSS 는 우선순위가 같으면 **뒤에 온 것이 이깁니다.** 그래서 앞의 정의를 읽고
고쳐 봐야 뒤의 블록이 덮어씁니다.

**실제로 이것 때문에 난 사고**:
`@supports` 없이 파일 끝에 둔 clamp 폴백이 모든 브라우저에서 앞의 clamp 를 덮어써,
디스플레이 모드 글자가 화면 크기와 무관하게 항상 19px 로 나왔습니다.
한 달 가까이 아무도 몰랐습니다.

→ **디자인을 갈아엎기 전에 CSS 통합이 먼저입니다.** 자세한 계획은 `docs/디자인개편.md`.

## 6. 지금 미완성인 것 (디자인과 무관하지만 알고는 있어야 함)
